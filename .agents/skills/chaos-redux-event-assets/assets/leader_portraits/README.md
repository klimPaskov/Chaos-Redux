# HOI4 leader portrait reference shelf

This compatibility shelf exists at the user-facing `assets/leader_portraits/`
path requested for portrait work. It contains review-only Vanilla HOI4 leader
portrait references at their native full-portrait canvas; it is never a runtime
asset destination and must not be wired into a `.gfx` file.

The canonical organized library remains
`../vanilla_reference/portraits/leaders/`. Keep the two shelves byte-aligned
when a reference is refreshed, and use `REFERENCE_MANIFEST.md` for the current
file list and source relationship. The contact sheet is a labelled review aid,
not a portrait to ship.

Use these references for framing, head-and-shoulders scale, subdued painted
finish, period clothing, quiet backgrounds, and the 156x210 leader-portrait
family. For a grounded historical person, still follow the mandatory workflow:
unchanged attributed archival photograph, exact head-and-shoulders crop,
identity-preserving ImageGen HOI4 repaint, deterministic 156x210 candidate,
independent likeness/style/provenance audit, then DDS wiring only after PASS.

This shelf contains no Event 006 advisor icons, dossier portraits, or small
portrait derivatives.
