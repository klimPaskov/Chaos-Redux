# HOI4 leader and commander reference pack

This skill-local pack is a curated male-only review aid for Chaos Redux country-leader and army/navy-commander portraits. Every reference is a byte-identical copy of a canonical vanilla reference under `../vanilla_reference/portraits/`; the pack is not runtime art and must never be wired into the mod.

Use `leaders/contact_sheet.png` for full `156x210` country-leader framing and `commanders/contact_sheet.png` for full `156x210` army/navy-commander framing. Inspect the native portrait and the contact sheet together. The subdued painted finish, head-and-shoulders or restrained-bust crop, quiet period background, readable face at 156x210, controlled contrast, and lack of text or modern props are the style baseline.

Grounded Event 006 people are not generated from these references. Use the unchanged archival male source, exact head-and-shoulders crop, identity-preserving ImageGen repaint, deterministic `156x210` processing, independent likeness/style/provenance audit, and only then DDS wiring. Truly fictional high-chaos people may be generated, but must be distinctive and culturally coherent without gore, stereotypes, memes, or normal interchangeable faces.

The source mapping, native dimensions, hashes, and male-only selection boundary are recorded in `REFERENCE_MANIFEST.md`. The canonical semantic reference library remains `../vanilla_reference/`; this pack exists so an agent can open the exact HOI4 leader/commander examples quickly without confusing them with advisor cards, operatives, icons, flags, or event art.
