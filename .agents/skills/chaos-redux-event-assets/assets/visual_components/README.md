# Visual components

This folder holds the asset skill's reusable visual references and background layers. Every PNG and PSD is available locally. Use [CATALOG.md](CATALOG.md) to find a file by family, canvas, transparency, and approved role, then inspect its labeled contact sheet and the individual image.

- [Focus pieces](focus_pieces/contact_sheet.png) show subject scale, silhouette, shading, and composition for ImageGen prompts.
- [Focus backgrounds](focus_backgrounds/contact_sheet.png) show frame and emblem arrangements for reference.
- [Idea, national spirit, and decision category backgrounds](national_spirit_backgrounds/contact_sheet.png) include catalog-marked persistent backdrop layers. The decision category roundel is a candidate for that family; circle, rectangle, ring, and shield backgrounds are candidates for idea or national spirit art.
- [Portrait backdrops](portrait_backdrops/contact_sheet.png) are framing references within the existing portrait workflow.

The installed vanilla or Chaos Redux consumer and the matching canonical reference family determine final dimensions, alpha, frame behavior, and sprite wiring. An approved backdrop remains a separate source layer beneath original ImageGen subject art. Keep the source, prompt, composite PNG, and final DDS distinct in the asset handoff. These library files are not runtime GFX.
