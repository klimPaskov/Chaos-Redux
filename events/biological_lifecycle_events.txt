# ============================================================================
# CHAOS REDUX - ORDINARY BIOLOGICAL LIFECYCLE STATE EVENTS
# ============================================================================
# Overview:
# - Executes exact-state incubation and weekly lifecycle callbacks for the four
#   ordinary biological agents.
# - Scripted effects own due-day guards and scheduler flags, so stale or
#   duplicate callbacks cannot apply a second tick.
# - These events are triggered only by an affected state; no global pulse is
#   used. Weaponized zombies are intentionally excluded.
# ============================================================================
