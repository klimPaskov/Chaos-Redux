# ============================================================================
# CHAOS REDUX - EVENT 028 ASTEROID INCOMING
# ============================================================================
# The global major event is dispatched by the shared event pool. The dispatcher
# prepares one exact three-pair target board before this opening event appears;
# the event itself only stages a selected pair, accepts the two-day trajectory,
# and presents the target country's one preparedness decision.
#
# Physical resolution is owned by the Event 028 runtime effects. It plans the
# main and fragment footprints before mutating any state, merges overlaps by
# strongest profile, records exact population losses through the shared Deaths
# ledger, and reports current owner/controller receipts after the impact.
# Nuclear-scale map visuals are presentation only; no nuclear ledger, fallout,
# condemnation, retaliation, nuclear Chaos, or nuclear Deaths path is used.
# ============================================================================
