# ============================================================================
# CHAOS REDUX - EVENT 030 TIME TRAVELER
# ============================================================================
# A man who remembers a later time appears in one country. Two proofs verify
# him, the host chooses how he works with the state, and the strongest
# rewards come from consultations whose objectives the government carries out.
# Foreign countries compete for him and for the copied knowledge. The events
# below are the chain. Choices, costs and objectives live in the decisions
# (common/decisions/030_time_traveler_decisions.txt) and the scripted effects
# (common/scripted_effects/030_time_traveler_*.txt).
#
#   .1   hidden entry on the selected host
#   .2   opening report, five ways to handle the visitor
#   .3-.7 remembered war variants (Germany and the Soviet Union, the United States)
#   .10  first proof        .11 second proof        .12 forecast checked
#   .13  access arrangement .14 revision            .15 the visitor leaves
#   .16  a shared forecast reaches an ally
#   .20  family picker      .21 offer               .22 success
#   .23  partial result     .24 failed result
#   .30  hidden rival turn (AI members only)
#   .31  compromised staff  .32 forged advice       .33 asylum declined
#   .34  seizure report     .35 archive copied      .36 foreign cell caught
#   .37  report of a foreign operation (human members)
#   .38  captured double    .39 sting result        .54 bait result
#   .40  hidden rumor dispatcher, .41-.46 the six rumors
#   .50  a human country learns it may act
#   .51  custody lost       .52 traveler killed     .53 traveler vanished
#   .55  the traveler leaves by agreement
# News: chaosx.news.300 public revelation, .301 the Berlin-Moscow Axis,
# .302 intelligence on Japan.
# ============================================================================
