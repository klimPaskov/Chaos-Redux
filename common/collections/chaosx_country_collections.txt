# ============================================================================
# CHAOS REDUX - REUSABLE COUNTRY API COLLECTIONS
# ============================================================================
# Country tags are still three-character engine identifiers. These named
# collections are the stable `chaosx_country_*` API: later events can select a
# carrier, region, or event family without inventing another tag. A collection
# is an active scope view, so callers must still check that a tag exists,
# belongs to the requested origin, has a safe anchor, and is content-ready.
# The static Event 006 registry arrays remain the source of truth for dormant
# reservations and package admission.
# ============================================================================
