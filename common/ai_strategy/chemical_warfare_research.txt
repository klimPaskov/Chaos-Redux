# ============================================================================
# CHAOS REDUX - ROUTE-AWARE CBRN RESEARCH AI
# ============================================================================
# Overview:
# - Protects before expanding an offensive program.
# - Uses confirmed attacks, known enemy capability, contamination, outbreaks,
#   explicit doctrine routes, and country identities instead of Condemnation as
#   a threat proxy.
# - Keeps each offensive profile on a narrow historical agent family.
# - Does not authorize use, create targets, or bypass project requirements.
# - `ai_strategy.value` does not parse script constants in this context, so the
#   values below are centralized as file-local constants.
# ============================================================================
