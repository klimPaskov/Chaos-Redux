# ============================================================================
# CHAOS REDUX - DIFFERENTIATED CBRN COUNTRY-PROFILE AI
# ============================================================================
# Overview:
# - Gives the major and secondary profiles distinct research, medical-support,
#   and regimental-role preferences while retaining the shared CBRN safety
#   gates, exact route conditions, and real equipment requirements.
# - Offensive research in the existing chemical strategy files remains the
#   source for agent-family preferences. This file supplements it with each
#   profile's defensive, medical, delivery-support, and biological-response
#   priorities.
# - Biological special-project selection remains in
#   common/special_projects/projects/biowarfare_main_projects.txt, where its
#   native AI weights enforce the Tularemia < Anthrax < Plague < Smallpox
#   ladder. This file does not turn a project into a decision or authorize a
#   delivery route.
# - AI strategy values are file-local because this context does not parse
#   shared script-constant values. No strategy below grants equipment, creates
#   a target, or supplies an unsupported estimator.
# ============================================================================
