# ============================================================================
# Overview:
# - Defines the Anthrax, Plague, Tularemia, and Smallpox strategic air raids.
# - Native essential equipment reserves the exact agent model at raid creation.
# - Every native outcome invokes bio_resolve_strategic_raid_outcome exactly once.
# - The shared resolver owns consumption, protection/countermeasure context,
#   lifecycle seeding, evidence, attribution, Condemnation, history, and refunds.
# - Native state targeting keeps cooldowns and lifecycle writes on the exact
#   same var:target_state.
# - No launch-state estimator, aircraft-presence proxy, ordinary-air mission
#   hook, or fallback contamination route exists in this file.
# ============================================================================
