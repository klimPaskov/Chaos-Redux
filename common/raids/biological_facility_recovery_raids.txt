# ============================================================================
# CHAOS REDUX - CAPTURED BIOLOGICAL FACILITY RECOVERY RAIDS
# ============================================================================
# Overview:
# - Two native land raids resolve an exact captured biological arsenal state.
# - A selected division must contain a Biosecurity Assault Detachment.
# - The selected division's own unit leader must command an Army Headquarters
#   with a Biological Security Section. The current raid API cannot put a
#   character trigger in unit_requirements, so a visible fail-closed success
#   factor makes a formation without that exact assigned section unable to
#   succeed; no national or unrelated-headquarters proxy is used.
# - Equipment reservations represent the additional protective, containment,
#   evidence-custody, and demolition stores committed to the recovery force.
# - Outcome helpers consume, transfer, destroy, or accidentally release only
#   the payload ledger already attached to var:target_state.
# ============================================================================
