# ============================================================================
# CHAOS REDUX - NATIVE DOOMSDAY RAIDS
# ============================================================================
# One chemical and one biological last-resort raid use the existing CBRN
# categories. Native essential_equipment reserves one of each of four agents
# at preparation. A successful outcome enters one guarded all-state resolver,
# which consumes only the still-stockpiled balance and accounts for the four
# reserved lots in the record. Failed outcomes never invoke that resolver.
# The raid target authenticates the operation; the catastrophe covers the
# exact domestic and enemy-front state sets defined by each doomsday system.
# Native raid definitions require static values; the four-lot reservation
# mirrors the script constants in the corresponding doomsday effect files.
# ============================================================================
