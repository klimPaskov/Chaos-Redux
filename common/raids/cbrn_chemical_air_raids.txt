# CHAOS REDUX - SELECTED-STATE CHEMICAL AIR RAIDS
# ============================================================================
# Overview:
# - Reuses the established chemical raid identifiers for Sarin, Soman,
#   Malodor, and the behavioral-agent project, and adds the earlier agents.
# - Every native outcome calls one shared selected-state chemical adapter.
#   The adapter reserves the exact class payload, resolves the native result,
#   accounts for protection and the native condition receipt, and dispatches
#   exposure or a no-release attempt exactly once.
# - Native success factors are identical across ordinary chemical agents.
#   Agent identity changes class, potency, persistence, protection burden, and
#   post-release consequences after the delivery roll.
# - Existing Chaos Redux military-raid icons are referenced without changing
#   or replacing their files. New agent IDs use the registered Stage 6
#   chemical-air operation icon.
# - No ordinary air mission, idle aircraft, aircraft-presence scan, or
#   continuous-air contamination path is present here.
# ============================================================================
