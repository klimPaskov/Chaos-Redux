# Overview:
# - Reserves one plague-bomb payload and its support equipment through the
#   native raid system, with Command Power allocated by the raid itself.
# - Uses the existing Biological Raids category, plague map icon, air-base
#   origin, and plague-strike bomber and delivery-chance precedents.
# - Limited, successful, and critical outcomes carry the exact actor, victim,
#   and state into fixed hidden actor events. Those events own the final release
#   gate and scaled consequences.
# - No scripted payload, support-equipment, Command Power, or fuel payment is
#   made in these callbacks.
# ============================================================================
