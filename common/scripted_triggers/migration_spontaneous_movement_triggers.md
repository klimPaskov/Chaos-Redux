# Spontaneous sparse-state readiness

`migration_spontaneous_movement_state_is_ready` is a read-only STATE gate for the existing sparse owner.
It requires the existing human owner/controller, active displacement, material flight pressure, positive configured population floor and expired/absent existing cooldown.
An active humanitarian corridor contract blocks another ordinary attempt, preventing duplicate staging or requests while pending/accepted.
Accepted private ordinary passages are consumed by the separate exact-row branch before this readiness gate, so a real host acceptance is not stranded behind the thirty-day attempt cooldown.
No timing, pressure or population constants are changed, and no recurring/world scan is added.
