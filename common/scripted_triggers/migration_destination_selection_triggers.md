# Destination selection trigger contracts

The existing normal internal, foreign, transit, resettlement and donor predicates retain their prior contracts.
Operational reception availability accepts optional unprefixed temporary `migration_destination_selection_required_people`, default zero.
When positive, it proves nonnegative current load plus the entire request no greater than valid current capacity before both complete weighted passes; exact fit qualifies and one-person deficit contributes zero weight.
Other callers supplying no amount retain their earlier spare-capacity contract.
`migration_destination_preparable_candidate_is_valid` runs on each directly adjacent foreign STATE from one explicit live origin.
It requires the saved acting country, actual foreign owner/control, no war, no other pending incoming offer/forced-return issue, native route/food proof, all shared front hazards clear, civilian factories, current affordability and a meaningful possible paid service/policy change.
Missing housing/medical receipt or capacity is the only preparation readiness omission; no safety, route or actor fact is invented.
It creates no service, load, destination binding or route authorization.
The caller uses this identical predicate in both complete weighted passes and retains every qualifying neighbor, not only the first or a unique neighbor.
The exact drawn endpoint is later rechecked by the corridor contract and paid preparation helpers.
Independent same-scenario probability comparison remains required for the changed eligible candidate set.
