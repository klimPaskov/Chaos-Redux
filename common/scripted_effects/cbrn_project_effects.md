# Random CBRN project reward

`grant_random_chaos_special_project_available_tech` is an existing country-scoped reward effect used by event and focus callers. It selects one of nine weighted project families when a matching technology or project remains available, sets `chaos_random_special_project_granted` on a delivered reward, and grants that family's delivery technology where applicable. It does not choose a facility, authorize a CBRN policy, or issue weapon stock.

The four ordinary biological bomb candidates, the weaponized-zombie candidate, and the Sarin and Soman candidates keep their existing random-list weights and technology eligibility. If a candidate's special project has already been completed while its delivery technology is absent, the selected effect grants the missing technology without completing the project again. The weaponized-zombie branch also avoids rerandomizing its already completed profile. An incomplete project still completes once through its original effect before the technology grant. The Black Plague and D'Rhondan entries already exclude completed projects in their own availability gates and are unchanged.

This guard preserves the intended reward when a completed project and delivery technology diverge, while preventing duplicate completion outputs. It does not repair the separate [exact-facility provenance blocker](../../docs/plans/chaos_warfare_system_plans/2026-09-27_random_biological_grant_facility_scope.md): scripted completion does not execute `facility_state_effects`, and the random reward has no exact site input. A biological project awarded this way therefore does not create a monitored arsenal by inference.

Source acceptance cases are: an incomplete project with missing technology completes once and receives technology; a completed project with missing technology receives only technology; a completed zombie project with missing technology keeps its current profile; a completed project with its technology already present is excluded by the existing candidate modifier; and Sarin/Soman completion guards act independently when the Soman branch is selected. The nine candidate weights and eligibility modifiers stay unchanged, so their selection shares should be identical before and after this output-only correction. Native project completion, technology state after save/reload, and exact facility behavior remain engine validation items.
