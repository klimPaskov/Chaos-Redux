# Random CBRN project reward

`grant_random_chaos_special_project_available_tech` is a country-scoped reward effect used by UWR setup and focuses. It selects one of nine weighted project families when a matching technology or project remains available, sets `chaos_random_special_project_granted` on a delivered reward, and grants that family's delivery technology where applicable. The UWR caller wrapper binds an exact eligible biological facility or valid monitored arsenal before selection; the generic reward does not authorize a CBRN policy or issue weapon stock.

The four ordinary biological bomb candidates keep their numeric random-list weights but exclude incomplete projects when the UWR wrapper cannot prove a current exact source facility. If a candidate's special project has already been completed while its delivery technology is absent, the selected effect grants the missing technology without completing the project again or designating another arsenal. A newly completed Anthrax, Plague, Tularemia, or Smallpox project registers and monitors the same bound state after confirmed completion. The weaponized-zombie branch avoids rerandomizing its completed profile. The Black Plague and D'Rhondan entries already exclude completed projects in their own availability gates and are unchanged.

The [exact-site correction](../../docs/specs/chaos_warfare_system_specs/corrections/2026-09-27_uwr_exact_biological_project_site.md) resolves the source-provenance gap through one UWR wrapper and the existing facility rewards. Scripted completion does not execute `facility_state_effects`; the explicit registration helper uses the wrapper's validated regular event target instead of inferring a source from any owned state. Prior designation history is retained after a lost facility, so a later focus cannot silently replace it.

Source acceptance cases are: an incomplete ordinary biological project with a valid exact site completes once, receives technology, and registers that site; the same project with no valid site is excluded; a completed project with missing technology receives only technology; a completed zombie project with missing technology keeps its current profile; and Sarin/Soman completion guards act independently when the Soman branch is selected. The nine candidate heads and numeric weights remain, but the biological eligibility conditions change, so before/after selection shares require the named probability comparison. Native project completion, technology state after save/reload, and exact facility behavior remain engine validation items.
