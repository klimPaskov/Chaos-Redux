# Native chemical land raid adapter

`cbrn_resolve_chemical_land_raid_outcome = yes` runs in the native raid-instance `actor_effects` scope. The raid supplies `var:actor_country`, `var:target_state`, `var:victim_country`, and temporary `cbrn_raid_route`, `cbrn_raid_agent`, `cbrn_raid_engine_outcome`, and `cbrn_raid_phantom_mist` inputs. The adapter saves short-lived event targets, then enters `var:actor_country` for every country capability, policy, ledger, and dispatch operation. `ROOT` remains the raid instance; `cbrn_chemical_land_raid_policy_allows_exact_target` therefore compares the saved countries directly, while `cbrn_chemical_action_static_content_is_valid` checks the shared metadata without the country-rooted legacy policy trigger. The four supported routes are cylinder release, projector barrage, artillery fire plan, and armored delivery; the outcome must be limited success, success, or critical success for any release. An optional positive `cbrn_raid_payload_reserved` overrides the route cost only when a native variant has actually reserved that exact quantity, as in the Japan Black Friday campaign.

Native `essential_equipment` reserves the exact agent payload archetype for cylinder, projector, and armored routes, or `chemical_artillery_ammunition` for artillery. Artillery reserves 121 ammunition units, of which 120 form the chemical payload receipt and one is the old support-shell charge. The adapter sets the corresponding consumed-payload proof for the shared consequence record; it never debits or refunds equipment. A missing target, unsupported outcome, invalid policy, or rejected action produces no release. `cbrn_raid_release_accepted` defaults to missing and becomes supplied only after `cbrn_dispatch_chemical_action_record` proves it dispatched once. The caller can use that output to set campaign cooldowns without treating a reserved but rejected strike as a completed attack.

The adapter stores short-lived actor, exact state, and victim in regular event targets `cbrn_action_actor`, `cbrn_action_target_state`, and `cbrn_action_victim_country`. They belong only to the current effect chain and need no persistent cleanup. The shared action reset clears temporary output values before route setup. `cbrn_land_raid_set_payload_requirement` maps route to `cbrn_payload_route_cost`; `cbrn_land_raid_apply_engine_outcome` maps limited and critical outcomes to existing dose constants; `cbrn_land_raid_apply_phantom_mist_result` reduces military and civilian death fractions and increases disruption only for an authorized malodor Phantom Mist native variant. It clamps disruption to the existing action output ceiling.

The shared resolver receives the route, agent class, severity, exact-target policy proof, native consumption proof, target protection, condition receipt, and doctrine Condemnation multiplier, then prepares and dispatches the action record. Native raid definitions call only the public adapter. The old timed-decision ledger and payload debit helpers are not part of this route.

This file introduces no icons. Native raid icons and the existing CBRN decision category art remain in their raid and interface files.
