# CHAOS REDUX - EVENT 038 MALTA CRUSADERS ACTION COSTS
# ============================================================================
# Every Crusade Council, logistics, recruitment, campaign, settlement and
# Eleventh Crusade action has one published cost set. malta_publish_costs turns
# the base values of the malta_cost constants into global.malta_cost_<action>_
# <resource> whenever the actor changes the footprint (opening, weekly pulse,
# demand queued, recovery opened or closed). The payment checks in
# 038_malta_crusaders_triggers.txt, the cost texts in the localisation file and
# the malta_pay_<action> effects below all read those globals, so what the
# player sees, what is checked and what is paid are one number.
# Stockpile debits use the shared helpers of chaosx_dynamic_effects.txt.
# The four demand actions also publish a half cost for the compromise answer.
# The completed focuses that lower a cost set a discount flag; malta_apply_cost_discounts
# applies the factor of malta_cost_scale.discount after every publication.
# The completed focuses that lower a cost set a discount flag; malta_apply_cost_discounts
# applies the factor of malta_cost_scale.discount after every publication.
# The completed focuses that lower a cost set a discount flag; malta_apply_cost_discounts
# applies the factor of malta_cost_scale.discount after every publication.
