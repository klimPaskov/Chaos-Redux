# Event 012 live authority epoch bindings

Purpose: bind live participant, demand, reconciliation, and victor-renewal permissions to the actual current Gods authority episode without changing Event 012's shared host generation.
Historical settlement and victory reports use their independent frozen proof.
These private fields add no public meter, cost, icon, or timer.

All three binding effects run in participant COUNTRY scope and accept no named parameters.
`gods_of_africa_bind_participant_epoch` is called only after genuine registration has appended the country to the current host's native participant array and committed its shared generation.
It stores the actual host object, ID, origin, and local authority epoch.
Missing authority or membership produces no new binding, and this helper does not initialize history or grant authority.

`gods_of_africa_bind_demand_epoch` runs after the native demand fields are committed and before its immutable contract ledger opens.
The contract ledger preserves the epoch with its origin/generation/demand-ID tuple, including the last consumed terminal receipt.
A replacement demand cannot inherit an earlier episode's permission.

`gods_of_africa_bind_reconciliation_epoch` runs when the ordinary defiance review is created.
It records the exact host object/ID, origin, shared generation, and local epoch.
Paid offer, host acceptance, and native timeout owners require that current review identity; timeout also requires its actual present deadline to have elapsed.
`gods_of_africa_clear_reconciliation_epoch` removes only transient review identity, retaining accepted-reconciliation sequence and lifetime history.

The matching triggers validate actual stored country existence and identity rather than `scope_exists` on a variable scope.
They do not invoke a ROOT-dependent owner predicate from a participant ROOT.
Ordinary participant permission additionally retains native roster membership, original participant validity, and shared generation proof.
A former victor's renewal request separately stores the accepting host epoch; withdrawal of a stale request remains available without renewed authority.

Native capitulation has already invalidated ordinary healthy-host permission.
The actual winner is therefore checked through callback authorization, live actor eligibility, exact retained participant host object/ID/origin/epoch, and actual membership in the defeated host's array before cleanup.
That callback appends victory history before exemption and captures its latest defeated epoch, while its independent report can survive loss cleanup.
No faction member, annexer, or generic war relation substitutes for the native winner.

`gods_of_africa_continent_is_secured` distinguishes actual continental settlement from a defeated Scramble's settled enum.
It requires a settled Scramble without its defeat response, or the explicit applied World Is One scenario type.
Initial continental formation does not prove security; the normal formation and Evolution I owners both call the same idempotent initializer, so whichever occurs second can begin the existing consolidation interval.
The Africa Is One scenario seeds first-proof and Evolution I chronology without replaying their rewards.
An applied World Is One scenario is a separate post-security starting phase and cannot start new tribute through a later Evolution I callback.
The owner finalizes retained history when the continent is secured during consolidation and does not begin ordinary tribute in that case.

Both ownership and actual control of an African host-core state block ordinary pardon and personal victor renewal.
War and state observation still belong to the separate effect-side conduct owner; these requirements do not create or count history in a trigger.

The annexation callback runs directly on native FROM, independent of annexer ROOT, and records a terminal annexation witness for the original Gods owner.
Gods cannot reselect that annexed country after release.
The shared World Order host-transfer bridge's separate foreign-ROOT issue remains a documented owner dependency; this private cleanup does not claim to repair that shared transaction.

Usage from actual registration:

```text
# After native participant-array append and shared generation assignment.
gods_of_africa_bind_participant_epoch = yes
```

Defaults and cleanup: validators reject absent inputs; failed bindings preserve existing metadata without granting new permission.
Live demand epoch and original-host work fields clear only after contract closure and frozen slot release.
Participant authority fields survive archival as historical pointers, but live permission still requires current physical authority and roster membership.
All settlement, victory, contribution, and doctrine history remains with its separate retained owners.
