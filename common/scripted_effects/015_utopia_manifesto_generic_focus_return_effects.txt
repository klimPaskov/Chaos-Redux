# Contract:
# Purpose: capture, restore without rewards, and clear the completed-focus receipt for the installed generic_focus tree.
# Scope: COUNTRY.
# Inputs: none; capture is called only from the proven generic_focus origin branch before tree adoption.
# Outputs: Boolean country flags keyed to exact native focus IDs; restore marks only receipted focuses complete.
# Defaults: no receipt flag is set unless its focus was completed when captured.
# Side effects: unlock_national_focus bypasses a receipted focus without firing its completion effect; no focus reward is replayed.
# Lifecycle: capture clears stale receipt flags first; restore clears each consumed receipt; teardown clears all remaining receipts.
# Usage: call capture before loading utopia_manifesto_tree, then restore immediately after the guarded return loads generic_focus.
