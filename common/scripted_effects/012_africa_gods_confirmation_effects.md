# Event 012 permanent-defiance confirmation

Purpose: let a human review permanent defiance before the existing irreversible outcome runs.
Scope: participant COUNTRY; all helpers use boolean calls and have no parameters or implicit default amounts.
No request or cancellation changes a cost, Wrath, tribute history, protection, a demand balance or any running deadline.

`gods_of_africa_request_defiance_confirmation = yes` rechecks the actual defiance and contract-history permissions.
An AI country calls the existing `gods_of_africa_permanent_defiance` action directly, preserving its decision scores and outcome.
A human request writes one pending flag and freezes the current host object ID, origin ID, host generation and authority epoch before firing `.622`.
The regular event target `gods_of_africa_confirmation_host` supplies the named country in that dialog.
A second human request cannot replace that envelope while it is pending.

`gods_of_africa_confirm_permanent_defiance = yes` requires human control and the same current authority, then consumes the envelope before invoking the existing defiance owner.
At event firing, the confirmation option is hidden if the receipt is stale, the contract can no longer close, or defiance is otherwise unavailable.
Native option visibility is selected at firing, so the effect rechecks those same permissions when clicked and rejects any later authority change.
The cancel option is always available and calls `gods_of_africa_clear_defiance_confirmation = yes` without gameplay consequences.
Cancel is defined first, so the native event timeout also withdraws the request instead of declaring defiance when the player does not answer.
The native timeout remains unchanged; no second timer or recurring cleanup is introduced.
An AI at dialog firing has only that cancel option.
If control changes to AI after a human dialog opened, the confirmation callback itself rejects AI control and closes the receipt without declaring defiance.

The envelope is a pending UI acknowledgment, not continuing gameplay authority.
Host loss invalidates confirmation through the normal authority guards; its frozen identity remains until the dialog is answered so another request cannot overwrite a still-open confirmation.
No cleanup path is allowed to reinterpret that old acknowledgment as permission for a successor or later epoch.
Already paid material, the original demand deadline and the existing aftermath report `.609` remain with their original owners.

The confirmation reuses `GFX_report_event_012_africa_gods_defiance` from `interface/012_africa_event_pictures.gfx`, pointing to `gfx/event_pictures/012_africa/report_event_012_africa_gods_defiance.dds`.
No new image, counter, focus icon, public meter or separate event-catalog row is introduced.
The accepted requirement is the full Gods spec's Participant response model, permanent-defiance confirmation at line 672, and the October 7 decision audit.
Native popup behavior and the same-scenario AI audit remain acceptance work; source presence alone does not close them.
