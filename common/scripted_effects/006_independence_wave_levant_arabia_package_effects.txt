# ============================================================================
# CHAOS REDUX - EVENT 006 LEVANT AND ARABIA PACKAGE LAYERS
# ============================================================================
# Overview:
# - Level 2 layers on the regional framework engine (agent decision D25) for
#   IW-073 Hejaz (CUX), IW-078 Imamate of Oman (IMO), IW-081 Lebanon (LEB) and
#   IW-082 Palestine (PAL).
# - Each `_apply_package_layer` runs once inside framework setup: it installs
#   the country's starting problem and marks the layer as applied.
# - Each `_complete_*` effect is the result of one paid project in
#   common/decisions/006_independence_wave_levant_arabia_decisions.txt. Values
#   move through the shared clamped helpers.
# - Each `_cleanup_package_layer` checks its own package id and removes the
#   projects, ideas and receipts; the framework cleanup calls all four.
# No effect iterates countries or states.
# ============================================================================

# IW-082 Palestine (PAL)
# ---------------------------------------------------------------------------

# The vanilla PAL neutrality leader is the mandate's High Commissioner. A
# released Palestine suspends that leader role for its own generation; cleanup
# restores it exactly as vanilla defines it.
independence_wave_pal_apply_package_layer = {
	if = {
		limit = { has_character = PAL_harold_macmichael }
		remove_country_leader_role = {
			character = PAL_harold_macmichael
			ideology = oligarchism
		}
		set_country_flag = independence_wave_pal_mandate_leader_suspended
	}
	add_ideas = independence_wave_pal_divided_municipalities
	set_country_flag = independence_wave_framework_package_layer_applied
