# ============================================================================
# CHAOS REDUX - EVENT 006 IW-093 / IW-098 SIGNATURE FOCUS EFFECTS
# ============================================================================
# Overview:
# - Writes only package-local, visible state values and route receipts for the
#   additive Asante (IW-093) and Sokoto (IW-098) focus branches.
# - Pays political-power, command-power, and equipment costs before recording
#   staged transactions. Timed project flags are closed by a later focus so
#   infrastructure is not granted immediately for an unfinished receipt.
# - Improves the existing package forces through experience, command power,
#   doctrine support, and receipt flags; no focus creates a free division.
# - The final FORM-24/FORM-25 focuses record preparation only. They never set
#   runtime attestation, install characters, change identity, or commit a
#   formable country.
#
# Scope: country unless a state scope is written explicitly. All four package
# values are clamped by the package helpers after every mutation.
# ============================================================================
