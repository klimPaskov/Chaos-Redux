# - These shared script constants are the deterministic public vocabulary for
#   the Event 025 Antarctic recovery race and its Event 036 aircraft overlap.
# - Identity, phase, action, evolution, sector, route, result, tie-break, and
#   value namespaces are stable integration contracts for parent event files.

#   positive requirement mirrors used by trigger thresholds and callers.
# - The extra roster and tuning aliases are retained because the current
#   Event 025 runtime already references them; they do not create gameplay.
# - This file grants no technology, equipment, history, country, or event.
# ============================================================================
