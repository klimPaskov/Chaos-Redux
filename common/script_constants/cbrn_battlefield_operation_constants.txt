# ============================================================================
# CHAOS REDUX - EXACT-STATE CBRN BATTLEFIELD OPERATION CONSTANTS
# ============================================================================
# Overview:
# - Centralizes preparation, cooldown, readiness, command-power, support-store,
#   essential-equipment, and condition-receipt tuning for the four non-air
#   chemical delivery routes.
# - These values describe a deliberately selected state operation. They are
#   not a combat-target estimator, aircraft-presence proxy, weather pulse, or
#   country-wide periodic tick.
# - Payload lots remain owned by cbrn_chemical_delivery_constants.txt and are
#   debited only by cbrn_try_debit_action_payload after the exact target record
#   has passed its static policy and stock checks.
# - Numeric values are gameplay tuning. Historical confidence is low to
#   moderate because one payload lot abstracts filling, transport, handling,
#   and an operation-sized release rather than a fixed historical mass.
# ============================================================================
