# Exact people-denominated shocks are converted into a population-scaled
# 0-100 need contribution. A cumulative shock equal to one fifth of the live
# state population reaches the component ceiling; smaller shocks remain
# proportionate. The persistent shock then recedes through the bounded active
# registry instead of requiring a flat decision-side subtraction.
