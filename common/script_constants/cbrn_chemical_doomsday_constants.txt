# ============================================================================
# CHAOS REDUX - CHEMICAL DOOMSDAY ADAPTER CONSTANTS
# ============================================================================
# Overview:
# - Centralizes the native doomsday route's state-target, condition-receipt,
#   and batch-Condemnation tuning.
# - The adapter accounts for four native reserved lots and consumes the
#   remaining cylinder stock exactly once, then
#   allocates those real lots across the exact controlled-state array. It does
#   not estimate weather, activity, target selection, or aircraft presence.
# - Values are gameplay tuning with low historical confidence. A legacy
#   cylinder is an operation-sized abstraction, not a fixed chemical mass.
# ============================================================================
