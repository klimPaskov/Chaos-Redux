# Overview:
# - Defines the shared CBRN data-model enums and bounded tuning tables.
# - Owns Chemical Readiness, policy, contamination, evidence, attribution,
#   protection, agent-class, route-profile, and exposure-output constants.
# - Keeps exact-state air raids distinct from the unsupported continuous-air
#   mission route. The latter is a recognized rejection value only.
# - Biological agent identities are reserved for the later biological stage;
#   weaponized zombies retain a separate weapon class and source label.
# ============================================================================
