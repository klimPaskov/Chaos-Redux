# CHAOS REDUX - FAMINE AND MIGRATION STATE DYNAMIC MODIFIERS

# The food-security evaluator owns the score, stage flags, and mortality.
# These state-scoped modifiers expose bounded supply, production, mobility, and
# reception consequences for the active flags. The refresh effect removes all
# families before adding the current set, so stage changes and cleanup are safe.
# ============================================================================
