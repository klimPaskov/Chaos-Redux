# ============================================================================
# CHAOS REDUX - EVENT 014 SCRIPTED GUI
# ============================================================================
# Human-facing status surfaces only. All gameplay actions remain decisions or
# scripted pulses, so AI follows the same costs and no GUI click can bypass a
# mission, cooldown, population transaction, or Deaths record.
# The network board intentionally uses the documented player_context under
# top_bar because its dirty refresh and dynamic country/state lists require a
# player-owned scope; its controls only change view state or select a target.
# Event targets are deliberately absent from every GUI block.
# ============================================================================
