# ============================================================================
# CHAOS REDUX - CHAOS UI WEAR SCRIPTED GUIS
# ============================================================================
# Attaches the wear decals in interface/chaos_ui_wear.gui to vanilla windows.
# Each decal has one icon per Chaos tier and colour; the element visible
# triggers read the live chaos_tier and world_end global flags through
# common/scripted_triggers/chaos_ui_wear_triggers.txt, so a tier change, a
# settings or debug tier change, a load and the world-end colour switch all
# show on the next interface update with no stored copy to go stale. Tier 0
# shows nothing. The chaos_ui_wear_disabled global flag (Settings >
# Miscellaneous) hides every overlay. No dirty variable is set, so the GUIs
# refresh every tick, which is what makes the live flag reads effective.
# Generated from docs/assets/chaos_ui_wear/gen_gui.py.
# ============================================================================
