# ============================================================================
# CHAOS REDUX - CHAOS UI WEAR SCRIPTED GUIS
# ============================================================================
# Attaches the crack decals in interface/chaos_ui_wear.gui to vanilla windows.
# global.chaos_ui_wear_frame holds the Chaos tier (0-5) and is refreshed by
# update_chaos_ui_wear whenever the Chaos tier is recalculated. The dark
# decals show before the world ends; their purple twins replace them once the
# world_end global flag is set. The chaos_ui_wear_disabled global flag (Settings
# > Miscellaneous) hides every overlay. No dirty variable is used so the
# world_end colour switch is read live; every check is a flag or variable lookup.
# ============================================================================
