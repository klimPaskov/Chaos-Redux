# ============================================================================
# CHAOS REDUX - GENERIC CBRN MILITARY INDUSTRIAL ORGANIZATIONS
# ============================================================================
# Overview:
# - Defines the chemical-payload and chemical-air designer families mapped by
#   the accepted country-program matrix.
# - Equipment and production bonuses apply only to exact custom payload
#   archetypes. No ordinary artillery piece, CAS airframe, tactical bomber, or
#   unrelated support-equipment line receives these bonuses.
# - Scripted route effects query completed traits through
#   cbrn_designer_triggers.txt and remain subject to the shared payload,
#   exposure, evidence, and Condemnation contracts.
# - Static MIO values use one file-local tuning table because this database does
#   not accept script-constant tokens in its native bonus fields.
# ============================================================================
