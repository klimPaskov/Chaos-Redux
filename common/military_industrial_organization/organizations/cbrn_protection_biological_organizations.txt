# - Defines the four accepted generic designer families that were not covered
#   by cbrn_organizations.txt.

#   biological-payload, or CBRN-instrument equipment families.

#   never alter the Tularemia < Anthrax < Plague < Smallpox potency ladder.
# - Static MIO values use this file-local table because the organization
#   database does not accept script-constant tokens in native bonus fields.
# ============================================================================
