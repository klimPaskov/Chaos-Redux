# ============================================================================
# CHAOS REDUX - EVENT 033 ACID RAIN NATIONAL RESPONSE DECISIONS
# ============================================================================
#
# This file owns the public decision surface only. The Event 33 runtime owns
# quotes, debits, temporary reservations, active receipts, completion, cancel
# cleanup, preparedness changes, and state consequences. Every complete effect
# below selects a matrix row and calls the runtime API; it never scans the
# world or substitutes a mortality effect.
#
# Every requirement a player sees is a localised custom tooltip; internal
# checks sit in hidden triggers. acid_rain_start_action rechecks the same
# gates before any debit. National families run side by side, one each;
# evacuations and recovery work run per state up to the band caps.
#
# Each custom_cost_trigger rebuilds the final quote from the stored row, the
# same path the start effect debits. The custom_cost_text keys read the
# persistent acid_rain_cost_<row>_<family> display rows that the quote
# refresh effects publish for players, and hide every zero-valued family.
