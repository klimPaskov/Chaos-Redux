# ============================================================================
# CHAOS REDUX - EXACT-STATE CBRN BATTLEFIELD OPERATION DECISIONS
# ============================================================================
# Overview:
# - Exposes one agent-selection control and four state-targeted timed
#   operations. Chemical deployment remains a decision surface here because
#   the native raid API is not a verified Army-HQ-to-state receipt for these
#   ground routes.
# - Each route commits immediately to the selected state, pays its political
#   power cost, then completes after its preparation duration. The completion
#   effect consumes payload and route equipment before the shared consequence
#   pipeline resolves the release.
# - AI scoring is route-aware and target-aware. Country profiles modify route
#   preference only; they never create a target, grant a payload, or bypass
#   the shared policy and protection gates.
# ============================================================================
