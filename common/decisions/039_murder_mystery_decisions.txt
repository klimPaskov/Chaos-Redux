# CHAOS REDUX - EVENT 039 MURDER MYSTERY DECISIONS AND MISSIONS
# ============================================================================
# Overview:
# - These ordinary decisions expose the accepted Event 039 investigation,
#   foreign-cell, Brotherhood, derivative, and World Without Leaders actions.
# - Every consuming action writes the runtime pending action and phase before
#   calling the local decision adapter, which delegates payment and resolution
#   to the existing transactional helpers.
# - Selectable missions use real deadlines and distinct completion, timeout,
#   and cancellation paths. Active-mission gates keep each category bounded.
# - Initiating actions and real objectives use separate bespoke Event 039
#   decision and mission sprites from the event's icon registry.
# ============================================================================
