# CHAOS REDUX - EVENT 038 MALTA CRUSADERS DECISION CATEGORIES
# ============================================================================
# Four simple categories read the same campaign state of the actor:
#   The Crusade Council      demand answers, Joint Command, Jerusalem, treasury
#   Mediterranean Campaigns  logistics, regional crusades, settlement, missions
#   The Banners              raising formations
#   The Eleventh Crusade     recovery after the expedition collapses
# The council header (in the category description, built by scripted
# localisation) shows Command Standing, Order Cohesion and Sacred Legitimacy
# with the next material threshold. The dedicated Crusade Council window of
# the design is not part of this implementation. Recruitment has its own
# category so that no phase shows more than six rows.
# ============================================================================
