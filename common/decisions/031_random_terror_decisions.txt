# ============================================================================
# CHAOS REDUX - EVENT 031 RANDOM TERROR DECISIONS
# ============================================================================
# Decision-owned surface for the Random Terror response and territorial actors.
# Categories stay ordinary and compact.  State-targeted actions use the same
# state flags consumed by the Event 31 runtime, save the selected state as the
# short-lived random_terror_action_state target, and never use a capital proxy.
#
# UI budget: phase and route gates keep normal government lanes at three to
# five visible actions (six hard maximum).  Mission slot flags reserve three
# concurrent lanes; the parent runtime must use the same slot contract for
# event-created missions.  All custom costs are manually debited below.
# ============================================================================
