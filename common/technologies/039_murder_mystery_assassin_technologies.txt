# Overview:
# - This compact technology line unlocks real operations-kit production and
#   the five Event 039 profiles plus their Saboteur Cell support company.
# - The line sits at the bottom of the infantry folder in its own branch
#   (gridbox murder_mystery_clandestine_combat_training_tree in
#   interface/countrytechtreeview.gui). allow_branch hides the whole branch
#   from every country that is not an Assassin State or derivative, and allow
#   keeps the same countries from researching it.
# - Assassin countries research the line normally; focuses and the starting
#   forces package grant the same technologies through set_technology.
# - Master Cadre Command is researchable only after Evolution V, and
#   Mechanized Infiltration only on the pragmatic route that opens
#   conventional support, matching the units' spec gates.
# - Values are deliberately conservative: the unit family has useful short
#   attack and terrain bonuses, but no universal defence, armour, or air cover.
# ============================================================================
