# Chemical shell tank support compatibility definitions:
# - These 18 inactive agent-specific support IDs remain parseable for existing
#   references but are not granted by CXT or selected by current AI templates.
# - Accepted compatibility exception, 2026-10-04: the overhaul amendment drops
#   these eighteen roles and they are unreachable in normal and CXT play, but
#   their identifiers are entries in the ordered synchronized token list at
#   common/synchronized_dynamic_tokens/chaosx_tokens.txt, whose stated purpose
#   is stable token allocation; dropping eighteen entries would shift every
#   later identifier for every package that reads that list.
#   Unreachability: each carries active = no, which the unit documentation
#   defines as usable only through an explicit technology unlock, and no
#   technology anywhere declares enable_subunits for any of the eighteen. They
#   appear in no AI template, no history order of battle and no CXT unlock, and
#   the only script naming them, chemical_tank_shell_triggers.txt, is itself
#   called from nowhere.
#   Remove this file, its localisation, sprites and trigger file together with
#   their token entries only in a change that can also renumber that list.
# - Fielded armored delivery uses the consolidated light, medium, and heavy
#   flame-chassis companies in cbrn_regimental_support.txt. Selected payloads
#   are reserved by operations rather than standing divisional equipment bills.
