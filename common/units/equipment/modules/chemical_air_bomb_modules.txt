# Overview:
# - Defines exact-agent payload-handling racks for CAS and tactical bombers.
# - Each rack is a native raid eligibility marker; it does not prove that an
#   ordinary mission released chemical payload.

#   shared CBRN exposure pipeline.

#   equipment-module parsing while keeping every tuning value in one table.
# ============================================================================
