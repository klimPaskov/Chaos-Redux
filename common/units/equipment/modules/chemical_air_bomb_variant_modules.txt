# ============================================================================
# CHAOS REDUX - CHEMICAL AIR PAYLOAD DESIGNER VARIANT MODULES
# ============================================================================
# Overview:
# - Defines exact-agent aircraft rack variants unlocked by completed Aerosol
#   and Air Delivery Bureau traits through hidden technologies.
# - Lightweight racks reduce only their own weight and agility burden and carry
#   less payload. Long-range racks increase only aircraft designs that install
#   the exact rack and impose a larger maneuver penalty.
# - Combined racks compose both physical changes. Ordinary aircraft without one
#   of these modules receive no bonus, and no module can release toxic payload
#   outside an explicit selected-state operation.
# - Static module fields use this file-local tuning table because equipment
#   module databases do not accept script-constant tokens in native stat fields.
# ============================================================================
