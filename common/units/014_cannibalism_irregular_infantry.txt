# ============================================================================
# CHAOS REDUX - EVENT 014 FICTIONAL CANNIBAL IRREGULAR INFANTRY AND CAVALRY
# ============================================================================
# Overview:
# - Defines nine inactive Event 014 line sub-units, including one horse-mounted
#   cavalry family that remains infantry equipment-bound.
# - Each family has a distinct sprite token as an active map-model consumer
#   contract for the parent entity and model wiring.
# - All families share the explicit cannibal irregular-infantry category while
#   retaining ordinary infantry equipment and support compatibility.
# - The deliberately extreme attack and speed profile is balanced by low
#   organisation, low strength, weak defence, and high supply pressure.
#
# Runtime ownership:
# - These definitions are inactive in ordinary recruitment and are raised only
#   through the locked Event 014 template contract.
# - `common/on_actions/014_cannibalism_on_actions.txt` registers the same nine
#   definitions with the bounded CXT test-country extension.
# - The sprite tokens are consumer contracts for the parent model/entity work;
#   this file intentionally does not create any mesh, animation, asset, GFX,
#   counter, or sound file.
#
# Speed reference:
# - Infantry equipment has a vanilla maximum speed of 4.
# - Cavalry has a vanilla maximum speed of 6.4 through its 0.6 modifier.
# - Every infantry-equipped family below exceeds 6.4 after its speed modifier.
# - March Predation Column uses the retained motorized transport gate and is
#   therefore the fastest family by design.
# ============================================================================
