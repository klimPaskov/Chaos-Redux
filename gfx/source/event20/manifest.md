# Event20 Black Plague visual asset manifest

Generation date: 2026-07-24 for the report/super-event rows and 2026-08-01 for the response decision-icon rows. Source mode for all rows: `$imagegen` built-in official ImageGen. Report and super-event source PNGs are retained under `gfx/source/event20/source_png/`; their processed previews are under `gfx/source/event20/processed_png/`; response decision-icon evidence remains under the active `docs/assets/020_black_plague/` workspace, and all runtime DDS files are in engine-facing folders. The source family was selected because Event20 is fictional, alternate-history, and high-chaos; no archival image could represent the invented Rat King scenes without losing the requested specificity.

## Processing and QA notes

- The report source was processed with `.agents/skills/chaos-redux-event-assets/tools/process_report_event_image.py` using deterministic seed `20020`; the result is exactly `210x176`, RGBA, sepia black-and-white, with transparent corners and a soft shadow.
- Super-event sources were resized with Pillow Lanczos to exactly `457x328` RGB before DDS conversion; no text or watermark was present.
- All DDS outputs were created with `.agents/skills/chaos-redux-event-assets/tools/convert_to_dds.py` and validated as one-level uncompressed BGRA: 128-byte header, pixel format size 32, flags 65, fourCC 0, 32-bit masks `0x00FF0000/0x0000FF00/0x000000FF/0xFF000000`, texture caps `0x1000`, and exact payload length.
- Optional Doctor Wu/weaponization report art was not requested as a required row and was not generated.
- No custom country flag, Rat King leader/commander/operative portrait, idea/national-spirit icon, or focus icon was created in this report/super-event package. The two response decision icons are documented above and in `docs/assets/020_black_plague/decision_icons_manifest.md`.
