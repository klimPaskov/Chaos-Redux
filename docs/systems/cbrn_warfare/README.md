# CBRN Warfare documentation

This directory contains the shared chemical, biological, condemnation, genocide, doctrine, organization, and delivery systems used across Chaos Redux.

## Core overview and registries

- [`overview.md`](overview.md) is the entry point for the complete shared CBRN system.
- [`chaos_warfare_doctrine.md`](chaos_warfare_doctrine.md) defines doctrine, institutions, technology commissions, readiness, and officer-corps integration.
- [`chaos_unit_family_registry.md`](chaos_unit_family_registry.md) defines the shared unit-family registration and provider contract.
- [`cbrn_action_records.md`](cbrn_action_records.md) defines unified action records used by consequences and history-facing systems.

## Operations and organizations

- [`cbrn_operations_surface.md`](cbrn_operations_surface.md) maps the shared CBRN operations surface.
- [`cbrn_battlefield_operations.md`](cbrn_battlefield_operations.md) defines battlefield operation ownership and execution.
- [`cbrn_chemical_delivery.md`](cbrn_chemical_delivery.md) defines chemical payload delivery and shared consequences.
- [`cbrn_biological_ai.md`](cbrn_biological_ai.md) defines biological-program AI behavior.
- [`cbrn_hq_command.md`](cbrn_hq_command.md) defines the Army Headquarters command system.
- [`cbrn_occupation_and_nerve_suppression.md`](cbrn_occupation_and_nerve_suppression.md) defines occupation and nerve-agent suppression behavior.
- [`cbrn_camp_integration.md`](cbrn_camp_integration.md) defines restricted-site camp integration.
- [`cbrn_diplomacy_actions.md`](cbrn_diplomacy_actions.md) defines shared diplomatic actions.
- [`cbrn_designers.md`](cbrn_designers.md) defines CBRN military industrial organizations.
- [`cbrn_historical_advisors.md`](cbrn_historical_advisors.md) and [`cbrn_historical_scientists.md`](cbrn_historical_scientists.md) document the shared historical character rosters.

## Specialized subsystems

- [`biological_warfare/`](biological_warfare/README.md) contains biological agents, dissemination, countermeasures, sabotage, raids, and zombie-facing integration.
- [`chemical_warfare/`](chemical_warfare/README.md) contains chemical operations, doctrine modules, tactics, traits, and country-specific programs.
- [`condemnation/`](condemnation/README.md) contains the condemnation and sanctions contract.
- [`genocide/`](genocide/README.md) contains the implemented camp-repression crisis and its preserved source specification.

Atmospheric contamination belongs in `../air_cleanliness/`. Chaos gains and death accounting belong in `../chaos_meter/`.
