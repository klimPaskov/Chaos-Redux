# CBRN restricted-site camp integration

The restricted contaminated-site escalation keeps the camp package's territorial and political ownership while using the shared chemical exposure dispatcher for the one-time release.

## Resolution

1. The camp GUI or exact-state decision selects `camp_rework_action_state_id` and proves an existing eligible active site.
2. The camp resolver chooses the highest available chemical tier and records its existing tier-specific cylinder cost, evidence pressure, accident pressure, and recurring duration.
3. `cbrn_camp_effects.txt` binds that exact state, maps the camp tier to the shared chemical agent and class, and sets the `restricted_chemical_site` route.
4. The shared payload system consumes the matching `chemical_*_payload_cylinder_1` equipment model using the camp tier's exact cost.
5. The shared protection resolver reads military and civilian masks, filters, decontamination, antidote, medical, and warning coverage from the target state and its controller/owner.
6. The adapter supplies a verified contained-site condition envelope: Chemical Readiness scales release efficiency, CBRN command integration scales command contribution, the selected active site supplies target proof, and the route records that wind and terrain are not release modifiers for this abstract enclosed-site action.
7. The shared dispatcher records unit disruption, civilian Deaths, contamination, medical saturation, mask losses, evidence, attribution, Condemnation, responsibility, and confirmed-use history once.
8. Only after dispatch proof does the camp system set the active restricted-site flags, register the evidence site, apply camp pressure, and bridge the shared Deaths result into the camp responsibility ledger.
9. Camp monthly processing then owns recurring stockpile maintenance, suppression pressure, site persistence, and the separate monthly Deaths pulse.

## Scope boundary

The route never creates, reveals, or authorizes a camp, extermination site, experiment site, restricted chemical site, or generic concentration law. It can operate only on an already eligible exact camp target. Camp killing efficiency remains a camp-owned monthly multiplier and does not replace the shared one-time chemical record.

The route does not estimate weather, terrain, aircraft activity, adjacent states, capital states, or an unselected target. It is not a dynamic-effects or dynamic-triggers entry point because it is a camp-specific adapter used only by the camp GUI and restricted-site decision.

| `common/scripted_effects/camp_repression_rework_effects.txt` | Existing camp eligibility, site state, monthly maintenance, and camp pressure. |

| `common/scripted_guis/camp_repression_ledger_scripted_gui.txt` | Camp ledger action gate. |
