# Chaos Redux settings documentation

This directory documents shared settings controls and their persisted or staged behavior. It does not redefine the layout of the settings interface.

## Navigation

- [`chaosx_event_logging_controls.md`](chaosx_event_logging_controls.md) defines shared logging and diagnostic controls exposed through settings.
- [`chaosx_help_window.md`](chaosx_help_window.md) defines the help-window content and ownership boundaries.
- [`chaosx_settings_export.md`](chaosx_settings_export.md) defines settings export behavior.
- [`settings_miscellaneous_menu.md`](settings_miscellaneous_menu.md) defines miscellaneous settings and their runtime effects.
- [`settings_numeric_manual_inputs.md`](settings_numeric_manual_inputs.md) defines typed numeric entry, validation, and staged application behavior.

Triggerable scenarios are documented with the event system in `../event_system/triggerable_scenarios.md`. Shared main-menu and map-mode contracts belong in `../interface/`.
