# Decision category presentation audit

This audit covers the complete union of current Chaos Redux decision-category metadata and top-level decision containers as of 2026-08-09. The detailed metadata table below covers the original 240 category definitions; the source-mapped inventory under `docs/plans/decision_category_formable_state_puzzle_plans/repo_inventory.md` adds the 56 original container-only ids and provides the full 296-id crosswalk.

The active installed consumer is Vanilla HOI4 `interface/countrydecisionview.gui`: the normal category picture occupies a 114x101 region inside `decision_category_desc`, while an attached scripted GUI is inserted below the category description.

The review order is ordinary icon/text, static picture, animated picture with static fallback, compact attached display, then full scripted GUI or a separate mechanic window.

Animation was not selected because none of the accepted picture additions needs motion to communicate mobilization, escalation, territorial change, or transformation.

## Summary

- Audited category ids: 296 unique ids from 240 original metadata definitions and 287 top-level decision containers.
- Current mod metadata definitions: 263 after the 21 formable attachments in this task plus separately owned UWR and Independence Wave FORM-09 metadata admissions in the shared worktree.
- Original container-only ids: 56, comprising 48 formable categories with Vanilla metadata inheritance, seven Independence Wave council categories, and `soviet_collapse_uwr_blacksite_category`.
- Baseline pictures across the full union: 81, comprising 34 mod-defined pictures and 47 inherited Vanilla formable pictures.
- Final pictures across the full union: 90 after three archival and six generated additions.
- Baseline scripted GUIs: 20.
- Final scripted GUIs: 41 after 21 compact formable state-puzzle displays.
- Accepted new archival static pictures: 3.
- Accepted new generated static pictures: 6.
- Accepted animated pictures: 0; no selected category needed motion to communicate its state.
- Accepted compact attached displays: 21, all for fixed-state single-decision formables.
- Accepted new full scripted GUIs or separate mechanic windows: 0.
