# Event 010 Death Super-Event Research — Black Oath / Herald Oath Reveal

This note is the focused text handoff for the optional Event 010 `Death` Herald route super-event.

The functional role label below is not final localisation. It is only a research and implementation label.

This note supplements the broader research in `docs/super_events/010_death_super_event_text_research.md` and narrows the recommendation to the implemented Black Oath / Herald reveal route.

## Role summary

- Functional role label: `Herald oath reveal`
- Trigger: a major country or player-led country publicly pledges to Zol / takes the Black Oath
- Role: hidden-route reveal; public betrayal of the living
- Tone target: government euphemism, cultic surrender, documentary oath language, state-level betrayal

## Selected final text package

- Selected title: `A Covenant with Death`
- Selected button / cultural remark: `We are at agreement.`
- Selected main quote: `We have made a covenant with death, and with hell are we at agreement.`
- Selected quote source: Isaiah 28:15, King James Version
- Source type: scripture / primary text
- Year / period: 1611 KJV translation
- Attribution confidence: High
- Copyright note: Public domain

## Why this package fits the exact role

This is the strongest complete package for a state publicly swearing itself to Zol. Isaiah 28:15 is not merely a death line; it is explicitly framed as rulers declaring a false bargain they think will shield them from catastrophe. That makes it unusually precise for a government entering the Black Oath under euphemistic, self-justifying language.

The title is short and final enough to mark a super-event without sounding like the route's terminal world-end state. The button keeps the bureaucratic tone of a signed settlement or formal understanding. The quote supplies the full betrayal and vow in one verified line.

## Implementation recommendation for the parent

- Use the selected package if the route is presented as an official public pledge, treaty, or state oath to Zol.
- Keep `A Covenant with Death` as the strongest title unless the parent deliberately wants less explicit scriptural naming.
- If the event image centers on a signed document, black seal, or cabinet table, `Set to his seal.` is the best backup button.
- Do not reuse the functional role label `Herald oath reveal` as final localisation.
- No text blocker remains for this optional super-event.
