## Fit

Isaiah 28:15 is the strongest researched source for the Black Oath route because it names a formal bargain with Death. The title and remark use the language of an agreement, which matches a state pledge, sealed paper, and public betrayal of the living.

The quote intentionally uses only the opening clause. The full verse continues into a longer doctrinal structure, while the super-event needs a short oath line that can be read quickly on screen.
