# Event 31 non-portrait asset source research

Research date: 2026-08-29.

Scope: rights-cleared, public-domain, licensed, or otherwise defensible non-portrait visual records for generic terror response, evacuation, relief, reconstruction, damaged transport, period communications, and fictional terminal-event visual reference.

Safety boundary: this pass searched only for civic, humanitarian, archival, military-response, communications, and reconstruction material, and did not research operational extremist methods, real extremist branding, sacred hostile imagery, or real extremist organizations.

## Outcome

The Event 31 super-event prompt requires fictional, ambiguous, non-sacred terminal imagery for The False Revelation and The Broken Claim, so historical photographs are not suitable as the final reveal or defeat images without a parent-approved change of source mode.

The existing super-event images remain an inventory-only generated-art package and were not overwritten, reprocessed, or treated as sourced material.

Two existing report images have a defensible archival source match and can remain source candidates: the London Waterloo evacuation photograph and the Würselen civilian-aid photograph.

The existing railway-repair and damaged-bridge report candidates lack durable source records in the named asset package and remain needs_user_review.

The external records below are research-only candidates because no external file was downloaded into the Event 31 package during this bounded pass.

No new PNG, DDS, manifest, GFX definition, localisation entry, workbook row, or runtime wiring was created by this task.

## Source and rights status

Status values used here are verified-source-match, candidate-reference, generated-inventory, unverified-existing, and needs_user_review.

Public-domain statements below are limited to the jurisdiction and basis stated by the source record, normally a United States federal or military official-duty basis.

The project should retain the archive or photographer attribution even where the source record states public domain.

No record is called rights-cleared when the source page, archive, author, date, or licence could not be verified.
