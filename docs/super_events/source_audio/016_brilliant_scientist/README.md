The immutable Wikimedia page revisions, API records, source files, and source SHA-1 values provide the local provenance chain; the source pages and license links remain the public references.

- `evidence/license_eff_open_audio_1_0_original_eff_wayback.html`: archived original EFF Open Audio License 1.0 page for audio ID 90.
- `evidence/license_eff_open_audio_1_0_fedora_archive.html`: readable preservation of EFF Open Audio License 1.0.1, whose changes from 1.0 are identified as typographical and non-substantive.

The Brahms performer credit is corroborated by Musopen's current [Academic Festival Overture page](https://musopen.org/music/68-academic-festival-overture-op-80/) and [Skidmore College Orchestra / Johannes Brahms index](https://musopen.org/music/performer/skidmore-college-orchestra/composer/johannes-brahms/). The immutable Commons page remains the locally preserved rights record and includes the worldwide public-domain dedication, unconditional fallback grant, and VRTS ticket.

## Provenance note for Mahler II

The Commons credit hyperlink points to movement IV inside the Archive.org item, but the preserved Commons file is not movement IV. Its exact `11,147,620` byte size and SHA-1 `2be6474fb03c665ab7e31d47c91e50c289233d5e` match `02.PSO020103-Mahler-5-II.ogg` in the frozen Archive.org metadata. That resolves the hyperlink typo without inference from the music itself.
