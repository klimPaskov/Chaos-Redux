# ============================================================================
# Event-owned six-phase expedition race. The entry event initializes the
# bounded participant registry, opens one human entry window, selects the
# bounded AI-major roster after human responses, and shows one opening
# super-event. Participant state is advanced by country-scoped scheduled pulse
# events and decisions; no recurring world scan is used.

# The gameplay helpers live in
# common/scripted_effects/025_alien_technology_in_antarctica_runtime_effects.txt.
# The shared recovery ledger lives in the Event 025/Event 036 adapter and the
# Event 016 custom-technology owner API.
# ============================================================================
