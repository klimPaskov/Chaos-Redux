# The Pirate Amnesty GFX handoff

The runtime sprite is registered in `interface/fallout_world_end.gfx` as `GFX_report_event_fallout_pirate_amnesty`.

The event chain uses that sprite in `events/fallout_world_end_events.txt` for opening, delayed result, and callback presentation. The runtime texture path is `gfx/event_pictures/pirate_amnesty/report_event_fallout_pirate_amnesty.dds`.

The art is a dedicated fictional report image for candidate `789`. It is not shared with the Fallout transition, The Ghost Convoy, or The Harbor Without a City.
