# The Clean Certificate GFX handoff

Register `GFX_report_event_fallout_clean_certificate` in `interface/fallout_world_end.gfx`.

The runtime texture is `gfx/event_pictures/fallout_clean_certificate/report_event_fallout_clean_certificate.dds`.

The event consumers are the human opening, delayed result, and seasonal review blocks `chaosx.fallout.719`, `chaosx.fallout.721`, and `chaosx.fallout.723`.
