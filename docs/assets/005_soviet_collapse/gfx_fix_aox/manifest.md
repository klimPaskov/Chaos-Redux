# AOX focus icon package manifest

This package archives the installed 47-focus AOX icon set for Event 005 Soviet Collapse. Every selected asset has an original native-alpha ImageGen source, a 94x86 processed PNG, a converted DDS, an exact sprite/runtime crosswalk and candidate lineage.

The full focus names, descriptions and actual completion reward blocks are recorded in [aox_source_inventory.json](notes/aox_source_inventory.json). Exact submitted prompts, ImageGen output paths and retained candidate source paths are in [aox_imagegen_prompts.json](prompts/aox_imagegen_prompts.json). Pixel-level processing, alpha, bounds and strict DDS results are in [candidate_lineage.json](notes/candidate_lineage.json) and [dds_roundtrip_report.json](notes/dds_roundtrip_report.json).

The exact current consumer uses 94x86 textures through interface/005_soviet_collapse_focus_icons.gfx. The canonical national-focus references are 100x88; that reference canvas was not substituted for the live AOX texture size. Canonical art and visual-component assets were used only as style and composition references, not as runtime art or layered source images.
