# The Engineer Franchise GFX handoff

The runtime event picture is registered in `interface/fallout_world_end.gfx`.

- Sprite: `GFX_report_event_fallout_engineer_franchise`
- DDS: `gfx/event_pictures/engineer_franchise/report_event_fallout_engineer_franchise.dds`
- Consumer: `events/fallout_world_end_events.txt` events `chaosx.fallout.796`, `.798`, and `.800`
- Source and processed evidence: `docs/assets/796_engineer_franchise/`

The chain is an ordinary Fallout consequence-side chain. It does not register Fallout itself as a public event, evolution, or super-event.
