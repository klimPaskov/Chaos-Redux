## 2026-07-11 uniqueness correction

This section preserves historical dual-format comparison evidence from before the sound-only runtime migration. Its former OGG paths and hashes are not current runtime requirements.

The superseded ID 37 OGG matched Soviet Collapse ID 14 over the full 932-word Chromaprint sequence: similarity was `0.993730` against the ID 14 OGG and `0.994434` against its WAV file, both at zero offset. This is alternate encoding of the same recording, not merely use of the same composition. The previous ID 37 source remains preserved as `docs/assets/013_natural_disasters/audio_source/earth_rupture_egmont_source.flac` for audit history.

The replacement source is preserved as `docs/assets/013_natural_disasters/audio_source/earth_rupture_grieg_mountain_king_source.flac`. Its local SHA-1 is `7D34C97620149EFF83BC14A1E838EF5D8E66746B`, identical to the checksum published on the Commons file page, and its SHA-256 is recorded in the table above. The final WAV SHA-256 is `189AF2FD28DEFD122CDF80CA0CCBF34317268148B3379C0BEE382285F17346A8`; the WAV SHA-256 is `1D527BAD4BC93D77AC4265D4791D3B8ADABBA88C38C745F9A7623D554B6B7CFF`. Both decode to canonical 44.1 kHz stereo signed-16-bit PCM SHA-256 `0657C8A2E6897428E44C0423D2BEF0B3B4BDE15CB74BCC2C17B06F9AC0B911FE` and have a duration of `118.000` seconds. The replacement's nearest non-Event-013 decoded-audio comparison scored `0.589419`, well below the `0.993730–0.994434` confirmed-reuse cluster. IDs 38–42 also remained distinct from every other registered super-event recording.
