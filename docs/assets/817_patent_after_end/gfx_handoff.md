# Patent After the End GFX handoff

The event picture uses `GFX_report_event_fallout_patent_after_end`.

The sprite is declared in `interface/fallout_world_end.gfx` and points to `gfx/event_pictures/fallout/report_event_fallout_patent_after_end.dds`.

The report card is a static fictional image. No animation, audio, portrait, flag, or scripted GUI surface is required by this routine chain.
