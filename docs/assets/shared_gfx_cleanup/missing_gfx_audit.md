# Remaining Missing GFX Audit

## Scope and method

This audit compares static `GFX_` references in Chaos Redux gameplay, GUI, GFX, scripted-localisation, event, and localisation files against sprite definitions in both Chaos Redux and the installed vanilla game. Comment-only examples and dynamic prefixes ending in an underscore are excluded. Texture paths are checked against both loose mod and loose vanilla files.

All missing GFX problems in the requested biological-operation, Event 002 category, Japan campaign, map-mode, division-picker, flag, and related cleanup surfaces are resolved. The entries below remain outside this bounded cleanup and require their own event asset packages or inherited-interface review.
