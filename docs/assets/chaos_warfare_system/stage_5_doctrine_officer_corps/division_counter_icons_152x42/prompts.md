# Large division-counter generation prompts

Source mode for every row: built-in `$imagegen`, one independent generated source master per counter on flat `#00ff00` chroma-key, then official chroma-key removal. The final runtime file is a two-frame 152x42 strip: active/color frame at x=0..75 and neutral/monochrome frame at x=76..151. Each frame is a 76x42 transparent counter face.

Shared constraints: authentic HOI4 large land-counter language, thick near-black outline, warm ivory main shape, restrained burnt-orange accent, one bold role silhouette, no text/letters/numbers, no glossy 3D, no photorealism, no gradient-heavy rendering, no fake checkerboard, no white halo, no opaque square background, no copied vanilla symbol.
