# Chaos Redux Stage 2 protective-equipment icon manifest

Package scope: generated source masters, processed transparent PNGs, final DDS mirrors, runtime-copy DDS files, contact sheets, and parent wiring handoff for the bounded Stage 2 protective-equipment asset set.

Counts: 11 technologies, 14 equipment cards/archetypes, 2 decision categories, 19 decisions, and 5 state dynamic-modifier icons - 51 complete assets.

All sources are `imagegen` masters using the prompt key recorded below and expanded in [stage_2_prompts.md](prompts/stage_2_prompts.md). Sources use a uniform neon-green chroma key only as a processing field. Processed PNGs use real alpha. Final DDS files were produced with `.tools/convert_to_dds.py` using the verified uncompressed 32-bit BGRA convention, exact dimensions, and no mip chain.

Verified contracts used here:

- Technologies and idea-style state modifiers: `64x64`.
- Equipment cards and archetype summaries: `131x52`, matching the current equipment-card reference `gfx/interface/technologies/anthrax_bomb_equipment.dds`; no card was resized from another asset type.
- Decision icons: `32x32`.
- Decision categories: `52x40`, matching the current category reference `gfx/interface/decisions/decision_category_contamination_defense.dds`.
- Equipment runtime equivalent: `gfx/interface/technologies/stage_2_protective_equipment/equipment/`, because the repository has no verified `gfx/interface/equipment/` contract directory.

Path roots are repository-relative. Each package DDS archive path has an identical runtime-copy DDS at the listed `gfx/` path.

Parent closure: every sprite name and runtime path listed below is now wired exactly in `interface/cbrn_protection.gfx`. Row-level wording such as `sprite name proposed` or `exact sprite supplied` records the asset handoff state at production time; it is not an unresolved wiring uncertainty. The three source-slug/gameplay-ID differences for the national-reserve, priority-state, and emergency-state decisions are mapped explicitly in their Gameplay ID column.
