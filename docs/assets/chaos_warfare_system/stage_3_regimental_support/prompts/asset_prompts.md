# Stage 3 Regimental Support generation prompts

Source mode for every item: built-in `$imagegen` generation on a flat `#00ff00` chroma-key background, followed by the official local chroma-key removal helper. The shared visual direction was: Chaos Redux HOI4-style interwar/WWII field-manual icon art; olive drab, charcoal, bone-white, oxidized brass, muted hazard amber; tactile worn metal/rubber/canvas; one bold central subject; no text, watermark, halo, sticker border, glow, modern biohazard clip-art, hazard glyphs, biological bombs, camp imagery, or genocide imagery.

- `medium_armored_delivery_detachment`: medium tank with squat turret, sealed delivery drums and protected side racks.
