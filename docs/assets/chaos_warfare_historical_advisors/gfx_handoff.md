# Historical CBRN Advisor GFX Handoff

Runtime DDS files are installed under `gfx/interface/advisors/cbrn/`.

`interface/cbrn_historical_advisors.gfx` registers one `GFX_idea_<character>` sprite for each of the twelve static characters.
`common/characters/cbrn_historical_specialists.txt` assigns the corresponding sprite as the character's army-small portrait while preserving the existing army-large scientist portrait.

No raid icon, doctrine icon, leader portrait, or existing Chaos Redux icon was overwritten.
No cross-type substitute or generic advisor icon is used.
