# Spec 66 The Second Dust Bowl asset package

This package contains the generated static report-event picture for Spec 66, The Second Dust Bowl.

The image is a fictional North American plains farmstead under an ash-darkened sky. It shows blowing soil, improvised windbreaks, covered seed rows, period farm trucks, and small farm families securing the crop. It is intentionally not a famous archival-photo recreation and contains no readable text, brands, flags, attested symbols, zombie imagery, animation, or audio.

The source image was generated with the official built-in ImageGen workflow because the scene is fictional and alternate-history. It was then processed with the repository report-event processor to the standard `210x176` RGBA report-card footprint and converted with the repository DDS converter to an uncompressed one-level BGRA DDS.

Runtime output: `gfx/event_pictures/fallout_world_end/report_event_fallout_second_dust_bowl.dds`.

Runtime sprite: `GFX_report_event_fallout_second_dust_bowl` registered in `interface/fallout_world_end.gfx`.

The asset package does not own `.gfx` or gameplay edits. Parent wiring now consumes the sprite from events `chaosx.fallout.656`, `chaosx.fallout.658`, and `chaosx.fallout.660` in the dormant reviewed tranche.

Live report-card presentation remains unverified because HOI4 was not launched.

The source PNG, processed preview, prompt, manifest, validation notes, contact sheet, and handoff are retained here while the event remains active.
