# Children of the Cordon GFX handoff

The interface registration lives in `interface/fallout_world_end.gfx`.

The event picture references `GFX_report_event_fallout_children_of_cordon`. The sprite points to `gfx/event_pictures/fallout/report_event_fallout_children_of_cordon.dds`.

The event file uses the same sprite for the human opening, the delayed result, and the delayed callback. The hidden AI lanes never display the picture, but retain the same event definition so the scheduler has one token family.

No school, border inspection, clean certificate, returning disease, zombie, or ordinary super-event asset is used by this chain.
