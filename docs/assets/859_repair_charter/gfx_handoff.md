# The Repair Charter GFX handoff

Register `GFX_report_event_fallout_repair_charter` in `interface/fallout_world_end.gfx` with texture path `gfx/event_pictures/fallout/report_event_fallout_repair_charter.dds`.

The runtime consumer is the human opening, delayed result, and charter audit events in `events/fallout_world_end_events.txt`. Hidden AI events use the same event token path without rendering the picture.
