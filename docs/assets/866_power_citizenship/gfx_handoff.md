# Power as Citizenship GFX handoff

Register `GFX_report_event_fallout_power_citizenship` in `interface/fallout_world_end.gfx`.

The sprite points to `gfx/event_pictures/power_citizenship/report_event_fallout_power_citizenship.dds`.

The event range `chaosx.fallout.866` through `chaosx.fallout.872` uses this sprite for the human-facing opening, delayed result, and citizenship audit. Hidden AI and cleanup blocks retain the same picture reference for consistent asset audits.
