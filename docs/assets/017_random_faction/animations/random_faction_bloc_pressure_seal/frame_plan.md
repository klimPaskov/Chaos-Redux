# Frame Plan

| Frame | Motion state | Visual change |
|---|---|---|
| 000 | rest | lowest pressure state |
| 001 | rising | pressure signal begins |
| 002 | rising | subject tightens and light grows |
| 003 | high | warning or seal light strengthens |
| 004 | peak | strongest cable/pressure state |
| 005 | easing | pressure starts falling |
| 006 | easing | subject relaxes |
| 007 | rest return | visually close to frame 000 for loop continuity |
