# Image-Generation Prompts

These prompts produced the six original fictional 1936 revival flag masters.

They are preserved verbatim so the source intent and historical-status boundary remain auditable.

## DSX — Oyo revival

```text
Use case: logo-brand
Asset type: flat 1936 alternate-history country flag master for Hearts of Iron IV, Oyo revival (tag DSX)
Primary request: create one original, culturally grounded but explicitly fictional Oyo revival flag. Use a large, clean interlaced Ìbọ̀ / Solomon-knot motif derived from documented Oyo royal vocabulary, with a subtle pair of outward cavalry spearheads integrated into the knot rather than separate weapons.
Style/medium: exact flat vector-like flag graphic, orthographic, full rectangular canvas, crisp hard edges, no texture.
Composition/framing: 3:2 landscape flag filling the entire image; deep indigo field; one large centered ivory-gold interlaced knot with restrained dark red accents; balanced negative space; emblem must remain recognizable at 10x7 pixels.
Constraints: this is a fictional 1936 revival design, not a claimed historical flag; no people, faces, deities, sacred caricature, text, letters, numbers, maps, coats of arms, crowns, stars, generic Pan-African tricolor, gradients, shadows, highlights, bevels, outlines that look like stickers, waving fabric, folds, flagpole, sky, scene, perspective, vignette, border frame, watermark, or signature. Output only the clean flat flag artwork.
```
