# Dormant Fallout Mine Generator report art

Spec 64 root outputs are `source_generated.png`, `processed_210x176.png`, `manifest.json`, `report_event_fallout_mine_generator.dds`, and `handoff.md`.

This temporary package contains the fictional generated source photograph and the deterministic HOI4 report-card treatment for the dormant Fallout Mine Generator tranche.

The approved scene is an ash-dimmed sub-Saharan African mining settlement with a corrugated generator shed, guarded machinery, ore carts and stockpiles, anonymous workers at a ration ledger, and sparse food stores.

The source mode is `$imagegen` because the scene is fictional and alternate-history, and a unique documentary composition is more appropriate than a real archive photograph.

The processed preview is the approved `210x176` RGBA report-event card with transparent edge space, a subtle deterministic tilt, soft shadow, black-and-white treatment, restrained sepia, and documentary grain.

The root machine-readable manifest is `manifest.json`. The root handoff is `handoff.md`.

The review contact sheet is `contact_sheets/report_event_fallout_mine_generator_contact_sheet.png`, and the DDS decode inspection is `processed_png/report_event_fallout_mine_generator_dds_decode.png`.

The runtime DDS is ready at `gfx/event_pictures/fallout_world_end/report_event_fallout_mine_generator.dds`.

The sprite is registered in `interface/fallout_world_end.gfx` as `GFX_report_event_fallout_mine_generator`.

No gameplay, localisation, GUI, event, or spreadsheet files are part of this asset package.
