## Authorized identity and source mode

The portraits depict one unnamed fictional supernatural Bodhisattva incarnation in a 1936 alternate-history setting and its staged forms. The task explicitly excludes Siddhartha Gautama, Padmasambhava, any other historical or living person, and any sourced religious painting's identity. Current effects create the leader with the anonymous name “The Bodhisattva”; the inspected portrait consumers do not name a historical leader. The False Buddha retains the same fictional face and is presented through a clearly altered, corrupt posture and costume. The Empty Seat contains no person.

This fictional identity uses native ImageGen rather than grounded sourcing. The connected `image_gen.imagegen` tool returned local original PNG paths and exposed no model selector; this package records only that actual execution route and does not claim a backend model name. No paid model provider or RunPod was used. The native image calls requested opaque full-canvas portraits because the inspected runtime portrait family is opaque.

The first Godly Figure source used the installed vanilla `Portrait_USA_Generic_land_4.dds` only as a painterly-finish and framing anchor. Its face, identity, clothes, insignia, and background were excluded. The parent accepted Godly Figure v1 and Refuge Bodhisattva v1 as original identity/style seeds on 2026-10-06, then reviewed all ten static native/4x crops and all sixteen playback positions in both native/4x animation contacts and approved the full twelve-DDS package for installation on 2026-10-06. See `notes/candidate_review_log.md`.

Tibetan monastic robe colors and construction and the Acala vajra prop were checked against the pages in `notes/prop_research.md`. Those pages were design-only research and did not provide an identity, portrait source image, or image input. Rights restrictions or unclear licenses for their photographs were respected by not downloading or using the photographs. The portrait-backdrop contact sheet was inspected only after the installed vanilla references; its assets were not supplied to ImageGen or used as portrait pixels.
