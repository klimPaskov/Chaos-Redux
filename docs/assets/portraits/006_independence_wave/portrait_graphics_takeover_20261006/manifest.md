## Source-quality findings

The KOS file is the accepted 3,769x6,000 Commons individual image. The overexposure is present in the original scan; no cleaner rights-cleared single-person image was found in the bounded search, and the old candidate image itself is damaged/background-only. The retained group photo was not used because the former front-right crop does not identify Shaban.

The CHU federal-presidium source is the D13-accepted Gayaz Ishaki book plate. A clearer Commons portrait from 1911 is available locally, but it is 25 years before the 1936 start and depicts a substantially younger Ishaki, so it was not substituted. A 1938 Warsaw crop is a promising closer-era Commons source, but its original file download returned HTTP 429 during this run; no source bytes were archived and no candidate was installed. The currently installed source crop already includes head and shoulders, so no contrast treatment was applied.
