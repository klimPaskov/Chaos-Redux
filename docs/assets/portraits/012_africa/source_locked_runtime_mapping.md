# Event 012 priority-member historical portrait runtime map

This file is the source-of-truth map for the sixteen male-only priority-member portrait consumers. Every runtime DDS is a 156x210 direct source crop or resize and is deliberately not repainted into a different historical likeness. The original source masters are retained in this directory with the `source_master_` prefix, and the crop/evidence workspaces remain under `docs/assets/012_africa_world_order/`.

The runtime contract is `gfx/leaders/012_africa/priority_members/portrait_012_africa_priority_<package>_sovereign_source_locked.dds` and the matching stable sprite is `GFX_portrait_012_africa_priority_<package>_sovereign`. The character keys and carrier tags are unchanged; no new country tag is created.

The four pre-photography or non-human-image rows are intentionally explicit: Kilwa uses a map panel, Great Zimbabwe uses an archaeological artifact, and Aksum/Nubia use ancient ruler artifacts. No generated face, tribal caricature, fabricated regalia, or unsupported insignia is attached to a historical person. Fictional ImageGen portraits remain a separate package family and are not used by these sixteen historical identities.

The runtime files are registered in `interface/012_africa_priority_member_characters.gfx`, while the source-crop DDS evidence and crop metadata remain under `docs/assets/012_africa_world_order/source_crops/portraits/`. Rights and attribution details for the archival rows are recorded in `docs/assets/012_africa_world_order/manifests/012_africa_priority_male_portrait_sources_licence_notes.md` and the source manifest beside it.
