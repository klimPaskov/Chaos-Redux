# Canal Schedule asset handoff

Runtime wiring is owned by the main implementation tranche.

The report card sprite is `GFX_report_event_fallout_canal_schedule` in `interface/fallout_world_end.gfx`.

The runtime file is `gfx/event_pictures/fallout_world_end/report_event_fallout_canal_schedule.dds` at 210 by 176 pixels with one mip level and an uncompressed BGRA layout.

Events 628, 630, and 632 use the report picture. The source and preview remain in this candidate package for review and are not reused by another event family.
