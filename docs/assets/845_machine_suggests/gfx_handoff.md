# The Machine Suggests GFX handoff

The runtime sprite is registered in `interface/fallout_world_end.gfx` as `GFX_report_event_fallout_machine_suggests`.

The event picture path is `gfx/event_pictures/machine_suggests/report_event_fallout_machine_suggests.dds`.

The gameplay consumer is `events/fallout_world_end_events.txt`, events `chaosx.fallout.845` through `chaosx.fallout.851`. The image is deliberately separate from the Laboratory Citizenship and Failed Calculation assets.
