# Event 012 Africa narrative-image generation records

All assets were generated with the official ImageGen tool in historical-scene mode. Matching canonical vanilla references were supplied from `.agents/skills/chaos-redux-event-assets/assets/vanilla_reference/event_art/` only: `report/report_event_african_soldiers.png` for reports, `news/news_event_001.png` through `news_event_004.png` for news, and the named super-event references below for super-events.

The common negative direction for every prompt was: no readable text, watermark, UI artifact, modern prop, logo, or generic futuristic costume. Report and news prompts additionally requested realistic 1930s–1940s clothing, vehicles, architecture, and documentary composition. Super-event prompts requested painterly historical-war-game composition without text or logos.
