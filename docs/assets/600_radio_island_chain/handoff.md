# Radio Island Chain asset handoff

Gameplay owns the .gfx sprite registration and event picture references.

The source workspace is docs/assets/600_radio_island_chain/. The processed preview is processed_210x176.png. The final runtime file is gfx/event_pictures/fallout_world_end/report_event_fallout_radio_island_chain.dds.

The sprite name is GFX_report_event_fallout_radio_island_chain. It is referenced by events chaosx.fallout.600, chaosx.fallout.602, and chaosx.fallout.604.

The DDS header was checked for DDS magic, a 124-byte header, 210 by 176 dimensions, 32-bit BGRA pixels, one mip level, and an exact 147968-byte payload. The normal-map cold-weather route remains gameplay-owned and is not represented by this report card.
