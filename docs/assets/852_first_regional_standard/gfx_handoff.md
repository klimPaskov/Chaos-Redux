# The First Regional Standard GFX handoff

The runtime sprite is registered in `interface/fallout_world_end.gfx` as `GFX_report_event_fallout_first_regional_standard`.

The event picture path is `gfx/event_pictures/fallout/report_event_fallout_first_regional_standard.dds`.

The gameplay consumer is `events/fallout_world_end_events.txt`, events `chaosx.fallout.852` through `chaosx.fallout.858`. The image is dedicated to the standards chain and is separate from the Machine Suggests and Laboratory Citizenship assets.
