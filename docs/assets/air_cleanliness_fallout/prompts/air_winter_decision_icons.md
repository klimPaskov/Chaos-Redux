# Air Winter Decision Icon Prompts

Each icon was generated in one separate built-in `imagegen` call. No reference image or previously generated image was supplied to any call. The complete prompt for a call was the shared contract below followed by that asset's block. The category prompt used the category-size wording in the shared contract. Every other prompt used the decision-size wording.

The response-priority icon deliberately depicts a wholly fictional abstract map board, so its built-in `imagegen` call used the standalone verbatim prompt recorded below instead of inheriting the shared contract's global `no map` constraint.

## Shared contract

```text
Use case: stylized-concept
Asset type: isolated Hearts of Iron IV decision-interface icon source art
Primary request: create one compact, action-specific civil-defence pictogram for a fictional soot-and-ash winter crisis
Style/medium: hand-painted Hearts of Iron IV interface art, aged 1940s civil-defence poster and engraved-metal character, realistic period materials, strong near-black outline, bold silhouette, restrained highlights, limited internal detail, not flat vector art
Composition/framing: one centered isolated emblem, square source canvas, generous empty padding on every side, no crop, no element touching an edge, readable when reduced to 32 by 32 pixels. For the response-category icon, compose for a wider 52 by 40 pixel category crop
Lighting/mood: cold slate-blue winter light with selective warm amber or muted red accents, severe but practical, weathered rather than glossy
Background: perfectly flat, solid, uniform #ff00ff chroma-key background from edge to edge
Constraints: no cast shadow on the background, no background texture, no gradient background, no halo, no frame, no card, no UI chrome, no readable text, no letters, no numbers, no watermark, no signature, no modern equipment, no photorealistic scene, no map, no flag, no split panel, no collage
Avoid globally: zombies, undead people, corpses, skulls, bones, blood, gore, monsters, infection symbols, biohazard symbols, radiation symbols, gas-mask skull motifs, supernatural imagery
```

## Response priority

```text
Use case: stylized-concept
Asset type: isolated Hearts of Iron IV decision-interface icon source art
Primary request: create one compact civil-defence pictogram for designating the current emergency response priority during a fictional soot-and-ash winter crisis
Subject: a small battered 1940s civil-defence map board viewed almost top-down, showing several abstract irregular administrative areas. One central state-shaped area is clearly singled out in warm ochre and held by one large round muted-red pushpin, while all other areas remain cold slate blue-grey. The board, highlighted area, and pin must read instantly when reduced to 32 by 32 pixels.
Style/medium: hand-painted Hearts of Iron IV interface art, aged 1940s civil-defence poster and engraved-metal character, realistic worn paper and board materials, strong near-black outline, bold silhouette, restrained highlights, limited interior detail, not flat vector art
Composition/framing: one centered isolated emblem on a square source canvas, board at a slight diagonal with the priority pin near the visual center, generous empty padding on every side, no crop, no element touching an edge
Lighting/mood: cold slate-blue winter light with the single warm ochre priority area and muted-red enamel pin, severe but practical, weathered rather than glossy
Background: perfectly flat, solid, uniform #ff00ff chroma-key background from edge to edge
Constraints: no cast shadow on the background, no background texture, no gradient background, no halo, no frame, no card, no UI chrome, no readable text, no letters, no numbers, no watermark, no signature, no modern equipment, no photorealistic scene, no flag, no split panel, no collage. The map shapes must be wholly fictional and must not resemble any real country, real border arrangement, or real-world territorial claim
Avoid: recognizable national borders, recognizable country outlines, flags, coats of arms, military insignia, arrows, route lines, compass roses, targeting reticles, hazard symbols, radiation symbols, biohazard symbols, zombies, skulls, bones, blood, gore, monsters, supernatural imagery. Do not use #ff00ff anywhere in the subject
```
