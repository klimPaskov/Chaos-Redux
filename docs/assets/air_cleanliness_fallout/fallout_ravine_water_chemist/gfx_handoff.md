# Ravine Water Chemist GFX handoff

Register the dedicated report sprite in `interface/fallout_world_end.gfx`.

```text
name = GFX_report_event_fallout_ravine_water_chemist
texturefile = gfx/event_pictures/fallout_world_end/report_event_fallout_ravine_water_chemist.dds
```

The event picture is referenced by `chaosx.fallout.499`, `.501`, and `.503`.
