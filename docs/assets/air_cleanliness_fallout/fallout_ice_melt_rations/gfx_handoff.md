# Ice Melt Rations GFX handoff

Register the dedicated report sprite in `interface/fallout_world_end.gfx`.

```text
name = GFX_report_event_fallout_ice_melt_rations
texturefile = gfx/event_pictures/fallout_world_end/report_event_fallout_ice_melt_rations.dds
```

The event picture is referenced by `chaosx.fallout.492`, `.494`, and `.496`.
