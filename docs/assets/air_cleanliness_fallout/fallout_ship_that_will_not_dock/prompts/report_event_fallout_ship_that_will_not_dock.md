# The Ship That Will Not Dock report-event prompt

Create a fictional alternate-history mid-century relief vessel outside a cold ash-dark harbour. Show civilian families under blankets, a ship doctor, a radio operator, sealed medical crates, a period tug, a quarantine boat, a frost-rimmed breakwater, wet cobbles, low winter light, and ash residue on the water. Keep the scene documentary and concrete. Use no text, flags, logos, modern objects, zombies, or gore.
