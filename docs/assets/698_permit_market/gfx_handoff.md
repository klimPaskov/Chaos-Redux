# Fallout Permit Market GFX Handoff

Register `GFX_report_event_fallout_permit_market` in `interface/fallout_world_end.gfx` with texture `gfx/event_pictures/fallout/report_event_fallout_permit_market.dds`.

The event file uses the sprite for human opening, result, and callback blocks. Hidden AI blocks use the same dedicated sprite only as a safe event definition reference and remain non-visible.

Do not move this art into a zombie, super-event, audio, or shared report path.
