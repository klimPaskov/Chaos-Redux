# Laboratory Citizenship GFX handoff

The runtime sprite is registered in `interface/fallout_world_end.gfx` as `GFX_report_event_fallout_laboratory_citizenship`.

The event picture path is `gfx/event_pictures/laboratory_citizenship/report_event_fallout_laboratory_citizenship.dds`.

The gameplay consumer is `events/fallout_world_end_events.txt`, events `chaosx.fallout.838` through `chaosx.fallout.844`. The image is deliberately separate from the Failed Calculation, Reactor Shift, and Grid Vote assets.
