## Processing notes

The raw grids are the retained ImageGen source evidence. `remove_chroma_key.py` with `--auto-key border --soft-matte --transparent-threshold 12 --opaque-threshold 220 --despill` produced alpha-clean grids. A local crop/resize pass only normalized, inset-cropped, trimmed disconnected grid specks, centered, and resized each generated cell to its type target; it did not invent or draw artwork. DDS conversion used the repository converter at `.agents/skills/chaos-redux-event-assets/tools/convert_to_dds.py`.
