## Deterministic post-processing

- Chroma-key sources were processed with the official
  `remove_chroma_key.py` helper using `--auto-key border --soft-matte
  --transparent-threshold 12 --opaque-threshold 220 --edge-contract 1
  --despill`.
- Report art was processed with the repository
  `process_report_event_image.py` default 210x176 report-card pipeline.
- DDS files were created only with the repository `convert_to_dds.py` legacy
  uncompressed BGRA converter.
- Flag sources were mapped without dithering to the fixed civic palettes
  recorded in `manifest.md`, reduced to 82x52, 41x26, and 10x7, mapped back
  to the same palette at every size, and written as uncompressed bottom-origin
  32-bit TGA.
