# Event 006 Mediterranean and Danube flag ImageGen prompts

## Provenance rule

Every source raster in this package came from a separate call to the official
ImageGen tool. Historical images were used as subject and geometry constraints;
canonical Chaos Redux flag images were used only as technical examples of flat,
orthographic, small-size-readable presentation. No cited SVG or local drawing
was substituted for an ImageGen source.

The original tool outputs remain in the generated-image store and exact copies
are retained under `source_png/`. The two rejected Trieste edits are retained so
the selection decision is auditable.
