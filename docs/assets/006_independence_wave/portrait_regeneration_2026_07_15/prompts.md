# Event 006 fictional portrait generation directions

Each row was generated independently with official ImageGen. Leader rows used
the canonical vanilla Stauning and de Valera PNGs as style-only inputs.
Commander rows used the canonical vanilla land-commander and Mannerheim PNGs.
Every call required a portrait-orientation, head-and-shoulders composition that
could crop cleanly to `156x210`; painterly HOI4 semi-realism; hand-painted skin,
hair, cloth, and props; restrained interwar colour; soft directional light;
crisp individualized eyes and facial structure; subtle canvas texture; deep
vignette; period-authentic clothing; no copied real person, readable text,
frame, watermark, photorealism, anime, or modern equipment.
