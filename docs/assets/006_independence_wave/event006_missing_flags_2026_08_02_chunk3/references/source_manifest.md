| Tag | Context source | Design input and limitation |

| HSX | https://en.wikipedia.org/wiki/Muisca | Raft, sun, river, and mountain archaeology cues; no attested 1936 flag claim. |
| HUX | https://en.wikipedia.org/wiki/Patagonia | Wind, steppe, coastal wave, star, and sun cues; explicitly non-Welsh, non-Araucanian, and non-Argentine. |

Attempts to retrieve additional Wikimedia image references for the first three regional groups were rate-limited, so the package records the authoritative context URLs and the uncertainty instead of inventing a license or copying an unclear image.

The local ImageGen source masters are original generated files and are documented in `../metadata/asset_manifest.csv` with their runtime paths and SHA-256 values.
