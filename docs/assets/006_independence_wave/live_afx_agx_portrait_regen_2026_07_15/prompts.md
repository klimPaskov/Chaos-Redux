# Event 006 live AFX/AGX portrait prompts

All four masters were generated on 2026-07-15 with four separate calls to the
official OpenAI Codex built-in `image_gen` tool. The canonical vanilla leader
portrait library and its portrait contact sheet were inspected before the
calls and used for manual style and crop review; they were not passed as image
inputs and no vanilla face was copied. Each accepted source is the first and
only output requested for that identity.
