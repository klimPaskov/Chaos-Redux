# Event 006 researched flag tranche - COX-EBX

The generated source is flat orthographic flag artwork; no fabric, pole, scene, painterly texture, or ideology variant is used.

Design-reference URLs, source/reference hashes, ImageGen prompts, processed PNG hashes, TGA hashes, exact dimensions, origin/header checks, and decoded PNG/TGA equality are recorded in `metadata/flag_validation.json` and `metadata/hashes.sha256`. Wikimedia Commons licensing is file-specific; this package records the exact file/page URL and treats those files as reference evidence only. The final generated masters are original ImageGen outputs.

No ideology variants were requested or created. Map-only references for HYX, DKX, and DLX are documented as uncertainty-bearing regional evidence; their generated designs are not represented as exact historical standards.
