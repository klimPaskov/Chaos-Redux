# Event 006 researched flag tranche — COX–CYX

This package contains ImageGen source masters constrained by retained historical or regional reference inputs, mechanically flattened 820x520 masters, processed PNG previews, and bottom-origin 32-bit BGRA TGA triplets. The generated source is flat orthographic flag artwork; no fabric, pole, scene, painterly texture, or ideology variant is used.

Design-reference URLs, source/reference hashes, ImageGen prompts, processed PNG hashes, TGA hashes, exact dimensions, origin/header checks, and decoded PNG/TGA equality are recorded in `metadata/flag_validation.json` and `metadata/hashes.sha256`. Wikimedia Commons licensing is file-specific; this package records the exact file/page URL and treats those files as reference evidence only. The final generated masters are original ImageGen outputs.

No ideology variants were requested or created. The remaining assigned tags `DAX`, `DBX`, `DFX`, `DHX`, `HYX`, `DKX`, `DLX`, `DPX`, `DVX`, and `EBX` remain in the same package workspace for the next production tranche.
