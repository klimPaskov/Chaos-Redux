# Event 006 pre-DDS portrait reference shelf

This directory is the flat, reference-only shelf for source-derived Independence Wave portraits after the HOI4-style repaint and before deterministic 156x210 normalization or DDS conversion.

It contains exactly 56 original-size RGB PNG repaint masters directly in this directory. There are no nested folders and no 156x210 PNGs here. The filenames, source paths, SHA-256 values, dimensions, generation records, and review status are recorded in [PRE_RESIZE_MANIFEST.md](PRE_RESIZE_MANIFEST.md).

The shelf includes protected BAY Rupprecht and RHI Matthes masters, source-derived trial masters, and withdrawn or research-gated masters. The David Grenfell retry-04 and retry-05 raw masters are retained here as evidence copies despite their likeness hold; they are not runtime inputs. A file's presence is provenance only; it does not grant runtime admission, replace a leader, authorize a DDS, or bypass rights, identity, date, and independent HOI4-style review gates.

Former normalized shelf copies are not retained in this directory. The originating package workspaces and their manifests remain the authoritative processed-pipeline evidence; the flat shelf itself is intentionally limited to original-size masters.

Raw archival photographs, exact crops, ImageGen prompt records, review sheets, contact sheets, fictional or institutional portraits, flags, icons, advisor art, dossier derivatives, DDS files, and runtime-decoded textures remain outside this shelf by design.

This shelf has no runtime references. Follow the asset skill's mandatory attributed archival male photograph -> exact head-and-shoulders crop -> identity-preserving HOI4-style repaint -> independent likeness/style/provenance audit -> DDS workflow before wiring any grounded portrait.
