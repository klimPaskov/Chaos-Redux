## Description

### Object description

Son of Joseph Gervase Spendlove and Edith Mary Spendlove, of Brooklands, North Collingham, Notts. CWGC has date of death as 17 November 1914. Buried at Ypres Town Cemetery

### Object description

Second Lieutenant Gervase Thorpe Spendlove. Unit: 2nd Battalion, The Prince of WalesVolunteers (South Lancashire Regiment). Death: 17 November 1914 Killed on by a shell exploding in his dug-out. Western Front

### Physical description

Head portrait press cutting
