## Status

**No flag or country package is content-ready.** This tranche contains research, distributable reference images, production boundaries, and later ImageGen briefs only. It contains no generated art, no final PNG, no TGA ladder, no `.gfx` or gameplay wiring, no localisation, and no country files.

Current production dispositions:

- Sardinia: evidence-ready for a clearly labelled alternate-history civic synthesis; orientation and route ownership still require approval.
- Sicily: the surviving 1848 national colour supports a route-specific exact-object reconstruction, but it is not a neutral baseline and its original proportions are unresolved.
- Trieste: a red civic flag with one white/silver corsesca is attested for the 1918-1936 city and the post-war Zone A/Free Territory model; exact digital red, historic proportions, and the production silhouette still require review.
- Banat: blocked/synthesis-required. No attested 1918 Banat Republic flag was located in the authoritative and scholarly sources consulted.

## Files

- `source_manifest.csv`: hashes, authorship, rights, authority, and use restrictions for every saved image.
- `historical_evidence.md`: package-by-package evidence, exact geometry where supported, dating, function, archive, and rights.
- `design_notes.md`: registry fit, vanilla-identity boundaries, route ownership, and production decisions.
- `imagegen_handoff.md`: strict prompts and commissioning gates for a later ImageGen production pass.
- `source_images/`: only images with an explicit redistribution licence.

## Source-of-truth order

When sources disagree, use this order:

1. dated law, treaty, decree, archive record, or catalogued surviving object;
2. official institutional history;
3. specialist scholarly or vexillological study;
4. a licensed modern reconstruction only as a visual aid.

The files in `source_images/` do not override the dated evidence described in `historical_evidence.md`.
