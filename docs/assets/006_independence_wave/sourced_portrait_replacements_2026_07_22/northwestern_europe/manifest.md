# Event 006 sourced portrait replacement ledger - Northwestern Europe

Research date: 2026-07-22. This is a source-mode package only. The fourteen files
under `source_masters/` are original downloads from the named source URLs; they
have not been cropped, resized, retouched, converted, or copied into runtime
folders. There are no PNG previews, DDS files, `.gfx` edits, advisor assets, or
contact sheets in this package.

`source_ready` means that the original bitstream was downloaded and its source,
date, and a defensible rights basis are recorded. `needs_rights_review` means a
local original exists but the archive/license chain or role fit needs a separate
approval before processing. `blocked` means a defensible candidate and source
page were identified, but no verified original bitstream was acquired in this
timeboxed retry; no substitute or generated face is supplied.

## Second bounded source retry

The retry added six face-visible original masters: Staf De Clercq, Joris Van
Severen, Jules Destrée, Robert Bontine Cunninghame Graham, William Edmund
Ironside, and David Lloyd George. Institutional/archive originals were used for
the latter three (Rijksmuseum IIIF, Library of Congress TIFF, and Internet
Archive page scan); the first three are verified Commons originals with an
explicit PD-anon-70-EU/PDM or public-domain basis. Wikimedia upload requests
were not retried after the host returned HTTP 429. A direct Bundesarchiv image
of Heinrich Held and a separate Bundesarchiv alternate for Franz Ritter von Epp
were inspected but rejected because the catalogue marks those digital images as
paid/not free; neither file nor any other rights-unclear alternate is retained.

Six roles remain explicitly `blocked`: AJX Johannes Hoffmann, BRI Morvan
Marchal, BRI Célestin Lainé, BAY Heinrich Held, BAY Franz Ritter von Epp, and
WLS Saunders Lewis. No substitute, generated face, proxy/re-encoded image,
crop, resize, PNG, DDS, or runtime file was created. The fourteen retained
masters remain source-only and must undergo the separate identity-preserving
processing and approval workflow before use.
