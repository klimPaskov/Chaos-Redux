## Shared provenance and QA

- Source mode for every row: `$imagegen` clean flat design, no fabric/artwork scene.
- Source masters are retained under `source_png/`; prompts are retained under `prompts/`; processed PNG masters and size previews are retained under `processed_png/`.
- Runtime files are the only engine-facing outputs. No `.gfx`, gameplay, localisation, or ideology files were edited.
- `metadata/eex_iax_flag_validation.json` records source, processed, package-TGA, and runtime-TGA SHA-256 hashes for all 18 rows plus the full uncompressed 32-bit bottom-left TGA headers and exact byte lengths.
- Contact sheets `contact_sheets/eex_iax_source_masters_contact_sheet.png`, `contact_sheets/eex_iax_normal_flags_contact_sheet.png`, and `contact_sheets/eex_iax_source_and_ladders_contact_sheet.png` provide visual evidence from source through all three runtime sizes.
- No ideology variants were created. No existing base flag was replaced.

All eighteen rows are `handed_off`; the main agent can wire them through normal HOI4 country-tag flag lookup without a `.gfx` sprite definition.
