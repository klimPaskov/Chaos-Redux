# Event 006 generated event-scene prompts

## Scope and source mode

ASSET-001 through ASSET-006 use generated documentary art because each scene depicts a fictional or alternate-history Event 006 moment rather than a real photographed event or real person. Every prompt forbids readable text, watermarks, modern objects, real-person likenesses, duplicated insignia, and modern cinematic styling. The generated files are source illustrations; target-size treatment is recorded in `generated_event_scenes_manifest.md`.

## ASSET-001 — wave summary

Create a convincing black-and-white press photograph from 1936–1945 showing the first public hours of an independence wave. A broad civic crowd gathers outside a worn provincial government building while several small local administrations distribute papers from the steps; clerks, civilian officials, police, soldiers, workers, and families must all read clearly. Include period street furniture, one modest 1930s utility truck, documentary depth, natural overcast light, imperfect film grain, and no single national identity dominating the scene. No map, no readable signs, no modern clothing or equipment, no famous person, and no theatrical propaganda pose. Landscape composition suitable for a later HOI4 report-event card crop.
