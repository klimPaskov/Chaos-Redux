# Reference retention policy

This folder intentionally retains text notes and stable URLs rather than copied page images.

- UNESCO and official institutional pages were used for descriptive research; no site photograph was copied because item-level image rights vary.
- The Wikimedia Idel-Ural SVG is discussed in the ledger as a contested modern reconstruction, but it is not retained as runtime art and is not copied into this package.
- Mar Eshai Shimun Foundation photographs, the Newcastle Levies photograph, and other archive images were not downloaded because the reviewed pages did not provide clear redistribution permission.
- The Library of Congress image listed in the ledger has a no-known-restrictions notice but depicts a different person and is explicitly excluded.

`urls.txt` is the re-check list. `reference_notes.md` contains short paraphrases rather than copied page text.
