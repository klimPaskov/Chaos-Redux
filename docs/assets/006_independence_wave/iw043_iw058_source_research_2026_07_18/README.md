# IW-043 / IW-058 source research package (2026-07-18)

This package is the source-only visual research handoff for the accepted Event 006 signature-country plans covering IW-043 (Middle Volga / Volga Bulgaria routes) and IW-058 (Assyria / Mesopotamian routes).

It does not contain final flags, generated art, portraits, DDS/TGA files, `.gfx` edits, or gameplay wiring. The ten requested cosmetic identifiers are proposed identifiers only. A later flag artist may use the research dispositions here to make flat, modern, ImageGen flag designs; the references are not instructions to copy a historical flag.

Files:

- `source_ledger.csv` — valid CSV with source URLs, local reference path, dates, provenance, confidence, licensing/reuse notes, design dispositions, and uncertainty.
- `flag_design_dispositions.md` — item-level historical basis, prompt-ready geometry/palette guidance, and disallowed symbols for all ten cosmetic identifiers.
- `portrait_eligibility.md` — real-person viability review, with the optional Mar Eshai Shimun XXIII candidate kept separate from the institutional generated-portrait baseline.
- `gfx_handoff.md` — explicit no-runtime-art status and future sprite identifier list for the parent wiring pass.
- `references/reference_notes.md` — short paraphrased notes tied to the ledger (not copied page text).
- `references/urls.txt` — stable URLs and access date for later verification.

Research scope and safety:

- Historical material is used to ground symbols, institutions, and color/geometry decisions. No unattested medieval reconstruction is presented as an authentic flag.
- Assyrian, Chaldean, Syriac, and Aramean identities/churches remain distinct. A church or Levies mark is not promoted to a community-wide state emblem without explicit attribution.
- Current (post-1936) Assyrian national-flag designs, modern church seals, and modern Iraqi state flags are research references only and are excluded from direct baseline copying.
- Rights-unclear archival photographs are not downloaded or transformed. The one real-person candidate (`ASY_shimun_eshai`) is `needs_user_review`; no portrait output is approved.
- No Event 006 advisor art is requested or supplied. BAY/RHI protected portraits are outside this package.

Access date for all web checks: 2026-07-18 (Europe/Kiev).
