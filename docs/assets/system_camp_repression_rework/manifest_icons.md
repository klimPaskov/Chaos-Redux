# Camp repression rework icon asset manifest

## Delivery summary

This package contains the complete accepted static icon tranche for the camp repression rework:

- 37 decision icons at `32x32`
- 30 idea/national-spirit icons at `64x64`
- 5 special-project icons at `161x98`
- 10 achievement compositions at `64x64`, each delivered as normal, grey, and not-eligible variants
- 82 distinct generated source compositions, 102 processed PNGs, 102 package DDS files, and 102 live DDS files
- four final review contact sheets

The 72 decision, idea, and special-project sources use a flat chroma-key background and transparent final alpha. The 10 achievement sources use the repository's opaque framed-achievement convention. Every source is a distinct built-in `imagegen` composition; no source artwork was duplicated, recolored, or derived from another icon.

## Scope and exclusions

The inventory was reconciled against current camp repression decisions, ideas, special projects, repository sprite definitions, and vanilla sprite definitions.

- `GFX_decision_category_repression_ledger` and `GFX_decision_open_repression_ledger` were already complete in the accepted Ledger GUI asset package and were not recreated.
- `GFX_sp_mengele_cloning` already had a defined live texture and was not recreated.
- `GFX_decision_generic_political_discourse` resolves to a vanilla sprite and was not recreated.
- No undefined custom decision-category sprite remained after that reconciliation.
- Report, news, super-event, portrait, and Ledger GUI assets remain outside this icon tranche.
- Achievement IDs `000_chaos_redux_60` through `000_chaos_redux_69` are included as the explicitly accepted scope expansion.
- No `.gfx`, gameplay, localisation, workbook, or root asset-manifest file was edited by this asset tranche.

## Generation and processing record

The shared decision/idea prompt directed `imagegen` to create a single centered 1930s–1940s hand-painted grand-strategy emblem, readable at its final UI size, isolated on perfectly flat `#00FF00`, and free of text, numbers, logos, flags, political insignia, people, protected-class imagery, portraits, blood, gore, and graphic violence. Every paper, seal, dial, stamp, shield, and tag was requested blank. Each row below records the distinct subject supplied to that shared prompt.

Special-project prompts used the same restrictions but requested a coherent wide `1.64:1` tableau with enough green margin for exact `161x98` fitting. Achievement prompts requested a distinct opaque square composition with a dark bronze beveled frame and explicitly prohibited the disabled-state cross from the generated source.

Transparent UI sources were processed with the official `imagegen` chroma-removal helper using border auto-keying, soft matte, transparent threshold `12`, opaque threshold `220`, and despill. Final fitting preserves aspect ratio, adds a restrained dark edge and soft shadow for small-size readability, and leaves transparent margins. DDS export uses one-mip uncompressed 32-bit BGRA.

Achievement grey variants are exact grayscale conversions of the normal icon. Not-eligible variants composite the accepted repository cross overlay over the grey icon. The original skill reference folder is absent, so this package uses the accepted recovered overlay at `docs/assets/011_secret_alliance/source_png/achievement_not_eligible_overlay_recovered.png`; that source is documented as a `0.07/255` mean-error reconstruction from eight repository pairs and has the required 939 non-zero-alpha pixels. An exact package copy is preserved at `icons/source/achievements/achievement_not_eligible_overlay_recovered.png`. No red tint, generated cross, or hand-drawn substitute was used.

The deterministic pipeline is preserved at `icons/_tooling/process_icon_assets.py`.
