# Colonial and Generic Event Art Prompts

Package: `system_camp_repression_rework`

Workflow: built-in `$imagegen` (`image_gen`), one distinct generation call for every asset.

Shared contract:

- Taxonomy: `historical-scene`.
- Intended use: fictional or composite HOI4 report/news imagery, not archival evidence.
- Period: 1939-1946 photographic technology, clothing, architecture, vehicles, props, lenses, and press composition.
- Source output only: report-card tilt/sepia, news grayscale/contrast, exact crop, grain, and DDS conversion were local deterministic steps.
- Anonymous fictional people only; no real-person likeness claim.
- No readable generated text, protected-class selector imagery, graphic gore, SS runes, swastikas, or Rising Sun imagery.
