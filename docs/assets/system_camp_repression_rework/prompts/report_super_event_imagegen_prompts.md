# System Camp Repression Rework Report and Super-Event Image Prompts

All selected sources were generated with the built-in `imagegen` tool in `historical-scene` mode. No input image was used. Each identity received a separate call and a separate source PNG.

The first `super_event_pingfang_exposure` result was rejected before package use because the model placed the readable number `731` on the building. It was not copied into the repository. The final prompt below explicitly forbids the digits and produced the selected blank-facade source.
