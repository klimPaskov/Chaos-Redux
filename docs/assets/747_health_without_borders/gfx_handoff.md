# Health Without Borders GFX handoff

The interface registration lives in `interface/fallout_world_end.gfx`.

The event picture references `GFX_report_event_fallout_health_without_borders`. The sprite points to `gfx/event_pictures/fallout/report_event_fallout_health_without_borders.dds`.

The event file uses the same sprite for the human opening, delayed result, and delayed callback. Hidden AI lanes remain picture-free while retaining the same event token family.

No sealed-city, zombie, military assault, ordinary super-event, real-person, or real-flag asset is used by this chain.
