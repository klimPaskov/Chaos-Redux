# Event 020 Black Plague dedicated news strips

Status: `installed`. All nine requested generated news strips have source PNGs, exact processed previews, final DDS files, prompt records, contact sheets, DDS round-trip QA, registered sprites, and mapped Event 020 news consumers.

Source mode: native `$imagegen` generated fictional or alternate-history period documentary/news imagery. Generation fits because Black Plague outbreak states, Rat King events, and Rat Nation consequences are fictional and require bespoke scenes rather than real archive identities. No real person, real place, real battle, or readable publication is represented.

Reference evidence: the canonical `.agents/skills/chaos-redux-event-assets/assets/vanilla_reference/README.md` and `CATALOG.md`, the native `.agents/skills/chaos-redux-event-assets/assets/vanilla_reference/event_art/news/contact_sheet.png`, the installed Vanilla `interface/eventpictures.gfx` news sprite definitions, `interface/eventwindow.gui` news `event_picture` consumer, and the installed `gfx/event_pictures/news_event_001.dds` legacy header were inspected before generation.

Processing: each native wide source was center-fit to `397x153` with Lanczos resampling, converted to grayscale, autocontrasted with a 1% cutoff, and saved as opaque RGBA with equal RGB channels and alpha `255`. Each processed PNG was converted with `.agents/skills/chaos-redux-event-assets/tools/convert_to_dds.py` to a one-level legacy uncompressed 32-bit BGRA DDS. Every DDS has exact length `243092` bytes, declared dimensions `397x153`, pixel format flags `65`, bit count `32`, masks `0x00ff0000/0x0000ff00/0x000000ff/0xff000000`, texture caps `0x1000`, alpha range `255-255`, and pixel-identical decoded round-trip evidence in `qa/dds_roundtrip_qa.json`.
