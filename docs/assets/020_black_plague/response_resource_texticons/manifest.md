The parent reports both sprite registrations in `interface/020_black_plague_texticons.gfx` are wired, along with three Response Capacity hover consumers. Medical Reserve cost-row token use remains for the wider cost-row rollout.

The canonical `icons/decisions/contact_sheet.png` was inspected before the Event 020 Medical Reserve decision icon. The texticon dimensions come from the installed vanilla resource family: `GFX_fuel_texticon` and `GFX_civ_factory` use 18x18 transparent DDS files, while `GFX_manpower_texticon` uses 18x16. The existing mod `GFX_medical_capacity_texticon` is also 18x18. The installed texture definitions are recorded in both JSON manifests.

The current Medical Reserve decision icon at `gfx/interface/decisions/020_black_plague/decision_medical_reserve.dds` was used only to understand the event subject; the new Medical Reserve texticon is a separately generated supply satchel. The Response Capacity panel at `interface/020_black_plague_response.gui:141-150` shows the capacity value as text and has no icon. Its 96x27 progress-strip asset is for countermeasure progress, so the new Response Capacity texticon is original field-triage artwork with two visible treatment bays.

Both selected PNG sources were generated by the built-in `image_gen.imagegen` tool with `transparent_background=true`. Source, processed, and final DDS files retain alpha. Processing crops the alpha>8 subject envelope with 4% transparent padding, resamples premultiplied RGBA with Pillow 12.3.0/LANCZOS into the inspected 18x18 texticon canvas, and does not use background removal.

The final DDS files are 18x18 legacy uncompressed BGRA, one level, 1,424 bytes each. Strict header checks and Pillow decoding confirmed alpha 0-255 and pixel-for-pixel equality with each processed PNG. The contact sheet is `review/contact_sheet.png`; it shows each ImageGen source, the native 18x18 PNG and DDS pixels, nearest and smooth enlarged previews, the actual visible alpha bounds, and Response Capacity candidate 01 marked rejected.

Response Capacity candidate 01 is preserved with its source and prompt because it failed the native-size readability review: its twin bays and cross collapsed into a low-contrast mass. Candidate 02 is selected and has a distinct two-bay silhouette at 18x18. No fallback or final-art simplification was used.

Status: both generated texticon assets are handed off, with sprite registrations and Response Capacity hover consumers wired per the parent. The Medical Reserve cost-row token is available for the wider cost-row rollout.
