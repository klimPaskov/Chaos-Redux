# The Failed Calculation GFX handoff

Register the dedicated sprite in `interface/fallout_world_end.gfx`.

```text
GFX_report_event_fallout_failed_calculation
gfx/event_pictures/failed_calculation/report_event_fallout_failed_calculation.dds
```

The event source uses this sprite for human-visible events `chaosx.fallout.831`, `chaosx.fallout.833`, and `chaosx.fallout.835`. Hidden AI and cleanup events do not present the picture to the player.
