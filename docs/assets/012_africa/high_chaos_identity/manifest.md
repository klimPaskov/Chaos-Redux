## Scope

This package replaces the remaining generic human portrait gap for the five scoped high-chaos tags:

- `BBS` — Baobab Senate
- `TDM` — Tidemark Dominion
- `ANW` — Ananse Web
- `OVN` — Orisha/Vodun Nature Courts
- `CRR` — Crocodile Rivers

All five portraits are institutional or entity portraits. None depict a real historical human leader. All five should keep institutional leader names rather than personal random-name pools.

This portrait-only package did not produce flags. The later generated symbolic flag package supersedes the older flag gap for these five tags; see `docs/assets/012_africa/generated_flags/manifest.md` and `docs/assets/012_africa/implementation_asset_manifest.md` for live root, medium, small, and ideology-variant flag coverage.
