# Event 012 strange-force identity icon prompt record

The original provider prompt files for this retained package were not present in the repository. This record is an audit reconstruction of the visual intent used by the existing native ImageGen source PNGs and is not a regeneration request.

All eight units use an original Hearts of Iron IV-style symbolic icon treatment with a dark, high-contrast painted subject, a restrained occult-strange-force accent, and a chroma-key green source background removed before target processing. The source PNGs are review material only; the exact-size processed PNGs and DDS files are the runtime handoff.

| Unit | Reconstructed subject intent |
| --- | --- |
| Gorilla Heavy Infantry | Armored gorilla silhouette with heavy infantry mass, jungle foliage, and a forceful forward-facing pose. |
| Pan Sappers | Horned or pointed-eared Pan-like sapper with engineering tools and fieldworks cues. |
| Stone Cohorts | Stone-bodied cohort or fortress sentinel with masonry, shield, and disciplined formation cues. |
| Riverborn | Aquatic or river-serpent guardian with flowing water, spear, and basin/river symbolism. |
| Forest Giants | Ancient tree or forest giant with roots, canopy, and colossal guardian scale. |
| Oracle Recon | Divination eye, feathers, and scouting/reconnaissance symbolism with an occult watchfulness cue. |
| Disaster Wardens | Shielded warden containing storm, flood, or disaster energy while preserving a disciplined protector silhouette. |
| Plague Carriers | Sealed containment vessel, mask, or carrier silhouette with disease-control and hazardous-material cues. |

The target family sizes are technology 64x64, decision 32x32, focus/goal 94x86, division emblem large 76x42, and division emblem small 30x12. The source and intermediate alpha canvases intentionally retain their native source dimensions so that the chroma-key removal remains inspectable.

No character portraits, animation, or copied vanilla art are present in this package. Vanilla references were used only for family framing and target conventions, never as final art.
