# Event 012 Africa Focus Filter Icons

- Related event id: `012`
- Related event slug: `africa`
- Asset type: national focus search filter icons
- Package path: `docs/assets/012_africa/focus_filter_icons/`
- Source mode: generated dedicated filter-icon source art through the Event 012 icon subagent
- Target size: `27x27`
- Final live DDS folder: `gfx/interface/focusview/filter/012_africa/`
- GFX file: `interface/012_africa.gfx`
- Focus assignment file: `common/national_focus/012_africa_focus.txt`
- Localisation file: `localisation/english/chaosx_gui_l_english.yml`

This package supersedes the old five-filter package for active Event 012 focus routing. The active Africa tree now uses the full route taxonomy plus the retained special Authority Atlas and World Order filters. The old `FOCUS_FILTER_AFR_CHARTER`, `FOCUS_FILTER_AFR_SCRAMBLE`, and `FOCUS_FILTER_AFR_BESTIARY` textures remain in the folder only for compatibility with any older references; the current Event 012 tree no longer assigns those coarse filters.

The new icons are not cropped, resized, recolored, or lightly edited goal icons. They use dedicated 27x27 symbolic filter artwork with transparent unused canvas and no opaque square backing.
