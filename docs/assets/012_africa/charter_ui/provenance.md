# Event 012 Charter League UI provenance

All sixteen requested textures use the official built-in ImageGen workflow. The source PNGs in this workspace are the untouched generated outputs copied from the Codex generated-image store. Prompts requested hand-painted Hearts of Iron IV UI texture, a restrained brass/indigo/earth palette, text-safe interiors, and no readable text or watermark.

The animation source frames were generated independently with the same centered 64x64 framing and a flat `#00ff00` chroma-key backdrop. The seal frame plan is rest, rising glint, expanding rays, stamped peak, settling, fading, and return. The authority-ring frame plan is dim rest, clockwise arc growth, closed peak, softening, and return. Local processing removed only the key backdrop and normalized each authored frame to 64x64. No transform-only, recolour-only, blur-only, glow-pulse-only, or offset-only frame was promoted to runtime.
