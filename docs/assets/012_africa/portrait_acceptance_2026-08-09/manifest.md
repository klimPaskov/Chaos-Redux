# Event 012 Africa portrait acceptance manifest

Date: 2026-08-09

This manifest is the current source of truth for the retained Event 012 portrait package. It covers sixteen historical source-placeholder sovereigns, six fictional high-chaos adult-male sovereigns, three symbol-only evolution images, and the RSA alternate-history branch portrait. Every runtime portrait is 156x210 pixels. Historical portraits are unchanged source crops/resizes; fictional portraits use native ImageGen evidence; evolution images contain symbols only and no people, faces, silhouettes, animals, or body parts.

## Counts and runtime contracts

- Historical source placeholders: 16, each wired through `interface/012_africa_priority_member_characters.gfx` to `gfx/leaders/012_africa/priority_members/portrait_012_africa_priority_<package>_sovereign_source_locked.dds`.
- Fictional high-chaos sovereigns: 6 adult-male character portraits, all wired through `interface/012_africa_leaders_fictional.gfx`; Pan is the accepted v5 DDS and the other five remain their accepted v4 DDS packages.
- Symbol-only evolution images: 3, wired through `interface/012_africa_evolutions.gfx`; the v3 source generation replaces the older people-bearing v2 drafts.
- RSA branch: 1 individually archived adult-male Xhosa source portrait, wired through `interface/012_africa_rsa_portraits.gfx`; no generic vanilla portrait remains in the branch leader effect.
- Processing: PNG evidence is RGBA 156x210 and DDS output uses `.agents/skills/chaos-redux-event-assets/tools/convert_to_dds.py --width 156 --height 210`, BGRA 32-bit, one mip level, 131168 bytes per file. The DDS round-trip contact sheet decodes every accepted output back to 156x210.
