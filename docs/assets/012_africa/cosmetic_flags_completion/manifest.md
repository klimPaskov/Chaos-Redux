# Event 012 Africa Cosmetic Flag Families Completion

Date: `2026-06-17`

Scope: completion of the Africa cosmetic flag families for the Event 012 unifier base, route, and dynamic union identities.

Source mode:

- `AFR` and the five dynamic union identities were derived from the existing live/generated Event 012 symbolic flag family already present in the repository.
- The eight route identities were created as new fictional symbolic flags in the same palette/readability family, with local source-master compositing only.
- No web sourcing was used.
- No real national flags, modern emblems, or sacred regalia were copied.

House rules used in this package:

- Live flag filenames are explicit for the base stem and every ideology stem.
- Shared visuals across ideologies are intentional and written to separate files instead of relying on fallback behavior.
- Normal, medium, and small flags use `82x52`, `41x26`, and `10x7`.
- Root DDS copies were generated for the package record and the live `gfx/flags/` root files.

## Conversion notes

Local generation and conversion workflow used:

```bash
python3 <local PIL generation script>
convert <processed_png> -define dds:compression=none DDS:<final_dds>
```

TGA orientation note:

- ImageMagick TGA output was not used for final live flags because it wrote `- top` TGAs in this environment.
- Final live TGAs were written through PIL so the `file` output matches the existing non-top HOI4 flag convention.
