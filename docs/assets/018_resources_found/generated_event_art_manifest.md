# Event 018 Generated Raster Asset Manifest

## Package overview

This package contains the complete generated raster tranche for Event 018, Resources Found. Every accepted source image is original model-generated artwork; no third-party image or external licence is involved. The shared Oth-Kesh visual anchor is `docs/assets/018_resources_found/source_png/oth_kesh_species_reference_source.png`.

Runtime totals:

- 10 report-event DDS files at `210x176` with transparent report-card corners.
- 6 news-event DDS files at `397x153`, processed from true grayscale `L` PNGs.
- 3 super-event DDS files at `457x328`.
- 4 large leader/commander DDS portraits at `156x210`.
- 3 commander-small DDS portraits at `50x67`.
- 1 Vhorruk animation-sheet DDS at `1248x210`, containing 8 real source frames at `156x210`.
- 18 uncompressed 32-bit TGA flags: 6 distinct identities at `82x52`, `41x26`, and `10x7`.

All DDS files use the repository's one-mip 32-bit BGRA format. All flags use bottom-left origin and 8 alpha bits.

## Validation

The deterministic processor is `docs/assets/018_resources_found/_tooling/process_event_018_raster_assets.py`. It uses the project report-card processor with SHA-256 `5b51613f391934960a8310268041c66b00fdd31bc12da2393eb02c8f3dc87bd9` and `.tools/convert_to_dds.py`.

Validation checks exact dimensions, report transparency, news grayscale mode, DDS masks/mip count/pixel identity, TGA image type/32-bit depth/bottom-left origin/pixel identity, distinct source identities, distinct animation frames, an 8-frame GIF, and the absence of an obsolete `DHO_WORLD_END` final flag.

## Scope and omissions

No optional route portrait was produced because the final implementation does not map `leader_018_cave_collective` or `leader_018_cave_world_end`. Icon, focus, idea, decision, achievement, and scripted-GUI art belongs to the separate icon/GUI asset tranche. No requested raster identity in this tranche was simplified or omitted.
