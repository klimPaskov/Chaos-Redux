# Event 018 icon and category-picture generation provenance ledger

## Scope and authority

This is the exhaustive source ledger for the 150 Event 018 assets identified by the final completion audit: 65 focus icons, 36 unique idea/state icons, 44 decision or decision-category icons, and 5 decision-category pictures. Runtime names come from the live sprite registry and consumers. Source, keyed-alpha, processed, and runtime paths come from the preserved workspace masters and `docs/assets/018_resources_found/_tooling/process_event018_assets.py`.

The source mode is not inferred from appearance. Every one of the 150 source PNGs contains signed C2PA assertions naming `OpenAI Media Service API` and `digitalSourceType = trainedAlgorithmicMedia`. The binary C2PA scan returned 65/65 focus, 36/36 idea/state, 44/44 decision/category-icon, and 5/5 category-picture matches. These files are therefore recorded as original generated artwork, not internet-sourced, archival, public-domain, user-provided, or derived from a real person's likeness.

The pre-production family briefs are preserved in `docs/specs/018_resources_found_specs/prompts/resources_found_asset_prompt.md`. It did not retain the verbatim request body for each individual generation call. The prompt records below therefore use the explicitly permitted family-template form and interpolate one final, asset-specific subject per row. They are canonical prompt contracts grounded in the pre-existing brief and visible source masters, not fabricated quotations of an API transcript.
