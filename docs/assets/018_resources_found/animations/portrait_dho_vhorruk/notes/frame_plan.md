## Real source-frame sequence

1. Neutral command posture and relaxed breathing slits.
2. Early inhale: slits open, chest plates lift, two dust grains fall.
3. Full inhale: brighter sensory organs, expanded plates, mineral vapor.
4. Sensory shift toward screen-left while plates begin to settle.
5. Alert hold: narrowed sensory structure, lit flex seam, crown chip falls.
6. Exhale: eyes center, plates settle, vapor disperses.
7. Late exhale: slits nearly close and chamber seam light dims.
8. Return to neutral with the final dust motes, ready to loop into frame 1.

Each state is a separate generated portrait edit with locally redrawn anatomy, dust, vapor, sensory organs, or mineral plates. The final animation is not produced by moving, scaling, rotating, warping, blurring, filtering, or recoloring one still image.
