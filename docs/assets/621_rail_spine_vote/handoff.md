# Rail Spine Vote asset handoff

Gameplay owns the `.gfx` sprite registration and event picture references.

The source workspace is `docs/assets/621_rail_spine_vote/`. The processed preview is `processed_210x176.png`. The final runtime file is `gfx/event_pictures/fallout_world_end/report_event_fallout_rail_spine_vote.dds`.

The sprite name is `GFX_report_event_fallout_rail_spine_vote`. It is referenced by events `chaosx.fallout.621`, `chaosx.fallout.623`, and `chaosx.fallout.625`.

The DDS header was checked for DDS magic, a 124-byte header, 210 by 176 dimensions, 32-bit BGRA pixels, one mip level, and an exact 147968-byte payload. The image is dedicated fictional report art and does not prove the normal-map route.
