# Achievement Icon Regeneration Manifest

- Package: `docs/assets/achievement_icon_regen_hoi4_style_death_generic_2026_06_21/`
- Task scope: regenerate the listed Death and generic achievement icon families in HOI4 achievement style
- Asset type: achievement icons
- Target size: `64x64`
- Source mode: `$imagegen`
- Variant workflow: each `_grey` and `_not_eligible` variant was derived locally from the selected completed icon
- Final DDS format: `32-bit ARGB8888`
- Existing filenames preserved exactly
- Existing interface wiring preserved; no `.gfx` edits were made

## Shared Style Prompt

All generated base tiles used the same house style:

`Hearts of Iron IV achievement medal art, painted enamel, bronze laurel frame, full square tile, one clear central subject, strong contrast, readable at 64x64, no text, no transparent background, no white border.`
