# Metro Republic Below asset handoff

Gameplay owns the .gfx sprite registration and event picture references.

The source workspace is docs/assets/614_metro_republic_below/. The processed preview is processed_210x176.png. The final runtime file is gfx/event_pictures/fallout_world_end/report_event_fallout_metro_republic_below.dds.

The sprite name is GFX_report_event_fallout_metro_republic_below. It is referenced by events chaosx.fallout.614, chaosx.fallout.616, and chaosx.fallout.618.

The DDS header was checked for DDS magic, a 124-byte header, 210 by 176 dimensions, 32-bit BGRA pixels, one mip level, and an exact 147968-byte payload. The normal-map cold-weather route remains gameplay-owned and is not represented by this report card.
