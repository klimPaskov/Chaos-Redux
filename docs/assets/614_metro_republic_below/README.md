# Metro Republic Below report asset

This dedicated Fallout report image supports candidate 614 and its human result and callback events.

The generated source is a fictional European metro refuge with surface survivors descending through a damaged station, tunnel councils, ration crates, utility lamps, and guarded access points. It contains no readable text, real flags, real people, zombies, or gore.

The processed report card is 210 by 176 pixels. The runtime DDS is BGRA, one mip level, and is wired only through the Fallout-owned sprite GFX_report_event_fallout_metro_republic_below.

Source and runtime hashes are recorded in manifest.json. The report picture stays event-scoped and does not replace the normal map or the Fallout blackout surface.
