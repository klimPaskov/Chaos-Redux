# Event 012 Africa sovereign portrait generation records

All eight portraits in this tranche were generated with the built-in ImageGen tool as fictional high-chaos sovereigns. The historic polity names provide regional and material grounding only; no portrait claims a real person's likeness. Each source is a single-subject, portrait-oriented 2:3 master intended for deterministic export to an opaque 156x210 HOI4 leader texture.

Shared constraints for every prompt: one adult African sovereign only; tight head-and-shoulders bust; quiet low-detail background; controlled dramatic face lighting; subdued painterly HOI4 leader-portrait realism; no text, watermark, UI, labels, modern objects, modern uniforms, councils, groups, crowds, maps, busy scenes, caricature, stereotypes, masks, fantasy armor, extra limbs, duplicate faces, or cropped faces.
