# Event 012 dramatic council portrait prompts

The previous source-locked atmosphere prompts produced landscapes, ruins, and tint-only passes and are superseded. These records describe the accepted built-in ImageGen masters in `source_generated/`; each prompt used its matching prior source package only as an architecture/material/polity reference and did not preserve or claim any real-person likeness.

All prompts used the built-in ImageGen tool, target portrait composition, close official HOI4 painted-photographic style, 1930s/1940s material culture, readable distinct faces at 156x210, and the shared prohibitions: no text, watermark, UI, modern objects, caricature, invented sacred symbol, landscape-only, empty room, object-only, or solitary generic face.
