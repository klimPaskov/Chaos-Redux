# Clinic or Council GFX handoff

Register `GFX_report_event_fallout_clinic_or_council` in `interface/fallout_world_end.gfx` and point it to `gfx/event_pictures/fallout/report_event_fallout_clinic_or_council.dds`. Event ids `880`, `882`, and `884` use this sprite. The runtime texture is already converted to the 210x176 report-event size.
