# Event 014 Warlord Command Asset Manifest

## Scope

This package completes the 34 missing pre-reveal/warlord command surfaces registered in `interface/014_cannibalism.gfx`—two category icons, two category pictures, 18 decision icons, and 12 idea icons—and the two report-event pictures referenced by `interface/chaosx_pictures.gfx`.

Hannibal, the Wendigo, the unified-command burden (`idea_cannibalism_unified_command_burden`), and the Hannibal portrait are explicitly excluded. The public-reveal report is the only asset in this package that depicts the fictional revealed commander. All other art keeps the final commander absent or off camera. No animation package is required because every produced sprite is static and one-frame.

## Production record

- Source mode: built-in `$imagegen`, one generated composition per surface.
- Prompt ledger and safety-retry record: `prompts/warlord_command_prompt_ledger.json`.
- Reproducible processor: `process_warlord_command_assets.py`.
- Transparent icon cleanup: official chroma-key helper with soft matte and despill.
- Report-event treatment: repository `process_report_event_image.py`, producing tilted sepia/monochrome 210×176 transparent cards.
- DDS format: uncompressed BGRA8, one mip, alpha preserved.
- Validation: `validation/warlord_command_asset_validation.tsv`.
- Contact sheets: combined source, processed checkerboard, decoded live DDS, and type-specific processed sheets under `contact_sheets/`.
- GFX registration remains with the owning implementation agent.
