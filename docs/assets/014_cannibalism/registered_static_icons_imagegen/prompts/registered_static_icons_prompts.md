## Source and rights record

- Source mode: OpenAI built-in `imagegen`, one generation call per final asset.
- Source type: original fictional generated artwork. No archive photograph, real atrocity image, real victim, living artist reference, film still, mod asset, or vanilla asset was used as source art.
- External source URL, author, archive, and public-domain claim: not applicable.
- License note: no third-party source license is asserted; use of the generated outputs remains governed by the applicable OpenAI service terms and the Chaos Redux project rules.
- Era direction: invented 1936-1945 military equipment, ration stores, field medicine, transport, uniforms, bureaucracy, and fortifications.
- Cultural guardrail: prompts exclude national, religious, sacred, Indigenous, and other borrowed cultural motifs.
- Output mode: transparent icons were generated on a flat `#00ff00` chroma-key field and processed with the official imagegen chroma-removal helper. The category picture was generated as an opaque full-bleed scene.

## Common transparent-icon contract

Every transparent icon prompt identified the exact HOI4 asset type and final use (`32x32` for category/decision/mission icons, `64x64` for idea/state-spirit icons), then applied these requirements:

> Compact HOI4 painterly interface art using period military materials, a centered isolated silhouette, bold value contrast, enough padding for clean alpha removal, and readability at the final target size. Place the subject on a perfectly flat uniform solid #00ff00 chroma-key background with no texture, gradient, floor, reflection, or cast shadow. Use no text, readable writing, letters, numbers, watermark, modern object, national/religious/cultural/sacred motif, badge rim, coin frame, medallion, fake checkerboard, white outline, glow, opaque square backdrop, or green in the subject.

All gore is fictional. The palette uses dirty khaki, field grey, blackened steel, rust, bone, aged paper, mud, and dried or dark crimson blood.
