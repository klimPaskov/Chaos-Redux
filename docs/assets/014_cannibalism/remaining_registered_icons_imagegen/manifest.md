This package supplies exactly the remaining 68 registered static Event 014 icon assets from the frozen missing-asset ledger. Report images, news images, focus icons, achievements, flags, portraits, and animations are outside this tranche.

## Generation and processing contract

- Every final source was created by one distinct built-in image-generation call. No CLI image-model invocation was used.
- The sources are fictional painterly period tableaux or isolated chroma-key icon subjects. No sourced atrocity photography or fallback artwork was used.
- Seven first attempts containing an unintended red-cross emblem were rejected and preserved in `source_png/rejected/`; each affected asset was regenerated with a stricter no-emblem prompt.
- Panels are cover-cropped to 114x101 and forced fully opaque.
- Transparent icon families are keyed with the official imagegen chroma-key helper, fitted with crop-safe padding, given a restrained outline/shadow, and guaranteed transparent outer corners.
- DDS output uses the parent-approved Microsoft DirectXTex converter at `C:/Users/klimp/AppData/Local/Temp/chaos_redux_tools/texconv-may2026.exe` (version 2026.5.8.1, Authenticode valid, SHA-256 `DCFDEC10244E02CF5037FBA089C55FB7E1326B1C8181742D77D15FA5CB5EEF06`). The processor pins this exact backend.
- Package DDS and runtime DDS are byte-identical; decoded DDS pixels are pixel-identical to the processed PNGs.
