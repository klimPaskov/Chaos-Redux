# Event 014 asset archive cleanup

This archive is a source and QA workspace, not a runtime dependency. The game consumes the installed files under `gfx/`, `sound/`, `interface/`, and related runtime directories; it does not load files from `docs/assets/`.

The cleanup keeps the evidence needed to reproduce or audit an accepted package: selected source artwork and processed input, provider receipts and provenance, exported `.mesh`/`.anim` files, runtime DDS textures, validation JSON, reports, manifests, audio evidence, and the final handoff notes. It removes automatic Blender backups, superseded intermediate checkpoints, provider binary download caches, frame-by-frame Blender preview caches, historical candidate galleries, duplicate DDS/text dumps, and rejected portrait/counter batches that are already described by the retained manifests and audit notes.

No installed runtime file, accepted export, selected source-provenance record, derived runtime audio, final counter, installed portrait, flag, GUI art, or final handoff is removed by this pass.

## Retention rules

- `exports/`, `textures/`, `audio/`, `evidence/`, `validation/`, `runtime/`, package manifests, selected `refs/sourced/` source-page records, and final input manifests are retained.
- Blender checkpoints are disposable after the retained per-action validation JSON and export/reimport reports exist. No `.blend` checkpoint is a runtime dependency.
- `.blend1` automatic backups, superseded Blender checkpoint chains, and disposable preview archives are removed; the selected source input, provider receipts, manifests, hashes, and reimport proofs remain the audit record.
- Provider download binaries are workspace cache. Their task receipts, hashes, provenance JSON, and package manifests remain; the files can be re-downloaded from those records if a future rebuild is required.
- Adapter log streams, historical candidate galleries, duplicate protected Blender source snapshots, and source/derived reference caches are workspace cache, not shipping evidence. The selected `refs/sourced/` artwork and provenance remain, and the retained reports, hashes, manifests, processed source input, and validation JSON preserve the audit trail.
- Portrait and counter folders retain the selected/final candidates and validation outputs only; old candidate galleries, contact sheets, replacement batches, and rejected DDS previews are disposable.
- The remaining blocked Bone Riders and Network Cadre packages retain their latest reviewable source, manifests, and validation evidence, but no unsupported runtime claim is introduced.

The cleanup is deliberately limited to the Event 014 archive. It does not touch unrelated asset packages or runtime wiring.

## Verification

The first pass on 2026-08-25 measured `docs/assets/014_cannibalism/` at 1,501,911,950 bytes (1.40 GiB) across 4,525 files. A second conservative pass then removed all model-package `provider/`, Blender `checkpoints/`, sourced `candidates/`, adapter `logs/`, March preview archives, and disposable audio-source download/archive/extraction directories. The archive now measures 822,413,452 bytes (0.766 GiB) across 1,696 files, with no such disposable directories remaining. The installed runtime trees under `gfx/`, `sound/`, and `interface/` were outside the cleanup path. Historical manifests may mention removed provider-cache paths; those references are retained as lineage records rather than live runtime dependencies.

## Second-pass removals

- Removed all provider binary/cache folders under the nine model slugs.
- Removed all Blender checkpoint folders and the March Predation Column preview archives.
- Removed sourced candidate galleries and adapter log folders.
- Removed only disposable audio-source download, archive, extraction, comparison, and training folders; final derived WAVs, license/source-page records, and retained provenance stayed in place.
