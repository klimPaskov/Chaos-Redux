# Event 014 closure static-art prompt ledger

## Generation route

- Generator: Codex built-in imagegen tool.
- Source mode: generated; no internet, reused, default, placeholder, or transformed existing artwork.
- Date package: 2026-07-12.
- Final count: 21 independent generations.
- Icon source treatment: perfectly flat solid #FF00FF field, official imagegen chroma-removal helper, then independent 32x32 processing.
- Panel source treatment: opaque documentary-style source, independently cropped and graded to 114x101.

## Shared icon prompt contract

Every icon prompt identified the asset as a Hearts of Iron IV decision or decision-category UI icon composed specifically for 32x32. It required richly hand-painted 1930s-1940s grand-strategy art, period-authentic materials, one bold centered silhouette, generous padding, graphic dark blood where the subject called for it, and no frame. The background request was a perfectly flat solid #FF00FF chroma field with no shadow, gradient, texture, reflection, floor, or lighting variation. Every prompt prohibited #FF00FF in the subject, cast/contact shadow, readable generated text, watermark, checkerboard, opaque square, medallion, sticker border, glow, and white outline.

The four post-reveal winter-hunt prompts and the two winter-cell/muster prompts additionally prohibited ancient/classical, sacred, tribal, antler, horn, and living Indigenous motifs. The early-safe tracker prompts used the stricter information-hazard restrictions recorded below.
