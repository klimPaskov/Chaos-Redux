# Event 014 Europe/Asia/Africa Warlord Portrait Manifest

Tranche ID: `E14-POR-WARLORD-EAA-01`

This manifest covers exactly 24 regional Event 014 warlord portraits: CBA-CBH
for Europe, Asia, and Africa. It intentionally excludes Middle East, North
America, South America, and Oceania. The parent merge owns the combined
all-region manifest and all-set contact sheet.

All processed PNGs are `156x210 RGBA`. All runtime DDS files are uncompressed
32-bit BGRA, `156x210`, one base image, and `131168` bytes. SHA-256 values for
every source, processed PNG, and DDS are in
`europe_asia_africa_hashes.sha256`.

## Europe

The unsuffixed texture is the Europe runtime texture. Each texture is already
registered under both the unsuffixed portrait sprite and the explicit
`_europe` portrait sprite in `interface/014_cannibalism.gfx`.
