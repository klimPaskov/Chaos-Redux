That source is preserved at `source_png/decisions/rejected/aftermath_decisions_atlas_01_rejected_first_pass_source.png` with SHA-256 `F8F33BCC571E17AA738CF9BA94B4A9851898C5C03F8C9B53C710667A1CB439B8`.

The accepted last ten decisions use the unchanged second atlas source, and all four category sources remain unchanged.

## Processing and runtime conversion

Each crop was passed through `C:/Users/klimp/.codex/skills/.system/imagegen/scripts/remove_chroma_key.py` with `--auto-key border --soft-matte --transparent-threshold 12 --opaque-threshold 220 --edge-contract 1 --despill --force`. Processed decisions are normalized to exact 32x32 RGBA PNGs and categories to exact 50x40 RGBA PNGs. The four processed corners are forced transparent and alpha is remapped to a full 0..255 range where necessary.

Runtime DDS files were written with `.agents/skills/chaos-redux-event-assets/tools/convert_to_dds.py` as uncompressed 32-bit BGRA DDS textures with exact contract dimensions. DDS files were decoded back to PNG for pixel comparison and review contact sheets.

The machine-readable manifest, two assignment ledgers, exact sprite blocks, and validation report are in this folder. The validator checks 22 decision rows plus 4 category rows, unique source hashes, manifest/ledger sprite parity, exact dimensions, DDS headers and payload lengths, alpha, and decoded-DDS pixel identity.
