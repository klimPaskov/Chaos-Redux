# Stage 4 Temporal Frame Plan

| Frame | Separately authored visual state |
| --- | --- |
| 000 | Present Kruger studies a brass chronometer while an older self waits behind him. |
| 001 | A younger Kruger enters with an unopened notebook; the present self turns toward him. |
| 002 | The older self reaches across the present self to adjust the chronometer. |
| 003 | Present Kruger stands between young and old selves as all three choose different eyelines. |
| 004 | The young self writes while the present self points to a clockwork diagram. |
| 005 | The old self sits, visibly frailer, and passes a sealed instrument case forward. |
| 006 | Present Kruger receives the case; a different arrangement of clocks surrounds him. |
| 007 | A middle-aged variant enters profile with a broken watch and raised hand. |
| 008 | Four age states form a staggered laboratory council with distinct poses. |
| 009 | Present Kruger operates the opened case while the other selves withdraw. |
| 010 | The old self remains alone behind him, resting one hand on the chronometer. |
| 011 | Present Kruger closes the instrument and returns toward the frame-000 tableau. |

Each row requires a separately generated source image. Recolouring, smearing, dissolves, or geometric transforms of another frame do not satisfy the plan.
