# Event 016 aftermath decision icon contract

## Scope

The qualifying-defeat aftermath requires twenty-two distinct `32x32` decision icons and four distinct `50x40` decision-category icons.

The gameplay identifiers and runtime paths are already registered in `interface/016_brilliant_scientist_aftermath_decisions.gfx`; asset production must use those exact names and must not rename gameplay identifiers.

Every icon needs a retained source master, keyed or alpha intermediate, processed PNG, one-level uncompressed BGRA DDS, decoded DDS preview, provenance record, manifest row, technical validation, and source/processed/decoded contact sheets.

## Visual direction

Treaty icons should read as scientific law, institutional exchange, protected personhood, and prohibition rather than generic diplomacy.

Inspection icons should read as a physical laboratory register, formation ledger, sealed command archive, and final dismantlement certification.

Reconstruction icons should read as rail-and-factory repair, survivor medicine, a memorial archive, and the closing reconstruction board.

Remnant icons must keep clone, machine, paleogenetic, xenobiological, portal, temporal, biological, alien, and Singularity evidence visually distinct.

The palette should remain compatible with the Event 016 period-science package while avoiding resized focus art, reused KRG category emblems, generated text, modern electronics, flags, logos, and watermarks.
