# Event 015 Ledger District ImageGen Prompts

All calls used the built-in ImageGen tool. Every listed role or state was a separate call and therefore has an independent result handle. The accepted research-town master is a targeted built-in ImageGen edit of its own independent draft; it is not derived from another role.

Exact result handles and workspace source paths are recorded in `metadata/source_provenance.json`.
