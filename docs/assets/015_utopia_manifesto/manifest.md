# Event 015 Dormant Asset Archive

Event ID `015` is currently a disabled placeholder. The active Utopia Manifesto gameplay, UI, localisation, achievement, and super-event wiring has been removed.

The non-super-event art in this folder is retained only as dormant source material. It is not registered by an active `.gfx` file and is not referenced by live gameplay.

## Preserved

- Focus, decision, idea, achievement, flag, report, news, and Ledger GUI source or processed art that does not use a `super_event_utopia_*` filename.
- Runtime non-super DDS/TGA art under `gfx/interface/`, `gfx/event_pictures/`, `gfx/achievements/`, and `gfx/flags/` is likewise dormant unless another feature explicitly wires it in later.
- The source spec package remains under `docs/specs/015_utopia_manifesto_specs/`.

## Removed

- Final super-event DDS files under `gfx/super_events/015_utopia_manifesto/`.
- Package super-event PNG/DDS files named `super_event_utopia_*`.
- Utopia super-event audio package files and their source-audio archive.
- Active Utopia asset tooling and handoff documents that described removed runtime wiring.
