# Event 012 World-Order Cosmetic Flag Package

This active asset workspace contains the 39 generated cosmetic identity flag ladders declared in `common/countries/012_africa_world_order_cosmetic.txt`, producing 117 final TGA textures. Every identity has a distinct flat orthographic ImageGen source master and deterministic HOI4 normal, medium, and small exports. No country or cosmetic tag was added, renamed, or recoloured in place.

Source mode for every row is `$imagegen` using the built-in image generation path. The prompts required an intentional heraldic/civic emblem, a horizontal flag, no readable text, no flagpole, no fabric, no folds, no perspective, no shadows, no painterly scene, and readability at 10x7. High-chaos identities use symbolic weather, mythic, covenant, or maritime motifs and do not assign supernatural traits to any human ethnicity.

All source masters are retained under `docs/assets/012_africa_world_order_flags/source_png/`. Processed previews are under `docs/assets/012_africa_world_order_flags/processed_png/`. The review sheet is `docs/assets/012_africa_world_order_flags/contact_sheets/flag_ladders.png`. The processing evidence script is `docs/assets/012_africa_world_order_flags/notes/process_flags.py`.
