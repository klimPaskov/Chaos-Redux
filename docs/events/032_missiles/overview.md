# Event 032 - Missiles

Event 032 is a Minor Repeatable event rooted at `chaosx.nr32.1`. It uses the Calm World minimum-chaos rule, has no cluster membership, and enters through one bounded global firing transaction. The transaction freezes the eligible country scopes once, processes each frozen recipient once, and leaves repeatable pacing, first-news, and history accounting to the shared event dispatcher.

## Program lifecycle

Each recipient receives one normalized step through the existing `experimental_rockets` technology line. The core records a persistent stage, Operational Reserve, Launch Readiness, Command Control, guidance grade, retaliation posture, incident cap, and program phase. Mature recipients receive a bounded site-and-reserve package rather than a recurring global scan or an unbounded grant.

Launch sites are physical state records owned by the current controller. Registration requires a valid owned and controlled state, valid terrain and infrastructure, and available network capacity. Site records retain capacity, reserve custody, hardening, damage, isolation, compromise, rogue state, strategic-region identity, and incident receipts. Capture, civil war, release, annexation, succession, destruction, and scuttling reconcile the physical site and its reserve exactly once.

## Operations and consequences

Precision strike, strategic barrage, saturation barrage, and counterforce strike use the same persisted operation receipt with different costs, capacity demands, preparation windows, drift weights, damage profiles, and target rules. Preparation freezes the actor, victim, exact target state, profile, payload, site, reserve, and incident root; commitment revalidates those scopes and cannot silently retarget.

The scripted operation adapter owns the Event 032-specific preparation, launch, guidance, drift, impact, interception, damage, deaths, evidence, attribution, incident, and cleanup contract. Native raid behavior was inspected as a precedent, but no native raid is registered because the installed raid surface does not expose the required site custody, payload, guidance, attribution, and bounded cleanup contract.

Natural-disaster damage enters through a controller-validated, fail-closed bridge. The percentage reserve component is settled through the accepted/rejected reserve receipt before site mutation; destruction then settles the remaining ordinary allocation and captured-held receipt through the current-controller scuttle adapter, while strategic capacity loss recovers in bounded step-sized receipts without creating reserve.

Special payloads require the existing technology, policy, real stockpile, and site custody. Event 032 consumes the selected payload and submits the validated delivery to the shared CBRN, Deaths, Air Cleanliness, evidence, Condemnation, and Fallout consequence owners. Event 032 does not own a world-end branch, and it preserves the Event 16 reaction helper while keeping Event 23 and Event 76 ownership separate.

## Evolutions

The five separate evolution tracks are Saturation Arsenals, Unreliable Guidance, Special Warheads, Rogue Launch Commands, and Automatic Retaliation. Each track has its own eligibility gate, pacing entry, log row, AI factors, adoption state, interaction hooks, and disabled-safe behavior.

Automatic Retaliation exposes Off, Supervised, Delegated, and Automatic postures. Warning records retain source incident, attribution, root, parent, generation, queue kind, and response state. Verification and response windows are ordinary decisions and missions; automatic response uses bounded queued events and chain receipts and never makes a direct recursive launch call.

## Decisions, missions, and SCN-015

`missiles_program_management_category` is one ordinary category with a static picture and a dedicated category button. Its scripted description presents reserve, readiness, command control, technology, site count, guidance, target, posture, and the active crisis without adding a dedicated scripted GUI.

The category is phase-gated across establishment, maintenance, expansion, operations, preparation, incident, rogue-command, and retaliation emergency states. Routine actions are replaced by relevant emergency actions, while timed missions cover launch-state survey, secondary-site construction, site repair, site recovery, strike preparation, warning verification, and retaliation-network restoration.

SCN-015, Missile Age, is registered through the shared Triggerable Scenarios window at raw ID `15`. It supports Global Proliferation, Saturation War, Command Breakdown, Special Payload Crisis, and Retaliation Network profiles at four bounded intensities. The adapter uses the same profile preflight and idempotent country package contract as the core and never creates payload inventory or a terminal world-end state.

## Achievements and visual package

Event 032 has eight durable achievements: Exact Distance, Still on the Line, Break the Chain, Keys Returned, No Second Sun, Empty the Silos, Sky Full of Steel, and Long Reach. Tracking uses operation, incident, site, warning, war, repair, survival, evolution, and disqualifier receipts rather than current state alone. Every achievement has completed, grey, and not-eligible DDS states.

The visual package contains three full-canvas images, one category button, three program ideas, five site-state modifiers, three status texticons, five guidance icons, four retaliation-posture icons, 27 decision icons, seven mission-family icons, and 24 achievement-state icons. The exact runtime mapping and per-file visual audit are recorded in `docs/events/032_missiles/asset_audit.md`; Event 032 runtime DDS files are grouped under `gfx/event_pictures/032_missiles/`, `gfx/interface/decisions/032_missiles/`, `gfx/interface/ideas/032_missiles/`, `gfx/interface/state_modifiers/032_missiles/`, `gfx/texticons/032_missiles/`, and `gfx/achievements/`.
