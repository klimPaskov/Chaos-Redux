# Event 012 Africa release-candidate source of truth

## Purpose and release boundary

This file is the current documentation index for the Event 012 Africa release candidate. It reconciles the accepted specification, the subsystem event documents, dated implementation handoffs, current runtime evidence, the synchronized 239-row visual disposition matrix, and the shared acceptance ledger. The model-production record is mixed: Oracle Recon has an accepted local Meshy 7 PDX mesh and five-action export/reimport package with its replacement counter and runtime files staged, while live validation remains pending; Disaster Wardens intentionally reuses vanilla infantry with its custom registrations retired; the elephant formation intentionally reuses vanilla elephantry with its custom registrations retired; Gorilla Heavy Infantry, Pan Sappers, Stone Cohorts, Riverborn, Forest Giants, and Plague Carriers remain blocked or unpromoted under their current manifests. The other 18 full frame-animation packages, six promoted Tier A visual/runtime packages on existing Independence Wave carriers, six fictional male portraits, three no-person evolution images, four super-event roles, all 102 actions, all 16 priority-member package surfaces, the RSA Allied civil-war route, W4/W5 source certification, the Charter GUI, and the six world-order packages retain their separate evidence and gates. For the model subset, this is an asset-production handoff, not an in-game completion claim. Event 012 is playable and source-complete at the accepted gameplay boundary, but it is not genuinely finished while model live validation and blocked-package promotion, the Buganda replacement, strict grounded-portrait acceptance, temporary-workspace closure, and bounded MCP evidence remain unresolved.

The 2026-08-10 reconciliation supersedes older rows below that describe W5 as uncalled, the six continent packages as unique-package blockers, model or animation packages as deferred, or only three priority portraits as runtime-admitted. The current model status is instead governed by the per-package `job.yaml` and `manifest.md` files and the eight current strange-force handoffs for Oracle, Forest, Disaster, Plague, Gorilla, Pan, Stone, and Riverborn; the separate Elephant handoff records its explicit vanilla-elephantry reuse. The current package, animation, portrait, and super-event evidence is also recorded in `docs/events/012_africa/world_order.md`, `docs/events/012_africa/evolutions.md`, `docs/events/012_africa/portrait_runtime_gate.md`, the current acceptance ledger, and the installed asset manifests.

The accepted identity remains Event 12, a tier-4 Minor Fire-Once event in Formables cluster 6 with Severe member severity and entry event `chaosx.nr12.1`. The Formables cluster remains repeatable, while Event 12 itself remains fire-once.

The accepted evolution interpretation remains Baseline at tier 4, Evolution I at public tier 4, Evolution II at public tier 5, Evolution III at public tier 6, and the requested Evolution IV material as post-unification world-order escalation rather than a second logged tier-6 row.

## African-capital host and RSA integration contract

`africa_is_eligible_host` is the only host predicate. It admits every existing country whose current capital is in Africa, including original SAF, Ethiopia, Liberia, subjects, civil-war governments, and countries outside the 51-row named playbook matrix. Manual availability, automatic selection, the `.1` entry, and initialization all use this same contract. Event 12 is unavailable for lack of a host only when the map contains no live country with an African capital.

Named countries receive their full or compact dossier. An unmapped African-capital country receives the capital-only compact package and a continent-wide contact pool. Zero to five contacts may be frozen; a sparse or empty roster changes the opening sequence but never blocks selection. Meaningful focus trees remain active, while only the generic focus tree is replaced by the shared continental tree.

`africa_rsa_shared_entry_is_eligible` remains only as specialised proof for the optional Allied-rupture opening. It never controls whether South Africa can receive Event 12. The canonical `.1` entry calls `africa_rsa_start_allied_civil_war` once only after `africa_rsa_allied_branch_can_start` succeeds; otherwise South Africa receives the ordinary additive opening and keeps `south_african_focus`. `africa_rsa_record_event_log_history` continues to append Event 12 system rows for the dedicated rupture outcomes.

## Triggerable scenario: SCN-011 Africa Is One

The live registry row for the Event 012 manual scenario is `SCN-011`. The historical `SCN-008` reservation is occupied by Every Banner Rises, while raw slot `8` is Independence Wave, so neither historical identity is reassigned to Africa Is One.

The row exposes two types, `Africa Is One` and `World Is One`, with the shared four intensity stops `Low`, `Medium`, `High`, and `Maximum`. Low supplies a limited emergency force and modest opening deltas, Medium supplies a regional package, High supplies a large force and broader deltas, and Maximum supplies the strongest opening package. The selected type chooses the ordinary continental opening or the terminal-campaign preparation branch.

A fresh-host launch calls the manual Event 012 preflight, reuses the weighted African-capital host and frozen-contact builder, and queues the canonical `chaosx.nr12.1` entry for the selected host's commit barrier. An existing-host launch resolves the committed `event_target:africa_host` in place and applies the same one-shot opening without creating a second host or tag.

`Africa Is One` opens the continental systems and queues the existing Scramble response callback. `World Is One` opens the existing world-order package and terminal continental-campaign route, but it does not set `world_end`, write final proof, or assert the terminal identity; normal package, proof, settlement, and identity gates remain authoritative.
