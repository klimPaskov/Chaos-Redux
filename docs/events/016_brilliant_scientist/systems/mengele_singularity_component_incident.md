# Mengele Singularity component incidents

The registered Mengele Directorate can research the six existing Strategic Singularity component projects after it completes private Singularity Theory, holds the required live facilities, and receives registry access.
Each completed native component enters the separate Mengele component array once; the array's length determines the private component count and does not alter the Kruger project board.

## Risk and recovery

Each component's risky Prototype reward tests a private incident roll after the player selects that option.
The roll uses the existing Prototype capacity and accident stage factor as its incident weight, with a complementary safe weight in the same bounded random list.
An incident records one private active flag, a permanent history receipt, and the established Singularity command power and stability penalties.
An already active incident prevents another private incident from being recorded until the first is recovered.

The `mengele_event016_singularity_incident_recovery` decision commits two civilian factories for the existing technical response duration.
Its callback stores and debits Political Power, Support Equipment, and fuel through one exact private receipt.
Cancellation refunds a complete unsettled receipt once, while expiry consumes it and clears the penalty before recording recovery history.
Provider cleanup cancels an unresolved receipt and clears transient incident state while preserving the component array, learned projects, and both histories.
