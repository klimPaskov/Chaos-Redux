# Exact native stage completion hooks

The existing mapped native projects and radar technologies deliver their exact completion identity to the Mengele provider receipt helpers through hidden output calls.
Each call authenticates the live provider, family, requested stage, exact source, private predecessor, and empty paid receipt before settlement.
A matching active paid timer retains its current lifecycle under the user's explicit decision.

## Native file ownership

The mod replaces each native file at its original relative path and preserves all its installed definitions.
This prevents the standalone same-ID project definitions from combining their equipment and module output lists with vanilla definitions.
The user-supplied cycle1 live QA evidence reports the duplicate entries in air_projects.txt, radar_projects.txt, nuclear_projects.txt, and rocket_projects.txt at error.log lines 2-14.
The source fix removes the two standalone native marker override files.
