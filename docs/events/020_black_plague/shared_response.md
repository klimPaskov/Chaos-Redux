# Event 020 Disease Response Categories

Event 020 uses two coordinated decision surfaces. The dedicated `black_plague_response_category` owns national cure research, medical logistics, knowledge policy, international cooperation, and recovery. The existing `chaosx_disease_containment_category` and disease board retain selected-state quarantine, hospitals, treatment, cordons, rat clearance, transport controls, demolition, anti-rat operations, and terminal state missions. State actions check the selected state's phase and control and resolve through a bounded project that pays equipment, fuel, civilian production, command power, or stability as appropriate.

The dedicated category mounts the Event 020-owned `black_plague_response_category_scripted_gui`. Its compact, read-only dashboard shows Countermeasure Progress as the primary 0–100 meter and Medical Reserve and Response Capacity as the two supporting values. Programme stage, country and worldwide deaths, and international-response status remain available through concise text and tooltips. The dashboard starts no projects and changes no gameplay state; all cure, logistics, cooperation, knowledge, recovery, and selected-state actions remain decisions on their existing category surfaces.

Each of the 26 ordinary timed shared actions and the Royal Node counterstrike uses the [active-project cancellation correction](../../specs/020_black_plague_specs/corrections/2026-09-27_shared_state_action_cancel_lifecycle.md). Start-only gates reject an active action to prevent a second order on the same state; running actions instead cancel for real state, country, route, or receipt invalidation. The Royal Node continuation test retains its rat-held target, access, and military-route requirements. Changing the selected board state does not terminate valid work already underway. Completion clears the state action scale and grants the existing result, while cancellation clears any country-side pending token; the existing spent materials and cooldown remain.

The action ids are centralized in `black_plague_shared_action` in `common/script_constants/020_black_plague_shared_response_constants.txt`. Durations, costs, burden, pulse reductions, recovery gains, and anti-rat results are kept in the same constants file. A state action uses the selected state's three active population bands (`minimum`, `large`, and `metropolitan`) to scale support equipment, motorized equipment, and fuel. The country-level knowledge programmes use the country cost band and commit `country_program` response burden while active.

The selected-state material check accepts the exact displayed band payment. The minimum band's calculated 22.5 trucks round upward to a whole 23 before payment; its display and inclusive check use the same 23-truck requirement. Ordinary selected-state actions do not impose an additional unshown standard or country material floor. Train, Command Power, and route requirements remain on the individual actions. National knowledge actions and Royal Node, Crown Strike, and Royal Burrow operations retain their separate fixed payments and inclusive gates. Both shared and dedicated payments debit real motorized models through the existing model-aware helper, taking model 0 before model 1; dedicated payment history records actual completion. The shared English cost text quotes the Black Friday price table entries for these constants through supported scripted-localisation getters, so the shown price follows a Black Friday sale; the selected-state material quote follows the same population bands as payment, and each band pays its registered table price (`global.black_friday_price_black_plague_shared_cost_scaled_<band>_<resource>`). Response Capacity uses its registered texticon in shared custom cost rows. Native ordinary decision-list fit, race-safe transaction outcomes, and full four-type cost-budget alignment remain unverified.

State pulse flags are cleared when the state becomes Cured or when the disease episode's terminal cleanup runs. A cancelled action pays no second outcome and releases the action burden. The terminal cleanup also clears the shared country flags and re-evaluates the shared crisis board.

## Country knowledge actions

The dedicated category includes Publish Findings, Restricted Alliance Exchange, Hoard Protocol, Steal Foreign Progress, International Medical Mission, Emergency Countermeasure Drive, medical-reserve production, and the countermeasure programme. They require the countermeasure programme or recorded findings where appropriate, use equipment and fuel rather than political power, and feed the existing 0–100 countermeasure progress producer. Preserving the Royal Basin archives in the defeat report registers the responder and exposes Publish Findings immediately; its recovered evidence remains latent until the normal countermeasure setup transfers it, so the archive cannot cure a state or skip the 0–100 progression. Intelligence theft requires a real intelligence agency and operative; it does not use a synthetic `operative_recruited` flag. Route-crisis responses, Royal Node strikes, Crown Strike, and Seal Royal Burrows remain in the shared state-containment category because they depend on a selected state or active territorial emergency.

Royal Node AI willingness is urgency-aware rather than a flat emergency score. It rises when terminal preparation or RTX Dominion is high, when the country has an active Severe Crisis state, and while at war; the thresholds and factors live in `black_plague_response_ai` so balance changes do not scatter magic numbers through the decision file.

After Evolution V opens its earned route, a human country that still holds established Black Plague ground can start either native mission in the shared containment category, and may run both concurrently when it meets both gates. Hold the Line pays support, motorized, infantry, train, fuel, manpower, command-power, factory, stability, and war-support costs and gains weekly progress from war, countermeasure readiness, and held states. Secure the Refuge uses the same payment surface at a higher cost, requires a held terminal capital, refuge node, or city, and gains an additional node bonus. Success lowers global Rat King terminal preparation, raises countermeasure progress, and improves containment without curing a state. Timeout raises terminal preparation and Rat King hunger and adds incoming exposure to the remaining human-established states. Both missions are removed by the event-owned runtime when the last eligible ground is lost or when the terminal takeover begins. Crown Strike and Seal Royal Burrows use the same native mission surface: a state-selected zero-day launcher stores the target marker, and the country mission owns the 180-day timer, cancellation, factory reservation, and exactly-once shared-action resolution.
After a Rat defeat or full eradication, the dedicated category exposes three optional country projects. Rebuild and Keep Vigilance runs for 210 days, advances countermeasure findings, improves containment and treatment in controlled recovering or cured states, and lowers relapse risk. The International Inspection Compact runs for 360 days with a faction partner and a controlled coastal hub; its timed country flag reduces internal transport, troop, refugee, and port exposure on both ends of those routes. Condemn Future Weaponization runs for 60 days, records the verified ban, improves stability and war support, advances the countermeasure programme, and blocks the existing Black Plague weaponization project. Each action pays the country material band, reserves civilian factories, registers Response Capacity, and resolves through a logged event without instant cure or state deletion.
The dedicated category also exposes a 420-day Population Recovery Programme and a 120-day Memorial and Biosecurity Charter. Population Recovery applies a timed state stewardship modifier to controlled recovering or cured states with devastation, lowers that devastation, improves treatment, and lowers relapse risk. The Memorial Charter is permanent for the country, adds stability and war support, and gives recovered states a durable stewardship modifier while preserving the countermeasure record. Neither project changes a phase without the ordinary state machine.

## Integration points

`black_plague_process_current_state_persistent_response` calls `black_plague_apply_shared_action_pulse` after Black Plague-specific response deltas and before the final state delta application. National capacity recomputation counts an active shared state action and an active country programme. The response registry retains shared-action states and owners so a live project cannot disappear from burden accounting.

## Future depth

Future response work can add state-specific scripted tooltips for each population band and faction-level findings diplomacy without changing the two-category ownership boundary or action API. Any new action must reserve a new constant id, add a phase-gated trigger, define a real cost and duration, add a player-facing name/description/cost tooltip, and extend terminal cleanup. Native missions that need a state target must follow the Crown/Seal pattern: a zero-day state launcher, an explicit state marker and owner, a country mission with `days_mission_timeout`, and a resolver that clears both marker and mission during timeout, cancellation, defeat, and world-end cleanup.
