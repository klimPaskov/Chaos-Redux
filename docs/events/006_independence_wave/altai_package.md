# IW-053 Altai Package

IW-053 is a package-local Event 006 tranche for the vanilla `ALT` carrier, state `654` as its anchor, optional state `40`, and reservation group `RG-654-40`.

The package remains fail-closed and is not admitted to the central adapter, attestation, preflight, SCN-008, deterministic Join, dispatcher, or Event 005 paths by this tranche.

## Compact and founding crisis

The package defines Council Cohesion (`independence_wave_altai_council_cohesion`) and Mountain Guard Readiness (`independence_wave_altai_mountain_guard_readiness`) ledgers.

Both ledgers clamp from 0 to 100, begin at package-local starting values, and must reach the stable threshold before the founding mission can resolve successfully.

The founding mission requires the ALT package gate, setup completion, a selected route government, stable ledgers, and continued ownership and control of state 654.

Capital loss, anchor loss, package failure, or a force-contract mismatch keeps the package incomplete and applies the package failure effect where the project path has already begun.

## Projects and governments

The Altai category contains ten serialized projects for Oyrot depots, mountain guards, Altai communities, former-host ledgers, constitutional autonomy, the traditional land compact, socialist councils, emergency command, durable sovereignty, and the Altai frontier network.

Only one project may run at a time, and each project uses the shared Event 006 material-cost helpers plus the package-local readiness gate.

The four route installers cover constitutional, popular-council, traditional, and emergency mountain governments.

## Shared focus and force contract

ALT uses the shared Independence Wave focus tree with five guarded callbacks for the mountain council, Oyrot communities, mountain guards, former-host ledgers, and the Altai frontier network.

The accepted package binding is state `654` with optional state `40`, capital state `654`, and `RG-654-40`.

The accepted force mapping is the `mounted_mobile` profile with five paths: integrate militias, regional guards, secure depots, terrain units, and league cadres.

The package accepts military tradition `61` from the package-local contract.

The shared force table currently records `p61 = 57`, so the setup gate records the mismatch and fails closed rather than silently tuning or substituting the value.

Navy and air inheritance are disabled, and no map, state, province, port, railway, supply, resource, or building data is written by this package.

No new leader, advisor, portrait, flag, cosmetic tag, or asset runtime reference is introduced here.
