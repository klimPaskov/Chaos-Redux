## Ledger, lifecycle, and timing

`common/script_constants/006_independence_wave_constants_registry.txt` defines the shared package pressure values `minor_gain = 6`, `standard_gain = 12`, `minor_loss = -6`, and `stable = 65`. `common/scripted_triggers/006_independence_wave_karelia_crimea_package_triggers.txt` defines `can_use_independence_wave_kar_reg04_focus_group` and `can_use_independence_wave_cri_reg04_focus_group`. `common/scripted_effects/006_independence_wave_karelia_crimea_package_effects.txt` supplies `independence_wave_kc_reset_reg04_focus_deltas`, `independence_wave_kc_capture_focus_ledgers_before_reward`, `independence_wave_kc_apply_reg04_focus_deltas`, `independence_wave_kc_report_new_stability_compact`, `independence_wave_kar_award_language_appeals_companion`, `independence_wave_kar_award_ski_guard_companion`, `independence_wave_cri_award_land_hearings_companion`, and `independence_wave_cri_award_service_rolls_companion`. The pre-reward capture variables are `independence_wave_kc_kar_forest_before_reward`, `independence_wave_kc_kar_mandate_before_reward`, `independence_wave_kc_cri_return_before_reward`, and `independence_wave_kc_cri_settlement_before_reward`; existing `independence_wave_kc_{forest,mandate,return,settlement}_delta` inputs are zero-initialized for each focus reward. Each reward records before-ledger values, applies the existing clamped ledger change, and reports a contested-to-compact transition only if that reward crosses the stable threshold. The four matching paid success callbacks in `common/decisions/006_independence_wave_karelia_crimea_decisions.txt` call companion helpers after the existing base reward when focus history already matches; branch completion calls the helper if payment came first. The four durable markers clear in `common/scripted_effects/006_independence_wave_focus_effects.txt` only when `independence_wave_assign_focus_framework` reloads the full tree and resets completed focuses with `keep_completed = no`.

One chosen group route costs `5 + 5 + 7 + 7 = 24` focus units, or 168 nominal days at seven days per unit at standard speed. The existing capital-administration prerequisite costs five units/35 nominal days, so a continuous sequence from that prerequisite through the docket costs 29 units/203 nominal days. The optional inventory focus adds five units/35 nominal days; doing both sequentially costs 34 units/238 nominal days. These are source-derived nominal timings, not engine or live-game measurements. The founding mission remains 210 days, paid projects retain their durations and one-active-project lock, and route government plus other mission receipts still apply. A focus route does not by itself bring both ledgers to 65, and whole-package deadline feasibility has not been established by this tranche. Inventory callbacks and all existing paid costs, cancellation/failure behavior, and base decision rewards are preserved.
