# IW-044 Tatarstan Package

## What the package is

IW-044 releases the dormant vanilla TAT carrier around state 249 Kazan when the Independence Wave planner has a valid Volga reservation and the living former host can be preserved.

Tatarstan keeps its vanilla country identity, history, state ownership rules, Alemasov character, party names, and installed base flags outside an Event 006 origin.

## Runtime flow

The region-05 planner loads package `iw_044`, reserves state 249 in `RG-MIDDLE-VOLGA-KAZAN`, captures the actual former host, and refuses a living carrier or a conflicting Event 005 origin.

The package setup initializes the shared Event 006 framework, starts the hidden founding mission, records Civic Concord and River Security, checkpoints the vanilla Alemasov command roster, assigns the shared focus framework, installs the p44 regular-defector force contract, and opens the four package route lanes.

The founding mission resolves when state 249 and the capital remain secure, both visible ledgers reach the stable threshold, and one route government is installed before the founding deadline.

The package cleanup removes its mission, decisions, ideas, route flags, ledger variables, network receipts, and generation flags, then restores TAT's vanilla democratic political baseline and party names.

## Visible package ledgers

**Civic Concord** uses the internal variable `independence_wave_tat_rada_cohesion` and represents agreement among municipal, village, railway, and religious communities.

**River Security** uses the internal variable `independence_wave_tat_river_readiness` and represents control of the Volga crossings, depots, rail approaches, and regional guard chain.

Both ledgers are clamped from 0 to 100, begin below the stable threshold, change through focuses, projects, route installation, former-host settlement, network work, and failure, and are shown in the ordinary package decision category.

## Routes and decisions

The package exposes constitutional civic government, agrarian community government, socialist council government, and river emergency command.

The founding mission and ten paid projects cover river depots, border guards, community compacts, former-host ledgers, constitutional autonomy, the agrarian compact, socialist councils, emergency command, durable sovereignty, and the Volga River network corridor.

The network corridor is locked until the founding settlement is resolved, the network and league routes are available, the capital is controlled, and both ledgers are stable.

## Force and AI contract

The p44 profile uses regular defectors with regional river guards, secure depots, professional officers, and capital-border defence as the reinforcement pathway.

The package does not inherit navy or air forces from the former host.

Tatarstan AI layers prioritize river defence, infrastructure, equipment production, former-host restraint, emergency security, and post-settlement army growth while the shared focus AI chooses the route.

## Focus and assets

Tatarstan uses the shared full Event 006 focus framework and owns five guarded package hooks for provisional assembly, river communities, border guards, former-host settlement, and the Volga River corridor.

No bespoke focus tree, scripted GUI, portrait, flag, or route cosmetic asset is required for this vanilla carrier package.

The vanilla Alemasov leader and installed TAT flag ladder remain untouched by package setup and cleanup.

## Connections and limitations

Event 005 owns the Idel-Ural and TAT origin surfaces, so the package remains guarded against an Event 005 origin and against a live shared reservation collision with IW-043.

The package is admitted through the central adapter, content-attestation, normal preflight, scenario preflight, and deterministic Join order only after its source contracts pass together.

Map-wide MCP diagnostics and typed probability fixtures remain external validation limits, so no live save, AI balance, or save-load claim is made here.
