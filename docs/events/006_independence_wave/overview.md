## Release transaction

The shared Liberations coordinator owns the transaction lifecycle:

1. Begin an Event 005, Event 006, or joint plan.
2. Reserve every selected country tag, reservation group, unique anchor, host, and one protected state per host; during a joint incident Event 005 anchors are frozen first and Event 006 rerolls against them.
3. Reject living tags, active origins, duplicate anchors, occupied reservation groups, and state collisions.
4. After all anchors are frozen, run compact territory for every selected package before running extended territory for any package. Trim optional collisions and host-survival failures without dropping the anchored country.
5. Revalidate aligned rows, ownership, host survival, exact counts, and the complete owner/controller/core/capital recovery ledger at lock.
6. If a host capital is a frozen release row, move it to that host's protected state before ownership changes.
7. Prove that every selected dormant tag has an exact runtime adapter, audited history laws and command roster, and the content-ready flag before ownership changes.
8. Release and transfer all accepted rows in one effect chain, counting a state only after both its owner and controller match the frozen target. Any failed transfer blocks package initialization and incident commit.
9. Verify the complete frozen ownership footprint, then cross the explicit finalization barrier before any country package, force, technology, politics, host-asset transfer, or active registry is applied.
10. Count every Event 005 and Event 006 terminal package proof, append Event 006 durable origin history only after all package proofs pass, commit the shared plan, and queue presentation only after that commit succeeds.

## Patron, network, and league state

Patron rows store the patron country, owner generation, total influence, aid value, and nine channel values. Dead, stale, and empty rows are reverse-pruned before strongest-patron and dependency checks.

The informal network and league registries use country plus generation as their authoritative key. League transitions have exact source phases, idempotent dates, and mutually exclusive phase flags. Network exit cascades founder and member removal; league exit preserves the informal network and active origin. The enforcement ledger records seven factual grounds: patron-client capture, annexation of a member, refusal of binding arbitration, abandonment of a promised rescue, repeated charter breach, sponsorship of a member coup, and an unauthorized offensive war under the defensive charter. The current leader may run one 120-day expulsion vote against a member with a live ground when at least four members remain. Timed recognition, arbitration, rescue, expulsion, and war-mandate actions freeze and revalidate the originally selected country instead of following later state ownership. Rescue arms are reserved at commitment, delivered only on success, refunded after peace or ordinary cancellation, and forfeited when client capture abandons a member still at war. A Defensive Congress member may spend diplomatic capacity and a civilian factory for a 45-day mandate granting one target-specific 365-day war authorization; the first matching declaration consumes it, while any other offensive declaration supplies the unauthorized-war ground. Successful expulsion removes the member through the aligned membership helper, retains its active origin and informal-network relationship, marks it discredited, reduces the five league values, and may enter league crisis. The expelled country opens a separate generation-safe rival compact with its own leader, aligned member rows, route, cohesion, common cause, patron capture, shared reserve, confidence, host pressure, and paid actions. Invitations have separate delivery, recipient-response, and ratification stages; expiry uses the same decline and cleanup transaction as an explicit refusal. Event Details exposes every aggregate and lets the player cycle through each surviving rival member's contribution and confidence. A war between two live league members, started through the Event 006 war-relation hook, latches the member-war failure state that the league-crisis entry reads alongside failed rescue; both latches are cleared when the league is reformed, dissolved, or restarted from the informal network.
A third latch records patron capture when the league's patron capture value first reaches 60 in a formal, durable, or reformed league.
