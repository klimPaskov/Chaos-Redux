# Event 006 Montenegro package

IW-030 uses the registered vanilla `MNT` carrier and the reserved Montenegro anchor at state 105. The package belongs to the Balkans and Danube region, uses the `mountain_or_frontier` archetype, and follows force mapping profile `mountain_frontier` with military tradition `p30`.

The runtime adapter keeps the vanilla MNT history and flag identity intact. The setup effect installs the shared Event 006 focus framework, baseline civilian economy, export focus, and volunteer-only laws, then records mountain cohesion, crown legitimacy, host routes, the traditional-authority versus assembly power struggle, the Danubian ambition family, the league route, and the dynamic starting force contract. No Event 006 advisor icon is created.

The country-owned decisions cover the timed founding crisis, mountain depots, regional guards, the Cetinje-Podgorica administrative register, former-host ledgers, four government routes, durable sovereignty, and the Balkan network corridor. Every project consumes the shared command, manpower, equipment, train or convoy, stability, war-support, or time cost palette and changes both public Event 006 ledgers and the Montenegro-specific values. The founding crisis lasts 540 days, giving the serialized 495-day project path a bounded reaction margin. Because state 105 opens with one civilian factory, MNT administrative and sovereignty projects commit that factory directly rather than requiring an unavailable second reserve. If the former host is absent or at war, the host-ledger project closes through a non-bilateral fallback that grants decisive crown legitimacy while preserving the local compact. Reopening the mountain depots supplies the same stronger crown-legitimacy settlement for a voluntary route.

Every paid project clears the failure latch when it begins, so each distinct cancelled or timed-out project applies its own penalty while duplicate failure callbacks from the same incident remain suppressed. The five package milestones shared by decisions and the generic focus tree are idempotent. Completing a depot, guard, office, former-host, or Balkan-corridor milestone through one surface prevents its reward from being applied again through the other.

Montenegro keeps the vanilla MNT country history and does not copy an OOB or history file. Event 006 installs dedicated sourced male portrait placeholders for Krsto Popović and Blažo Jovanović through character-scoped `set_portraits`, so their shared vanilla portrait definitions remain unchanged. The emergency route uses the separately defined Mitar Martinović as a country leader and corps commander. Vanilla Blažo Đukanović remains untouched and is not an Event 006 portrait or route consumer.

The admitted portrait package is archived under `docs/assets/006_independence_wave/iw030_mnt_portrait_source_placeholder_2026_08_09/` with source files, exact crop metadata, 156x210 candidates, review sheets, checksums, provenance, and wiring notes. A flat durable source archive also lives under `docs/assets/portraits/006_independence_wave/iw030_montenegro_source_placeholders_2026_08_09/`. Popović uses a Wikimedia Commons CC BY-SA 3.0 source with VRTS permission, while Jovanović and Martinović use public-domain archival sources. These are unchanged-source placeholders: each source is explicitly cropped to a readable head-and-shoulders composition, resized to 156x210, converted to DDS, and wired without an ImageGen or RunPod repaint.

The Event 006 roster checkpoint `chaosx.nr6.350` attaches `MNT_independence_wave_mitar_martinovic` once when IW-030 is selected, then publishes `independence_wave_mnt_roster_checkpoint`. The package roster and emergency government route use this distinct role-correct identity. Vanilla `MNT_blazo_dukanovic` remains untouched and is not an Event 006 consumer. The checkpoint guard makes setup retries idempotent and does not copy or mutate vanilla MNT history.
