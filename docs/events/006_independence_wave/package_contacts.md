# Event 006 package contacts

Every admitted Event 006 package registers these foreign contacts when its origin commits (`independence_wave_register_package_contacts` in `common/scripted_effects/006_independence_wave_package_contact_effects.txt`).
A contact is an actor source for the foreign reaction queue and counts as the recorded-relationship family (three points) of the foreign score. It adds nothing beyond that family, and a contact that is the country's own former host, a subject, or a country that no longer exists is skipped.
