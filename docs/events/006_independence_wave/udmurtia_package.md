# IW-048 Udmurtia package

IW-048 is a package-local Event 006 implementation for vanilla UDM at Izhevsk, state 399. The package models an industrial-forest republic whose workshop administrations, rail communities, and local councils must stabilize a compact before a route government can carry it.

## Source and identity

The carrier remains the vanilla `UDM` tag, vanilla history, vanilla capital 399, vanilla Boris Berman character `UDM_boris`, vanilla leader portrait token, and vanilla normal, medium, and small ideology flag ladder. No portrait, flag, country-history, character, or `.gfx` asset was created or replaced by this tranche.

The package uses the registry's `industrial_security` force profile and the existing shared `industrial_breakaway` package-archetype constant because the shared archetype table has no separate `industrial_security` archetype token. This mapping is documented for later admission review and does not alter the central registry.

## Package mechanics

The package-local constants define workshop control, forest-rail readiness, founding and project durations, civilian-factory floor, and four route political distributions. The package trigger file gates the UDM original tag, Event 006 liberation origin, state 399 capital ownership, former-host relationship, package depth, Volga–Urals region, force profile p48, and generation-safe force readiness. Its prepared-package predicate matches the accepted factory/rail reinforcement pathway rather than substituting terrain units.

The package provides a 420-day workshop congress mission and ten timed projects. The project families cover workshop depots, industrial guards, Udmurt community registration, former-host ledgers, constitutional autonomy, forest-land administration, worker councils, industrial emergency command, durable sovereignty, and the Volga–Ural corridor. Project failure applies bounded legitimacy, recognition, capacity, security, instability, and ledger losses through reusable Event 006 effects.

Factory-bearing administration and strategic projects use UDM-specific cost text triplets so the visible commitment matches their one-civilian-factory modifier.

Five shared focus anchors call UDM-only helpers for the workshop council, rail communities, industrial guards, former-host ledgers, and Volga–Ural corridor. These hooks add no focus nodes and do not change the shared tree layout.

The package-local AI file supplies strategy factors for industrial survival, host restraint, settled compact, and emergency guard behavior. The current probability adapter reports no weighted strategy surface, so no quantitative balance claim is made.
