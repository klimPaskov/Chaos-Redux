# IW-040 Kuban Package

IW-040 is an admitted Event 006 package for vanilla KUB and state 234. It preserves the ordinary Kuban history, vanilla Ivanis Nikolaevich roster, vanilla portrait, and actual former-host target captured by the release planner. Its four route-specific cosmetic flag ladders are generated alternate-history syntheses and leave the vanilla KUB base flag untouched.

## Compact and founding crisis

The package defines two visible country-scoped ledgers, Civic Concord (`independence_wave_kub_rada_cohesion`) and Mounted Readiness (`independence_wave_kub_mounted_readiness`), clamped from 0 to 100. Both must reach the stable threshold before the 600-day founding mission can resolve successfully.

Within the 600-day mission window, success requires a selected government, stable ledgers, and ownership and control of state 234. Loss of state 234, loss of the current capital control, or loss of the generation setup receipt cancels the mission immediately; failure applies the package failure deltas and cancels active projects through their ordinary cancellation effects.

The four government-choice projects are the only decisions allowed to start while this founding mission is active. They serialize against each other, preserve their existing costs, durations, cancellation rules, and route outcomes, and can satisfy the mission's government requirement. Every other package project remains locked until the founding mission resolves successfully.

## Projects and governments

The Kuban category contains ten paid projects covering depots, border guards, community guarantees, former-host ledgers, four government settlements, durable sovereignty, and the Black Sea steppe network corridor.

Only one project may run at a time. Every project requires capital control and uses the shared Event 006 material cost helpers. Durable sovereignty and the network corridor additionally require founding settlement resolution; the corridor also requires network membership, an available league route, and stable ledgers.

The four government projects install constitutional, agrarian, socialist, or emergency route state and reuse the vanilla Kuban leader rather than inventing an unreviewed character.

## Shared focus and forces

Kuban uses the shared full Independence Wave focus tree and has five guarded hooks for administration, community settlement, border guards, former-host ledgers, and the network corridor. Its five-node land and mounted-service group records petitions, reconciles grain and rail registers, chooses between non-host hearings and a mounted service-roll audit, and publishes a final docket. Focus rewards change Civic Concord and Mounted Readiness through the existing clamped ledger helper.

The group reuses five focus icons already registered in `interface/006_independence_wave.gfx`: `GFX_goal_independence_wave_founding_administration` uses `gfx/interface/goals/006_independence_wave/goal_independence_wave_founding_administration.dds`; `GFX_goal_independence_wave_infrastructure_authority` uses `gfx/interface/goals/006_independence_wave/goal_independence_wave_infrastructure_authority.dds`; `GFX_goal_independence_wave_popular_councils` uses `gfx/interface/goals/006_independence_wave/goal_independence_wave_popular_councils.dds`; `GFX_goal_independence_wave_army_integration` uses `gfx/interface/goals/006_independence_wave/goal_independence_wave_army_integration.dds`; and `GFX_goal_independence_wave_former_host_settlement` uses `gfx/interface/goals/006_independence_wave/goal_independence_wave_former_host_settlement.dds`.

The docket requires the matching branch and a completed, paid Register the Community Compacts or Integrate the Border Guards project. Separate package flags publish those receipts only on successful project expiry; the generic focus callback flags do not stand in for payment. Completing the focus and paid project in either order grants one matching ledger companion. All five nodes require active Event 006 origin, complete IW-040 setup, the full-tree contract, and owned, controlled, capital state 234.

The IW-040 force contract is mounted-mobile with no navy or air inheritance, using the p40 pathway and the military-tradition value 80 recorded in the force mapping. The central runtime adapter, normal and scenario preflight, content-attestation entry, and Join priority are wired to the exact dormant KUB/state-234 contract.
