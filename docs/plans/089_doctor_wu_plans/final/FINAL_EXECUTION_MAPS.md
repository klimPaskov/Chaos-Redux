# Doctor Wu final MCP and subagent execution maps

These are future execution assignments. No named specialist or HOI4 MCP operation ran in this planning pass. Every child receives a fully self-contained brief and no inherited parent thread. In Codex use `fork_turns="none"` where the actual spawn schema supports that contract. Use canonical roles or their generated runtime equivalents, never a generic substitute presented as a named specialist.

## Common child input packet

Pass the exact source files, current user corrections, acceptance state, owner interfaces, prior handoff, allowed files, output path, named scenarios, and forbidden changes. The coding parent remains responsible for integration and final acceptance. A failed tool route is recorded without fabricated output. Actual schemas must be discovered in the execution environment.

## Dependency order

Resolve owner acceptance and read current contracts first. Implement neutral accounting and typed transactions before clinical service. Add the baseline research portfolio before evolved behavior, then foreign/domestic contest, political settlement, country routes, and final presentation. Asset work may run in parallel only after its actual consumer and acceptance basis are stable. Probability baseline work precedes every weight patch. Documentation and catalogue closure follows implementation evidence.

## Scenario and evidence handling

The machine-readable [scenario inventory](scenario_inventory.json) indexes the 190 named review cases in Parts 10–17 with their owning part. All are marked not run. It is a discovery index, not a completed probability pool. The auditor must expand each into explicit input state and expected ordering using the source design. Additional earlier case sets remain in Parts 5–9 and must also be expanded. Part 20 supplies the required end-to-end clinical, accounting, evolution, diplomacy, country, visual, and multiplayer tests.

Before/after comparisons use matching source dependencies, scenario values, seeds, language, resolution, and UI scale. Exact engine syntax and native timing use current installed documentation. Missing schemas, artifacts, vanilla files, viewers or tools remain named evidence gaps. No local symbolic test below is a replacement for any MCP family.

## Parent release gate

The parent reviews all child output, the final coverage matrix, unresolved gates, asset source/rights records, actual runtime references and meaningful user live-game evidence. The autonomous debug-playtest skill is not invoked by this map and requires its own explicit authorization. Do not control the desktop or launch a game merely because the package includes validation scenarios.
