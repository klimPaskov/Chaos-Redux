## Scope and references

The package covers all 13 020_black_plague achievements, all three 027_doctrine_research achievements, and all five asteroid_incoming achievements. The existing sprite names and runtime texture paths are preserved in interface/chaosx_achievements.gfx.

The canonical achievement contact sheet and individual vanilla examples 30_minutes_of_hel, crusader_kings_2, assuming_direct_control, and britzkrieg were inspected before generation. Their installed vanilla DDS files decode to 64x64 RGBA and match the canonical PNG references pixel-for-pixel. The parent-approved 031_generated_batch_native.png contact sheet was inspected for Chaos Redux laurel-medallion style. No catalog component was layered into the achievement artwork.

The exact supplied backgrounds and red X overlay were used unchanged. Their SHA-256 values are recorded in asset_manifest.json and match the event-assets skill hashes.

## Art and processing

Each selected subject was generated with the built-in ImageGen tool using transparent_background: true and a text-only prompt, then retained as a native RGBA master with its exact request, input lineage, output path, and hashes in evidence/generation_receipts_manifest.json. The first cordon attempt and its targeted edit were rejected because their outer red fringe remained; both source masters are preserved, and candidate 02 is the selected cordon master.

All selected masters have genuine alpha with range 0-255. Premultiplied-alpha Lanczos processing placed each complete source on a centered 64x64 transparent canvas; visible bounds retain 2?7 pixels of margin. 020_black_plague_burn_warrens uses a 60x60 centered art scale to keep the flame clear of the edge. The deterministic grey sources preserve the color source alpha and placement, and each not-eligible source composites the unchanged overlay over that grey source.

All 21 source triplets were passed through process_achievement_icons.py; a separate --audit pass verified every staged DDS as a strict one-level 64x64 BGRA triplet with exact source-layer/background compositing equality. The staged DDS alpha matches the supplied template backgrounds.

Completed-to-grey mean absolute RGB difference is 5.442 at the minimum and 8.761 at the median; the generated subject-only color-to-grey minimum is 7.564. Every achievement clears the 3.8 review minimum, with color accents in the subject art. The red X changes 935-939 pixels against each grey state.

Immediately before promotion, a read-only guard checked all 63 assigned runtime DDS files against the frozen baseline with zero mismatches. The promotion manifest records each prior and promoted hash, and the post-promotion audit passed all 21 runtime triplets.
