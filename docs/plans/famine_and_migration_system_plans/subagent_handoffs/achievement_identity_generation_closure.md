# Famine and migration achievement identity-generation closure

> **Superseded historical identifier banner (2026-08-25):** Any `fm_*` or `famine_migration_*` identifier quoted in this historical handoff is source-snapshot terminology only and is superseded; current authorities use separate `famine_*`, `migration_*`, or narrow neutral `civilian_transfer_*`/`humanitarian_*` names; see [source_of_truth_map.md](../source_of_truth_map.md).

Scope: bounded achievement evidence repair for `No One Left at the Gate`, `Break the Blockade`, `Roads Home`, `A Place at the Table`, `The Grain Stayed Home`, and `The Country Did Not Empty`. The patch keeps the existing eight achievement IDs and assets, does not add an event, GUI, mapmode, recurring world scan, AI factor, population creation, or mortality endpoint. Its one-time startup baseline pass follows the existing bounded country setup pattern.

Prompt traceability: `Break the Blockade` is covered by prompt lines 21-25; `No One Left at the Gate` by lines 53-60; `Roads Home` by lines 88-92; `A Place at the Table` by lines 179-185; `The Grain Stayed Home` by lines 210-220; and `The Country Did Not Empty` by lines 237-248, including the threatened-displacement and simultaneous war/famine closure requirements.

## Trigger syntax repair

Vanilla `documentation/triggers_documentation.md` lines 2118-2132 require the explicit form `check_variable = { var = varname value = value compare = operator }`; the shorthand form is `check_variable = { varname > value }`. The achievement effect file contained 33 malformed hybrids of those forms and the achievement trigger file contained 15. All 48 are now explicit, preserving `greater_than` semantics for the `>` cases and `less_than` for the single `<` case. A post-edit census reports zero `check_variable = { var = ... > ... }` or `<` hybrids in both owned files.

## Identity contracts

The initial-core baseline is seeded by `famine_migration_achievement_seed_initial_core_baseline` from the existing one-time `on_startup` country setup pass, before the first daily food evaluation can apply famine mortality. It sums the starting `state_population_k` of the exact country's core states, derives the integration and threatened-share targets once, and sets `famine_migration_achievement_tracking_initialized` as the write-once guard. The normal achievement initializer no longer seeds this value on a later interaction, so deaths, movement, or a changed core map cannot rewrite the baseline. Because `on_startup` does not run on save load, the existing tag-scoped `on_daily_CXT` repair path repeats the helper only for an unseeded CXT save. An unseeded non-CXT legacy country fails the natural-campaign predicate rather than snapshotting a post-mutation population.

`No One Left at the Gate` is keyed by receiving country, one prepared corridor generation, origin state ID, front state ID, counterpart country ID, offered cohort ID, and the explicit qualifying cohort ID/amount arrays. At acceptance the helper reads the authoritative global cohort ID, host, status, amount, and source arrays. A row qualifies only when it is live in the exact origin, has a positive amount, and has an approved camp/genocide/exterminatory source (`camp_repression`, `gulag_repression`, `forced_labor`, or `deportation`) or the exact corridor origin has active displacement/trapped evidence plus catastrophic famine. The offered cohort must be present in that explicit set. Aggregate trapped population is never used as the cohort identity.

Protection accepts only an exact transfer result with positive debit and survivor credit, zero route deaths, debit equal to the ledger amount for the exact cohort, origin and destination event targets matching the persisted origin/front, the corridor generation matching the origin state, and destination ownership matching the receiving country. Each cohort is appended once to the protected array. Terminal cleanup copies aligned qualifying/protected/resolved IDs and amounts, evaluates durable outcome after terminal flags are set, and clears active arrays/counters. Completion requires completed terminal status, exact equal protected/resolved cohort counts, equal protected and qualifying ledger totals, receiving-state safety, and no pushback, forced return, internment, or forced-labor disqualification. The helper can reuse the exact corridor origin target as the transfer-origin target, but never falls back to an aggregate or unrelated cohort result.

`Break the Blockade` stores one exact blockade state ID and generation at catastrophic start. Relief requires a proven donor-backed state delivery in the same state, sea or air route mode, positive credit, and the same generation. Recovery and survival use that same state/generation. The trigger rejects a country-wide relief flag combined with a different blockade state or crisis.

`Roads Home` selects one unique live cohort row whose amount reaches the major-cohort threshold. Maturity starts only for that row and receives a new generation when the row changes. Voluntary return records the same cohort ID and generation and requires a valid survivor transfer and majority debit. A different mature or returning cohort cannot combine with the ledger.

`A Place at the Table` binds each actual local-integration destination state to its integration cohort and a state generation. Food safety is refreshed only for a bound state whose persistent generation matches the country array; acute, famine, or catastrophic stages remove that state from the safe set, while later stable recovery can re-add it. Completion requires the exact bound-state count and safe count to align, at least one integrated state/cohort pair, the existing three-origin and integrated-population thresholds, and stability. Medical observation is not required and unrelated owned states are never snapshotted.

`The Grain Stayed Home` starts a new extraction generation only when `fm_maintain_extraction` activates extraction. `fm_release_reserves` is eligible for the achievement ledger only after an acute/famine state has an active extraction flag, positive extraction and production/transport evidence, a recorded shock, and a non-catastrophic stage. The transaction sets `famine_migration_extraction_suspended`, clears the active flag, and zeros the current extraction input/component before recording suspension. A same-state new generation clears the prior suspension, alternative-logistics, and recovery flags before recording its own shock; same-generation rerecording remains idempotent. Alternative logistics must be proven on the same state and generation, and stable recovery must occur before completion. The existing decision cost, timer, normal density, and AI weights are unchanged.

`The Country Did Not Empty` records a severe-core state only when the state is a core of the country, the owner is at war, displacement is active, and the exact trapped/flight threatened amount is positive. The country ledger sums threatened displacement amounts rather than resident population. A generation is reset when the war window closes or a new severe state follows an all-recovered window; a recovered state clears only its terminal severe marker after the floor check so a later same-state famine can bind a fresh generation. New severe cores clear the all-recovered flag, and a later live major cohort clears the all-resolved flag. Completion requires aligned severe/recovered arrays, equal current counts, simultaneous war/displacement proof, the threatened-share threshold, all exact famine recovery, an exact major-cohort resolution transaction, independence, and no floor/annex/tag/debug disqualification.

## Before/after exploit pairs

- Gate: an unrelated later arrival, wrong origin, wrong front, wrong cohort, aggregate-only amount, partial debit, or route death no longer increments protected people. A later crisis starts with cleared active arrays and a new generation, so stale IDs cannot suppress or satisfy it.
- Blockade: relief to state B cannot combine with famine, recovery, or survival from blockade state A. Stable terminal recovery clears the state-bound tracker, so a later catastrophic episode on that state receives a new generation and clears prior outcome flags.
- Roads: cohort A maturing and cohort B returning no longer satisfies the majority return predicate. Re-recording cohort A in the same generation is idempotent.
- Place: an ordinary open reception followed by local integration can now bind a destination state without a medical mission. If that bound state later reaches famine, its safe ID is removed and the predicate fails until the same bound state recovers.
- Grain: releasing reserves while extraction remains active no longer records suspension. No active extraction, no acute floor, no crop/transport shock, a wrong state, a wrong generation, or reserve release alone cannot qualify.
- Country Empty: peacetime serial famines cannot create severe-core entries because the current state must prove war plus active displacement. Whole resident population is not counted as threatened displacement, a recovered state can enter a later exact generation, and a newly recorded severe core invalidates a previously closed all-recovered flag.

## Reset, cleanup, idempotence, and saves

Identity arrays and numeric counters are cleared at gate start; terminal gate arrays retain the terminal evidence needed by the achievement and are replaced at the next gate start. Corridor cleanup snapshots terminal identity before route IDs are cleared and is safe to repeat. Blockade, extraction, receiving-state, threat, and major-cohort flags are cleared when their exact state/cohort/generation changes or when their terminal window is invalidated. Re-recording the same cohort, state, or transaction does not append a duplicate or advance its generation. All evidence is ordinary country/state variables and aligned arrays, so it persists through save/reload; live engine save/reload validation remains parent-owned.

The initial-core baseline is likewise ordinary country state and is never cleared or recomputed by the achievement interaction helpers. New games receive it in the bounded startup pass; an unseeded ordinary legacy save remains fail-closed instead of acquiring a late baseline. The CXT daily registration path is the only existing-save repair call because it is already the package's tag-scoped setup contract.

None of these helpers mutates state population, recruitable manpower, or the deaths ledger. The existing exact transfer endpoint remains the only movement/death owner; the achievement code reads its measured debit, survivor credit, and route-death result.
