## Existing patterns

### Shared adapter input contract

`famine_migration_apply_pressure_request` at `common/scripted_effects/chaosx_famine_migration_effects.txt:1077-1128` defaults food-only application and then clears every one-shot request field. Its valid trigger at `common/scripted_triggers/chaosx_famine_migration_triggers.txt:75-83` requires a valid human-compatible state, positive `famine_migration_pressure_request_amount`, non-unknown `famine_migration_pressure_request_source`, and positive `famine_migration_pressure_request_actor_proven`.

The public wrappers at `chaosx_famine_migration_effects.txt:1157-1284` expose famine, flight, occupation, camp, gulag, forced labor, deportation, bombing, nuclear, Fallout, outbreak, disaster, war, peace, event, air-cleanliness, chemical, biological, cluster, and scenario source labels. The wrappers do not discover state, actor, cause, severity, or amount; the owner must set those facts before calling them.

The pressure endpoint converts a positive amount into normalized food pressure when `famine_migration_pressure_request_apply_food` is positive and into flight pressure/registered displacement when `famine_migration_pressure_request_apply_flight` is positive. It does not mutate civilian population and does not create a movement cohort.

### Exact movement and custody patterns

`famine_migration_transfer_civilians_exact` at `chaosx_famine_migration_effects.txt:1482` performs the sole origin population debit, measures the actual debit, subtracts separately logged route deaths, credits only survivors at the destination, reconciles residual conservation, and updates the cohort host. A caller must provide `famine_migration_transfer_people`, request proof, border proof, transport proof, safety proof, actor proof, and `famine_migration_route_destination`; the trigger contract is at `chaosx_famine_migration_triggers.txt:85-95`. A future Event 5/6/21/28/33/50/95 movement owner must call this only from an exact route transaction and must not add another population debit or arrival credit.

`famine_migration_record_cohort_custody_action_exact` at `famine_migration_adapter_effects.txt:57-163` requires one explicit aligned cohort ID, an internment or forced-labor action, the current whole-row living amount, transaction proof, actor proof, site proof, current state host, and valid persisted owner. It refuses inference from a camp flag, death amount, quota, or country-wide condition. The camp owner demonstrates the correct pattern at `camp_repression_rework_effects.txt:5080-5120`.

The direct-death aliases at `famine_migration_adapter_effects.txt:200-216` are only for a source owner that has not already debited population and that can prove an accepted occupation-repression, forced-labor, or forced-displacement reason. They are not valid post-death callbacks and are not a generic “event happened” hook.
