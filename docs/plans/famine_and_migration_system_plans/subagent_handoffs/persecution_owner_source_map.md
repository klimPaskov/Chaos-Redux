## Existing patterns

The current source has a clear strict-owner pattern. An owner establishes the exact state, actor, cause, amount or action, and proof variables, calls a narrow adapter, then clears one-shot request fields. The shared adapter does not discover states, infer actors, or convert a site/building/quota into a person-level fact.

The strongest exact state/actor/action pattern is the generic camp dispatcher plus concrete action state. `camp_rework_action_state_id` preserves the selected state through the nested action, ROOT is the action actor, and the exact custody staging/commit path can validate one aligned live cohort, current host, transaction proof, actor proof, and site proof. The generic detention path has a special fallback that can activate a site without a staged cohort, so a targeted-cohort receipt must remain conditional rather than being invented.

The strongest replay pattern is the German camp-prison transfer. It uses `genocide_decisions_taken` as a monotonic transaction input, saves origin/actor/source-owner/destination/reception-owner targets, rejects lower and mismatched equal transactions, and persists the last transaction, actor, cause, custody status, owners, and exact amounts. This is a movement owner, not a general persecution-state owner, and must not be reused to infer current persecution outside the transfer source.

The current camp registry is deliberately broader than current persecution. `camp_rework_register_active_site` is reached from generic activation, inherited/static registration, country-specific laboratory and experiment paths, test-country setup, and evidence-related paths. `is_valid_camp_active_site_state` also accepts building/site markers and Soviet famine-pressure markers. Therefore a canonical writer must sit in accepted action/operation branches or a new owner-local proof helper, not in the registry or type resolver.

The canonical boolean should be a state-local projection only. Responsible actor, current controller, state owner, cause class, operation generation, and targeted cohort ID must be separate state variables or chain-local event targets. None of the 13 consumers needs a cohort or cause identity inside the boolean, but the producer must retain those identities for actor responsibility, condemnation, exact movement, replay, and later clearing.

- Canonical producer and clearer are absent. Consumers currently test a flag that no source path sets or clears.
- Generic occupation-law transition callback with exact state, responsible actor, current owner/controller semantics, action generation, and replay identity is unavailable. The occupation profile resolver is a read-only current-law mapping, not a transition receipt.

- Event MCP inspection/rendering was partial because `MCP_INLINE_FILES_TRUNCATED`; the retained artifacts do not prove a complete event graph for the selected CBRN event.

### Ordinary risks

- `is_valid_camp_active_site_state`, `camp_state_site_type`, building levels, `genocide_soviet_famine_pressure_site`, `forced_labor_quota`, evidence flags, and country-level active-camp registries describe site/context or pressure, not necessarily a current qualifying persecution action.
- `genocide_responsible_country` is an actor/responsibility pointer and is not automatically the state owner or controller. The spec normally treats current controller applying or benefiting from occupation policy as responsible while the state owner remains the affected country.
- A state can have overlapping detention, forced labor, Gulag, extermination, CBRN, and historical/evidence markers. A boolean clear must be aggregate/recomputed, not tied to one site flag.
- The state flag cannot carry a targeted-cohort ID or cause identity. Forced movement, return, Condemnation, and actor-specific reporting require their own event targets and durable transaction/generation fields.
- CBRN active flags are timed operation windows. The parent must decide whether the canonical persecution projection follows the active operation window, the current coercive law, or both; the generic law path remains blocked until exact transition ownership exists.
- Concurrent edits can move line numbers and alter the consumer count. Re-run the censuses immediately before any source patch.
