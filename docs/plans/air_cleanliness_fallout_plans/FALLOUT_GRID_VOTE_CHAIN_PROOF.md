## Candidate and receipt contract

The registry admits an East Asian Technate with Manchurian Reactor Keeps memory, a host state carrying the closed Patent After the End memory, current Air Winter and Supply Access receipts, surviving infrastructure, a foreign neighbor, durable grid ledgers, and one affordable branch. It selects the lowest eligible native state. The opening freezes owner, controller, generation, neighbor, winter values, supply, and grid ledgers before issuing one ordinary receipt.

The four branches are Share Power With Every Neighbor, Favor the Settlements That Built the Lines, Reserve Power for Domestic Districts, and Bind the Grid to Military Corridors. They use distinct Food, Medicine, Fuel, Scrap, Power, Recognition, and Cohesion costs. The result arrives after exactly `42` days. The second-year callback arrives after exactly `330` days.

## Effect and cleanup contract

Results and callbacks grade Air Winter, Supply Access, Medicine, Cohesion, Recognition, grid legitimacy, dependency pressure, export trust, reserve power, client capacity, diplomatic power, and grid memory. Failure sends bounded Deaths through the shared Deaths request path and damages one host infrastructure level. The chain writes a selected-neighbor state memory, bilateral opinion, country memory, and Event Log history `9195`. Hidden AI follows the same outcome and cleanup path.

Cleanup releases the result and callback receipts independently, clears reserved host and neighbor state flags, closes the authenticated host memory, and clears all country registries. The chain never requests Fallout and never registers Fallout as an ordinary Event Log entry or evolution.
