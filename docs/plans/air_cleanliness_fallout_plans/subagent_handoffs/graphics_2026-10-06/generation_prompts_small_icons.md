# Fallout small icon and texticon generation prompts

All prompts below were submitted to the built-in ImageGen tool with `transparent_background=true`. Decision/category assets use the inspected canonical decision/category references and existing Fallout decision miniatures as style anchors. The Recognition icon uses installed vanilla texticon references; the canonical reference library has no texticon folder.
