## Conditional findings

**Easy Decisions mode can mint the relief-vote fee.** The relief decision charges the fixed quote at `common/decisions/fallout_consolidated_decisions.txt:756-765`, while `air_cleanliness_treaty_open_relief_vote` stores that configured amount at `common/scripted_effects/fallout_consolidated_effects.txt:140288-315`. The failure branch also refunds the configured amount at lines 140329-335. Cancellation and unfunded closure consume the saved quote and add political power at lines 140399-418 and 140471-475. The installed console documentation says Easy Decisions mode removes decision costs and cost triggers and reduces `days_remove` timers to one day (`documentation/console_commands_documentation.md:798-802`, revision `b65548c92b318f84f2185be790a3e0f2bce331ea646e233bf2ea85114bf8215d`). If that mode is active, an unfunded or invalidated vote returns 25 PP although the decision charged none. This is conditional debug-mode behavior, not a standard-mode balance defect.

**The shared relief receipt can be overwritten before an old report expires in Easy Decisions mode.** Normal votes use a 21-day decision timer and a 120-day caller cooldown; an unfunded result shortens only the caller's retry flag to 14 days and does not set the recipient's recent-target flag (`common/script_constants/fallout_consolidated_constants.txt:46771-46786`, `common/scripted_effects/fallout_consolidated_effects.txt:140389-395, 140560-573`). A different eligible member can call another vote after the first ballot releases. The result event `chaosx_air_treaty.19` reads the mutable global result, counts, and pledge values in its descriptions and options (`events/fallout_world_end_events.txt:724-797`), and the closure writes that shared receipt before firing `.19` to all live members (`common/scripted_effects/fallout_consolidated_effects.txt:140468-475, 140490-540, 140568-573`). The event has no `timeout_days`; the offline Event modding reference says the default choice window is 13 days (`paradox_wiki/Event modding - Hearts of Iron 4 Wiki.md:186-191`, revision `96327b896298420d84058394a44ed08be7eb518726b8f207b392fea71f05d43d`). In ordinary play, even a second caller who starts immediately cannot close a normal 21-day vote before the prior report's 13-day window. The cancellation route does not write a new global result. With Easy Decisions mode, however, a second vote can close after one day and overwrite the old report's receipt before its default timeout. Treat this as an abnormal debug-mode fragility, not a standard-mode blocker.

## Reviewed correctness points

The signed-score selector now accepts the first eligible row regardless of score, then retains the existing score and tie ordering; its presence marker is set with the selected row (`common/scripted_effects/fallout_consolidated_effects.txt:57351-57418`). Ordinary receipts require that a score exists rather than requiring it to be positive (`common/scripted_triggers/fallout_consolidated_triggers.txt:11596-11604`). I found no remaining positive-score sentinel defect in the changed path.

The recovery cohesion delta is initialized, accumulated, copied into the helper input, applied, and cleared within the helper; the caller invokes it inside the once-per-generation survivor-memory guard (`common/scripted_effects/fallout_consolidated_effects.txt:2802-2820, 2941-2943`). No lost or double-applied cohesion delta was found in source.

Orientation outcomes are saved only inside the authenticated, not-yet-applied result guard and before the transient transaction is finished (`common/scripted_effects/fallout_consolidated_effects.txt:63678-63702`). The summary helper resets on generation change and stores the outcome under the matching component (`common/scripted_effects/fallout_orientation_summary_effects.txt:10-39`).

Reconstruction answer checks bind the partner's stored proposer variable to the carried regular event target, then verify the proposer's generation, active proposal, and exact recipient (`common/scripted_triggers/fallout_consolidated_triggers.txt:37661-37679`). Cleanup clears the reciprocal pointer only when it still identifies the same pair (`common/scripted_effects/fallout_consolidated_effects.txt:140719-140737`). The annex and capitulation hooks call cleanup in the documented native scopes (`common/on_actions/fallout_consolidated_on_actions.txt:24-36`). I found no scope or pairing defect in the reviewed changes.

The variable-duration refusal flag uses `meta_effect` to supply the dynamic day count and targeted `@PREV` token (`common/scripted_effects/fallout_consolidated_effects.txt:140742-757`). The offline wiki documents targeted flags and meta-effect substitution, while installed effects documentation lists `meta_effect` support and its accepted targets. No syntax defect was found in this path.
