# The School in the Vent Room event addendum

## Review decision

Implement candidate 289 as the next dormant global-survival tranche. It follows
the durable First Safe Birth memory and covers a different matrix family from
birth policy, census memory, medicine, and shelter. The chain is a second-
generation institution rather than a generic education bonus.

## Authored choices

The technical class teaches repair and grid safety. The history class preserves
names and maps without turning old claims into an automatic war goal. The civic
class teaches water rosters, clinic notices, and repair duties. The faith class
keeps a shared family calendar while leaving room for families who do not attend.
These are four manually written lanes with separate costs and outcome deltas.

## Delayed transaction

The opening reserves one result after 28 days and one callback after 210 days.
Human visible cost is three for the opening and one for each delayed receipt.
Hidden AI pays zero visible cost and calls the same branch, grading, result,
callback, history, and cleanup effects. Result failure uses Deaths at 0.12
percent. Callback failure uses Deaths at 0.06 percent. Cleanup cannot clear the
durable First Safe Birth memory and does not create a scheduler activation.

## Review boundary

The chain remains dormant and uncounted until the accepted numerical contract
opens activation. No host authority, save recovery, multiplayer, or live Event
Log presentation is claimed.
