# Fallout Black Start event addendum

Black Start adds a country-level recovery family after Shelter Marriage Law.
It treats the first electrical restart as a political institution rather than
as a generic repair bonus. Four authored policies have distinct costs,
thresholds, durable ledgers, prose, AI priorities, modifiers, and Event Log
payloads.

The implementation surfaces are:

- candidate `310`, transaction `710018`, route `7118`
- events `chaosx.fallout.310` through `.316`
- history `9123` with fifteen payload values
- Power, Scrap, Cohesion, Recognition, Reclamation, capacity, governance,
  dependency, resilience, and exposure variables
- dedicated Black Start report art and a registered sprite
- human and hidden AI parity, delayed result, callback, authenticated cleanup,
  Deaths-backed failure, and dormant scheduler state

The branch result is delayed by 45 days. The maintenance callback is delayed by
270 days. The result modifier lasts 420 days and the callback modifier lasts
300 days. Failure rates are 0.07 percent for the result and 0.035 percent for
the callback, both routed through Deaths.

This tranche is intentionally dormant until a live activation coordinator is
approved. It does not claim the engine-native all-province thermonuclear sweep,
blackout authority, save recovery, or multiplayer proof.
