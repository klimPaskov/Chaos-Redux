Callback grading uses thirteen equally weighted components, including inverse current Disease Pressure, inverse current Refugee Pressure, and inverse current Exposure, so worsening pressure cannot improve the thaw result. The callback grade is frozen before the human callback popup renders and hidden AI uses the same frozen outcome. Callback memory retains the selected branch and outcome and applies branch-specific ledger changes.

Result failure requests `0.15%` of the current state population and callback failure requests `0.07%`, both with the Fallout aftermath reason and a minimum remaining population of `100` people. Success and partial outcomes change state Supply Access, Shelter Capacity, Reclamation, Exposure, Disease Pressure, Refugee Pressure, survival resources, Cohesion, War Support, durable branch ledgers, state memory flags, and dynamic modifiers.
