# Fallout Permit Market Chain Proof

## Static scope

Permit Market is a dormant Quarantine State candidate with event ids `698` through `704`, candidate `698`, transaction `710071`, route `7174`, and survivor history `9177`. The source lives under `add_namespace = chaosx.fallout`. It is not a Fallout consequence event, ordinary Event Log entry, evolution, or ordinary super-event.

## Admission and receipts

The candidate producer selects the lowest eligible current native owned state after `fallout_event_691_memory_closed`. It requires current owner and controller identity, current generation, durable survival resources, Air Winter Shelter Capacity, Supply Access, Adaptation, bounded Exposure and Disease Pressure, surviving population, Quarantine government, public-health memory, grievance memory, and one affordable branch. The opening freezes owner, controller, generation, state Air Winter values, Supply Access, reliability, compensation, fatigue, backlog, and cause memory.

The human and hidden-AI opening lanes use issued ordinary receipts. Delayed result and callback lanes use Fallout-owned delayed receipts with distinct transaction offsets. Cleanup is idempotent, callback-first, and releases the result ticket before the callback ticket. Generation, owner, controller, target-state, and memory checks fail closed.

## Branches and delayed effects

Issue Local Passes, Audit Every Register, Delegate Permits to the Wards, and Sell Temporary Permits have exact Food, Medicine, Fuel, Scrap, Power, and Recognition costs. Each branch has deterministic success, partial, and failure thresholds, branch-specific Air Winter and Supply Access deltas, public-health and movement-grievance deltas, reliability and compensation effects, inspection fatigue and appeal backlog changes, cause memory, stability, and dynamic modifiers. Result failure damages infrastructure and sends a bounded Deaths request. Callback failure sends a second bounded request.

## Presentation and memory

Human opening, result, and callback events use `GFX_report_event_fallout_permit_market` and dedicated localisation. Hidden AI has parity through separate event ids and the same effect functions. Survivor Event Log history `9177` records branch, result, callback, and cancellation payloads through the shared log router. No tag, state, successor, population transfer, or recurring scheduler is created.

## Static limitations

This proof does not claim runtime dispatch, host authority, save recovery, multiplayer delivery, Deaths readback, player-visible presentation, or exact engine-native all-valid-province thermonuclear sweep. Hearts of Iron IV was not launched.
