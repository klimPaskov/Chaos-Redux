# Fallout Old Weather Station event addendum

## Accepted scope

The Old Weather Station is the next manually reviewed global-survival candidate after The Reactor Without a Country.
It uses a native radar-station state and the dormant Fallout scheduler contract.

## Implementation surfaces

- candidate `373`, transaction `710027`, route `7127`
- events `373` through `379`
- four authored policies with distinct resource and governance costs
- 42-day result and 300-day station review callback
- forecast, radio contact, and climate-intelligence ledgers
- Deaths-backed state failure and radar-first damage ladder
- dedicated Event Log history `9132`
- dedicated report art and runtime DDS

## Review boundary

The candidate is dormant. It is not counted toward the 660-block release floor until scheduler activation, caller ownership, save recovery, multiplayer behavior, Event Log delivery, and final audits are proven.
