# Fallout Ice Melt Rations chain proof

Status: implemented as a dormant reviewed tranche, not release-floor credit.

Events `chaosx.fallout.492` through `.498` are defined once in `events/fallout_world_end_events.txt`. The root uses the Fallout namespace and the opening has a dedicated report picture and concrete boreal or highland text.

Candidate `492` uses transaction `710044`, route `7144`, and history `9149`. The producer initializes a country station filter reserve, then selects the lowest owned state that passes `fallout_event_492_ice_melt_state_is_current`. That trigger requires a produced current-generation Air Winter snapshot, surviving state population, water-security evidence, regional frozen-water eligibility, a supported urban state category, current Fallout identity and resource rows, and low enough supply access. The producer copies the state water-security value into the country-owned pressure row before appending the candidate.

The four branches are controlled boiling, untreated meltwater, a clean-ice expedition, and guarded fuel rationing. The result waits `42` days. The ice-ledger callback waits `300` days. Human and hidden-AI lanes share the deterministic viability calculation, separate public and station filter ledgers, resource costs, branch memories, Deaths-system failure route, and authenticated cleanup.

The chain changes Water, Fuel, Filters, Medicine, Cohesion, Recognition, operation memory, water reserve, station filter reserve, expedition credit, stability, war support, Air Winter exposure, adaptation, reclamation, and supply. Failure damages native infrastructure, naval-base, or industrial capacity in order and requests exact state population loss through the Deaths system. Event Log history `9149` maps twelve branch payloads and three callback payloads through the shared name and detail routes.

The dedicated report image was generated through the approved event-art workflow, processed at `210x176`, converted to a one-level uncompressed BGRA DDS, copied into the runtime Fallout picture directory, and registered as `GFX_report_event_fallout_ice_melt_rations`. The asset manifest records source, processed, preview, and runtime hashes.

Static checks for this tranche cover seven unique event definitions, matching event constants, candidate and Event Log wiring, balanced edited script blocks, no raw unsupported comparison operators, no predecessor Desalination identifiers in the new runtime files, and BOM encoding for the localisation file.

The chain is dormant and earns zero countable blocks because scheduler activation, host authority, save recovery, multiplayer delivery, full-screen Fallout blackout, and runtime Event Log delivery remain unproven. No HOI4 runtime was launched.
