## Evidence standard

For each resolution, record the installed game version and DLC state, exact source path, section or line range, source revision, what was actually read, what the tool checked, and the limits of any runtime observation. A script parser's success cannot prove native parameter semantics. A save can prove one observed result, not every possible country configuration.

Follow every required omitted or paginated source before claiming complete local reference coverage. Do not use online wiki results in place of the project's required offline reference. Do not claim a Windows path exists in this container because it appears in a supplied skill.

## Permitted next step

These are gates for implementation and production, not invitations to replace the concept. An implementer should resolve them in dependency order, beginning with C01 through C07. A capability that fails must return a concrete decision request with evidence and the affected design requirement. It must not be silently omitted from a completion report.
