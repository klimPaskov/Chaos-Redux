## Evidence needed for closure

Each native result should record the installed game and relevant DLC state, current repository revision, exact reproducible fixture, observed result and any save or screenshot evidence.
Use the required HOI4 MCP probability route for probability claims and the actual game for transaction and interface claims.
A manual source review can close a documentation question but cannot establish delivered construction or a save-safe native transaction.
Test changes that affect shared costs, transfer or Chaos with the other owning systems present.

## Independent review gates

The native matrix does not replace a real near-completion improvement-loop subagent.
The improvement-loop, specialist audits and final completion audit remain not run in this package.
A parent-authored explanation of how they should run is an assignment, not a completed audit.
