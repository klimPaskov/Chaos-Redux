The federation transforms its core, so no country tag is created. The prefix `LAWF` appears nowhere else in this mod, the installed game or Kaiserreich.

### Checks

`ev40_check.py` is clean: no undefined effect, trigger, constant, event, scripted localisation function or localisation key. `hoi4.focus_inspect` ran once on the federation tree and reported no blockers, no crossings, no overlaps, 64 resolved titles and three long connectors by design. A scan of every `custom_cost_text` token (44) found all three row variants defined. The static localisation audit was run for all localisation files. Weighted decisions were calculated by hand from the script (see the doc page).
