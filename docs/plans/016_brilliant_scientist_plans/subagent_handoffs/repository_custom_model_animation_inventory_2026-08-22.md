# Repository custom model animation provenance inventory — 2026-08-22

## Scope and acceptance rule

This is a read-only repository audit requested for the Chaos Redux custom 3D model pipeline. The only file written by this audit is this handoff. No gameplay, entity, GFX, model, animation, job, or source asset was changed, and no commit was made.

The acceptance rule supplied by the user is strict: every custom runtime model must use genuine provider/professional skeletal actions. Blender-keyed/simple procedural motion, whole-rig transform motion, static-pose aliases, semantic action reuse, and transform-only actions do not qualify and must be redone through Meshy. A provider-generated mesh alone does not prove provider-sourced animation. A checked-in `.anim` file alone does not prove acceptable provenance.

The audit distinguishes installed runtime model packages from planned or unwired jobs. Event 002 zombie and Event 012 Africa line-by-line reviews were delegated to separate specialist audits; this report records their stable group-level findings and exact source roots without duplicating every state line.

## Classification definitions used below

- **Pass:** every required runtime role has a dedicated action, provider/professional lineage is recorded, the actual exported `.anim` bytes are present, and actual-byte reimport proof exists.
- **Provider partial:** some provider/professional actions and reimports are proven, but at least one required role is manually authored, missing, semantically reused, or blocked by weapon/contact proof.
- **Manual/procedural:** Blender reports explicitly identify local semantic skeletal authoring or the source route is a hand-keyed action generator. Removing scale curves or keeping the root in place does not change this classification.
- **Unverifiable/missing:** a handoff claims actions or a provider mesh, but the source job root, action task IDs, action reports, or runtime-to-source proof is absent from this worktree. It is not promoted to genuine provider status.
- **Alias/reuse:** an entity state points to another semantic action, a static pose, a whole-rig transform, or a copied vanilla entity. This fails the required dedicated-role test even when the referenced action itself is genuine.
- **Static:** the consumer is explicitly a static map/building/entity mesh with no skeletal action role. It is not a failure unless its consumer is later changed to an animated unit entity.
