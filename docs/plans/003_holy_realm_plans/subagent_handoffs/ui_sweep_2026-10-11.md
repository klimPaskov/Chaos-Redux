The renderer reports the Mandala core as clipped by floating-point noise (`218.4` versus `218.39999999999998`), unavailable metric metadata for the `holy_realm_mandala_chaos` font, and normalized viewport drift for parent-relative text between resolutions. The actual images show no corresponding cut pixels, missing glyphs, or movement relative to the container. Hover/disabled/locked control states were not rendered because the authorized scenario contract requests `states = ["normal"]`; all five tab click triggers are `always = yes`, and no gameplay control in the container has an unavailable state. These checks remain limits rather than claims of game validation.

The Diplomacy body preview displays the literal nested token `[GetHolyRealmPanelConquestLine]`. `localisation/english/003_the_holy_realm_l_english.yml` defines that nested call, and `common/scripted_localisation/003_holy_realm_scripted_localisation.txt` defines its always-valid final fallback `holy_realm_panel_conquest_quiet`. The offline localisation reference states that `defined_text` supplies localization values and that dynamic localization is evaluated within localization calls; vanilla AAT keys contain the same `[Get…]` call pattern. The tool preview did not recursively expand this nested scripted-localization token, so this is recorded as a renderer limitation with source support, not promoted to an in-game defect. No localization change was made.
