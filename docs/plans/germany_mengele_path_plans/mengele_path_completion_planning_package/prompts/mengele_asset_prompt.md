# Mengele asset prompt

Use `chaos-redux-event-assets` for every visual asset tied to the Germany Mengele path.

## Sensitivity rules

This path concerns real historical atrocity material. Use restraint. Avoid gore, victim spectacle, sensational experiment imagery, heroic perpetrator framing, modern reenactments, film stills, modern props, and fake historical documents with readable generated text.

Do not generate real leader portraits or real person's likenesses. If the repo needs Josef Mengele or another real person portrait, use a real source image with license documentation and process it according to the real leader portrait workflow.

Generated art is allowed only for symbolic, fictional, or documentary-style visuals that clearly do not claim to depict actual victims, actual experiments, or real historical photographs.
