# Mengele achievement prompt

This package does not require new achievements by default. The current source describes a Germany gameplay chain connected to the camp and genocide crisis system rather than a standalone random-event spec with mandatory achievements.

During repository verification, check whether the accepted design or existing files already define Mengele achievements. If they do, finish the full achievement surface: triggers, disqualifiers, icons, localisation, docs, and tests.

If adding achievements is appropriate, do not reward atrocity escalation as comedy or simple completion. Prefer difficult goals around exposure, containment, evidence preservation, tribunal pressure, avoiding the Directorate path, defeating the Directorate, or stopping the world-order branch under strict conditions.

If no achievement is appropriate, document `not_needed` in the completion report with source evidence and auditor agreement.
