# Subagent routing matrix

| Need | Subagent | Timing | Output |
| --- | --- | --- | --- |
| File map is unclear or current-source files moved | `chaosx_repo_explorer` | Before edits only if direct search is not enough | File map and edit-order report |
| Repeated variables, event targets, cleanup, or helper logic | `chaosx_scripted_system_architect` | Before duplicating logic | Helper patch or architecture plan |
| Decision and mission quality | `chaosx_decision_mission_auditor` | After decision implementation | Patch handoff or audit |
| Clone focus tree quality | `chaosx_focus_tree_auditor` | After focus edits | Patch handoff or route audit |
| Directorate and clone client package | `chaosx_country_package_auditor` | After country or tag edits | Patch handoff or package audit |
| Super-event quote and button | `chaosx_super_event_text_researcher` | Before final localisation | Sourced text research note |
| Super-event audio | `chaosx_super_event_audio_researcher` | Before wiring or verifying audio | OGG, source docs, license note |
| Historical or documentary image | `chaosx_asset_source_researcher` | Before image wiring | Source, PNG, DDS, manifest |
| Symbolic generated image | `chaosx_generated_event_art` | Only when source mode is generated | Generated source, DDS, manifest |
| Icons | `chaosx_icon_artist` | If decision, idea, focus, or achievement icons are missing | Icon package and GFX handoff |
| Localisation | `chaosx_localisation_auditor` | Before completion | Key-level patch or audit |
| Improvement pass | `chaosx_improvement_loop_planner` | After main implementation tranche | Addendum or closure handoff |
| Docs cleanup | `chaosx_documentation_curator` | After several handoffs or stale docs | Source-of-truth map or cleanup patch |
| Spreadsheet | `chaosx_spreadsheet_doc_worker` | After final wording exists | Workbook update report |
| Final audit | `chaosx_event_completion_auditor` | Last step | Completion audit |
