## Findings, sorted by severity

1. **High — the national category header exceeds the mechanic-value budget.** `localisation/english/035_great_depression_l_english.yml:102` renders seven lines with Severity/band/trend, Phase, Doctrine, Next threshold, three cause slots, Current incident, Selected center, Objective, and Relapse. The interaction budget in `.agents/skills/chaos-redux-scripted-gui/SKILL.md:36-40` normally permits one main value plus two supporting values, with four simultaneous values as the hard ceiling. Most fields are named and useful, but their simultaneous presentation exceeds that ceiling. Reduce the header to Severity plus the immediate phase/objective and one selected-center or cause summary, and move incident, relapse, and secondary cause detail to the action or incident tooltip where it changes the next choice.

2. **High-risk unresolved — `great_depression_prepare_action_tooltip_values` returns temporary variables for use after a scripted-effect boundary.** The helper at `common/scripted_effects/035_great_depression_decision_effects.txt:174-228` creates the `great_depression_tt_*` temporary outputs, and `common/decisions/035_great_depression_decisions.txt` calls it 100 times before caller-side `custom_effect_tooltip` keys read those values. Callers do not initialize the outputs first. The offline Data structures page warns that temporary variables created inside scripted effects may not exist after return (lines 437-442; SHA-256 below), and `common/scripted_effects/chaosx_dynamic_effects.md:362-420` records the project's caller-initialization safeguard. This creates a broad risk that displayed consequence amounts are missing or stale; no runtime artifact was returned to establish whether that occurs in the current build. Recommended fix: initialize the caller-visible outputs before the helper at each outer effect call, or move the calculation and consuming tooltip into the same effect block.

3. **Medium — late Event 34 boom starts still miss the supplier cost quote.** The owner's shared-tree change fixes suppliers present at worldwide activation: `great_depression_event34_supplier_adapter` now calls `great_depression_refresh_costs` (`common/scripted_effects/035_great_depression_effects.txt:6796-6816`), and `great_depression_initialize_worldwide_pressure_registry` calls the adapter for every `industrial_boom_active` or frozen supplier it visits (`:6600-6616`). The conference opener also refreshes contributors and the bounded at-risk supplier array (`common/scripted_effects/035_great_depression_decision_effects.txt:1368-1389`). This is quote-consistent with `great_depression_costs_are_ready` (`common/scripted_triggers/035_great_depression_decision_triggers.txt:104-115`) and the participant's four-resource affordability gate (`common/scripted_triggers/035_great_depression_decision_surface_triggers.txt:1755-1764`). However, `great_depression_global_supplier_risk_countries` is an at-risk-contract registry, not every conference-eligible boom supplier: `great_depression_register_supplier_risk` only adds suppliers with `great_depression_supplier_contract_at_risk` and caps that list (`common/scripted_effects/035_great_depression_effects.txt:6301-6324`). A boom can start after worldwide activation: `events/034_industrial_boom.txt:12-27` is triggered-only and only excludes a target already in a national Event 35 crisis; it sets `industrial_boom_active` at line 27 without calling the adapter. The join predicate admits any `industrial_boom_active` country (`common/scripted_triggers/035_great_depression_decision_surface_triggers.txt:1739-1753`), so a late, contractless supplier can still appear without a quote. Add a narrow Event 34 start-path adapter call after setting the active flag, guarded by `has_global_flag = great_depression_worldwide_episode_active`; the existing Event 35 adapter already handles quote initialization and its supplier-risk registration safely.

4. **Unresolved scenario evidence — maximum simultaneous action count.** The native `great_depression_category` has 94 child entries in one file: 79 ordinary decisions and 15 missions. Its visibility is gated by national crisis, contagion exposure, supplier, conference, doctrine, stage, target, and completion triggers, so 94 is not the simultaneous count. Six mutually exclusive opening doctrine choices are simultaneously visible when doctrine is unassigned, already consuming the hard six-action maximum before any other primary action. The focused `hoi4.decision_inspect` inventory did not return, so the maximum visible primary-action count by phase remains unproven. The source has one main mission slot and two support slots, for a three-mission cap.

5. **Review note — the 70-day freight mission is short, with no exact spec duration target.** `great_depression_event.freight_mission_days = 70` (`common/script_constants/035_great_depression_constants.txt:52`) is below the decision skill's normal easy-mission recommendation of 90 days. The Event 035 spec says the objective appears when logistics disruption is a top cause but does not set a freight duration target (`docs/specs/035_great_depression_specs/035_great_depression_spec_part_3_decisions_missions.md:423-433`), so this is a balance review item rather than a confirmed defect.
