## Baseline gate finding

`great_depression_selected_center_target_is_valid` requires the state to be owned and controlled by `ROOT`, marked as a Depression Center, not Liquidated, currently registered to the active episode, and either selected by the human country or any eligible target for an AI country (`...decision_surface_triggers.txt:753-805`). `great_depression_center_project_target_is_open` rejects state authorization, active work, pause, certification, and the country-level active project (`:806-817`). The Public Works predicate then requires the state to be Reopened and to lack `great_depression_center_public_works_receipt` (`:926-931`). `great_depression_can_start_regional_works_program` only delegates to that predicate (`:1969-1971`); it adds no mapped-need condition.

The current hard gate therefore excludes Distressed, Idled, Shuttered, and Abandoned centers even when they have a repair or conversion need. It admits a Reopened center without requiring any mapped need, so a healthy no-need Reopened center can satisfy the same gate. The requested state set is Distressed, Idled, Shuttered, Reopened, and Abandoned, excluding Liquidated, with current ownership/control/registration, no active project, no old Public Works receipt, and a real mapped need. This mismatch is the exact baseline defect.

## AI score source trace

The decision defines `base = constant:great_depression_target_weight.base`, whose current constant is `10`. The conditionally applied modifiers are `+14` for the Relief Coalition profile, `+8` for State Coordinator, `+6` when refreshed costs are ready and every nonzero resource is affordable, `+8` when the target is recoverable, and `+4` when the target has more than one civilian factory or more than one military factory. A factor of `0` applies when `great_depression_ai_center_target_is_doomed` is true. The relevant constants are `great_depression_ai_weight.blocked = 0`, `standard = 6`, `strong = 8`, `dominant = 14`, and `great_depression_scaling.center_industry_weight = 4` in `common/script_constants/035_great_depression_constants.txt:1384,1422-1436`.

Two modifiers conflict with the intended expanded gate. `great_depression_ai_center_target_is_recoverable` only checks that the center is not Liquidated, so it is true for every currently eligible target and does not distinguish useful work. `great_depression_ai_center_target_is_doomed` treats Abandoned and Liquidated as doomed (`...decision_surface_triggers.txt:1554-1576`). The existing Reopened-only gate makes that zero factor unreachable today. If Abandoned becomes eligible without correcting this predicate's application, the intended abandoned-works conversion is assigned zero AI weight. No coefficient change is indicated; the owner should align these predicates with mapped need and permitted project types while retaining the numeric tuning values.

The `+4` industry modifier rewards raw factory count, not repairable damage or a missing construction need. The AI score can therefore favor a high-industry Reopened center without proof that Public Works has useful work there. Actual profile, affordability, target state, candidate race, and competing decision scores were not supplied to the evaluator, so no combined score, rank, dominance share, or starvation probability is claimed.
