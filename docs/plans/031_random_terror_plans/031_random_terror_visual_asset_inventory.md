# Event 31 Random Terror visual asset inventory

## Scope and acceptance basis

The active user goal and the attached visual-audit request accept complete implementation and repair of every Event 31 visual asset described by `docs/specs/031_random_terror_specs/`.

This current-state inventory starts from runtime registrations and engine flag lookup identities rather than from the temporary asset workspace.

This is a runtime inventory snapshot, not a complete accepted-requirement coverage proof.

Visual verdicts summarize the parent family reviews, while missing consumers and procedural evidence gaps remain independent acceptance failures.

The current total is **444 runtime files**: 307 unique textures in `interface/031_random_terror.gfx`, 135 flag files for eight base carrier identities and 37 cosmetic identities across the normal, medium, and small ladders, and two shared super-event textures.

The earlier 420-row count omitted the eight base carrier flag triplets. The unrelated AXS through AXZ flags remain excluded.

There are 45 flag lookup identities and 37 distinct authored designs.

The eight base carrier identities intentionally share their imagery with the eight corresponding dormant cosmetic identities.

A current decoder comparison confirms pixel equality for all 24 base-to-dormant pairs across the three sizes.

The base files use uncompressed 32-bit TGA with descriptor 8 and bottom origin, while the cosmetic files use uncompressed 24-bit TGA with descriptor 0 and bottom origin.

Their different encodings explain the different file hashes without changing the flag imagery or orientation.
