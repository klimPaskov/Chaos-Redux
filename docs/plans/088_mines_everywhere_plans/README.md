Place this folder at `docs/plans/088_mines_everywhere_plans/`. The authoritative creative specs and final prompt files belong in the companion `docs/specs/088_mines_everywhere_specs/` folder.

`implementation/` contains the native capability gates, state and dispatcher contract, observed and proposed repository touchpoints, catalog handoff and dependency-ordered implementation stages. These files are plans, not native code or proof of engine support.

`subagent_briefs/` contains 10 bounded, self-contained future custom-agent assignments. All are NOT RUN. The folder intentionally does not contain invented subagent outputs. Real future outputs belong in `subagent_handoffs/` only after actual execution.

`review/` contains the parent-authored design review and the package-level audit. Parent review is not independent custom-agent review and does not complete the mandatory custom improvement-planner pass.

No gameplay, registry, localisation, asset, workbook or connected repository file was edited by this planning delivery. Runtime art was planned rather than generated. Event 088 remains To Be Reworked.
