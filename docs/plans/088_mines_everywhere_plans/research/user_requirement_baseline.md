# User requirement baseline

Source: the user's direct Event 088 brief supplied with the archive in this conversation. This file records the authoritative requirements, not new engine research.

Event 088 is Mines everywhere, Minor Fire-Once, To Be Reworked, Chaos level 1, Sudden Abundance Medium. It replaces the old one-random-sea-region concept completely.

Every valid naval strategic region on the current campaign map must receive the incident in one firing. The intended addition is 1,000 mines for every valid country that can own mines in every valid naval region. Ownership stays separate so opponents can have fields in the same sea at the same time.

Existing mines are never cleared or replaced. Additions stack on existing fields, subject to the ordinary native maximum for one country and region. The intended ordinary saturation target is 1,000. Separate country fields may coexist at their individual limits.

The region set must come from the current campaign map, including compatible additions and changes. No region is chosen randomly and no percentage of valid seas is skipped. Invalid owners or landlocked countries may be excluded, but that exclusion cannot remove a valid sea region from worldwide coverage.

Normal mine sweeping remains effective. Mines are actual fields and are not permanently unsweepable. A route cleared after the event is genuinely reopened against the incident rather than automatically mined again.

The user requested full specifications expanded through the full planning skill, other provided skills and provided subagents. They required full reading before drafting and explicit honesty about incomplete reading, truncation or simplification. All supplied texts were fully read. Referenced external reading and actual custom-subagent execution were not completed, as recorded in the source ledger.
