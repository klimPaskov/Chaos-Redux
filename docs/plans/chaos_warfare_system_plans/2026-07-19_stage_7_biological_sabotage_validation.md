## Contract scenarios

1. **Base doctrine preparation:** an eligible actor with exact Anthrax stock, support equipment, Command Power, policy, readiness, and a valid foreign state prepares the 160-day native raid or the matching timed covert decision. The exact models are reserved by the selected surface, the route-specific Command Power cost is applied once, and the selected state remains the sole target.
2. **Doctrine escalation:** Theater Contamination or Terminal Hazard exposes only its mutually exclusive native preparation variant, raises downstream harm and AI willingness, shortens cooldown, and permits only the bounded post-resolution Command Power refund. Equipment debit is unchanged.
3. **Native and covert partial and full release:** each native callback or covert timer resolver passes the exact state, controller, actor, agent, route, result, payload required, payload consumed, and proof into the shared lifecycle. Only a supplied dispatcher status creates release history.
4. **Ordinary failure:** a valid committed ledger can write low-confidence attempt evidence and hidden attempted-use Condemnation, but no outbreak or completed deliberate-use history.
5. **Policy, readiness, controller, or episode change:** full release validation fails. If the original committed ledger is still exact, only failed-attempt evidence, hidden Condemnation, and cooldown survive. There is no doctrine refund and no alternate state.
6. **Corrupt or incomplete ledger:** neither release nor failed-attempt history is fabricated. Transient actor/state records clean up and the player-facing result remains rejected.
7. **Abort or invalid route context:** no alternate state, replacement payload, or lifecycle release is fabricated. The native raid or covert decision owns its reservation cleanup, while a resolver that reaches the shared adapter records only the evidence and cooldown permitted by the exact context contract.
8. **AI defensive and consequence gates:** defensive CBRN profiles, active outbreak exposure, and high Condemnation plus import vulnerability suppress use; retaliation, unrestricted authority, desperation, prepared domestic programs, doctrine, and matching state evidence increase use.
9. **Shared-dispatch rejection:** a valid weighted release whose shared lifecycle record is nevertheless rejected records only attempted-use evidence, hidden Condemnation, and cooldown. It receives no doctrine refund and creates no release history.
10. **Competing covert leads:** a new failed attempt by a different actor cannot relabel an equal or stronger retained evidence lead. Actor, agent, date, and victim metadata change only when the current actor owns the stored lead.

These are source-contract scenarios, not a claim that the package-level balance scenarios have been completed. Final cross-route package scenarios remain open under the overall completion audit.
