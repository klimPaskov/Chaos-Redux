## Contract scenarios

1. **Base doctrine commitment:** an eligible actor with exact Anthrax stock, support equipment, Command Power, policy, readiness, and a valid foreign state starts the 160-day variant. The exact models and Command Power are debited once and the state receives one committed ledger.
2. **Doctrine escalation:** Theater Contamination or Terminal Hazard exposes only its mutually exclusive timer variant, raises success and AI willingness, shortens cooldown, and permits only the bounded post-resolution Command Power refund. Equipment debit is unchanged.
3. **Partial and full release:** the resolver passes the exact state, controller, actor, agent, route, result, payload required, payload consumed, and proof into the shared lifecycle. Only a supplied dispatcher status creates release history.
4. **Ordinary failure:** a valid committed ledger can write low-confidence attempt evidence and hidden attempted-use Condemnation, but no outbreak or completed deliberate-use history.
5. **Policy, readiness, controller, or episode change:** full release validation fails. If the original committed ledger is still exact, only failed-attempt evidence, hidden Condemnation, and cooldown survive. There is no doctrine refund and no alternate state.
6. **Corrupt or incomplete ledger:** neither release nor failed-attempt history is fabricated. Transient actor/state records clean up and the player-facing result remains rejected.
7. **Cancellation:** all committed material and Command Power remain lost. Attempt history and cooldown apply only if the complete committed ledger is provable; no doctrine refund applies.
8. **AI defensive and consequence gates:** defensive CBRN profiles, active outbreak exposure, and high Condemnation plus import vulnerability suppress use; retaliation, unrestricted authority, desperation, prepared domestic programs, doctrine, and matching state evidence increase use.
9. **Shared-dispatch rejection:** a valid weighted release whose shared lifecycle record is nevertheless rejected records only attempted-use evidence, hidden Condemnation, and cooldown. It receives no doctrine refund and creates no release history.
10. **Competing covert leads:** a new failed attempt by a different actor cannot relabel an equal or stronger retained evidence lead. Actor, agent, date, and victim metadata change only when the current actor owns the stored lead.

These are source-contract scenarios, not a claim of live package-scenario completion. Final cross-route package scenarios remain open under Stage 7.
