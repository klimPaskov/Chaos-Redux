# Random biological project grants and exact facility provenance

**Disposition: blocked.** The accepted CBRN overhaul requires existing biological stockpile safety and advanced-project contracts to remain coherent. The country-scoped `grant_random_chaos_special_project_available_tech` helper in `common/scripted_effects/cbrn_project_effects.txt:12-88` can grant Anthrax, Plague, Tularemia, or Smallpox project completion, but none of its active callers passes an exact facility state. The installed `documentation/effects_documentation.md:2896-2915` says scripted `complete_special_project` skips `facility_state_effects`, including when its optional `state` field is supplied. Those four native project callbacks are the source of facility registration in `common/special_projects/projects/biowarfare_main_projects.txt:490-510,728-748,961-981,1199-1219`. A random scripted grant therefore cannot claim its project has a monitored source arsenal.

The active UWR focus calls in `common/national_focus/005_soviet_collapse_custom_splinters.txt:1412-1419,1434-1440,1531-1538,1718-1725` all invoke the helper from country completion rewards. The Tver Directorate builder selects a random state without returning that selection to the grant; the Experiment Camp builds a camp rather than a biological facility. UWR successor setup at `common/scripted_effects/005_soviet_collapse_effects.txt:22354-22378` separately attempts exact Tver state 247 registration before two random draws, but it does not make Tver the source of those draws. In the normal setup the four biological projects are already granted before the draws. CXT's unique-candidate registration is independently guarded in `common/scripted_effects/chaosx_test_country_effects.txt:225-280`.

The current random helper remains reward-only. It neither assigns a first eligible state nor reuses an existing arsenal pointer as fabricated provenance. `bio_stockpile_safety_start_monitor` requires a validated country arsenal pointer and avoids duplicate monitor scheduling (`common/scripted_effects/biological_stockpile_safety_effects.txt:751-766`). To make every random biological grant facility-backed, each site-producing caller must preserve and pass an exact owned, controlled state with a positive valid facility level, then register and start monitoring once. The present focus callers have no such shared input. Choosing a new facility or treating a camp as an arsenal would change accepted gameplay and needs its own designed source and focus integration; no fallback was applied here.

The read-only source audit's acceptance cases are valid Tver, absent Tver facility, a later focus after Tver loss, and CXT with zero, one, or multiple candidate facilities. It found no exact-state route for the generic grant. The connected MCP exposes no `hoi4.reference_context`, `reference_search`, `reference_read`, or `source_lookup`; the offline Effects and Focus modding wiki sections and installed vanilla special-project and effect documentation were read locally.
