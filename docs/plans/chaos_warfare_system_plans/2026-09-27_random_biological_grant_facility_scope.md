# Random biological project grants and exact facility provenance

**Disposition: superseded by the [accepted UWR exact-site correction](../../specs/chaos_warfare_system_specs/corrections/2026-09-27_uwr_exact_biological_project_site.md).** This document preserves the read-only baseline that identified missing facility provenance before the user's 2026-09-27 choice to establish an exact eligible facility first. The current UWR wrapper, facility-reward preference, selected-state registration, and remaining validation limits are documented in that correction.

At the baseline audit, the country-scoped `grant_random_chaos_special_project_available_tech` helper in `common/scripted_effects/cbrn_project_effects.txt:12-88` could grant Anthrax, Plague, Tularemia, or Smallpox project completion without an exact facility state. The installed `documentation/effects_documentation.md:2896-2915` says scripted `complete_special_project` skips `facility_state_effects`, including when its optional `state` field is supplied. Those four native project callbacks registered a facility on native completion in `common/special_projects/projects/biowarfare_main_projects.txt:490-510,728-748,961-981,1199-1219`. This baseline could not prove a monitored source arsenal for a random scripted grant.

At the baseline audit, the UWR focus calls in `common/national_focus/005_soviet_collapse_custom_splinters.txt:1412-1419,1434-1440,1531-1538,1718-1725` invoked the generic helper from country completion rewards. The Tver Directorate builder selected a random state without returning that selection to the grant; the Experiment Camp built a camp rather than a biological facility. UWR successor setup separately attempted exact Tver state 247 registration before two random draws, but it did not make Tver the source of those draws. In the normal setup the four biological projects were already granted before the draws. CXT's unique-candidate registration was independently guarded in `common/scripted_effects/chaosx_test_country_effects.txt:225-280`.

The baseline helper was reward-only. It neither assigned a first eligible state nor reused an existing arsenal pointer as fabricated provenance. `bio_stockpile_safety_start_monitor` required a validated country arsenal pointer and avoided duplicate monitor scheduling (`common/scripted_effects/biological_stockpile_safety_effects.txt:751-766`). The accepted correction binds and revalidates an exact state before an incomplete ordinary biological grant and does not treat a camp as an arsenal.

The read-only baseline source audit's acceptance cases were valid Tver, absent Tver facility, a later focus after Tver loss, and CXT with zero, one, or multiple candidate facilities. It found no exact-state route at that revision. A [nine-entry random-pool inspection](hoi4-agent://workspace/mod_chaos_redux_ea3b2d67c2c0/artifact/bb1e773eb20a6fd4c9ab0ed6c288cecdc540c8619c5c36e799a058a3da8e52a5/8a3d139190f6a008cd695b9c4338140be06eea6dd9af5e1da2fab7af699de2b6/probability-inspect-352985f03451.json) at revision `bec5719fffd89278` resolved the candidate list but not eligibility or selection probability without technology/project state. Focus inspection reached the UWR source at revision `5cda4697cdbbf69a`, and event traces for the downstream safety chain were partial at `c1123483b63f`. The reference MCP routes were not exposed in that audit; the offline Effects and Focus modding wiki sections and installed vanilla special-project and effect documentation were read locally. No gameplay files changed in this original audit.
