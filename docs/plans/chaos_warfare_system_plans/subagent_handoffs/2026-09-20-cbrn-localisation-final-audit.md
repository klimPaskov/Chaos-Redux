# CBRN localisation closure, 20 September 2026

Scope: English CBRN, chemical, biological, and linked event text. This handoff records a bounded source audit and the localisation edits below. It does not claim live-game visual or runtime validation.

## Patch and display change

- Deleted `localisation/english/cbrn_battlefield_operations_l_english.yml` (37 keys). Its former agent selector and five decision attacks had no live decision consumer after `common/decisions/cbrn_battlefield_operation_decisions.txt` was removed. Old icon sprite names in `interface/cbrn_battlefield_operations.gfx` are asset references, not localisation consumers.
- Deleted `localisation/english/biological_sabotage_l_english.yml` (25 keys). Its old decision attacks had no live decision consumer after `common/decisions/biological_sabotage_decisions.txt` was removed. Native sabotage raids use `biological_sabotage_raids_l_english.yml` keys.
- `cbrn_designers_l_english.yml`: `cbrn_medical_respiratory_care` now displays **Respiratory and Burn Care**; its tooltip continues to state both 15% choking-agent and blister-agent death reductions. Removed unreferenced `cbrn_medical_burn_treatment` and `cbrn_medical_burn_treatment_tt`. Parent accepted one combined node within the exact 12-node biomedical MIO, and `common/military_industrial_organization/organizations/cbrn_biomedical_organizations.txt` consumes the combined key. Other concurrently edited values in this file belong to their owners.
- `cbrn_chemical_delivery_l_english.yml`: shortened `choking_chemical_air_payload_desc`, `blister_chemical_air_payload_desc`, `nerve_chemical_air_payload_desc`, and `incapacitating_chemical_air_payload_desc`. Before: “exact raid-reservation archetype” implementation language. After: identifies sealed agent-class loads, chemical air raid use, and the current payload profile. Agent distinctions remain intact.
- `cbrn_doctrine_l_english.yml`: removed obsolete offensive Headquarters preparation-time lines from `cbrn_theater_contamination_doctrine_spirit_tt` and `cbrn_terminal_hazard_doctrine_spirit_tt`, coordinated with the HQ owner removing that posture and its constants. Rewrote both full spirit tooltips and descriptions after a parent screenshot review found the terminal tooltip's internal accounting disclaimer visible. The terminal tooltip fell from roughly 2,000 characters and 14 numeric bindings to 881 characters and five decision-relevant bindings. It now states chemical deaths, biological deaths, Command Power refund, existing camp deaths under Unrestricted Authorization, and lower Condemnation alongside the greater harm. The theater tooltip is 693 characters with four bindings for dose, biological deaths, refund, and cleanup. The neighboring Hazard Assault Cadres description no longer explains that it grants no payload.
- `cbrn_mio_redesign_l_english.yml`: shortened six visible organization names to fit the narrow MIO title area: `cbrn_chemical_protection_consortium` → **Chemical Protection Works** (25 characters), `cbrn_biomedical_industry_directorate` → **Biomedical Directorate** (22), `cbrn_delivery_engineering_bureau` → **CBRN Delivery Bureau** (20), `cbrn_ici_organization` → **Imperial Chemical** (17), `cbrn_advanced_containment_institute` → **Containment Institute** (21), and `cbrn_strategic_delivery_authority` → **Strategic Delivery Office** (25). Their descriptions retain the complete institutional meaning, including the full Imperial Chemical Industries name. The other five national organization names are 6–13 characters and were left unchanged. No `docs/*.md` file quoted the old exact names in the scoped search, so no documentation text was changed.

No new scripted localisation was added. The two doctrine tooltip rewrites intentionally removed several secondary numeric bindings while retaining their effects in direct prose; native idea modifiers also show attrition and supply use. The retained values use dynamic constants and whole-percent formatting. Other existing variables, scripted-localisation calls, costs, and attributed quotations were not altered. None of the edited passages contains a sourced quotation.

The biomedical MIO's combined treatment text matches its single trait consumer. The spreadsheet owner should mirror **Respiratory and Burn Care** if a catalog field names the medical node; no workbook was edited.

## Prose findings

- Vagueness: the retained `cbrn_occupation_l_english.yml` protective-aid description says “civilian ledger”; a player-facing description should describe masks reaching civilians. This file was not changed because occupation mechanics are outside this patch.
- Bloat and repetition: `biological_sabotage_raids_l_english.yml` still has 12 highly repetitive base/theater/terminal descriptions. Its eight outcome tooltips were concurrently rewritten by the raid owner to remove lifecycle jargon and balance notes, so that result wording is no longer an unresolved item.
- Obvious explanation and style: the four air-payload descriptions' “archetype” language was fixed. The obsolete Headquarters preparation lines and the terminal doctrine's accounting and camp-unlock disclaimers were removed. The Hazard Assault Cadres description now states its effect directly.
- Overcomplication: the live occupation nerve-suppression requirement strings carry dense multi-condition lists. A separate occupation owner should preserve all requirements while splitting visible conditions from background implementation terms.
- No em dash, semicolon, or quote normalization was introduced. Secondary doctrine numeric bindings were reduced for legibility while their gameplay consequences remain described; this was part of the parent's explicit concise-tooltip request.
