# Timed respirator decision audit

**Disposition:** implementation source reviewed; no gameplay files changed. User-approved behavior is to quote and reserve the calculated respirator crates at selection, then return unused crates on cancellation or target invalidation. The reservation helpers and lifecycle paths below implement that behavior in source. The backend contract is documented in [the reservation implementation handoff](2026-09-25_timed_mask_reservation_backend_implementation.md).

## Findings by severity

- **Medium — confirm the cost-type ceiling treatment.** The UI presents Political Power, one aggregate respirator-crate amount, and civilian-factory use in [the occupied cost row](../../../../localisation/english/cbrn_protection_l_english.yml#L81) and [the aid cost row](../../../../localisation/english/cbrn_occupation_l_english.yml#L31). The reservation effect can debit five separately tracked equipment stockpiles: reconditioned and gas-mask equipment models 1–4 ([cbrn_protection_effects.txt](../../../../common/scripted_effects/cbrn_protection_effects.txt#L1116)). Thus the mechanic has six consumed stock types including PP, or seven cost/commitment types if the two-factory allocation is counted separately. The generic mask icon and single crate total are a coherent player-facing abstraction, but the strict four-cost rule needs an explicit interpretation or accepted exception. If each concrete stockpile ID counts separately, reduce the paid resource set to four or fewer types; do not silently treat the five model IDs as one type in the cost audit.
- **Category density — no issue.** The two protection categories each define exactly six decisions: program management starts at [line 39](../../../../common/decisions/cbrn_protection_decisions.txt#L39), and civil defence starts at [line 256](../../../../common/decisions/cbrn_protection_decisions.txt#L256). The occupied program belongs to civil defence; no category has more than six decision entries, and no other decisions attach to these categories.

No source-level blocker was found in selection-time quoting, PP thresholds, crate escrow, concurrent external-aid targets, completion/cancellation, or control-transfer refunds.

Cancellation closes the count and refunds. Both PP gates are inclusive: exactly 25 qualifies, below 25 does not. The shared PP debit helper subtracts the same 25-point constants displayed in the decision rows; `ai_hint_pp_cost` is also 25. Factory gates, modifiers and displayed values all use two. Partial stock is supported: the row reports the available capped quote, selection reserves no more than live stock, and completion can distribute only those receipts. PP remains spent after cancellation when a positive shipment was reserved; the tooltip accurately says it is committed at selection and explicitly promises crate refunds, not PP refunds.

The occupied program’s quote and reserve traverse the same currently eligible states and model order. Aid uses its selected state and donor stock. There is no second stockpile debit on completion: both delivery wrappers read the receipt variables and refund unused balances. A stock change between rendering and selection can change the live quote; the selection effect is authoritative and records the actual reservation.

## Visibility, concurrency, and player-facing clarity

The aid decision’s `target_root_trigger` allows either a new shipment-capable donor or a donor with a positive active-reservation count; its target/visible checks retain the already-funded state rows when stock or factories are no longer available ([decision lines 320–341](../../../../common/decisions/cbrn_occupation_decisions.txt#L320), [category visibility trigger](../../../../common/scripted_triggers/cbrn_occupation_triggers.txt#L59)). A state cannot accept another aid reservation while either the timed project or external-escrow flag exists ([state eligibility](../../../../common/scripted_triggers/cbrn_occupation_triggers.txt#L514)). Different states may be funded concurrently from the remaining free stock.

The count lifecycle is idempotent per target: registration requires an active escrow and no counted flag, then increments the donor country count; close requires that target’s counted flag, decrements the recorded donor, clamps at zero and clears the flag ([cbrn_occupation_effects.txt](../../../../common/scripted_effects/cbrn_occupation_effects.txt#L102)). Completion, cancellation and control transfer close it before any refund clears the donor pointer. A later timed cancel therefore cannot double-decrement or double-refund. The newly added independent “already has external escrow” guard is present at [cbrn_occupation_triggers.txt:517](../../../../common/scripted_triggers/cbrn_occupation_triggers.txt#L517), so target validity does not rely solely on the timer flag.

Both cost strings use PP, mask-equipment and factory texticons; no resource label is written as plain prose. The tooltips explain selection commitment, factory duration, crate return conditions, duration and completion effects. Values have clear meanings. The category descriptions are static summaries, and the occupied tooltip accurately separates spendable PP/crates from ongoing factory allocation. There are no active goal missions here beyond the two targeted timed decisions. The aid’s AI modifier refers to the selected `FROM` state’s core, owner’s faction, and trauma; the occupied-program weight is country-wide and checks occupied work plus eligible contaminated/high-population states. Source structure is valid for those scopes. Numerical AI evaluation/comparison remains with the parent’s separate probability audit; this report makes no balance claim.
