# Timed respirator reservation backend handoff

Disposition: **implemented backend; integration queued**. The accepted selection-time reservation design is implemented only in the shared protection effect/trigger files owned by this subagent. Decision definitions, occupation effects, transfer callbacks, cost-row localisation, and final validation belong to the parent and are not implemented here. The explicit user decision on 2026-09-25 is the acceptance basis for reservation, exact displayed payment, refunds, and no second stock debit. This patch has no fallback distribution route for these two timers.

## Files changed and public contracts

- `common/scripted_effects/cbrn_protection_effects.txt`: added state-scoped per-model reservation, two idempotent refund effects, two reserved-distribution wrappers, and an escrow branch in each of the five model steps of the existing distributor. Ordinary nonreserved distribution continues through its original stock debit branch.
- `common/scripted_triggers/cbrn_protection_triggers.txt`: added pure live-ledger state quote and stock cap helpers, the national occupied-program quote, and a live-ledger occupied target predicate. `cbrn_country_has_occupied_distribution_work` now uses that predicate.
- `common/scripted_effects/cbrn_scripted_effects.md`: documents helper purpose, scopes, inputs, outputs, defaults, side effects, receipt model, and usage.

Country-scope trigger `cbrn_quote_occupied_program_mask_reservation` needs no input and outputs temporary `cbrn_mask_reservation_quote`: the sum of each eligible controlled non-core state's rounded need, capped at actual national stock of the five concrete models. It uses `all_controlled_state` with an `if` per state so the loop cannot short-circuit at an ineligible state. State-scope trigger `cbrn_quote_external_state_mask_reservation` needs paying country `ROOT` and outputs the same temporary variable, capped to one target state's need and donor stock. State-scope `cbrn_quote_occupied_state_mask_reservation` outputs uncapped temporary `cbrn_reservation_quote_state_need`. Both state quotes use current population, five existing civilian model ledgers, fitting points, filter condition, local delivery factors, donor program/design modifiers, and per-state rounding; they do not read effect-only snapshots. Cost-row localisation and effect `if.limit` callers should initialize their output temp before calling a scripted trigger, because the offline Data structures reference notes that temps created inside a scripted trigger may not survive its boundary. No trigger is callable as a standalone effect.

State-scope trigger `cbrn_state_can_reserve_occupied_masks` combines controlled non-core emergency validity with a positive live-ledger quote. The country work gate now uses it. Parent start marking should use it too; `cbrn_state_can_receive_occupied_masks` still reads stored effective coverage and could disagree with the payment quote.

State-scope effect `cbrn_reserve_requested_masks_to_state` takes temporary `cbrn_mask_escrow_requested` (integer quote/allotment) and `cbrn_mask_escrow_external` (zero for occupied program, one for aid). The paying country is `ROOT`. It debits the five concrete models in reconditioned/basic/improved/advanced/sealed order, writes five persistent state receipts under `cbrn_occupied_mask_escrow_*` or `cbrn_external_mask_escrow_*`, saves the donor country as `cbrn_occupied_mask_escrow_donor` or `cbrn_external_mask_escrow_donor`, and sets the corresponding state active flag. Temporary `cbrn_mask_escrow_completed` is the actual number removed. An existing active receipt of the same kind blocks reentry. The caller must require a positive completed value before considering the project paid and must not infer it from the cost-row text alone.

State-scope `cbrn_refund_occupied_state_mask_reservation` and `cbrn_refund_external_state_mask_reservation` take no input. They return each unused model to the stored donor and clear its amount, pointer, and active flag. Output `cbrn_mask_escrow_refunded` is the returned count; `cbrn_mask_escrow_refund_blocked` is one when an active receipt has no existing donor. In that case the receipt stays in state rather than crediting another country. Repeated calls after a completed refund have no equipment effect. A country variable used as scope is supported by offline Data structures and existing Chaos Redux `var:... = { ... }` country-scope precedents; exact runtime behavior still needs the parent’s final validation.

State-scope `cbrn_distribute_reserved_occupied_masks_to_state` and `cbrn_distribute_reserved_external_masks_to_state` consume only their matching five receipts. Both require the four existing distribution temporary inputs: `cbrn_distribution_target_fraction`, `cbrn_distribution_base_cost_mult`, `cbrn_distribution_effectiveness_mult`, and `cbrn_distribution_new_filter_condition`. They recalculate need and preserve the common distributor's five-model order, civilian model totals, fitting points, filter condition, replacement demand, country totals, and achievement proof. They then refund unused models. Outputs are existing `cbrn_distribution_consumed_crates`, `cbrn_distribution_usable_crates`, and either `cbrn_reserved_distribution_proof` or `cbrn_external_distribution_proof`. The occupied wrapper requires the state still be controlled by the original donor `ROOT`. The external wrapper uses its state donor pointer and does not read current free stock. The caller must check current target validity before invoking either wrapper; invalid targets should call refund directly.

## Parent integration order

1. In the occupied decision cost row, compute `cbrn_quote_occupied_program_mask_reservation` from the paying country. In the aid target row, compute `cbrn_quote_external_state_mask_reservation` in the `FROM` state with donor `ROOT`. Bind `[?cbrn_mask_reservation_quote|.0]` to the respirator icon beside the existing Political Power payment. The offline Decision modding page says a custom row does not debit and cannot be combined with native cost, so parent moves PP into the custom payment and debits it manually once. The `condemnation_response_costs.txt` scripted-localisation pattern is the repo precedent.
2. On selection, recalculate the same quote in an effect `if.limit`, then call `cbrn_reserve_requested_masks_to_state`. The country program iterates the same eligible controlled states and requests each `cbrn_reservation_quote_state_need`; real stock depletion automatically bounds later states. For aid, call once on the selected state. Only charge PP and set project markers after a positive `cbrn_mask_escrow_completed` receipt. Preserve partial-stock behavior.
3. In `cbrn_complete_occupied_state_distribution` (owned by parent in `cbrn_protection_decision_effects.txt`), keep its existing distribution inputs and positive-delivery resistance/compliance guard, but invoke `cbrn_distribute_reserved_occupied_masks_to_state` for an active occupied receipt. In the external aid owner, invoke `cbrn_distribute_reserved_external_masks_to_state` and keep the existing positive-delivery history/opinion proof. Neither parent completion path may call a free-stock debit after receiving a reservation.
4. Cancellation invokes the matching state refund before clearing markers. The occupied program loops receipt-bearing states, including states that no longer match the original eligibility trigger. On state control change, invoke both refund helpers for receipt-bearing states in a separate branch that is not gated on preexisting civilian-mask crates or `fallout_world_rewrite_callbacks_are_allowed`. Run this before `cbrn_transfer_state_civilian_mask_ledger` clears the occupied target flag. Split the in-flight cancel predicates from start affordability so zero free stock and committed factories do not self-cancel.
