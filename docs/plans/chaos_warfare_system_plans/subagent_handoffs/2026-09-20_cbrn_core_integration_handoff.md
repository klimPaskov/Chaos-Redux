## Current implementation

The only national policy decisions are `cbrn_choose_retaliation_only`, `cbrn_choose_battlefield_authorization`, and `cbrn_choose_unrestricted_authorization` in `common/decisions/cbrn_doctrine_decisions.txt`. Each displays the same five-Command-Power custom cost row, uses the same affordability trigger, debits five Command Power only after `cbrn_set_use_policy` accepts the choice, and starts `cbrn_doctrine_policy_reassessment` for 90 days. The policy cost constant now has only those three live keys. Doctrine milestones grant capabilities without setting policy; initialization retains numeric legacy-policy normalization for compatibility. Localisation in `localisation/english/cbrn_simplification_l_english.yml` describes the current three policies and shows the cost only in the decision cost row, not again in the category description.

`cbrn_refresh_country_mask_snapshot` derives military coverage, shortage, and Chemical Readiness from actual issued masks, filter condition, decontamination capacity, and training. `cbrn_run_protection_maintenance_cycle` services filters and issues military masks first, then distributes civilian masks when a chemical threat, state alert, contamination, or historical 1939 issue warrants it. The country-owned `cbrn_protection.1` event reschedules at the 30-day constant and performs annual loss on every twelfth cycle; there is no new global daily, weekly, or monthly country iteration. The Civil Defence category appears for an actual chemical emergency, enemy chemical capability, or active biological outbreak, rather than simply because a country owns masks or has an old civilian-distribution flag.

At the 1936 British bookmark, `chaosx_apply_starting_cbrn_mask_profiles` suppresses the fixed ENG warehouse grant and all civilian distribution before calling `chaosx_apply_historical_eng_1936_force_scaled_profile`. That idempotent country helper derives a real basic-mask grant from deployed military requirement, issues 75% through the ordinary military stock-debit helper, and retains a 25% force-scaled replacement reserve. The historical startup worker applies the same real-stock reconciliation to the remaining 1936 profile tags, assigning 75% to established majors, 100% to Italy, 50% to Japan, and 25% to the smaller defensive group, with a separate 25% reserve in each band. The later 1939 bookmark keeps the separate dated common stock profile. Its hidden `cbrn_protection.3` event restores ENG as country `ROOT` for the one-time civilian issue after startup history's bounded country selector. `cbrn_apply_historical_uk_1939_civilian_issue` compares the historical 40,000-crate civilian target with already issued state ledgers and controlled core population, uses remaining warehouse masks first, grants only the gross stock shortfall as real basic mask equipment, and uses the ordinary state distributor to debit equipment and credit civilian masks. The receipt flag prevents double grant.

The HQ capability triggers use the three surviving Operations, Protective Logistics, and Medical Countermeasure roles. The retired separate land-preparation and launch decisions, their event file, and the orphan readiness-recovery event are gone. `chemical_warfare_effects.txt` retains only tactic sync, while `cbrn_battlefield_operation_effects.txt` classifies native land raid route and agent receipts. `cbrn_exposure_effects.txt` now grants the armored project benefit only from the native actor-country armored marker, exact target event target, matching actor, route, target-supplied proof, and paid payload proof. The dead `cbrn_battlefield_active_*` country/state ledger gate was removed without changing the residual 0.50 hazard floors.
