# Native chemical land raid contract audit — 2026-09-26

**Disposition:** Implemented source evidence for the 55 land definitions; native creation, cancellation, refund, and engine outcome behavior remain unverified.

The installed `common/raids/_documentation.md` says `essential_equipment` is required to create a raid and collected after creation. It documents raid-instance outcome callbacks and their actor, victim, state, and province variables, but no creation, cancellation, or refund callback. Vanilla `common/raids/naval_commando_raids.txt` and `nuclear_raids.txt` use native essential equipment as the creation cost. The Chaos Redux [native-raids skill](../../../.agents/skills/chaos-redux-native-raids/SKILL.md) owns the scope and payment contract used here.

A read-only definition-level audit of `common/raids/cbrn_chemical_land_raids.txt` found 55 exact-weapon entries: ten cylinder or Phantom Mist, nine projector, nine artillery, and 27 armored variants. All 55 use `chemical_raids`, a supply-node starting point, a state target, an assigned-unit requirement, native `essential_equipment`, and four native outcome levels. Every outcome calls `cbrn_land_raid_bridge.1` once, records a raid history entry, and applies its declared unit-damage effect. No definition contains an additional equipment block or a scripted stockpile debit. The category file uses army intelligence for both `chemical_raids` and `biological_raids`.

A second read-only crosswalk checked all 220 outcome callbacks. For each of the 55 definitions, the four callbacks carry the agent and delivery-route markers implied by its ID, one distinct failure/limited/success/critical marker, one Phantom Mist marker, and exact actor, state, and victim event targets. The hidden `cbrn_land_raid_bridge.1` event requires exactly one route, agent, result, and Phantom Mist marker before it invokes `cbrn_resolve_chemical_land_raid_country_outcome`. That resolver accepts only the three successful outcome classes, rechecks the exact target and policy, records native payload consumption as proof, and does not debit or refund stock itself. Artillery's 121 reserved shells include the separately documented 120-shell payload plus one support shell.

The neighboring category inventory found 145 `chemical_raids` or `biological_raids` definitions across twelve files. Each has a native target, starting point, `ai_will_do` block, and `success_levels` block; no raid definition directly adds or removes stockpile equipment. Of the 145, 144 have native `essential_equipment`. The one exception is `zombie_cure_strike`, a cure-delivery capability unlocked by the `zombie_cure_bomb` special project. It requires ten Command Power, an assigned bomber wing, an active cure, and a valid affected target; the mod defines a cure-bomb icon but no stockpiled cure-bomb equipment archetype. The [anti-zombie bomb system](../../systems/cbrn_warfare/biological_warfare/zombie_anti_zombie_bombs.md) describes this capability route. This inventory proves only the presence of AI selection blocks, not their weights, choice probabilities, or execution behavior.
