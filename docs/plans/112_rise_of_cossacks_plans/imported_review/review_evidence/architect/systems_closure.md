## Deterministic cost classification

Part 03 section 7.1 is authoritative.
Every existing scripted component has one size class, with Flat as the default.
Sadmin, Sstate, and Sarmy are never multiplied together.
Classification does not create a fee.

| Component | Accepted size treatment |
|---|---|
| A01 civilian founding bridge | Flat 35 PP base |
| One-off workshop or admitted bridge alternative | Flat 60 PP administrative base, native construction or conversion stays native |
| A27 extension | Flat 20 PP base |
| Actual negotiated arms consideration | Flat agreed base with delivery-owned escrow |
| A14 and E04 explicitly targeting one named state | Sstate applies to their administrative PP component only |
| Charter ratification or reform, national and federal congress, constitutional or consolidation acts, and default national first-peace administration | Sadmin applies only to the existing PP fee |
| M01 and M04 | Sarmy applies only to the existing Army XP component |
| M02, M03, M05, M06 and other per-formation XP fees | Flat unless a later explicit accepted row changes the class |
| Scripted CP | Flat, with the complete final action requirement limited to 60 CP |
| Stated equipment, manpower, fuel and material delivery | No size multiplication of the physical quantity |
| Native-owned allocations, costs and refunds | Entirely native pipeline, no second scripted quote or debit |
| Every other unlisted component | Flat |

Specific named rows take precedence over broad administration.
Original more specific P, GP, or E04 promise ownership also takes precedence over a default national review.
A true scripted price then receives only its eligible ordinary modifiers and already-authorized J integration adjustment, followed by the shared source composition and one upward quantum.
Flat is not a blanket exemption from those existing quoted-price rules.
Physical obligations and native operations retain their actual distinct ownership and do not become larger deliveries because a separate price changed.
Mission time, native manpower requirements, training, construction and physical objectives are not scaled by the three size factors.

A final scripted quote of 61 CP, or a combined final CP requirement above 60 for one action, blocks that action before any component is paid.
It is neither silently clamped nor overcharged.
Native CP is inspected through the native pipeline without inventing a second shared quote.
