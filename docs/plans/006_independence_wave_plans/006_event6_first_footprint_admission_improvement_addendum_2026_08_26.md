## Decision

Event 006 is not ready for closure.

The accepted design promises a worldwide independence wave, but the current playable boundary is geographically concentrated: nine content-attested packages are in Northern and Western Europe, eight in the Balkans and Danube, four each in Mediterranean/Iberia and Eastern Europe, three in the Caucasus, two in Volga/Urals/Siberia, and one each in the Americas and Southeast Asia/Oceania. There is no content-attested selectable package in six accepted regions: Levant and Arabia, North Africa and Sahara, West and Central Africa, East Africa/Great Lakes, Southern Africa/Indian Ocean, and South Asia/Himalaya.

The next expansion should therefore be a bounded six-row **first-footprint cohort**:

1. IW-095 Dahomey.
2. IW-108 Buganda.
3. IW-136 Sindh.
4. IW-130 Madagascar.
5. IW-086 Tripolitania.
6. IW-073 Hejaz.

This cohort gives each presently empty region one serious playable package without adding a new global mechanic, a new focus tree, a fallback identity, or a substitute map binding. It connects existing registered candidate rows to the accepted survival, government, former-host, Network, League, shared-focus, and regional-formable systems.

IW-095 is the first implementation handoff. It has the cleanest map contract: registered carrier `DAH`, dedicated current state 776 Dahomey, reservation group `RG-NIGERIA-COARSE`, a distinct French former host, and no protected-capital or shared-tag ambiguity. Its identity, portrait, and symbol evidence still must be cleared before central admission.

No gameplay, localisation, asset, spreadsheet, or spec file is changed or authorized by this addendum.

## Playable package contract

Each row must ship as one atomic package. Package setup must initialize the accepted shared Statehood values, improvised-government/recognition/command/border/patron ideas, force archetype, former-host pointer, cleanup generation, and full shared-focus framework or reviewed carrier overlay. Package-local mechanics deepen the row without creating six new global systems.

### Common lifecycle

1. The central transaction reserves the exact tag, anchor, optional territory, reservation group, and living former host.
2. The package setup installs one opening identity, a source-cleared roster, a bounded force package, the shared survival category, and one package-specific founding mission.
3. Four serialized projects raise shared administrative capacity, security, public legitimacy, recognition, or regional reach. At most one paid package project may run at a time.
4. Three mutually exclusive government settlements resolve the founding conflict: civic/constitutional, traditional/institutional, or emergency command. Patron-client content remains the accepted shared route and is not duplicated.
5. One former-host settlement and one regional Network corridor connect the package to shared Event 006 systems.
6. The package may register its accepted formable family, but the formable reveal and proclamation remain fail closed until that family has its own complete territory, member, identity, AI, asset, cleanup, and GUI evidence.
7. Annexation, civil war, route replacement, sovereignty loss, formable absorption, generation mismatch, and invalid former host clear missions, temporary ideas, targets, invitations, and package variables.
