# ============================================================================
# CHAOS REDUX - EVENT 006 REGIONAL FRAMEWORK FOCUS GROUPS A
# ============================================================================
# Overview:
# - Defines country-specific shared-focus groups for the first 22 admitted
#   Level 2 regional framework packages: CUX, IMO, LEB, PAL, RIF, DSX, DUX,
#   UGA, RWA, BRD, HAR, SOM, TIG, BAR, MAD, FDX, SIN, BLC, PSH, KAS, HYD and MYS.
#   The parent-owned full Event 006 tree imports these roots and descendants.
# - Each group uses the live regional framework generation and original tag.
#   Project focuses call the exact completion effect already used by the paid
#   decision, and bypass when that project's result already exists.
# - Three-project packages receive a paid, 70-day, host-policy support focus
#   and a regional integration capstone after their three project focuses.
#   Four-project packages receive their four project focuses and the same
#   one-time regional integration capstone.
# - No static X-tag runtime scopes, new icons, or separate country trees are
#   used. No focus grants a project result when its paid decision is in flight.
# ============================================================================
