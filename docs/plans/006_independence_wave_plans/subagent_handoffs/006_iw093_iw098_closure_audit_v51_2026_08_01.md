# IW-093 DOX / IW-098 SOK portrait and package closure audit v51

Date: 2026-08-01.

Scope: bounded source, provenance, portrait-gate, flag, ownership, and runtime-completeness audit for the grounded male leader and commander packages of IW-093 (DOX) and IW-098 (SOK). This audit does not generate art, admit a fallback, edit gameplay, edit `.gfx`, convert DDS, or launch Hearts of Iron IV.

## Disposition

No requested grounded portrait package is admitted as complete.

The current evidence supports one provenance-ready DOX leader source, but its source-locked HOI4 repaint still fails the visual identity gate. All DOX commander identities remain blocked because the named identities are invented/generated and no face-visible, redistribution-clear, named Asante commander source was found. All SOK leader/commander closure paths remain blocked by rights, date, identity, or source-integrity gaps. Existing DDS and sprite registrations are therefore non-admitted runtime artifacts and must not be treated as clearance evidence.
