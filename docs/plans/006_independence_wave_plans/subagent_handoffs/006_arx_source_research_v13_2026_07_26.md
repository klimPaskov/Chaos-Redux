# Event 006 ARX source research v13

Date: 2026-07-26

Status: **PARTIAL / crown role blocked**.

This bounded research pass rechecked the missing Sardinian crown/council role
and a Sardinia-linked commander lead. It did not process images, edit gameplay,
promote a package, or authorize runtime wiring.

## Findings

1. Adalberto di Savoia-Genova cannot be reused as a free ARX portrait subject.
   The installed vanilla files own `ITA_prince_adalberto`, including its
   character definition, history recruit, and portrait registration. Cloning
   or transferring that live vanilla character would violate the Event 006
   origin/ownership rule.
2. No rights-clear, non-vanilla replacement for the ARX crown/council role was
   established in this pass. The current fictional `ARX_vittorio_pala` portrait
   therefore remains an unadmitted grounded-polity treatment, and IW-018 stays
   outside compile-time content attestation.
3. A new commander lead is source-ready for a later bounded treatment:
   Cagliari-born Gen. Giuseppe Pizzorno (1891-1980), active in the 1936 setting
   through East Africa command and later Brigade Sassari/Chief of Staff work.
   Wikimedia Commons `File:Giuseppe Pizzorno.jpg` is 145x160 and records
   `PD-Italy` and `PD-1996` with an L'Unione Sarda source. This is a research
   lead only; it has not been cropped, repainted, reviewed, or wired.
4. The already preserved Vittorio Vernè source remains a viable commander
   candidate because the prior source audit records Commons `PD-Italy` and
   `PD-1996` and a Sardinia-linked 176th Legion command connection. Vernè is
   not claimed to be Sardinian-born.

## Admission boundary

The ARX package requires a complete sourced male roster for every live
leader/commander role, plus independent visual/provenance audits and a parent
country-package re-audit. No source lead in this handoff changes that gate.
Do not create DDS files, add `.gfx` sprites, replace the fictional crown
portrait, or add Pizzorno until the crown role is cleared and the full package
is rechecked.
