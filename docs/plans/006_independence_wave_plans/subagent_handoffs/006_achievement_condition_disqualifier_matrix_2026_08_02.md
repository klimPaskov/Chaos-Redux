Date: 2026-08-02

## Shared eligibility and provenance gate

Every visible Event 006 achievement uses `independence_wave_achievement_eligible_tooltip` for its `possible` block and its specific `independence_wave_achievement_*_is_complete` trigger for `happened`. The sovereign-actor family requires an active Event 006 country, no subject status, no capitulation, a controlled capital, and no historical subject-status flag. The two IW-058/CHU achievements add their own package, original-tag, recognition, origin-separation, route, and state-proof gates rather than accepting a reused tag by name alone.

## Static receipt

The matrix contains 16 unique `chaosx_006_*` definitions, 16 unique completion-trigger references, one shared eligibility gate, and the four hidden achievement rows required by the source design. The existing custom achievement parser confirms that all 16 definitions resolve to unique trigger blocks. This receipt does not promote the catalog status, prove runtime unlock behavior, or replace the still-required focused GUI/consumer checks.

## Maintenance rule

When an achievement condition, disqualifier, threshold constant, writer flag, or hidden/visible status changes, update this matrix and the matching localisation and achievement audit handoff in the same change. Do not weaken a negative condition to make a row easier to satisfy, and do not infer a live witness from this source-level receipt.
