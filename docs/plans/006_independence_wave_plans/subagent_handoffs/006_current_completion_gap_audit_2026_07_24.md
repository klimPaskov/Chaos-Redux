## Planner readiness defect

Region 1 package wrappers apply the runtime automatic-readiness trigger, which includes the compile-time content gate.

Several later regional `can_plan` definitions instead test only exact identity, origin safety, or package-local conditions.

The planner then computes evolution-dependent weights in `common/scripted_effects/006_independence_wave_package_planner_effects.txt` and commits a reservation without reapplying the common content gate.

The execution path in `common/scripted_effects/006_independence_wave_execution_effects.txt` later rejects the selected package because its adapter/content attestation is absent.

Because the release is synchronized and fail-closed, one such reservation rejects the entire wave rather than merely skipping that package.

The same common readiness predicate must govern capacity witnessing, weight eligibility, reservation, scenario selection, and execution.
