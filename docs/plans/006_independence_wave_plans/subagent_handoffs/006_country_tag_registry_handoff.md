## Scope

Event 006 candidate registry without pretending that a registered tag is a
playable package. It supplies dormant map-color/culture shells and final public
country-name localisation only where the accepted research establishes a safe
public identity. Runtime selection remains controlled by the separate
`independence_wave_package_content_ready` gate.

## Readiness contract

No country in this tranche receives
`independence_wave_package_content_ready`. That flag may be granted only after
the package has all of the following wired and audited:

- accepted identity and territorial binding;
- political authority, leader, and command roster;
- sourced or generated final flags and required portraits with provenance;
- dynamic starting-force mapping and materialization;
- Event 006 ideas and visible values;
- full Event 006 tree for a new X tag, or safe additive overlay for a reused
  registered tag;
- package AI, diplomacy, former-host relation, regional ambition, routes, and
  formable access;
- complete player-facing localisation and all required assets.

This keeps registration from becoming permission for shallow bulk content and
makes every incomplete or sensitive package fail before allocation.
