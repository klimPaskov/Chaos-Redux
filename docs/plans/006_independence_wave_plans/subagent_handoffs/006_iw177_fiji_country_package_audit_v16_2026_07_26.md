# IW-177 Fiji country-package audit (v16)

## Scope and status

This is a read-only country-package audit for the accepted distinct-group alternative `IW-177` (Fiji, `FIJ`). No gameplay, localisation, GFX, map, or vanilla files were changed. The audit used `AGENTS.md`, `chaos-redux-subagents`, `chaos-redux-events`, `hoi4-focus-trees`, `hoi4-decisions-missions`, and `chaos-redux-event-assets`, the required offline Paradox wiki pages, and the relevant installed vanilla country/state/history and documentation files.

**Result: FIJ is structurally valid in registry and map terms, but it is not a runnable or attested Event 006 country package.** The accepted identity remains a founding congress that negotiates representation, veto, autonomy, revenue, and defense clauses before any wider island federation. The package must distinguish chiefly and communal authority, colonial administration, labor, shipping, and defense interests. No generic or invented leader, portrait, flag route, or shallow copied package should be admitted.

## Map, politics, military, industry, supply, and playability risks

- **Map safety:** The single compact state is safe on the installed map. `ENG` must retain a protected remnant and capital `126`; no extension should be added without a new host-capacity and collision audit. The reservation group already blocks FIJ/SAM/FSM automatic co-admission.
- **Leadership:** Vanilla FIJ has no leader or OOB. The source dossier is a hard blocker because a grounded male-only package cannot use a generated generic portrait, an opposite-gender name pool, or an invented historical claimant. An institutional name is valid only when the body is genuinely collective and the image is authentic and attributable.
- **Politics:** The vanilla democratic 50/neutrality 38 baseline is not a FIJ Event 006 identity. The package needs a visible founding-congress settlement that can trade representation, veto, autonomy, revenue, shipping, labor, and defense authority without treating chiefly, communal, colonial, and labor institutions as one generic faction.
- **Forces:** The generic mapping is already exact and should be consumed rather than re-authored: `coastal_maritime`, tradition 53, `p177` reinforcement mask 659, navy inheritance only, and no air inheritance. The runtime must create non-empty coastal/local infantry forces and a proven officer/command roster, then expose the mapped reinforcement paths.
- **Technology and supply:** The vanilla baseline is intentionally small: one infantry-weapons level, 20 convoys, infrastructure 2, one naval base, no OOB, and no FIJ production lines. The package must explain how inter-island depots, signals, maintenance, fuel, convoys, and port loss affect play, while avoiding an unsupported air or industrial windfall. The installed package currently exposes no Technology Tree Viewer, so technology-tree rendering/inspection remains an unresolved limitation.
- **AI:** No FIJ AI strategy exists. Without survival/restraint/host-threat weights, FIJ can stall in a one-state island start or take suicidal wars before the congress and shipping systems mature.
- **Formables:** FORM-39's registry profile (`minimum_members = 3`, `minimum_consents = 3`, `minimum_anchors = 3`, low AI willingness) has no dedicated carrier/member transaction. FORM-48's exact founding ledger is HBX/HAW/FSM-only. FIJ must remain outside both until a named, consent-led adapter and route identity are implemented.
- **Event 005:** Current guards are origin-safe, but the final FIJ package must participate in the same frozen reservation and final-live-revalidation barrier. Do not rely on a delayed event target or a FIJ-only exclusion; the joint coordinator owns ordering and rollback/recovery evidence.
