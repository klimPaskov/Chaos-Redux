## Executive result

The current IW-013 NAV source package is substantially wired at the adapter level, but the package is not safe to admit. No gameplay patch was applied because the remaining failures are central attestation, living-tag/preflight, rights/provenance, and unavailable runtime-evidence gates rather than an unambiguous local NAV reference defect.

The apparent research-state conflict is a documented split rather than permission to guess: historical traceability is state 172, while the installed compact runtime anchor and vanilla NAV capital are state 792; states 172 and 806 are optional NAV-core extensions. The source package consistently uses 792 for the compact release anchor, but live map rebind and ownership/controller evidence could not be obtained because both required map MCP calls returned `Transport closed`.

The strongest admission blockers are that `iw_013` is absent from the central content-attestation allowlist, normal preflight requires a dormant candidate while vanilla NAV is a living country owning 792, the shared Join attestation list omits `iw_013`, route flags remain generated alternate-history synthesis with rights review open, and the Aguirre portrait has unresolved current-runtime versus historical-evidence provenance/hash terminology. These gates must be resolved by the parent and the owning rights/portrait workers; this audit does not relax them.
