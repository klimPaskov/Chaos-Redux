## Scope and behavior

The tranche contains 22 package-gated shared-focus groups and 110 focus definitions: one paid-project opener, two compatible paid-project branches, one paid former-host reinforcement, and one regional-congress action.

Each opener is positioned relative to `independence_wave_overlay_take_stock_of_independence` at x=3/y=6, with the accepted full-tree x=-35 offset. Its two project children sit at x=-1/+1 on y=1, the host reinforcement at x=0/y=2, and the congress cap at x=0/y=3 relative to the opener.

The three paid-project focuses call the package's existing `independence_wave_<tag>_complete_<project>` helper and use its existing result flag. Their available triggers block while that same paid decision is active, and their bypass activates after the paid receipt is set.

The sibling project focuses are compatible and both can be completed. Project dependencies already present in the paid decisions are mirrored by an available-trigger receipt gate, with the first project's focus as the visible prerequisite anchor.

The host reinforcement follows both project children and `independence_wave_complete_founding_settlement`. It costs 70 days plus the existing diplomatic-standard palette, whose selected payment is 20 command power and either 10 convoys or 10 trains.

The host focus checks affordability when selected and again in its guarded completion effect. Payment, route reinforcement, domestic fallback, and the current-generation receipt are all inside one guarded effect, and `cancel_if_invalid = yes` cancels the focus if its requirements disappear during the focus.

For a living former host, the reinforcement follows the selected negotiation, guarded-frontier, association, or reclamation route through the existing bilateral-ledger effect. If the former host is absent, the focus applies the package-specific domestic boundary values in the second table and does not call a host-scope effect.

The congress cap requires the current-generation host-support receipt and the open Regional Ambition survey. It calls the existing regional congress outcome by setting `independence_wave_regional_congress_called` and applying `independence_wave_focus_reward_diplomatic_step` once.

The global congress flag opens the existing postwar integration-authority focus path, whose separate local-committees prerequisite remains in force. The parent must make the generic `independence_wave_call_regional_congress` focus bypass when this flag already exists, so the generic action and the country-specific cap cannot award the congress outcome twice.

All focus identities use the existing package trigger, which combines original tag and package ID, plus the live regional-framework and current-generation gates. The new groups contain no static tag-only runtime scope.

The final payoff for IW-150/Aceh contains no PUSA reference, and the IW-161/Mon State group contains no post-1947 organization. Their Level 3 signature modules remain outside this tranche.
