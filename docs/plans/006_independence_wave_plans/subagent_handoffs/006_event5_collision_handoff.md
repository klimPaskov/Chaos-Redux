# Event 005 / Event 006 Collision Handoff

## Scope

Read-only audit of Soviet Collapse release, adoption, focus loading, scenario, and terminal-release paths against the accepted Independence Wave origin and reservation rules. No files were changed.

## Direct collision findings

Event 005 currently has no Event 006 reservation, tag, anchor, state, or origin guards.

- Progressive Event 005 selection can carve states from a living Event 006 country when the state retains `soviet_collapse_original_union_state` and the two systems resolve the same geographic space under different tags.
- The terminal/exhaustive release path releases absent eligible tags and can also adopt an already living non-Soviet country with a qualifying core. It then applies Event 005 mechanics and focus content.
- Event 005 focus loading accepts a generic breakaway condition in addition to Event 5 creation. This can replace a meaningful Event 006 tree and conflicts with the written Event 005 documentation.
- The Liberations cluster currently fires its members serially after independent selection. A 2–10 day queue delay means a plan held only in event targets would not survive.

## Exact shared-tag collisions

The systems share these 20 registered tags:

`KAR`, `DON`, `KUB`, `CRI`, `TAT`, `BSK`, `CHU`, `MEL`, `UDM`, `KOM`, `YAK`, `BYA`, `ALT`, `NEN`, `FER`, `CIN`, `DAG`, `ARM`, `GEO`, `AZR`.

A living tag must be reserved by its creator system and excluded from adoption or recreation by the other system.

## Mandatory integration changes

- Event 005 must publish its exact provisional tag and state footprint into the shared Liberations plan before Event 006 draws.
- Event 006 must reroll all tag, state, and reservation-group collisions after the geographically constrained Event 005 reservations are frozen.
- Event 005 terminal adoption must explicitly exclude active Event 006-origin countries.
- Event 005 focus-tree replacement must be limited to countries actually created by Event 005, not generic breakaways.
- Pre-existing recipients may receive narrowly scoped Event 005 treatment only when that does not claim creator provenance or replace their content.
- Both member presentations may remain delayed, but their ownership mutations must execute once behind a synchronous joint commit barrier.
