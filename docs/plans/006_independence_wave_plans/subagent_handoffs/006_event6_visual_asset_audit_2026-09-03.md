# Event 006 visual asset audit and repair

Audit date: 2026-09-03. Scope: every accepted Event 006 visual family, its gameplay consumer, sprite or direct filename, GFX or GUI definition, runtime texture, source and processed evidence, and documented orphan or rights state.

## Result

The parent-owned inventory covers all 49 accepted asset IDs. The current runtime contains 330 Event 006 DDS files across report, super-event, GUI, focus, idea, decision, and portrait folders; 1,530 flag files for 102 registered tags across five variants and three size ladders; 48 achievement states; and 104 Event 006-specific state-puzzle pieces across fourteen folders. The wider shared state-puzzle shelf contains 888 DDS files, of which only the 104 Event 006 pieces are in this audit scope.

The specialist audits found no missing texture path, duplicate Event 006 sprite name, case mismatch, malformed final DDS, visible crop, clipping, matte, alpha, frame-boundary, or alignment defect in the accepted runtime families. Two isolated `(255,0,255,1)` spill pixels were removed from processed previews and their runtime DDS files were reconverted. Eleven missing idea-picture references and two missing Siberian decision references were repaired to the accepted same-family Event 006 sprites; the exact wiring change is recorded in `006_event6_visual_asset_wiring_repair_2026-09-03.md`.

The inventory is not a completion claim for Event 006. Grounded portrait source and rights gates, GLC identity evidence, most ASSET-046 formable emblems, several flag provenance rows, GUI dynamic-state proof, and super-event/audio reachability remain fail-closed.
