## QA results

All twelve runtime DDS files are 94×86 legacy uncompressed 32-bit BGRA with a 124-byte header, pitch 376, a single image level, and a 32,464-byte payload/file. Pillow decoded all twelve. Each decoded RGBA image exactly matches its corresponding 94×86 processed PNG pixel-for-pixel. Every accepted native and processed image preserves alpha spanning 0–255; DDS decodes retain the same alpha range and alpha bounds. All twelve DDS file hashes and decoded pixel payload hashes are unique.

The final contact sheet was inspected after generation. At actual focus-icon scale the compositions remain distinguishable, and the parent has separately confirmed set-level visual uniqueness.
