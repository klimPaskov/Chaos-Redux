`independence_wave_assign_focus_framework` in `common/scripted_effects/006_independence_wave_focus_effects.txt` lines 29-75 loads `independence_wave_focus_tree` only for the explicit `full_framework` assignment; additive assignments never call `load_focus_tree`.

The additive carrier trigger in `common/scripted_triggers/006_independence_wave_focus_triggers.txt` lines 55-64 currently admits only an explicitly registered Iceland carrier, which is deliberate fail-closed behavior for countries without a reviewed owning tree; the exact IW-043 and IW-058 setup effects choose `full_framework` at `common/scripted_effects/006_independence_wave_iw043_iw058_package_effects.txt` lines 1313-1314 and 1421-1422.

The exact package triggers at `common/scripted_triggers/006_independence_wave_iw043_iw058_package_triggers.txt` lines 19-56 require `original_tag = CHU` or `original_tag = ASY`, the correct package ID and package flag, Event 006 origin, and absence of the Soviet-collapse origin flags and variable.

Event 005 CHU preservation is explicit: `CHU` is included in `is_soviet_collapse_internal_republic_focus_tree_tag` at `common/scripted_triggers/005_soviet_collapse_triggers.txt` lines 2853-2890, the meaningful internal-republic focus tree includes the CHU-gated Volga roundtable and workshop-guard focuses at `common/national_focus/005_soviet_collapse_republics.txt` lines 4611-4664, and the Event 005 dispatcher loads that tree at `common/scripted_effects/005_soviet_collapse_effects.txt` lines 10224-10228.

Vanilla has no custom CHU or ASY national-focus tree to preserve beyond this Event 005 CHU tree; vanilla ASY uses its generic tree and capital state 676.
