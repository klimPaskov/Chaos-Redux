## Findings and limits

1. **Accepted receipt and state-control exclusion is incomplete.** Part 5 explicitly says that the DHC successor receipt, or Event 005 ownership/control/reservation of 218 or 238, blocks IW-039 setup (`docs/specs/006_independence_wave_specs/specs/006_independence_wave_spec_part_5_country_packages_and_regional_overlays.md:96`). The current shared guard checks `DHC = { exists = no }` and *current-plan* reservations on 218/238, but contains no `soviet_collapse_don_host_successor` receipt check and no independent Event 005 ownership/control check (`common/scripted_triggers/005_006_liberations_collision_triggers.txt:34-43`). Event 005 sets the successor receipt (`common/scripted_effects/005_soviet_collapse_effects.txt:22504-22510`). A DHC-first case with no living DHC and no current reservation therefore has no explicit receipt barrier in this predicate. Current IW-039 admission gates prevent release, so this is a **pre-admission design/implementation gap**, not evidence of a live IW-039 collision.
2. **Reservation checks are scoped to one current plan.** `is_liberation_release_current_reserved_state` requires a state flag, a stored plan ID, and equality with `global.liberation_plan_id` (`common/scripted_triggers/chaosx_liberation_release_triggers.txt:121-129`). The 218/238 checks therefore reject only current-plan state reservations; an old state flag with another plan ID does not block. The DON country reservation test is broader and checks the flag without plan-ID equality (`common/scripted_triggers/005_006_liberations_collision_triggers.txt:36-40`). Normal cleanup and rollback clear that country flag (`common/scripted_effects/chaosx_liberation_release_effects.txt:53-58,926-942`), but a stale flag would conservatively suppress ordinary DHC despite IW-039 being inactive. The normal noncollision path remains otherwise gated by the pre-existing high-chaos and 218/238 SOV owner/control requirements (`common/scripted_triggers/005_soviet_collapse_triggers.txt:8194-8208`).
3. **The guard is applied at candidate weighting, not independently at the IW-039 reserve call or execution preflight.** Weights are recomputed before each draw (`common/scripted_effects/006_independence_wave_effects.txt:3388-3404,3629-3642`); the IW-039 reserve helper then loads and reserves 245/optional 238 without another direct collision predicate (`common/scripted_effects/006_independence_wave_package_region_effects_registry.txt:946,969,974-981`). Reservation sets the DON marker and pending metadata (`common/scripted_effects/chaosx_liberation_release_effects.txt:723-727`; `common/scripted_effects/006_independence_wave_package_planner_effects.txt:976-995`), which the DHC guard observes. The later execution preflight proves adapter, attestation, reserved carrier, and anchor but does not repeat the DHC receipt/state-control rule (`common/scripted_effects/006_independence_wave_execution_effects.txt:320-342`; `common/scripted_triggers/006_independence_wave_package_dispatch_triggers.txt:207-212`). There is no source evidence here of a practical interleaving during one effect chain; require an explicit final collision proof before future admission rather than treating the weight pass as an executed event-order guarantee.
4. **No literal alias bypass was found in the bounded creation search.** Mod tag registration names DHC separately (`common/country_tags/chaosx_countries.txt:29`); installed vanilla registers DON separately as the Don Republic (`C:/Program Files (x86)/Steam/steamapps/common/Hearts of Iron IV/common/country_tags/00_countries.txt:212`) with ordinary capital 218 (`C:/Program Files (x86)/Steam/steamapps/common/Hearts of Iron IV/history/countries/DON - Don Republic.txt:1`). Repository-wide literal `transfer_state_to = DHC` search found only the two transfers inside `soviet_collapse_spawn_dhc_if_enabled` (`common/scripted_effects/005_soviet_collapse_effects.txt:23519-23531`); the tag predicates in decisions, AI, and focuses did not expose another literal DHC creation effect. This does not prove that dynamic or engine-generated routes cannot exist.
