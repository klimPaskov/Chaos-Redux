## Required future production gate

For any portrait that later becomes eligible, the parent must preserve the unchanged attributed archival master, create the exact head-and-shoulders crop with `extract_portrait_source_crop.py` and equality JSON, run a source-locked identity-preserving ImageGen repaint in the matching male HOI4 family, produce deterministic `156x210` processing, obtain an independent likeness/style/provenance audit, and convert to DDS only after a PASS. A source photo, raw ImageGen result, candidate PNG, DDS, or existing runtime sprite is not clearance by itself.

For any flag that later becomes eligible, the parent must cite the design reference, document geometry/colour/symbol ownership, use ImageGen to create a clean flat orthographic design, compare the source master against normal/medium/small exports, and reject fabric, perspective, shadows, invented seals, unsupported calligraphy, or unreadable small sprites. This handoff contains no generated flag source or runtime flag.

7. DOX exact 1935 flag: no primary geometry or ownership evidence; modern Asante reconstructions and secondary variants are research leads only.
8. SOK exact 1936 flag: plural historical banners exist, but no Hasan-era court standard is proven; modern/state/generic jihad/reconstructed flags are excluded.

No fallback, generic portrait, generated grounded officeholder, invented flag geometry, flag art, DDS, `.gfx`, gameplay, localisation, or runtime promotion was used.
