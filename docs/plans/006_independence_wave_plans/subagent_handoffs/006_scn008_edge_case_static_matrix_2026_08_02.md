## Static closure boundary

The matrix proves source ordering and fail-closed guards only. It does not promote an unbound package, make the fourteen-package attestation set larger, or claim that the 14/20 automatic bands have enough admitted capacity. Those package and capacity gates remain controlled by the allocator audit and the current whole-event completion authority.
