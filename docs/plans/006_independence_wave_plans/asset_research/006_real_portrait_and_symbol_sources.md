# Event 006 real portrait and symbol sources

## Research standard

This document separates historical evidence from reusable media rights. A scholarly page can establish identity or date without licensing the image embedded on that page. A Commons file is not cleared merely because it is hosted on Commons; its source, author, date, jurisdiction tag, attribution, and any conflicting archive restrictions still require review.

Statuses:

- Cleared candidate: source page identifies the subject and supplies a workable reuse license or public-domain rationale. Production must preserve the attribution and license text in the asset manifest.
- Conditional: historically useful, but the date, identity, underlying source, attribution, or cross-jurisdiction rights record needs one more check before the file is copied.
- Research only: establishes an identity, institution, or historical motif but does not license a distributable image.
- Excluded: anachronistic, misattributed, insufficiently sourced, restricted, or too broad for the package identity.

The contextual source IDs already accepted in docs/specs/006_independence_wave_specs/research/006_source_register.csv remain the historical starting point. Blank URL fields and book citations in that register are not image licenses. Each final asset still needs an asset-specific source record.

## Attribution payload to retain

Every copied source file must be accompanied by a manifest row containing:

- Event and package ID.
- Subject or exact institution.
- Original filename and source-page URL.
- Direct archive or collection identifier when available.
- Creator or institution.
- Creation and publication date, including uncertainty.
- License name and link, public-domain rationale, and required attribution.
- Modification record for crop, restoration, color treatment, and DDS conversion.
- Historical-use note explaining whether the source is contemporaneous, earlier, later, or a reconstruction.
- Identity-use note explaining why the symbol belongs to this package and route.
