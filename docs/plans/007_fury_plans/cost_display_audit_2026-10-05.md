## Helper contract for the parent’s shared API documentation

`fury_cost_display_quote_component` is a private COUNTRY-scope scripted-trigger API used only by Event 007 cost localisation. It takes caller-set positive `fury_cost_display_ordinary_cost`, `fury_cost_display_family_mask`, and exact `fury_cost_display_resource_kind`. A zero family mask means the component stays fixed during a Black Friday sale. The caller must initialize `fury_cost_display_quoted_amount`, `fury_cost_display_quote_valid`, and `fury_cost_display_affordable` before each invocation; the getter branches do so independently before their fresh computation.

For a nonzero family mask, an inactive Black Friday sale uses the ordinary amount; an active sale calls `black_friday_quote_custom_cost` afresh in the current payer country scope. The quote API’s returned positive amount is the displayed amount. If an active sale quote fails, the helper retains the ordinary amount only as a red diagnostic display and sets quote-valid and affordability to zero, so a missing or malformed active source cannot create a green price. A zero family mask bypasses the sale quote, preserving the depot’s 40 support equipment and 6,300 manpower additions as fixed charges.

For every valid quote the helper sets `universal_cost_affordability_resource_kind` to the exact input kind and `universal_cost_affordability_amount` to the exact positive quoted amount, then calls `universal_cost_resource_kind_is_native` and `universal_cost_component_is_affordable`. It does not read `available`, `visible`, `custom_cost_trigger`, route flags, phases, candidate pools, gate epsilons, or cached `black_friday_fury_display_*` amounts. The final `always = yes` makes this a data-producing trigger; each literal-green branch checks quote-valid plus affordable, and each literal-red branch recomputes and selects the complement.

All outputs and shared quotation scratch values are temporary. The helper does not debit or credit a resource, change a flag or variable, store a quote for later, or alter a decision’s gameplay effects. No generic framework capability or cross-event index row is being proposed. The parent requested the narrow contract be appended to `common/scripted_effects/chaosx_dynamic_effects.md`.

The offline scripted-trigger reference documents calls as boolean `yes/no` triggers but does not describe a scripted-trigger argument interface, and the installed documentation search did not identify such a parameter contract. The helper therefore uses documented caller-set temporary variables instead of an undocumented script-parameter form.
