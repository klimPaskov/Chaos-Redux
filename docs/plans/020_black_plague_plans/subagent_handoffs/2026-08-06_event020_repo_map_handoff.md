## Existing patterns

The natural path centralizes origin selection, state registration, scheduled callbacks, spread, and current-state reports in scripted effects rather than duplicating logic in each event option. The scheduler stores a runtime generation and due-day guard before firing `chaosx.nr20.900`, then dispatches country/state response callbacks and one spread phase. The on-action file deliberately avoids a global periodic loop, which is the correct performance pattern for the current design.

The shared disease category is the established UI/decision pattern. State-targeted decisions use `state_target = any_controlled_state`, `on_map_mode = decision_view_only`, a root visibility trigger, a target-state trigger, dynamic costs, and cancellation when the selected state becomes invalid. Native missions use `days_mission_timeout`, `complete_effect`, `timeout_effect`, and explicit cancel paths; Hold the Line and Secure the Refuge are intentionally human-only with `ai_will_do = { base = 0 }`.

RTA and RTX decisions are country-scoped and consume capped brood/royal meters. Internal broods are represented by state flags and variables, so country, focus, decision, achievement, and event-log consumers must use the same markers. The two focus trees are separate files with route convergence and authored connector detours, not a generated common tree.

The existing mapmode preserves black as the established Black Plague base and uses phase/provenance/rat-control borders for readable status. Any future map change must preserve this layered pattern and must be checked through the map tools rather than source-only review.
