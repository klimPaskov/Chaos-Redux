**Disposition: unresolved proposal for parent acceptance within the 2026-09-20 user-approved CBRN clarity scope.** This is a bounded repair to Event 020's existing selected-state response and terminal operations. ## Decision to make

The 26 ordinary selected-state timed actions in `common/decisions/020_black_plague_shared_response_decisions.txt:101-646` preserve distinct prevention, transport, medical, containment, recovery, and anti-rat outcomes, but eight can qualify together on a prepared/threatened state. All currently debit scaled support equipment, trucks, and fuel and commit one or two civilian factories plus two or three Response Capacity, so the ordinary start already has five true cost types. Train and Command Power actions add a sixth; Royal Node, Crown Strike, Seal Royal Burrows, Hold the Line, and Secure the Refuge have still longer payment rows. The accepted 2026-09-26 cost-quote correction deliberately left this interaction and cost redesign open.

The **payment model** below is a concrete unresolved proposal. The initial staged-visibility matrix is an upper bound for the 26 shared ordinary IDs only; the full-category census below proves it is **insufficient as a six-row solution**. Do not implement that local matrix alone. A final visibility decision must give one integrated priority contract to every state start in `chaosx_disease_containment_category`, preserving existing IDs, timers, outcomes, and target identities. This is an open parent acceptance gate within the user's short-loop scope.

## The shorter player loop

The player first chooses a selected state. In Prepared/Exposed, they establish surveillance, restrict a route, and place medical capacity. An adjacent established outbreak replaces national prevention law with a border response; rat pressure replaces a lower-priority route control with an anti-rat line. In active infection, the menu shifts to relief, sanitation, emergency sealing, and medical aid. Contained and Recovering states replace emergency choices with residual tracing, staffing, administration, and reconstruction. Cured states expose only lasting vigilance or release of restrictions. A state with rat-occupation history receives at most two anti-rat choices alongside the phase choices. The state action active/cooldown gate continues to allow only one ordinary timed project on that state at once.

This uses the existing shared disease category and board selection. It creates no new button family, category, tab, popup, or dedicated Event 020 GUI. The original action IDs remain so active decisions, mission markers, localisation mappings, and saved action identifiers can resolve through the existing owner and cleanup path.
