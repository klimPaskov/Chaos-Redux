## Accepted design decisions

The parent accepted the one-on-one isolation boundary under the user's G6 direction. Stages I and III can still resolve several independent wars, but a selected pair is ineligible if either country has another active enemy. The former claim that the engine safely resolves one crowded multi-country war has been removed because Event 009 cannot prove the other participants safe under the native whole-war effect.

The parent accepted applying peace before any player or observer message. Under the parent-accepted G2 correction, each human-controlled country among the settled war participants receives one result popup using the same aggregate variant, with no second observer-news copy. If every settled participant is AI-controlled, one global news event fires after peace. A failed forced request receives one reason-bearing rejection report. The existing major-stage restriction remains, so the fresh-USA Italy-Ethiopia case reports `major_locked` before Stage II.

The parent source review also accepted preserving the Settings precheck selection through `.1`. The prior unconditional preparation could make a second weighted selection, disconnect the applied/result pair from `event_cluster_actor`, and cause the report/news names to diverge from the entry's selected pair. Reuse is conditional on a ready context plus both selected targets. The existing in-transaction trigger remains the final safety check. If that validation fails, the entry reports `no_safe_pair` without recording success history.

The parent accepted honoring the shared evolution setting gates while retaining the existing war-pressure thresholds. The single isolated minor base branch remains available if every evolution is disabled. The parent accepted the 181-day country cooldown against the 180-day No Winner check and removal of the redundant five-pair Circular threshold. Full accepted decisions and their evidence are in `../agent_decisions_2026-10-05.md`.
