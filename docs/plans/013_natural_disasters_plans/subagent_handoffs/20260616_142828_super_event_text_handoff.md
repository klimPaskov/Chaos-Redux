# Event 013 Super-Event Text Handoff

## Recommended final package

- Title: `The Unquiet Earth`
- Button: `Not single spies.`
- Main quote: `Nor can nature be commanded except by being obeyed.`
- Quote attribution: Francis Bacon, *Instauratio Magna* / prefatory *Novum Organum* material, 1620
- Quote source URL: https://www.gutenberg.org/cache/epub/13182/pg13182-images.html
- Button source: William Shakespeare, *Hamlet*, Act 4, Scene 5
- Button source URL: https://shakespeare.mit.edu/hamlet/hamlet.4.5.html

## Why this is the strongest fit

This package reads as abnormal-disaster recognition, not world-end prophecy. The title is short and specific. The Bacon line gives the super-event a clean non-terminal thesis: nature is no longer something states can simply command through routine institutions. The Shakespeare fragment works as a concise button because Evolution IV disasters now arrive in named bursts rather than alone.
