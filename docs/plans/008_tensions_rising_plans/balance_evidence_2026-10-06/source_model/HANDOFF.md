# Event008 source model handoff

The bounded executable model in [model_balance.py](model_balance.py) reads the current Event008 helper, its caller and trigger blocks, the relevant constants, and the generic Chaos meter effect directly from source. It refuses to run if the source shape changes around the recipient cap, equal-slice application, meta expansion, returned actual meter delta, caller accumulation, report-stage guards, cooldown gate, or Chaos meter arithmetic.

Run it from the mod root with `python docs/plans/008_tensions_rising_plans/balance_evidence_2026-10-06/source_model/model_balance.py`. The retained run is [result_2026-10-06.json](result_2026-10-06.json), which contains source and model SHA-256 hashes, tested inputs, all packet cases, static source assertions, and limitations.

The run exercised 168 world-tension cases: the five source packets (baseline 2, stage 1 3, stage 2 5, stage 3 8, stage 4 12) and future fractional packets 0.05 and 2.05, each across eligible counts 0, 1, 10, 20, 30, 50, 180, and 240 and starting global threat 0, 0.95, and 1. The minimum country slice is 0.1 points. The modeled selected count is `min(eligible_count, max(1, floor(packet / 0.1)))` when both packet and eligible count are positive; each selected recipient gets an equal packet slice. The model verifies no recipient count exceeds either eligible count or the integer cap, and the slices sum to the packet within floating tolerance.

The returned helper output is modeled as the actual clipped global-threat change multiplied by the source reporting scale of 100, then clamped to zero. At full global threat, the returned delta is zero; with only 0.05 threat capacity remaining, it reports the clipped amount rather than the requested packet. Root and stage-world callers explicitly initialize the temporary output, then add the actual output to the pending report accumulator. The helper contains no write to that report accumulator. A caller that ignores the helper output records no report addition; the incident path therefore cannot mutate the pending main-report world-tension snapshot through this helper.

The source-derived static checks confirm first-effectful report-stage capture is guarded by `tensions_rising_report_effectful`, and a new batch plus report acknowledgement clear that flag. The automatic-availability trigger rejects the global 30-day recent-shock flag, while the random-event preparer applies that rejection only when `automatic_event_firing_context` is present. These are source-control-flow assertions, not runtime scheduler tests.

Three before/after examples exercise the visible generic Chaos meter block for positive, zero, and negative changes. They model rounding of the requested change, application to the global meter, minimum-zero clipping, and final meter rounding. Static source checks verify the root snapshots global Chaos before the complete effect sequence, synchronizes the world-tension tracker before measuring the final meter, computes `final - before`, and adds that net actual delta to the pending report. The examples assert that the root-observed delta equals the modeled before/after meter change. Shared tracker behavior itself remains an explicit external input; the broader tier-final eligibility guard and settings-disabled behavior are outside this model.

Native source-country eligibility, native `random_select_amount`, global-threat engine application, and tracker synchronization are explicit bounded stubs. Recipient selection uses the first N eligible records deterministically, so this package provides no probability estimate. It does not model on-action scheduling, scope propagation, PREV behavior, pulse cadence, or opinion effects, and it does not replace installed-game/MCP or live-game evidence.
