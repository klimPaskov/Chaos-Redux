## Balance, validity, dominance, and repetition findings

The authored Event 028 opening and reopen boards use identical four-option modifier structures after replacing target slot 1, 2, or 3. Protected targets have a final zero factor, so the later enemy and target-value additions in those same blocks cannot lift a protected target above zero.

The current friendly-ground trigger checks both `OWNER` and `CONTROLLER` for the target state and states one and two land steps away. The friendly holder set covers the chooser, non-hostile faction partners, and co-belligerents. A target that would harm such a state receives a 0.25 strike factor. This closes the previously reported occupied-friendly ownership gap at the source level, but `AST_AI_OCCUPIED_FRIENDLY_RING` has no MCP result. The source does not include guaranteed or non-aggression-pact countries in the collateral friendly-holder set; whether those relations should count as friendly ring exposure needs a spec decision.

The `AST_AI_06` subject and ally results in the 2026-10-06 takeover history and the earlier baseline handoff are source-only claims. The historical estimate that an enemy target falls from about 50 percent to about 20 percent when friendly ground lies within two steps is not MCP evidence and is not endorsed by this audit.

Source structure avoids several direct invalid-choice paths: the three target options require a ready board, the not-ready fallback is mutually exclusive, the target acceptance choices follow pair validity, and crater actions require action-specific readiness and resources. The seven state selectors now exclude unaffordable candidates before ranking. The AI score blocks remain unchanged across the preserved decision snapshot and current file, while the available target set changes.

The event option raw weights have several potentially rank-changing modifiers for ideology, war, desperation, fragmentation, mineral control, target capitulation, Chaos, and friendly-ground exposure. No sweep result is available, so dominance, thresholds, near-zero options, and rank reversals are unverified. The same applies to preparedness and recovery scores. No starvation, repetition rate, or snowball claim is supported by an MCP trace.

The crater profile random list has three equal raw weights and persists a result once assigned. No cooldown or repeated sampling occurs after a profile is stored. The random list has no explicit seed in source, so this audit does not report a seeded outcome.

The historic takeover record says the earlier AI protection patch committed as `5e5a99788` after its probability check failed. It also lists live checks for a peaceful chooser, an enemy target, crater front weighting, and peace settlement. Those checks remain unperformed here.
