New effects `012_africa_gods_victor_effects.txt:14–31` require the authorized capitulated ROOT to match the current global host, save the actual defeated host as a regular target, then enter native FROM.

The winner is recorded at effects `34–64` before exemption is set.

Thus the first capture's already-proved live participant input can append kind/day/count before losing authority.
The permanent result, exemption and report snapshot follow the history append.
No PP, stock, fuel, Wrath or punishment transaction is present in victory recording.

If Gods runs first, its prefix records the winner, then cancellation removes ordinary membership.
If World-order runs first, its prefix records the winner before that owner's defeat processing.
In either source ordering, first capture sets exemption, which makes the shared current-generation/registered predicate reject a second record even before roster cleanup.
Acknowledging the report does not remove exemption, so immediate presentation cannot reopen that duplicate-record gate.

## Request, explicit consent, staleness and independent defiance

The relationship predicate at new triggers `34–49` requires a living ordinary victor, an already active committed host, host origin, permanent recorded/exempt facts, a history-count ledger, positive victory count, compatible origin, and optional owner-ID equality to THIS.id.
It intentionally does not require the actor's old participant generation or current major rank, permitting historical consent after host succession or loss of rank.
Request eligibility at `66–74` requires peace with Africa, no controlled current-host core, and no current request.
It does not depend on having ten PP.

Request at new effects `74–86` snapshots host ID, generation, origin and current victory sequence, then marks the request.
The current-request predicate at triggers `51–64` compares all four values against the current host/episode and rechecks war/territory eligibility.
A changed host ID, generation, origin or victory sequence closes acceptance.
An eligible stale offer can be overwritten by a fresh explicit request.
There is no request charge, timeout, automatic authority grant or defiance pardon.

Commit at effects `88–115` requires the current request and ROOT to be the actual current active host.
Entering participant scope from a host targeted action retains that accepting-host ROOT.
A participant event with ROOT equal to the victor fails the owner proof, and an unrelated or former host ROOT also fails.
The helper records the consenting episode/host/generation/day, appends kind 14/day/count directly under its historical proof, then clears exemption and the request and attempts normal enrollment.
Direct historical append is necessary here because the actor can still have an older participant generation and exemption before consent is committed.
The normal history writer would reject that state.
Eligible enrollment receives the normal first-demand delay, while an ineligible minor records consent without being forcibly enrolled.
The existing history initializer retains the already present ledger, so the consent append is not erased by that enrollment attempt.

Repeated commit cannot pass once exemption and request are consumed.
A later actual victory sets exemption again, advances victory sequence, and clears an earlier request, so an old accepted episode or offer cannot clear the new exemption.
The source stores current requests and latest presentation rather than a separate event-instance archive.
War/core conditions gate current eligibility, but this review does not claim every temporarily invalid request is automatically permanently revoked by a clock.

Core seek at `3807–3826` selects the no-charge victor request branch first.
Its ordinary paid branch still requires ordinary reconciliation eligibility before transferring ten PP and recording the paid offer.
An exempt actor with an already current request cannot fall through into paid ordinary reconciliation because exemption closes the shared generation predicate.
Core accept at `3831–3847` requires accepting-host ROOT and dispatches either the valid victor commit or the old paid completion.
Direct old `gods_of_africa_complete_reconciliation` at `2962` also has the ROOT host/active guard, plus current review, paid and offer proof.
No self-approval path was found in either core completion entry.

Victor commit does not clear `gods_of_africa_permanent_opt_out` or erase prior defiance.
Successful normal enrollment restores live defiance from that permanent flag.
The old review and real ten-PP payment plus host acceptance remain necessary to pardon it.
If enrollment eligibility is absent, permanent opt-out still remains for any later eligible enrollment.
The initializer's old-host-loss rejection at core effects `18–30` is unchanged, and no new victor helper reopens global Gods authority.
Renewal concerns only a host whose owning framework is already valid and active.
The separate recovered-original-host/exile reopening requirement remains incomplete outside this tranche.
