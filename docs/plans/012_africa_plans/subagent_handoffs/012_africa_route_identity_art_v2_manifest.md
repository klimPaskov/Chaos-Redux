# Event 012 Africa route identity art v2

This active package contains seven independently generated constitutional identity flag ladders and seven independently generated transparent route emblems. It is retained as source and QA evidence while the parent agent wires the existing cosmetic tags and standalone sprites.

## Source and reference basis

- Source mode: built-in OpenAI ImageGen for every flag and emblem master. No external image, vanilla texture, or prior mod art was used as an image input.
- Reference review: canonical `.agents/skills/chaos-redux-event-assets/assets/vanilla_reference/flags/` and `icons/factions/` were inspected before generation. Vanilla dimensions and TGA origin conventions were followed.
- Flags are flat orthographic designs; emblems use transparent chroma-key removal with the installed `remove_chroma_key.py` helper, then deterministic alpha-bounds crop and 64x64 canvas placement.
- All seven route identity packages are alternate-history or supernatural symbolic assets, not depictions of real institutions or people.

## Processing and format evidence

- Flag source masters are 1536x1024 RGB PNGs. Each ladder is an independent mechanical cover-crop to 82x52, 41x26, and 10x7, saved as RGB processed previews and 32-bit RGBA TGA runtime files.
- Runtime flags use Pillow TGA output with descriptor byte `8` (bottom-left origin, no top-origin bit), matching the installed vanilla flag convention. The TGA footer is retained where Pillow writes it; this does not alter the image origin or dimensions.
- Emblem masters are 1254x1254 RGB PNGs generated on a solid #00ff00 chroma key. Alpha removal used `C:\Users\klimp\.codex\skills\.system\imagegen\scripts\remove_chroma_key.py --auto-key border --soft-matte --transparent-threshold 12 --opaque-threshold 220 --despill`; alpha-cleaned evidence is retained in `notes/alpha_emblems/`.
- Emblems were cropped to nontransparent bounds, fit within a 56x56 interior, centered on a 64x64 transparent RGBA canvas, then converted with `.agents/skills/chaos-redux-event-assets/tools/convert_to_dds.py --width 64 --height 64`. DDS files are legacy one-level uncompressed BGRA with 128-byte headers and `DDSCAPS_TEXTURE`.
- Visual comparison sheets are retained at `contact_sheets/flags_source_and_ladders.png`, `contact_sheets/flags_tga_decoded.png` (decoded runtime TGAs), and `contact_sheets/emblems_source_and_processed.png`.
- Full SHA-256 hashes, dimensions, modes, and byte sizes are recorded in `notes/hashes_dimensions.txt`.

## Prompts and limitations

Route-specific normalized prompts are in `prompts.md`. All masters were created through the built-in ImageGen path on 2026-08-01. Generated flag designs are alternate-history inventions; no historical flag or real-world heraldic claim is being asserted.

The Windows environment does not provide the Unix `file` utility, so TGA format evidence is recorded from Pillow decode plus direct header inspection (type 2, 32-bit pixel depth, descriptor 8, expected dimensions). At 10x7, fine heraldic details necessarily merge; each small export retains its route-specific field layout and central silhouette. The parent agent must add the seven standalone sprite definitions and point the existing `GFX_idea_africa_unity_*` consumers at the emblem DDS paths; this package intentionally does not edit `.gfx`, gameplay, localisation, country, or workbook files.
