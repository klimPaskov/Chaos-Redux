# Gods Strength physical-input API

This owner file supports the accepted Strength factor families in the Gods full specification, including direct African core control and military power relative to the world.
Its current territorial collector is staged for integration with the existing Strength owner.
It is not a completed Strength repair until the owner consumes the result and the world comparison, lifecycle, balance cases and documentation are integrated.

`gods_of_africa_measure_territorial_control = yes` runs in the current Event 012 host country, independently of native ROOT.
It has no caller inputs or temporary outputs.
It uses `input = collection:states_in_africa` inside native `every_collection_element`, then returns to its host through PREV.
It creates no recurring hook or all-country iteration.

The host's normal private outputs are `gods_of_africa_strength_african_state_total`, `_african_owned_states`, `_african_controlled_states`, `_african_secured_states`, `_african_core_total`, `_african_secured_cores`, `_territorial_control` and `_territory_observation_day`, with the repeated `gods_of_africa_strength` prefix understood.
Counts reset to zero on each authorized observation.
The territory score is secured African host cores divided by every African state, scaled by the existing component maximum.
A small host's complete home-core control cannot masquerade as complete continental control.
Ownership, occupation/control, secured ownership/control and core legitimacy remain distinct observations.
An empty collection yields zero rather than division by zero.
Other country calls leave their state untouched.
No compliance, history, payment, reward, public display or raw Strength value changes here.
