# Event 012 Africa priority-member packages: final country audit

Date: 2026-08-09

Scope: the sixteen priority-member packages in `docs/specs/012_africa_specs/matrices/012_africa_priority_member_package_matrix.csv`. This audit covers country tags and origins, package registration, politics, male sovereign promotion, mechanics, force payloads, League clauses, refusal and counterproposal paths, overlap settlement, post-settlement actions, focus and decisions, AI weights, state setup, localisation, assets, and cleanup. GUI, event ledger/workbook, promoted high-chaos packages, and portrait binary production remain outside this handoff.

## Result

All sixteen rows have a distinct package predicate, an existing carrier or direct-tag origin, package-specific politics flags and party names, a named male sovereign character, mechanic/force/post-settlement actions, League and overlap branches, event and decision localisation, focus/decision AI weighting, lifecycle ideas, and cleanup. No new country tag was created. Every character row in `common/characters/012_africa_priority_member_characters.txt` is explicitly `gender = male`; no Event 012 female character, female leader metadata, or opposite-gender name pool was found.

Two runtime defects were corrected in this pass. The nine vanilla-carrier branches in `africa_priority_member.1240` now recruit the character directly in country scope, matching the documented `recruit_character` effect, and all three constitutional installers now always call the accepted sovereign-role runtime installer. Portrait provenance is therefore not a politics-only gate and does not suppress sovereign promotion. The portrait worker still must replace every source-locked placeholder with an accepted male ruler/person receipt before release.
