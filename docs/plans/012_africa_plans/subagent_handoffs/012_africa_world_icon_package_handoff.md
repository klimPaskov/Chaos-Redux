# Event 012 external-world icon package handoff

This asset-only package supplies the 121 external world-package focus icons and 38 world-order founding/route idea icons. It does not edit gameplay, localisation, interface `.gfx`, or GUI files.

## Completion

- Focus icons: 121 complete, processed at 94x86 and converted to DDS.
- Idea icons: 38 complete, processed at 64x64 and converted to DDS.
- Every row below preserves the recovered sprite name and texture path from `git:99f405fe4^:interface/012_africa_world_order.gfx`.
- Generated sources are atlas tiles; green chroma was removed with the official imagegen helper and final PNGs have transparent corners.

## Parent wiring

Use the `sprite_name` token for focus `icon =` fields and idea `picture =` fields. Runtime DDS files already live at the exact `texture_path` values in the table and in the JSON manifest.
