## Scenario contract reconciled

The public row is Africa Is One and exposes two types, Africa Is One and World Is One. Both types use four intensity stops: Low, Medium, High, and Maximum. Low supplies a limited emergency force and modest opening deltas, Medium supplies a regional package, High supplies a large force and broader deltas, and Maximum supplies the strongest opening package.

The fresh-host path calls the manual Event 012 preflight, reuses the weighted African-capital host selector and frozen-contact builder, and queues the canonical `chaosx.nr12.1` entry for the existing initialization commit barrier. A failed or invalid preflight does not create a host.

The existing-host path resolves the committed `event_target:africa_host` and applies the opening in place. It does not create a second host, tag, or global campaign target.

Africa Is One opens the continental systems and queues the existing Scramble response callback. World Is One initializes the existing world-order package and prepares the terminal continental-campaign route, but it does not force `world_end`, final proof, terminal identity, or an automatic terminal victory; normal package, proof, settlement, and identity gates remain authoritative.
