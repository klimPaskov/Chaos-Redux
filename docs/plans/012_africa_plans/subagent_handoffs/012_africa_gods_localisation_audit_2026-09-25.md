## Confirmed wording and display findings

1. **Broken cost icon.** `gods_of_africa_protection_cost` at `localisation/english/012_africa_gods_l_english.yml:129` uses `£war_support_texticon`. No `GFX_war_support_texticon` definition was found in the mod or installed vanilla interface. Vanilla defines `GFX_war_support_icon` in `interface/topbar.gfx:257`, and other mod cost text uses `£GFX_war_support_icon`. Replace this token with the registered icon and verify it in a production decision view. The motorized-equipment token has a mod definition and the other inspected icons have installed definitions.
2. **Incomplete optional price.** The same key lists the Event 013 manpower, support equipment, trucks, convoys, fuel, stability, and war-support charges, matching `natural_disaster_pay_neighbor_relief` in `common/scripted_effects/013_natural_disasters_effects.txt` and the constants in `common/script_constants/013_natural_disasters_constants.txt`. That owner effect also applies `natural_disaster_begin_outbound_relief_light_burden`; Event 013's `natural_disaster_cost_outbound_relief_tooltip` explicitly calls this a temporary construction burden. Add that consequence to the optional cost explanation. Display the negative stability and war-support values as clear losses, since those are actual charges. The current very long second line may wrap poorly or overflow; the ordinary decision has no production GUI render evidence here, so visual fit is **unresolved**, not passed.
3. **Host report option addresses the wrong actor.** `chaosx.nr12.610` is fired inside `event_target:africa_host` in `common/scripted_effects/012_africa_gods_effects.txt:3656` and its own trigger requires the active host. Yet `.610.a` says “Receive the protection.” The host paid and sent it. Recommend “Stand by the pledge” or “Send the protection.”
4. **Report prose hides the action.** `.610.d` says “bounded protection package,” “Its shipment is real,” and “further support depends on Africa's mandate and the partner's circumstances.” This reads as implementation explanation and omits the concrete guaranteed base shipment. Suggested direction: name the selected partner if the saved `gods_of_africa_protected_participant` event target resolves in the event, state that Africa sent equipment and fuel, and mention only conditional services that can actually be present. Do not promise Event 013 relief as automatic. Example pending scope validation: “Africa has sent infantry equipment and fuel to [gods_of_africa_protected_participant.GetName]. Its council may also grant access, send transport, or open relief where those services are available.” The event inspector did not establish the saved target's rendering context, so validate this token before adopting it.
5. **Defiance report uses internal receipt language.** `.609.d` says “where their receipts remain valid,” which exposes bookkeeping to the player. It also says “declaration ... has been recorded” without naming the defiant country. Suggested direction: “This government has defied the Gods of Africa. Africa has stopped ordinary demands and withdrawn the guarantees, access, and reception services it granted under the compact. Retaliation remains possible; only reconciliation can restore the relationship.” Preserve the receipt-limited cleanup in script, rather than explaining receipt internals in prose. The existing sentence semicolons violate the requested style rule. Its `gods_of_africa_defiance_effect_tt` repeats the same suspension and reconciliation point and should be shortened to the player consequence it adds.
6. **Protection tooltip repeats the cost and title.** `gods_of_africa_protect_partner_desc` and `gods_of_africa_protect_partner_effect_tt` each restate the base payment and list nearly the same conditional support. Keep the price in `gods_of_africa_protection_cost`; make the description say who qualifies and what they receive. Make the effect tooltip identify the 180-day cooldown, its reserve-focus reduction if relevant, and the key conditional outcomes. The current decision text says “diplomatic, logistics, intelligence, or reception support,” which is too abstract to tell a player whether a guarantee, market access, intelligence, transport, capital work, Event 013 relief, or shelter/medical capacity can occur. Avoid implying the Event 013 mission always opens.
7. **Focus promise specificity.** `gods_of_africa_focus_security_oaths_desc`, `_shelter_faithful_desc`, `_relief_beyond_desc`, and `_expedition_desc` use “reciprocal,” “bounded,” “measured,” and “military assistance” without naming the enabled service. Source links security to military access and possible La Resistance intelligence, shelter to the protection gate and Migration reception capacity, relief to stability/capital work/conditional Event 013 mission, and expedition to war support. Rewrite those four descriptions around those concrete effects while keeping DLC and owner gates visible in the actual decision tooltip. `gods_of_africa_focus_no_sanctuary` belongs to the judgment branch and should not be described as the sanctuary service.
8. **Scope and policy clarity.** The protection description says “a reliable partner at peace,” consistent with the participant trigger, but does not explicitly say the partner must be registered. The cost line does not show the 180-day repeat interval or 120 days after the reserve focus. Add those to the decision consequence text if no existing rendered requirement supplies them. DLC-gated AAT market access and La Resistance intelligence must be described as conditional, not guaranteed. Transport's 20-unit shipment and the host's 40-unit floor, and intelligence's five points per category for eligible current host enemies, are absent from player-facing protection text; use concise conditional detail if the decision view can fit it.

No inspected text claims population movement. The docs correctly distinguish Migration shelter/medical capacity from movement, and preserve completed shipments, construction, learned intelligence, and dispatched Event 013 missions on compact withdrawal. The `.610` effect tooltip says withdrawal occurs “if defiance begins” but omits archive, host loss, cancellation, and settlement. The player-facing wording should not imply defiance is the only cleanup path; a compact-wide “while the relationship lasts” formulation would be shorter and more accurate.
