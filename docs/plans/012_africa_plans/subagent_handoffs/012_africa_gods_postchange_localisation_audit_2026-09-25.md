## Remaining localisation issues

1. **Blocked feedback:** `gods_of_africa_protection_cost_blocked` at `012_africa_gods_l_english.yml:130` is textually identical to the normal row and colors all three amounts yellow. If fuel, political power, infantry, or the shared reserve fails the inclusive host gate, the player sees no red cost or reason in this keyed row. The hover explains the reserve obligation but does not identify which check failed. The parent should give the blocked state a visible red signal and, if feasible, a concise resource-specific reason; no individual failure behavior is claimed from the current source.
2. **Static transport value in one key:** `gods_of_africa_protect_partner_effect_tt` at `:128` says `20-unit`, while the cost hover and focus description interpolate `gods_of_africa_transaction.transport_amount`. The literal matches today's constant but can drift. Use `[?constant:gods_of_africa_transaction.transport_amount|0]` in that sentence when revising the key.
3. **Conditional payment icons and threshold clarity:** the hover key at `:131` spells out “convoy or train shipment” without the matching texticons for those possible additional equipment payments. It also says “shortage-checked,” which does not tell the player that the partner must hold fewer than 20 of the chosen type. The current 40-unit post-transfer floor and convoy-first priority are accurate. A concise hover revision could show each alternative with its icon and dynamic amount, state the recipient shortage threshold, and keep the existing floor. The text does not need to imply both alternatives are paid.
4. **Prose:** the effect tooltip is one long list of conditional services. “This focus shares” assigns the intelligence action to the focus rather than the protection decision, and “an agency in both countries” is awkward beside the source's two agency checks. The tooltip and cost hover each contain a semicolon, contrary to the event writing rule. The Event 012 report, decision description, effect tooltip, cost hover, and relief focus description still repeat that Relief Convoy is separate and priced elsewhere. Keep at least one explicit decision-level distinction, then trim repetition if the parent makes a prose pass. These are copy-quality findings, not evidence of a changed mechanic.
5. **Event 013 display limit:** its preserved five-value inline cost key exceeds the decision skill's three-value presentation budget. This is a pre-existing display issue, not authorization to reduce, hide, waive, or reprice any of its material or stability/war-support costs. A presentation-only solution requires separate review and native evidence.
