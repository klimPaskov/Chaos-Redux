# Event 12 African-Capital Host Eligibility Handoff

## Outcome

Event 12 can select every existing country whose current capital is in Africa. Liberia, Ethiopia, South Africa, subjects, governments in civil war, capitulated governments, dynamically created countries, and unmapped tags all use the same eligibility predicate.

## Authoritative host contract

`africa_is_eligible_host` requires only `exists = yes` and `capital_scope = { is_on_continent = africa }`. The shared availability trigger, weighted candidate scan, manual and automatic prefire paths, canonical entry event, settings dispatch, and selected-host initializer all consume that predicate.

Named dossier mapping, focus-tree type, capital control, African cores, contact count, subject or exile status, capitulation, civil war, Event 006 binding, nonhuman or special-chaos classification, and the South African Allied framework do not remove a country from the host pool. Separate event-active, event-resolved, and world-end lifecycle guards remain intact.

## Content assignment after selection

The existing 22 full and 29 compact mappings still assign named opening content. An African-capital country outside that matrix receives the compact capital-only package, neutral scripted-localisation fallbacks, and a continent-wide contact pool. This is the defined default package, not a substituted named dossier.

The contact freeze accepts zero to five live regional governments. Sparse or empty rosters reach the direct no-contact opening rather than cancelling Event 12. The specialised South African helper now controls only whether its Allied-rupture branch can start.

The continental focus loader replaces only `generic_focus`. Ethiopia, South Africa, and every other host with a meaningful existing tree keep that tree and receive Event 12 through additive events, decisions, ideas, and scripted systems.

Every candidate retains a positive clamped selection weight, so no eligible host can disappear from the weighted pool.
