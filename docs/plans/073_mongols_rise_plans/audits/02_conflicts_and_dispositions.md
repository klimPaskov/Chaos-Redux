# Conflicts and dispositions

## Authority rules

The user's attached brief defines the requested Event 073 concept. Supplied owning skills define production and planning constraints. Current local implementation must be inspected before coding. A proposed enhancement, a file's location, or an audit note is not automatically user approval.

Allowed dispositions are unresolved, accepted and queued, implemented, promoted to authored specification, rejected, superseded, and blocked. This package uses promoted to authored specification for parent-authored design incorporated into the main files. It does not equate that label with a later explicit user approval.

## Deferred proposals

A new custom Karakorum map-building model, a separate model for every tumen family, literal resurrection of Genghis Khan, new religious-policy mechanics, and a new world-end scenario are not part of this baseline. They need an explicit separate proposal and acceptance before adding production obligations.

A universal prohibition in the division designer is also not assumed from the phrase normal cavalry army. The required baseline governs the event's normal recruitment, grants, templates, bonuses, AI, and qualification. Any stronger engine restriction must be verified and described honestly.
