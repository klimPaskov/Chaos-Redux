## File-level manifest fields

Each final expanded row records asset ID, family, exact source URL or original source file, creator, license, attribution text, source hash, work owner, dimensions, alpha mode, variant or frame count, output path, consumer, production status, review evidence, and runtime evidence. A source-page link alone is not a redistribution license.

## Conversion and alpha

Use the repository's existing DDS converter and inspect its current contract. The supplied asset skill requires the expected BGRA output with the correct 128-byte header and alpha handling. Preserve transparent edges and do not flatten an icon against an arbitrary background.

Native transparent generation is preferred where available. Background removal is a fallback with its own edge inspection. Each icon is reviewed at final size before and after conversion.

## Temporary and durable files

Temporary event assets may live under the established Event 073 temporary asset folder during production. They remain while work is blocked. Promote final outputs and durable provenance before cleanup. Never delete the durable portrait source archive as part of temporary cleanup.

No font files are part of this package or its proposed asset delivery.
