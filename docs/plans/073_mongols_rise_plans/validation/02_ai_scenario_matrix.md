# AI scenario matrix

## Status and interpretation

All scenarios are NOT RUN. Desired rankings below are hypotheses for implementation tests, not measured probabilities. First filter for valid actors, legal actions, and feasible payments. Then inspect scores. Only a complete normalized option pool supports a probability claim.

|---|---|---|---|

## Probability report requirements

For every tested decision, record the valid option pool, each exclusion reason, each raw score and modifier, normalized probabilities if the engine exposes them, and the observed result over a suitable repeated scenario set. Do not label a score of ninety as a ninety-percent outcome without the rest of the pool.

Use fixed scenario conditions when comparing changes. A different opponent, date, or alliance network can legitimately change the result and cannot serve as a controlled before-and-after test.
