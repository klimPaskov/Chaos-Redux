# Event 059 implementation handoff

## Source-of-truth package

Read all files under:

`docs/specs/059_the_offensive_specs/`

The five numbered specification parts define accepted design. Matrices define proof obligations. Prompts define specialist and implementation work. Quality records explain corrections, exclusions, source coverage, and unresolved implementation facts.

## Recommended implementation order

### 1. Repository and reference inspection

- inspect existing Event 059 event files, registration, weights, enable defaults, history, localisation, and any legacy flags
- inspect the current Diplomacy cluster registry, the superseded Diplomatic Panic name, and all member metadata
- inspect global report fan-out patterns for multiplayer
- inspect evolution registration, MTTH, toggles, history, and Event Details patterns
- inspect generic and country-specific AI strategy plans
- inspect current country creation, release, civil-war, restoration, annexation, and control-transition hooks
- inspect special Chaos actor strategy ownership
- inspect achievement registry and icon consumers
- read required local vanilla documentation and examples

### 2. Baseline evidence

Before changing weighted behavior:

- run event inspection and rendering on the legacy Event 059 chain
- record current event weight, Fire-Once state, and save identifiers
- run probability inspection on every candidate AI pool that the implementation may change
- record representative vanilla or current Chaos Redux outcomes for the named baseline scenarios

### 3. AI architecture plan

Spawn the scripted-system architect with the dedicated prompt. Resolve:

- generic plan versus country-local registration
- control transition behavior
- later-country coverage
- evolution independence
- owner-plan precedence
- tuning ownership
- legacy migration
- bounded call sites

Do not start broad AI implementation before this plan is reviewed.

### 4. Event activation and migration

Implement:

- stable Event 059 root identity
- one global active state
- one-time player report fan-out
- one history record
- bounded 15 to 25 Chaos manifestation
- one-time guard
- legacy state migration
- Fire-Once removal and duplicate guard

### 5. Baseline AI layer

Implement baseline front, concentration, production support, air, naval invasion, existing war-goal, and useful war participation behavior with full safety constraints.

Verify weak minor, major power, landlocked, maritime, subject, exile, and special actor cases before adding evolutions.

### 6. Evolution layers

Implement each layer independently:

- Relentless Offensives for persistence and follow-up
- Predatory Powers for valid opportunity use
- Total Offensive for scale and risk

Implement active-event MTTH paths and pre-fire catch-up. Verify disabled-stage combinations.

### 7. Cluster and Event Logs

- assign Diplomacy cluster and High member severity
- resolve required or optional role, participation chance, and member minimum tier from the authoritative Diplomacy defaults
- do not preserve or invent an event-specific participation override
- verify cluster pacing and Fire-Once state
- wire Events, History, Evolutions, Event Details, and Clusters
- use global actor presentation

### 8. Probability and balance audit

Spawn the probability auditor with the complete pools and all 46 scenarios. Resolve every unsafe dominance, starvation, invalid target, disabled-layer leak, or missing rank reversal.

Do not describe a score as an exact probability unless the tool proves the complete normalised pool.

### 9. Localisation and assets

- write final text from Part 5 direction
- create the event report image
- create the achievement icon states
- wire sprites and consumers
- complete manifests and durable provenance records
- run the localisation auditor

### 10. Achievement

Implement qualification, snapshots, duration, target tracking, major-ally restriction, survival, target defeat, core control, cleanup, persistence, and exploit guards from the achievement prompt.

## Hard failure conditions

Do not accept the implementation when any of these remains:

- direct combat or production-output bonus
- Event 059 behavior active under human control
- later AI countries not covered
- recurring unbounded global scan
- Evolution III recreates a disabled lower layer
- arbitrary wars against unrelated weak targets
- suicide attacks through critical supply, fuel, manpower, or transport failure
- generic strategy overrides a hard owner plan
- cluster assignment remains Diplomacy or blank
- evolution activation changes Chaos
- duplicate shared war or death Chaos
- pre-fire catch-up creates report spam or broken history
- unsupported AI keys were guessed
- final art or achievement icon is missing or placeholder
- authoritative workbook and exports disagree
- required subagent or live evidence is missing from a completion claim

## Current planning blockers

Exact engine syntax, actual repository paths, native plan reevaluation, later-tag inheritance, legacy identifiers, and final tuning remain unresolved until local authoritative references and tools are available. These are explicit implementation tasks, not permission to use approximations.
