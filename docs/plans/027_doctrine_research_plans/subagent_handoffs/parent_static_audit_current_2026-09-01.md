## Source coverage

The Event 027 source set contains 31 unique `chaosx.nr27.*` event definitions. The root `chaosx.nr27.1` is hidden, actorless, and invokes one bounded `doctrine_research_fire_global_batch` fanout. The firing effect snapshots live countries with at least one valid adapter action, appends a separate country-owned batch, fixes its firing stage and choice count, and starts only the oldest queued batch. Later firings append independent rows without merging, resizing, or overwriting an active batch.

The human route contains the opening, domain, Grand Doctrine, track, subdoctrine, confirmation, result, continuation, summary, native-adoption, ambiguous, and no-option pages. AI resolution uses the same validity predicates, chooses from weighted candidate lists, confirms through the same transaction path, and recalculates after each successful choice.
