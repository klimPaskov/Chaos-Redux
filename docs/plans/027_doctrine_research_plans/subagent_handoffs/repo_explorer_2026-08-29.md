## Existing patterns

- The closest global fanout is Event 019: its root calls infantry_spawn_fire_manifestation, which performs one bounded generation-wide pass, initializes each eligible country, and schedules human-facing country events. Event 027 needs the same one-firing shape but must add one country-owned batch, ordered queue, AI silent resolution, and native-doctrine receipt ledger per valid country.
- Event 025 demonstrates a simpler hidden root plus every_country next-day chain, but its broad major/human selection and news bridge do not satisfy the Event 027 validity, AI, or batch contract.
- CBRN HQ events demonstrate how to persist an owner or target across delayed country events using save_event_target_as; use this pattern only for country-owned queued follow-ups and cleanup, not for a recurring world iterator.
- The shared on_daily event timer already services automatic event selection. Adding a separate on_daily or on_weekly world scan for Event 027 would violate the specification and create avoidable performance and duplicate-firing risk.
- The Event Log uses aligned arrays and generic type/tier/stage fields. Event 027 global history/evolution rows should use the existing no-actor path unless the implementation deliberately creates an actor, which the accepted spec does not require.
- Cluster registration is an aligned-array contract: definition IDs, names, unlock tiers, event membership, member roles, chances, minimum tiers, danger flags, row IDs, triggers, and severities must remain the same length and order.
- Event 019 is the nearest achievement pattern for generation or batch identity ledgers. Event 027 achievements require stronger checks for same evolved batch, same-domain receipt, exact five receipts, four distinct stable tracks, and exclusion of native-only mastery.
- Chaos Warfare's existing native reward effects are the intended downstream integration. Event 027 should select the native doctrine track/subdoctrine and let native rewards and CBRN recording helpers fire, rather than setting technologies directly.
