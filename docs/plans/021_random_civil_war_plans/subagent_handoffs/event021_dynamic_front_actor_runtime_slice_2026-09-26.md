## Implemented behavior and helper map

| Helper | Scope and input | Output and side effects | Call site |
| --- | --- | --- | --- |
| `event021_parent_review_registered_ordinary_fronts` | Original host, its crisis ID, durable actor registry | Snapshots every same-crisis AI ordinary secondary actor whose recorded immediate war ended, then invokes the existing close path for each from a separate temporary array. The close may unregister an actor without mutating the iterated snapshot. | `event021_parent_review_secondary_front` during bounded country review and settlement. |
| `event021_parent_refresh_ordinary_secondary_presence` | Original host, crisis ID, durable actor/crisis/status rows | Rebuilds the host's secondary presence flag and compatibility pointer from surviving registered opposition actors still at war. It changes no sibling row. | After one ordinary secondary close. |
| `event021_parent_review_event6_secondary_front` and `event021_parent_refresh_event6_secondary_presence` | Original host, crisis ID, registered Event 006 secondary-origin actors | Reviews each completed host war from a stable snapshot, records the actor's independence outcome, clears its active secondary role, then rebuilds the host's compatibility receipt from still-warring package actors. | Bounded country review and settlement. |
| `event021_parent_finalize_event6_secondary_actor` | Original host at cleanup, crisis ID, registered secondary-package-origin actors | Snapshots and finalizes each package actor independently; actor cleanup can remove a durable row without changing the snapshot. Event 006 identity, focus, force, and fired history are not written here. | Host crisis cleanup. |
| `event021_parent_update_front_resolution_receipts` | Current active crisis country and its crisis ID | Inspects every same-crisis active registered opposition actor and its immediate war. Missing crisis identity, misaligned key registry arrays, or a live opposition actor with no valid opponent fails closed. Planned rows still block resolution until consumed or rejected. | Bounded review, per-front closure, settlement. |

The role marker `random_civil_war_event6_secondary_origin` is an actor classification, not a counted slot. It survives a secondary war's end so host cleanup can find that package actor, and actor cleanup or annex teardown removes it. Ordinary and Event 006 review stage actors into separate temporary arrays before invoking any cleanup that can change the durable registry. No array is mutated from its own `for_each_scope_loop`.
