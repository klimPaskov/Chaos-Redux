# Event 015 Generic Focus Return Reference Audit - 2026-10-06

## Finding

The installed `load_focus_tree` documentation says `keep_completed = yes` keeps completed focuses from the previous tree only when those focus IDs also exist in the new tree. It does not document a historical completion cache for IDs absent from the replacement tree, so a later reload cannot recover those absent IDs from `keep_completed` alone. The offline wiki's shared-focus section describes the same common-ID use. Sources: installed `documentation/effects_documentation.md:4771-4789`, revision `2cdc93d26775990468eed167442f7a416b13059fb8fe07d139b54250b79209af`; offline `paradox_wiki/National focus modding - Hearts of Iron 4 Wiki.md:818-838`, revision `bd989a13237c464f140a0aa671cc42c30a48e84a27dae791b8914654fb9c6203`.

The installed `complete_national_focus` documentation gives no reward-suppression parameter, and the offline effects row lists only the focus ID plus `use_side_message` and `originator_name`. The wiki's country-creation guidance says `complete_national_focus` fully completes the focus and grants its effects. Sources: installed `documentation/effects_documentation.md:2870-2878`, revision `2cdc93d26775990468eed167442f7a416b13059fb8fe07d139b54250b79209af`; offline `paradox_wiki/Effects - Hearts of Iron 4 Wiki.md:1801`, revision `997ddb09bfd63efb41a425149c46bd812d5f8953217a403386b2f6c85196aa0c`; offline `paradox_wiki/Country creation - Hearts of Iron 4 Wiki.md:317-326`, revision `0c0e57915a7d1eef9ddeebe91c7329e18f4f224af98ac33fac5edd35e3aaa35d`.

There is a documented no-reward restoration effect: `unlock_national_focus = <focus_id>` bypasses the specified focus, marks it complete, and does not fire its `complete_effect`. The installed documentation confirms this is a country-scoped effect; the offline wiki supplies the bypass and no-reward semantics. This is the narrow safe API for restoring a previously completed generic focus after `generic_focus` is loaded, provided the original completed-ID receipt was captured before the tree switch. Sources: installed `documentation/effects_documentation.md:8524-8532`, revision `2cdc93d26775990468eed167442f7a416b13059fb8fe07d139b54250b79209af`; offline `paradox_wiki/Effects - Hearts of Iron 4 Wiki.md:1800`, revision `997ddb09bfd63efb41a425149c46bd812d5f8953217a403386b2f6c85196aa0c`; offline `paradox_wiki/Country creation - Hearts of Iron 4 Wiki.md:317-326`, same country-creation revision.

## Duplicate-reward risk

Using `complete_national_focus` to recreate the receipt would replay generic focus completion rewards. The installed vanilla `common/national_focus/generic.txt` defines `army_effort` to grant 25 army experience and a one-use land-doctrine cost reduction at lines 34-52; `industrial_effort` grants a one-use industry research bonus at lines 1004-1022; and `construction_effort` adds one instant civilian factory at lines 1065-1146. Restoring those completed IDs through `complete_national_focus` would issue those rewards again for each replayed receipt entry, including another factory for each restored construction focus. Repeated re-entry could repeat the duplication if the event lifecycle permits re-acceptance; re-entry eligibility was outside this reference scope. `unlock_national_focus` avoids replaying the completion effect.

Vanilla syntax precedent: `ITA_start_civil_war_effect` in `common/scripted_effects/ITA_scripted_effects.txt:1576-1930` loads `italian_focus` with `keep_completed = yes` at lines 1799-1802. It corroborates the syntax and common vanilla use; the installed documentation above is the evidence for the common-ID limit.
