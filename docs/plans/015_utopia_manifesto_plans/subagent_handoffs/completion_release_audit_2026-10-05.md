## Disposition

The accepted G7 manual-release behavior is implemented in the current source and passes this static scope and lifecycle trace. This handoff does not re-certify the whole event package: the existing whole-event PASS is frozen at 2026-07-18, the current coverage documents have stale inventories, and no current Event MCP artifact was produced for these changes.

The G7 acceptance basis in the parent task is explicit: a human USA requesting Event 15 receives one destination notice (`chaosx.nr15.97`) when another valid minor is selected, or one no-candidate/already-used notice (`chaosx.nr15.98`) when no opening can be dispatched.
