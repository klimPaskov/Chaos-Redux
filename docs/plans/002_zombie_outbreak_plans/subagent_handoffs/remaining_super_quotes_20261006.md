### Slot 3 button text and allusion comparison

**Recommended: “The dead inherit the earth.”** This is a five-word adaptation of the Matthew 5:5 KJV beatitude, not a direct quotation and not an attribution to scripture. The source wording is “Blessed are the meek: for they shall inherit the earth.” The inversion is compact, specific to zombies, and states the changed balance of power without commanding a gameplay action. Source: [Matthew 5:5 KJV](https://www.biblegateway.com/passage/?search=Matthew+5%3A5&version=KJV).

**Backup: “Human rule has ended.”** It is direct and spare, but only use it if the slot’s trigger represents an actual collapse of human rule; otherwise it overstates the result. **“The old world is gone.”** is a less literal alternative if the event signals irreversible social collapse but not human extinction. **“Hold the last refuges.”** is an action-like alternative, but use it only if the event is specifically about defending surviving enclaves.

The selected wording reworks only the short idea “inherit the earth”; it does not reproduce a full verse. Bible Gateway labels its KJV text public domain, while UK publication rights in the Authorized Version are administered by Cambridge University Press. If the main agent instead chooses a verbatim KJV line, follow the UK rights note above.

### Slot 5 button text comparison

**Recommended: “Count them, bury them, rebuild.”** It has a clear three-part rhythm and joins memorial duty to recovery. It reads as a response to the defeat and does not claim the player has already completed any action.

**Backup: “Mourn the dead. Build again.”** This is plainer and slightly less distinctive. **“We will remember them.”** is directly from Binyon’s selected quote and would make the button redundant, so avoid repeating it. No cultural source is claimed for either original-prose button.
