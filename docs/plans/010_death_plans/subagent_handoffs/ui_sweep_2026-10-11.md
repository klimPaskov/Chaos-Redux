# Event 010 Black Atlas visual sweep

## Outcome

No GUI source change was made. The current source geometry matches the parent-accepted four-tab reference, and no specific new layout defect was confirmed from source alone. Production visual acceptance remains unresolved because both allowed `hoi4.gui_render` attempts returned `Transport closed` without artifacts. This is a source review and tool-gap handoff, not a visual-pass claim.

## Ownership and accepted design

The interface belongs to Event 010 Death. The independent root is `death_black_atlas_container` in `interface/010_death_black_atlas.gui`; its player-context bindings are `death_black_atlas_scripted_gui` in `common/scripted_guis/010_death_black_atlas_scripted_gui.txt`. `death_country_containment_category` in `common/decisions/categories/010_death_categories.txt` attaches the window. The opener is `death_open_black_atlas` in `common/decisions/010_death_decisions.txt`, entered after public reveal while Death is undefeated.

The `DTH` identity owns the event, but the Atlas actor is a human country other than DTH: the opener explicitly excludes Death. The baseline fixture used `USA` as the human consumer after public reveal. That is a declared synthetic actor fixture, not a campaign observation; the category's response-access condition could not be production-rendered.

The parent accepted the four-tab layout and native Close control under the user's Event 010 release authorization on 6 October 2026. The accepted design preserves all eleven summary values, displays no more than four per pane, defaults to Seas, shows Book only under the existing forbidden-method condition, and falls back to Seas if Book loses visibility. The acceptance basis, mappings, state rules, and limits are in [acceptance.md](final_black_atlas_gui_audit_2026-10-06_evidence/reference/acceptance.md). The larger six-panel dashboard remains unresolved and was not implemented.

Current hashes at review time are `7EA8CF06F2A1ACDDF0775A33B07D2607C3F2F354D59FAE074F327937C57CD37A` for the `.gui`, `A2721CEB482D74210CBF1A2CABEAB99BFE636026FE810ACBBE9BA02F2FBBE0F0` for the scripted GUI, `E15C4DC286F70B45DCC3350E0B1A1D4B2636AEEA35C2E89288910A9974A6F010` for `interface/010_death.gfx`, and `842EA03CDAD8EB95DBF8368C316F08BF63E02C90DF2A8F6CB8091971056A6462` for the GUI localisation. These files were clean at the start and remain unedited.

The root is 520x236, matching the existing `death_black_atlas_background.dds` dimensions. The animated header sheet is 4000x36 with eight frames, giving 500x36 per frame and matching its x=10,y=8 placement. The title at x=22 has maxWidth 450 and ends at x=472, leaving an 8 px gap before the 32x33 Close control at x=480. Tabs use the installed 116x36 `GFX_tab_small_116` frames at x=22, 142, 262, and 382, y=46. The panes share x=22,y=82 bounds of 476x112 and are visibility-exclusive. Labels use x=22,width160 and values x=194,width304, preserving a 12 px gutter. The footer sits at x=22,y=206 with width478,height22 and ends at y=228, leaving an 8 px bottom margin.

No source-geometry defect was established. Paired tab elements and pane bounds overlap by design and are guarded by mutually exclusive scripted-GUI visibility triggers. The maximum pane budget is four values: Seas has four; Fronts has four, counting Watch current and maximum separately; Compact has three; Book has one. The four tab actions plus Close are the five navigation choices. None spends a cost or changes gameplay. The fourth tab position is intentionally empty when Book is hidden.

The normal fixture would keep all tab flags clear, show selected Seas, and hide Book. A selected Fronts fixture sets only `death_black_atlas_tab_fronts`; a Book fixture additionally requires one of the existing forbidden-method flags. A locked Book fallback fixture keeps the stale Book tab flag set but clears every forbidden visibility flag, so the Book pane and tab disappear and Seas remains selected. `death_black_atlas_gui_header`, the short tab labels, stage/coast/line/compact bands, and 42-character footer fit the accepted reference bounds. There is no displayed state name in this Atlas, so a long state-name case is not applicable; a long-text check should use the actual longest coast status, `all remaining coasts exposed`.

The installed background, static header, eight-frame animated header, vanilla tabs, and vanilla Close sprite are present and remain unchanged. The source keeps text and interactive controls native; no raster replacement, new art, GFX registration, or asset handoff is needed.
