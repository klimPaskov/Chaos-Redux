# Final GUI scenario inputs

The normal screen models a generic neutral Hungarian administration with an active controlled site, reform access, adequate civilian factory capacity, no restricted inventory capacity, and no enemy forces near the selected site.
The evidence order is visible but disabled by its location requirement.
The selected location is Northern Hungary with one camp building level and a declared test input of 1,250 cumulative civilian deaths in the state.
These are test inputs, not a claim about a running campaign or historical figures.

`sites_all_orders` deliberately activates every existing action to stress the maximum layout.
It is not a valid normal Germany route; Germany uses its dedicated country kit.
The long-name locked fixture uses ten building levels and 999,999 recorded state deaths to stress text width and unaffordable costs.
All selected-site price getter values in the render fixtures are calculated from the current `camp_site_cost` coefficient table for their declared building levels.
The normal case and hovered case share the same quote.
Legacy policy and territory activation fixtures remain separate from selected-site quotes.

The source-linked GUI render verifies native layout and states under these explicit inputs.
It does not execute the quote, debit, casualty effects, or campaign progression.
