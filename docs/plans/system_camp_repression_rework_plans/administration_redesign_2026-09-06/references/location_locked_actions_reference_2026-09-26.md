# Locations locked-action reference

Acceptance basis: the user's instruction that contextual actions and disabled states be clear, separate native controls.
The [current-source 125% stress baseline](../mcp/after/locations_stress_current_source_125.png) has a selected long-name site, a scrolled roster, large values, a hovered purpose control, and a locked survivor-release control. The locked release button is dark but says `Release Survivors`, making its unavailable state indistinguishable from an ordinary resting action.
The intended correction retains the exact 900×540 native Locations geometry and the same separate active/locked button pairs. A locked work, purpose, or release button uses its own short `Unavailable` label; its existing requirements tooltip remains attached, and its scripted GUI `click_enabled` is always false. Available controls keep their current action labels and click effects.
No bitmap control, extra panel, gameplay payment, or new state selector is introduced.
The [post-edit 125% MCP image](../mcp/after/locations_stress_locked_label_current_source_125.png) confirms that `Release Unavailable` fits the existing button next to the hovered `Change Purpose` control without clipping, shifting the list, or changing the selected site's values.
