# Locations locked-action tooltip reference

Acceptance basis: the user-approved three-view native administration interface requires each contextual action to show its current requirements, blocked reason, cost and consequence in the tooltip. This is a scoped repair to the established 900×540 Locations layout, with no geometry or background change.

The baseline images are [`locations_locked_label_current_source_1920.png`](../mcp/after/locations_locked_label_current_source_1920.png) and [`locations_locked_label_current_source_1280.png`](../mcp/after/locations_locked_label_current_source_1280.png); the 125% stress baseline is [`locations_stress_locked_label_current_source_125.png`](../mcp/after/locations_stress_locked_label_current_source_125.png). The intended reference keeps every native rectangle and its concise unavailable label in exactly the pictured position, while the affected button owns a reason-specific native tooltip.

| Reference region | Native element | Intended state and tooltip |
| --- | --- | --- |
| Left contextual action | `camp_admin_site_work`, `camp_admin_site_work_locked`, `camp_admin_site_work_locked_empty`, `camp_admin_site_work_locked_purpose`, or `camp_admin_site_work_locked_mandate` | Mutually exclusive native controls allow a work order only for a living labor or penal cohort under a coercive mandate; the locked control names the first missing operating-site, purpose, custody or national-mandate condition. |
| Middle contextual action | `camp_admin_site_role` or `camp_admin_site_role_locked` | The active purpose order displays the current political-power quote and killing-role consequence; the locked control states that this is not an operating site under the player's authority. |
| Right contextual action | `camp_admin_site_release`, `camp_admin_site_release_locked`, `camp_admin_site_release_locked_site`, or `camp_admin_site_release_locked_empty` | Mutually exclusive native controls distinguish absent operating authority, living-survivor exhaustion, and a government that cannot authorize release. Each retains the same 164×38 rectangle and disabled visual. |

The previous baseline used `camp_admin_site_release_tt` for both active and disabled controls; it explained the general release action but not which requirement blocked the current state. `camp_admin_site_work_tt` and `camp_admin_site_role_tt` had the same issue for their locked controls. The first zero-custody render also exposed an active Pause Work button with nobody in custody; the shared click and effect predicate now requires living custody, a labor or penal role, and a coercive mandate. The repair uses separate fixed localisation keys because the selected-site predicates are explicit and the earlier dynamic scripted-localisation picker tooltip made MCP inspection time out. No new asset is required.

The connected `hoi4.reference_context`, `reference_search`, `reference_read` and `source_lookup` routes are still absent; exact offline GUI, trigger, scope, localisation and vanilla sections, with hashes, are recorded in [`local_reference_evidence_2026-09-26.md`](../mcp/local_reference_evidence_2026-09-26.md).
