# Five-state Japan occupation-control sensitivity

Disposition: implemented as a source-model sensitivity, not accepted as a historical loss calibration or live-engine receipt.
Acceptance basis: the user's request for distinct Japanese occupied-China, Pingfang, evidence and outbreak paths, with cause-separated actual population losses.

Installed vanilla history assigns `controller = JAP` on `1938.10.25` to Beijing 608, Nanjing 1035, Shandong 597, Jiangsu 598 and Qingdao 743 while retaining `owner = CHI`.
November 1938 is the first full month after these entries.
The test assumes continued direct JAP control through July 1945, the last full month before the August surrender order, because the selected installed state histories record no later controller override.
This is an explicit game-history continuity assumption, not an archival province-by-province control series or a live campaign state.
[U.S. General Order No. 1](https://history.state.gov/historicaldocuments/frus1945v07/d390) and the [U.S. Army's *China Offensive*](https://history.army.mil/portals/143/Images/Publications/catalog/72-39.pdf) bound the endpoint; they do not verify every state controller for every intervening month.

`test_five_installed_direct_japan_control_states` reads the installed initial state populations, applies the unchanged 90% China exposure share at source enrollment and the unchanged 0.1% monthly Japanese campaign fraction for 81 full months, then closes each living row.
It measures one source-model occupation-cause debit per state and month, tests population conservation and prevents an August post-window increment.
No mortality coefficient or source population was tuned to a casualty target.

This occupation-only arithmetic is deliberately separate from detention, forced labor, Pingfang institutional deaths, outbreaks and killing-center causes; each of those remains zero in this fixture because it has no measured receipt for them.
State 328 Kirin/Harbin is a MAN-subject territory that can support the separately gated Pingfang institution but cannot be inserted into the direct-JAP occupation row without changing the controller rule.
The [NARA Unit 731 archive](https://www.archives.gov/iwg/reports/japanese-interim-report-march-2002-1.html) supports a distinct institutional path, not an inferred institutional death quantity for this state-level test.

The earlier [China archival snapshot sensitivity](historical_benchmark_2026-09-25.md) varies a 160-million occupied-area *claim* reported in a [17 August 1945 FRUS telegram](https://history.state.gov/historicaldocuments/frus1945v07/d380).
That claim includes areas held by Japan and puppets, so the resulting one- and 38-month tests cannot be added to these five direct-JAP rows or treated as a direct-JAP census.
The present 3,863,319 model deaths are not a sourced historical estimate for these states: the 1936/installed starting population is a proxy for the unknown October 1938 local population, actual territorial control and competing violence or movements are unverified, and no physical HOI4 population receipt or AI campaign execution has been observed.
The result is a warning about scale and the need for origin-preserving movement and cause separation, not a calibration success.
