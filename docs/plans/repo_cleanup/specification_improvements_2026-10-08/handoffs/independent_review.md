### IR-01: restore the camp terminal boundary

The [immutable camp core base, line 306](C:/Users/klimp/AppData/Local/Temp/chaos-redux-specs-audit-20261008-qgzbgbrz/proposals/migration_repression/base/docs/specs/system_camp_repression_rework_specs/specs/system_camp_repression_rework_spec_part_1_core_loop.md:306) says: “World-end scenario hooks should remain indirect. This system can help raise chaos and create world threats, but a camp network itself should not become a world-end scenario unless a country-specific chain, such as the Mengele Directorate, reaches its own terminal world-order route.”
The first reviewed candidate replaced the complete integration passage and ended at line 309 with “Require one custody settlement, conserved movement/reception and preserved PAUSE; the takeover's engine, visual and probability gates remain open.”
That kept mortality safeguards but lost the independent limit on terminal scope.
Part 3 retains the allowed Mengele route, which does not reproduce the prohibition on turning an ordinary camp network into its own world end.
The repaired candidate restores: “A country-specific chain such as the Mengele Directorate owns terminal world-order progression; the shared camp network contributes only its existing Chaos and threat consequences.”
Disposition: resolved by restoring the source boundary; final candidate acceptance remains parent-owned.
