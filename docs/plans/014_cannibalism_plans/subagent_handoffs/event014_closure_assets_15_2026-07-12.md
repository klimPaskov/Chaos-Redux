## Scope and result

Every artwork was independently generated with the Codex built-in imagegen route. No sourced, reused, default, placeholder, copied, recoloured, or transformed existing icon was used. No animation was required. No gameplay, localisation, GFX, spec, spreadsheet, or skill file was edited, and no commit was created.
