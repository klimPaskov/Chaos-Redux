Date: 2026-08-24

## Executive result

The source package covers all nine required custom sub-unit IDs and maps each ID one-to-one to a hidden activation technology, a named locked template, Event 019 provider 523, and the idempotent CXT extension. No custom equipment archetype was added, so `common/script_enums.txt` needs no Event 014 equipment entry. `Bone Riders` uses the custom cavalry battalion and `Scavenged Elephant Column` uses the installed vanilla `elephantry` battalion. The new `cannibalism_reset_event014_activation_technologies` helper clears exactly the nine Event 014 bridge technologies at reusable rollback/release and before a new incarnation's current bridge grants, without resetting vanilla `elephantry`, ordinary donor technology, CBL's additive technology union, or ZZZ technology.

The live origin set is exactly Island Host, Siege Commune, and March Host. A case-insensitive runtime-source search under `common`, `history`, `events`, and `localisation` found zero `Prison Host` or `prison_host` matches; historical handoffs may still mention the retired proposal and are not runtime content.

All nine definitions are inactive at database load and have explicit irregular-infantry classification, speed, strength, organisation, damage, defence, supply, and equipment contracts. The ten shared templates are locked and set to `force_allow_recruiting = no`, while the existing paid formation effects own manpower, Larder, support equipment, artillery equipment, infantry equipment, motorized equipment, caps, and Deaths accounting. The source cleanup paths delete all ten templates and units.

The only blocking validation limitation is current-workspace HOI4 MCP access. The post-patch `hoi4_tech_inspect` and `hoi4_tech_render` calls returned `status = error`, `code = WORKSPACE_NOT_REGISTERED`, and zero artifacts for workspace `event014_country_audit_20260824`; a bounded no-workspace technology call also timed out without a result. The bounded Event inspect/render and Warlord focus inspect/render calls returned the same `WORKSPACE_NOT_REGISTERED` blocker, so no current engine artifacts are claimed for those call sites. A prior registered-workspace technology pass is preserved in `event014_unit_activation_fix_v1.md` and reports nine one-to-one technology rows with no source issues plus a representative render with no unresolved icon sprites. The installed package has no separate Technology Tree Viewer.
