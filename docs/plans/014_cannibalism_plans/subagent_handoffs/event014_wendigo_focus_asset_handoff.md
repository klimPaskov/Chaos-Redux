# Event 014 Wendigo Focus Asset Handoff

## Scope and result

This bounded asset tranche supplies the missing exact 28 DDS focus icons for the post-reveal original-ZZZ Wendigo Hannibal overlay. It does not alter the focus tree, reward effects, localisation, sprite registration, GUI, audio, spreadsheet, or catalog.

The final set is complete. Every focus has its own independent fictional gore-heavy imagegen source and its own 94 by 86 BGRA DDS at the already registered path.

## Skills and references used

- `chaos-redux-event-assets` governed asset type separation, focus-icon size, source preservation, DDS placement, manifest, contact-sheet, and handoff rules.
- `imagegen` supplied 28 distinct built-in generations and the installed magenta chroma-removal workflow.
- The required offline wiki core pages, National focus modding, and Interface modding were consulted.
- Vanilla `interface/goals.gfx`, `interface/goals_shine.gfx`, and representative focus DDS art were inspected.
- The full Event 014 focus, Wendigo, asset, acceptance, cultural-guardrail, focus-route, asset-inventory, graph, asset-prompt, and overlay-handoff requirements were read.
- `common/national_focus/014_cannibalism_wendigo_focus.txt`, `common/scripted_effects/014_cannibalism_wendigo_focus_effects.txt`, and `interface/014_cannibalism.gfx` were read in full.
- The dedicated focus-reference folder named by the asset skill was absent, so the documented fallback used vanilla focus art, the existing Event 014 focus family, and established Chaos Redux Wendigo palette/body-horror material.

## Validation evidence

- Exact focus IDs, registered texture paths, processed PNGs, and final DDS files match 28-for-28.
- All DDS files are 94 by 86, 32,464 bytes, one-mip uncompressed 32-bit BGRA/B8G8R8A8-style textures.
- Every DDS decodes pixel-identically to its processed PNG.
- Source, processed, decoded-pixel, and DDS SHA-256 sets each contain 28 unique values.
- The 256-bit perceptual dHash set contains 28 unique values. The closest pair differs by 73 bits, ruling out recolor/transform duplication.
- All alpha masters have transparent corners and no surviving magenta key pixels or fringe.
- Actual-size processed and decoded-DDS contact sheets were reviewed. All 28 icons remain legible and match their focus meanings.
- Cultural/content review found no borrowed living Indigenous insignia or regalia, readable text, stock icon, real victim, or fallback art.
