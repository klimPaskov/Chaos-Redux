## Resolved pre-lock first-band AI design

The pre-lock Wendigo target-priority package intentionally uses fixed first assignment:

- `cannibalism_wendigo_apply_new_scored_enemy_priority` checks `cannibalism_wendigo_prelock_scored_priority_targets` before applying a band and records each target after the first application.
- Repeated pre-lock calls can discover newly valid targets without stacking duplicate entries on already recorded targets.
- An already recorded pre-lock target keeps its first low, medium, or high band.
- `cannibalism_wendigo_apply_scored_terminal_priorities` is a separate post-lock pass.

Official `effects_documentation.md` documents `add_ai_strategy` and exposes no corresponding scripted removal effect. The current source contract therefore does not falsely promise continuous removal or re-banding.

This behavior is promoted consistently in:

- `specs/014_cannibalism_spec_part_9_ai_balance_and_integrations.md`;
- `specs/014_cannibalism_spec_part_12_acceptance_criteria.md`;
- `matrices/ai_strategy_matrix.md`;
- `docs/events/014_cannibalism.md`;
- `quality/package_status.md`;

Each surface calls it resolved intentional design and distinguishes it from the separate one-time post-lock escalation. It is not a limitation awaiting remediation, an accepted residual P3, or an open finding. Former P3-01 is closed with P3 at zero.
