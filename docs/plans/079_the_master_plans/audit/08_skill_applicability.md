## Profiles used for planned delegation

The architecture, decision, AI, UI, asset, icon, writing, spreadsheet, documentation, country-package, completion, and improvement roles have narrow briefs in the dispatch plan. The repo explorer has a bounded engine-evidence task. These are planned roles, not executed contributors.

The portrait, focus-tree, 3D, super-event audio, and super-event text profiles are not assigned production work because that work would add unrelated surfaces to this event. The skill maintainer is relevant only if implementation discovers a reusable skill defect. It must not turn Event 79-specific tuning into a project-wide instruction.

## Conflicts observed in supplied profiles

Some specialist profiles contain older production details that differ from their owning skill. The 3D profile contains model/tool-direction differences, the super-event audio profile has a different duration range from its owning skill, and an older completion profile can imply a broader GUI rewrite than the current GUI skill requires. None of those conflicts changes Event 79's planned production surfaces.

During an actual delegated task, the parent must resolve the applicable conflict explicitly against the current owning skill and user task. This planning package does not modify the source skills or pretend that every profile instruction can be executed simultaneously.
