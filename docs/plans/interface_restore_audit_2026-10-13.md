## Scope and method

The owner plan `docs/plans/chaos_redux_restore_plan_2026-10-12.md` was read fully before work.
The audit covers every reachable commit from 1 August 2026 touching `interface/*.gui`, `interface/*.gfx`, including interface descendants, or `common/scripted_guis/`.
The classification uses actual parent-to-commit diffs, named controls/sprites, current survival and supersession, and acceptance records; a commit title or a missing acceptance record alone does not establish an unrequested change.
Each source can be reproduced with `git show <commit>^:<path>` and `git diff <commit>^ <commit> -- <path>`; disputed token changes were also traced with `git log -S/-G`.
Add-only registries were checked separately from edits to existing sprite definitions, so new portraits, report art, focuses, counters and mechanic assets are retained.
No original artwork was reinterpreted; the restored bindings point to their original assets.

Classes: **a** means new window, control, mechanic integration or new content registration; **b** means a concrete defect repair, an owner-directed restoration or mechanical maintenance without layout change; **c** means existing-window restyling or information/control removal.
Mixed commits carry multiple classes because their hunks have different purposes.
**c?** was the initial audit’s uncertain classification, not a finding that the owner did not request it; the current action for every such choice is resolved above.
An explicitly authorized redesign is marked as a retained exception in the c-shaped rows; requested redesigns do not honestly fit the user's category “unrequested redesign.”
