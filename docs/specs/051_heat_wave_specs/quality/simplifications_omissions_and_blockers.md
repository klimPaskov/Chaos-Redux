# Simplifications, Omissions, and Blockers

## Design coverage

No requirement from the attached Event 51 rough brief was intentionally removed. The package expands every named system and adds implementation, AI, presentation, asset, achievement, validation, and anti-bloat detail.

The package is a planning deliverable. It does not claim implementation.

## Blockers in this environment

### Live repository unavailable

The Windows Chaos Redux repository was not mounted. Existing Event 51 files, exact identifiers, current owner APIs, event-log registries, cluster scripts, map-mode source, super-event slots, and workbook structure could not be inspected directly.

Result:

- file paths and new identifiers are proposals
- implementation prompts require collision and precedent checks
- no source code was changed

### Offline Paradox wiki unavailable

The required offline wiki snapshot was not supplied in the mounted files.

Result:

- no claim of engine-syntax verification
- implementation must read the required pages before editing

### Installed vanilla and reference mods unavailable

The Hearts of Iron IV installation and approved Workshop references were not mounted.

Result:

- no final modifier, map, event, decision, GFX, audio, or UI syntax was selected from live precedents
- asset dimensions remain subject to consumer inspection

### HOI4 MCP unavailable

The configuration defines the server, but the executable and repository working directory were not available here.

Result:

- no event inspect, render, or compare
- no probability inspect, sweep, or compare
- no map inspect or rewrite proof
- no GUI or technology evidence

### Custom subagent runtime unavailable

All twenty subagent definitions were read, but no custom subagent invocation tool was exposed.

Result:

- role-based passes were performed manually
- no subagent-generated patch, asset, or audit report is claimed

### Actual terrain conversion unverified

The rough brief requires eventual desert and wasteland outcomes. HOI4 terrain ownership and the current map tool route could not be inspected.

Result:

- the permanent environmental ledger and exact design are specified
- actual map conversion remains an implementation evidence gate
- no modifier-only fallback is pre-approved

### Assets not produced

This task requested specifications. Image and audio assets were not generated, sourced, processed, converted, or wired.

Result:

- complete briefs and handoff requirements are supplied
- every final asset remains pending implementation

### Final super-event quote and audio not selected

Research directions and source pools were established, but the live audio catalogue, rights files, and dedicated researcher outputs were unavailable.

Result:

- no invented quote or unverified recording was selected
- the final super-event remains dependent on text and audio research

### Workbook not edited

Only CSV exports were supplied. Project rules identify the XLSX as the only editable source.

Result:

- the stale Fire-Once conflict is documented
- no CSV was edited
- a spreadsheet worker prompt defines the later update

### In-game validation not performed

The game and explicit autonomous debug-playtest authorization were absent.

Result:

- no live behavior claim
- detailed acceptance scenarios are supplied for later user and tool validation

## Explicit design exclusions

The following were deliberately excluded because they would add unrelated maintenance or duplicate existing systems:

- universal water stockpile
- extra public meters beyond intensity and state stress
- separate heat death, Famine, or Migration ledger
- direct heat Air Contamination source
- repeated super-events

These are design decisions, not missing work.

## Final planning status

The specification package is complete as a planning artifact. Implementation status remains not started in this environment.
