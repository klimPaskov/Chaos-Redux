## Authorized assets

Create only:

- nine event, report, recovery, and super-event image masters defined as `HW-ART-01` through `HW-ART-09`
- one decision category picture, static fallback, and accepted frame animation package
- twelve decision icons
- Local Heat Stress, water failure, and environmental degradation state icon families
- one national Heat Emergency idea icon only if a live consumer is implemented
- twelve separate achievement icon triplets after final achievement IDs are locked


## Visual rules

- period-authentic 1936 to 1945 documentary treatment
- no modern vehicles, electronics, plastic tanks, road markings, or emergency branding
- no readable generated text
- strong human and infrastructure subjects
- icons use native transparent backgrounds and preserve alpha
- full-canvas event and category scenes use the consumer's required opaque treatment
- each icon type has separate source art
- no primitive local drawings or resized unrelated icons

## Animation

Use real per-frame source artwork. Do not create final motion through transforms, filters, opacity, or recoloring of one still.

Deliver source frames, processed frames, sheet PNG, sheet DDS, static PNG and DDS, GIF preview, contact sheet, manifest, and GFX handoff.

## Output and ownership

Use temporary evidence under `docs/assets/051_heat_wave/` and final runtime assets under event-scoped engine folders.

Asset workers do not edit gameplay, events, decisions, localisation, GUI, or workbook files. The parent owns non-portrait wiring.

Record prompts, sources, rights, hashes, dimensions, alpha mode, runtime path, sprite, consumer, and review status.

Mark blocked assets honestly. Do not substitute placeholders.
