# Asset brief

## Visual direction

The event uses neutral, grounded military imagery suitable for many countries in the late 1930s and 1940s.
Its visual subject is a contested frontier, with real troops and boundary markers.
Avoid a famous historical battle, identifiable national propaganda, named leaders, and geographic details that imply one fixed country pair.
Generated staged imagery must not be presented as an authentic historical photograph.

Inspect the canonical visual references and the actual owning consumer before producing final assets.
The supplied asset skill defines the processing requirements, but the reference shelf itself was not available for visual review in this planning pass.
The following sizes are specified by that skill where noted.
An unlisted consumer size must be measured from its canonical reference and definition.

## Report and news handling

Produce the report and news as separate compositions for their different shapes.
Do not make the wide news scene by stretching the report image.
Use the project's report processor to produce its tilted photographic-card treatment and transparent corners.
Use the canonical news treatment in black and white.
Report imagery may use the processor's supported restrained sepia or black-and-white treatment according to the reference family.

The report can be reused among compatible country notices within this event.
An attacking capture and a defensive retention must still have distinct written outcomes.
A neutral border scene can support both without implying a particular winner.
The news composition should suggest an outbreak affecting several frontiers without painting a false world map or tiny unreadable flags.

## Icon handling

Category and achievement symbols must remain readable at their final native sizes.
Use transparent subject sources where the project processor requires them.
Keep important detail away from areas covered by canonical frames or overlays.
No text, numbers, miniature labels, or nation-specific flags are required inside these icons.

For achievements, inspect `achievement_template.png`, `achievement_template_grey.png`, `overlay.png`, and the current `process_achievement_icons.py` workflow.
Derive the state treatments deterministically from each approved subject source.
The icon worker supplies subject sources, processed finals, native-size previews, provenance, and exact IDs.
The parent owns runtime wiring and acceptance.

## Acceptance

Every final image must have the correct canvas, alpha behavior, consumer, filename, and registry identity.
Review the report in an actual event window, the news in its actual news consumer, the category symbol in the native decision interface, and all achievement states in the shared achievement interface.
A source image at generation resolution is not the acceptance view.

No assets are generated by this planning package.
The separate asset and achievement prompts define the production work and explicitly require the unavailable reference inspection before final output.
