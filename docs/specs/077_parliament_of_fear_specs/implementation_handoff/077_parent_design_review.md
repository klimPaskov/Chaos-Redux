# Parent design review

This is the authoring assistant's own consistency review. It is not an independent subagent audit and does not close the mandatory improvement-loop requirement.

| Issue found | Decision | Applied result |
|---|---|---|
| Accusation and loyalty were at risk of becoming one status | Separate support, evidence, and occupancy | An accused loyal bloc can still support the government until an actual suspension or withdrawal |
| Purging opponents could reduce the majority denominator | Keep the chamber at 100 influence seats | Control requires 51 regardless of vacancies |
| A fully occupied minority chamber could lack an appointment route | Add a confidence-settlement case inside negotiated protection | Recovery can obtain support without inventing vacancies or a fifth action family |
| Low political power could make a crisis permanently unwinnable | Add slow preliminary review and institutional restoration | The country can trade time and political control for recovery |
| A parliamentary loss could incorrectly remove any head of state | Add profile-specific legal and authority routes | Presidential and military outcomes have distinct predicates |
| Later conspiracies could retroactively justify earlier false charges | Freeze original truth and create new causal plot records | Old false accusations remain false |
| Great Purge could become an unlimited removal loop | Limit waves, losses, and instance frequency | Containment can stop uncommitted waves while losses persist |
| Native purges and other events could remove the same person twice | Require explicit character and crisis ownership | Unsupported overlapping native phases defer the new crisis |
| Civil-war connection could split the same country twice | One committed split owner and a handoff record | Event 021 and Event 077 share one actual outcome |
| Aftermath achievements could lose progress during cleanup | Separate persistent aftermath and history records | Cleanup releases the active slot without erasing valid long-term progress |
| Numeric implementation detail could dominate the source spec | Place exact contracts, machine-readable anchors, and test matrices in supporting handoffs | Numbered parts remain primarily gameplay and presentation design |
| Extra meter and button ideas could bloat the interface | Retain three readouts and four action families | Evidence and impairment stay contextual |

## Additions considered and rejected

A separate legitimacy meter, an investigative-resource currency, and a permanent conspiracy-strength gauge would add competing maintenance tasks. Their useful information is represented through support agreements, institutional impairment, evidence descriptions, and preparation warnings.

A custom political focus tree for every possible target would duplicate existing country content and weaken dynamic compatibility. The design preserves meaningful native or inherited political content. Successor country packages still require a full identity and asset-conservation audit.

A generic death total derived from abstract seats would misrepresent what those seats mean. Deaths are recorded only for actual committed character or established population outcomes, with shared systems retaining their ownership.

Generating final historical quotes, named portraits, and audio choices before source verification would create false authority. Those production gates remain explicit.
