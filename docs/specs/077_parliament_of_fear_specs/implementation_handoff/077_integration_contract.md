## Entry transaction

Build the target pool from the deduplicated union of valid major countries and player-controlled countries. Apply the shared country crisis-burden selection rules. Exclude unresolved Event 077 instances and countries with no meaningful compatible institution. Native purge conflicts use a certified adapter or temporary deferral, not unilateral deletion of native state.

Eligibility and capacity are checked before the root event is accepted as a real firing. Reserve exactly one shared crisis slot for the selected recipient, then initialize the instance atomically. The active three-crisis limit includes Event 077 as one crisis. An empty pool, failed reservation, or invalidated target must not create a ghost instance, increment the repeatable success state, or consume an opening Chaos contribution.

The recipient, log actor, and country context must agree. Initialize through the established recipient event pattern. Do not assume a shared selector's ROOT is already the affected country. The root's existing namespace remains the integration point, while internal IDs are allocated only after checking the complete live namespace.

## Persisted instance model

Each active country owns one instance identity, lifecycle stage, Paranoia, occupied influence, governing support, generated blocs, current cases, active commission, appointment queue, agreements, institution damage, plot records, evolution state, purge-wave state, source-overlap ledger, and cleanup obligations.

A case owns its original truth category, source identity, available evidence, target links, findings, government actions, and completion state. New evidence references an existing source or creates a new one with a material reason. It does not reroll guilt. A later coercion-created plot has a new organization record and a causal link to the prior action.

An appointment record owns the selected vacancy group and expected restoration process. Revalidate at completion so that an external appointment or country transition cannot overfill the chamber. A character reference is unique across all roles and cases. Its role-specific removal is recorded once and reconciled with its owning native or Chaos Redux system.

Persistent achievement and aftermath records are separate from disposable active-case data. Normal cleanup must preserve the records required for the two-crisis achievement and 60-day post-purge recovery achievement.

## Processing and callback safety

Use existing shared country-local update hooks where appropriate. Do not add a new world-wide daily, weekly, or monthly country scan without user permission. An active country's bounded assessment can inspect its own state and event-owned records. External changes should arrive through existing hooks or explicit adapter notifications.

There must be one pending ordinary update chain per instance. Clear its pending marker before evaluating and rearm only when the instance remains active. Every delayed inquiry, appointment, warning, and purge callback carries a resolvable country and instance identity. A callback from an earlier instance must be inert.

Selection, initialization, removal, split commitment, closure, and crisis-slot release are idempotent. Repeated evaluation in the same tick or after a reload cannot duplicate payment, characters, global Chaos, or achievement credit.

No random resolution occurs merely because the GUI opens, closes, refreshes, or changes selected bloc. Commitment establishes or consumes the appropriate authoritative outcome. The engine's available deterministic and save-persistent mechanisms must be verified from actual references.

## Government adapter contract

Each profile provides its verified institution name, bloc-generation inputs, interpretation of governing support, valid appointment processes, allowed removals, legal leadership-change path, candidate leadership sources, and consequences of minority support.

The adapter must expose a genuine recovery path when support is below 51 and there are no vacancies. A confidence-settlement case allows negotiated support through Protect the Accused without inventing a personal allegation against the prospective partner. Institutional restoration remains available when vacancies exist and cash is insufficient.

A generic fallback can describe an unspecified governing establishment. It cannot invent an elected parliament, monarchy, secret police, or constitutional power. Country-specific profile claims are blocked until supported by repository content and appropriate primary references.

The Soviet-style comparison is a design reference. The supplied archive does not include the installed Soviet paranoia implementation. Inspect the native files and the country's character-removal ownership before claiming coexistence is supported.

## Supported data and capability gates

The project describes dynamic helper systems, but the exact runtime contracts must be inspected before use. Verified documentation mentions `union_compatible_researched_technologies_from_donor`, which uses the `technology_union_donor` regular event target. Reuse it only when its actual implementation and required scope have been confirmed. It does not grant permission to annex a country or copy every technology blindly.

The documented country classifiers `is_special_chaos_country`, `is_actual_nonhuman_country`, and `uses_normal_civilian_systems` can inform compatibility after live inspection. Special status alone does not exclude an otherwise ordinary human political state.

Intelligence, industrial organizations, and named research figures require DLC and character capability checks. The baseline system works with political blocs and abstract institutions. Missing optional capabilities change the available target representation, not the existence of core investigation and recovery.

The universal cost framework must be read in its actual implementation. The documentation's existence is not proof of a particular callable effect or inline-cost formatter.

## One action-resolution path

GUI controls, decisions, event options, missions, and AI must converge on one validated action contract. The path resolves the selected target and mode, checks current availability, calculates the current quote, checks inclusive affordability, applies a single debit, commits the action, and records completion or cancellation.

Exact known costs are recomputed before commitment. A stale quote returns a revised preview or cancels without payment. A changed character or institution never substitutes a new victim. The same guard applies to manual and AI actions.

No more than four spendable cost types occur on one action, with at most three values in a compact price line. Political sacrifices that are not currencies still require a clear explanation and validated result. Essential low-resource recovery modes must not accidentally inherit a majority requirement from coercive actions.

## Seat and evidence invariants

The influence allocation sums to 100. Governing support cannot exceed filled-and-functioning seats. Suspended and vacant seats do not provide support. A case marker alone does not change support or occupancy. Purged is a committed removal history and visual transition, after which the seat is vacant.

The fixed majority threshold is 51. Stable recovery requires support of at least 55 and at least 80 functioning filled seats. The exact value 51 is a mathematical majority, not a violation of the project's preference for rounded balance rewards.

Allocation uses current country inputs and a deterministic conservation rule. Rounding cannot produce 99 or 101 seats. Generated blocs receive stable identities for the instance. A new label or sorting order cannot reset agreement or accusation history.

## Leadership and armed-outcome ownership

An ordinary loss of support cannot immediately call a civil-war effect. The government profile first applies its valid confidence or authority process. A coup requires an organized plot and real relevant backing. A civil war additionally requires a viable state and force package.

Only one owner commits a civil-war split. Event 021 and Event 077 must share an explicit handoff result. Both cannot split the same country independently. Preserve meaningful country content and available focus paths when a successor is created. Do not add a superficial bespoke focus tree only to satisfy a checklist.

Character, ship, aircraft, division, equipment, state, and research inheritance must be reconciled. Use a verified native civil-war mechanism where suitable, but test what it actually transfers. Any extra emergency mobilization has a defined source and cannot duplicate inherited forces.

Resolve a successful coup's valid leader before commitment. When no valid alternative exists, the outcome may be an attempted or failed replacement with appropriate consequences. It cannot install an unnamed fictional historical person by default.

## Shared systems and damage

Reuse the event engine's repeatable weight decay, recovery, and cap behavior. The member and cluster count as one pacing development. Event-specific incident frequency must not modify global root-event frequency a second time.

The event's three national-spirit surfaces consolidate administrative crisis, institutional damage, and settlement aftermath. Their exact modifiers are verified against the installed game. Repeated crisis instances update a bounded aggregate and preserve remaining recovery without indefinite stacking or duplicate ideas.

Global Chaos has an attribution ledger. The same removal cannot receive a full institution premium and a full Great Purge premium unless a distinct incremental cause is explicitly documented. Shared war, ideology, annexation, and death sources remain owned by their established systems. Abstract seats never become an invented death count.

## GUI ownership and multiplayer

The event owns its chamber window and decision-category attachment. Shared settings, event log, event details, super-event framework, and registries remain parent-owned. The UI worker receives only the bounded chamber surface.

Selection should be local presentation state where supported. The actual action target and payment are authoritative. Two clients must not accidentally overwrite one another's selection or resolve the same action twice. Verify the engine's available GUI context and multiplayer semantics rather than assuming arbitrary client-local variables exist.

Test multiple active country instances, observers, country switching, reloads, and a country transition with a pending callback. Hidden case truth is never exposed by observer-only debug strings in production.
