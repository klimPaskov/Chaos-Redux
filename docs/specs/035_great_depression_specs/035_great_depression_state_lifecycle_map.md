# Event 35 Great Depression 2.0 state and lifecycle map

## National lifecycle

```text
Independent selection
Event 34 collapse
Financial Contagion conversion
Second Great Depression conversion
    -> validate exact country and source
    -> create or deepen Event 35 episode
    -> apply opening or deepening shock
    -> select or convert Depression Centers
    -> Panic and Contraction
        -> Depression
            -> Stabilization
                -> Recovery proof
                    -> Strong, Uneven, or Hollow Recovery
                -> relapse to Depression
            -> Economic Paralysis emergency
                -> survive and return to active crisis
                -> fail and deepen state or political consequences
```

## Phase transition conditions

| From | To | Required proof |
| --- | --- | --- |
| Entry | Panic and Contraction | API accepted, opening shock and centers created |
| Panic and Contraction | Depression | Minimum opening duration completed and opening mission resolved |
| Depression | Stabilization | Severity below initial stabilization threshold for sustained period, no unresolved emergency |
| Stabilization | Recovery proof | Severity at Recovery Floor, required centers resolved, doctrine consolidation complete |
| Stabilization | Depression | Relapse threshold, failed proof, center reclosure, or major shock |
| Recovery proof | Recovery | Proof duration completed with no invalidating shock |
| Any active phase | Economic Paralysis emergency | Severity reaches `100` and unused emergency receipt is available |
| Economic Paralysis emergency | Active Depression | Emergency succeeds and Severity falls |
| Economic Paralysis emergency | Deeper crisis | Mission fails and guarded consequence applies |

## Depression Center local lifecycle

```text
Distressed
  -> protected or treated
  -> Reopened

Distressed
  -> sustained national and local pressure
  -> Idled
      -> recovery project
      -> Reopened or Restructured
      -> failed project or new shock
      -> Shuttered
          -> major reopening project
          -> Reopened or Restructured
          -> prolonged failure or deliberate policy
          -> Abandoned or Liquidated
              -> long reconstruction
              -> Scarred Resolution
```

## Local stage transitions

| Current state | Improvement path | Deterioration path | Physical loss eligibility |
| --- | --- | --- | --- |
| Distressed | Protection, credit, orders, works | Sustained Severity and local shock | No |
| Idled | Doctrine project and freight restoration | Failed project, blockade, state damage | Normally no |
| Shuttered | Major reopening, trusteeship, restructuring | Prolonged failure or liquidation | Conditional after warning and receipt check |
| Abandoned or Liquidated | Long reconstruction or accepted scar | Further Event 35 deletion blocked by cap | Prior bounded loss only |
| Reopened | Maintain supply and relapse proof | New exact shock can return it to Distressed | No automatic loss |

## Treatment overlays

A center has no more than one main active treatment.

| Treatment | Local effect | National effect | Failure memory |
| --- | --- | --- | --- |
| Protected | Slows deterioration and protects essential output | Lowers industrial pressure | Rescue dependence |
| Public Works | Adds employment and repairs bottleneck | Lowers demand and logistics pressure | Unfinished works |
| Finance Restored | Reopens credit and trade connection | Lowers credit pressure | Guarantee burden |
| Austerity Resolution | Closes unsupported commitments | Lowers fiscal pressure | Unemployment and labor scar |
| Trusteeship or Nationalization | Protects and reallocates capacity | Lowers volatility | Political and efficiency burden |
| Asset Reorganization | Reprices and consolidates capacity | Can lower rescue dependence | Liquidation and concentration scar |

## Event 34 conversion map

| Event 34 region state | Event 35 local start | Special memory |
| --- | --- | --- |
| Completed and protected | Distressed | Strong reopening opportunity |
| Completed ordinary | Distressed or Idled | Existing project value |
| Fragile Miracle Region | Idled or Shuttered | Credit bubble and labor exhaustion |
| Speculative project | Idled or Shuttered | Speculative exposure |
| Unfinished project | Idled | Abandoned Works |
| Failed or abandoned | Shuttered or Liquidated | No duplicate legacy reward |
| Lost industrial state | Disconnected receipt | National shock and state-transfer rule |
| Evolution III corridor center | Shuttered or severe Idled | Network-collapse relation |
| Evolution III secondary state | Internal receipt or visible center | Counts only when cap and importance justify it |

## Ownership transition map

```text
Center changes controller
  -> pause source-country project
  -> freeze payment and project receipts
  -> apply national shock based on industrial importance
  -> preserve state condition
  -> determine new controller validity
      -> normal civilian controller with Event 35
          -> adopt into its center registry if cap and relevance allow
      -> normal civilian controller without Event 35
          -> receive local burden and limited management action
      -> special or invalid controller
          -> preserve state receipt without ordinary management
  -> prevent dual active ownership
```

## Civil-war map

```text
Original country enters civil war
  -> assign national episode owner
  -> distribute live center records by current control
  -> give secondary side only the economic burden it actually controls
  -> preserve doctrine history on original government
  -> new government selects its own valid response
  -> prevent full crisis cloning across minor sides
  -> continue recovery after war
```

## Recovery result map

| Result | Center condition | National condition | Persistent outcome |
| --- | --- | --- | --- |
| Strong Recovery | All centers Reopened or successfully restructured | Low Severity, no unresolved emergency | Best bounded doctrine legacy, fewest scars |
| Uneven Recovery | One mixed or scarred center allowed | Crisis resolved with institutional or regional cost | Mixed legacy and one or two scars |
| Hollow Recovery | Liquidation, abandonment, or major capacity loss | Severity controlled through contraction | Weaker legacy and clear permanent cost |
| Continued Depression | One or more required centers unresolved or Severity too high | Active category remains | No premature closure |

## Cleanup map

```text
Recovery result frozen
  -> cancel invalid missions
  -> settle exact resource commitments
  -> remove temporary national modifiers
  -> convert center treatment into Reopened, Mixed, or Scar state
  -> remove active center arrays
  -> preserve compact episode history and state receipts
  -> apply post-recovery safeguard
  -> keep active national or global evolution consequences only when still valid
```

## Repeat episode map

```text
Recovered country
  -> safeguard period
  -> independent weight remains low
  -> later independent event or immediate valid consequence
  -> new episode reads prior reforms and scars
      -> strong reform lowers matching starting pressure
      -> hollow recovery raises matching vulnerability
      -> bounded starting range preserves recoverability
```
