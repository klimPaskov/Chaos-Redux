Each test needs the current installed references, actual owner adapters, an authorized fixture, and observable evidence. Use the shared registered CXT action or an explicitly prepared test fixture. Daily registration must remain inert.

Record fixture/save identity, implementation revision, relevant settings and DLC, actual actor/asset identifiers, expected versus observed state, and the owner receipts. Separate parser checks, source inspection, tool rendering, simulation, and user-run game evidence. Unknown capability is not a pass.

## Additional mandatory focused cases

The twelve sequences do not replace the Part 17 matrix. In particular, verify current/future subject army control, exact cost quote/debit/refund parity, simultaneous resource commitments to incompatible missions, route-lock idea transformations, no-DLC equivalents, complete focus reachability, every manual profile/intensity, actual country flags and portrait continuity, and long-name/low-resolution UI behavior.

An optional owner absent in a fixture produces no fabricated contribution. Mark the corresponding integration case blocked until that owner and its contract exist. The ordinary event must still work when it does not depend on that missing owner. A core unknown, such as actual character transfer or global control observation, blocks the affected operation rather than being counted as a successful fallback.

Stop broadening tests when the required gate is satisfied and no concrete unresolved risk remains. Keep raw evidence and summaries that distinguish successful exact proof, bounded estimates, sampled outcomes, unresolved observations, and implementation limitations.
