# Inflation planning package

This is the complete accepted design and implementation handoff for Event 100, Inflation. It expands the user's brief while retaining one signed balancing problem, harmful deflation, continuous stabilization, actual-opposition political failure, inherited economic damage, repeatability and the four specified evolutions.

The imported package lives at `docs/specs/100_inflation_specs/`.
The separate review-record archive mentioned by the original author was not included in this import.
It is supporting provenance, and the accepted specification remains readable without it.
Working implementation plans and actual specialist handoffs belong under `docs/plans/100_inflation_plans/` and its `subagent_handoffs/` folder.

All named actions and content concepts are working labels, not final localisation. Numbers are proposed gameplay tuning anchors. The package does not claim runtime implementation, finished art, calibrated AI, native rendering or live-game testing.

The [research record](100_inflation_research_and_bibliography.md#independent-review-and-accepted-refinements) attributes design acceptance to the original planning parent after architecture, decision and improvement-loop reviews.
That acceptance is preserved by this import review, without treating the request to extract and review documents as authorization to implement them.
The supplied-source manifest records the original planning team's reading claim and attachment identities, rather than a current-checkout inventory or proof that this importer read those original sources.
The pinned repository investigation and unavailable installed-game/MCP evidence have separate boundaries in the research record.
Current workflows follow this checkout's AGENTS.md and owner skills, including `chaos-redux-xlsx` for any later workbook work.
To Be Reworked is the package's requested planning status, without a status promotion from importing these documents.
