# Event 014 Cannibalism reveal identity note

This file contains implementation-only identity data for the final reveal. Do not use these strings in pre-reveal player-facing text, Event Details, spreadsheet fields, visible achievements, asset filenames, or public route labels.

## Final reveal leader

True final unifier: Hannibal.

Event 014 creates this leader during Evolution II through hidden network buildup. Evolution II should show indirect signs of a single supreme cannibal leader. Evolution III reveals the leader when the cannibal network is strong enough. After the reveal, he unites cannibal actors into one country or dominant terminal identity and becomes the leader.

## Fusion branch

If the Wendigo country exists when the reveal or terminal branch fires, the cannibal network and the Wendigo country unite under Wendigo Hannibal. This branch receives a new portrait, Wendigo unit access, Wendigo unit training, inherited cannibal country buffs, fused supernatural buffs, and terminal world-end conquest behavior. After the terminal lock, the fused country should be functionally impossible to defeat and destined to take over the world.
