# Research to Design Connections

| Research lesson | Design consequence | Surface |
| --- | --- | --- |
| Isolation and starvation can destroy a strong taboo | Baseline eligibility weights long wars, low supply, casualties, convoy loss, and cut-off formations | Entry event and Field Hunger |
| Discovery often begins through physical evidence | Early reports focus on altered bodies, missing burial parties, empty stores, and avoided positions | Events, reports, Event Details |
| Command failure can create the conditions | Command Integrity tracks rotation, officer replacement, military police, ration discipline, and legal action | Decisions and national spirit |
| Abandoned islands and detention sites can become self-contained disasters | Evolution II selects remote islands, prisons, occupied states, and disconnected garrisons as high-risk targets | State incidents and commune creation |
| Necessity claims can become a moral and legal crisis | Investigations distinguish survival acts, predatory murder, command complicity, and ritual recruitment | Trial events and suppression routes |
| State neglect can turn victims into an organized threat | Harsh abandonment and exploitation improve short-term terror while raising Cell Strength and Warlord Emergence | Exploitation route |
| Cannibal stereotypes have often racialized outsiders | Any normal country can host, all cult identities are invented, and art avoids real cultural regalia | Country packages and assets |
| Wendigo adaptations can erase living cultural context | Reuse only existing Chaos Redux crossover language, add no new claims or borrowed sacred motifs | Wendigo Hannibal branch |
| Cannibalism can be survival behavior without ideology | Baseline stays separate from Evolution I ritualization | Event state machine |
| Organized atrocities require supply, hierarchy, and concealment | Evolution II adds network logistics, prisons, ports, occupied territories, and repeated command patterns | Network mechanic and AI |
| Recovery takes longer than battlefield victory | Liberated states receive trauma, population recovery, burial, and trust missions | Aftermath decisions |
