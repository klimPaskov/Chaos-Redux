# Event 014 Cannibalism localisation handoff

This is a direction file. It does not contain final player-facing localisation.

## General tone rules

- early text is uncertain and investigative
- mid-stage text is institutional and fearful
- late cult text can become openly monstrous
- exploitation text sounds self-damning and severe
- hidden leader text remains concealed before Evolution III reveal and must not use the true name early
- Event Details never list raw effects
- option text can use grim irony only when it fits the actor and stakes

## Dynamic placeholders to consider

- affected country name
- target state or named region
- target army or command if available
- current response posture
- selected island or port
- cannibal country name
- hidden leader actor after Evolution III reveal
- containment progress description
- public fear band
- evolution stage name

## Event text surfaces

| Surface | Direction |
| --- | --- |
| opening report title | short military report title, no cult reveal |
| opening description | disputed reports from units, hospitals, and ration offices |
| discipline option | command response and formal military severity |
| logistics option | practical ration, convoy, and medical response |
| secrecy option | bureaucratic denial and controlled files |
| exploitation option | cruel instrumental response, route-locked |
| public leak news | press and foreign observers react to missing soldiers and field records |
| successful containment | relief and trauma, no victory comedy |
| failed containment | reports multiply and command language loses control |
| Evolution I event | ritual and ideology become visible through repeated behavior and symbols |
| Evolution II event | islands, prisons, and remote garrisons become organized danger zones |
| Evolution III event | network logic, coordinated cult routes, and global fear |
| cannibal country news | open breakaway or commune declaration, severe and public |
| defeat aftermath | records, tribunals, missing lists, and cleanup |

## Decision text surfaces

Decision names should feel like actions by a government or army office. Descriptions should tell the player what the country is doing and what visible risk exists. Blocked text should name missing resources or objectives.

Examples of direction, not final text:

- field kitchen decision uses ration ledgers and guard posts
- hospital audit uses missing wounded and medical records
- prison transfer freeze uses prisoner routes and camp overcrowding
- island inspection uses naval patrols and silent docks
- evacuation uses convoy or rail routes and risk of exposure at destination
- exploitation uses fear as a weapon and hints at later loss of control

## Focus text surfaces

Cannibal country focus text should sound like an abnormal regime building institutions out of hunger, fear, and command. It should not sound like a normal national development tree.

Route tone:

- council route is ritual bureaucracy and controlled obedience
- warlord route is predatory military command
- hidden-leader route is strategic, cold, and concealed until the reveal state. Pre-reveal text should mention obedience, matching orders, and a supreme cannibal leader only indirectly
- restrained consumption route is tactical self-control for survival
- runaway consumption route is accelerated ruin
- expansion route speaks through ports, prisons, roads, depots, and hunting grounds

## Super-event text surfaces

All super-event titles, quotes, button remarks, and cultural references require research. Do not paste working labels into localisation.

Description direction can be drafted after the trigger and role are implemented, but final quote and audio must come from the super-event research workflow.

## Spreadsheet wording direction

Spreadsheet Details should be one readable player-facing paragraph. It should mention:

- random country at war
- reports among units
- containment decisions
- spread to other countries if not contained
- ritual evolution, cannibal islands, hidden-leader unification, and hidden-leader world-end route as non-default escalation

It should not mention:

- variable names
- exact penalties
- raw death calculations
- implementation history

## Pre-reveal secrecy discipline

No pre-reveal player-facing text should use the true leader name, direct identity, or achievement wording that spoils the hidden leader. Before the reveal, use rumours, identical orders, repeated symbols, and references to an unnamed supreme cannibal leader. After the reveal, implementation may use the final name only on surfaces that are meant to show the revealed leader.
