## Required files per package

Every package needs:

- tag or transformation identity
- country definition and history
- names and adjectives
- party and ideology localisation
- leader and portrait
- flags in all sizes
- starting ideas
- focus tree assignment
- decisions and missions
- starting units and templates
- equipment and manpower logic
- commander roster
- AI strategy
- shared special-country classification
- actual-nonhuman classification when valid
- event log actor mapping
- asset manifest entries
- defeat and cleanup logic

The final country-package audit reports P0/P1/P2/P3 all at zero. Every warlord slot has seven regional portrait/name variants, for 56 distinct portraits. Constituent technology union is additive. Original ZZZ retains its country package, while normal queue recruitment for the locked Pack closes during transformation before the first overlay focus.
