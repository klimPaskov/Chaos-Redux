# Event 014 Cannibalism, Part 6: Decisions, Missions, and Scripted GUI

## Decision-system purpose

The player should fight or exploit a living crisis. Decisions must represent logistics, unit control, investigation, suppression, relief, raids, recruitment, population consumption, network operations, unification, and transformation. The category must never become a political-power store.

Every major decision family uses at least one concrete non-political cost or map requirement.

## Ordinary-country category phases

### Phase A: Field breakdown

Visible values:

- Field Hunger
- Command Integrity
- current compromised theater
- active compromised formations
- immediate supply status

Available families:

- logistics relief
- formation rotation
- investigation
- witness and prisoner protection
- legal response

Active mission cap:

- one logistics mission
- one formation mission
- one investigation mission

### Phase B: Ritual cells

Unlocked by Evolution I.

Additional visible value:

- Cult Cohesion

Additional families:

- infiltration
- amnesty
- symbol and supply disruption
- officer network removal
- terror exploitation

Active mission cap can expand through institutional focuses or successful containment.

### Phase C: Organized network

Unlocked by Evolution II.

Additional visible value:

- Network Reach

Additional surfaces:

- selected target state card
- selected foreign node card
- island and port alerts
- warlord country list
- joint suppression actions

The system can open a separate mechanic window because the player now manages multiple countries and nodes.

### Phase D: Military counterwar

Used when communes and warlord countries control territory.

Additional families:

- liberation operations
- blockade
- coalition aid
- commander hunting
- state recovery
- anti-unification actions

### Phase E: Hannibal counterwar

Available after reveal.

Additional families:

- strike network anchors
- break warlord loyalty
- rescue or destroy Larder routes
- protect locally cured countries from external seeding
- stop ordinary terminal progression
- stop Wendigo transformation before lock

## Ordinary decision family map

### Supply restoration

Actions:

- repair named rail route
- restore named port
- escort emergency convoy
- build temporary supply hub or depot
- transfer trucks and trains
- evacuate impossible garrison

Dynamic costs respond to:

- distance from capital
- state infrastructure
- convoy route
- division count
- local population
- war damage
- enemy air and naval pressure

Failure results:

- Field Hunger increase
- cell opportunity
- unit loss
- foreign spread route

### Formation control

Actions:

- rotate a compromised division
- screen replacements
- suspend an officer chain
- disarm a refusing unit
- assign military police
- protect medical and burial details

Requirements:

- replacement divisions
- equipment
- manpower
- army experience
- access to the formation's state

Failure results:

- mutiny
- desertion
- cell transfer
- warlord formation at extreme severity

### Investigation

Actions:

- forensic recovery
- ration-ledger audit
- prison manifest review
- witness protection
- trace ritual objects
- inspect kitchen and burial sites

Dynamic factors:

- Command Integrity
- state control
- recent combat
- concealment policy
- organizer experience

Partial success should be common. A player can learn the source but fail to capture the organizer, or rescue witnesses while losing records.

### Legal response

Actions:

- public court-martial
- protected closed tribunal
- conditional amnesty
- disbandment
- execute captured organizer
- expose government exploitation

Tradeoffs:

- stability
- Command Integrity
- Cult Cohesion
- foreign trust
- martyr risk

### Cell suppression

Actions:

- infiltrate cell
- seize ritual store
- sever courier route
- isolate a prison
- secure port manifests
- simultaneous raid

Costs:

- intelligence exposure
- military police
- support equipment
- unit commitment
- time

### Humane containment

Actions:

- emergency food relief
- prisoner protection
- field hospital security
- family notification
- burial and identification program
- rehabilitation camp for coerced followers

These actions should matter mechanically. They lower recruitment and rumor pressure, improve testimony, and speed state recovery.

### Exploitation

Actions:

- authorize terror battalion
- feed selected prisoners
- deploy compromised troops against a fortified position
- falsify losses
- export a terror unit to an occupied state

Rewards:

- major short-term combat and occupation advantages

Risks:

- Cult Cohesion
- Network Reach
- condemnation
- officer independence
- future warlord creation
- achievement disqualification

### Island and port operations

Actions:

- reconnoiter silent island
- escort relief ship
- evacuate garrison
- blockade commune
- raid hidden anchorage
- assault island Host
- protect nearby island states

Costs:

- convoys
- fuel
- naval or air assets
- marine or supplied divisions

### Warlord counterwar

Actions:

- fund local resistance
- target warlord commander
- liberate a feeding state
- secure captured prisoners
- destroy Larder infrastructure
- protect a relief corridor
- process captured warband units

### Global network disruption

Actions:

- international registry
- intelligence exchange
- joint raids
- courier interception
- synchronized port inspection
- coalition convoy escort
- anti-seeding screening

### Hannibal counterwar

Actions:

- encourage warlord defection
- attack convergence host
- seize network capital
- destroy global courier hub
- liberate high-consumption state
- cut continental Larder route
- prevent terminal focus conditions

### Wendigo transformation counterwar

Actions:

- identify transformation anchor
- assault anchor state
- evacuate threatened population
- disrupt ritual logistics
- break Wendigo recruitment site
- delay countdown
- destroy final anchor before lock

These decisions disappear after terminal transformation because the branch has become a world-end state.

## Mission design

### Restore the route

Objective:

- control and repair named supply nodes
- keep them connected for a dynamic duration
- maintain supplied formations in the target theater

Success:

- major Field Hunger reduction
- cell growth stops

Failure:

- cell strengthens
- formation refuses rotation

### Screen the division

Objective:

- move the compromised unit to a safe state
- keep it out of combat
- supply replacement manpower and equipment

Success:

- organizer targets revealed
- unit returns clean or is safely disbanded

Failure:

- deserters seed another state

### Hold the prison

Objective:

- maintain a loyal garrison
- prevent prisoner transfer
- keep supply and communications open

Success:

- prison cell suppressed

Failure:

- Prison Host sequence advances

### Reach the island

Objective:

- send a valid convoy or landing force
- restore port access
- maintain contact

Success variants:

- rescue
- negotiated surrender
- secured investigation

Failure variants:

- ship disappears
- force defects
- commune strengthens

### Break the network

Objective:

- destroy several linked nodes within one shared window

Success:

- large Network Reach reduction
- surviving cells lose foreign support

Failure:

- nodes relocate and become harder to detect

### Stop the unification

Objective:

- defeat or isolate the selected host
- force enough warlords to resist or defect
- reduce Network Reach before the reveal sequence completes

This mission exists only immediately before the reveal when the network conditions are visible through public convergence signs. It must not name Hannibal before the reveal.

### Stop the transformation

Objective:

- capture or destroy anchor states before the Wendigo countdown ends

Success:

- Wendigo Hannibal loses terminal access and falls back to a powerful nonterminal merged country

Failure:

- terminal world-end lock

## Scripted GUI concept

### Early attached header

The ordinary category header should be compact.

Elements:

- two large meters for Field Hunger and Command Integrity
- Cult Cohesion slot hidden until Evolution I
- selected state portrait or map card
- active mission summary
- small animated warning seal when a value reaches a dangerous band

### Network window

Evolution II opens a separate movable window.

Tabs:

1. Domestic Cells
2. Islands and Communes
3. Foreign Links
4. Warlord States
5. Countermeasures

The window should use a sortable list of active nodes rather than one hardcoded panel per country.

Node card information:

- country or state
- node type
- strength band
- known route
- last incident
- selected counteraction
- uncertainty level

The interface can show lines or threads between nodes as an animated decorative layer. The animation must not imply a named individual.

### Cannibal command window

Cannibal countries see:

- Larder meter
- Frenzy meter
- controlled-state cards
- recruitment capacity
- raid target card
- Network Alignment after Evolution II

### Revealed command window

After Hannibal's reveal:

- final portrait
- warlord loyalty list
- global Larder
- global Network Reach
- continental target cards
- world-end progress when eligible

### Wendigo transformation window

- transformed portrait
- anchor-state cards
- countdown
- Wendigo unit capacity
- critical terminal warning

## GUI button contract

Every interactive button needs:

- cost text
- blocked cost text
- requirements
- result direction
- warning direction
- scripted effect owner
- scripted trigger owner
- AI equivalent
- cleanup behavior

GUI buttons must use the same balance logic as decisions. They cannot bypass costs, cooldowns, logging, or route locks.

## Animation plan

### Early warning seal

- 8 frames
- 64 by 64 frame size
- slow pulse from dried blood mark to wet glint
- static fallback
- active only at dangerous Field Hunger or low Command Integrity

### Cult Cohesion emblem

- 8 frames
- separate source frame for each ritual-mark state
- appears only after Evolution I

### Network threads

- 12 frames
- moving signal and courier lights across a dark map layer
- no face or supreme symbol
- decorative, state-aware intensity

### Island alert

- 8 frames
- distant ship light, missing signal, dark shoreline progression
- used on island cards

### Selected target card

- 6 frames
- subtle state-specific blood and paper movement
- must retain text readability

### Larder meter

- state variants for empty, low, stable, high, and overflowing
- animation at critical low and high only

### Frenzy border

- 8 frames
- increasing violent motion at high Frenzy

### Hannibal portrait

- 12 source frames
- 156 by 210 each
- 1872 by 210 horizontal sheet
- complete feral skull-licking action with jaw, tongue, fingers, wrists, eyes, skull angle, blood, shoulders, and cloth independently redrawn across the sequence
- no transform-only motion

### Wendigo Hannibal portrait

- 16 source frames
- 156 by 210 each
- 2496 by 210 sheet
- separate asymmetric predatory crouch, lunge, claw reach, jaw-unhinging apex, recoil, swallow spasm, and tense return with anatomy, ice, breath, flesh, blood, and shadow independently redrawn
- preserve identity across frames
- no merely recolored or ice-skinned human portrait

### Unification seal

- 12 frames

### Terminal warning frame

- 12 frames
- used for ordinary and Wendigo world-end readiness with distinct art

## Static fallback policy

Every animated element has a static fallback. The fallback is final art, not a placeholder. The static fallback appears when animation is disabled, unsupported, hidden by route state, or not currently active.

## Decision clutter control

- show only relevant phase
- use selected target cards for foreign countries and states
- hide obsolete baseline actions after local victory
- replace weak early actions with stronger evolved versions
- cap active missions
- hide actions for invalid or dead targets
- close categories after global defeat
- remove pre-reveal network uncertainty UI after Hannibal appears

## AI equivalent behavior

AI does not need to click the human GUI. Every action maps to decisions, scripted effects, timed pulses, or strategy plans using the same requirements and costs.

AI priorities:

- save supply route before cosmetic action
- rotate compromised units before public propaganda
- protect prison and island nodes when severe
- avoid exploitation unless desperate and ideologically compatible
- use joint suppression when multiple countries share a link
- target transformation anchors before ordinary fronts when terminal risk is high
- cannibal AI spends Larder on units only when supply and territory can support them
- Hannibal AI prioritizes absorption, coalition hubs, and high-population routes

## Accepted maintained-objective closure

The maintained mission layer contains exactly eight families:

1. restore the supply corridor
2. rotate compromised formations
3. investigation
4. hold the prison
5. reach the island
6. break the network
7. stop unification
8. stop transformation

The final six use runtime durations, capped progress, persisted state or country targets, node or actor generation checks where relevant, and separate full, partial, failure, timeout, and cancellation outcomes. Objective pulse work iterates only the bounded actor and objective-country registries.

Seven paid action families close the previously missing action layer: officer-chain replacement, ritual-cell infiltration, ritual-economy disruption, silent-island reconnaissance, feeding-state liberation, network-submission preparation, and network-resistance preparation. Every action has a real resource gate and payment, a cooldown or one-shot lifecycle, route-aware AI, and cleanup. None grants free units, equipment, population, or Larder.

The Wendigo closure adds four terminal-hunt surfaces, one receipt-backed Pack muster, and one inherited winter-cell operation. The terminal hunt owns one persistent target and a 120-day mission. Launch, pressure, defender counterpressure, success, failure, timeout, route break, actor removal, terminal lock, and global cleanup all use the same bounded lifecycle. A hunt success adds only five transformation progress, a failure removes ten, and only the transformation pulse can apply the final lock.

The read-only achievement tracker is deliberately excluded from the operational decision inventory. Its 18 entries are permanently unavailable and contain no cost, effect, cooldown, completion hook, or AI block.
