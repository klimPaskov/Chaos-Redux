- Event 14 is registered as Minor Fire-Once.

## Baseline event

- A valid ordinary country at war is selected through dynamic risk factors.
- Invalid target state produces `N/A` weight presentation.

- The first incident does not use cult or supernatural certainty.

## Local and global victory

- Local victory removes every country cell and completes stabilization.
- Local victory protects against passive relapse.
- External seeding and invasion can still return the threat.
- One country's victory does not cure foreign countries.
- Global victory requires every host, cell, commune, island, warlord, and unified actor to be absent.
- Event-owned pulses and world-threat state clean up after global victory.
