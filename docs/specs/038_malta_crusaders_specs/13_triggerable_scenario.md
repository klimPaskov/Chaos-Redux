# Triggerable scenario: Believers vs Nonbelievers

## Scenario identity

| Field | Working value |
| --- | --- |
| Scenario ID | `SCN-015`, provisional pending workbook collision check |
| Scenario name | Believers vs Nonbelievers |
| Owning event | Event 38 |
| Type control | Holy World actor setup mode, if final design retains useful variants |
| Intensity | Low, Medium, High, Maximum |
| Terminal runtime | Shared Event 38 Holy World runtime |

The current supplied scenario catalog ends at SCN-014. Implementation must inspect the authoritative workbook before assigning SCN-015 permanently.

## Purpose

The scenario launches the final religious world war immediately for players who do not want to complete Event 38, the Holy See route, evolution pacing, Papal preparation, or continent proof.

It is a manual sandbox and challenge setup. Normal source-event gates do not block it.

## Launch eligibility

The scenario should be launchable unless:

- a shared terminal state is already active
- the setup cannot create or select any valid Papal actor
- the selected player context is invalid
- another launch transaction is already in progress
- a required map or country registry is malformed

The launch cannot be blocked by:

- current Chaos
- Chaos tier
- Event 38 firing history
- event enable state
- event Chaos level
- evolution enablement
- the 800 preparation stage
- continent proof
- Teutonic Order state
- prior super-event history
- date
- route prerequisites

## Confirmation flow

The scenario row opens a detail view. The player chooses intensity and any approved scenario type. Pressing Launch Scenario opens a confirmation window that reads the values at confirmation time.

Cancel leaves the world unchanged.

The launch button, disabled state, and confirmation use the same eligibility trigger.

## Actor selection

### Existing valid actor

Use an existing Malta Crusader, Holy See, or Kingdom of God actor when:

- it exists
- the Pope is supreme ruler
- it can serve as the terminal actor
- using it will not replace another human player's country without choice

Priority:

1. human-controlled valid Papal crusader actor
2. existing Holy See
3. existing Kingdom of God
4. existing Malta Crusader under Papal rule

### Transformable actor

If a valid Event 38 actor exists without Papal supremacy, the scenario can transform it only after resolving human control and government ownership. The setup installs the Pope and terminal identity through a bounded scenario transaction.

### Created actor

If no valid actor exists, create the Holy World actor directly with:

- Malta
- Rome
- Jerusalem
- a selected maritime bridge
- enough nearby coherent territory to function
- ports
- supply
- industry
- manpower
- equipment
- forces
- Pope as supreme leader
- terminal focus or decision access

The setup cannot create disconnected random states. It uses the Event 38 state collections and intensity package.

## Internal Chaos transition

The scenario launch immediately raises global Chaos into World Collapse before calling the terminal branch.

Rules:

- use the shared Chaos adjustment and history path
- record the scenario setup as the cause
- set a value at or above 1000 according to the current system contract
- do not bypass the shared terminal tier after setup
- clear the scenario-only bypass before ordinary terminal processing

The player does not need to begin at 1000 Chaos.

## Scenario setup transaction

1. save selected scenario, type, and intensity
2. set a narrow Event 38 scenario setup flag
3. freeze or create the Papal actor
4. install Rome as primary capital and Jerusalem as secondary sacred center
5. create territory, subjects, ports, supply, industry, forces, and identities by intensity
6. install the Pope and terminal government
7. raise Chaos into World Collapse
8. create the initial believer and nonbeliever candidate pools
9. resolve human side choices
10. resolve AI side choices
11. form coalitions
12. set the shared Holy World terminal state
13. fire the super-event
14. queue regional wars
15. clear scenario bypass, setup arrays, and temporary targets

The normal and scenario routes must converge on the same terminal effects after step 12.

## Immediate world division

### Human side choices

Every human-controlled ordinary country receives a direct side choice unless already controlling the Holy World actor.

Choices:

- join the believers
- join the nonbeliever resistance
- use an intensity-specific neutral or independent option only if the final scenario design supports a coherent third role

A human actor should not be forced by ideology or relations.

### AI assignment

AI assignment uses:

- prior Papal alignment
- ideology
- relations
- fear
- existing wars
- faction commitments
- territorial exposure
- religious movement influence
- hostility to Malta or the Pope
- strategic balance

The assignment target by intensity is a balance band, not a fixed percent applied blindly. Major powers and industrial totals matter more than country count.

## Intensity packages

### Low

**Holy World territory:** compact core around Malta, Rome, Jerusalem, Cyprus, and selected valid footholds.

**Believer side:** modest minority of eligible states, mostly small and medium supporters.

**Subjects:** zero to two principalities or Papal administrations.

**Military:** core terminal formations, limited elite package, strong but constrained logistics.

**Nonbelievers:** retain most major powers and industry.

**Campaign character:** difficult Papal expansion from a strong Mediterranean base.

### Medium

**Holy World territory:** stronger Mediterranean network with several connected ports and sacred centers.

**Believer side:** meaningful coalition across several regions.

**Subjects:** several principalities and Papal administrations.

**Military:** additional special formations, more believer contributions, stronger supply.

**Nonbelievers:** retain several major industrial blocs.

**Campaign character:** balanced global war with a clear Papal coalition.

### High

**Holy World territory:** broad Mediterranean and selected continental holdings.

**Believer side:** large coalition across several regions.

**Subjects:** active principalities, order states, and Papal administrations.

**Military:** strong terminal armies, several active fronts, robust logistics.

**Nonbelievers:** retain enough majors, resources, and strategic depth for a real war.

**Campaign character:** immediate multi-continent conflict.

### Maximum

**Holy World territory:** strongest plausible accepted Holy World configuration without automatic victory.

**Believer side:** extensive Papal bloc with broad geographic reach.

**Subjects:** developed principality and administration network.

**Military:** near-maximum terminal formations and support.

**Nonbelievers:** protected minimum major-power, industry, resource, and naval strength.

**Campaign character:** full global war already underway.

## Balance floors

At every intensity:

- at least two major nonbeliever industrial centers should remain when the world state permits
- nonbelievers retain meaningful naval and air capability
- believers do not receive every strategic resource
- the Papal actor has supply for its starting forces
- isolated believer states receive a viable coalition route or are not selected
- no side is assigned a country that cannot leave its current terminal conflict safely

If the current world cannot satisfy the intended balance, the setup adapts or rejects. It does not force a predetermined ratio that produces broken factions.

## Scenario type options

A type control is useful only if it changes the setup materially. Recommended options are:

### Papal Dominion

More direct Papal territory, fewer autonomous believers, stronger central terminal actor.

### League of Believers

More allied believer governments, fewer direct Papal possessions, stronger multinational coalition.

If the type control adds clutter without changing play, omit it and keep one scenario type. The scenario window should not expose a cosmetic switch.

## Immediate war

War begins immediately after side assignment, using rapid regional pulses.

Priorities:

1. current borders
2. Mediterranean and Europe
3. adjacent continental fronts
4. overseas major powers
5. remaining remote states

The setup reuses the Holy World regional queue. It does not maintain a separate scenario-only war system.

## Terminal systems

The scenario uses the standard Holy World:

- terminal ideas
- unit families
- alliance rules
- believer contributions
- nonbeliever mobilization
- conquest settlements
- victory and defeat
- super-event
- event freeze

Any scenario-specific setup bonus expires or transitions into the standard terminal state.

## Atlantis exclusion

The scenario does not automatically trigger the Teutonic Order or Atlantis.

After setup, Atlantis can arise only if gameplay later creates its exact hidden conditions. Because the scenario clears bypass state, no missing source prerequisite is silently treated as satisfied.

## Repeat launch

The scenario cannot be launched twice in one active setup or terminal campaign. A completed or defeated scenario can be relaunched only if the shared scenario framework and user settings explicitly support reset, and only through a complete cleanup transaction.

## Multiplayer

- the current player controls the Holy World actor only when the scenario selection says so
- other human players receive side choices
- country transformations preserve player control where possible
- no human country is annexed or converted during setup without a direct choice
- confirmation is authoritative for the launching player
- setup choices and random results are deterministic across clients

## UI and localisation

Scenario details should explain:

- the Pope immediately leads a terminal Holy World actor

- the selected intensity changes Papal territory, believer strength, subjects, and starting fronts
- the launch raises Chaos into World Collapse and begins the world war

The UI should not expose internal bypass flags, exact AI formulas, or hidden Atlantis rules.
