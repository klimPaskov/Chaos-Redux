# Evolutions and pre-fire scaling

## Evolution contract

Event 38 has three evolutions. They are logged mutation tracks inside the same event identity. Normal territorial stages, focus completions, formables, and order settlements are not evolutions.

| Evolution | Working title | Chaos requirement | Main new behavior |
| --- | --- | ---: | --- |
| I | The Orders Return | 200 or more | additional orders, foreign volunteers, deeper rivalries, specialized unit packages |
| II | The Crusader Principalities | 400 or more | subject creation, local governance, church disputes, succession, broader opening footprint |
| III | The Age of Holy War | 600 or more | foreign religious movements, relic system, Blessed formations, wider religious diplomacy |

Evolution activation changes no Chaos. Concrete later outcomes can use the shared Chaos pipeline.

## Post-fire evolution pacing

After Event 38 fires, each enabled evolution uses dynamic pacing. The nominal base is about 90 days. The exact MTTH should respond to campaign state.

### Evolution I factors

Faster when:

- Malta controls Jerusalem
- several Catholic governments support Malta
- order influence is already high
- the crusade is winning
- Chaos is well above 200

Slower when:

- Malta is close to defeat
- Order Cohesion is critically low
- foreign support routes are closed
- the event's evolution is disabled

### Evolution II factors

Faster when:

- Malta controls several coherent regions
- direct occupation burden is high
- at least one order demands territory
- Crusade Authority is functional
- Evolution I is active

Slower when:

- no valid principality region exists
- Malta has only its island heartland
- all candidate country carriers are invalid
- Authority is fractured

### Evolution III factors

Faster when:

- Sacred Legitimacy is high
- several principalities or foreign supporters exist
- Jerusalem is stable
- the Pope recognizes the crusade
- Chaos is well above 600

Slower when:

- public relic scandals already discredit the cause
- condemnation is severe
- the Pope is hostile or absent
- the crusade is in recovery

Evolution MTTH factors and event option weights require the MCP probability workflow. The candidate pool, external state, and exact scenario assumptions must be declared.

## Pre-fire evolution rule

An evolution that is already active before Event 38 fires changes the initial release immediately. The setup uses the highest enabled active evolution and includes every lower package.

The event must not spawn baseline Malta and schedule a later catch-up pulse. Catch-up would create broken early balance, duplicate forces, and confusing event logs.

## Baseline package

### Territory

- Malta
- Holy Land command
- Jordan corridor where valid
- Cyprus maritime bridge
- one conditional expeditionary foothold

### Armed forces

- fortress garrison
- bounded knight, mounted, ranged, siege, engineer, and local guard package
- modest transport and escort support

### Mechanics

- three public values initialized in the functional but unstable range
- Crusade Council open
- core focus tree routes open
- no principality required at start
- no relic required at start
- no Blessed formation required at start

## Evolution I pre-fire package

### Territory

Normally unchanged from baseline. Territorial scaling is not the primary Evolution I tool.

### Armed forces

- more Armored Knight and Mounted Knight equipment
- one or more additional formations within the setup cap
- stronger Archer or Crossbow cadres
- one additional Siege Host when supply can support it
- more engineers and Hospitaller support
- expanded commander roster

### Orders

- additional order headquarters already active
- at least four public order families represented
- one initial order demand can be queued after the player sees the setup
- stronger foreign chapter presence

### Logistics

- more convoys, trains, fuel, and support equipment
- stronger ports or depots
- larger workshop capacity

### Values

- slightly higher Authority floor
- wider Cohesion variance because more orders compete
- modest Legitimacy support from foreign arrivals

## Evolution II pre-fire package

Includes Evolution I.

### Territory

- broader but coherent footprint
- one additional selected foothold when it connects a theater or stabilizes supply
- no more than one extra displaced owner beyond the accepted package cap unless a single owner holds several selected regions

### Principality

At least one valid principality or order state exists at opening. Priority order:

1. Kingdom of Jerusalem or Jerusalem commandery
2. Crusader Cyprus
3. Aegean order state
4. another valid coherent regional actor

The actor receives a full minimum country package and cannot be created when no valid territory or carrier exists.

### Armed forces

- principality garrison and militia
- multinational crusader forces spread across the opening network
- stronger local recruitment support

### Governance

- regional settlement decisions open earlier
- charter and obligation system initialized
- direct-rule and subject-rule tradeoffs active

### Values

- Authority reflects the broader administration burden
- Cohesion reflects land grants
- Legitimacy reflects the first recognized principality

## Evolution III pre-fire package

Includes Evolution I and II.

### Foreign support

- immediate religious support receipts from valid countries
- at least one sponsor, ally, or expeditionary contributor when the world state permits
- broader recognition and reaction events

### Relic or legitimacy grant

The opening receives one of:

- a relic claim with uncertain authenticity
- Papal recognition
- a widely recognized crusader banner or sacred tradition
- another equivalent Sacred Legitimacy package

The setup cannot invent a real relic without a sourced tradition. A fictional claim must be clearly framed as a claim.

### Blessed forces

- at least one Blessed formation
- full equipment and manpower
- a strict cap
- route-valid sponsor

### Logistics and military

- stronger air or naval transport
- larger reserve stockpile
- additional allied participation
- stronger strategic bridge defence

### Values

- higher Sacred Legitimacy floor
- higher Authority floor
- Cohesion can start high under a coordinated coalition or lower under intense order competition

## Evolution I: The Orders Return

### Public premise

Revived and newly created military orders arrive with volunteers, officers, money, equipment, and competing demands.

### New systems

- full six-order council
- order headquarters
- foreign order chapters
- order-specific recruitment and unit upgrades
- deeper demand and rivalry events
- dominant-order and confederation routes

### Major incidents

- competing claims to Jerusalem
- treasury dispute
- foreign chapter refuses command
- order demands an island or city
- Papal arbitration request
- mixed-order victory
- hospital neutrality dispute

### Failure behavior

Low Cohesion can create command refusal, separate fronts, or a breakaway headquarters. The evolution does not force civil war.

### Event log

Record one evolution entry after activation is committed. Use Event 38, evolution type I, stage 1, current tier, and Malta as actor.

## Evolution II: The Crusader Principalities

### Public premise

The crusade begins creating states and territorial administrations that can outlive individual campaigns.

### New systems

- principality creation
- charters and obligations
- local church and elite politics
- succession
- subject military contributions
- staged integration
- principality federation

### Major incidents

- charter negotiation
- order land dispute
- local elite demand
- succession crisis
- subject refuses levy
- principality asks for independence
- Papal administration conflict

### Failure behavior

Weak principalities can collapse, defect, demand autonomy, or become local restorations. Malta can absorb, replace, negotiate, or abandon them through valid settlement effects.

### Event log

Record one evolution entry after the first valid activation, not once per principality.

## Evolution III: The Age of Holy War

### Public premise

The Malta crisis inspires foreign religious movements, relic searches, and a wider contest over who can claim sacred authority.

### New systems

- relic claims and custody
- foreign religious support
- Catholic political movements
- rare crusader uprisings
- Blessed formations
- broader religious diplomacy
- ambiguous battlefield miracle reports

### Foreign movement rules

A foreign movement requires:

- sufficient local support or instability
- a valid political actor
- no protected-country exclusion
- bounded target selection
- a clear relationship to Malta or the Pope

It cannot create spontaneous crusader uprisings in every Catholic state through a world scan.

### Miracle direction

Events describe witnesses, improbable outcomes, disputed relic effects, and public belief. The code uses ordinary morale, recovery, organization, recruitment, and event outcomes.

### Failure behavior

False relic scandals, Papal rejection, atrocities, or catastrophic defeats can collapse Sacred Legitimacy and weaken foreign support.

### Event log

Record one evolution entry after activation. Later relics and movements are ordinary Event 38 outcomes.

## Disabled evolution behavior

Each evolution has its own enabled state. When disabled:

- pre-fire setup does not include that package
- activation does not record
- gated focuses and decisions stay hidden
- recorded flags do not set
- later stages do not treat it as completed
- baseline campaign remains completable
- lower enabled evolutions still work

The Holy See and Kingdom of God remain baseline focus outcomes and do not require a disabled evolution unless a specific evolved feature is used.

## Evolution and Chaos

Evolution state gives zero Chaos. Examples of concrete Event 38 outcomes that can change Chaos are listed in the shared-system specification. Generic wars, annexations, deaths, contamination, and unconventional weapon use already have shared sources and must not be counted twice.

## Evolution acceptance tests

1. Event fires below 200 Chaos
2. Evolution I active before event fires
3. Evolution II active before event fires without a valid principality region
4. Evolution III active before event fires with no valid foreign supporter
5. Event fires first, then each evolution activates through MTTH
6. each evolution disabled separately
7. actor annexed during evolution delay
8. Jerusalem lost during evolution delay
9. human and AI Malta
10. save and reload before and after activation
11. event-log row metadata and ordering
12. no duplicate setup package or duplicate formations
