# Demilitarization: presentation and asset coverage

The event uses the normal map, ordinary reports and news, one ordinary decision category, and one staged national-spirit family. Army Cohesion is the single persistent custom value. Presentation should keep the territorial rule and the army's real condition understandable at a glance.

All titles, labels, option names, and image names below are working directions, not final localisation.

## The category

Use a small category icon, a static category picture, a short description, formatted cohesion text when active, and the ordinary decision list. This fits the supplied rule for a simple category picture. The picture supplies identity while the normal decision controls carry the actions.

The current geographic summary distinguishes frontier, inward belt, and near-total restriction. State names come from native localisation. Show whether the current capital is actually usable. When another source still holds a DMZ during war, attribute the remaining restriction accurately.

Cohesion has a number, a worded band, and a causal explanation. Colour can reinforce meaning but cannot carry the meaning alone. Do not add a decorative custom gauge that duplicates the text or creates another public score.

Use a short list of urgent or relevant targets. Below the urgent muster, allow at most one recovery row summarising the highest outstanding target and clean-review progress. A decision tooltip explains exact costs and current validity. A report explains what happened. Event Details explains the premise and broad evolution, with the precise mechanical effects left to the appropriate tooltips.

## Text direction by surface

| Surface | Content and tone direction |
| --- | --- |
| Opening news | Period press account of widespread military withdrawal. Use observable empty posts and changed movement patterns. Do not invent a named international treaty or government responsible for the whole event. |
| Local baseline report | The real frontier footprint and what happened to existing troops. Adapt for inland space, thin territory, and no local land-border effect. |
| Deeper report | A second line of garrisons and staging areas becomes unusable. Name actual affected regions where the available text space permits. |
| First measured desertion report | Actual missing personnel, abandoned kit, and disrupted service routines. Distinguish an incomplete muster from verified losses. |
| Endangered-formation notice | Identify the real formation, the remaining interval, and the practical ways to resolve attendance. Keep factual uncertainty in the narrative and exact conditions in the tooltip. |
| Full-dissolution report | State that an actual formation has ceased to function. Describe living personnel and equipment disposition without presenting the loss as combat deaths. |
| Total report | Closed provincial barracks and concentration in the actual remaining legal space. A capital refuge may be described only when one exists. |
| War transition | Explain release of Event 114 territorial restrictions and suspension of its peacetime penalties. Keep surviving outside DMZ claims and Event 096 conditions distinguishable. |
| Peace transition | Explain the current footprint returning after the last war. Refer to preserved service problems rather than claiming the army has been reset. |
| Programme outcomes | Describe the specific resource commitment and military result. Constructive responses can use dry administrative irony. Losses and backlash use a sober register. |
| History and Event Details | Global opening and evolutions use the correct actor convention. Local incidents use their real country. Details describe the premise, and impossible availability displays N/A. |
| Catalog summaries | Mirror the accepted premise and final implementation-written localisation. Preserve current identity and migration provenance. |

On light parchment report and news backgrounds, use plain readable text without colour codes. Do not paste invented quotations, literary fragments, slogans, or cultural jokes into the specification. Source any specific allusion before implementation uses it.

Use fictional period documentary scenes for invented events, with plausible 1936–1945 equipment and anonymous subjects. Real named people, documents, or photographed places require attributed source research.

Report scenes begin as full-canvas photographs. Local processing supplies black-and-white treatment, sepia paper, slight tilt, transparent corners, and shadow. News scenes receive their own wide press-photo composition. Do not generate an interface frame or functional text into either source.

Icons require native transparent backgrounds from generation. The ordinary decision, mission, category, spirit, and achievement families have separate source artwork and outputs, with each canvas checked against its actual consumer. A category emblem resized to 32 pixels is not a completed decision icon.

## Evidence for implementation acceptance

Every selected asset must have a verified consumer, canonical reference family, saved generation request or attribution, source lineage, processed PNG, runtime DDS, registration, and native-size review.

The asset prompt owns exact production instructions. The parent implementation agent owns final non-portrait GFX registration and gameplay wiring. A successful conversion is insufficient if the icon is unreadable, a subject is clipped, the alpha is damaged, or the actual consumer uses a different canvas.

The presentation pass must confirm that each gameplay state reads correctly, including no-border countries, zero-space countries, another owner's remaining DMZ, wartime suspension, scarce resources, an invalid formation target, and a programme cancelled by war.
