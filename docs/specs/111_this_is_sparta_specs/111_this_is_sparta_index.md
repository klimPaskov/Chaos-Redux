# This is SPARTA!!!: specification package

## Package purpose

This package contains the complete planning specification for current Event 111, originally cataloged as 116. Extract the ZIP into `docs/specs/` so the resulting folder is `docs/specs/111_this_is_sparta_specs/`.

The user-authorized premise is an immediately independent Sparta in Laconia, a finite returned ancient army, a weak modern state, a large modernization and conquest tree, five major campaigns and the high-Chaos Age of Heroes evolution. The package develops that premise into playable institutions, geography, military growth, decisions, treaties, failure recovery, AI, assets and implementation contracts.

This is a specification deliverable. Production code, a map patch, final localisation, images, models, audio and native game validation belong to the future implementation described in the prompts. New labels and keys are working design identifiers. They are not finished player text or a claim that native identifiers have already been allocated.

## Main design decisions

Sparta receives its own Laconia state through a required build-time map split. This preserves the intended location and leaves the rest of the Peloponnese for the opening campaign. Exact province membership, new state ID, capital, supply and compatibility are installed-map gates. The event does not silently transfer the whole Peloponnese.

The original host is finite. Modern Greeks and later eligible residents provide continuing recruits. Research progresses from two to five slots through real institutions. The country has exactly three public custom values, with Mythic Strain appearing only after evolution, and at most three simultaneous tree-owned spirit stages.

The five campaigns have different geographic and administrative demands. Hegemony can establish a union or league. Alexander can centralize or use real regional clients. Thermopylae can follow either complete eastern corridor. West must sustain a real crossing or Adriatic approach. Colonies needs nine selected ports across five basins and functioning maritime services.

The first material mythic proof is fixed to the Dioscuri. Other families require their own sites and undertakings. Talos remains globally unique. The birds remain a limited aerial force. Native modern weapons, logistics, diplomacy and site control provide counterplay.

Sacred dyarchy is a late overlay after a normal route charter. Castor is the native visible sovereign and Polydeuces has an actual second sovereign and military office. Their portraits remain separate. Six sacred flag variants preserve the six earned formable identities. One true-frame animated portrait overlay is planned, with a static fallback.

## Catalog handling

The current brief identifies this event as 111 and its original identity as 116. Supplied exports and the inspected repository still use the legacy numbering. Their old row 111 names Resistance. The implementation must reconcile that collision without guessing destinations or relabeling ambiguous old history.

The editable catalog is `docs/spreadsheets/chaos_redux_events_catalog.xlsx`. CSV files are export-only. The connected repository fetch exposed only a Git LFS pointer for the workbook, so no live workbook cells, formulas, validation or status were inspected or changed. This specification retains the brief's To Be Reworked status and unassigned cluster.
