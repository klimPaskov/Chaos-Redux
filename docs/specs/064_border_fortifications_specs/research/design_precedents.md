# Event 064 Design Precedents

This note records design lessons and visual reference families. It is not final historical text for localisation. Asset and implementation workers must verify any external source they use.

## Why historical line systems matter

Real and imagined fortification systems show how a defensive line depends on fields of fire, obstacles, terrain, supply, command, air warning, depth, mobile reserves, and the enemy's ability to bypass or concentrate against it.

Event 064 should use those lessons without simulating one named historical line in every country.

## Reference families for visual and layout research

Useful visual families include:

- Maginot Line works
- Westwall or Siegfried Line works
- Czechoslovak border fortifications
- Mannerheim Line positions
- Metaxas Line positions
- Alpine fortifications
- Stalin Line and later Soviet fortified regions
- Atlantic Wall coastal positions
- interwar border bunkers, blockhouses, anti-tank obstacles, observation posts, and field works from several countries

The final Event 064 art should combine period-consistent features into a fictional global frontier. It should not reproduce a protected photograph or imply that one named national system appeared everywhere.

## Core gameplay lesson: strongpoints matter more than carpet

A useful line has decisive nodes. Passes, bridges, railways, ports, cities, and supply routes matter more than empty ground.

Applied to Event 064:

- baseline creates broad coverage
- Defense in Depth selects strategic anchors and approaches
- Fortress States adds integrated regional support
- Fortress World protects internal objectives
- caps and quotas preserve weak sectors and bypass routes

This produces a map with patterns a player can read.

## Core gameplay lesson: depth protects against one breach

A single border belt can fail when an attacker concentrates at one point or bypasses the line. Secondary positions, reserve routes, and fallback hubs make a defense durable.

Applied to Event 064:

- depth positions are bounded
- each position protects a real route or objective
- the event does not build a second complete wall
- a later capital or supply redoubt can keep a country fighting after the border falls

## Core gameplay lesson: logistics decides whether concrete is usable

Static defenses need ammunition, food, repair, transport, communications, and reserves. A strong bunker in an isolated state can be less valuable than a moderate position linked to a supply network.

Applied to Event 064:

- Fortress States can improve infrastructure, rail, or existing supply support
- Keep the Roads Open gives a distinct logistics response
- AI looks at supply strain before spending on more concrete
- free supply hubs remain exceptional

## Core gameplay lesson: air and observation shape fixed defenses

Observation, warning, anti-air, and communications can make a defended sector harder to isolate or suppress.

Applied to Event 064:

- state anti-air and radar appear only in strategic states
- radar remains rarer than forts
- air-defense projects require a real air or strategic-site role
- Event 23 and Event 32 sites can raise protection priority

## Core gameplay lesson: coastal defense needs selected sites

Coastal fortification is most useful around ports, naval bases, supply points, and likely landing approaches. A full coast carpet is expensive, visually repetitive, and hard to balance.

Applied to Event 064:

- Evolution II coastal work requires a state with both land frontier and coast
- automatic coastal forts protect ports and bounded approaches
- island countries do not receive Evolution II Fortress States solely because they have coastline
- Fortress World can give islands internal redoubts

## Core gameplay lesson: bypass and concentration remain counters

A line can shape strategy without making attack impossible. Attackers can bypass it, attack from several directions, isolate supply, use engineers, prepare artillery and air support, or exploit a weak sector.

Applied to Event 064:

- ordinary caps stay below selected anchors
- internal carpets are forbidden
- Study the Breach gives direct counterplay
- target-bound exercises reward preparation against real forts
- existing game mechanics remain relevant

## Core gameplay lesson: old lines become map history

Borders move. A defensive line can become an internal belt, a captured strongpoint, or a barrier used against its original owner.

Applied to Event 064:

- completed buildings never move with a new political border
- new frontiers wait for a later wave
- releases and annexations inherit physical structures
- The Great Shuffle can leave strange old lines across new countries
- no recurring border-maintenance scan is needed

## Avoiding common fortification-event problems

### Problem: every country receives the same strategic value

A level on every border province affects a compact state and a continental empire differently.

Response:

- use per-country summaries
- use sublinear evolved quotas
- score strategic roles
- scale response costs
- give island countries a later valid role

### Problem: the event freezes wars

High automatic levels everywhere can overwhelm AI and current doctrine.

Response:

- one baseline level per wave
- caps below level ten
- selected anchors with lower ordinary frontier levels
- natural cooldown
- breach posture and target-bound offensive project
- AI probability audit

### Problem: support buildings become free economy

Blanket infrastructure and supply hubs can make the event an industrial bonus unrelated to defense.

Response:

- state selection
- role-based packages
- repair and existing network improvement first
- new supply hubs exceptional
- material player costs for deeper integration

### Problem: high tiers only add larger numbers

Increasing every border fort from four to six does not create a new experience.

Response:

- Defense in Depth changes geography
- Fortress States changes regional systems
- Fortress World changes the national interior
- each stage has a separate report and first-materialization milestone

### Problem: event choices are fake

Letting the player accept or reject already completed world defenses would make the event premise inconsistent.

Response:

- automatic construction is hidden-root work
- player choice concerns use, supply, or breach preparation
- every route changes a different strategic problem

## Art composition lessons

The event report image should use depth to communicate scale. Avoid a world map or fields of repeated tiny bunkers.

Recommended composition:

- one clear foreground emplacement
- obstacles and communication trench in middle distance
- a road, rail, settlement, or terrain objective beyond the line
- inspection parties occupying completed works
- distant line segments that imply broad coverage

The decision category picture can combine a fort sector, transport link, and observation position. It should remain a military scene with no painted interface controls.

Icons need one concept each. A combined air and coastal decision icon can use a general fortified-flank warning symbol when three small literal objects become unreadable.

## Research gates for implementation

Before using a named historical reference in final art research:

- identify the exact source image
- record creator, archive, date, rights status, and URL where required by project rules
- confirm whether it can be distributed or only used as private composition reference
- avoid copying a distinctive protected photograph
- remove flags, insignia, readable signs, and country-specific claims from generated final art unless the accepted design requires them

The asset research scope centers on period fortification architecture, terrain, obstacles, inspection parties, and military logistics.
