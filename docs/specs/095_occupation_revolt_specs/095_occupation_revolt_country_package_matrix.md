## Required per-country activation record

Record canonical tag, origin provenance, authentic home states and center, alternate seat, current ownership/control, character availability, government identity, laws, research slots, compatible basic technology, surviving stocks and formations, army/navy/air access, current meaningful focus tree, completed route commitments, country symbols, AI role and allowed diplomatic relationships.
Use the smallest repair needed for missing data.
Preserve existing valid data.
Do not create ideological leader variants or flags solely because a generic matrix has empty columns.

## Route parity

Every actual claimant must be able to defend its base, obtain and use real equipment, establish national command, settle its government, pursue supported home-region expansion, negotiate an attainable outcome and end the event cleanly.
A country keeping a native tree receives the same essential programs through decisions and missions.
A country receiving the restoration tree also uses those same operation contracts and receipts.
A completed focus and its decision counterpart cannot award the same program twice.

## Uninspected required sources

The supplied archive documents the national-origin and country-package approach but does not contain every native country file, tag registry, history file, character file or installed focus tree.
Those actual sources have not been fully read in this task.
The implementation country-package auditor must inspect each affected profile and retain exact paths and evidence before declaring its row complete.
This matrix is full design coverage by archetype, not a fabricated all-country implementation audit.
