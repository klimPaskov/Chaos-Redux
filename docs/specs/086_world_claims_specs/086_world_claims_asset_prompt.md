Inspect actual skill-local vanilla references and their contact sheets before production. If a required contact sheet is missing, build it from real references, label filenames and native dimensions, and update the reference README/CATALOG as instructed. Do not claim those images were reviewed in the planning chat. Keep source, processed candidate, approved runtime output and evidence separate.

Produce all ten report/news briefs, the seven decision icon families, the single confidence family, eight achievement concepts' complete native icon-state families, the full approved dynamic identity flag inventory, and all exact-state puzzle assets required by the active-map pages. Follow the flat reference-constrained imagegen rule for flags and preserve identity evidence where a grounded polity supplies a motif. Variants must be substantive compositions, not just recolors. Do not use one generic flag for every possible greater country.

The dynamic territory system selects prepared resources. It does not generate flags or textures during play. Final asset counts must be derived from the approved geographic and identity registry and recorded in a manifest. Resolve missing coverage before making a family selectable.

Map pieces must use exact installed geometry from the canonical registry and approved consumer workflow. Never hand-draw or image-generate a state outline. Preserve page projections, wrapping, tight bounds, source hashes, unresolved/qualifying cues and shared state identity. Pieces are static and informational. Do not add a decorative category picture behind the puzzle. Archived producers need deliberate review, not casual execution.

Use the required native PNG-to-DDS conversion contract and decode every final DDS back to PNG at native size. Record dimensions, headers, byte lengths, alpha checks and exact pixel equality. Native flag files use their proper TGA workflow. A preview PNG or assets_pending manifest is not a final runtime asset.

For the UI, create the required reference images and image-to-native-element mapping, obtain explicit parent acceptance, and coordinate with the bounded event UI worker for inspect/render and matched state/resolution evidence. A text specification is not a visual approval.

Delegate source research, generated event art, icon work and localisation through their real supplied profiles as appropriate. Record actual execution and evidence. Finish with the asset manifest, source/provenance record, native-size contact sheets, runtime registration crosswalk, hashes, conversion/round-trip evidence, missing coverage and an explicit completion status. Hash-aware final synchronization must not let an older source overwrite an approved runtime candidate.
