## Tracking notes

Keep first-participation classification, wave ancestry, country epoch, target provenance, core-profile receipts, project credit, adopted geographic signature, consolidation result, rival overlap, assurance receipt, and global denominator provenance. Each concept uses only the fields required by its predicate.

Achievements cannot be reconstructed from current cosmetic names. Native game cores without a WC award receipt do not satisfy WC-specific core achievements. Save migrations may preserve provable historical evidence but must not guess missing waves or continuous holding intervals.

Use the project's real visibility, completion, multiplayer and icon-state patterns. Each concept needs the complete native 64×64 icon family used by that system. Parent approval of final writing and assets does not replace proof that the unlock predicate works.
