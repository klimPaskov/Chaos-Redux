# Identity resolver and flag production matrix

Working family labels are not final localisation. No finished flag artwork is included. The design calls for a finite prepared identity library selected from genuinely dynamic territorial results. The engine must not be described as synthesizing images or arbitrary new country tags during play.

| Territorial family | Name basis | Visual brief | Provider precedence |
| --- | --- | --- | --- |
| Compact connected state | Registered anchor or physical feature plus appropriate political form | Founding motif within a coherent new composition, readable when small | Eligible native regional provider first |
| Peninsula / mountain / basin | Reviewed geographic descriptor | Region-specific structural motif, no fake historical crest | Native provider only when the actual route fits |
| Multi-country region | Reviewed regional descriptor and actual government form | Union of related territories without turning every flag into a collage | Reuse provider's own complete identity when valid |
| Island group / strategic sea | Reviewed maritime descriptor | Distinct shore or island composition with a restrained maritime motif | Native maritime provider retains its conditions |
| Continental | Registered continent descriptor and government form | Greater-scale emblem with a distinguishable institutional center | No duplicate of an existing unavailable native empire |
| Transcontinental | Held-center relationship and reviewed descriptor | Balanced multiple-center composition | Native provider's uniqueness rules remain its own |
| Hemisphere / global | Explicit scale and actual constitutional presentation | Broad unity motif distinct from continental artwork | Global WC result is not reserved by unrelated cosmetic names |

## Political variants

For each required dynamic family, produce the active game's four standard ideology presentation variants where the repository uses them. Verify actual keys before registering. Variants must be compositionally and symbolically appropriate, not only recolors. Additional ideology groups introduced by the mod require explicit mapping or their own valid variants.

Native flag output sizes: 82×52, 41×26, 10×7, in the verified native TGA contract. Preserve a high-resolution source and inspect the native-size outputs. Complete all required family and political variants before the family becomes selectable.

The number of final outputs is derived from the approved geographic/identity registry: three sizes per required prepared political variant per distinct dynamic family, minus genuinely reused native outputs. This package does not invent a final count without that registry. A count left unknown at this stage is a production gap to resolve, not an excuse to ship a single placeholder for every geography.

## Identity transaction

Resolve the claimant epoch, active identity owner, accepted name family, current political variant, and all runtime resources before charging a dynamic proclamation. Commit territorial recognition separately from the player's optional cosmetic adoption. A retained-identity choice receives its territorial milestone without triggering a cosmetic owner change.

A later ideology change can update the selected family's supported presentation without paying or rewarding the proclamation again. A later native event may legitimately take cosmetic ownership. World Claims must not repeatedly overwrite it from a refresh loop.

## Engine probes

Test country labels in the map, diplomacy, war participation, faction and subject views, news, and scripted localisation. Verify adjective and definite-article behavior only where the engine supports those fields. Test long names, non-ASCII descriptors, missing keys, absent variants, save/load, and cosmetic removal.

Do not rely on unverified dynamic `set_country_name` syntax or arbitrary string concatenation. If the engine supports only predeclared localisation keys or cosmetic resources, compile the needed combinations. A failed combination is an explicit coverage blocker.

## Geographic claim discipline

A flag or name does not prove a nation's historical right to a region. Descriptions explain the government's ambition. A historical-cultural family requires reviewed sources and careful terminology. Prepared artwork should avoid inventing heritage that the actual route does not establish.
