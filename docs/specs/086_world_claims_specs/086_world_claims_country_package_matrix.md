# World Claims: country continuity and formable-provider matrix

This event meaningfully changes countries through territory and optional identity. The matrix prevents a cosmetic formation from becoming an accidental replacement of the country's existing content. Existing-provider scripts require further source inspection before integration.

| Country family | Territorial access | Identity route | Country content retained | Specific gate |
| --- | --- | --- | --- | --- |
| Ordinary independent minor | Same all-neighbor claims as a major | Any justified dynamic scale, eligible native providers first | Actual tag, leader, parties, ideology, focus tree, research, units, generals, advisors, equipment, laws, diplomacy and economy | No original-major restriction on formation |
| Ordinary independent major | Same frontier and per-wave outer rules | Same dynamic resolver and providers | Same preservation contract | Larger F affects allowances, not a unique all-world shortcut |
| Subject or dominion | Own frontier, not patron frontier | Prepare dynamic ambition; generic proclamation waits for independence | Autonomy, overlord, native restrictions and existing country content | Native providers may permit formation only through their own real rule |
| Civil-war newcomer or released country | Own current owned frontier at next firing | Fresh claimant epoch and candidates | Native engine's new country package is preserved | No copied rewards or clocks from the defeated government |
| Continuing country after cosmetic formation | Same epoch, new current borders | Explicit compatible identity-owner handoff | All unrelated content and WC history | Cosmetic display is not a new recipient |
| Annexed and later re-created country | New epoch by default | Re-resolve geography and providers | Native retained cores are facts, not new WC achievements | Explicit proven continuation adapter required to retain old ledger |
| Government with no foreign land neighbor | No territorial claims in that firing | May preview justified holdings-based ambitions at I+ | Ordinary country and diplomatic options | No random overseas compensation claim |
| Special playable territorial actor | Apply real project classifier; preserve universal claim intent | Valid geographic identity only if compatible with actor-owned content | Actor's own economy, integration, leader and country systems | Explicit nonstandard integration/provider adapter, no blanket exclusion |
| Bookkeeping or dormant entity | Not a territorial participant | None | Do not awaken or create it | Validity predicate distinguishes it from a real government |

## Provider inventory to complete in the live repository

The supplied catalogs and focused repository search identify potential providers associated with the Holy Realm, African country transformations, Malta Crusaders, Old Great Bulgaria, and Persia. These are discovery leads, not verified automatic compatibility. Read each actual current route, country package, focus tree, territory policy, localisation, and cosmetic assets before adding a provider adapter.

A provider record needs its stable identifier, owning package, exact availability helper, exact territory helper, completion entry point, cost owner, identity owner, core policy, DLC restrictions, chronology and continuity policy. Record which native requirements remain unmet in a WC preview. A raw cosmetic-tag occurrence is not a complete formable provider.

Geographic similarity alone never invokes a named route's special ideological, religious, supernatural, or political story. A regional WC ambition can share a continent with an event without automatically inheriting that event's mechanics or identity.
