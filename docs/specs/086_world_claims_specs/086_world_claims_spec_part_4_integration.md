# World Claims: occupation, integration, and cores

## Starting Compliance belongs to the claimant

World Claims promises a starting point, not a permanent minimum. When the country controls a state that its own World Claims expansion marked, its applicable entitlement is 25, 50, 75, or 100 percent according to the effective profile.

The initial operation raises Compliance to that value only when it is lower. It never reduces an existing value. Afterward, native occupation rules, losses, events, laws, and other valid systems continue to affect Compliance normally.

The entitlement is consumed even when existing Compliance is already higher. A country that begins control at 70 percent while entitled to 25 percent cannot save its unused reward, wait for Compliance to collapse, and ask for a refill.

Another occupier does not inherit the World Claims grant, integration-project credit, or control history. That country can receive its own entitlement only if it independently holds World Claims provenance for the state and satisfies its own conditions.

## Upgrades are not stacks

A higher activated profile can upgrade a previously used entitlement. A country credited at 25 percent can later receive a one-time upgrade to 50 percent. This raises the current value to 50 only if necessary. It does not add another 50 percentage points.

The ledger tracks credited Compliance ceilings, not just Evolution numbers. Evolutions II and III both supply 75 percent, so entering III cannot issue a second 75-percent grant. Evolutions IV and V similarly share 100 percent.

An upgrade that becomes available while the state is not controlled by the claimant remains pending. It may be applied on the next valid control only if that higher profile is then active and enabled. Repeated loss and recapture do not restore previously consumed ceilings.

Examples clarify the result. A state at 60 percent remains at 60 when its claimant first receives a 25-percent entitlement. A state that fell from 50 to 20 after its grant remains at 20 on an unchanged repeat. A genuine new 75-percent upgrade can raise that 20 to 75 once. The next recapture does not do it again.

## What counts as control

The claimant must be the state's actual controller under the engine's state-control policy. Owning the state while an enemy controls it is insufficient for the integration grant. Controlling one province inside a state is insufficient unless the engine has actually assigned state control to that country.

The game must have an applicable occupation-Compliance relationship. A state already core to the claimant requires neither a starting grant nor World Claims integration. It is treated as already integrated for ambition qualification, without creating a new core reward receipt.

The World Claims core rule follows the user's control-based design. Legal ownership is not an additional requirement for earning a World Claims core. This allows wartime integration after a sustained occupation. Adding a core does not itself make the state owned territory for the next frontier wave.

## Control history and interruption

Continuous control begins no earlier than the moment World Claims provenance exists for that country-state pair. A claim generated while the country already controls the state starts the recorded World Claims interval then. The system does not invent years of prior qualifying occupation that it never observed.

Loss of state control resets the continuous-control clock and the continuous high-Compliance clock. The original provenance and spent entitlement survive. Recapture begins a new control interval without providing another initial Compliance grant.

A temporary fall below the required Compliance threshold resets the high-Compliance clock, while the control clock can continue. The country must rebuild genuine support and maintain it for the appropriate period. A higher Evolution can shorten the required intervals but cannot manufacture unobserved time.

Timers use elapsed game dates and proven transitions, not the number of maintenance ticks or the number of times the player opens the category. Save and reload preserve them without awarding time twice.

## Earning a core

A World Claims core requires all of the following at commitment: the proper active core-capable profile, valid claimant-specific provenance, present state control, sufficient continuous control, sufficient current Compliance, and the required continuous high-Compliance interval.

The normal standards are 360 days and 80 percent at Evolution III, 120 days and 90 percent at IV, and 30 days and 95 percent at V. Their high-Compliance intervals are respectively 60, 30, and 10 days.

Qualification awards the core automatically. A country does not need to pay political power for each state or click hundreds of ready-state buttons. The category can provide an informational ready-state list and a summary of recently integrated territory.

The operation is idempotent. An already existing core produces no new reward, achievement increment, or Chaos change. If another system grants the core first, World Claims records that the state no longer needs its own award.

## Integration projects

The player can improve a difficult frontier through a limited number of concrete projects. Their purpose is to give agency when ordinary occupation is slow or strategically awkward. They supplement the universal grant and automatic core process.

A civil-integration project provides one local, claimant-specific gain of 10 percentage points of Compliance, capped at 100. A connection project can grant up to 25 percent of the selected pair's required control duration as preparation credit. Preparation credit does not replace continuous real control below the minimum physical holding period: 270 days at III, 90 days at IV, and 25 days at V.

The high-Compliance interval always remains mandatory. A project never makes a state instantly core on the day it is taken. Each project reward has a country-state-project-family receipt. Repetition, renaming, recapture, and selecting the same state through a successor ambition cannot farm it.

Projects have real territorial objectives and material costs. They may require retaining a corridor, repairing a damaged connection, or holding an administrative center without losing the target region. A player who declines them can still integrate through the normal route.

## Ambition integration and core integration

A state can count as integrated enough for a regional proclamation before cores are enabled. The proclamation test accepts an existing core or sufficient native Compliance plus the ambition's holding requirement. Ordinary noncore possessions may qualify through native integration without receiving World Claims provenance or benefits. The separate ambition holding record must verify their control time. This does not pretend that they are already native cores.

At later stages, the integrated heartland can contain actual World Claims cores, original national cores, and well-administered non-core states. The interface must distinguish these categories in hover information even when several count toward the same political milestone.

A proclamation never applies a blanket core effect across its geographic envelope. Missing states remain missing. Controlled but unready states retain their clocks. Another claimant's successful proclamation changes none of these facts.

## Loss, survival, and restoration

Earned cores are permanent unless a separate established game system explicitly removes them. Defeat can therefore leave a former greater state with contested cores rather than erasing its entire history. World Claims does not remove other countries' claims or cores to tidy the map.

Capitulation with continued country existence preserves the country's records while loss of control stops its timers. Full annexation ends active projects and queues. A later release creates a new administrative lifecycle for grant receipts and missions. Native claims or cores that the engine legitimately retains for the released tag remain map facts, not newly earned World Claims rewards.

A cosmetic name change does not create a fresh country lifecycle. A genuine successor created by another event inherits World Claims records only through an explicit, validated continuity decision from that owning system. It never receives them merely because it has a similar name, flag, ideology, or capital.

## Required integrity

The precise engine handling of Compliance across control changes must be proved. A state-level setter alone does not establish claimant isolation. If the implementation cannot preserve a claimant's own benefit without passing it to another occupier or erasing unrelated native Compliance, the Compliance feature remains blocked. The design must not quietly replace claimant-specific integration with a globally shared state bonus.
