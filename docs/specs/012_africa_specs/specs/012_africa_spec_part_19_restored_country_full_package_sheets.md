## Country package cleanup rules

- If a restored country is annexed through staged integration, retire its country-specific decisions and convert any unique ideas into regional integration modifiers only when the route supports it.
- If a restored country remains as an associated member, keep its flag and name visible and give the unifier federal or League bonuses instead of absorbing the tag.
- If a restored country defects to a rival bloc, preserve its identity and use rival logic rather than deleting it.
- If a high-chaos actor is removed, clear nonhuman or supernatural classification flags, route missions, disaster pressure links, and special unit recruitment.
