# 012 Africa spec part 26, restored polity extension sheets

This file expands the restored country package layer beyond the priority sheets already written. It is still a planning handoff, not a tag registry. Final tags, exact state ids, portraits, flags, and historical symbol files must be resolved in the live repo.

## Extension package rule

A restored polity is not a free annexation reward. It should appear as a member, subject, rival, federation unit, protectorate, or route-specific restored country. The unifier can later integrate it only through staged work, autonomy deals, puppet routes, or conflict.

Every restored package needs:

- direct public country name
- ideology names that stay readable
- region and state-group intent
- starting problem
- starting forces and reinforcement route
- League behavior
- integration behavior
- refusal or rival behavior
- asset source mode
- AI route stance

## Polity-specific refusal and integration behavior

Restored polities should not all behave like weak puppets.

| Behavior type | Countries likely to use it | Integration consequence |
| --- | --- | --- |
| High autonomy federalism | Asante, Kanem-Bornu, Sokoto, Buganda, Merina, Zanzibar, Barotse | can federate but resists direct annexation |
| Port autonomy bargaining | Kilwa, Mombasa, Zanzibar, Sofala, Mogadishu, Loango | requires convoy, dockyard, port security, and customs settlement |
| Sacred or cultural centre protection | Aksum, Ife, Timbuktu, Harar, Kush, Makuria | needs cultural guarantee and local institution protection |
| Military restoration pride | Zulu, Dahomey, Oyo, Mossi, Tuareg confederation | may accept army integration first, political integration later |
| River and trade mediation | Songhai, Kongo, Luba, Lunda, Futa Toro, Kazembe | can serve as regional mediator if respected |
| Tiny island or city-state protection | Comoros, Pate, Lamu, Seychelles | accepts defense and port autonomy, should not be forced into major army role |
| High-chaos nonhuman separation | Gorilla nation, Chimpanzee nation, Living Statues, Stone Host | never use human restored-polity templates |

## Starting force scaling

The implementation should create dynamic starting forces from local conditions.

| Factor | Effect direction |
| --- | --- |
| local population | more militia and infantry capacity |
| local industry | better equipment and support units |
| ports | port guards, convoy missions, marines only for stronger ports |
| mountains or desert | specialized local templates with supply tradeoffs |
| capital victory point | stronger capital guard |
| colonial war state | more irregulars and defectors |
| League aid | better equipment and training |
| high chaos | stranger units only for flagged high-chaos actors |
| restoration legitimacy | more officers and better organization |
| coerced release | weaker morale and higher resistance |

## Reinforcement pathways

Each restored country should have at least two reinforcement pathways.

- local militia mobilization that costs equipment and local support
- capital or port guard mission that requires holding named states
- League training mission that costs infantry equipment and support equipment
- foreign volunteer corridor if a sponsor or League member supports it
- regional cavalry or mountain unit path where terrain fits
- industrial cadre path if the country completes local factory or rail projects
- high-chaos special unit path only for nonhuman or supernatural actors

## Direct naming rules

Public map names must stay direct.

Allowed examples include `Kanem-Bornu`, `Kingdom of Kanem-Bornu`, `Futa Jallon`, `Loango`, `Sultanate of Zanzibar`, `Barotse`, `Mombasa`, `Adal`, `Harar`, `Comoros`, and `Kuba`.

Do not name restored countries as a bureau, office, board, mission, compact, or authority. Those words can name internal bodies, decisions, councils, or route mechanics only.

## Country package acceptance

A restored country package is complete only when it has a spawn route, public names, politics, starting problem, starting forces, reinforcement path, League behavior, integration behavior, AI stance, assets, localisation direction, and cleanup.
