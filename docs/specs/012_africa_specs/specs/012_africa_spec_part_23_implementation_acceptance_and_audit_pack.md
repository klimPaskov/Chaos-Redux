## Research gates that must remain blocked until resolved

- Final super-event title, quote, button text, cultural remark, and audio selections.
- Exact historical flags and real leader portraits.
- Exact state ids and state group membership.
- Additional source-language obscene names beyond the two required strings.
- Any real-world cultural, religious, or political reference used as final player-facing wording.

## Final audit sequence

After implementation, run focus, decision, country package, localisation, asset, documentation, spreadsheet, and completion audits. The completion auditor should compare the accepted spec pack, all plan files, subagent handoffs, and implementation files. Any simplification must be documented before a completion claim.
