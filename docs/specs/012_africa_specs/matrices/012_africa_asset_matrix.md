# Event 012 Africa — Asset Matrix

This matrix summarises visual assets planned by the spec. The full production brief is in `prompts/012_africa_asset_prompt.md`.

## Source-mode rule

- Real leaders, real historical flags, and attested real symbols: source through `chaosx_asset_source_researcher`.
- Fictional leaders, symbolic councils, invented flags, supernatural identities, nonhuman entities, icons, UI art, and high-chaos scenes: generate through the appropriate asset subagent.
- Animated final assets require real source frames, static fallback, sheet DDS, preview GIF for review only, manifest, and `.gfx`/`.gui` handoff.

## Asset acceptance criteria

- Every asset has source PNG, processed PNG, final DDS/TGA where applicable, manifest entry, and handoff note.
- Focus, idea, decision, achievement, and flag assets are not resized copies of each other.
- Real people and real symbols are sourced, not generated.
- Fictional/supernatural assets are documented as generated and not presented as historical sources.
- Animated assets include frame plan, source frames, processed frames, sheet PNG/DDS, static fallback, preview GIF, and sprite handoff.
