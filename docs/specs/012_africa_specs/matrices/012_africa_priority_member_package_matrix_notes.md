# Event 012 Africa priority member package matrix notes

This matrix summarises the first 16 fully playable restored and regional member packages from spec part 9.

## Selection principle

The first tranche is intentionally selective. It covers different political forms, regions, economic problems, territorial overlap types, and League relationships. It does not imply that the other polity-catalog entries are unimportant. Those entries remain available for compact release, autonomy, cultural recognition, later promotion, or regional congress outcomes.

## Package standard

Every priority package contains:

- a safe compact formation basis
- a starting political and material problem
- a distinct mechanic or decision family
- several country-specific focus modules
- a starting force identity and reinforcement direction
- more than one valid relationship with the Charter League
- a refusal, withdrawal, or rival path
- route-aware AI
- post-settlement play
- a bounded asset family

## Anti-bloat rule

Priority countries use the shared continental tree, Charter values, regional councils, relationship ladder, corridor systems, and integration stages. Their focus modules and mechanics alter those systems. They do not duplicate them.

The implementation should not create every historical border, every claimant, every city, every constituent authority, or every overlapping polity as a separate permanent tag. Compact autonomy, cultural institutions, associated countries, state modifiers, scripted councils, and dormant candidates remain valid outcomes.

## Audit use

A priority package is incomplete if it has only a tag, flag, leader, and generic tree. It must have a playable first problem, a territorial safety rule, a reason to cooperate or refuse, a military growth route, and a reason to remain active after its initial settlement.
