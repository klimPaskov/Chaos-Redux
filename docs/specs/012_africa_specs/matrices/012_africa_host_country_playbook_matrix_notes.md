# Event 012 Africa host-country playbook matrix notes

This matrix converts the host-specific design in spec part 7 into a compact implementation and audit reference.

## Depth model

- **Full host dossier:** 22 historically and strategically distinct starts. Each receives a bespoke starting problem, first proof mission, several overlay modules, route biases, rival pressures, a post-unification legacy, route-aware AI, and a bounded high-chaos gate.
- **Compact host signature:** 29 smaller or more conditional starts. Each modifies the shared continental opening without receiving a parallel large tree.

The shared continental focus tree, Charter League system, regional councils, decision families, and integration ladder remain the common backbone. A host entry changes the problem the player must solve and the way shared branches behave. It does not create a second isolated ruleset.

## Promotion and demotion

A compact signature can be promoted when it becomes the principal regional host, leads a durable rival bloc, anchors a major corridor or island system, or receives a Tier A restoration identity. A full host can be demoted for a particular campaign when its viable territory, institutional base, or access is too weak for a serious long campaign.

## Audit use

The matrix should be used to verify that:

- every valid host has at least a compact opening identity
- no full host is implemented as a cosmetic rename only
- the first proof mission is playable and connected to the host problem
- route AI respects the host’s survival problem
- post-unification content remembers the host
- high-chaos material remains gated
- a host overlay reuses shared Charter systems instead of duplicating them

The full prose design and historical caveats remain in spec part 7 and the host-country research addendum.
