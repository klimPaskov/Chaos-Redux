# Africa canonical goal prompt

Implement Chaos Redux Event 012, Africa, from the canonical planning package. This is gameplay implementation, not a new planning pass.

Core promise: one valid African-capital country becomes the Africa unifier and gains a large Africa event package. It must not instantly annex or core the continent. It should lead a staged anti-colonial and continent-unification system with deep focus routes, Charter League membership, defended African countries, influence pressure, rival blocs, restored polities, diaspora return, regional integration, Scramble reaction, and rare high-chaos content.

Required surfaces:
- fire-once event selection for a valid African-capital country
- RSA-in-Allies branch that starts a civil war instead of a simple unifier flip, with Allied peace if the continental side wins
- cosmetic identity and direct country names
- large non-linear Africa focus tree with Shared Opening, Federal Charter, Revolutionary Congress, Crown of the Continent, Continental Command, Sacred Soil, Black Star Return, Deep Green, Scramble, and world-route gates
- Charter League values for member confidence, unifier influence, autonomy demand, rival appeal, resistance pressure, and League cohesion
- target states from contact to observer, protected, associate, member, federal member, dependent member, rival, hostile, and integration crisis
- refusal logic, rival bloc formation, reconciliation, exit, puppet, federal, and coercive routes
- staged regional integration with no free full continent cores
- priority restored polity packages and high-chaos nonhuman actors with proper classification
- diaspora shipping lanes, settlement capacity, industrial cadres, reception confidence, backlash, and lane security
- Scramble for Africa outside-power reaction tree after Africa is secured
- high-chaos nonhuman and supernatural routes only behind gates, never as human African caricatures
- fictional disease and disaster pressure with containment, blowback, AI restrictions, and no real-world disease instructions
- achievements with tracking flags, disqualifiers, icons, docs, and localisation
- assets by source mode, including sourced real flags and portraits, generated fictional and nonhuman assets, route icons, decision icons, idea icons, achievement icons, and super-event images
- researched super-event packages with final quote, remark, audio, image, docs, and music table only after source review

Keep country names direct. Do not use office-like map names. Preserve only the two required source-language leader-name strings as untranslated flavor data. Do not invent additional obscene names without source review.

Before claiming completion, run focus, decision, country, localisation, asset, scripted-system, super-event, spreadsheet, and completion audits. Report any simplification, missing route, fallback, placeholder, missing asset, missing AI, missing localisation, missing state id, or unclosed research gate.
