## Main system

Build a phased Charter League decision layer with a selected member, selected region, selected restoration candidate, or selected world-order target workflow. The player should see current relevant actions, not all 102 rows at once.

Required families:

- protection
- accession
- regional congress
- integration
- economy
- diaspora
- rival blocs
- constitutional route crises
- host opening and proof recovery
- priority-member promotion
- high chaos
- Scramble response
- post-unification governance
- world order

## Country-specific behavior

The first proof mission, recovery mission, corridor type, target preference, and risk profile must come from the selected host overlay. Do not make every host protect the same neighbour or complete the same generic mission.

Priority member packages must call the shared action systems through their distinct mechanic. Asante uses stool and council legitimacy. Oyo uses corridor and city compact. Sokoto uses emirate compact and reform. Kanem-Bornu uses lake and caravan obligations. Manden uses assembly legitimacy. Kongo uses cross-border consent. Buganda uses kingdom confidence. The remaining priority packages follow their matrix entries.

Promotion into a full country package needs viable territory, local support, institutions, access, a distinct role, and a safe overlap settlement. It must not be a free tag button.

## Constitutional crisis layer

Implement the seven route-crisis actions and the postwar constitutional review. Each crisis must test the route’s governing promise:

- federal deadlock
- republican election legitimacy
- royal succession
- food and industrial planning balance
- commander loyalty and handover
- confederal emergency ratification
- Covenant obligation and containment
- postwar demobilisation and constitutional review

The crisis can succeed, partially succeed, fail, or transform the constitution where the spec allows it. It must not resolve through a small political-power payment.

## Action quality

Every important action must have:

- owner and target validation
- route, host, and phase visibility
- dynamic cost based on relevant resources and state
- clear blocked requirements
- duration suited to difficulty
- success, partial success, and failure where the action is risky or timed
- visible effects on Charter Authority, Continental Reach, Integration Burden, Colonial Pressure, Member Confidence, route commitments, readiness, diaspora trust, ecological wrath, or connected systems
- AI use
- cancellation and cleanup
- exploit protection

Use equipment, manpower, trains, convoys, fuel, XP, factories, route access, state control, local support, confidence, legitimacy, ecological concessions, and time pressure where they fit. Political or command power can be one part of a cost but should not replace the material burden.

## Presentation

Use a scripted GUI or decision-category-attached interface for values, selected member, clauses, projects, regional congresses, host proof, country-package promotion, route crises, and alerts. Normal decisions and missions remain the action surface.

Long requirements need custom tooltips and dynamic localisation. Costs should be icon-first. Dynamic integer values should not display unnecessary decimals.

## Clutter control

Use relationship state, phase, route, host overlay, selected target, regional pool, active mission caps, emergency state, and replacement of obsolete actions. AI must evaluate valid targets without human selector clicks.

## Integration rules

Positive opinion alone cannot grant integration. Use confidence, clauses, route compatibility, local support, state control, relationship history, and manageable burden. Occupation requires long settlement and cannot grant instant continent-wide cores.

## High-chaos and terminal rules

High-chaos actions require Evolution III or an explicit equivalent opening, valid actors, enabled systems, bounded disaster or disease targeting, and full cleanup. Terminal world-order actions require shared world-end guards and resolved continent identities.
