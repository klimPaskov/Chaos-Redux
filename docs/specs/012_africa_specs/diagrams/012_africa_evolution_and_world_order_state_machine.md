# Event 12 Africa evolution and world-order state machine

The event begins at Chaos tier 4. The design therefore uses three logged post-fire evolutions and treats the requested Evolution IV as a post-unification escalation layer rather than an impossible fourth post-tier track.

```mermaid
stateDiagram-v2
    [*] --> Baseline

    Baseline: Protection-first host package
    Baseline: Early League and regional overlay
    Baseline --> EvolutionI: dynamic pacing after continental consolidation conditions

    EvolutionI: Wider interventions and regional wars
    EvolutionI: Foreign powers recognise continent-scale danger
    EvolutionI --> EvolutionII: dynamic pacing after stronger control and institutional thresholds

    EvolutionII: Stronger claims, integration, core cleanup, and strange formations
    EvolutionII: Expanded focus and decision branches
    EvolutionII --> EvolutionIII: dynamic pacing at extreme chaos with valid high-chaos content

    EvolutionIII: Nonhuman and supernatural actors
    EvolutionIII: Disaster, disease, ancient host, and world-order branches
    EvolutionIII --> AfricaIsOne: all continental settlement conditions completed

    Baseline --> AfricaIsOne: grounded unification can succeed without high-chaos route
    EvolutionI --> AfricaIsOne
    EvolutionII --> AfricaIsOne

    AfricaIsOne --> ScrambleCrisis
    ScrambleCrisis --> StableAfrica: recognition or defensive victory
    ScrambleCrisis --> FragmentedAfrica: member cascade or lost continental war
    ScrambleCrisis --> PostUnificationIV: Africa stable and world-order path chosen

    PostUnificationIV: Requested Evolution IV content layer
    PostUnificationIV: Sponsorship, continent unifiers, unions, and rivalries
    PostUnificationIV --> ContinentalWars: terminal conditions and rival powers exist
    PostUnificationIV --> StableAfrica: world-order route declined or closed

    ContinentalWars --> DynamicUnion: negotiated multi-continent union
    ContinentalWars --> RivalSettlement: rival continent defeated or subordinated
    DynamicUnion --> ContinentalWars: unresolved rival continents remain
    RivalSettlement --> ContinentalWars: unresolved rival continents remain

    ContinentalWars --> TheWorld: one eligible continent-scale power remains and all settlements complete
    TheWorld --> [*]
    FragmentedAfrica --> [*]
    StableAfrica --> [*]
```

## Pacing notes

- Evolution incidents use dynamic MTTH and do not fire instantly unless a forced evolved opening explicitly calls for it.
- Disabled evolutions must not set recorded flags or block the grounded route.
- High-chaos content is optional and cannot become a hidden prerequisite for Africa is one.
- Post-unification Evolution IV content is still a major playable layer, but it should not be logged as an impossible extra chaos-tier evolution if the shared system supports only one evolution stage per tier.
- The World requires the shared world-end threshold, terminal guards, resolved continent identities, and a fully researched super-event package.
