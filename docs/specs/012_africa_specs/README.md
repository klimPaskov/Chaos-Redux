# Event 012 Africa canonical planning package

This is the final canonical planning package for Chaos Redux Event 012, Africa.

It consolidates the first, second, and third planning passes, then adds final closure material for the sections that still needed expansion. It is a planning and implementation handoff package. It is not gameplay implementation.

## What this package covers

- Africa unifier event start
- valid African-capital country selection
- RSA-in-Allies civil war branch
- direct country naming rules
- Charter League target mechanics
- member confidence, influence, autonomy demand, rival appeal, resistance pressure, and League cohesion
- refusal logic, rival blocs, reconciliation, puppet routes, federal routes, and coercive risks
- large non-linear Africa focus tree route structure
- route closure for Federal Charter, Revolutionary Congress, Crown of the Continent, Continental Command, Sacred Soil, Black Star Return, Deep Green Covenant, Scramble, and world route gates
- restored and revived African polities by implementation tier
- regional integration projects and staged coring
- diaspora shipping lanes, returnee settlement missions, industry cadres, cultural diplomacy, backlash, and achievements
- Scramble for Africa outside-power reaction
- super-event research candidates and audio source leads
- high-chaos nonhuman and supernatural route safety
- fictional disease and disaster pressure boundaries
- achievements, tracking flags, asset motifs, and acceptance criteria
- canonical prompts for coding, assets, focus trees, decisions, country packages, achievements, super-events, state mapping, and final audit
