# 012 Africa leader-name flavor source rules

The event brief requires two source-language leader-name strings. These strings must be preserved as flavor data only.

## Required strings

- `qaama saalaa koo xuuxaa`
- `haadha kee waliin wal qunnamtii saalaa raawwadhe`

## Use rules

- Keep the strings untranslated in English-facing text.
- Use them only as possible leader, king, regnal, court, council, or title flavor.
- Do not use the strings for file names, script ids, tags, sprite names, asset names, focus ids, decision ids, variable names, or technical identifiers.
- Do not make the whole package revolve around the joke.
- Do not add more obscene names without source review.
- If more names are added later, require a source note, language note, confidence note, and native-speaker or reliable-source review where possible.
- Never use direct English profanity as the map name or country name.
- Avoid using the names for real historical people.

## Final pass decision

No additional obscene source-language names were added in this sandbox. That is a deliberate source-quality choice, not a design omission.
