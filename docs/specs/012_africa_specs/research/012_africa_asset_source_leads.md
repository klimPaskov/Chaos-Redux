## Flag source handling

- If a historical flag is attested, source it and document the image.
- If no flag is attested, create a historically grounded alternate design from sourced motifs and say that no direct flag was found.
- Do not replace existing vanilla base flags unless the route explicitly changes the identity.
- Use cosmetic tags for route transformations.
- Produce normal, medium, and small flag files with correct orientation.

## Portrait source handling

- Real historical leaders require real source portraits.
- Fictional leaders and councils can be generated.
- Nonhuman leaders must be generated and classified as nonhuman.
- One-person generated portraits need gender presentation notes and compatible name pools.
- Council portraits use institutional names, not random personal names.
