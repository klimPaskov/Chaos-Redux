# 097 Collaboration
## Part 10: Behavior acceptance and difficult cases

## Baseline acceptance

With three eligible countries A, B, and C, one baseline firing must change exactly six directed relationships. It must never create A-to-A, B-to-B, or C-to-C collaboration. Each relationship receives no more than 10 native percentage points and retains its own prior value.

The same scenario must work with a democracy, a subject, and a country without an agency. Any native incompatibility must be identified before the feature is declared implemented. Changing all three countries to a convenient ideology is not a valid demonstration.

All mechanical grants occur before reports are acknowledged. Leaving every human report open, acknowledging them in a different order, or loading a save must not change who received the grant.

- A firing in a world of about one hundred countries finishes its pass in daily batches, each beneficiary once, and the opening report appears only after the pass completes.
- Nonhuman countries and the named special Chaos families receive and grant nothing, and every other unusual human country participates.

## Repeat and cap acceptance

A second legitimate firing adds a second layer to current native values. Replaying the first firing's delivery does not. Native operations performed between firings remain reflected in the final values.

A pair at 95 reaches the native 100-point normalized cap with a 10-point offer and produces only 5 points of actual gain. A pair already capped has zero actual gain and no special overflow effect.

Newly released countries receive the next firing's current grant. They do not receive every past layer. Reusing a cosmetic identity must not be treated as releasing a new country.

An all-capped world must not manufacture a positive result or direct Chaos. Automatic availability and the shared repeatable recovery path must remain consistent with the implemented native cap detection.

## Evolution acceptance

Test first appearance at low Chaos, late first appearance with advanced enabled evolutions, and later evolution of an already active event. A pre-evolved first appearance still pays one normal grant.

Test each individual evolution disabled and every evolution disabled. The baseline remains usable. An enabled later evolution must not silently restore an explicitly disabled earlier behavior.

The normal grant must be 10, 20, or 25 according to actual enabled capabilities. It is never the sum of the stage values. Crossing a Chaos requirement without an actual activation must not change the grant or produce a false history entry.

## Early administration acceptance

Test a genuine hostile capture with C equal to 45, 50, 60, and 100. The 45-point network receives no evolved handover. The other initial offers target 70, 80, and 80 compliance respectively, preserving a higher current value.

Test a colony, the sponsor's own core, overlapping claimant cores, an allied transfer, and an actual enemy capture. Only the correct applicable homeland and sponsor can produce the handover.

Test repeated control changes and a later increase in network strength. An old offer cannot be paid again. A higher offer provides only its newly available difference. A native capitulation conversion remains distinct and must not be reduced.

Test an evolution activating during an existing occupation. Its one-time eligible review must use the same receipt as a later capture, preventing another payment on the next state transition.

## Fifth Column acceptance

Test proximity just below and at 75%, then below and at 90%, using the actual current native threshold. Test the 25% absolute-progress guard and a target already capitulated.

Test a sponsor without a victory-point homeland foothold, a sponsor with insufficient collaboration, a real qualified sponsor, and several qualified sponsors in the same incident. No coalition-wide reward is permitted.

Test the five-day separation. A first award cannot trigger the second award immediately. A comeback, loss of foothold, peace, actor removal, or setting change before the second stage must invalidate the pending effect.

Test a capped network and a native collaboration reduction later. Resolved opportunities must not become renewable refills. No direct capitulation command or country-wide surrender modifier may be used to substitute for the native mechanism.

## Government acceptance

Demonstrate an actual native collaboration government created from a qualifying network and defeated occupation. Include a case where native capitulation consumes or converts the prepared value, using the verified pre-defeat observation rather than guessing from later compliance. A generic puppet is a failed test even if it receives similar modifiers or a collaboration-themed name.

Demonstrate the native government's real state bundle, sponsor, country identity, and ongoing relationship. Demonstrate that foreign-controlled or disputed states are not stolen by the offer.

Test a non-democratic sponsor and a democratic sponsor. The democratic route must preserve unrelated war, faction, and puppeting restrictions. Its success cannot depend on a temporary ideology switch.

Test native access before Evolution IV, refusal to install after readiness, creation after a postponement, and invalidation after restoration or loss of territory. The evolution cannot lock native features, repeat its readiness intervention, or execute from a stale notice.

Test two rival sponsors with separate lawful occupations and one contested identity. Valid separate governments may exist only where native constraints permit them. Duplicate tags or duplicated territory fail acceptance.

## Connected-event acceptance

- A government in exile receives the installation report and the lost-protector report, and neither changes any value.
- A restored country's Purge lowers only the former installer's network by one layer, never below zero; Amnesty leaves it and applies the 90-day modifier to the restored states.

An Event 095 restoration must be able to remove a collaborator regime's control under its own accepted rules. Event 097 must neither erase the claimant nor reconstruct the old regime from pending work.

A restored country receives only the native collaboration its actual identity preserves and subsequent normal grants. No retrospective universal catch-up is allowed.

An Event 052 leak reduces only the exposed country's networks inside at most three named exploiters, by no more than one baseline layer each, never below zero, and grants nothing.

After the Fallout transition begins, no Event 097 path writes collaboration: test a pending global grant, a delayed Fifth Column stage, a readiness offer and an Event 052 reduction across the transition.

Test the harsh-rule deferral: a capture under a harsher-than-standard occupation rule pays nothing, keeps the offer unspent, and pays once when the rule is relaxed while the state is still held; switching back to the harsh rule afterward does not claw back compliance or reopen the offer.

For the treaty connection, Spanish and Portuguese networks remain distinct. Government credit, state ownership, and collaboration cannot move merely because the treaty proposes a sphere. A Galicia-only route does not satisfy the world-partition achievement.

## Chaos and history acceptance

One global manifestation pays one global direct impact. The breadth increment counts distinct targets crossing the deep-network threshold, not pairs. Reports and duplicate deliveries pay nothing.

Native capitulation, annexation, government creation, peace, restoration, liberation, and independence must each follow the correct shared accounting without an extra Event 097 copy of the same consequence.

The actorless manifestation and actor-specific breakthroughs must remain correctly distinguished in history. The theoretical evolution description must not appear as a claim that an evolution already happened.

## AI acceptance

All automatic network effects are identical for AI and human countries. Government choice must follow the real legality checks before applying the strategic preference policy.

Exercise each score example in Part 7 and conflicting modifiers. An unavailable input must be reported. It must not default to whichever answer makes installation easiest.

Review the event's actual shared pool and repeatable cluster behavior with the prescribed probability tools. Source inspection or a hand-calculated score does not prove normalized game selection chances.

## Presentation and achievement acceptance

All five report states must have processed, wired assets and readable dynamic text. The text must describe foreign subversion rather than a universal cooperation agreement.

Every achievement must prove positive eligibility, near-miss failure, exploit rejection, save/load persistence, and interval reset. Optional connected challenges must remain properly gated until their companion behavior exists.

Inspect completed, grey, and not-eligible icons at actual game size. Inspect report images in their real UI consumers, including long dynamic country names and light-background text.

## Durability and scale

Test a save between the global grant and report acknowledgment, between Fifth Column stages, and before a government creation action. Reloading must not repeat mechanical rewards.

Test country removal, civil-war identities, subject changes, exiles, annexation, restoration, and cosmetic renaming. Stale references must not redirect an award to an unrelated country.

Exercise a large-country-count campaign and a large coalition war. The normal global firing may need a bounded all-pairs operation, but the completed design must not require a permanent daily or weekly scan of every country pair. Ongoing work should follow actual active occupations, fronts, consequences, and achievement cohorts.

## Completion standard

The event is ready only when these behaviors are implemented with the real native mechanic, the required settings and shared framework remain intact, assets and localization are complete, and the required evidence has been reviewed.

A missing native capability, unsupported democratic route, unresolved connected-event contract, or unperformed validation must remain visible in the implementation handoff. None can be disguised by replacing the mechanic with a simpler generic modifier or by describing intended behavior as tested behavior.
