# Event 097 Collaboration Specification Package

Event 097 Collaboration is a Minor Repeatable event at Chaos level 1 and a Medium member of the Intelligence cluster. Each firing gives every country a layer of native collaboration inside every other country. Four evolutions turn those networks into deeper recruitment, prepared local administrations, an internal fifth column, and installed collaboration governments.

## Acceptance basis

### Explicit user decisions

These come from the user's event brief and are fixed:

- Event 097 Collaboration is Minor Repeatable at Chaos level 1, in the Intelligence cluster as a Medium member, with status To Be Reworked.
- Every country gains collaboration against every other country, globally and symmetrically, through the normal collaboration mechanic. It ignores ideology, alliances, relations, and plausibility.
- The event is repeatable. Each firing deepens the networks, and values stack only as far as the normal system allows.
- There is no separate Collaboration currency or large event-specific management system. The normal collaboration mechanic is the event.
- The four evolutions, their names, their Chaos requirements of 200, 400, 600, and 800, and their described behavior.
- The connection to Event 095 Occupation Revolt, where installed governments can become targets of a national restoration uprising if enough opposition survives.
- The connection to the Treaty of Tordesillas Restoration event, whose spheres can rely on collaborator governments.

### Accepted design

Everything else in the specification parts, matrices, handoffs, and prompts is design that expands the brief. Its acceptance basis is the parent planning agent's acceptance within the user's request to create full specifications and expand the idea thoroughly. It has not been reviewed by the user. It includes the stance choice, layer sizes, network bands, every number, both decision categories, Collaborators Unmasked, Open Gates, Turned Regime, the Installed Administration lifecycle, local auxiliaries, the restoration pressure contract, the cluster combinations with Events 039 and 052, the Event 063 link, the Chaos impact map, the super-event, and the achievements. All numbers are tuning anchors that must pass the balance and probability reviews named in the package.

### Unresolved

These need a user decision or an engine fact before the dependent part is built:

- The installer route for democratic and non-aligned governments, if the scripted collaboration-government effect honors the ideology rules (Part 3).
- Whether relative reductions are possible through the native collaboration effect (A2 and the Purge option in Part 4).
- Whether Open Gates and Turned Regime have clean engine routes (Part 3).
- The Intelligence cluster's numeric id, which differs between the catalog, the cluster documentation, the Event 052 package, and runtime (Part 5).
- A war-weighted selection factor for Event 097. It would need a new event-owned weight hook in the shared selection system, so it stays a proposal outside this specification.
- Evolution pacing checkpoints, as described in the scripted architecture plan disposition.

The research notes list every engine fact that could not be verified during planning, because vanilla files, vanilla documentation, and the HOI4 MCP tools were unavailable.
