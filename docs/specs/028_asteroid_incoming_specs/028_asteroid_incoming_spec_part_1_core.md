# Asteroid Incoming

## Catalog entry

- Event ID: `28`
- Event name: Asteroid Incoming
- Event type: Major
- Campaign behavior: Global fire-once major event
- Baseline Chaos level: Calm World
- Status before implementation: To Be Reworked
- Cluster: None

## Event promise

For a brief period, a scientific project can alter the path of a very large Earth-bound asteroid. The chooser cannot cancel the danger after opening the event. The choice is where the object will go. Three dynamically selected countries appear as possible targets, each tied to one visible impact state. A fourth option preserves the original near-miss path.

A selected strike becomes a global map event. The trajectory locks for two days, the center state is destroyed, three land-adjacency rings suffer decreasing damage, civilian losses enter the shared Deaths system, affected countries receive consolidated reports, a permanent crater remains on the map, and an atmospheric dust load affects the world. The map explosion is presentation only. Every ledger, report, modifier, and diplomatic record must identify the source as an asteroid impact.

The miss is a complete outcome. It causes no hidden impact, no dust, no fragment strike, and no later punishment for avoiding the disaster. The world receives one close-passage news event and the major event is consumed.

## Campaign role

Event 028 should create one clear strategic decision followed by a long consequence chain. It has four campaign roles.

1. It gives the chooser direct control over a rare global disaster.
2. It changes the map through permanent and regional destruction.
3. It creates a shared recovery problem through atmospheric dust and damaged logistics.
4. At higher Chaos, it places powerful strategic objectives around crater states.

The event should remain readable despite its scale. The player makes one targeting choice, affected countries manage a phased recovery category, and the world sees one visible dust state. Internal calculations can be detailed. The visible surface should stay focused on the next useful action.

## Fixed design rules

The following rules are acceptance requirements.

- The entry event must offer exactly three distinct valid country and state targets plus one miss option.
- A target option must identify the country, state, and broad region before the player commits.
- The event must be unavailable when the system cannot construct three valid target pairs. It must not offer fewer targets or substitute invalid countries.
- The main target state must be selected before the choice event opens. The state cannot change after the option is shown.
- The two-day lock preserves geographic coordinates. Ownership, control, government, faction, or tag changes during the delay do not move the asteroid.
- The main impact center loses all civilian population and all buildings and becomes a permanent asteroid crater state.
- Main impact rings use shortest land-adjacency distance. A state is processed once at the strongest applicable ring.
- Directly adjacent states lose about 50 percent of their civilian population. The next ring loses about 25 percent. The third ring loses about 5 percent.
- Damage crosses borders through actual state adjacency.
- All civilian losses use the shared Deaths system and real state population transactions.
- Each affected country receives one consolidated report after the full impact transaction. The event must not create one popup per state.
- The impact visual must not create nuclear-use history, nuclear condemnation, radioactive fallout, nuclear retaliation, nuclear diplomacy, or any other nuclear consequence.
- Atmospheric dust follows every main impact and no miss.
- The global super-event follows a main impact and identifies the locked target country and region.
- The close-passage outcome uses global news and does not use the impact super-event.
- Global Fragmentation begins at 600 Chaos when the evolution is enabled and an impact is chosen.
- Extraordinary Minerals begins at 800 Chaos when both evolutions are enabled and an impact is chosen.
- The main crater armour bonus is plus 100 percent to existing land-division armour for its current controller.
- Each fragment crater contributes another plus 20 percent to existing land-division armour for its current controller.
- Crater benefits follow current control and are recalculated without duplicate or stale modifiers.

## Full event flow

### 1. Major-event selection

The shared event system selects Event 028 as a major event. The event prepares its chooser and builds three target pairs before any option is displayed. The major history context identifies the chooser. The final chosen target is stored as outcome data.

### 2. Target choice

The chooser sees three target cards and the miss option. Each impact option shows the country flag, country name, state name, broad region, and an impact-severity summary. When fragmentation is active, the choice surface also states that additional fragments are expected worldwide. It does not reveal their locations.

### 3. Confirmation and lock

An impact choice opens a confirmation step because the action cannot be reversed. Confirmation saves the locked country, state, region, and date. A global transaction flag blocks duplicate Event 028 instances. The target country receives an emergency response event. Other human players receive a short trajectory notice after the lock.

### 4. Two-day delay

The target country chooses one limited preparedness stance. No stance prevents the center state from being destroyed or changes the required ring population percentages. Preparedness affects command continuity, early repair, stockpile survival, and the opening recovery burden.

### 5. Impact resolution

The main center and three rings resolve as one protected transaction. Global Fragmentation, when active, resolves after the main center and before country reports. Overlapping footprints use the strongest applicable damage level and never apply the same civilian loss twice.

### 6. Reports and super-event

The system totals losses by country, updates Deaths, creates the crater state or states, applies dust, sends one report to each affected country, and broadcasts one global impact summary. The dynamic super-event then names the locked main target and region.

### 7. Recovery period

Affected countries receive emergency and reconstruction actions. Every country can use a smaller dust-mitigation family while atmospheric dust remains active. Crater controllers gain security and survey actions under Extraordinary Minerals.

### 8. Persistent aftermath

The main crater remains permanent. Fragment sites remain persistent crater states under their lighter damage profile. Dust decays through visible stages and eventually closes its temporary decision surfaces. Extraordinary mineral bonuses continue to follow control for the rest of the campaign.

## Choice quality

The three targets should create tension without making one option obviously fake. The system should prefer states with population, industry, logistics, and a meaningful three-ring land footprint. It should avoid three targets from the same small region when the world offers broader choices. The player should still receive unusual target combinations across campaigns.

The miss option must remain mechanically credible. The player sacrifices the chance to destroy a rival and any later access to crater material, while avoiding global damage and dust. No hidden reward should make the miss strictly superior in every campaign. No hidden penalty should punish a player for choosing restraint.

## Interaction with shared systems

### Major-event pacing

Impact and miss outcomes both consume Event 028, reset major weights under the shared major-event rules, and reset timer acceleration. The miss is not a cancellation that returns the event to the pool.

### Chaos Meter

Civilian deaths add Chaos through the shared Deaths rule. Air Cleanliness changes caused by dust also affect Chaos through the shared contamination synchronization. The event should not add a second arbitrary Chaos reward on top of those measured sources unless later balance evidence proves the normal sources are insufficient.

### Deaths

Every direct and continuing civilian loss must name an asteroid-specific reason. Main impact, main rings, fragment centers, fragment rings, and unresolved rescue deaths should remain distinguishable in the Deaths log while still rolling into country totals.

### Air Cleanliness

Dust enters Air Cleanliness as impact dust and atmospheric debris. It is separate from chemical, biological, nuclear, and radioactive sources. Its initial injection and monthly reservoir must be visible in the Air Cleanliness history.

### Natural Disasters

Event 028 owns the impact geometry, crater conversion, immediate damage, reports, and dust load. Event 013 can receive bounded aftermath calls for supported secondary disasters such as wildfire, ashfall-like debris, landslide, or flooding where terrain and existing family support make sense. Event 013 must not duplicate the primary asteroid history row or replace an unsupported family with another disaster.

### Condemnation

The selected impact is an intentional hostile act in narrative terms, but it is not unconventional-weapon use under the shared chemical, biological, nuclear, or atrocity source families. Any separate diplomatic reaction should be event-owned and should not contaminate the shared condemnation ledger with a false weapon category.

## Replay value

Replay value comes from target composition, impact geography, national borders crossed by the rings, the target government's preparedness stance, fragment locations, dust severity, and later crater control. The event does not need a large option tree. Its changing map context should make the same four opening choices produce different campaigns.
