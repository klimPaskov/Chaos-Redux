## Optional super-event 3: Fury defeated after terminal branch

This aftermath super-event is optional design and is not implemented; the terminal-wide `chaosx.nr7.53` report currently marks the last terminal Fury's fall.
Build it only if the README records it as accepted.

Role: defeat aftermath.

Trigger: all Fury actors are defeated after the world-end branch has been active long enough, or after the Fury faction controlled enough land to reshape the campaign.

Purpose: show that the world survives, but the border system and war memory remain damaged.

Tone: reflective and tired, without clean triumph.

Title direction: `The Quiet Borders`, `The Offices Close`, or `After the March`.

Description direction: Fury commands are dismantled, captured maps are archived, and reconstruction begins amid lasting distrust and militarized borders.

Button text direction: `Count what remains`.

Quote direction: a real quote about rebuilding after war, the cost of victory, or memory after violence, preferably public domain.

Image direction: generated or suitable public-domain archive image of an abandoned border office, sealed maps, soldiers guarding an archive, and tired officials.

Audio mood: a slower public-domain or clearly licensed reflective track, not triumphant unless the music still carries cost.

## Required documentation if built

Record title, description, button, and quote localisation, quote research notes, the image handoff, and the selected audio with title, creator, performer or source, URL, license, duration, usage terms, final file, sound ID, and music table row.
Do not claim the package complete with placeholder or undocumented audio.
