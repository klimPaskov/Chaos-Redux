## Handoff rules

Each implementation delegation must name the exact source paths, allowed mutations, source revision, accepted design, required references, scenarios and output evidence. Use `fork_turns="none"` for these custom roles. Parallelize only independent ownership. The patch owner preserves immutable before sources before weighted edits, then provides the same fixtures to the probability auditor. Parent review is required after every source or asset handoff. Durable specialist handoffs belong in `docs/plans/115_heroic_crusade_plans/subagent_handoffs/`, with an exact filename supplied in each delegation. Asset production evidence may remain in its explicitly assigned active workspace until promotion under the owner rules.

The historical supplied specialists and the continued readers were used only for the tasks recorded above. Production-only or conditionally relevant specialists are mapped for the implementation stage rather than falsely reported as executed. No image generation, audio production, native UI implementation, spreadsheet edit, skill mutation or 3D production occurred in this planning turn.
