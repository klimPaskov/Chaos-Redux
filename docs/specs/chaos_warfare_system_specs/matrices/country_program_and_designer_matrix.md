## Country-specific final-name process

1. Search existing country MIOs and designers.
2. Prefer an existing appropriate firm or agency.
3. Verify any new historical institution through reliable sources.
4. Use a generic national board when no verified firm fits.
5. Create localisation and icon only after the identifier is stable.
6. Record source confidence in documentation.

## Balance rule

Country identity changes access, starting readiness, and AI behavior. It does not grant immunity from equipment, deaths, contamination, or Condemnation.
