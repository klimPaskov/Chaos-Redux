## Starting legacy conversion

Current country cylinder stockpiles should be converted through one migration effect:

- chlorine and phosgene to choking lots
- mustard and lewisite to blister lots
- sarin and soman to nerve lots
- tabun according to final design choice

Conversion preserves relative arsenal scale but not the current identical country bundles. New-start history uses the country matrix instead.
