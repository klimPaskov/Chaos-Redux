# CXT Exact Biological Arsenal Registration

Status: accepted within the user's CXT and biological-stockpile integration requirement; implemented in source, with event-helper and engine-state validation pending.

Scripted `complete_special_project` grants CXT's ordinary biological projects before its special facilities are provisioned. Installed HOI4 documentation states that scripted completion does not apply facility-state effects, so the ordinary project callback cannot identify a physical arsenal for CXT. The CXT setup now runs `chaosx_test_country_register_unique_bio_arsenal` after the facility allocator and initial stockpile grant. It scans only CXT-owned states once and counts states that CXT controls, that can host an ordinary pathogen episode, and that have a positive biowarfare-facility level. One eligible state is saved as a regular event target for the current effect chain and revalidated before any pointer is written. Zero or multiple candidates set `chaosx_test_country_bio_arsenal_registration_blocked` and leave the monitor unstarted; no ranked, random, capital, or national fallback is used.

Registration requires CXT to have completed the Anthrax, Plague, Tularemia, and Smallpox projects and to lack both a valid arsenal pointer and prior designation history. It records the exact facility state, the CXT actor, the scripted-project pointer source, and the date; it then refreshes the existing risk snapshot and calls the idempotent monitor scheduler. A positive-level damaged campus remains eligible, matching the shared pointer-validity rule. A later helper call cannot replace an existing valid or historical designation. The scan is bounded to CXT's owned states during one player-triggered setup and introduces no worldwide periodic action or CXT replenishment hook.

The source owner is `common/scripted_effects/chaosx_test_country_effects.txt`; the existing pointer contract is in `common/scripted_triggers/biological_stockpile_safety_triggers.txt` and `common/scripted_effects/biological_stockpile_safety_effects.txt`. `docs/testing/chaosx_test_country.md` records the fixture behavior. CXT uses the existing biological facility model, project icons, and stockpile-monitor UI assets; no sprite, GFX alias, or player decision is added.
