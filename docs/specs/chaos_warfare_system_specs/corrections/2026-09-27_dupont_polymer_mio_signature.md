# DuPont protective-materials MIO signature

**Disposition: implemented in source; native MIO outcome and AI choice remain unverified.** The user's accepted 2026-09-20 MIO design requires six historically grounded national identities with distinct rewards and tradeoffs. The read-only national audit found that DuPont and ICI previously overrode the same durable-filter node for almost identical reliability and cost bonuses. This correction assigns DuPont a production signature in the existing protective-clothing branch, while ICI remains a filter-reliability specialist.

The [Science History Institute's Carothers history](https://www.sciencehistory.org/education/scientific-biographies/wallace-hume-carothers/) documents DuPont laboratory development of neoprene and nylon by 1930 and describes neoprene as a successful but expensive specialty rubber. [Its nylon production history](https://www.sciencehistory.org/stories/magazine/nylon-a-revolution-in-textiles/) dates a large dedicated nylon plant to 1938. These sources support a polymer-materials identity; they do not establish historical DuPont gas-mask or CBRN protective-clothing contracts. The protective application and numerical bonuses are explicit gameplay calibration, and the later tree node represents subsequent industrial scale rather than full 1936 mass nylon output.

`cbrn_dupont_organization` still inherits the same twelve-node Chemical Protection Works tree and remains available to USA. Its single national override moves from `cbrn_protection_durable_filter_canisters` to `cbrn_protection_protective_clothing_sets`. The override adds +18% production capacity to advanced protective equipment while retaining the inherited node's +8% equipment build cost and skin-protection completion effect. ICI's filter node gives +12% reliability with +4% build cost. The protected path therefore trades DuPont's production volume for ICI's higher durability; neither directly grants an army combat statistic or authorization to use CBRN weapons.

Source arithmetic for the fully unlocked advanced-mask path is DuPont +28% capacity from the +10% common foundation and +18% national node, with +28% reliability from common nodes; ICI gives +30% reliability on the same path. The inherited build-cost contributions are approximately +20% for DuPont and +21% for ICI when added as source modifiers, including the common -4% initial trait. These are source sums, not measured engine-effective production results. Showa Denko's separate +34% capacity path remains the larger dedicated source stack. No country or trait AI weights changed, so there is no weighted-score delta to compare; the existing MIO `ai_will_do` route has no supported probability adapter.
