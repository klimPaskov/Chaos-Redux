# Civilian field-kit allocation

**Disposition: implemented in source; consumer validation unresolved.** The user's 2026-09-20 CBRN overhaul requires automatic protection from real equipment, military priority, threatened-state civilian response, and no worldwide daily or weekly iteration. The parent applies those decisions to field decontamination equipment here. This note records the accepted implementation calibration; it is not a claim of engine validation.

Field Decontamination Kits research permits the existing decontamination equipment family to support both deployed forces and civilians. The military requirement remains one kit per four thousand deployed troops, rounded upward. Kits physically in divisions count first. Stockpiled kits cover any remaining military requirement before civilian availability is calculated. Stock above that reserve is one shared civilian pool; calculating coverage does not debit equipment.

A controlled state qualifies for civilian allocation with positive population and either an exact chemical-raid alert, real chemical contamination, or civilian masks already issued while its controller faces an enemy chemical capability. The last case prepositions cleanup for a credible threat so a prepared state has equipment-backed protection against a first strike. A clean state with no prior civilian issue does not dilute the pool. Each qualifying state's requirement is one kit per 100,000 residents, rounded upward as a gameplay calibration. The country's available pool is divided by the sum of qualified state requirements, capped at full coverage. Each state receives the same fraction of its own requirement. Institutional decontamination capacity scales that equipped fraction; without the research, kits, or a qualifying state threat, the civilian decontamination protection layer is zero.

The country-owned 30-day protection event refreshes the allocation, and an exact chemical action refreshes live stock before protection is resolved. Alert creation/clearance and state-control transfer refresh the affected country pools. No global periodic hook is added.

No new icon is required. The existing `GFX_decontamination_equipment_1_medium` sprite is registered in `interface/cbrn_protection.gfx:32` and reads `gfx/interface/technologies/stage_2_protective_equipment/equipment/decontamination_equipment_1.dds`; the existing Civil Defence category art remains its category identifier.

At a ten-kit military requirement with six kits already in divisions, stockpiles of four, nine, and fifteen kits leave zero, five, and eleven kits available for civilians respectively. If two threatened states require four and six kits, they receive zero and zero, two and three, or four and six kits. The last case retains one unused kit. Engine evaluation, current-state display, and rendered decision text remain validation work.
