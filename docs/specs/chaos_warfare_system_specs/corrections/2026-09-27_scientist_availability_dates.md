# CBRN scientist availability dates

**Disposition: implemented in source; historical and engine review remain open.** The user's accepted 2026-09-20 overhaul requires an individual review of all 67 CBRN scientists, date-appropriate availability, and a distinction between scientific competence and offensive program authorization. The 67-character source audit found six recruitment dates that preceded the specific wartime or administrative roles used in the existing roster rationale. This correction adjusts those six dates without changing their skill, expertise, portrait, technology, doctrine, or policy grants. The user confirmed on 2026-09-25 that all wired portraits already in the mod are approved.
