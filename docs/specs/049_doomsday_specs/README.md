# Event 049 Doomsday Specification Package

## Purpose

This package defines the complete planning handoff for Event 049, **Doomsday**, which replaces the unreworked catalog concept **Mass Panic**.

The event is a Major global crisis at Chaos level 4. It creates a dynamic predicted end date, a global belief crisis, country response systems, peace pressure, institutional withdrawal, two evolutions, a shared emergency focus branch for captured governments, a failed-date aftermath, and the public world-end route **The Final Vigil**.

The design keeps the player-facing mechanic within the accepted value budget. The player tracks only **Doomsday Conviction** and **Time Until the End**. Country belief, movement composition, organization, suppression backlash, institutional resilience, peace pressure, and terminal readiness remain hidden or appear as short qualitative statuses.

## Design boundaries

Doomsday administrations remain transformations of existing human countries. Their political identity uses event state, institutional leaders or councils where needed, national spirits, scripted localisation, a shared emergency focus branch, decisions, and Final Assembly membership.

Player interaction uses phased decisions, a compact status header, and a strong category picture. The asset scope is limited to the listed two-dimensional gameplay and presentation families.

The terminal route is public and event-owned. It follows the shared world-end contract, has its own Event Details row and persistent toggle, requires 1000 or more Chaos, and remains separate from the ordinary arrival of the predicted date.
