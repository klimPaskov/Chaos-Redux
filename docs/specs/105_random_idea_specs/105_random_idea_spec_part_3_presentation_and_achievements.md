# 105 Random Idea: presentation and achievements

## The result report

Use the ordinary Chaos Redux report surface for the human recipient's result.
Keep its premise short and concrete, with the sense that unrelated national conditions have appeared without a sensible reason.
The mechanical result belongs in the result tooltip and the normal national-spirit display.

The report should communicate three things at a glance: which evolution determined the bundle, how many direct draws resolved, and whether the fresh pool was exhausted.
It should provide the ordered native names of the public selected identities in its result detail, with a separate retained-status indication where that distinction matters.
The detailed list is optional reading, rather than sixteen full modifier descriptions placed in the report body.
Retention labels refer to the saved end-of-firing observation used by the Chaos settlement, not live ownership when an old report is later opened.
Later changes remain visible in the ordinary live national-spirit display and the next firing's burden refresh.

Use the selected ideas' existing localisation and existing icons when their ordinary visibility permits it.
Preserve native hidden presentation for hidden spirits.
They still count in selection, direct-draw records, and burden, but the ordinary report may group them by count rather than reveal internal IDs or secret text.
Do not invent an attractive public icon, name, or description to disguise a missing or hidden source asset.
If a public definition lacks a translated name, use the established unresolved-localisation treatment and reserve raw technical identifiers for diagnostics where possible.

A native self-removal or replacement does not become an Event 105 failure narrative.
The result detail should distinguish an assignment whose original identity is no longer present from an identity still held.
Do not announce that every selected modifier is active, permanent, or relevant to the recipient.

The acknowledgement performs no grants, rerolls, Chaos changes, or achievement claims.
A report left open must not block AI grants or another human country's resolution.
Each queued report must retain the firing context needed to show its own result, rather than reading the most recent global or country result and displaying it as an earlier firing.

The event itself creates at most one ordinary result report per human recipient per firing.
Notifications produced by a selected idea's own native behavior remain owned by that idea's system.

## Event history and details

The shared event history receives one normal Event 105 firing record.
It should describe a worldwide occurrence without falsely assigning the whole event to the country whose countdown happened to dispatch it.
Use the framework's explicit actorless state so a stale country target cannot appear as the actor.

Retain the stage and global outcome summary associated with that firing's history identity.
The entry may expose the original Chaos snapshot, recipient count, and aggregate direct-draw or retained counts through the established detail conventions where supported.
It must not show the latest firing's country results under an older row.
Detailed country receipts are retained for their pending reports and the framework's existing bounded history horizon, rather than creating a new unlimited world-by-country archive.
If older country detail is no longer retained, show only the genuine saved summary for that older firing.
Only per-firing presentation detail may expire here.
The compact historical set of exact direct-dispatch identities persists for burden and achievements under the established country-continuity and save-migration rules.

Event Details describes the premise: every country acquires unfamiliar national conditions drawn from the loaded game.
It does not paste effect syntax, list every modifier, disclose the registry implementation, or become a catalogue of all eligible ideas.
Evolution detail directions should distinguish double, triple, variable, and storm-sized assignments without promising useful or lasting effects.

The normal event type, stage names, help text, and result terminology must agree across the report, history, Event Details, evolution previews, and catalog mirror fields.
The finished localisation is written during implementation after the actual supported result presentation has been verified.
This specification supplies directions only.

## Writing directions by surface

| Surface | Required direction | Information to preserve |
| --- | --- | --- |
| Event title | Use the user-provided Random Idea identity consistently | Event 105 |
| Report description | A short account of arbitrary national conditions appearing throughout the world | No claim of deliberate reform, ideological alignment, or selected benefit |
| Acknowledgement | A concise reaction to the assigned result | No implied reroll, choice, or payment |
| Result tooltip | Compact ordered public identity names with draw and retention distinctions | Correct country and firing, exact whole-number counts, native hidden presentation |
| Exhaustion result | Explain that this country has no more fresh eligible identities in the available complete pool | Fewer draws are not a duplicate prize or a penalty |
| Event Details | Describe the premise and intended surprise | No effect list or implementation explanation |
| Evolution details | Explain the relevant change in quantity and, for Storm, existing-burden damping | Thresholds and total-count semantics |
| History summary | A global occurrence and its saved result summary | Actorless ownership and original firing context |
| Technical diagnostics | Exact identity, pool readiness, dispatch state, retained state, and loadout version | Clear distinction between observed result and unresolved engine behavior |
| Catalog mirror fields | Mirror the implemented public text in fields defined as mirrors | No independent paraphrase or invented implementation status |

Use plain, connected prose with familiar words.
Avoid bureaucratic filler, a stock paperwork scene, an elaborate explanation of randomness, em dashes, semicolons in prose, and staged comparisons with an alternative event.
The report does not need invented quotes, a named speaker, historical claims, or a long story to justify an absurd outcome.

## Achievement principles

These achievements reward playing through unusual national combinations.
Neither unlocks merely because Event 105 fires, because the player receives a specific lucky spirit, or because a report is acknowledged.
They use direct-draw identity history and normal campaign outcomes without changing the idea pool.

The two proposed achievements are ordinary visible entries in the existing achievement framework.
Their precise public wording and final keys are completed by the achievement and localisation owners after collision checks.
The working keys below are event-owned symbolic proposals, not newly allocated numeric shared IDs.

Both require normal achievement-eligible play according to the existing framework.
Debug firings, console-granted completion, a synthetic test loadout, or unsupported human-country switching cannot supply qualifying Event 105 receipts.
Reloading a legitimate save is allowed and must preserve progress.
Loaded compatible mods do not disqualify a run merely for adding valid national ideas.

### Achievement A: Improvised Victory

Working key: chaosx_105_improvised_victory.

**Title direction:** achieving a major military victory with a national identity assembled from unrelated parts.

**Description direction:** identify the starting-minor requirement, the existing burden threshold, the qualifying major enemy, the absence of a major ally, and the player-owned victory conditions.
The description should make clear that the random bundle is a condition of the challenge rather than a guaranteed military advantage.

| Field | Exact design |
| --- | --- |
| Eligible start | A human-controlled country that is independent and not a major at campaign initialization |
| Enrolment | After a legitimate Event 105 firing, the country currently holds at least six distinct identities in its direct-draw history and is already fighting at least one enemy that is currently a major |
| Target selection | Form enemy-major/war pairs across active wars that meet the no-other-major condition, choose the enemy with the most owned civilian plus military factory building levels, break an exact tie by verified stable country order, then by verified stable war order if the same enemy can appear in more than one qualifying war, and freeze both selected identities |
| War context | At enrolment, no other major fights on the player's side of that tracked war |
| Victory condition | Within 730 days of enrolment, the tracked enemy capitulates with this player country receiving the verified native capitulation credit |
| Player contribution | At capitulation, the player has at least 25% participation on its side of the tracked war using the verified native measure |
| National condition | At that moment, the player still holds at least six distinct prior direct-draw identities |
| Continuing requirements | Remain independent, remain the same tracked human country, never capitulate, and have no other major fighting on the player's side of the tracked war during the enrolled attempt |
| Attempt failure | Another major joins the player's side, an existing ally becomes a major, a verified war merge puts another major on that side, the target war ends without the qualifying victory, the target identity becomes unresolvable, the deadline passes, or a continuing requirement fails |
| Reattempt | A later legitimate Event 105 firing may enrol a new attempt if all initial conditions are met again |
| Visibility | Visible with understandable tracked requirements, using existing achievement presentation |
| Difficulty | Hard |

This requires a real war contribution and a major opponent's defeat while carrying an unusual national combination.
It prevents an ally's victory from being awarded to an uninvolved observer.
The achievement does not inspect whether the six ideas are helpful or harmful, since introducing that judgement would require a separate compatibility or power classifier.

Track the enrolled firing, country identity, enemy identity, war identity, enrolment date, deadline, and disqualifying conditions.
If native war membership makes the final same-enemy/multiple-war tie impossible, document that verified invariant instead of inventing a war-order API.
The factory comparison uses the same documented owned building-level measure specified for the industrial achievement, without dockyards or off-map capacity.
Use the framework's existing war and capitulation hooks where their semantics are proven.
The player's own promotion to major status is allowed after the qualifying minor start.
Major-ally disqualification includes both joining and promotion, and requires authoritative transition coverage.
A periodic snapshot alone cannot prove that no forbidden interval occurred.
An approximate occupation count or an arbitrary tag check cannot silently replace native participation or capitulation credit.
If those measures cannot be obtained exactly, the achievement remains an implementation blocker pending a revised accepted condition.

The military-star subject in the asset table belongs to this achievement.

### Achievement B: Strange Prosperity

Working key: chaosx_105_strange_prosperity.

**Title direction:** sustaining industrial progress under an increasingly unfamiliar national identity.

**Description direction:** explain the small-country start, qualifying Storm burden, original-state industrial growth, time window, and final stability without implying a new economic-management mechanic.

| Field | Exact design |
| --- | --- |
| Eligible start | A human-controlled independent country with no more than 20 civilian and military factory building levels combined in its owned states at campaign initialization |
| Enrolment | After a legitimate Idea Storm firing, currently hold at least eight distinct identities in the country's direct-draw history |
| Enrolment snapshot | Save the exact set of owned states and their combined civilian plus military factory building levels, F0 |
| Industrial target | Reach at least F0 + max(10, ceil(F0 / 2)) civilian plus military factory levels inside that same state set |
| Observation window | Meet the final conditions between 365 and 730 days after enrolment, inclusive |
| Territorial condition | At the successful checkpoint, own and control every state in the enrolment set |
| Political condition | At that checkpoint, have at least 70% stability and remain independent |
| National condition | At that checkpoint, currently hold at least eight distinct identities in the country's direct-draw history |
| Continuing requirements | Remain the same tracked human country and never capitulate or become a subject during the attempt |
| Attempt failure | The deadline passes, the tracked state set cannot be migrated faithfully, or a continuing requirement fails |
| Reattempt | A later legitimate Idea Storm firing may enrol a new attempt after the previous attempt ends |
| Visibility | Visible through the existing achievement framework |
| Difficulty | Hard, with a long campaign commitment |

Only factory levels inside the saved state set count toward growth.
Factories gained by annexing other states therefore cannot satisfy the target.
Normal construction, national focuses, and other legitimate effects inside the saved states may contribute, since all are part of ordinary campaign play.
Do not count dockyards, off-map factories, occupation-derived factory access, resource production, or temporary industrial modifiers as these building levels.

The checkpoint conditions are evaluated at the successful observation, not asserted continuously for a year.
This avoids pretending that a periodic check proves uninterrupted stability or continuous ownership.
The explicitly continuous independence and capitulation restrictions need authoritative lifecycle receipts.
Damage does not erase a constructed building level from the growth measure unless the engine actually removes that level, so the implementation must use the documented building-level measure rather than available production capacity.

Use the shared achievement scheduler and the saved enrolment state set for checks.
Do not create a new daily scan over all world states.
The state set and F0 remain fixed for an enrolled attempt, including across reloads.

The industrial-growth subject in the asset table belongs to this achievement.

## Achievement tracking boundaries

An enrolled attempt cannot overwrite its target, starting industry, deadline, or state set every time Event 105 fires.
Later legitimate firings can help the country meet the current burden requirement, but they cannot repeatedly reset an active attempt to an easier baseline.
Reattempts are explicit new attempts after a completed or failed earlier attempt.

Direct-draw history used by achievements has the same exact-identity semantics as Storm burden.
A count of visible icons is insufficient because hidden ideas remain eligible and distinct IDs can share an icon.
An accumulated count of every attempted grant is also insufficient because the final requirements demand ideas currently held.

Achievement completion adds no extra national idea, reroll, Event 105 Chaos, or event-owned management action.
It remains an achievement in the existing system.
Its final three-state icons and tracking receipts are separate required deliverables for implementation.
