Start with the [reading guide](132_secret_society_influence_reading_guide.md), which lists the reading order and the authority of each file.

The design, numerical tuning, achievements, presentation text and asset inventory in this folder are authored proposals.
Their existence does not establish user acceptance, implementation, runtime registration, localisation, art or validation.
The catalog status remains Unavailable until the parent completes the registry and workbook migration and an implementation is accepted.
