For each underlying failure, allow the initial request and at most one useful corrected or narrower retry. A new scenario name, agent, file or resumed turn does not reset that budget. Skip a retry where the service is known unavailable. Then inspect relevant local references and actual source, calculate representative cases and continue implementation. Record the limitation once with what new evidence would justify another attempt. Confirmed defects still need fixing and a focused recheck.

Use direct source cases for exact-cost equality, native reservation at paid entry, depleted reserves after payment, receipt replay, neutral cancellation, chapter-cap race, saturated-case recovery, verified historical cessation, civil-system retirement and duplicate callbacks. Keep source-model outputs separate from native observations. Inspect source or transaction state before retrying an uncertain write. Broaden validation only for an actual remaining risk, and request logs or a debug playtest only when that work is explicitly invoked.
