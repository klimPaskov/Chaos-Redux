# Event 010 Death Planning Package

This package is the source planning handoff for Event ID 10, `Death`. It replaces the obsolete `Spirit of War/Peace` event entirely.

## Main spec files

- `specs/010_death_spec_part_1_core_flow.md` — event identity, replacement mandate, origin, stages, reveal, world-end, event-log role.
- `specs/010_death_spec_part_2_mechanics.md` — variables, consumption effect, wasteland rules, spread, withering, coastal jumps, defeat, ghosts, evolutions, scenario.
- `specs/010_death_country_package_and_focus_tree.md` — Death country package, Zol, units, fixed-purpose focus/progression tree, Herald route.
- `specs/010_death_decisions_ui_ai.md` — decisions, missions, Living Compact, Dark Methods, Black Oath, Black Atlas UI, AI behavior.
- `specs/010_death_assets_super_events_achievements.md` — visual assets, super-events, achievements, catalog row direction, acceptance criteria.
