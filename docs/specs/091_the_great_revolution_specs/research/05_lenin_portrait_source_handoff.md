## Five dynamic stages for ordinary joined leaders

The five required visual stages are a subtle forehead anomaly, a closed line, a partially open eye, a bright open eye, and a fully transformed appearance that retains the leader's recognizable identity. These correspond to Influence stages 20, 40, 60, 80, and 100. They are separate from Lenin's own baseline power presentation.

Create five transparent overlay masters with proposed stage suffixes 01 through 05. Do not include the face or head in an overlay source. The nominal portrait canvas is 156 by 210, subject to the actual consumer. A verified face-relative anchor, placement metadata, or another complete supported method must accommodate the current leader rather than a roster of a few famous figures.

Politics and Diplomacy are separate acceptance surfaces. Each needs its own verified binding, placement, scale, crop, layer order, click-through behavior, stage selection, and fallback. A successful Politics screenshot does not prove Diplomacy works. Leader replacement must update the current target without inheriting another character's cached image or dropping a still-active institutional stage.

The overlay container should not intercept political or diplomatic controls. It should remain valid across supported resolution and UI-scale settings. The implementation owner must prove the current portrait pipeline can select and display overlays for all eligible current leaders. An unsupported dynamic consumer is a blocker requiring parent resolution, not permission to ship a partial famous-leader list.

Animation uses actual changing eye, lid, and local tissue frames under the frame-animation workflow. Each stage has a readable static fallback with the same meaning. No animation, source crop, or final DDS exists in this package.
