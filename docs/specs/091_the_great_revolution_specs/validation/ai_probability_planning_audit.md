## Classification used in this report

- **Specified, unmeasured** means the planning file defines a formula or rule without a tool-verified outcome.
- **Score-only** means the value ranks or expresses AI willingness and is not a click probability unless the native adapter proves it.
- **Timing-only** means a deadline, cooldown, cadence or due date, not a random selection distribution.
- **Unresolved** means an adapter, live pool, external input, game rule or measurable result is unavailable.
- **Exact, bounded or sampled result** would describe native analysis output, and none exists.

The reviewed 091 formulas introduce no MTTH surface.
The inherited 001 progression, cooldown and incident cadence are timing inputs that need their native source and callback context.
