## Classification used in this report

- **Specified, unmeasured** means the planning file defines a formula or rule. It does not mean a tool verified the outcome.
- **Score-only** means the value ranks or expresses AI willingness. It is not a click probability unless the actual native adapter proves a probability interpretation.
- **Timing-only** means a deadline, cooldown, cadence, or due date. It is not a random selection distribution.
- **Unresolved** means an adapter, live pool, external input, game rule, or measurable result is unavailable.
- **Exact, bounded, or sampled result** would describe native analysis output. This audit produced none of those result classes.

The reviewed Event 091 planning formulas do not introduce an MTTH surface. The existing 001 scheduled progression, cooldown, and incident cadence remain inherited timing inputs that need their native source and callback context. They are not treated as MTTH results here.
