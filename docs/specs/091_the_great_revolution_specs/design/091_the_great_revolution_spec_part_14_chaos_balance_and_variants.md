# 14. Chaos, balance, and campaign variants

## What Chaos records

Chaos changes follow concrete outcomes. Evolution activation, a stored-weight increase, a displayed popup, a selected focus, and a repeated threshold inspection do not create Chaos by themselves. The event uses one-time outcome receipts and calls the shared Chaos owner for each accepted change.

Generic wars, annexations, subjects, factions, ideology changes, deaths, world tension, nuclear use, and contamination already have shared effects. Event 091's premiums represent the specific supernatural shock, new global reach, political incorporation, or dismantling of the extraordinary system. The implementation must give each premium its own reason rather than count the generic fact twice under a different label.

## Initial tuning map

All values are planning targets based on the user's scale. They require full-pool selection review and later campaign observation. These numbers are not runtime balance results.

| Concrete outcome | Event-specific Chaos change | Receipt and ownership |
| --- | ---: | --- |
| Lenin and the nonhuman host first appear | +20 | One campaign-wide manifestation receipt after opening commit |
| Opening revolutionary territory first exists on an inhabited continent | +5 per continent, maximum +25 | One receipt per continent within the opening, the sixth continent remains a fact but adds no extra premium |
| First communist major joins | +10 | One campaign-wide ideological alignment shock, separate from generic faction or war effects |
| First communist major refuses and enters ideological war | +5 | One campaign-wide refusal shock, separate from ordinary war creation |
| First ordinary joiner develops a visible third eye | +5 | One campaign-wide confirmed public transformation, not every portrait-stage redraw |
| First joined major becomes Lenin's subject through the influence route | +10 | One campaign-wide supernatural loss-of-sovereignty premium |
| First joined major is annexed through Influence | +15 | One campaign-wide abnormal incorporation premium, generic annexation remains shared |
| Inhabited rule reaches 10 percent | +10 | First crossing only, no regain farming |
| Inhabited rule reaches 25 percent | +20 | First crossing only |
| Inhabited rule reaches 50 percent | +40 | First crossing only, Red World still requires strictly more than half |
| A major ordinary joiner declares independence | -5 | First qualifying independence per major supporter |
| A continental command is permanently destroyed | -5 | Once per command identity, never a temporary disable |
| Lenin's body and all required survival systems are defeated | -50 | One final defeat receipt |
| A bound major is fully restored after defeat | -10 | One restoration receipt per major, separate from generic release or ideology changes |

Momentum threshold crossings, finite reinforcement delivery, a focus completion and failed containment have no additional Event 091 premium unless they actually produce a distinct listed outcome above. Their real wars, casualties, territorial incorporation and other generic consequences continue through the appropriate shared owners. This explicit zero-extra-premium rule prevents broad implementation labels from inventing another growth award.

The proposed choices within the user's ranges are -5 per permanently destroyed command and -50 for final defeat. This uses clear multiples of five. A minor command disable, an ordinary battle victory, or a temporary retreat does not receive those final-resolution premiums.

## Cascading thresholds

An event outcome can legitimately raise Chaos across another threshold. Apply each eligible premium once in a bounded deterministic order, then re-evaluate the current state. For example, reaching the 50 percent rule milestone can add 40 Chaos and leave the world above 1000. Red World can then become eligible only if its strictly-more-than-half rule condition, active Lenin and country, scenario setting, and terminal-state checks also pass.

At exactly 50 percent, the milestone can fire but Red World cannot. At exactly 1000 Chaos, Red World cannot. A threshold premium is never awarded merely because a preview calculation says it would occur. If the underlying territorial or political transaction aborts, the premium does not commit.

Defeat premiums must not erase another active world threat. The 091 source flag is cleared and the shared aggregate is refreshed. The global threat remains active if zombies, the Holy Realm, another scientist, or another registered source still requires it.

## Balance levers and player consequences

| Lever | What it should control | What it must not replace |
| --- | --- | --- |
| Communist popularity | The uncapped proportional country selection target, subject to inherited-state and overlap rules | A fixed minimum or maximum number of states |
| State levels and rebel history | Preparation quality, depot value, family mix, and readiness | A second unrelated opening state roll |
| Whispers | Preparation, aggressive local organizing, and stored selection weight | Direct event firing or unlimited divisions |
| Host strength | Scale of possible defection, equipment sources, and local military challenge | Invented stocks or duplicated transferred armies |
| Supply and connectivity | Whether the revolutionary map can become an operational army | A cosmetic penalty erased by supernatural coordination |
| Influence | Ordinary joiner access, dependence, and sovereignty struggle | Trotsky's autonomy or every government's politics |
| Momentum | Current strategic power, reinforcement opportunities, coordination, and survival capacity | A public ledger of many component currencies |
| Occupation and institutions | Whether captured areas become productive and politically secure | Free global cores or immediate full compliance |
| Counterplay | Liberation, exposed anchors, independent commands, cures, and supply disruption | One-button victory or a guaranteed unwinnable opening |

Early strength should come from prepared regions and real military mass. If the campaign repeatedly produces fragile isolated one-division revolts, tune regional grouping, deployment readiness, inherited formations, and finite seed distribution. Do not add a blanket per-state elite spawn. If the opening is predetermined by free armies, reduce unsourced manifestations, immediate deployable shares, or preparation multipliers while preserving the proportional territory rule.

Ordinary joiners need a viable positive story. Aid should solve actual shortages and enable operations. If they accept only because refusal is impossible, improve the delivered benefits and role-specific objectives. If joining is always optimal and costs nothing, make institutional access and dependency consequences clearer. Independence must remain mechanically available even when an unprepared country is likely to lose its war.

## Validation philosophy

Arithmetic examples establish the interpretation of formulas. They do not establish game balance, native AI probability, or engine compatibility. Static review verifies names, ownership, bounds, complete paths, and stale-callback behavior. The HOI4 tools, when available in the implementation environment, inspect the actual full lifecycle and complete probability contexts. Later controlled gameplay verifies the playable experience.

Do not launch the game or request log files as part of this planning task. The implementation handoff supplies a concrete validation matrix, including source revision, installed content, scenario state, expected result, and evidence to capture. A future unsupported feature must remain visibly open until it is resolved or the user approves a specific redesign.
