## Cluster notes

The uploaded cluster catalog contains Natural Disasters and Natural Disasters 2 draft rows with missing IDs. A later workbook search result showed a stronger cluster entry where Natural Disasters contains Event 013 as its only current member. This package follows the user brief and uses Event 013 as the only member. Higher chaos makes the same event appear more often and with stronger internal sequence members instead of pulling in separate flood, heat, sandstorm, or earthquake events.

## Scenario notes

The uploaded scenario catalog contains SCN-007 Disaster Barrage. This package preserves the manual scenario idea: it launches Event 013 directly, bypasses ordinary prerequisites only for the manual launch, uses selected type and intensity controls, and never creates a terminal world-end branch.
