## Important availability limits

The actual Chaos Redux repository, the offline `paradox_wiki/` snapshot, vanilla Hearts of Iron IV files, and the Codex project subagent execution tool were not available in this chat environment. The package therefore uses the uploaded project files, uploaded catalogs, and external public research as planning input. It does not claim live repository inspection, in-game validation, implementation, asset generation, audio sourcing, or actual subagent runs.

The package is written as source specifications and handoff prompts. It avoids preserving any deleted Natural Disasters implementation and treats Event 013 as a fresh system design.
