# Localisation Prompt for Event 013 Natural Disasters

Use `chaosx_localisation_auditor` after implementation. This prompt is direction only and must not be pasted as final text.

## Required text surfaces

- Event 013 name and Event Details text.
- Evolution I, II, and III detail text.
- Event Log name and debug name selectors.
- Baseline reports by family or by family group.
- Evolution II global digest reports.
- Evolution III abnormal report and super-event handoff keys.
- Disaster Response and Reconstruction category name and description.
- Decision and mission names, descriptions, cost text, blocked requirement text, success or failure text where visible.
- Scripted GUI labels for active season, affected states, threatened states, delayed deaths risk, recovery phase, and storm corridor predictions.
- Dynamic area, state, country, family, severity, and recovery phase scripted localisation.
- Scenario UI text for Disaster Barrage type and intensity options.
- Cluster detail text for Natural Disasters cluster members.
- Achievement names and descriptions after final wording is written.

## Style direction

- Identify affected areas clearly.
- Describe visible consequences and recovery choices.
- Avoid listing hidden values in Event Details.
- Avoid update-history wording such as reworked or newly added.
- Avoid final super-event quotes, remarks, slogans, or allusions until research is complete.
- Avoid cheap humor for mass death.
- Avoid repeating the same report structure for every disaster family.

## Dynamic placeholders

Final localisation should use dynamic placeholders for:

- affected state name
- affected country name
- affected region name when state is not enough
- disaster family name
- recovery phase
- delayed risk band
- storm corridor next target
- tsunami arrival band
- highest active aftermath severity

Use integer formatting for counts and rounded values where appropriate.
