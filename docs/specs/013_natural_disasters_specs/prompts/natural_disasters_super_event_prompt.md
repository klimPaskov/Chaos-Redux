## Research requirements

For each selected super-event, find a real quote, verify wording and attribution, document source and confidence, and keep quote length suitable for the UI. Find a short cultural remark or button direction only after source checking. Do not invent quotes, slogans, lyric fragments, or allusions.

For audio, find public domain or clearly licensed music. Do not use generated tones, drones, oscillator music, default tracks, undocumented legacy audio, or unclear YouTube uploads. Preserve source files and provide final `.ogg` handoff only if licensing is clear.

For image direction, coordinate with the asset prompt. These are generated, fictional, high-chaos disaster images unless the parent later requests sourced real imagery.
