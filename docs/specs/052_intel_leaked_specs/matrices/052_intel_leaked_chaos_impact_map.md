## Anti-farming proof requirements

- Each source has a dedicated consumed proof.
- Manifestation proof is sequence-owned.
- Severe personnel proof is target-owned.
- Deep tranche proof is sequence-owned.
- Added-target Chaos uses the exact number of newly initialized target states.
- Severe single Total Compromise uses a mutually exclusive manifestation route.
- Recovery proof requires active containment before the natural deadline.
- Evolution logging and evolution state changes never call the Chaos source path.
- Decision clicks do not change Chaos unless a later concrete outcome satisfies a mapped row.
- Invalid-target cleanup cannot call manifestation or recovery again.
- External event hooks cannot write Event 52 Chaos directly unless the Event 52 owner accepts a proof-carrying result.
