## Event 52 public helper contract direction

The Event 52 owner should expose read-only facts and bounded request effects instead of allowing other events to read private arrays.

Useful read-only facts:

- country is an active target
- qualitative Exposure stage
- one or more archive domain classes are active
- country is a named exploiter against a target
- deception is active for a target-recipient pair
- sequence already consumed an external hook from the requesting system

Useful bounded requests:

- add or remove a small proved Exposure amount
- add a named exploiter candidate under the normal cap
- adjust one recipient's Reliance within bounds
- register a cooperative ally copy
- record a domain-specific contradiction

Each request should return success or rejection state and should clear one-shot inputs.
