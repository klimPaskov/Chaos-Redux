## Anti-bloat decisions

### No second public crisis meter

Officer loyalty, security reach, industry reach, regional support, and counterweights remain hidden. They affect Influence, removal, revolt setup, and qualitative tooltips.

### No full-screen crisis window

The event uses an ordinary decision category with a compact attached display. A larger window would add layout and maintenance cost without improving the one-value decision loop.

### No custom unit family

The Generalissimo commands existing armies. The event does not need new equipment, counters, audio, or 3D models.

### No fixed junta tag

A dynamic civil-war country preserves host identity and avoids a tag collision burden. A fixed tag remains blocked unless engine evidence proves it necessary.

### No ideology quota

The three political structures reflect forms of military rule. The tree does not add shallow communist, democratic, fascist, and non-aligned routes.

### No animated asset requirement

Static progression pictures, meter states, and route emblems communicate state clearly. Animation would add maintenance without enough gameplay value.

### No third super-event

The ruler transformation and world-end launch justify super-events. The civil-war start uses normal event and news presentation.

### No Generalissimo clones during world end

Other countries promote existing commanders or councils. The original character remains unique.
