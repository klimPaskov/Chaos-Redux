# Doctor Wu: shared owners and consequences

## One medical portfolio inside the existing world

Doctor Wu's institution studies and treats biological conditions through the systems that own them. It does not create a second population ledger, a parallel native raid transaction, a replacement famine system, or a second copy of another event's country. This part defines the final integration contract for the complete design.

The interfaces described below are proposed contracts unless the final source register identifies an existing verified helper. Their names describe responsibilities and are not claims that a generic API already exists. Parts 1–12 remain unchanged. This part completes event-wide attribution and handoff without silently rewriting their design.

## Compatibility and knowledge

A disease owner supplies a stable condition identity, current version, eligible living recipients, specimen or clinical-access requirements, valid diagnostic and treatment outcomes, outbreak stage, existing treatment compatibility, and the limits of its non-biological component. A weapon or organism owner additionally supplies the allowed fictional profile choices, actual stock identity, control and care requirements, and supported use routes.

The Wu owner records what the institute knows and which projects are qualified. The source owner decides what a treatment does to its condition. A foreign licence can copy an allowed knowledge object. It cannot automatically transfer specimens, people, physical output, manufacturing qualification, or a command relationship.

Every new compatible disease must have a possible treatment route while a qualified Wu and viable institute remain available. Missing current evidence can make a particular route unavailable. It cannot permanently classify a biological disease as impossible merely because it was added after Event 089. The integration contract must allow the disease owner to register a later version and supply an alternative clinical or specimen route.

Independent early discovery creates only the compatible capability. It does not set another event's fired flag, claim its story reward, create its character, or launch its manual scenario. If the normal source event later fires, its story still occurs and its capability grant is idempotently reconciled with the existing knowledge. Actual new material or people are granted only when that source's real outcome supplies them.

## Preserved decisions D01–D04

### D01. Legacy Event 089

The old technology-sharing chain, memberships, rewards, Kruger acceptance and refusal callbacks, and already queued meanings remain protected. A new Wu appointment cannot reinterpret a sharing choice. A completed legacy Event 089 does not receive a second fire-once reward simply because the new design now uses the catalogue number.

The implementation must distinguish legacy and medical request generations before any new entry commits. Old callbacks retain their original semantics. New medical callbacks require an exact medical request identity and never use the absence of a legacy flag as proof of a new request. The architect must inspect queued-event and save behavior before choosing final event identifiers and dispatcher wiring.

Where the engine cannot prove the origin of an old queued callback, that callback must remain on its legacy path. Medical migration is then an explicit versioned handoff, not an automatic interpretation of unknown saved context. Fresh-campaign registration and legacy-save migration are separate acceptance cases. This is a proposed migration contract, not a claim that the current source already implements it.

### D03. Finite medical-replacement cohorts

D03 remains an unapproved extension within the shared clone owner. It must be approved and implemented as a causally separate finite mode. Legacy Kruger, Mengele, and neutral CBRN clone consumers retain their existing behavior. Legacy recurring-income equipment is never issued as a substitute for a finite person.

For a finite created population N, let U be people not yet first-settled, S the historical number first-settled, and D the historical deaths before first settlement. The invariant is N = U + S + D. First settlement decrements U and credits exactly one accepted destination: civilian population, ordinary military manpower, or a recorded formation. Specialist qualification uses already counted people. Later death does not restore U.

Civilian settlement can later participate in ordinary national demographic and conscription systems. That is distinct from directly crediting both civilian population and military manpower in the first-settlement transaction. Native side effects must be inspected and reconciled so that the first grant does not duplicate the same people.

A transfer changes custody or the holder of an existing settled population or formation. It does not reopen the finite entitlement. Unknown custody blocks additional settlement of the disputed amount without declaring a death. Hidden batches, continuity copies, capture, exile, and new country formation all preserve the same accounting.

### D04. Native biological operations

Actual equipment is authoritative. Native creation, reservation, Command Power, cancellation, outcome, and history remain with the native operation owner. Wu supplies a qualified compatible capability and exact fixed profile where supported. It adds no second payload balance, staging directive, production decision debit, or scripted refund.

The prior source review found that the strategic-raid guide and final resolver disagreed about staging and partial refunds. The inspected resolver used an internal handling state and full completed-reservation accounting. That is inherited source evidence, not a claim that every current native cancellation path has been tested. Implementation must check the current owner before changing it.

A change in production standard, office, institution, or country cannot alter material already manufactured or reserved. A standard-specific operation must retain the correct material identity throughout preparation and resolution. If the native interface cannot distinguish that stock, the required extension is blocked until the owner provides the distinction. Ordinary material with a mutable country-wide profile is not an acceptable substitute.

## Four evolutions and settings

The evolution positions are 200, 400, 600, and 800 Chaos. Each has contextual pacing, an active-chain incident, an evolved-opening context, disabled continuity, and later baseline inheritance in Parts 12–15. Eligibility, activation, logging, and stage reconciliation give zero Chaos.

Only one pending delivery exists for a position and responsible institutional context. Changing host, adding a qualified copy, crossing the threshold repeatedly, reloading, or re-enabling cannot create duplicate delivery. An earlier disabled position is skipped without a false occurrence or date. A delivered position retains its actual history even if its extra behavior is later disabled.

N-D11 remains an explicit unapproved proposal: a never-delivered earlier position already bypassed by a later committed milestone stays bypassed for that campaign. Final implementation cannot silently treat this package as approval of that shared-settings policy. The implementation owner must record acceptance or a clearly documented correction before changing the behavior. Baseline research and ordinary institutional development remain available under either settings disposition.

For an evolved opening, the highest genuinely supported enabled context shapes the initial incident. Lower enabled contexts contribute their actual institutional facts without a cascade of free rewards. No advanced project is seeded. A higher Chaos number cannot substitute for the material facts required by that opening.

## Medical effects and overlapping recipients

A treatment request names its disease version, eligible current living recipients, compatible method, available material, qualified service, route, and clinical interval. The disease owner returns the accepted result. Only that result changes the disease, outbreak, recruitment support, or mortality risk.

Coverage uses the unique union of recipients for the selected purpose and interval. Two hospitals serving the same people do not add two populations. An army's service count is included only where those people are eligible for that purpose and are not already counted in the civilian service union. Unknown overlap cannot be reported as an exact national total.

Material limits, current route, provider capacity, reception, and food safety cap actual supplied reach. A qualified design alone is not coverage. Part 12's proposed 25 percent coordination reduction applies only to a separately supported administrative interval, never to research, manufacture, travel, clinical treatment, or qualification.

Field-hospital and other existing medical commitments retain their exact provider and episode. Closing Wu's service cannot release another provider's capacity. Reorganization cannot charge a team twice or free a team that remains assigned elsewhere. The previously noted quarantine cost issue requires an exact owner quote before its action is admitted to automatic delegation. A wrapper cannot conceal additional spendable resources beyond the four-type limit.

## Event-wide Chaos impact

This is the proposed final consequence map. New amounts are tuning proposals and do not imply approval or measured balance. The event's catalogue Chaos level remains 1. Shared baseline firing, wars, annexations, deaths, and contamination use their existing owners and are never paid again by this map.

| Outcome | Proposed Wu-owned impact | Trigger and anti-farming rule |
| --- | ---: | --- |
| Initial arrival and bounded demonstration | No additional Wu-owned anomaly payment beyond the configured ordinary event result | One fire-once incident. Refusal and referral do not repeat the reward. |
| Real contained disease episode reversed | Up to −5 | Owner-confirmed active episode and living-patient result. No reward for a staged demonstration or deliberately manufactured farming episode. |
| Real national epidemic reversed | Up to −10 total for that episode | This replaces the smaller Wu relief entitlement for the same episode rather than adding a second full payment. |
| Material global reversal of one disease episode | Up to −20 total for that episode | Requires actual multi-country results and owner proof. Earlier Wu relief for the episode is subtracted from the remaining entitlement. |
| First qualified hazardous modified capability | +5 once for the family | A genuinely completed new capability with actual qualification. Renaming, retooling, production, and transfer cannot repeat it. |
| First permanent enhanced-human programme | +5 once | Actual recipients complete the first qualified alteration. No reward at proposal, approval, or evolution. |
| First controlled engineered-zombie family | +5 once across the initial controlled-lineage milestone | Actual qualified and supported field capability. Not one reward for every batch or five rewards for superficial variants. |
| First living finite human replication | +5 once | Actual separately living person under finite accounting. Archive copying and replacement tissue do not count. |
| An escaped force becomes a distinct continuing threat | Up to +5 once for a new threat episode | Needs actual independent threat capability not already represented by the same source's registered consequence. |
| That distinct threat is durably contained | At most the recorded Wu threat contribution | Owner-proven end to the active threat. Repeated capture and release cannot farm reductions. |
| Sovereign demand, charter, appointment, or research proposal | 0 | These alter authority or planning, not global Chaos by themselves. |
| War, annexation, fatalities, biological use, or footprint change | Shared owner only | Wu adds no duplicate change for the same physical consequence. |
| Any evolution activation or reconciliation | 0 | Applies to all four stages, evolved openings, toggles, and qualified copies. |

Episode relief is a bounded cumulative entitlement. If five points were already paid for a local result and the same episode later qualifies for ten, only five additional points remain. A subsequent twenty-point global qualification adds at most ten. A source owner that already pays the same reversal takes precedence, leaving no duplicate Wu payment. Normal atmospheric recovery and death accounting remain their own unrelated measured changes.

The hard anti-farming exclusions include user-debug setup, intentionally repeated release and cure by the same responsible programme, renamed source versions with no new episode, split shipments, moved clinics, transferred copies, and repeated country formation. A genuine new naturally occurring episode can qualify if the disease owner proves it. A hidden harmful origin can be reconciled when discovered without deleting historical acts or inventing an unexplained positive penalty.

## Save, transfer, and multiplayer behavior

Pending cases retain an exact actor, target, object, generation, accepted quote, and current phase. A delayed popup can commit only the matching unconsumed response. An old response cannot select whichever newer contract happens to be active. A repeated click or loaded save cannot pay or grant twice.

Authority belongs to actual conceded rights in the relevant host. Knowledge belongs to its lawful holders. People have individual custody and appointments. A shared council cannot count the same team or stock twice. Parallel foreign contracts reserve independently and must compete for the same underlying available resources.

Annexation, civil-war settlement, and tag reuse require generation-aware cleanup. Real history is retained, matching live requests are settled, and unrelated owners' obligations remain untouched. A newly released country using an old carrier must not inherit stale appointment offers or material claims from an earlier generation.

Multiplayer uses the same owner transactions as AI and single-player. Simultaneous acceptances are serialized at the authoritative resource boundary. Two clients can see an offer, but only an unconsumed valid lot can be awarded. A losing concurrent action receives a reason and no debit. Local UI selection cannot become shared gameplay state.

## What implementation must prove

The complete design requires exact finite people, fixed stock, qualified staff reservations, medical recipient unions, versioned foreign and evolution cases, source-owned consequences, safe country and formation transfer, and legacy-save migration. These are concrete acceptance contracts. Source-only planning does not prove the engine supports every required transaction.

The final execution map assigns each unresolved seam to its owner and names the scenarios that must pass. The package's local tests check the stated arithmetic and document relationships only. No live engine, native cancellation, probability adapter, or shared-owner implementation is claimed here.
