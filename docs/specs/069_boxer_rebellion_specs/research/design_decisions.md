# Design authority and proposed choices

## Authority

The [original brief](user_brief.md) records the user's requested concept.
The user authorized thorough expansion, which supports proposing concrete gameplay around that concept.
It does not establish approval of every new balance value, route, asset requirement, or technical compromise in this package.
All additions remain proposed source design until adopted within the implementation task's authority.
Implementation evidence and design acceptance must be recorded separately.

## Preserved requirements

The catalog classification, both cluster memberships, flexible Chinese political map, independent Boxer movement, three government responses, interest-based foreign participation, dynamic intervention, competing settlement goals, all three named evolutions, lasting Boxer political content, occupation backlash, named connections, and major news opening are retained.
The source event is a single fire-once occurrence regardless of how many countries take part.

## Main proposed expansions

| Decision | Reason and scope |
| --- | --- |
| Add Intervention Pressure alongside Boxer Strength | Gives foreign crisis management a distinct visible signal without adding a large set of player meters |
| Keep local conditions qualitative | Avoids making regional organization, ritual practice, debt, and coalition disputes into additional persistent custom counters |
| Treat intervention as an event-owned agreement | Preserves existing factions and allows participants with different mandates. Actual shared-war and peace behavior still requires verification |
| Preserve independent Chinese government stances | Allows a fragmented China to react without assuming CHI controls all institutions and territory |
| Use a dedicated state only when territorial institutions justify it | Prevents a small local protest from receiving a free national army or overriding an existing country |
| Build three political routes | Local federation, central military command, and religious government offer different institutions and costs |
| Keep modernization open across political routes | Avoids making conventional weapons exclusive to one ideology or forcing religious government into a supernatural route |
| Give Evolution II three bounded schools | Distinguishes morale, concealment, and protection while preserving supply, casualties, and counterplay |
| Separate coalition goals and settlement terms | Rescue, suppression, withdrawal, occupation, and privileges need different proof and different cleanup |
| Limit repayments and use explicit treaty records | Makes obligations meaningful without unlimited debt or repeated collection of the same settlement |
| Allow one coordinated aftermath resurgence | Preserves occupation backlash without re-firing the source event or resetting rewards and resources |
| Use ordinary decision-category presentation | Two values, selected targets, and phased actions do not currently justify a full custom window |
| Reuse existing unit building blocks | The ordinary movement is represented by troops the engine already supports. A future custom subunit or model would need its own adopted requirement |
| Add four manual scenario types and twelve achievement designs | Supports replay and difficult natural-campaign goals while keeping manual setup out of achievement credit |
| Do not add a world-end branch | The user brief supports a continuing political and military crisis. Ordinary Boxer victory is not a terminal world condition |

## Deliberate planning boundaries

Focuses are specified at path and branch level, following the planning skill.
The final node count, prerequisites, layout, and names depend on the implementation and its reviewed consumers.
This does not permit removing any required route, decision family, institution, or payoff.

`BOXER_CARRIER` is a semantic placeholder, not a usable three-character country tag.
Geographical names are binding directions, not a substitute for the installed state manifest.
Unverified engine features remain blocked facts to resolve, not permission to claim a weaker behavior under the same label.

Balance numbers are proposed initial targets.
The package's AI and acceptance tables describe intended outcomes and do not report executed tests.
A later approved balance change must preserve meaningful choices, costs, ownership conservation, and the public value budget.
