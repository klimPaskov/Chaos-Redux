# First Asset Pilot Checklist

## Before paid work

- [ ] Tranche 0 local vanilla and exporter review is complete.
- [ ] Profile has calibrated numeric ranges.
- [ ] Dependency lock is approved.
- [ ] Environment report has no blocker or major finding.
- [ ] Meshy balance is known.
- [ ] Job schema passes.
- [ ] Reference preflight passes.
- [ ] Credit hard limit is approved.

## Generation

- [ ] Task ID recorded.
- [ ] Actual request schema archived and redacted.
- [ ] Successful outputs downloaded immediately.
- [ ] SHA256 and size recorded.
- [ ] Multi-view candidate review completed.
- [ ] Candidate decision recorded.

## Blender

- [ ] Clean isolated profile used.
- [ ] Provider source collection protected.
- [ ] Vanilla reference imported read-only.
- [ ] Orientation, scale, origin, and ground rule recorded.
- [ ] Geometry report passes.
- [ ] Materials report passes.
- [ ] Rig and action reports pass when required.
- [ ] Checkpoints exist.

## Export and runtime

- [ ] `io_pdx_mesh` version and hash recorded.
- [ ] `.mesh` exists and opens or parses as expected.
- [ ] Every required `.anim` exists.
- [ ] Export log reviewed.
- [ ] Runtime handoff is complete.
- [ ] Parent wired exact identifiers.
- [ ] Crosswalk has no missing accepted row.
- [ ] In-game scale, materials, orientation, and actions pass.
- [ ] Performance test matches expected instance density.

## Close

- [ ] Credits reconciled.
- [ ] No remote-only artifact remains.
- [ ] No secret appears in the package.
- [ ] Manifest status is accurate.
- [ ] No fallback or simplification was hidden.
