# Reference Image Preflight

Use this checklist on the final single image that will be sent to Meshy. The image may be user-supplied or autonomously generated by the workflow from the asset brief.

Hard rules:
- Meshy receives exactly one final reference image
- do not use a multi-view sheet, turnaround board, or separate side-profile images
- if `MESHY_API_KEY` is missing, stop before this checklist and instruct the user to set it as an environment variable

## Source and rights

- [ ] Exactly one subject is intended.
- [ ] Source mode is recorded.
- [ ] Provenance is recorded.
- [ ] License or user authorization is recorded.
- [ ] Original file is preserved.
- [ ] Original SHA256 is recorded.

## Composition

- [ ] Complete subject is visible.
- [ ] No required limb, barrel, wing, mast, wheel, tail, or roofline is cropped.
- [ ] Silhouette is readable.
- [ ] A workflow-generated reference has genuine native transparency and preserved alpha.
- [ ] An inherited, sourced, or user-provided opaque reference has a background simple enough to separate, or a documented fallback removal was validated.
- [ ] Transparent edges contain no halo, matte, fake checkerboard, clipped detail, or cast-shadow remnant.
- [ ] Cast shadow does not look like geometry.
- [ ] Subject is not heavily foreshortened.
- [ ] The image is large enough to inspect component edges.

## Geometry risk

- [ ] Dark regions that could become holes are identified.
- [ ] Overlapping limbs or components are identified.
- [ ] Thin structures are identified.
- [ ] Painted details that could become geometry are identified.
- [ ] Symmetry or intended asymmetry is documented.
- [ ] Unseen rear-side expectations are documented.
- [ ] Open cavities and hollow structures are documented.

## Texture risk

- [ ] Baked lighting is identified.
- [ ] Reflections and transparent parts are identified.
- [ ] Readable text or insignia is handled deliberately.
- [ ] Modern or incorrect details that must not survive are listed.

## Outcome

Choose one:

- [ ] `approved_original`
- [ ] `approved_derived`
- [ ] `needs_user_review`
- [ ] `blocked`
