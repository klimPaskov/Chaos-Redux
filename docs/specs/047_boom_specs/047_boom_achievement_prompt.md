# Event 47 BOOM achievement decision

Do not create an Event 47 achievement unless the user later approves a player-controlled objective that changes the design.

The current event chooses targets randomly and provides no prevention, preparation, response, investigation, or recovery action owned by Event 47. An achievement tied to being hit, avoiding a hit, receiving several hits, or having another country hit would reward random selection instead of player skill.

The implementation audit should confirm that Event 47 does not accidentally progress nuclear achievements through its mushroom-cloud presentation. It should also confirm that BOOM deaths do not satisfy achievements that require a nuclear strike, nuclear responsibility, fallout, or nuclear condemnation.

This boundary does not block achievements from shared systems. A player can still earn an existing famine, migration, reconstruction, survival, or other achievement later through real actions taken after the blast when that achievement's own conditions are met.
