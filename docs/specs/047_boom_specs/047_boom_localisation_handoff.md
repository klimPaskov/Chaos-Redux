# Event 47 BOOM localisation handoff

Use the Chaos Redux event writing rules. This file defines direction and required surfaces. It does not provide final pasteable localisation.

## Required surfaces

- Event name mapping for ID 47
- Main direct-hit report title, description, and option
- Neighboring-country report family
- Same-continent distant report family
- Global distant soundwave report family
- Secondary epicenter location notice family
- Bigger BOOM evolution title and details direction
- BOOM BOOM BOOM evolution title and details direction
- Event Details premise text
- Event Details evolution preview text
- Event History incident summary
- Debug name mapping
- Deaths cause label for Event 47 civilian deaths
- Blocked or degraded multi-strike explanation for test and debug surfaces

## Dynamic information

Final text should use the real selected state, owner, affected region, blast count, applied casualty total, and affected-state count where the owning surface supports them.

A secondary notice should identify the later epicenter without changing the player's camera.

## Tone

The tone is grave, physical, and confused. Direct victims should receive specific information about missing communications, destroyed settlements, broken railways, pressure damage, local force disruption, and early casualty estimates.

Distant countries should receive concrete local observations such as broken windows, instrument readings, frightened animals, harbor movement, or thunder-like sound.

The text must keep the cause unresolved. Accusations can appear only as unconfirmed reactions.

## Forbidden claims

Do not state or imply that:

- a nuclear weapon was used
- a named country attacked
- a hidden weapon owner exists
- investigators found a launch point
- radiation or fallout is present
- the event has a scientific, alien, divine, occult, or supernatural cause
- later events will reveal the truth
- the global soundwave creates a gameplay penalty

The word nuclear can appear only as an uncertain visual comparison.

## Option direction

Direct-hit options should communicate shock, grief, or the need to assess the destruction. Distant-country options should use restrained confusion or uneasy understatement.

Avoid comedy, memes, cheerful irony, triumph, taunting, and generic action phrases.

## Event Details direction

Event Details should describe the premise, independent repeatability, regional blast damage, global soundwave, and the two evolved incident profiles. It should not list exact mortality ranges, selection fallback rules, hidden receipts, or implementation terms.
