# Event 124 subagent usage map

This companion defines future implementation delegation for the proposed Sun Moves Away specification.
No named project specialist ran during this planning task.
Use the [acceptance matrix](124_sun_moves_away_acceptance_matrix.md) and [MCP usage map](124_sun_moves_away_mcp_usage_map.md) as the common evidence contract.
The [core](124_sun_moves_away_spec_part_1_core.md), [lifecycle](124_sun_moves_away_spec_part_2_evolutions_and_return.md), [decisions](124_sun_moves_away_spec_part_4_decisions_missions.md), [AI](124_sun_moves_away_spec_part_5_ai_balance.md), and [integrations](124_sun_moves_away_spec_part_6_integrations_and_chaos.md) control behavior and tuning.
Delegation cannot change that design.

## Parent ownership and sequence

The parent owns design, balance, identity migration, native-mechanism acceptance, global lifecycle integration, shared interfaces, and completion.
Confirm the catalog identity 124 (former catalog ID 136; Demilitarization moved to 114) and its registry reservations before allocating `chaosx.nr124.1` or related identifiers.
Every dispatch needs an exact current-source file allowlist.

| Stage | Required dependency and outcome |
| --- | --- |
| D0: Evidence and identity | Reconcile identity and reservations. Investigate both core engine mechanisms through installed documentation and exact precedents. |
| D1: Owner contracts | Establish receipts, clocks, enrollment, Heat arbitration, humanitarian and creature interfaces, and reservation release. |
| D2: Gameplay tranche | Implement actions, incidents, policies, missions, AI, manual setup, and Return. Preserve weighted-source baselines. |
| D3: Presentation | Produce classified assets and the event-owned panel against stable D2 contracts. |
| D4: Bounded audits | Review named scenarios, source, receipts, assets, and available evidence. Repair findings and recheck affected cases. |
| D5: Closure | Resolve improvement disposition, reconcile documentation/workbook, and audit final implementation. |

Stable asset briefs may proceed alongside D1–D2.
Keep unresolved core mechanisms explicit while independent work continues.
Worker handoffs cannot approve reduced substitutes.

## Dispatch and handoff contract

Use the canonical snake_case role names below.
Canonical `.claude/agents/<hyphen-name>.md` definitions generate Codex and other runtime files through `python .tools/sync/sync_agents.py`.
For example, `chaosx_event_ui_worker` maps to `chaosx-event-ui-worker.md`.
Follow current AGENTS, owning skills, and runtime model/effort profiles.

Every dispatch is self-contained, with no inherited parent-thread context.
Codex uses `fork_turns="none"`.
Supply identity, accepted parts, file/identifier allowlist, revision, preceding dispositions, scenario IDs, unresolved questions, forbidden edits, output path, and tool-retry history.

Use `docs/plans/124_sun_moves_away_plans/subagent_handoffs/` for actual implementation handoffs.
Each current handoff records changes, inputs/outputs, evidence, scenario limits, parent work, and deviations.
The parent reviews every output.
Unavailable delegation permits an honestly identified parent review while retaining explicit independent-review requirements.

## Shared-owner boundaries

Famine's real `famine_request_event_pressure` gateway requires proven state, people, source, and actor inputs and does not supply Sun replay protection.
Migration's `migration_accept_famine_survivor_request` accepts Famine-survivor requests only.
General Sun evacuation requires the appropriate inspected Migration operation, whose owner retains debit, route loss, delivery, and settlement.
Deaths accounting uses observed exact losses through its current owner contract.
Any real or archival image, including historical flags, photographs and historically attested emblems, routes to `chaosx_asset_source_researcher` and its source-verification rules, not to `chaosx_generated_event_art`, which covers only original fictional or alternate-history art.
Portraits route only to `chaosx_portrait_creator`, and 3D models route only through `chaos-redux-3d-model-pipeline` to `chaosx_3d_model_pipeline`.
Creature-family definitions and country identity flags do not establish surviving units in mixed armies.
No universal vampire survival predicate, Sun Return API, or completed Heat Wave exclusion owner was verified in the research.
The responsible specialist must establish each missing contract explicitly.
The parent reviews these interfaces against [part 6](124_sun_moves_away_spec_part_6_integrations_and_chaos.md) and the [research record](124_sun_moves_away_research_and_sources.md) before integration.
