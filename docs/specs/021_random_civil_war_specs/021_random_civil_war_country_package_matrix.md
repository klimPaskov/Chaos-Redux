## Package gates

Every actor needs:

- valid country or takeover route
- defensible public identity
- safe leader or institution
- coherent territory or same-tag path
- capital
- manpower
- equipment
- force-growth route
- AI
- decisions
- outcome
- cleanup
- asset ownership
- documentation

## Invalid package outcomes

When a candidate lacks any required surface:

1. try another valid actor in the selected country
2. try another archetype
3. try another target
4. mark Event 021 unavailable when no target remains

Do not:

- create a zero-state actor
- invent a grounded leader
- duplicate a tag
- substitute an unrelated package
- use an incomplete Event 006 package
- leave a temporary country permanent
- use a nonhuman package
- copy another event's actor without an integration contract
