# Conditional Subagent Prompt: Event 021 Asset Source Researcher

Use this prompt only when a final authorized Event 021 report or news image must depict a specific real historical scene, artifact, photograph, poster, symbol, or document.

Spawn `chaosx_asset_source_researcher` with `fork_context=false`.

Read:

- repository `AGENTS.md`
- `chaos-redux-event-assets`
- Event 021 asset prompt
- exact authorized asset row and consumer
- matching vanilla-reference family

Find and verify a period-appropriate source.

Record:

- source page
- direct file source
- archive or author
- date
- license or public-domain status
- usage terms
- why it fits
- uncertainty
- source checksum

Process the selected source into the required PNG and DDS package.

Do not source or create:

- character portraits
- new flags
- modern reenactment
- film still
- AI-looking historical reconstruction
- unrelated dramatic photo

Do not edit gameplay, localisation, GFX, GUI, event, decision, focus, or workbook files.

Write:

`docs/plans/021_random_civil_war_plans/subagent_handoffs/asset_source_researcher_handoff.md`

If no defensible source exists, mark the asset blocked. Do not substitute.
