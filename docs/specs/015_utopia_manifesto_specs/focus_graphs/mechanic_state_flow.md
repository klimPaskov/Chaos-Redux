## Value interaction guide

```text
HIGH NEED
  -> urgency, emergency stores, shortage missions, external case pressure
  -> can justify temporary Assignment
  -> harms Concord when prolonged

HIGH PLENTY
  -> aid, shorter workday, generous charters, formation proof
  -> can fall through war, blockade, overexpansion, or closed militarization

HIGH CONCORD
  -> local votes, league credibility, voluntary integration, crisis resilience
  -> falls through broken promises, quotas, forced settlement, and false claims

CHOICE
  -> innovation, trust, voluntary callings, slower emergency correction

ASSIGNMENT
  -> fast staffing, standardization, mobilization, evasion and legitimacy risk
```
