# Event 015 completion acceptance checklist

## Event identity

- Event ID 15 no longer uses `World Tension Subsides` wording or behavior.
- Event slug is `utopia_manifesto`.
- Classification is Minor Fire-Once.
- Cluster membership is not added unless a later accepted cluster design exists.
- Event log name, debug name, detail text, and catalog row all align after final localisation exists.

## Targeting

- Majors are blocked.
- Strong industry countries are blocked.
- Strong army countries are blocked.
- Special Chaos Redux nonhuman or terminal actors are blocked.
- No valid target produces `N/A` rather than a misleading zero weight.
- AI target selection favors minor countries and avoids dead-on-arrival targets.
- Player countries are eligible only if they pass the same gates.

## Event options

- AI accepts every time.
- Human player sees acceptance and rejection.
- Acceptance sets the Utopian package and tree.
- Rejection ends the event without hidden punishment.
- Final event text follows style rules and does not expose hidden mechanics.

## Focus tree

- Full replacement tree exists.
- Tree is loaded only for the accepting country.
- Tree includes opening trunk, four normal interpretations, hidden Marked Bounds, industry, vocation, military, diplomacy, expansion, geography, and late route families.
- Tree is non-linear and readable.
- Branches have route interaction and payoffs.
- Focus rewards are varied and not mostly small modifiers or new ideas.
- Every focus has localisation, icon, AI behavior, and route logic.
- Route coverage table exists in completion report.

## Utopian Ledger

- Need, Consent, Surplus, Overreach, Vocation Balance, and Foreign Suspicion exist.
- Values are visible through decision category or scripted GUI.
- Values change through focuses, decisions, missions, wars, state control, and foreign action.
- Values unlock, block, or modify content.
- Script constants or documented tuning hold thresholds and caps.
- Any auxiliary League confidence value is visible and gates League behavior without replacing the six required core values.

## Decisions and missions

- Utopian Ledger category exists.
- Decisions are phased and do not clutter the UI.
- Costs use resources, map objectives, time, and mechanic values.
- Timed missions have success and failure.
- AI can use equivalent actions.
- Stale target cleanup exists.
- Exploit checks cover claims, cores, units, aid, and League membership.

## Occupation and integration

- Needful land claims require Need proof or route risk.
- Arbitration exists before peaceful claims.
- AI cannot target majors or much stronger countries under ordinary logic.
- Integration uses storehouses, supply, compliance, resistance, local support, councils, or route-specific hardline alternatives.
- No large instant free core grants.

## Assets and presentation

- Required report image exists and is processed.
- Required focus, idea, decision, decision category, achievement, and GUI assets exist.
- Late route flags or cosmetic flags exist if implemented.
- Collective portraits exist if route leader changes need them.
- Animated sprites use real source frames, frame sheets, static fallbacks, manifests, and handoffs.
- No asset placeholder is marked complete.

## Super-events

- New Utopia and Marked Bounds super-events are implemented only after research is complete.
- Titles, quotes, button remarks, and audio are sourced and documented.
- Final audio is licensed or public domain, unique unless approved, 44.1 kHz, and wired through the existing helper.
- Image, text, quote, audio, slot, docs, and spreadsheet agree.

## Achievements

- Achievements are difficult and route-spanning.
- No achievement unlocks merely for accepting the event.
- Tracking flags and disqualifiers work from acceptance onward.
- Icons and variants exist.
- Localisation and docs exist.

## Audits and validation

Before claiming completion, run or spawn:

- focus tree audit
- decision and mission audit
- localisation audit
- country package audit if cosmetic identities, leaders, or flags changed
- scripted system architecture review if helpers were created
- completion audit
- spreadsheet worker after final in-game wording exists

The final completion report must list simplifications, blockers, and skipped meaningful validation. If none exist, it must say so and provide evidence.
