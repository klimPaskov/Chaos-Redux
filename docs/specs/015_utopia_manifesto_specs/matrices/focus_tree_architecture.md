# Utopia Manifesto expanded focus tree architecture matrix

This matrix is a route plan, not a coordinate map. The implementation agent should create exact focus positions and connections while preserving the route logic.

| Lane | Target count | Notes |

| Political routes | 45 to 60 total | uneven route depth, no five-focus main branches |

## Ultimate Utopia convergence

| Gate | Required proof direction | Route-colored answer |
| --- | --- | --- |
| Provision | stores can sustain domestic and foreign obligations | shared stores, planned stores, forced stores, or no-place stores |
| Work | work system functions without collapse | consent, correction, measurement, command, or hidden compulsion |
| Dwelling | households and wards have public living standards | charters, districts, wards, or precincts |
| Law | public law can answer contradictions | assemblies, magistrates, boards, mandate courts, or ledger law |
| Defense | the system can defend itself and its subjects | household guard, planned defense, mandate army, or no-place security |
| Land | claims are justified, renounced, chartered, or conquered with settlement | low Fracture route or coercive proof route |
| Foreign | League, subjects, wards, partners, or precincts function | determines final global order |
