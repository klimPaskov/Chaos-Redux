# Utopia Manifesto decision and mission prompt

Use this prompt after reading the full Utopia Manifesto specs and matrices. Focus on the Need Ledger, late enforcement, and puppet utopia systems.

## Main systems

Implement decision and mission systems for:

- Need Ledger
- Common Stores
- Vocational Rolls
- Need Dossiers
- Wards and Charters
- Common Table
- World Household Enforcement
- Daughter Commonwealth Office
- hidden Outopia actions

The decision layer must evolve through the focus tree. Early decisions should manage stores, trades, roads, and first surveys. Midgame decisions should manage claims, charters, wards, diplomacy, and integration. Late decisions should export, enforce, or renounce Utopia abroad.

## Late enforcement

Implement selected-target or capped target flows for foreign actions. The player should not see a debug wall of every possible target.

Late actions should include invitation, survey, store aid, local warehouse funding, trade teachers, ward magistrates, charter plebiscites, household guard training, false dossier correction, emergency ward orders, settlement congresses, and hidden precinct conversion.

Use concrete costs and objectives. Good costs include convoys, trains, trucks, fuel, support equipment, infantry equipment, manpower, civilian factory burden, army XP, local support, compliance, resistance, port access, rail access, state control, divisions in required states, stability, war support, and time.

## Puppet utopias

Represent utopian subjects with local values or compact equivalents:

- Local Stores
- Local Consent
- Vocational Acceptance
- Ledger Dependence
- Ward Autonomy
- Fracture Import

Subject forms should include Charter Commonwealths, Surveyor Protectorates, Necessary Wards, Daughter Commonwealths, and hidden No-Place Precincts where feasible. Subjects should have support needs, failure states, and final fates.

## Mission families

Implement timed or objective missions such as Trial Storehouse, Trial Trade Roll, Guard the Storehouses, Keep the Route Open, Stabilize the Ward, Charter Congress, Necessary Ward Order, Ring of Full Shelves, Renounce False Dossier, and World Household Congress.

Missions should require real actions such as holding states, protecting supply, escorting convoys, building state projects, reducing resistance, improving compliance, supporting subjects, or meeting local value thresholds. Do not make the main mission pattern passive stockpile checks.

## Cleanup and AI

Clear selected targets and decisions when targets die, change owner, leave scope, change subject fate, solve Land Need, renounce claims, or lose route validity. AI must have equivalents for meaningful human actions and should stabilize current subjects before creating more subjects.
