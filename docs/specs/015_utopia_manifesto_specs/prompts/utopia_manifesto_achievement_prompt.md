# Achievement prompt for Event 015 Utopia Manifesto

Implement the Event 015 Utopia Manifesto achievements from `matrices/achievement_matrix.md` and part 5 of the spec. Follow `AGENTS.md`, `chaos-redux-events`, `hoi4-focus-trees`, `hoi4-decisions-missions`, and `chaos-redux-event-assets`.

The achievements must not unlock just because the event fired. They must reward mastery of routes, mechanics, formables, hidden branches, difficult survival, subject management, late enforcement, restraint, or rare campaign states.

For each achievement, implement tracking flags or variables, unlock triggers, disqualifiers, final localisation, icon references, and documentation. Use the asset prompt for completed, grey, and not-eligible icon variants. Report any achievement that cannot be checked from final state and needs tracking during play.
