# Event 015 Utopia Manifesto, part 4 country identity, AI, evolutions, and balance

## Country package model

This event usually transforms an existing minor instead of creating a new tag. The host keeps its tag unless a late formable or cosmetic tag is reached. The transformation is still a country package because the host receives a new tree, new mechanics, identity variants, ideas, decisions, possible leaders, possible flags, and AI behavior.

| Surface | Design direction |
| --- | --- |
| Tag | host tag remains unless late formable or cosmetic tag is used |
| Focus tree | accepted host loads the Utopia Manifesto tree |
| Country name | host keeps current name early, then may gain route-specific cosmetic names |
| Party names | route-specific parties or movements should be defined for every ideology path used |
| Leader | current leader can remain, be constrained by a council, or be replaced by a fictional council or route leader |
| Flag | base flag remains unless route cosmetic tag is selected |
| Advisors | scholar, surveyor, storehouse administrator, household guard organizer, envoy, and coercive mandate figures |
| Starting military | no instant army reset, but emergency household guard decisions help tiny countries |
| Reinforcement pathway | unit growth through focuses, stores, guard missions, volunteers, workshops, and charters |
| AI | route-aware plan based on geography, ideology, strength, war state, chaos, and player proximity |

The package should not replace base flags for real countries. Route flags should use cosmetic tags or route-specific identities.

## Eligibility and target safety

The event should prefer countries that are small enough for a manifesto to plausibly change the entire state.

Good candidates:

- independent minors with limited factories
- small subjects with enough autonomy to act, if implementation supports focus replacement safely
- player countries that are not majors and not strong industrial powers
- island or landlocked minors with strategic problems the manifesto can solve
- countries not already controlled by a special event tree

Bad candidates:

- majors
- countries above the strong industry threshold
- special chaos countries and nonhuman countries
- countries in terminal world-end roles
- countries already assigned a major event-created focus tree that should not be overwritten
- countries whose annexation or civil war status makes focus replacement unsafe

The implementation should show N/A in the event list when no valid host exists.

## Dynamic identity routes

| Route | Public identity direction | Political direction | Military direction | Diplomatic direction |
| --- | --- | --- | --- | --- |
| Free Household Compact | original country as a voluntary commonwealth | democratic, socialist, or local pluralist | defensive militia and volunteers | league and charters by consent |
| Morean Council | commonwealth of the host country | moderate reform council | balanced defense | arbitration and recognition |
| Surveyor State | planned commonwealth or measured republic | neutral technocratic | strong logistics and production | lease diplomacy or managed wards |
| Good Place Mandate | eutopian state or mandate form | authoritarian welfare state | strong coercive defense and offense | needful demands and wardship |
| No-Place branch | outopian cosmetic variant | high-chaos bureaucracy or symbolic council | strange efficiency and instability | world-as-island doctrine |

## Starting forces and reinforcement

The event should not erase the host army. It should give small countries a pathway to survive.

### Emergency host support

If the host has very few divisions, the early tree should unlock Household Guard decisions. These should scale by population, equipment, stores, and chaos tier. A tiny country might get one or two local defense units after committing equipment and manpower. A larger minor should pay more and receive better but not free units.

### Unit families

| Unit family | Unlock | Requirements | Role |
| --- | --- | --- | --- |
| Household Guard | early military branch | infantry equipment, manpower, local support | defensive militia |
| Storehouse Watch | Common Stores branch | support equipment, state project | garrison and resistance control |
| Surveyor Detachment | Surveyor route | trucks or trains, army XP | rapid state control and logistics |
| Free Company Volunteers | consent or council route | high Eutopia, manpower, equipment | voluntary field units |
| Charter Ward Militia | successful ward integration | local support, compliance, stores | defense in integrated wards |
| Auxiliary Contract Force | auxiliary controversy branch | stores or money proxy, Fracture risk | stronger temporary manpower |
| Mandate Columns | coercive route | manpower, equipment, Fracture | offensive units with political cost |

Unit rewards should be linked to decisions or focuses. Avoid flat repeated division grants.

## AI route matrix

AI acceptance is always yes when the AI receives the event. After acceptance, route choice should be strategic.

| AI condition | Preferred route | Avoids | Notes |
| --- | --- | --- | --- |
| democratic or high stability | Free Household Compact or Morean Council | Good Place Mandate unless high chaos | prioritizes consent, stores, league |
| communist or socialist | Free Household Compact, Morean Council, or Surveyor State | no-place branch unless high chaos | favors common stores and worker choice |
| neutral monarchy or authoritarian minor | Surveyor State or Morean Council | full consent if unstable | wants state capacity and defensive order |
| fascist or militarist | Good Place Mandate or Surveyor State | Free Household Compact | only expand if targets are weak |
| island country | island branch plus navy and charters | inland-only path | values ports, convoy stores, coastal defense |
| landlocked country | inland island branch and rail guards | naval route | values rail, border wards, land leases |
| at war and weak | Household Guard and Stores | aggressive expansion | tries to survive first |
| high chaos and high Fracture | Good Place Mandate or hidden branch | pure consent route | dangerous AI allowed only under clear conditions |
| near a player major | Morean Council or defensive route | suicidal demands | AI should avoid angering much stronger player unless route demands it |
| world threat active | league relief or defensive common table | ordinary claims | can support anti-chaos cooperation |

## AI decisions

AI should use an equivalent action path even if humans use a scripted GUI.

AI priorities:

1. Fill Common Stores before starting expansion.
2. Stabilize capital and high-value states.
3. Raise Household Guard if division count is low.
4. Choose route based on ideology, geography, strength, and chaos.
5. Use need dossiers only when Land Need is real.
6. Prefer leases and charters before war unless on Mandate route.
7. Renounce claims when need is solved unless coercive route.
8. Integrate wards slowly with stores if resistance is high.
9. Avoid demands against much stronger countries unless backed by faction or late high-chaos route.
10. Do not use hidden branch unless Fracture and chaos conditions are met.

## Evolution detail

### Ledger of Hunger

This evolution appears when global chaos is at least Gathering Storm and the actor has low Common Stores, rising Land Need, wartime blockade, bombing, or refugee pressure. It unlocks emergency shortage missions, ration registers, foreign grain leases, and stricter public occasion choices. It should not force coercion, but it should make coercion tempting.

Active actor changes:

- emergency store missions become visible
- low-store penalties become stronger but more interactive
- AI raises priority on stores and defensive rail control
- public option text becomes more anxious in direction, without final wording

Pre-fire opening changes:

- the selected host begins with higher Empty Stores pressure
- the early tree prioritizes public works and storehouses
- the opening event should mention shortages as part of the public argument

### Continental Charters

This evolution appears at Rising Chaos when Land Need is high and the actor has enough stores, legitimacy, or expansion pressure to look beyond its home territory. It unlocks charters, plebiscites, settlement missions, and target dossiers with consent checks.

Active actor changes:

- charter decisions become available
- first lease or charter super-threshold can be prepared
- AI may seek small willing targets or weak neighbors
- peaceful route gets more tools, coercive route gets stronger temptation

Pre-fire opening changes:

- the first host can start with a preselected nearby charter target
- initial Land Need is higher but not automatically warlike

### The No-Place Argument

This evolution appears at Chaos Tier when Outopia Fracture is high or when the actor has used repeated forced assignments, coercive wards, or needful wars. It reveals the hidden route.

Active actor changes:

- hidden branch becomes visible
- Fracture warnings become more explicit
- coercive decisions gain stronger but riskier versions
- consent routes can still audit and step back if not locked out

Pre-fire opening changes:

- the host begins with a more polarized manifesto debate
- AI route weights allow more Surveyor State and Mandate choices

### The World as Island

This evolution appears at Totalen Chaos when the actor has become a regional force through league members, integrated wards, charters, or coercive settlements. It unlocks late ambition and super-event thresholds.

Active actor changes:

- Utopian Commonwealth, Eutopian League, or No-Place Mandate finishers become available
- super-event prompt package becomes relevant for final implementation
- foreign countries react more strongly to the actor's identity

Pre-fire opening changes:

- a late first firing can create a more advanced actor with stronger mechanics
- this should be rare and should not target a major or strong industrial country

### Empty Coast Memory

This evolution is only for World Collapse campaigns when the event is already active. It gives the actor preservation and refugee tools. It should not create a terminal world-end branch.

## Balance intent

The event should make a minor interesting and potentially strong. It should not make a random minor instantly stronger than a major. Strength must come from completing the tree, filling stores, integrating wards, and committing costs.

Balance principles:

- early bonuses are mostly survival and mechanics
- midgame strength comes from state projects and route decisions
- late route payoff can be strong if earned
- peaceful route snowballs through league members and legitimacy, not cheap wars
- coercive route snowballs faster but creates Fracture, resistance, and coalitions
- no route gets endless free cores
- no route gets war goals without Land Need proof or a late-route exception
- no country should pay the same decision costs regardless of size
- AI should not suicide into strong neighbors

## Country-specific adaptation

The shared tree should feel different depending on host geography and ideology.

### Island hosts

Island hosts should get early use from ports, convoys, coastal defenses, and the New Island branch. They should care about convoy routes and overseas charters. If they lack industry, they use common stores and port leases to grow.

### Landlocked hosts

Landlocked hosts should receive the inland island branch. It treats rails, mountain passes, river crossings, and border wards as the country's enclosing sea. They should use rail guards, defensive lines, and neighbor leases rather than naval content.

### Colonial or subject hosts

If a subject can receive the event safely, the manifesto becomes an anti-puppet or autonomy program. The tree should include independence through common stores, foreign recognition, and anti-puppet clauses. It should not instantly free the subject without work.

### Tiny hosts

Tiny hosts need emergency survival tools. They should use household guard units, store projects, and diplomatic charters. They should not be handed many factories for free.

### Already unstable hosts

Countries with low stability should face stronger Pamphlet Factionalism and Empty Stores problems. They can still become powerful, but early decisions should matter.

## Foreign reactions

Foreign reaction should depend on route behavior.

| Actor type | Reaction to consent route | Reaction to Surveyor route | Reaction to Mandate route | Reaction to hidden branch |
| --- | --- | --- | --- | --- |
| neighboring minors | may join charters or league | wary but open to leases | resist demands | fear and containment |
| majors | watch or sponsor | use as buffer | oppose if interests threatened | consider coalition |
| democratic powers | recognition if consent remains high | cautious recognition | condemnation | hostility |
| communist powers | support stores and labor reforms | support planned route | mixed if coercive | ideological confusion |
| fascist powers | exploit or oppose | respect strength | rivalry | likely hostility |
| special chaos countries | not normal diplomatic targets | threat response only | threat response only | world-threat interaction |

## Completion expectations for implementation

The final implementation should produce a route coverage report that compares this spec's required route families against implemented focus branches. It should explicitly report missing, merged, renamed, simplified, or queued routes.

The implementation should run focus, decision, localisation, country package, and completion audits before claiming the event complete.
