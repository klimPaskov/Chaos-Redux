# Event 015 Utopia Manifesto, part 2 expanded focus tree architecture

This file replaces the first focus-tree outline. The earlier outline was directionally correct, but it was too shallow for the promised country identity. The final tree should feel like a full political project that begins with a book, builds domestic institutions, turns those institutions outward, and then tries to reconcile every route into a late game claim about the perfected society.

All focus names in this file are working labels, not final localisation. The implementation agent should write final in-game names and descriptions from the direction here.

## Scale and shape target

The accepted host should receive a large shared tree with dynamic branches, not a narrow minor tree. The intended final tree should contain roughly 105 to 135 focuses before hidden branch variants. A normal playthrough should complete a smaller subset because political routes, enforcement doctrines, and hidden paths are mutually exclusive or conditional.

The tree does not need symmetry. Some paths should be longer because they carry more mechanics. The Surveyor State and Good Place Mandate should usually be wider than Free Household Compact because they manage more state tools and coercive options. Outopia should be compact at first, then expand sharply after reveal.

Recommended focus density by lane:

| Lane | Target focus count direction | Shape |
| --- | ---: | --- |
| Opening and first institutions | 14 to 18 | mostly shared, with two early forks |
| Political routes | 45 to 60 total | uneven, with route locks and route-specific support hooks |
| Economy and society | 20 to 28 | broad support branch with state projects and domestic pillars |
| Military and security | 16 to 22 | shared base, then route-colored defense choices |
| Diplomacy, expansion, and enforcement | 26 to 36 | broad late branch, linked to Need Ledger targets |
| Puppet utopia and subject management | 12 to 18 | unlocks after enforcement or charter focus groups |
| Ultimate Utopia convergence | 16 to 24 | final shared spine with route-colored endings |
| Hidden Outopia extension | 10 to 18 | hidden or concealed until Fracture and evolution gates allow it |

The implementation agent may tune the final count, but a branch with only four or five focuses is not enough unless it is a small connector. Every major route needs early, middle, late, and convergence roles.

## Opening spine, expanded

The opening spine should take the player from curiosity to institution. It should not hand out many flat bonuses. It should open the Need Ledger, set the first contradictions, and force the player to choose how public, bureaucratic, and coercive the project becomes.

| Stage | Focus role working label | Purpose | Unlock or connection |
| --- | --- | --- | --- |
| 1 | First Reading | the manifesto becomes a public issue | initial mixed idea, event memory, first option legacy |
| 2A | Cheap Edition | mass public circulation | reading-circle decisions, public support, higher expectation pressure |
| 2B | Sealed Survey Copy | official study before public release | faster survey tools, lower early panic, higher state secrecy pressure |
| 3A | Household Debates | voluntary public committees | early legitimacy and Free Household affinity |
| 3B | Convene the Surveyors | first official registry | Need Ledger values become visible |
| 4 | Count the Households | basic census of homes, food, trades, tools, land, and ports | creates first ledger baseline |
| 5 | Count the Empty Shelves | reveals store shortage and production need | Common Stores decisions |
| 6 | Count the Unchosen Trades | reveals work mismatch | Vocational Rolls decisions |
| 7 | Count the Unkept Roads | checks rail, supply, ports, and border routes | state project decisions |
| 8 | The Public Occasion Clause | introduces emergency work override | coercive tools with Fracture risk |
| 9 | The Island Question | island, coast, river, rail, and landlocked variants | geographic subbranch gates |
| 10 | The First Need Dossier | neighbor and state comparison begins | diplomacy and expansion branch preview |
| 11 | The Trial Storehouse | first state project goal | timed mission based on building, supply, and stores |
| 12 | The Trial Trade Roll | first chosen work mission | timed mission based on production and worker acceptance |
| 13 | The Ledger Is Not Law | route choice over whether numbers can command people | political route gate |
| 14 | The Route Council | public doctrine split | opens political doctrine routes |
| 15 to 18 | optional country-specific openers | island navy, mountain roads, colonial border, ruined industry, or tiny capital special cases | context variants without requiring separate trees |

The opening should also seed four long-term domestic values:

| Value | Meaning | How the opening affects it |
| --- | --- | --- |
| Common Stores | ability to feed, equip, and stabilize society | rises through storehouse and agriculture projects |
| Vocational Freedom | how much people can choose work | rises through voluntary choices, falls through forced assignment |
| Land Need | claim pressure based on food, space, ports, resources, and security | rises from shortages and blocked access, falls from domestic reforms |
| Outopia Fracture | gap between declared good place and lived coercion | rises from forced labor, unjust claims, subject abuse, and false dossiers |

## Domestic pillar branches

These branches are shared by all public routes, but route choices should change costs, rewards, and failure consequences. Each pillar should have enough depth to matter by itself, then feed the convergence branch.

### Bread and Stores pillar

This pillar should run from emergency shortage to late public abundance. It should be one of the main requirements for the Ultimate Utopia branch.

| Phase | Focus roles | Gameplay direction |
| --- | --- | --- |
| Early | common shelf, storehouse ledgers, winter reserve, plain ration rules | store value, consumer goods pressure, stability protection |
| Middle | market halls, convoy stores, inland granaries, state warehouses, repair culture | state projects, convoy or train costs, port and rail dependence |
| Late | no empty shelves, public feast as proof, stores beyond borders | unlocks aid missions, league support, puppet store convoys |
| Failure hooks | spoiled stores, black market clerks, unequal ration scandals | raises Fracture and can block convergence until corrected |

### Chosen Work and Workshops pillar

This pillar should make the economy feel different from normal industrial focuses. It should create output through work assignment, chosen trades, apprenticeships, and workshops.

| Phase | Focus roles | Gameplay direction |
| --- | --- | --- |
| Early | trade rolls, public workshops, tool houses, apprenticeship books | production and training decisions |
| Middle | workshops by district, standard tools, useful leisure, family craft contracts | factories, production lines, support equipment, army XP when militarized |
| Late | trade without idleness, choice with obligation, the perfect workday | high output if Freedom and Stores are stable |
| Failure hooks | coerced trades, false choice rolls, exhausted households | stronger output with Fracture growth |

### Houses, Health, and Public Halls pillar

This branch should be geographically grounded. It should use state targets, not only national modifiers.

| Phase | Focus roles | Gameplay direction |
| --- | --- | --- |
| Early | standard houses, clinics, baths, public halls | stability, resistance reduction, population retention |
| Middle | ward houses, state clinics, rebuilding districts, rail-linked housing | construction missions and integration support |
| Late | every household counted, no idle roof, public health covenant | stronger ward integration and subject stability |
| Failure hooks | resettlement pressure, overcrowding, forced household moves | Land Need rises and Fracture rises |

### Plain Law and Education pillar

This branch should make the manifesto into a teachable public order. It should support peaceful routes, but Mandate and Surveyor routes can use it for indoctrination or administrative obedience.

| Phase | Focus roles | Gameplay direction |
| --- | --- | --- |
| Early | plain law lessons, public lectures, useful study | research and advisor unlocks |
| Middle | school of magistrates, surveyor colleges, public disputation, ward teachers | integration, legitimacy, route-specific advisors |
| Late | laws short enough to remember, correction without gold, foreign schoolhouses | league and subject education tools |
| Failure hooks | doctrine tests, book loyalty, forbidden luxuries lists | hidden route pressure and public backlash |

### Useful Land Care pillar

This branch should lower Land Need when domestic solutions are possible. It should also sharpen the contradiction when the player claims land abroad while refusing to improve land at home.

| Phase | Focus roles | Gameplay direction |
| --- | --- | --- |
| Early | crop survey, irrigation, forest roads, hillside fields | infrastructure, supply, resource and food abstractions |
| Middle | land without waste, workshops near fields, road to storehouse | lower Land Need and improve stores |
| Late | prove no local waste, land care before land demand | blocks unjust Need Dossiers and improves diplomacy |
| Failure hooks | false scarcity reports, ignored rural districts | Fracture and target resistance rise |

## Political doctrine routes

The tree should have four public doctrine routes and one hidden doctrine route. Each public route should have a route opener, several middle groups, at least one side choice, at least one link into domestic pillars, at least one link into foreign policy, and a route-colored convergence focus.

### Free Household Compact

This route is consent-first. It should be strong in legitimacy, charters, federation, and clean integration. It should be weaker at rapid military production and emergency coercion.

Suggested depth: 10 to 14 focuses.

| Segment | Focus roles | Mechanical identity |
| --- | --- | --- |
| Opener | household consent assemblies | route lock toward consent and local autonomy |
| Public work | voluntary trade juries, right to change trade, appeal of the household | raises Vocational Freedom and lowers strike risk |
| Stores | common meals, public halls, shared winter store | turns Stores into legitimacy |
| Defense | household guard by consent, local watches, no forced levy clause | defensive units with support equipment and local support requirements |
| Diplomacy | no claim without need, charter before ward, public plebiscite office | peaceful expansion and League path |
| Side choice | household autonomy versus common obligation | autonomy lowers output but improves consent, obligation improves output with mild Fracture risk |
| Route finisher | consent charter | unlocks strong charters and League convergence |
| Convergence link | free pillar of work | satisfies Ultimate Utopia through Freedom, Stores, and charters |

Late route consequence: this route can enforce Utopia abroad only through invitation, protection, plebiscite, and store support unless the player later chooses a severe crisis override. It can still build puppet utopias, but they should be charter subjects with high autonomy and strong local consent.

### Morean Council

This route is the balanced humanist state. It should be the most flexible route. It should have more correction tools than the other routes and should be able to converge with most domestic and foreign branches.

Suggested depth: 10 to 13 focuses.

| Segment | Focus roles | Mechanical identity |
| --- | --- | --- |
| Opener | council of the book | creates reform council identity or constrains current leader |
| Law | magistrates of few laws, public correction, no gold offices | corruption reduction, advisor discounts, legitimacy |
| Work | necessary hours, rotating trades, learned leisure | balanced production and Freedom |
| Stores | audit the stores, equal table, repair before luxury | stronger Stores with low Fracture |
| Foreign | arbitration office, common table envoys, model charters | diplomacy and peaceful influence |
| Side choice | scholar magistrates versus elected correctors | technocratic stability or democratic legitimacy |
| Route finisher | tempered commonwealth | safe commonwealth identity and broad convergence access |
| Convergence link | corrected pillar of law | satisfies Ultimate Utopia through low Fracture and mixed institutions |

Late route consequence: this route should be able to build the cleanest Eutopian League. It can create puppet utopias as supervised charter commonwealths, but it should prefer release, arbitration, and federal membership over direct subject integration.

### Surveyor State

This route trusts measurement and planned administration. It should be deep because it controls the strongest domestic state tools and most subject-management machinery. It can become benign if audited, or coercive if the player treats the ledger as command.

Suggested depth: 13 to 17 focuses.

| Segment | Focus roles | Mechanical identity |
| --- | --- | --- |
| Opener | ministry of measures | route lock toward surveys and state planning |
| Census | useful hands census, household grids, district rolls | better dynamic calculations and shorter project cooldowns |
| Housing | standard houses, planned districts, ward clinics | strong state construction |
| Work | necessary assignment, rotation boards, efficient workshops | high output, Freedom pressure |
| Stores | stores before slogans, quantified reserves, route quotas | strong Stores and consumer goods relief |
| Security | public occasion boards, emergency work courts, labor appeal clerks | coercive tools with optional safeguards |
| Foreign | arithmetic of peace, survey missions abroad, technical protectorates | target scoring, puppet setup, ward administration |
| Side choice | audited surveyors versus unanswerable offices | lower Fracture and slower tools, or stronger tools and higher Fracture |
| Route finisher | planned commonwealth | route identity and advanced subject mechanics |
| Convergence link | measured pillar of provision | satisfies Ultimate Utopia through Stores, housing, and ordered work |

Late route consequence: this route should unlock the most detailed puppet mechanics. Surveyor puppets should have local ledger values and should send data, stores, and manpower through visible subject decisions.

### Good Place Mandate

This route declares that need can overrule consent. It should be powerful, risky, and morally coherent inside its own logic. It should not read like a normal fascist or military route. Its language is subsistence, necessity, and the alleged duty to build a good place.

Suggested depth: 13 to 18 focuses.

| Segment | Focus roles | Mechanical identity |
| --- | --- | --- |
| Opener | need over consent | hard route lock and coercive authority |
| Doctrine | wasted soil thesis, no idle acres, right of subsistence | stronger Land Need and demands |
| Labor | command the trades, household quotas, public occasion permanent | output and military production with Fracture growth |
| Wards | wards without delay, obedience houses, mandate magistrates | fast integration with resistance and foreign hostility |
| Army | arsenal of necessity, armed storehouses, needful army | war preparations and coercive subject enforcement |
| Foreign | prove need by arms, ultimatum of use, mandate over vacant land | temporary war goals and force-backed demands |
| Side choice | stern provision versus open conquest | stern provision keeps some legitimacy, conquest accelerates Fracture |
| Route finisher | mandate of subsistence | authoritarian identity and Mandate subject forms |
| Convergence link | necessary pillar of order | satisfies Ultimate Utopia through enforced stores and compliant wards |

Late route consequence: this route should unlock the strongest enforcement and the harshest puppet utopias. It should face coalition pressure, subject instability, and high Outopia Fracture if the player overuses forced conversion.

### Outopia hidden route

This branch should be hidden until high Fracture, a specific evolution, or late contradiction conditions reveal it. It is not a normal political route. It is the idea that the project has become a no-place machine that keeps redefining need until every border can be treated as provisional.

Suggested depth: 10 to 18 focuses after reveal.

| Segment | Focus roles | Mechanical identity |
| --- | --- | --- |
| Reveal | empty name | hidden route visible, animated seal state changes |
| Logic break | count what cannot be counted, false island of the map | Need Ledger values grow stronger and less stable |
| Space | shore inside every border, inland island doctrine | landlocked expansion logic and strange border claims |
| Labor | work without choosing, name without household | extreme production and legitimacy collapse risk |
| Foreign | every country is an unfinished ward, no-place surveyors abroad | coercive puppet conversion and foreign fear |
| Subject forms | precincts of the no-place | special subject type with low autonomy and high revolt risk |
| Finisher | world as island | high-chaos capstone and super-event eligibility |
| Convergence link | impossible pillar | corrupts Ultimate Utopia into No-Place Mandate if chosen |

Late route consequence: Outopia can form an ultimate state, but it should not be the same as Eutopia. It should be stronger in raw control and weaker in stable legitimacy. It should create the highest risk of coalition response and subject rupture.

## Military and security branch

The military branch should be deep enough to support both defensive utopia and expansion enforcement. It should not be a free division ladder. The player should build forces through institutions, equipment costs, support requirements, and state missions.

Suggested depth: 16 to 22 focuses.

| Subbranch | Focus roles | Gameplay direction | Route interaction |
| --- | --- | --- | --- |
| Household Guard | drill halls, local watches, capital tables, storehouse watch | militia templates, state defense missions, local support costs | strongest with Free Household and Morean |
| Planned Defense | district guard rolls, rail watches, standard arms depots | better templates and supply missions | strongest with Surveyor |
| Mandate Army | provision columns, armed storehouses, household quotas | stronger offensive preparation with Fracture | strongest with Mandate and Outopia |
| Border and Channel Works | pilot marks, coastal works, mountain roads, rail forts, convoy lanes | forts, coastal defense, rail hubs, port control | geography variant |
| Auxiliary Controversy | hired guards, foreign cadres, oath contracts, payment audits | manpower relief with legitimacy and dependency risk | branch can be restricted or exploited |
| Arsenal of Necessity | workshops to arms, support tools, emergency production, common artillery | military factories and production lines | feeds enforcement branch |
| Last Wall | common defense doctrine, supply under siege, oath of stores | strong defensive payoff | route-colored final defense idea |

The late convergence branch should require at least one mature military or security pillar. A society that cannot defend its stores should not be able to claim Ultimate Utopia.

## Diplomacy, expansion, and enforcement branch

The expansion branch should become larger than the first package described. It should start with persuasion and proof, then split into charters, protectorates, needful war, and late enforcement. It should be the main bridge into puppet utopia mechanics.

Suggested depth: 26 to 36 focuses before route-colored variants.

### Need Dossier line

| Phase | Focus roles | Purpose |
| --- | --- | --- |
| Early | first dossier, survey neighbor stores, count ports and rails | identifies legitimate target arguments |
| Middle | public proof office, foreign observers, compare unused land | adds conditions and counterplay |
| Late | dossier tribunal, claim renunciation office, need expiry law | prevents permanent claim spam and rewards honest restraint |

Need Dossiers should produce temporary claims, diplomatic demands, lease requests, arbitration missions, or war preparation. Claims should decay when Land Need falls, when the target grants a concession, or when the host fails to prove need.

### Consent Charter line

| Phase | Focus roles | Purpose |
| --- | --- | --- |
| Early | common table envoys, household invitation, storehouse embassy | peaceful influence over minors and neighbors |
| Middle | plebiscite observers, charter households, local law guarantees | peaceful state transfer, autonomy, or League joining |
| Late | charter commonwealth office, daughter commonwealth rights, federal stores | creates high autonomy utopian subjects or League members |

This line should let a high Eutopia country expand influence without conquest. It should also let a conquered region become a subject rather than an annexed core.

### Protective Wardship line

| Phase | Focus roles | Purpose |
| --- | --- | --- |
| Early | ward survey, emergency protection clause, storehouse guarantee | subject and puppet path after crisis or war |
| Middle | appoint magistrates, fund local stores, train household guard | creates puppet utopia mechanics |
| Late | ward constitution, local trade rolls, autonomy hearings | convert puppet to League member, integrate, or release |

Wardship should be the bridge between conquest and legitimate order. A player can use it honestly or abuse it. The mechanics should track the difference.

### Needful War line

| Phase | Focus roles | Purpose |
| --- | --- | --- |
| Early | just cause of use, exhausted diplomacy, defensive need brief | only opens when diplomacy fails or Mandate is chosen |
| Middle | ultimatum of subsistence, needful mobilization, seize the store route | temporary war goals and attack preparation |
| Late | war for the common table, enforce public provision, settlement after use | postwar puppet, charter, release, or integration choices |

War goals should not become ordinary permanent expansion. They should be tied to a specific dossier, specific target conditions, and postwar obligations. The player should have to settle the land through wardship, release, or integration.

### World Household Enforcement line

This is the late branch the original package lacked. It should unlock after a political route finisher, a mature domestic pillar, and either a League, a ward network, or a successful Needful War.

| Focus role | Unlocks | Route-colored behavior |
| --- | --- | --- |
| Public Proof of the Good Place | late goal missions to demonstrate domestic success | peaceful routes need high Eutopia, coercive routes need compliant wards |
| The World Household Agenda | target category for exporting utopia | opens selected-country enforcement board |
| Offer the Table | peaceful invitation and aid packages | Free Household and Morean use consent and stores |
| Measure the Neighbor | survey and technical mission | Surveyor uses target ledgers and protectorate setup |
| Demand the Idle Land Answer | force-backed demand | Mandate uses ultimata and temporary war goals |
| Open the Daughter Commonwealth Office | puppet utopia creation decisions | subject forms depend on route |
| Enforce the Ward Constitution | postwar subject stabilization goals | all routes need compliance, stores, and local order |
| Export the Chosen Trades | subject trade reform missions | can help or coerce subject economy |
| Store Convoys Abroad | overlord support mission | costs trains, convoys, trucks, and civilian burden |
| The Utopian Settlement Congress | converts subject fate | integrate, release, League membership, or direct ward |
| The World Learns the Ledger | global diplomatic reaction and ideology pressure | high Eutopia helps, high Fracture alarms neighbors |
| Every Border Must Answer | late coercive escalation | Mandate and Outopia only, coalition risk |

## Puppet utopia branch

The focus tree should support puppet utopias as an actual late game system, not only cosmetic puppets. The branch can sit below the enforcement line and beside the convergence branch. It should be visible only after the player unlocks charter, wardship, or enforcement tools.

Suggested depth: 12 to 18 focuses.

| Focus group | Purpose | Unlocks |
| --- | --- | --- |
| Daughter Commonwealth Office | establishes subject creation doctrine | subject decisions and subject type choice |
| Local Ledger Missions | gives subjects their own local values | Local Stores, Local Consent, Vocational Acceptance, Dependence |
| Store Convoy Pledge | overlord support channel | recurring aid missions and dependency tradeoff |
| Household Guard Cadres | subject defense formation | subject unit growth and autonomy pressure |
| Ward Magistrates | direct administration | compliance, resistance, and Fracture tradeoff |
| Charter Elections | autonomy and legitimacy path | subject can become League member later |
| Surveyor Protectorate Boards | technocratic subject path | efficient but dependent subject |
| Mandate Provisions | coercive subject path | fast compliance and high revolt risk |
| No-Place Precincts | hidden subject path | strong control, high rupture risk |
| The Subject Appeals | creates correction or rebellion event family | prevents static puppets |
| The Settlement Congress | choose final status | integrate, release, maintain subject, or League member |
| Common Stores Across Borders | subject network payoff | shared resilience and League cohesion |
| The Perfected Ward | route-colored subject capstone | required for some ultimate endings |

The branch should make puppet utopias valuable but demanding. A puppet without stores and consent should drain the overlord, damage Eutopia, raise Fracture, and become unstable.

## Ultimate Utopia convergence branch

At some point all mature branches should connect. This does not mean every route becomes the same. It means every route must prove its version of Utopia through the same broad questions:

1. Can the society feed people through Common Stores?
2. Can people work without the system breaking them?
3. Can households live under a public law they understand?
4. Can the country defend itself?
5. Can land claims be justified or renounced?
6. Can foreign wards, allies, or subjects be treated as part of the same moral order?
7. Can the contradictions of the manifesto be answered?

### Convergence gates

The convergence branch should unlock through multiple proof paths. The exact scripted checks belong to implementation, but the design should require real progress.

| Gate | Peaceful proof | State proof | Coercive proof | Hidden proof |
| --- | --- | --- | --- | --- |
| Provision | high Stores and no emergency famine | strong state warehouses | compliant ward stores | forced stores with hidden Fracture cost |
| Work | high Vocational Freedom | measured assignments with audit | command trades with stable output | work without choice |
| Dwelling | housing and health projects | planned districts | ward resettlement | no-place households |
| Law | consent charters and plain laws | surveyor review boards | mandate courts | ledger law |
| Defense | household guard and border works | planned defense | mandate army | no-place security |
| Land | renounced false claims or fair charters | surveyed concessions | successful needful wars | rewritten need |
| Foreign | League members or charter subjects | protectorates with functioning ledgers | obedient wards | precinct network |

Examples include stronger League cohesion, stable store convoys, subject settlement options, faster consensual integration, stronger but riskier mandate enforcement, or high-chaos Outopia projection.

## Route-colored ultimate endings

The same late branch can produce several final identities. The player should feel that all branches connected, but the final meaning should depend on route record.

| Ending | Route basis | What changes |
| --- | --- | --- |
| Household Eutopia | Free Household with high consent and low Fracture | League and charter subjects become stable, claims decay faster, coercive tools limited |
| Corrected Commonwealth | Morean Council with audits and mixed institutions | broad balanced bonuses, strong correction events, subject appeals easier to resolve |
| Measured Commonwealth | Surveyor State with audited boards or high state capacity | strong project speed, technical protectorates, lower chaos from honest surveys |
| Mandate of Subsistence | Good Place Mandate with compliant wards | powerful enforcement, fast subject conversion, higher coalition and revolt risk |
| No-Place Mandate | Outopia with high Fracture and hidden proof | extreme map logic, special subject precincts, severe diplomatic fear |
| Renounced Utopia | any public route that repeatedly renounces false claims | smaller but very stable diplomatic ending with strong achievements |

The implementation should not let the player stack incompatible ultimate endings. The final capstone family should be mutually exclusive or should convert previous route variables into one visible final form.

## Late goals to enforce Utopia abroad

The late tree should unlock goals, not only buttons. These goals should ask the player to prove the project abroad through targets, subjects, convoys, state control, compliance, and diplomatic pressure.

| Goal family | Unlock source | Objective direction | Outcome |
| --- | --- | --- | --- |
| Demonstrate the Full Stores | Stores capstone | keep stores high while supporting at least one foreign target or subject | improves peaceful invitation odds |
| Establish a Charter Commonwealth | Consent or Morean diplomacy | convert a willing minor, released state, or war settlement into a charter subject | high autonomy puppet with local consent mechanic |
| Build a Surveyor Protectorate | Surveyor route | run local ledger, housing, store, and trade missions in a subject | efficient puppet with dependence mechanic |
| Enforce a Necessary Ward | Mandate route | win a needful war or ultimatum, then stabilize the ward before deadline | coercive puppet or integration route |
| Create a Daughter Commonwealth Ring | late convergence | maintain several utopian subjects or League members with working stores | unlocks ultimate diplomacy payoff |
| Correct a Failed Ward | any route with unstable subject | fix revolt, empty stores, or false trade rolls before deadline | avoids rupture and Fracture spike |
| Renounce the False Dossier | any route with invalid claim | revoke a bad claim and compensate the target or subject | lowers Fracture and improves Eutopia |
| Bring the Table to a Major | high late ambition | pressure a weakened major through league, subjects, or war outcome | very hard route, not normal AI default |
| The World Household Congress | ultimate branch | hold a congress while League, wards, or subjects meet standards | final global claim about Utopia |

These goals should use mission timers, active target caps, and dynamic costs. They should not become a list of political power purchases.

## Branch interaction rules

The final tree must make branches interact in visible ways.

| Interaction | Required design behavior |
| --- | --- |
| Politics and stores | political route changes store project cost, public trust, and foreign aid credibility |
| Politics and work | route determines whether Vocational Rolls are consent-based, measured, mandated, or hidden |
| Politics and military | route changes defensive doctrine, unit creation style, and war goal willingness |
| Politics and expansion | route changes whether targets receive charters, protectorates, wards, or precincts |
| Economy and expansion | full Stores reduce Land Need and make peaceful influence stronger |
| Military and expansion | mature defense unlocks credible guarantees, while mandate army unlocks stronger ultimata |
| Education and subjects | public law and teachers reduce subject instability |
| Land care and claims | domestic land improvement reduces unjust claims and should block bad dossiers |
| Subject success and convergence | stable puppet utopias count toward ultimate proof, failed puppets delay it |
| Fracture and capstones | high Fracture should corrupt late endings unless explicitly corrected |

## AI route behavior for the deeper tree

The AI should always accept the opening event, but its focus route should not be random. AI host behavior should use country condition and route safety.

| AI condition | Preferred route behavior |
| --- | --- |
| tiny democratic or high stability minor | Free Household or Morean, with consent charters |
| weak neutral country with poor industry | Surveyor State, with audited boards if stable |
| high chaos, low stores, threatened by neighbors | Surveyor or Mandate depending ideology and war pressure |
| fascist or authoritarian host | Good Place Mandate more likely, but not guaranteed |
| communist host | Free Household, Morean, or Surveyor depending state capacity |
| island country | stores, convoy, channel defense, and New Island proof earlier |
| landlocked country | inland island, rail defense, and land care earlier |
| country near majors | defensive and diplomacy branches prioritized before coercive enforcement |
| high Fracture AI | Outopia can reveal only under high chaos or desperation |
| subject network AI | prioritize store convoys and subject stabilization before more demands |
