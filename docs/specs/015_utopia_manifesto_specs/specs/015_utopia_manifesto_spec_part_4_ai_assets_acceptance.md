# Event 015, `utopia_manifesto`, AI, assets, achievements, super-events, and acceptance

## AI strategy overview

The event can target AI countries, and AI always accepts if eligible. That means the AI must be able to run the Utopian tree without human-only systems.

The AI needs:

- focus route preferences
- decision category behavior
- target safety checks
- integration cleanup
- League membership logic
- foreign reaction logic
- high-chaos exception behavior

## AI route matrix

| AI actor | Ordinary preference | Conditional preference | Avoids | Reason |
| --- | --- | --- | --- | --- |
| Eligible democratic minor | Living Humanism | Utopian League if surrounded by friendly minors | Marked Bounds | public consent and diplomacy fit the government |
| Eligible communist or socialist minor | Guild Commonwealth | Common Store State if industry is very weak | Island Discipline if safe | useful labor and councils fit the ideology |
| Eligible neutral monarchy or paternal state | Island Discipline | Living Humanism if high stability and low threat | Guild radicalization unless labor pressure high | reform under guardianship fits the state |
| Eligible fascist or radical authoritarian minor | Island Discipline or Common Store State | Marked Bounds at high chaos and severe Need | Living Humanism | order and compulsion fit the government, but target safety still matters |
| Subject minor | Common Store State | Living Humanism if overlord relations are high | Marked Bounds before autonomy | storehouses prove capacity for autonomy |
| Island minor | Island Discipline plus Common Stores | League if nearby minors exist | landlocked port branch | geography supports the shore route |
| Landlocked minor | Common Store State plus Inland Island | Needful Port if Need is high and target is weak | naval content | rails and supply ring replace literal island mechanics |
| Tiny one-state minor | Living Humanism or Common Store | defensive Island branch if threatened | early claims | survival and diplomacy matter before expansion |

## AI focus behavior

AI should pick opening focuses in a survival order:

1. census and first storehouse
2. public reading or storekeeper commission based on stability and ideology
3. route opener
4. common stores or defense if threatened
5. vocation branch if economy stable
6. diplomacy if Surplus positive
7. Needful Land only if Need is high and target safety is acceptable
8. late proclamation only after route requirements are stable

AI should not rush Marked Bounds just because it is visible. The route should require high Need, high chaos, high threat, or high authoritarian weight.

## AI decision behavior matrix

| Value state | AI priority | AI should avoid |
| --- | --- | --- |
| Need above 75 | storehouses, rural rotation, defensive supply, emergency allocation if Consent safe | foreign aid and unnecessary claims until domestic Need is identified |
| Consent below 35 | public readers, councils, voluntary vocation, stop compulsion | forced assignments, Marked Bounds, needless wars |
| Surplus above 65 | aid, observers, storehouse upgrades, League | overbuilding stores that create no new choices |
| Surplus below 30 | domestic storehouses, infrastructure, production, fewer aid shipments | League expansion and mercenary spending |
| Overreach above 60 | repair, observers, renunciation, local councils | new claims, forced settlement, indirect war |
| Foreign Suspicion above 60 | observers, defensive posture, aid, pause claims | League rush and war goals |
| Vocation Balance below 45 | apprenticeships and second trade | urgent service unless war or severe Need |

## Foreign AI reactions

Foreign countries should react through decisions, events, or AI strategies.

### Nearby minors

- accept aid if relations are not hostile
- accept observer status more often from low-overreach Utopian states
- resist magistrates if ideology is hostile or suspicion high
- join League only after Friend status and confidence checks

### Nearby majors

- ignore or mock early harmless experiments
- increase watchfulness if Utopian country gains claims
- guarantee threatened minors if Utopian Overreach is high
- sponsor rivals if Marked Bounds expands too quickly
- accept defensive cooperation only if common enemy exists

### Overlords

- allow common store reforms if subject remains stable
- resist autonomy if subject uses the manifesto to organize independence too fast
- crack down or grant autonomy based on relation, ideology, war pressure, and subject contribution

### Faction leaders

- treat peaceful Utopian League formation as diplomatic competition
- treat Marked Bounds as regional threat if several claims or forced integrations happen
- may invite the Utopian country if it stays defensive and useful

## Formable and cosmetic identity planning

The event should include late identity routes, but implementation can use cosmetic tags if full tag switching would be too disruptive.

### New Utopia

Public map name direction: `New Utopia`, `Utopian Republic`, `Utopian Commonwealth`, or route-appropriate equivalent.

Requirements:

- accepted manifesto
- late proclamation branch complete
- high Consent
- high Surplus
- stable Vocation Balance
- Overreach below a safe threshold
- completed geography requirement, either island or coastal network, inland ring, federated port partner, or subject autonomy route
- no active Marked Bounds crisis

Effects:

- cosmetic identity and flag
- upgrade main national spirit to a mature route form
- unlock final integration, diplomacy, and League tools
- possible super-event if it changes regional order

### Utopian League

Public name direction: `Utopian League` or a country-specific league name that remains readable.

Requirements:

- minimum Friends or eligible member countries
- high Surplus or high Consent
- Foreign Suspicion below danger threshold unless hardline variant
- at least one successful aid or arbitration chain

Effects:

- faction or coalition with cohesion mechanic
- shared aid and defense decisions
- League member confidence
- super-event if major enough

### Marked Bounds State

Public name direction should stay direct. Do not use internal office names. Possibilities include `Utopian Commonwealth`, `Utopian State`, or original country name with hardline route adjective if localised well.

Requirements:

- Marked Bounds route complete
- high Overreach
- at least one forced integration or several marked claims
- military capacity to defend backlash

Effects:

- hardline cosmetic flag or spirit
- stronger claims and harsher integration tools
- major foreign suspicion
- possible dark-route super-event if it becomes a regional threat

### Formation safeguards

- no instant cores on all claims
- no formation if country is a puppet unless route permits subject formable through consent or independence
- no formation while capital lost
- no formation if active civil crisis or unresolved Marked Bounds backlash blocks it
- AI requires route-specific safety checks

## Starting forces and reinforcement pathway

The event does not spawn a new country at acceptance, but it does create a new military identity. Military growth must be dynamic and grounded.

### Unit families

| Unit family | Unlock | Source | Requirements | Role |
| --- | --- | --- | --- | --- |
| Household Guard | early defense branch | local militia and household service | infantry equipment, manpower, Defense vocation, state control | defensive infantry |
| Storehouse Engineers | common store and military support | civic engineers and railway crews | support equipment, trucks or trains, army XP | entrenchment, repair, logistics support |
| Harbor Watch | coastal or island branch | sailors, port guards, fishermen | infantry equipment, convoys, port states | coastal defense |
| Inland Ring Guards | landlocked branch | railway guards and pass detachments | trains, infantry equipment, supply hubs | rail and pass defense |
| Craft Militias | Guild route | factory and guild volunteers | infantry equipment, support equipment, Vocation Balance | flexible defense or light infantry |
| Hired Companies | Treasury Abroad focus | foreign mercenaries | Treasury variable, convoys, equipment, Suspicion cost | temporary expeditionary force |
| League Volunteer Cadres | League branch | member volunteers and instructors | Friend or League members, equipment, command capacity | allied reinforcement |
| Surveyor Columns | Needful Land or Marked Bounds | boundary surveyors and guards | army XP, trucks or cavalry equipment, Overreach risk | border and occupation support |

### Dynamic scaling

Unit creation should scale with:

- number of controlled core states
- manpower pool
- infantry equipment stockpile
- Vocation Defense share
- current war state
- chaos tier
- route and focus completion
- whether the country is coastal, island, landlocked, or subject
- whether the target state is threatened

Weak countries receive fewer but cheaper units. High-chaos or threatened countries can receive more emergency units, but equipment cost and Consent risks should also rise.

### Reinforcement pathways

The tree should not rely on one-time spawns. Reinforcement should come from:

- Household Guard missions
- apprenticeship and craft militia decisions
- defensive drill focuses
- storehouse engineer projects
- League volunteer missions
- hired companies with high cost
- integration of local defense committees in newly administered states
- port or rail guard missions after geography branch

## Super-event package direction

The initial event does not use a super-event. Late route outcomes can deserve one.

### Super-event candidate A, New Utopia proclamation

Role: ideological transformation and regional order announcement.

Trigger direction:

- country proclaims New Utopia or Utopian Commonwealth
- high Consent and Surplus
- stable Vocation Balance
- low Overreach
- geography condition complete
- at least one meaningful external recognition, League member, or integration success if the country has grown beyond a one-state minor

Presentation direction:

- title direction: short, specific, public recognition of a strange new commonwealth. Research required before final title
- description direction: describe public relief, common stores, household councils, and foreign observers trying to understand whether the experiment can last
- quote direction: More, humanist, civic, or public-domain political thought about commonwealth, need, or justice. Research required
- button remark direction: restrained cultural or literary allusion. Research required
- audio mood: solemn civic procession, early modern or choral influence, hopeful with unease. License research required
- image direction: generated super-event image, period civic square or harbor, manuscript and storehouse symbolism, no readable generated text

### Super-event candidate B, Marked Bounds doctrine

Role: dangerous ideological reveal and regional escalation.

Trigger direction:

- Marked Bounds route completed
- Overreach very high
- multiple forced integrations or marked claims
- at least one foreign power has reacted, guaranteed a target, or formed an opposing conference

Presentation direction:

- title direction: short and specific, showing the boundary doctrine becoming public. Research required before final title
- description direction: describe boundary markers, surveyors, guarded settlement columns, and neighboring states changing posture
- quote direction: public-domain source about justice, land, conquest, or false necessity. Research required
- button remark direction: grim, not comic. Research required
- audio mood: tense march, austere strings, or dark civic hymn. License research required
- image direction: generated super-event image with boundary posts, old manuscript symbolism, and troops or surveyors. Avoid modern flags, modern uniforms, and readable text

## Achievements overview

Achievements are mandatory because this is a deep event with focus routes, mechanics, formables, and rare outcomes. Full details are in the achievement prompt. Planned achievement families:

- complete the peaceful New Utopia route as a minor
- create the Utopian League without high Overreach
- gain land through arbitration and integration without offensive war
- survive and reform after opening Marked Bounds
- complete the six-hour ambition while keeping Vocation Balance stable
- as a landlocked country, complete the Inland Island route and secure a port or rail ring
- win a defensive war with Household Guards and low own casualties
- send aid to several Friends without collapsing domestic Surplus
- form a hardline Marked Bounds state and survive the foreign backlash
- keep all five vocation tracks viable for a long period

Achievements should be difficult and route-spanning. Do not unlock an achievement merely for accepting the manifesto.

## Acceptance criteria

The event is not complete until:

- event ID 15 is Minor Fire-Once and no longer World Tension Subsides
- AI acceptance is guaranteed for eligible AI targets
- player rejection path exists and cleanly blocks Utopian systems
- major and strong countries are blocked
- event list shows `N/A` when no valid target exists
- accepting country receives the Utopian replacement tree only for that country
- focus tree includes real political, economy, military, diplomacy, expansion, geography, and late branches
- Utopian Ledger values are visible and changed by decisions, focuses, missions, wars, and state control
- decisions use concrete costs and objectives beyond political power
- occupation and integration do not grant instant free cores
- Need claims are gated and safe for AI
- Vocation Accord creates choices and shortages
- route-specific AI exists
- assets are planned, created, converted, and wired before final completion
- super-event research gates are respected if late super-events are implemented
- achievements are implemented with tracking and icons
- docs/events and catalog workbook align with final in-game text
- focus, decision, localisation, country package, and completion audits run after implementation

## Known uncertainties for implementation

- Final factory and division thresholds need testing against the actual active event pool.
- Exact state scoring for `unused` or `underused` land needs a scripted trigger design that does not rely on morally loaded assumptions alone.
- HOI4 does not model food directly, so agriculture and common stores must use infrastructure, supply, consumer goods, factories, convoys, trains, equipment, manpower, and state modifiers.
- If the scripted GUI window proves too heavy for first implementation, the decision category header must still show all values clearly. That would be a simplification and must be reported before claiming completion.
- Late super-events require real quote, cultural remark, and audio research before localisation and audio wiring.
