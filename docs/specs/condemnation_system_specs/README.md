# Condemnation system specifications

The source design is [`specs/condemnation_impact_system_spec.md`](specs/condemnation_impact_system_spec.md). The implementation prompt is in [`prompts/condemnation_impact_goal_prompt.md`](prompts/condemnation_impact_goal_prompt.md).

The user's explicit 2026-09-20 CBRN implementation request additionally accepts a 0–1000 Condemnation range, an equipment multiplier of `1 + C/500` rounded up to whole equipment, and a 5–15% consumer-goods inspection burden for 180 days. These limits are accepted design, with implementation and validation pending the owner handoff and final source review; they supersede any conflicting older tuning proposal.

The broader expansion remains unresolved for acceptance wherever no attributable user decision or parent acceptance is recorded.
The tuning amendment alone does not establish approval or completion of every proposed sanction, UI or evasion route.

Current shared-system documentation is in [`docs/systems/cbrn_warfare/condemnation/condemnation_sanctions.md`](../../systems/cbrn_warfare/condemnation/condemnation_sanctions.md).
