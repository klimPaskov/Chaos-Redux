# Route transition map

This is an author-facing execution map for Parts 1–6 and 9. Counts are internal records, not public meters. A main acceptance means an explicit adopted principal arrangement whose promised delivery is secured.

## Historical acceptance and surviving leverage

Historical acceptance is not the same as current effective leverage. Successfully dismantling a protected institution can weaken a revolt without rewriting the country's history as “never signed.” A completed early closeout closes the principal relationship; it does not leave a resettable reward ladder.

## Conflicts to reject

Reject any path that permits peaceful possession at four acceptances, creates human collaborators after total clean refusal without a separate established cause, starts an opening civil war after five valid acceptances, duplicates the original parent through a foreign or Event 019 route, or hides a one-state substitute behind a successful route label.
