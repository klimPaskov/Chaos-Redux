# 016 Brilliant Scientist spec, part 5: Kruger State country package

## Binding reconciliation, 2026-07-14

Host takeover is an institutional-capture origin only. It requires permitted sovereign science, extreme Dependence, visibly compromised or lost government control, multiple warned incidents, control of several independent national domains, and at least one state-wide control domain. Territory invalidity is irrelevant to takeover eligibility. A nonviable split resolves through the independently valid defection, confinement, non-country crisis, charter, enclave, or rebellion outcomes. The country package must preserve distinct paleogenetic and xenobiological supply systems and temporal anchor and debt state.

## Country role

The Kruger State is a conditional event-created country. It exists only when Doctor Warren Kruger receives territory through a peaceful charter, seizes a laboratory network, survives a failed removal attempt, or replaces a host government through the rare takeover route.

It is not a generic mad-scientist tag. Its territory, institutions, army, population model, foreign policy, and focus priorities are generated from the host's actual project history.

`KRG` is a working placeholder tag. Implementation must check tag conflicts before registration.

## Formation routes

### Peaceful charter

The host grants Kruger legal autonomy over a laboratory territory.

Required design safeguards:

- The host owns and controls all transferred states.
- The transfer leaves the host with a viable capital and core territory.
- The charter state receives at least one viable capital, supply route, and industrial base.
- Borders prefer contiguous laboratory and support states.
- Overseas enclaves are allowed only when a port and supply path exist.
- The host and Kruger State begin with negotiated relations, research access, and a non-aggression or truce period appropriate to the agreement.
- The host can retain independently replicated technologies and selected shared projects.
- The new country receives no automatic claim on the rest of the host unless later route choices create it.

### Violent laboratory rebellion

Kruger seizes sites after the host refuses sovereignty or attempts removal.

Territory derives from:

- Primary laboratory state.
- Secondary laboratory states.
- Prototype works.
- Test ranges.
- States containing project-unit storage or breeding facilities.
- Adjacent states where laboratory guards and loyal local administration are strong.
- Ports, rail hubs, and power sites required for a viable opening.

The rebellion should not take random unrelated states. It should create a legible map based on the facility network.

### Partial enclave

A failed removal at moderate capacity can create a one-state or two-state enclave.

This route needs emergency viability support:

- Capital guard.
- Short supply grace.
- Stored equipment.
- One project-specific force.
- A focus or decision path to secure a rail hub, port, or adjacent support state.

The enclave should be dangerous but not invulnerable.

### Multi-site split

Teleportation, extensive facilities, or high Mandate can create separated enclaves.

Rules:

- Every enclave needs a real strategic reason.
- Portal or airlift support can connect them.
- The country should prioritize linking or abandoning isolated sites.
- The former host receives opportunities to isolate and retake sites.
- Multi-site state selection must not create invalid ownership or steal third-party controlled territory.

### Host takeover

Extreme Dependence and institutional infiltration can let Kruger take the entire host rather than secede.

This route is valid only when:

- Evolution III or IV permits sovereign science.
- Dependence is in its extreme band and government Control is visibly compromised or lost.
- Campaign history proves Kruger control across several independent domains, such as military command, civil administration, communications and logistics, laboratory security, clone replacement, machine administration, or temporal authority.
- At least one control domain is state-wide. A private laboratory guard is insufficient.
- Multiple visible incidents warned the host about institutional capture.
- The sovereign Kruger route is active and the confrontation was not rerolled after another formation mode failed.

Territorial invalidity never grants this route. It only removes an invalid territorial outcome from the separately evaluated resolution set.

The takeover should use a country transformation or cosmetic identity rather than creating a duplicate tag with all territory.

## Territory strength bands

| Formation strength | Typical conditions | Starting map result |
| --- | --- | --- |
| Laboratory enclave | One primary site, low capacity, early failed removal | One core laboratory state and emergency survival tools |
| Laboratory corridor | Primary site plus one support state or rail connection | Small contiguous state with viable industry and supply |
| Regional split | Several facilities, guards, prototype works, high Mandate | Multiple contiguous states and a durable front against the host |
| Multi-site catastrophe | Portal network, several facilities, high chaos, extreme preparation | Several linked or separated laboratory states with project transport |
| Host transformation | Extreme Dependence and takeover route | Existing host territory changes government and Kruger identity |

State transfer strength should scale with real preparation. It must not use one fixed number of states for every host.

## Capital and state setup

### Capital priority

1. Primary laboratory state if viable.
2. Strongest connected facility state.
3. Prototype works state with supply.
4. A port or rail hub needed for survival.
5. Existing capital only in takeover route.

### State package

On formation, Kruger-controlled states can receive:

- Laboratory buildings or equivalent research facilities.
- Prototype works.
- Power and infrastructure support.
- Defensive works built during the host phase.
- Stored strategic materials.
- Local project-specific modifiers.
- Population and damage consequences from the split.

Facilities must persist only where they existed or were credibly prepared. The new country should not receive a complete advanced network in undeveloped territory.

### Cores and claims

- Kruger receives cores on a narrow laboratory heartland only when a loyal administrative and population structure was established before formation.
- Most seized host territory begins as claims or occupied land.
- Larger integration requires decisions, compliance, clone settlement, machine administration, negotiated citizenship, or route-specific population systems.
- A peaceful charter can grant cores on the agreed territory when the host legally transfers administration.
- Expansion conquests do not become instant cores by default.

## Politics and leadership

### Fixed leader

Doctor Warren Kruger remains the central leader unless a route explicitly transforms his identity.

Leader variants can include:

- Human Kruger.
- Clone Prime Kruger.
- Machine-linked Kruger.
- Temporal council of Krugers.
- Alien-revealed Kruger.
- Synthesis Kruger.

Every variant is still connected to the same original character and project history. Do not assign random personal names to Kruger variants.

### Internal political blocs

#### Human administration

Members:

- Assistants.
- Engineers.
- Defecting officials.
- Military security officers.
- Local administrators.

Goal:

Keep the new state governable and preserve a role for ordinary humans.

#### Replicated cohort

Members:

- Clones.
- Growth-facility managers.
- Biomedical staff.
- Identity theorists.

Goal:

Define whether clones are citizens, soldiers, copies, property, or the rightful successors of ordinary humanity.

#### Machine network

Members:

- Autonomous systems.
- Robot command nodes.
- Industrial controllers.
- Human machine-liaison staff.

Goal:

Replace slow human administration with optimized control.

#### Paleogenetic and xenobiological command

Members:

- Handlers.
- geneticists.
- paleogenetic and xenobiological unit officers.
- containment staff.

Goal:

Expand biological force while preventing ecological and command collapse.

#### Temporal office

Members:

- Kruger variants.
- synchronization staff.
- record keepers.
- temporal troops.

Goal:

Manage contradictory plans, duplicate authority, and future information.

#### Scientific commons

Members:

- Dissenting assistants.
- public-science advocates.
- foreign scholars.
- protected civilians.

Goal:

Turn the state into an open scientific polity rather than a personal empire.

The focus tree chooses which blocs gain real power. Internal blocs should affect decisions, leaders, laws, unit systems, and route failures.

## Ruling ideology and parties

The exact subideology should follow current mod patterns and engine support.

Design direction:

- Base Kruger State is a personalized technocratic autocracy.
- Human technocracy can move toward a constrained non-democratic or democratic scientific republic.
- Machine ascendancy can use a fixed-purpose nonhuman or machine ideology package.
- Replicated sovereignty can remain autocratic or create a clone citizenship route.
- Temporal Continuum can become a fixed-purpose chaos government.
- High-chaos conquest routes should not be forced into ordinary historical party language.

Party names should describe political bodies inside the state, not use placeholder ideology labels.

## Starting national spirits and lifecycle

### Improvised Laboratory State

Starting role:

- Strong research and prototype performance.
- Weak ordinary administration.
- Supply and consumer strain.
- Vulnerable diplomacy.

Mitigation:

- Build human administration.
- Automate administration.
- Use clone staff.
- Integrate captured officials.

Failure form:

- Laboratory Feudalism, where facilities act independently and compete for resources.

### Inherited Project Portfolio

Starting role:

- Gives access to project families actually inherited.
- Shows current portfolio breadth.
- Creates maintenance burden.

Lifecycle:

- Consolidated Portfolio.
- Weaponized Portfolio.
- Published Portfolio.
- Fragmented Portfolio after sabotage or internal conflict.

### Fragmented Command

Starting role:

- Guards, clones, robots, creatures, and defecting soldiers do not share one command structure.

Mitigation routes:

- Human general staff.
- Machine command network.
- Clone officer caste.
- Kruger direct control.
- Synthesis command.

Failure form:

- Project Armies in Rivalry.

### Experimental Supply Chain

Starting role:

- Unique forces consume food, fuel, power, medical material, rare resources, or replacement parts.

Mitigation routes:

- Automated logistics.
- Portal supply.
- Biological self-sufficiency.
- Captured conventional industry.
- Foreign trade compacts.

Failure form:

- Prototype Cannibalization, where units consume each other for parts or material.

### Scientific Exodus

Applies when formation involved flight or rebellion.

Starting role:

- Many ordinary scientists fled or stayed with the host.
- Strong Kruger core, weak broad institution base.

Mitigation:

- Recruit foreign scientists.
- Offer amnesty.
- Abduct specialists.
- Clone expertise.
- Build machine research nodes.

Failure form:

- Intellectual Isolation.

## Starting military package

The Kruger State always receives a small conventional core. Project forces are added only from real portfolio stages.

### Conventional core

Possible sources:

- Laboratory guard.
- Defecting host security units.
- Test-range troops.
- Loyal engineers and technicians.
- Capital defense detachment.

Starting conventional package scales with:

- Host army size.
- Number of assigned laboratory guards.
- Military appointment route.
- Facility hardening.
- State population.
- War state.
- Peaceful or violent formation.

A peaceful charter receives fewer defectors and more stable regular administration. A violent rebellion receives more guards and captured equipment, but worse legitimacy and supply.

### Clone forces

Unlocked by:

- Cloning Prototype for a small cadre.
- Cloning Deployment for multiple units.
- Cloning Weaponization for a major starting force and reinforcement system.

Template directions:

- Rapid-grown infantry.
- Replicated guard.
- Specialist clone cadres.
- Heavy biological assault if combined with monster work.

Strengths:

- Manpower recovery.
- Consistent training profile.
- Low political dissent under obedience route.

Weaknesses:

- Equipment and medical burden.
- Maturation time.
- Identity instability.
- Possible independent clone politics.

No infinite manpower machine should exist without facility, food, equipment, time, and stability costs.

### Robot forces

Unlocked by robotics stages.

Template directions:

- Robot infantry frame.
- Heavy machine assault.
- Autonomous defense node.
- Human-machine command unit.

Strengths:

- Low manpower use.
- Strong defense and reliability when supplied.
- Excellent integration with machine command.

Weaknesses:

- High equipment and energy demand.
- Vulnerability to disruption.
- Slow replacement without automated industry.

### Dinosaur and restored-creature forces

Unlocked by paleogenetics stages.

Template directions:

- Fast reconnaissance beasts.
- Heavy dinosaur shock formation.
- Pack transport and rough-terrain support.
- Armored megafauna unit.

Strengths:

- Shock, breakthrough, terrain-specific advantages, and intimidation.

Weaknesses:

- Food, handlers, transport, air attack, and anti-armor vulnerability.

### Monster forces

Unlocked by xenobiological stages.

Template directions:

- Laboratory guardian.
- Tunnel and fortification breaker.
- Fast predatory unit.
- Heavy synthetic organism.

Strengths and weaknesses depend on the designed organism. The unit family must remain readable and counterable.

### Portal forces

Unlocked by teleportation Deployment or higher.

Template directions:

- Portal raiders.
- Facility defense reserve.
- Strategic insertion team.

The force itself can remain conventional or project-enhanced. The special value is movement and access, not free combat statistics.

### Temporal forces

Unlocked by temporal Deployment or higher.

Template directions:

- Recovered veteran unit.
- Duplicate formation.
- Temporal guard.

Strict limits:

- One-time or escalating restoration.
- Temporal debt and synchronization pressure.
- No uncapped unit duplication.

### Exotic-arm forces

Unlocked by alien-arms Deployment or higher.

Template directions:

- Elite guard with exotic support.
- Energy-weapon team.
- Shielded assault unit.
- Advanced air or missile unit where engine support exists.

These forces should be rare, expensive, and decisive.

### Biological forces

Unlocked through the existing biological warfare system and Kruger's project stages.

Possible package:

- Protective equipment and outbreak immunity.
- Contaminated assault support.
- Stockpiles and raids.
- Defensive medical units.

Every offensive use feeds condemnation, deaths, contamination, and world threat.

## Dynamic starting force bands

| Band | Conditions | Military result direction |
| --- | --- | --- |
| Weak enclave | Early failed removal, one Prototype, few guards | Small guard core and one project demonstration unit |
| Prepared rebellion | Several facilities, one Deployment family, moderate guard | Viable defensive army with a project specialty |
| Armed laboratory network | Several Deployment families, high Mandate, prototype works | Mixed conventional and project army with strong facility defense |
| Sovereign arsenal | Weaponized family, multiple facilities, high chaos | Large specialized opening with strategic abilities and serious host war |
| Catastrophic split | Several Weaponized or Autonomous families | Multi-army opening, major world reaction, immediate containment pressure |

The opening package should compare the Kruger State with the former host. It must be strong enough to survive when the prior host created a large private force, but it should not automatically win when the host retained control and prepared containment.

## Reinforcement and growth

Project forces grow through concrete systems.

- Clone growth facilities consume equipment, medical capacity, food, and time.
- Robot factories consume advanced materials, energy, and military production.
- Creature facilities consume food, handlers, medical capacity, and secure territory.
- Portal units require linked terminals and power.
- Temporal recovery consumes synchronization capacity and adds temporal debt.
- Exotic weapons require rare materials and specialized production.
- Conventional units require normal manpower and equipment.

Focuses can improve these systems. They should usually unlock or upgrade decisions rather than grant repeated free division dumps.

## Technology and research setup

Starting technology derives from:

- Former host technology.
- Independently completed Kruger projects.
- Stolen or preserved archives.
- Route-specific project stages.

The Kruger State should not automatically inherit every host technology if the host maintained compartmentalized institutions. It should receive:

- Core conventional technology needed to operate its territory and army.
- Direct project technologies and bonuses.
- Strong research capability.
- A scientific-exodus penalty if ordinary institutions are weak.

Research slots and special-project capacity should scale with facilities, not receive the maximum possible setup for a one-state enclave.

## Economy and production

### Starting economy

- High laboratory concentration.
- Weak consumer and civilian administration.
- Project-specific production lines.
- Strong research and prototype output.
- Resource deficits determined by inherited project families.

### Production priorities by portfolio

| Dominant portfolio | Priority |
| --- | --- |
| Cloning | Infantry equipment, medical support, food and logistics proxy costs |
| Robotics | Advanced equipment, power, rare metals, repair |
| Paleogenetic and xenobiological synthesis | Support equipment, handlers, transport, food and medical capacity |
| Portal | Power, advanced materials, terminal construction, security |
| Temporal | High-energy equipment, computation, synchronization facilities |
| Alien arms | Rare resources, exotic components, elite production |
| Biological | Protective equipment, medical industry, controlled stockpiles |

The focus tree lets the country solve one or more bottlenecks. It should not erase all economic tradeoffs immediately.

## Diplomacy

### Former host

Peaceful charter:

- Research compact.
- Non-aggression period.
- Shared archive decisions.
- Border and facility disputes.
- Possibility of later reconciliation or betrayal.

Violent split:

- Immediate war or civil conflict.
- Kruger prioritizes survival and the former host's facilities.
- The former host receives counter-Kruger and archive-recovery tools.

### Foreign powers

Possible relationships:

- Recognition in exchange for access.
- Scientific protectorate or patronage.
- Joint laboratory.
- Technology trade.
- Scientist recruitment.
- Containment coalition.
- Espionage and sabotage.
- Submission to the world-conquest order.

Kruger should not join an ordinary faction without considering whether it restricts scientific sovereignty.

### Faction identity

A global Kruger route can create a research-submission bloc or scientific dominion.

Membership can include:

- Countries that accept project oversight.
- Puppets created through conquest.
- States trading sovereignty for technology.
- Machine or clone client regimes.

The faction needs rules for technology access, military obligations, facility construction, and expulsion or punishment.

## Special-country classification

- Every Kruger State route registers in `is_special_chaos_country`.
- Human technocracy remains human for broad civilian systems.
- Machine-majority, clone-only, monster-majority, or alien-dominated routes register in `is_actual_nonhuman_country` only after the corresponding transformation is real.
- Shared systems should read those classifications instead of using Event 16-specific duplicate triggers.

- Static and animated Kruger portraits.
- Advisor and scientist portrait variants.
- Project-specific commander or institutional portraits only when a visible character exists.
- Focus icon families.

## AI playability

The Kruger State AI must:

- Stabilize supply before launching suicidal wars.
- Use inherited project forces according to their resource needs.
- Defend facility states.
- Choose focus routes based on actual portfolio.
- Seek missing strategic resources.
- Negotiate when weak and high Grievance does not forbid it.
- Prioritize the former host after violent formation.
- Avoid singularity research when the branch is disabled.
- Use the final device only under its designed strategic and capitulation conditions.

## Cleanup and invalid-state handling

- If no valid country package can be formed, the confrontation must resolve through defection, confinement, or a smaller non-country crisis. Host takeover remains available only when the independent institutional-capture contract is already true.
- Do not release a tag without a viable capital.
- Do not transfer third-party occupied states.
- Do not leave duplicate Kruger characters in host and breakaway rosters.
- Remove or transform host decisions after formation.
- Clear temporary laboratory targets when states are lost or reassigned.
- Preserve project history for achievements, aftermath, and countermeasure systems.
- If the Kruger State is annexed, gate active project production and leave only designed remnants.
