# Event 16 Brilliant Scientist, country package identity matrix

All country names and party labels in this file are working labels, not final localisation. Public map names should remain direct and readable. Internal offices, boards, commands, and laboratories should remain inside parties, ideas, focuses, decisions, and institutions.

## Kruger country package principle

The Kruger country should be a complete playable chaos country when it exists for more than a short revolt. It needs tag registration, map setup, history setup, leader identity, starting politics, flags, starting ideas, army package, reinforcement paths, focus tree, AI, localisation, and documentation. The package should scale from the host’s earlier choices.

The final tag must be chosen after repository inspection. This uses `KRG` only as a planning placeholder.

## Dynamic spawn strength formula

The starting strength should read the host history.

- Base guard strength comes from Security Integrity, military lab memory, and loyal guard decisions.
- Rebel conversion strength comes from Laboratory Autonomy, sealed city memory, private procurement memory, and hidden stockpile memory.
- Project army strength comes from clone, robot, specimen, xenotech, temporal, and nuclear memories.
- Host mitigation subtracts evacuation success, prototype destruction, peer review success, and emergency chain-of-custody success.
- Country Scale Band shapes equipment and factory capture. A major host creates a larger but more visible Kruger state. A minor host creates fewer units but can suffer a sharper relative loss.

Use weak, normal, severe, and extreme opening packages:

| Opening package | Trigger direction | Starting military direction |
| --- | --- | --- |
| Weak secession | low Autonomy, high Leverage, few risky memories | lab guards, a few militia divisions, weak equipment, no major project army |
| Normal secession | medium Autonomy and one or two project memories | guard infantry, technician companies, one project unit family |
| Severe secession | high Autonomy, sealed city, multiple risky memories | regular guards, prototype divisions, strong capital defenses, several project unit families |
| Extreme secession | host gave legal exemptions, sealed city, clone or robot or specimen program, plus nuclear or temporal route | major army, strong industry capture, route-specific elite forces, final-device eligibility if prerequisites exist |

## Country package cleanup

If Kruger dies, defects, is contained, or is annexed, cleanup should resolve the country package cleanly:

- remove or disable Kruger-specific advisor roles from countries that no longer have him
- clear active project decisions and component missions that require his country
- preserve safe captured-knowledge aftermath choices for victors
- keep project history for achievements and future event reactions
- classify remaining nonhuman units or escaped specimens through shared systems if they persist
- remove country cosmetic route flags only when the tag no longer exists or the route has been replaced by a postwar settlement
