# 016 Brilliant Scientist spec, part 4: evolutions and event chain

## Binding reconciliation, 2026-07-14

International recognition remains a conditional super-event package. Evolution II alone is insufficient; a verified global-relevance threshold is required. Host takeover is a rare institutional-capture culmination, not an alternative selected because a territorial split is invalid. The chain must also resolve one evidence-gated origin conclusion or preserve the unresolved state, and must record temporal debt, anchors, stabilization, and terminal commitment transitions where those routes are active.

## Evolution structure

Event 16 has four true evolutions. Ordinary appointment, laboratory growth, project approval, and confrontation remain baseline progression.

| Evolution | Normal chaos band | Identity change |
| --- | --- | --- |
| Evolution I | Gathering Storm | Kruger becomes a national institution and policy begins forming around him |
| Evolution II | Rising Chaos | Kruger becomes an international strategic asset and foreign powers act directly |
| Evolution III | Chaos Tier | His research becomes visibly strange, dangerous, and capable of creating autonomous power |
| Evolution IV | Totalen Chaos | Sovereign science and world conquest become available, with a strategic-singularity endgame |

World Collapse is a terminal eligibility state. It is not Evolution V.

Each evolution needs two entry paths.

- Active-event evolution changes a host that already employs Kruger.
- Pre-fire evolved opening changes the first appointment package when Event 16 has not fired yet and the world is already chaotic enough.

Evolution timing should normally use dynamic MTTH centered around roughly 90 days after conditions become valid. It can be shorter when the host has already created the matching state and longer when the relevant project, fame, or exposure is weak.

## Evolution I: national scientific ascendancy

### Core change

Kruger stops being one extraordinary advisor and becomes the organizing principle of national science. Ministries, universities, firms, armed forces, and newspapers begin competing for access.

### Active-event entry conditions

Possible condition set:

- Event 16 is active in a host country.
- Evolution I is enabled.
- The appointment has lasted long enough for institutional effects to appear.
- At least one project has reached Theory or Prototype, or the host has invested heavily in facilities.
- Kruger has enough fame, Mandate, or Dependence to become nationally important.

The evolution should not require high Mandate only. A public-science host can trigger it through fame and institutional spread.

### Active-event immediate changes

- Record Evolution I with the host as actor.
- Upgrade Kruger's portrait to the first evolved stage.
- Open the full directorate interface if it is not already open.
- Expand university, industrial, military, and assistant decision families.
- Add a national policy event about funding and oversight.
- Increase project capacity through a route-appropriate mechanism.
- Create a public reputation state that affects future foreign interest.
- Let the host select or confirm a scientific governance model.

### Pre-fire evolved opening

When Event 16 first fires in a world already eligible for Evolution I:

- Kruger arrives with published or rumored results already circulating.
- The selected host immediately faces university and military competition for his appointment.
- The opening can select the primary laboratory and governance model in the first event sequence.
- He begins with one completed conventional Theory stage chosen from host context.
- The first portrait remains close to the baseline portrait but carries the first subtle anomaly.
- Evolution I is recorded after appointment, not before a host exists.

### National policy routes

#### Public scientific renaissance

- Build a distributed research network.
- Publish reproducible methods.
- Improve conventional science, medicine, electronics, and industry.
- Lower long-term Dependence.
- Increase prestige and foreign observation.

#### Strategic national laboratory

- Concentrate resources in a protected facility.
- Accelerate military and impossible prototypes.
- Raise Mandate and Dependence.
- Create a stronger future laboratory enclave.

#### Industrial scientific concession

- Connect firms and factories directly to Kruger.
- Accelerate prototype production and advanced materials.
- Create patent, labor, corruption, and foreign-commercial events.

#### University confederation

- Let several institutions share the work.
- Improve assistant recruitment and independent replication.
- Slow concentrated secret projects.
- Create institution-specific rivalries and regionally distributed facilities.

### Evolution I event families

#### Universities compete for Kruger

Player choice direction:

- Concentrate work in one favored institution.
- Rotate grants.
- Let Kruger select personnel.
- Create a national council.

Effects:

Move Mandate, Dependence, Exposure, facility geography, assistant loyalty, and public prestige.

#### The impossible lecture

Kruger gives a demonstration that ordinary experts cannot fully follow.

Variants:

- Public lecture.
- Closed military briefing.
- Industrial demonstration.
- Interrupted lecture where a foreign observer recognizes something.

Purpose:

Open a project family, reveal character, and create the first portrait shift without confirming origin.

#### The ministry adopts his timetable

Kruger demands that normal procurement and review schedules be replaced.

Player choice direction:

- Accept emergency authority.
- Build a special review process.
- Refuse and accept delay.
- Divide authority among institutions.

#### Assistants become a school

Kruger's students begin teaching his methods.

Possible outcomes:

- Lower Dependence through real replication.
- Create a loyal Kruger cadre.
- Produce a foreign defector.
- Generate an internal ethical faction.

### Evolution I gameplay payoff

The country should clearly research and prototype faster than before. The cost is political structure and future path dependence, not a tiny stability penalty.

## Evolution II: international scientific contest

### Core change

Foreign governments conclude that Kruger is a strategic asset. Diplomacy and intelligence begin targeting the scientist, his assistants, his laboratories, and his archives.

### Active-event entry conditions

Possible condition set:

- Evolution II enabled.
- Evolution I recorded or equivalent evolved opening state.
- Kruger fame or Security Exposure crosses a meaningful threshold.
- At least one Prototype exists, or the host has a research advantage large enough for rivals to notice.
- There is at least one valid foreign actor with intelligence, diplomatic, technological, or military interest.

### Active-event immediate changes

- Record Evolution II with the host actor.
- Upgrade portrait stage.
- Open foreign-contact and counterintelligence panels.
- Create a global interest registry or dynamic target pool.
- Let rivals choose invitation, theft, sabotage, recruitment, joint work, protection, or assassination routes.
- Add diplomatic opinion changes based on access and secrecy.
- Create a security crisis event around Kruger's personal protection.

### Pre-fire evolved opening

When Event 16 first fires in a Rising Chaos world:

- Kruger's arrival is already known to several intelligence services.
- At least two foreign countries receive observation or invitation opportunities soon after appointment.
- The host begins with higher Exposure and a stronger security choice.
- Kruger arrives with one Prototype proposal rather than only Theory.
- The host can accept a foreign protection or joint-laboratory offer early, creating immediate diplomatic alignment.

### Foreign action families

#### Formal invitation

A foreign government offers a chair, laboratory, citizenship, protection, or strategic contract.

The host can:

- Refuse and tighten security.
- Permit a visit.
- Create a joint appointment.
- Use the invitation to negotiate aid.
- Let Kruger decide, increasing his personal authority.

Kruger response depends on Grievance, host support, project opportunities, and whether the foreign state can satisfy his demands.

#### Covert extraction

A foreign service attempts to move Kruger or a field-specific project team.

Target options:

- Kruger himself.
- A senior assistant.
- A prototype.
- An archive.
- A clone body or machine node after those projects exist.

Outcome is shaped by security, Exposure, foreign intelligence, laboratory geography, and internal loyalty.

#### Sabotage

Target a facility or project stage.

Possible consequences:

- Delay.
- Accident.
- Public scandal.
- Kruger injury.
- Assistant death.
- Hidden project force activation.
- Grievance against the host if protection fails.

#### Scientific courtship

Recruit assistants through grants, asylum, publication, or professional prestige.

This action should be more common and less immediately hostile than kidnapping. It can reduce host capacity and create a foreign counter-Kruger school.

#### Joint laboratory

Create a bilateral or faction laboratory.

Benefits:

- Shared project capacity.
- Lower cost.
- Diplomatic alignment.
- Independent replication.

Risks:

- Technology leakage.
- Foreign veto.
- Facility split during war.
- Kruger using both countries against each other.

#### Protection pact

A foreign power guarantees the host or laboratory in exchange for access.

This can deter assassination and rebellion, but increases foreign influence and can turn a domestic confrontation into an international crisis.

#### Assassination

High-risk action with severe diplomatic consequences.

The target country should consider it only when:

- Kruger is enabling a rival's decisive strategic advantage.
- The country cannot steal or bargain for access.
- War or extreme ideology makes direct action plausible.
- The relevant project portfolio creates a serious threat.

Assassination outcomes depend on clone, machine, temporal, security, and alien-origin states. A failed attempt can accelerate Evolution III and increase Grievance sharply.

### Security choice event

The host receives a major decision about who protects Kruger.

Options direction:

- Ordinary state security.
- Military guard.
- Kruger's private guard.
- Allied protection team.
- Public openness and dispersed risk.

Each option changes not only assassination chance but also who controls the laboratory when a sovereignty crisis begins.

### International prestige and suspicion

Foreign opinion should not be one universal penalty.

- Allies may want access and protection.
- Rivals may fear a strategic gap.
- Democracies may object to secrecy or unethical trials.
- Authoritarian regimes may admire the program and seek exclusive control.
- Scientific powers may compete for assistants and publication.
- Countries harmed by Kruger weapons may gain strong hostility and containment decisions.

### Evolution II super-event threshold

Evolution II does not automatically deserve a super-event. The international-recognition super-event should fire only if Kruger has become genuinely world famous through one or more of these:

- A public breakthrough with global implications.
- Several countries taking direct action.
- A major strategic prototype.
- A joint-laboratory crisis.
- A failed assassination that exposes the program.

This keeps the super-event tied to campaign significance rather than evolution bookkeeping.

## Evolution III: forbidden and autonomous science

### Core change

Kruger's work produces effects that ordinary institutions cannot safely contain. The project portfolio gains weaponization and autonomy stages. The host must decide whether science remains subordinate to government.

### Active-event entry conditions

Possible condition set:

- Evolution III enabled.
- At least one impossible Prototype or several advanced conventional projects.
- High project capacity, Dependence, Mandate, or a major accident.
- Foreign pressure or war making dangerous work attractive.
- Kruger has survived long enough for physical and behavioral anomalies to become visible.

### Active-event immediate changes

- Record Evolution III with the host actor.
- Upgrade Kruger's portrait to a clearly unsettling stage.
- Unlock forbidden project stages.
- Unlock the sovereignty panel in hidden-preparation mode.
- Start visible warning incidents tied to Independent Capacity.
- Let the host choose a safe public-science doctrine or a risky secret-project doctrine.
- Allow early removal, negotiated limits, or continued escalation.

### Pre-fire evolved opening

When Event 16 first fires at the Chaos Tier:

- Kruger arrives with one impossible Prototype or a functioning group of unusual assistants.
- His portrait already contains noticeable nonhuman or unstable details.
- The host receives a stronger immediate research and project package.
- Security and sovereignty questions begin earlier.
- Foreign powers already have competing explanations for his origin.
- A first hidden project preparation can exist, but the player must receive evidence before any later rebellion uses it.

### The central dilemma

#### Safe public science

The host requires publication, independent replication, and restrictions on autonomous weapons.

Visible result:

- Preserve a large conventional benefit.
- Lower Mandate and Dependence.
- Suspend or dismantle forbidden Weaponization stages.
- Increase foreign access and public prestige.
- Create a chance that Kruger accepts a scientific settlement, leaves, or resists.

The host may need to release, exile, confine, or dismiss Kruger if he rejects the limits. The result depends on prior capacity.

#### Risky secret projects

The host allows continued work on impossible weapons and autonomous systems.

Visible result:

- Stronger project rewards.
- More project capacity and strategic options.
- Higher facility burden, Mandate, Dependence, and security risk.
- New accidents and demands.
- Faster preparation for a Kruger sovereign state.

### Sovereignty demand chain

Kruger does not instantly rebel at evolution. He begins making concrete demands.

Demand sequence can include:

1. Direct procurement authority.
2. Immunity for assistants and guards.
3. A legally protected laboratory zone.
4. Control of project units.
5. Independent foreign negotiation.
6. Permanent ownership of archives and patents.
7. Recognition of a sovereign scientific territory.

The host can grant, negotiate, delay, or refuse each demand. Earlier approvals change what Kruger can enforce later.

### Visible evidence events

Evidence should be project-specific.

- Clone route: staff records contain identical people or a dead assistant returns.
- Robot route: machines continue working after power and command are withdrawn.
- Dinosaur route: feed shipments and reinforced enclosures appear without authorization.
- Monster route: local animals disappear and guards report movement beneath the laboratory.
- Teleportation route: sealed rooms are entered without doors opening.
- Temporal route: orders arrive before they are written or several Krugers appear in separate records.
- Biological route: a containment system is wired to a political demand.
- Alien route: equipment responds only to Kruger's touch or anatomy.

These events create a readable escalation without exposing the hidden threshold.

### Removal branches

#### Early successful removal

If Independent Capacity is low:

- Confinement, exile, or killing can succeed.
- The host keeps independently replicated science.
- Archives create an aftermath and foreign race.
- No Kruger State forms.

#### Defection or partial uprising

If capacity is moderate:

- Kruger escapes to a foreign patron.
- One facility or one project group rebels.
- A small enclave forms.
- Project troops appear only from supported families.

#### Full rebellion

If capacity is high:

- Multiple laboratory sites defect.
- Guards and project forces activate.
- Kruger State forms.
- Starting territory and army derive from actual preparation.
- The host faces a war unless a charter route was chosen.

#### Host takeover

If Dependence and infiltration are extreme and the full institutional-capture contract is proven:

- Kruger can replace the government through loyal institutions, machine administration, clones, or temporal duplication.
- This is a rare high-chaos route.
- The country changes visible identity and enters the Kruger focus architecture without creating an invalid territorial split.

## Evolution IV: sovereign science and world conquest

### Core change

Kruger concludes that national government is no longer necessary for his work. If he is still inside a host, he forces a final sovereignty settlement. If the Kruger State already exists, its focus tree opens the world-conquest and strategic-singularity branches.

### Active-event entry conditions

Possible condition set:

- Evolution IV enabled.
- Evolution III recorded.
- Kruger remains active or sovereign.
- At least one impossible family is at Weaponization or Autonomy, or several are at Deployment.
- Sufficient facilities or independent capacity.
- Totalen Chaos world state or equivalent event-specific escalation.

### Host-state immediate changes

If Kruger remains hosted:

- Record Evolution IV with the host actor.
- Upgrade to a severe animated portrait state if assets are ready.
- Fire final sovereignty demand.
- Start a deadline mission.
- Allow peaceful charter, total concession, military seizure, foreign-backed containment, or refusal.
- The resolution cannot remain indefinitely in a vague hosted state.

### Kruger State immediate changes

If the Kruger State exists:

- Record Evolution IV with Kruger as actor.
- Unlock world-conquest focus branch.
- Unlock global scientist recruitment, facility seizure, project weaponization, and strategic-singularity research.
- Refresh the shared world-threat state when actual conditions make Kruger existential.
- Create foreign containment and coalition actions.

### Pre-fire evolved opening

When Event 16 first fires in a Totalen Chaos world:

- Kruger arrives with established international reputation, one advanced Prototype, and a small loyal assistant network.
- He still begins through an appointment event. The player receives a real choice about governance and transfer.
- Sovereignty pressure develops quickly, but it is not an instant unavoidable rebellion.
- The host can still choose the public-science route if it acts immediately and accepts lower exclusive power.
- Foreign powers begin direct actions early.

### World-conquest doctrine

Kruger State aggression should be purposeful.

- Capture research facilities and high-industry states.
- Abduct or recruit scientists.
- Seize strategic resources and power sites.
- Target former host first after a violent split.
- Prefer countries holding stolen project archives.
- Form a project-specific army rather than generic infantry spam.
- Build a global laboratory network.
- Offer subordinate research compacts to countries willing to submit.
- Destroy or neutralize countries that lead containment coalitions.

### Evolution IV portrait routes

Severe portrait animation should reflect the dominant project portfolio.

- Clone Kruger.
- Machine-linked Kruger.
- Temporal Continuum Kruger.
- Xenobiological Kruger.
- Alien-revealed Kruger.
- Synthesis Kruger when no one family dominates.

The player should not receive every portrait variant in one campaign. The selected identity follows actual projects and political route.

## Evolution pacing factors

### Faster evolution

- High global chaos.
- High Mandate.
- High Dependence.
- Several active projects.
- Major breakthroughs.
- Failed assassination or sabotage.
- War emergency.
- Alien, time, or special-project connections.
- High public fame for Evolutions I and II.
- High autonomous project state for Evolutions III and IV.

### Slower evolution

- Distributed public science.
- Low project capacity.
- Independent replication.
- Strong safety oversight.
- Low foreign interest.
- Kruger injury or temporary confinement.
- Project failure without replacement facilities.
- Host instability that prevents sustained investment.

Evolutions should never happen instantly after the normal requirement is met unless a pre-fire evolved opening explicitly seeds the stage.

#### Accepted country-specific institutional settlement pilot (implementation in progress, 2026-08-02)

The accepted country-specific settlement contract is a bounded extension of the existing assistant-conflict node, not a new evolution family. `chaosx.nr16.5` retains its generic `.5.a` through `.5.c` choices and adds one conditional national settlement for `ENG`, `USA`, `SOV`, or `JAP` under the exact compatible context gates recorded in the core and Directorate specifications. Each national choice resolves the existing assistant obligation, calls one existing base resolver plus one bounded settlement resolver, and schedules the existing impossible lecture once.

The settlement receipt remains host-local institutional history. It does not copy through ordinary transfer or Kruger State formation, and it does not change the current actor, Kruger identity, project ledger, evolution timing, cluster registration, or event-log ownership. Transfer before `.5` evaluates the recipient's current tag; transfer after `.5` leaves the former host receipt with the former host while the recipient receives only the existing generic assistant state.

The existing `.7` facility and `.8` custody reports remain the only downstream reaction nodes. A national receipt appends its specified description clause and AI preference or caution factor without adding an option, effect, delay, substitute incident, project reward, or model reference. The six other named tags and all unnamed countries remain on the complete generic `.5` option pool. Static source inspection now confirms the promoted runtime identifiers, while status remains accepted / implementation in progress pending targeted balance, transfer, cleanup, and live-acceptance evidence.

## Event-log direction

### Main event history

The initial appointment records Event 16 with the selected host as actor.

A transfer should not create a second random-event firing. The final accepting country becomes the actor shown in Event Details and relevant history context. If the generic history row is recorded before the host selection and transfer finish, implementation must prepare the actor through the established pre-fire event-log pattern.

### Evolution records

Each evolution records:

- Event ID 16.
- Its own evolution type and stage.
- Display tier.
- Current host or Kruger State actor.
- Enabled state.

The evolution title and body direction should describe the visible institutional change, not internal variable names.

### Detail catalog previews

The Event Details evolution catalog should preview the four evolution identities without fake dates or log indexes.

### Actor transitions

If Kruger moves to a new country, the current actor for future evolution records becomes the recipient. If the Kruger State forms, future sovereign-science evolution and world-threat records use that country.

## Disabled evolution safety

- Disabling Evolution I must not block the host from receiving the basic appointment and project system.
- Disabling Evolution II removes the international escalation layer while preserving domestic security and normal diplomacy.
- Disabling Evolution III prevents forbidden autonomy and rebellion-gated project stages. The host needs a clean safe-science resolution instead.
- Disabling Evolution IV prevents the world-conquest branch and strategic singularity. A Kruger State can still exist as a powerful regional chaos country.
- No disabled evolution may set a recorded flag, unlock a later branch, or leave a required baseline resolution inaccessible.
