# Event 16 Brilliant Scientist, Kruger country package

All labels are working labels and not final localisation.

## Country role

If Doctor Warren Kruger escapes or secedes, he should become a country-level threat rather than a single rebel unit. The country is a fictional chaos country built around laboratories, project armies, impossible industry, and personal rule by Kruger.

The public country name should be short and map-readable. Working public name options include Kruger State, Kruger Dominion, or Kruger Imperium. The final implementation should choose a readable country name and keep internal bodies such as institute, directorate, council, and laboratory command as institutions, not the map name.

## Tag and classification direction

Use a conflict-free custom tag. Working placeholder: `KRG`. The final tag must be checked against the live repository.

The country should be registered as a special chaos country. It should become an actual nonhuman country only if the route has visibly crossed into alien, robot, clone-only, monster-led, or otherwise nonhuman rule. If it is still a human-led scientific dictatorship with strange armies, it can remain special without being classified as fully nonhuman.

## Spawn logic

Kruger should not spawn from nowhere unless the world-end branch is already active. He should seize the laboratory network the host allowed him to build.

Preferred spawn state selection:

1. The state containing the moved or sealed Kruger laboratory if one exists.
2. The host capital region if the laboratory was never moved and the capital has enough industry or infrastructure.
3. A high-industry core state controlled by the host with research, university, or military lab flavor.
4. A remote state chosen by a secret relocation decision.
5. A reserve host-controlled state with enough victory points and supply to support a playable crisis.

Neighboring state seizure should scale with Autonomy and project arsenal. A small, early rebellion may seize only one state and a few facilities. A late rebellion with clone vats, robot foundries, sealed reactor, and specimen parks may seize several states and begin as a serious war.

## Starting politics

Kruger should begin as leader. His ideology should be a special authoritarian scientific rule mapped to the closest supported HOI4 ideology group. The ruling party should represent a laboratory state, but the country name should remain a country name.

Possible internal factions:

| Faction | Route role |
| --- | --- |
| Human loyal staff | Stabilization, diplomacy, and ordinary industry |
| Clone command staff | Manpower, obedience, and ethical collapse |
| Machine coordination unit | Robot army, production, logistics, and AI command |
| Specimen handlers | Monsters, dinosaurs, fear, and occupation |
| Xenological inner circle | Alien weapons, alien proof, and Kruger’s nonhuman reveal |
| Temporal mathematicians | time machine and final device route |

## Starting military package

Starting forces must be dynamic. Use the host’s approved project memories, host industry, chaos tier, state population, and laboratory site strength.

| Package | Trigger memory | Unit direction | Strength scaling |
| --- | --- | --- | --- |
| Laboratory guards | Always | Light infantry, security detachments, armored cars if available | Scales with host security investments |
| Defecting engineers | Engineering or industry route | Support-heavy infantry, maintenance, rail guards | Scales with factories and infrastructure |
| Clone formations | Clone program approved | Low-experience but numerous infantry with manpower regeneration | Scales with clone facility level and biology projects |
| Robot cohorts | Robotics approved | Mechanized or special robot templates with high equipment need | Scales with automation and industry projects |
| Specimen packs | Creature synthesis approved | Monster or dinosaur shock units with supply and control penalties | Scales with specimen wing and biology danger |
| Xenoweapon cadre | Xenotechnology approved | Small elite infantry with high breakthrough or piercing | Scales with alien material custody |
| Temporal detachments | Time project approved | Veteran units or repeated divisions with instability risk | Scales with time machine progress |
| Nuclear security troops | Nuclear route approved | Strong guard and heavy support around reactor states | Scales with reactor and final device progress |

Kruger should have a reinforcement pathway through focuses, decisions, captured labs, state projects, and foreign theft. Repeating unit creation should consume real resources or raise instability unless the route is intentionally absurd in the late game.

## War goals and strategic behavior

Kruger should first try to defeat or subdue the former host. If he wins, he can absorb the host’s research system and receive a major boost. If he loses quickly, the host can capture projects and trigger containment aftermath.

After the host phase, the country should target:

- Nearby capitals.
- States with nuclear reactors, uranium, rocket sites, or high industry.
- Countries that previously sabotaged or tried to recruit Kruger.
- Alien or special technology event locations.
- Major powers with advanced research.

## Diplomacy

Most countries should distrust Kruger after sovereignty. A few desperate, authoritarian, high-chaos, or anti-host countries can consider deals. Foreign deals should be dangerous:

- Sell prototype access for equipment or recognition.
- Trade monsters or robots for military access.
- Offer research miracles in exchange for basing rights.
- Infect foreign labs with dependence.
- Recruit foreign scientists and lower their home country research.

All such deals should raise world tension, chaos, or world-threat pressure when the system supports it.

## Focus tree identity

Kruger’s focus tree should make him playable and dangerous. It should not be a vertical list of science bonuses. The tree should ask how the laboratory state stabilizes, what kind of army it builds, how much of Kruger’s alien nature is revealed, and whether it races toward the final device.

The tree needs:

- Opening survival and seizure branch.
- Internal control branch.
- Project army branches based on approved memories and later choices.
- Industry and logistics branch.
- Expansion and world conquest branch.
- Final device branch.
- Defeat or containment hooks if the world pushes him back.

## Defeat logic

If the host or a coalition defeats Kruger before the final device completes, the aftermath should depend on project history:

- Clone facilities can create survivor scandals and demobilization missions.
- Robot foundries can be dismantled or captured.
- Monsters and dinosaurs can escape into states and trigger smaller incidents.
- Alien weapons can be seized by rival powers.
- Time machines can create one last anomaly.
- Nuclear and final device facilities should require urgent containment.

A short contained rebellion should not produce a global treaty. A long war where Kruger conquers many countries can justify a defeat super-event and postwar reconstruction content.
