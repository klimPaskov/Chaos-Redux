# Event 16 Brilliant Scientist, Kruger State focus routes

All focus group labels are working labels, not final localisation. This section expands the Kruger State tree from the core spec into route groups, locks, reward families, and AI behavior.

## Tree role

The Kruger State tree should play like a sovereign laboratory at war. It is not a normal ideological country tree. It has politics, industry, army, expansion, and diplomacy, but those branches express one question: which part of Kruger’s arsenal becomes the state’s governing logic.

The tree should be available only to the event-created Kruger country or a host that publicly surrenders state authority to Kruger. Existing countries with their own trees should not be overwritten unless the event created or transformed them through the Kruger route.

## Opening spine

The opening spine establishes survival before route specialization.

| Anchor group | Purpose | Route locks | Reward families | Failure pressure |
| --- | --- | --- | --- | --- |
| Secession command | creates the first state apparatus around the laboratory | requires Kruger sovereign or surrendered route | capital defense, emergency guards, starting laws, first focus filters | host counterattack grows if delayed |
| Secure the laboratory state | protects the first capital and project sites | requires control of capital and at least one lab state | forts, anti-air, local supply, guard divisions | loss of lab state disables deeper routes |
| Inventory the arsenal | reads project memories and opens project lanes | requires secession command | reveals eligible clone, robot, specimen, alien, temporal, nuclear, or final-device lanes | weak inventory lowers route speed |
| Bind the staff | turns scientists, guards, and technicians into a state class | locks out public host reconciliation | core stability, advisor unlocks, research slots, internal security | high staff resistance triggers defections |
| Claim the host’s work | defines the first war goal against the former host | requires former host alive or recent defeat memory | claims on lab states, war goals, intelligence against host | former host gets containment missions |

The opening should give Kruger enough force to survive if the host empowered him heavily. A cautious host should face a smaller rebellion with fewer lanes open.

## Internal authority routes

Kruger should have internal political choices even as a fixed-purpose chaos country. These choices define how the lab state obeys him.

| Authority route | Unlock | What it means | Compatible lanes | Route locks and costs | Reward families |
| --- | --- | --- | --- | --- | --- |
| Personal genius rule | default route | Kruger rules through reputation, direct orders, and impossible demonstrations | all project lanes | weaker if staff resistance is high | leader traits, research slots, fast focus speed, fragile succession |
| Laboratory constitution | requires public institute or peer review memory | the state keeps formal councils and controlled science boards | public science, medicine, computation, limited defense | blocks most atrocity projects and final-device shortcuts | legitimacy, foreign defections, safer tech sharing, containment aftermath options |
| Military laboratory command | requires military lab or guard memory | officers and security units become the state skeleton | robots, rockets, nuclear, expansion | raises war pressure and lowers public legitimacy | elite guards, command power, army XP, doctrine, war goals |
| Machine administration | requires AI foundry or robot memory | automated systems manage production and discipline | robotics, automation, final device | blocks human public reforms | robot production, supply efficiency, low manpower dependence |
| Biological dominion | requires clone or specimen memory | life itself becomes the recruitment and labor system | clones, specimens, dinosaurs, medicine | raises panic and nonhuman classification risk | manpower, special units, occupation pressure, severe diplomacy penalties |
| Alien mask removed | requires xenotech and high Strangeness | Kruger’s public identity changes into a high-chaos sovereignty myth | xenotech, temporal, final device | hidden until late and chaos is high | alien weapons, shielded units, foreign panic, special super-event eligibility |

The player should see the public meaning of each authority route. The implementation should not display hidden formula details about revolt thresholds or final device triggers.

## Project army lanes

The project army lanes should be separate from the authority route. A Kruger State can combine more than one arsenal if it earned the memories, but each route needs costs, unit identity, limits, and branch payoffs.

### Clone host lane

Anchor groups:

| Group | Purpose | Rewards | Limits |
| --- | --- | --- | --- |
| Stabilize replication chambers | turns clone memory into controlled manpower | clone manpower pool, basic clone infantry template | needs medicine or clone memory |
| Issue obedience protocols | improves reliability and command | lower training time, better reinforcement | raises atrocity and panic hooks |
| Batch officer cadres | creates mid-tier leadership | commanders, staff officers, doctrine aid | high failure if Security is low |
| Endless ranks | capstone for clone-heavy route | large manpower regeneration and rapid divisions | severe supply and diplomacy cost |

Clone units should be numerous and replaceable. They should consume equipment and supply. They should not be free infinite divisions without logistics pressure.

### Machine army lane

Anchor groups:

| Group | Purpose | Rewards | Limits |
| --- | --- | --- | --- |
| Reopen automated foundries | converts automation memory into production | military factories, production efficiency, robot equipment line | needs automation or AI foundry memory |
| Machine guard templates | creates robot or mechanized guard units | low manpower divisions, defensive bonuses | expensive equipment and fuel |
| Autonomous logistics | lets machines solve supply problems | trains, logistics modifiers, repair speed | vulnerable to sabotage and computation attacks |
| War without soldiers | capstone | strong low-manpower army and attrition resistance | high factory burden and foreign fear |

Machine armies should feel expensive and relentless. They should not solve every manpower and equipment problem at once.

### Specimen and dinosaur lane

Anchor groups:

| Group | Purpose | Rewards | Limits |
| --- | --- | --- | --- |
| Secure the pens | makes creature forces deployable | specimen support units, fear modifiers | needs specimen memory |
| Field obedience conditioning | reduces disaster chance | better control and lower friendly accidents | costs medicine, equipment, and time |
| Prehistoric recovery | rare branch for dinosaur memory | dinosaur shock templates or unique battalions | high supply burden, AI rare |
| Release the impossible host | capstone | powerful shock attacks and panic effects | severe resistance and containment backlash |

Specimen armies should be terrifying and unstable. They need supply costs, containment missions, and possible postwar escaped-specimen cleanup.

### Xenotech lane

Anchor groups:

| Group | Purpose | Rewards | Limits |
| --- | --- | --- | --- |
| Decode alien material | turns xenotech memory into usable weapons | special equipment, research boosts | needs alien material or xenotech range |
| Shielded battalions | creates elite troops | breakthrough, defense, hard attack | small numbers and rare material burden |
| Unfamiliar aircraft | supports air and rocket branches | air research, jet or prototype bonuses | fuel and crash risk |
| Doctrine from elsewhere | capstone | unique combat bonuses and foreign panic | high Strangeness and diplomatic isolation |

Xenotech should be elite and narrow. It should not create endless armies unless paired with automation or clones.

### Temporal and teleport lane

Anchor groups:

| Group | Purpose | Rewards | Limits |
| --- | --- | --- | --- |
| Map folded distance | unlocks teleport logistics | redeployment, raid decisions, supply tricks | needs teleportation memory |
| Predictions office | uses temporal memory for strategy | planning speed, intelligence, focus bypass candidates | accident risk and false predictions |
| Displaced reserve | creates unusual reinforcement | small elite units, emergency defense | cannot be spammed |
| War from tomorrow | capstone | raid, sabotage, and late-game combat power | reality instability and final device acceleration |

Temporal routes should create strange movement and prediction, not a simple large stat bonus.

### Nuclear and final-device lane

Anchor groups:

| Group | Purpose | Rewards | Limits |
| --- | --- | --- | --- |
| Reactor guard state | secures nuclear sites | forts, guards, reactors, nuclear research | needs reactor memory or captured reactors |
| Delivery calculations | links rockets, teleportation, or aircraft | final device progress factors | requires delivery memory |
| Components under siege | creates the race | visible progress and enemy sabotage targets | gives the world counterplay |
| Final equation | capstone | terminal branch setup | requires world-end contract and super-event research |

The final-device lane should take time. It should never be a one-focus win button.

## Industry and logistics lanes

Kruger’s industry branch should support the army route instead of granting generic factories.

| Anchor group | Purpose | Rewards | Route interaction |
| --- | --- | --- | --- |
| Sealed city workshops | makes the capital a production organism | factories, building slots, supply | stronger if host built sealed lab |
| Automated contracts | turns private suppliers into state assets | production efficiency, resource extraction | stronger with automation memory |
| Railways into the perimeter | keeps the state alive | railways, supply hubs, trains | needed before large armies |
| Prototype depots | stores project equipment | stockpiles, decision cost reductions | vulnerable to enemy raids |
| Laboratory extraction zones | exploits controlled states | resources, compliance tools, resistance risk | dangerous under specimen or clone route |

## Expansion and diplomacy lanes

Kruger should expand by seeking useful knowledge, facilities, and strategic survival, not by generic conquest claims.

| Anchor group | Target logic | Rewards | AI notes |
| --- | --- | --- | --- |
| Punish the host | former host and lab states | war goals, claims, propaganda, host peace terms | highest early priority |
| Seize universities | nearby research centers and capitals | research bonuses, compliance missions | AI targets reachable countries |
| Capture reactors | reactor states and nuclear powers | final device progress, nuclear guards | high priority for final device AI |
| Collect alien material | alien-event states or owners | xenotech route | only if alien memory exists |
| Demand scientific tribute | small neighbors and defeated enemies | subjects, research payments, equipment | lower priority if at risk |
| Containment conference rupture | anti-Kruger coalition members | war goals, sabotage retaliation | appears after global response begins |
| World academy under one rule | late conquest branch | faction collapse pressure, global threat | Evolution IV only |

## Late convergence groups

Late tree convergence should depend on the route earned:

| Convergence group | Requires | Role |
| --- | --- | --- |
| Sovereign theorem | two major project lanes completed | research and political capstone |
| The army of the experiment | one army lane completed and former host defeated | route-specific military capstone |
| Laboratory world order | several major powers defeated or subject | world conquest branch |
| Final device race | nuclear plus one extreme memory | terminal race |
| Captured knowledge settlement | Kruger defeated or forced into treaty | aftermath branch if playable path allows it |

## Kruger AI focus behavior

Kruger AI should start with survival and host war priorities. It then chooses project lanes from actual memories.

| AI situation | Priority |
| --- | --- |
| weak secession package | opening survival, forts, guards, negotiated delay |
| clone memory high | clone lane, manpower regeneration, fast host war |
| robot or automation memory high | machine lane, industry, defensive production |
| specimen memory high | secure pens, panic warfare, supply support |
| xenotech memory high | elite weapons, alien material targets |
| temporal or teleport memory high | raids, intelligence, defensive redeployment |
| nuclear and delivery memory high | reactor guard, final device lane, component defense |
| close to defeat with final device progress | arming urgency and defensive focus |
| winning against former host | expansion toward research centers |

AI should not choose a project lane without the memory or a focus that creates the memory. AI should not ignore supply when using clones, specimens, or dinosaurs.
