# Event 16 Brilliant Scientist, foreign reactions and event connections

All labels are working labels and not final localisation.

## Foreign attention model

Foreign countries should notice Kruger through Public Fame, intelligence exposure, breakthrough count, and visible project incidents. Foreign reactions should be active and varied.

| Actor group | Ordinary response | Escalated response | Extreme response |
| --- | --- | --- | --- |
| Major powers | Invite, observe, offer grants, create rival institute | Spy missions, sabotage, asylum offer | Kidnapping, assassination, seizure war goal after Kruger secedes |
| Ideological rivals | Propaganda and suspicion | Theft and exposure campaigns | Sponsor anti-Kruger coalition |
| Allies | Research exchange and protective observers | Demand shared breakthroughs | Threaten rupture if host hides dangerous work |
| Subjects or puppets | Request access and protection | Become testing grounds if host is abusive | Revolt over experiments or staff disappearance |
| Neighboring countries | Border fear and intelligence interest | Fortify against test accidents | Join containment war |

## Foreign decision content

Countries that are not the host should not receive a full Kruger panel. They can receive a compact foreign reaction category once Kruger becomes famous or sovereign.

Decision families:

| Family | Who uses it | Purpose |
| --- | --- | --- |
| Offer academic asylum | Rivals and majors | Try to lure Kruger or staff away |
| Sponsor rival institute | Majors with industry | Gain partial research bonuses and reduce dependence |
| Fund laboratory theft | Spies and rivals | Steal project memory or delay host |
| Expose dangerous research | Democracies, rivals, enemies | Lower host stability or Public Fame |
| Purchase prototype fragments | Desperate countries | Gain small tech or equipment, raise risk |
| Join containment talks | Neighbors and major powers | Prepare coalition if Kruger secedes |
| Recognize Kruger | Opportunists after secession | Trade diplomacy for prototypes |

Costs should use intelligence capability, relations, money-equivalent political resources, equipment shipments, convoys, industry, and risk to diplomatic reputation. AI should avoid suicidal theft if the host is much stronger and security is high.

## Defection, assassination, and transfer

Kruger should not randomly vanish without a chain. If Security Integrity is low and foreign pressure is high, the host should receive incidents before a final outcome.

Possible outcomes:

| Outcome | Conditions | Consequence |
| --- | --- | --- |
| Defection abroad | Low security, high restrictions, strong foreign invitation | Kruger transfers to a new host with some project memories |
| Assassination | Low security, hostile foreign power, high public fame | Kruger dies, host loses advisor, possible stolen notes or martyr effect |
| Failed kidnapping | Security high enough | Host gains anger, rival penalty, and security mandate |
| Double agent scandal | Counterintelligence failure | Rival receives tech, host loses leverage |
| Staged asylum | Host uses diplomacy | Foreign access without losing Kruger, but theft risk grows |

## Connections to cataloged events

### Time Traveler

If Time Traveler has fired, Kruger can receive temporal project hints. The time project can become available earlier, but Security Integrity and Strangeness should suffer. If both Time Traveler and Kruger exist in different countries, special espionage events can involve attempts to compare impossible predictions.

### Alien Spacecraft

Alien Spacecraft should strongly boost xenotechnology. If the host controls recovered alien aircraft or tech, Kruger can build alien weapons or aircraft. If another country controls alien assets, Kruger can target it later as a conquest or theft objective.

### Tomorrow's Girls and anti-alien content

If alien paranoia systems exist, Kruger can become a suspicious subject. The host can test whether he is human. A successful test should not reveal everything early. It can show anomalies that raise Strangeness and unlock later routes.

### Mass Panic

Mass Panic can be triggered or intensified by public anomalies, escaped specimens, missing staff, or strange weapons. A public Kruger host can suffer panic if Public Fame and Strangeness are both high.

### Gift from Scientists

If this event fires after Kruger is active, the host can receive a stronger version or a strange version. If Kruger is sovereign, he can hijack the gift and convert it into project progress.

### Research Failure

Research Failure can target rivals that attempted to steal from Kruger, or it can represent an accident inside the host laboratory if Strangeness is high and security is low. Do not use it only as random punishment.

### Research Investment

Kruger can overperform investment categories. The host can channel investment into one field, but risky fields should increase project memories.

### Special Tech and Special Project

Kruger should hook into instant special technologies, but the implementation must prevent uncontrolled stacking. Strong gains should have project memory, cooldown, and danger tradeoffs.

### Super Soldiers and Crazy Scientist

These are natural biology and cloning hooks. If Super Soldiers or Crazy Scientist exists, Kruger can borrow techniques, compete with them, or absorb their projects. The event should avoid duplicating a whole biowarfare event, but it can create special variants.

### Chemical and biological warfare

Kruger’s biology projects can produce medicine, countermeasures, bioweapons, outbreaks, or doomsday links. Dangerous biology should interact with condemnation, deaths, and air cleanliness when the live repo supports those systems.

## Global response to sovereign Kruger

When Kruger becomes sovereign and begins conquest, the world should gain a containment logic:

- Nearby countries receive fear and border preparation events.
- Major powers can form a containment conference.
- Former rivals may temporarily cooperate.
- Countries with stolen Kruger tech may choose to return, hide, or weaponize it.
- Kruger can punish countries that attempted sabotage.
- If world-threat framework exists, Kruger sovereignty should contribute to the aggregate world threat.

## Localisation direction

Foreign reaction text should describe what countries actually see: visiting scientists vanishing, prototype papers circulating, guards refusing cabinet orders, strange aircraft over test ranges, hospitals receiving impossible medicine, and laboratories buying equipment at night. It should avoid generic diplomatic denial frames and should not label the content as a warning.
