# Decision and mission map for Brilliant Scientist

All labels are working labels and not final localisation.

## Host decision category lifecycle

| Phase | Category state | Decisions visible | Missions active | Cleanup |
| --- | --- | --- | --- | --- |
| Baseline | Kruger accepted | Choose public, secret, or screening posture | None or one setup mission | Hide transfer choices after resolved |
| Early program | Research focus selected | Institutional control, first focus selectors, advisor management | Build institute or laboratory mission | Clear setup flags after first facility |
| Evolution I | National fame | Public science, university, field investments, first foreign observer choices | Public institute and field demonstration missions | Hide baseline setup buttons |
| Evolution II | Security crisis | Counterintelligence, staff screening, foreign access, sabotage recovery | Guard laboratory, trace leaks, prevent defection | Clear foreign incident targets after resolution |
| Evolution III | Dangerous projects | Project approvals, quarantine, tribunal, restriction, arrest preparation | Containment readiness, evacuate staff, destroy prototypes | Hide safe-only decisions if sovereign branch starts |
| Evolution IV | Sovereignty crisis | Bargain, arrest, evacuation, surrender authority, wartime containment | Stop secession, hold lab state, seize project site | Remove host category if Kruger becomes independent and host loses all access |
| Aftermath | Contained or defeated | Archive, destroy, publish, weaponize, treaty sharing | Dismantle labs, secure specimens, audit notes | Clear Kruger targets and stale project decisions |

## Mission families

| Mission family | Owner | Requirement direction | Duration band | Success | Failure |
| --- | --- | --- | --- | --- | --- |
| Build public institute | Host | Commit civilian factories and keep stability above a safe threshold | Medium | Public science route, leverage, safer fame | Delayed institute and higher private autonomy |
| Secure sealed laboratory | Host | Place supplied divisions or guards near lab state, spend support equipment | Medium | Security Integrity and containment chance | Sabotage or guard loyalty drift |
| Trace stolen notes | Host | Intelligence agency or counterintelligence, target rival | 90 to 140 days | Recover notes and expose rival | Rival gains partial tech |
| Prevent defection | Host | Security, relations, staff protection | 120 to 180 days | Kruger stays and leverage improves | Kruger transfers or crisis escalates |
| Containment readiness | Host | Peer review, loyal guards, prototype inventory | 180 days or longer | Arrest option becomes realistic | Arrest attempt likely triggers rebellion |
| Evacuate laboratory staff | Host | Trains, convoys, civilian factories, security | 90 to 160 days | Reduces rebel assets and civilian losses | More staff join Kruger |
| Destroy prototype family | Host | Control project site and spend equipment or air assets | Hard, usually 180 days | Removes one future rebel asset family | Immediate revolt or disaster |
| Final device sabotage | Enemies of Kruger | Intelligence, air control, control nearby states, special forces | Hard | Delays final device | Kruger accelerates arming |
| Secure escaped specimens | Victor after defeat | Troops in affected states, supply, equipment | Medium | Removes specimen incidents | Monsters or dinosaurs spread |
| Dismantle robot foundries | Victor after defeat | Control industrial states, engineers, equipment | Medium | Removes robot resurgence | Automated insurgency |

## Cost palette

Use a varied cost model. Political power can appear, but should not dominate.

| Action type | Preferred costs |
| --- | --- |
| Public institute | Civilian factory time, stability, public fame risk |
| Military lab | Military factory time, army XP, command power, support equipment |
| Security | Infantry equipment, support equipment, manpower, intelligence agency access |
| Foreign observers | Relations, convoy access, intelligence exposure, Public Fame |
| Project approvals | Field-specific XP, factories, rare equipment, stability or war support, Strangeness |
| Arrest attempt | Loyal divisions, security integrity, leverage, possible stability shock |
| Evacuation | Trains, convoys, civilian factories, time |
| Prototype destruction | State control, air superiority or special forces, equipment, high risk |
| Final device race | Reactor control, rare project memories, industry, time, conquest objectives |

## Clutter control

Only the current phase should show the main decisions. The player should not see every project family at once. Field selector decisions should open or close focused project families. AI can evaluate hidden project decisions directly through scripted effects rather than using human-only selector clicks.
