# Event 016 Kruger State country-package matrix

## Binding reconciliation

Host takeover is an institutional-capture origin and never a territorial fallback. The country package inherits paleogenetic and xenobiological forces and supply systems separately, preserves temporal debt and anchor state, and cannot carry contradictory origin proof or terminal commitment flags.

## Country-package completion checklist

- Tag and conflict check.
- Country definition and history.
- Capital and valid territory.
- Core, claim, and occupied-state rules.
- Base and route flags in three sizes.
- Country names, adjectives, parties, ideologies, and cosmetic tags.
- Kruger character and portrait routing.
- Advisors, commanders, and route leaders.
- Starting ideas and lifecycle.
- Starting conventional and project forces.
- Equipment, manpower, supply, production, and technology.
- Focus-tree assignment based on actual event creation or transformation.
- Decisions and missions.
- AI strategy and templates.
- Special-country and nonhuman classification.
- Former-host and foreign diplomacy.
- Event log, docs, assets, achievements, and cleanup.
