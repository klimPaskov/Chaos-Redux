## Formula summary

- Facility projects mainly use civilian factories, time, stability, and public pressure.
- Military prototypes mainly use military factories, XP, equipment, fuel, and security.
- Sealed projects use multiple factory types, support equipment, manpower, security staff, and longer duration.
- Emergency containment uses loyal units, state control, equipment, trains, convoys, and security.
- Final-device work uses project memories, reactors, component states, industry, and sabotage pressure.
