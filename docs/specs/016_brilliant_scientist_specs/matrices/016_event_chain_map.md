# Event 016 event-chain map

## Binding reconciliation

The chain retains six mapped super-event packages and seventeen achievements. Host takeover requires proven multi-domain institutional capture and is never selected because territorial secession failed. Temporal actions create debt and anchor counterplay. One campaign-specific origin conclusion may lock, or the chain remains unresolved. Laboratory World and Strategic Singularity use mutually exclusive commitment locks.

## Core state flow

```text
Random fire-once selection
  -> eligible host chosen
  -> Doctor Warren Kruger appears
      -> public appointment
      -> secret military appointment
      -> rejection and transfer to another valid host

Accepted appointment
  -> primary laboratory selected
  -> +100% research anchor active
  -> persistent advisor and special-project scientist active
  -> governance and first field chosen
  -> staff and facilities grow
  -> first impossible result
  -> directorate period
  -> foreign attention
  -> forbidden projects and sovereignty demands
      -> public scientific settlement
      -> controlled secret compact
      -> unrestricted hosted state
      -> peaceful charter
      -> defection
      -> successful confinement or death
      -> partial enclave
      -> violent Kruger State rebellion
      -> host takeover

Kruger State or takeover
  -> survive opening
  -> choose political and project routes
  -> regional state or scientific commonwealth
  -> project empire
  -> global threat
      -> defeat aftermath
      -> Laboratory World terminal
      -> Strategic Singularity and Fallout terminal
```
