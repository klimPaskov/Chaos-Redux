# Decision, mission, and scripted GUI prompt for Event 16 Brilliant Scientist

Implement the host decision system and optional hybrid GUI from the canonical specs. Use normal decisions as the gameplay owner and AI path. Add the GUI only when the full project and confrontation system is implemented.

## Required decision surfaces

The host needs a Kruger management category with visible values for Research Momentum, Laboratory Autonomy, Security Integrity, Public Fame, Strangeness, Government Leverage, project load, containment gap, foreign heat, arsenal weight, and facility memory summaries. Do not reveal exact hidden rebellion formulas or unexposed world-end details.

## Decision and mission families

Implement public science, military laboratory, security, restraint, sealed-project, foreign attention, project approval, facility audit, laboratory relocation, quarantine, arrest or removal, prototype destruction, final confrontation, sabotage, and postwar oversight families. Costs must be dynamic and should use equipment, XP, manpower, stability, war support, fuel, convoys, trains, local support, intelligence exposure, construction burden, and state control where relevant. Political power and command power cannot be the only recurring cost model.

## Mission quality

Use timed missions for audits, guarding labs, securing supply routes, protecting or raiding laboratories, containing escapes, and sabotaging final-device sites. Missions need success, failure, partial success where useful, cleanup, active caps, route locks, AI behavior, and follow-up consequences.

## GUI design

If the hybrid GUI is built, show project cards, meter rows, security state, foreign attention, confrontation actions, final-device race state, and aftermath choices. Buttons should call the same cost logic and scripted effects as decisions. AI must never depend on human-only GUI clicks.

## Audit expectations

Use the decision and mission auditor after implementation when available. Check duplicate missions, weak reward dust, cost clarity, invalid targets, stale missions, exploit loops, missing AI, and player-facing tooltip quality.
