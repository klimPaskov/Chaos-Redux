1. Host appointment and institutional form.
2. Facilities and staff.
3. Scientific governance and replication.
4. Security and counterintelligence.
5. Project portfolio.
6. Foreign scientific contest.
7. Sovereignty confrontation.
8. Former-host recovery.
9. Kruger State administration and project forces.
10. Global submission, containment, and strategic singularity.

Hide obsolete categories and actions. Use phases, project capacity, selected foreign targets, route locks, emergency visibility, and cleanup.

## Required host actions

Implement the institutional, facility, staff, governance, security, resource, university, confrontation, and recovery families from part 2. Keep the primary laboratory state persistent and valid. Use concrete costs such as factories, equipment, trains, trucks, convoys, fuel, manpower, XP, tied divisions, medical capacity, stability, war support, intelligence exposure, facility capacity, and time.

## Required missions

- Independent replication.
- Named facility protection.
- Project-specific containment.
- Secure relocation.
- Sovereignty deadline.
- Archive recovery.
- Assistant-loyalty split.
- Singularity component capture and disarmament.

Missions need real objectives, dynamic durations, success, failure, partial success where useful, and route-aware AI.

## Foreign actions

Implement invitation, assistant recruitment, archive theft, sabotage, extraction, assassination, joint security, joint laboratory, public challenge, counter-Kruger research, and containment coalition actions. Use a compact selected-target human interface while AI can evaluate all valid targets. Clear dead and invalid targets.

## Kruger State actions

Implement route-specific production and administration for clone, robot, paleogenetic, xenobiological, portal, temporal, exotic, biological, diplomacy, recruitment, expansion, integration, and singularity systems. Paleogenetic and xenobiological forces require separate facilities, supply, failures, and counters. Force generation must use facilities, equipment, resources, and time. No uncapped weekly divisions.

Keep only Independent Capacity and Grievance hidden. Add temporal observation, authentication, anchor discovery, bounded recovery, per-target use records, ledger capture, and stabilization. ## AI and cleanup

AI uses equivalent actions without clicking the human GUI. It must check resources, route validity, project history, war state, targets, facilities, and evolution settings.

Clean:

- Selected targets.
- Temporary variables and flags.
- Missions after resolution.
- Invalid facilities.
- Host categories after transfer or formation.
- Project actions after death, annexation, or world end.
- Singularity construction after disarmament or terminal firing.
