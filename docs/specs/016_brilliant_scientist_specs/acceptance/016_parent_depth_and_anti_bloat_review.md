# Event 016 parent depth and anti-bloat review

## Review status

This is a parent-level design review performed after the ten-part source spec was assembled. It does not replace the project-mandated `chaosx_improvement_loop_planner` pass. That subagent could not be invoked in this chat interface because no project-subagent execution tool was exposed. The exact planner prompt is included in the package and is the first unresolved step in the continuation handoff.

## Feature promise

The event promises three things.

1. A sudden, absurdly strong scientific advantage.
2. A living relationship with one scientist whose power grows through actual national choices.
3. A project-derived breakaway threat that can escalate into world conquest or a terminal weapon.

The source spec now supports all three promises.

## Depth findings

### Opening power is preserved

The spec does not dilute the original concept. Appointment gives the requested `+100%` research-speed anchor and exceptional special-project access.

### Risk is choice-driven

The design avoids an unavoidable random betrayal. Kruger's capacity comes from Mandate, Dependence, facilities, guards, assistants, project stages, and Grievance. The player receives visible evidence before confrontation.

### Host play is distinct from breakaway play

The host uses an additive decision and interface system. The Kruger State receives the full focus tree. This prevents every random host from losing its national identity while still giving the breakaway country long-term depth.

### Project families affect more than modifiers

Projects change units, facilities, foreign actions, accidents, portraits, politics, rebellion, focus routes, countermeasures, super-events, and endgame systems.

### AI has real route logic

Host, foreign, and Kruger AI receive context-based plans. Human-only GUI actions have AI equivalents.

### Visual evolution is mechanical

Portrait stages and severe animations follow evolution and dominant project state. They are not decorative overlays detached from gameplay.

### World-end logic is compatible

The singularity can fire from any starting tier only by adding enough chaos to satisfy the normal terminal rule first. The design does not silently bypass the global system.

## Anti-bloat findings

### No universal science economy

The design stays centered on Kruger. It does not create a research bureaucracy system for every country.

### No host focus-tree replacement

Host countries retain their normal trees. Event content is additive.

### No fifth evolution

Four user-defined evolutions are enough. World Collapse remains the terminal gate.

### No automatic cluster

The event stays outside the planned Research cluster as requested.

### No mandatory triggerable scenario

A new Kruger scenario would add scope without being requested. The existing Army of Clones scenario receives only a connection hook.

### No super-event for routine milestones

Only international recognition at a real threshold, state formation, global threat, terminal outcomes, and major defeat aftermath receive super-event treatment.

### No requirement to finish every project

Limited capacity preserves replayability and prevents the project list from becoming busywork.

### No separate country for every project army

Clones, robots, dinosaurs, monsters, portal forces, and temporal units remain branches of one Kruger State unless future accepted design gives a strong reason for a separate actor.

### No final localisation inside the planning spec

The package gives tone and information direction. It does not flood the source spec with copy that may become stale during implementation.

## Remaining questions for the mandatory planner

The external improvement-loop pass should answer:

- Does the 85 to 115 focus target need a tighter branch count after reviewing current repo implementation patterns?
- Should host takeover remain a full route or a rare fallback when territorial secession is invalid?
- Does the international-recognition super-event add enough value to justify a unique audio and image package?
- Should the peaceful charter create a distinct scientific-commonwealth faction immediately or only after focus development?
- Are any project families still too similar in play, especially paleogenetics versus xenobiological monsters?
- Does the temporal branch need stronger failure content to offset recovery power?
- Should alien origin remain one rare truth route, or should several mutually exclusive explanations remain possible to the end?
- Does the 17-achievement working set contain redundant breadth challenges?
- Are the singularity and Laboratory World terminal branches sufficiently different in player experience?
- Is any further content likely to add bloat rather than choice?

## Parent recommendation

Do not add another broad mechanic before the mandatory planner pass. The current design is already large and connected. Any new addition should solve a specific identified gap rather than expand the event for spectacle.

## Current closure judgment

The design is complete enough to enter the mandatory planner and audit sequence. It is not process-closed because those project-required subagent passes have not run in this interface.
