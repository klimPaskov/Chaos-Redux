# Event 16 Brilliant Scientist canonical planning package

This is the clean canonical source-design package for Event 16, Brilliant Scientist.

It merges the completed first-pass package with the accepted second-pass improvement work. It does not include temporary continuation prompts. It does not create a third broad expansion. The improvement-loop closure is included and recommends moving to implementation, audit, asset production, super-event research, and documentation alignment.

## Package structure

- `specs/` contains the canonical 14-part source specification and a spec index.
- `prompts/` contains canonical prompts for implementation, assets, super-events, achievements, decisions, focus and country work, and the 3500 to 4000 character goal prompt.
- `matrices/` contains compact implementation matrices for AI, assets, decisions, projects, host overlay, Kruger routes, scripted GUI states, countries, and achievements.
- `research/` contains the science and wartime research inspiration note from the first pass.
- `reading/` records uploaded files processed and blockers that remain.
- `handoffs/` contains the canonical implementation handoff and closure note.
- `source_maps/` explains how Part 1 and the second-pass package were promoted.
- `validation/` records package-level style and structure checks.

## Honest status

This package is a planning and implementation handoff. It is not a gameplay patch. It does not include generated DDS assets, audio files, final quotes, final super-event titles, final button remarks, live repository validation, or spreadsheet workbook edits.
