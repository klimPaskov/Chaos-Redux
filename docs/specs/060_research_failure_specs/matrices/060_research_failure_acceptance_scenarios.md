# Research Failure acceptance scenarios

## Completion rule

Event 60 is not complete because the opening popup fires or because a research penalty appears.
Completion requires the target transaction, technology graph safety, decisions, AI, evolutions, foreign reactions, Event Logs, assets, localisation, documentation, workbook alignment, and cleanup to satisfy the scenarios below.

The implementation agent should record the exact evidence path for every scenario.
A blocked engine capability remains a blocker and cannot be relabeled as passed through a weaker substitute.

## Final evidence summary

The completion report should include:

- Files changed and identifiers added.
- Verified technology registry coverage by domain and DLC.
- MCP technology and probability evidence.
- Slot and lost-knowledge transaction evidence.
- AI scenario outcomes.
- Reconstruction timing and affordability results.
- Assets created and wired.
- Localisation and Event Log coverage.
- Workbook update and CSV export result.
- Every blocked or excluded technology family with reason.
- Every simplification, omission, fallback, or unverified surface.

No simplification can be omitted from the report.
