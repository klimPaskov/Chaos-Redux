# Event 039 Murder Mystery Improvement and Specialist Review

## Review purpose

This review tests the finished specification pack against the event-planning, improvement-loop, event, decision, focus, asset, animation, super-event, 3D, country, AI, localisation, documentation, and completion contracts supplied with the project.

The accepted rough idea asked for a leader murder, an investigation, five evolutions, a spreading cult, an international movement, an Assassin State, unusual military formations, a focus tree, a manual scenario, achievements, and a terminal World of Anarchy route. The finished pack retains every requested branch and converts each branch into an implementation contract with safety, AI, performance, assets, cleanup, and acceptance evidence.

## Source and runtime status

Every supplied Markdown file, TOML file, CSV catalog, and subagent definition was read in full. The subagent archive was extracted and all twenty definitions were reviewed individually.

The active environment did not expose a working project subagent invocation route. Two attempts through the available outer Codex bridge returned an MCP tunnel 404 response, and no local `codex` executable was available. No specialist process was therefore spawned. The specialist scopes, gates, prompts, and handoff requirements were applied manually in this review. This limitation affects process evidence only. It does not remove any planned gameplay or presentation surface.

The autonomous debug-playtest skill was not invoked because it requires explicit user authorization for desktop control. The current task is planning work and does not include live game testing.

## Improvements made during the review

### Host viability was strengthened

The first draft allowed a baseline host that could never support the Evolution III territorial split. That would make a requested evolution disappear for reasons known at event selection time. The final contract requires predictive split viability whenever Evolution III is enabled. Later wars can still invalidate the map, so the live split preflight remains fail-closed and delays the evolution until a safe transaction exists.

### The investigation became a playable system

The rough idea identified a search for the murderer but did not define how a player succeeds. The finished design uses six phases, Case Progress, Network Reach, evidence, witnesses, target protection, local incidents, map objectives, agency capacity, concrete costs, partial outcomes, and a final capture family. A capable government can solve the baseline case. Higher stages remain dangerous without making early effort irrelevant.

### Character deaths became safe transactions

The rough idea required leader, general, advisor, and operative deaths. Direct deletion would break country content and other event systems. The specification now requires a curated target registry, ownership checks, protected roles, prepared succession, generic office casualties, and rollback. A named character is never selected because a broad role search happened to find them.

### The cult and international network gained bounded state

The event now separates the original murderer, the core national cult, foreign cells, the movement heir, the Assassin State, and derivative countries. Cell maturity, immunity, inheritance, and reseeding are capped. This prevents endless hidden leaders, duplicate countries, stale targets, and daily global scans.

### The Assassin State became a complete country

The rough idea asked for a new state, civil war, focus tree, military, and expansion. The finished design provides a transactional state split, three political routes, industry, logistics, intelligence, custom forces, subjects, diplomacy, original-host conquest, postwar play, AI, player switching, defeat, and rollback. The country has a playable nonterminal campaign even when World of Anarchy never becomes available.

### Custom units received balance and ownership

The named Assassin formations now have distinct roles, equipment, production, caps, weaknesses, AI ratios, technology, counters, audio, models, and Event 19 ownership. They cannot become a free universal infantry replacement. The family uses one provider and the complete thirteen-callback contract.

### World of Anarchy became a campaign

The terminal route now has a public registry entry, a 1000 Chaos gate, sector activation, phased wars, protected government handling, viable successor administrations, victory, defeat, aftermath, persistence, and cleanup. It uses bounded event-owned registries and hooks instead of recurring full-world iteration.

### Presentation gained hierarchy

Most investigation incidents use reports and local events. International assassinations use news only when the target and consequence justify global presentation. The Assassin State reveal, terminal activation, and large-scale defeat aftermath are the three super-event candidates. Each remains gated by a real campaign threshold.

### Cultural safety became enforceable

The fictional movement has no historical religion, ethnicity, national origin, or real political doctrine. The specifications explicitly reject medieval Nizari legends, hashish myths, Alamut borrowing, ninja stereotypes, and the equation of anarchism with indiscriminate murder. Research sources and terminology rules are recorded in Part 17 and the bibliography.

## Anti-bloat decisions

The review rejected several expansions that would add maintenance without improving play.

- No dedicated investigation GUI is required.
- No extra public value beyond the two-value budget is allowed for each actor type.
- No independent focus tree is required for every foreign cell.
- No full country package is created for ordinary low-stage cells.
- No unlimited movement-heir chain is allowed.
- No super-event fires for routine murders or small cells.
- No universal daily or weekly country scan is allowed.
- No separate custom equipment type is created for every Assassin formation.
- No placeholder formable, historical order, or religious identity is used to fill lore gaps.
- No terminal activation is automatic merely because a manual scenario starts at high intensity.

These limits keep the event large enough to match the accepted idea while preserving clarity and implementation feasibility.

## Cross-source conflicts

### Catalog classification

The supplied event CSV still calls Event 39 Minor Repeatable and contains only a short succession-crisis description. The accepted source design changes it to Minor Fire-Once with five evolutions, the Assassin State, a scenario, and a public terminal branch. Implementation must update the authoritative XLSX and regenerate the exports.

### Intelligence cluster identifier

The supplied Intelligence cluster row has no assigned ID and no registered members. The package may use `9` as a planning placeholder only. The workbook must reserve the final ID before any script constant or registry row uses it.

### Scenario identifier

The current scenario export does not contain Assassin Network. The package may use `SCN-014` as a planning placeholder only. The authoritative workbook and live registry decide the final identifier.

### Super-event audio format

The current super-event skill requires final WAV files and settings-aware sound wrappers. The supplied audio-researcher TOML still instructs OGG output. The Event 39 specifications follow the current WAV contract. The canonical subagent TOML should be corrected and regenerated for other runtimes before production work begins.

## Closure position

Broad planning can stop. Another expansion pass would mostly add parallel values, extra cells, more route variants, or more presentation moments. That would raise complexity without fixing a known design gap. The next work should implement the package in tranches, compare each tranche with Part 18, and reopen planning only when repository evidence exposes a concrete engine, balance, or integration conflict.
