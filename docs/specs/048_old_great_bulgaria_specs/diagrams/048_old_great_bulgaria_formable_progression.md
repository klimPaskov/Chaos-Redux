# Formable progression

```text
Bulgaria
   |
   | Baseline territorial proof + integration
   v
Greater Bulgaria
   |
   | Evolution II + imperial settlement + broader Balkan proof
   v
Bulgarian Empire
   |
   | Evolution III + Black Sea gateway + Azov/Taman/Kuban/lower Don sphere
   v
Old Great Bulgaria
```

Greater Bulgaria is a complete baseline endpoint. Higher forms add new campaign horizons rather than serving as required steps for baseline completion.
