# Geographic state groups

This file defines semantic groups only. Exact Hearts of Iron IV state IDs are intentionally unresolved until the installed map is inspected.

## BG_CORE

The starting Bulgarian core territory that anchors every route.

## GREATER_BULGARIA_CENTRAL

The principal baseline proof for Greater Bulgaria. It should cover the central San Stefano and modern national-question set, centered on Macedonia, Western Thrace, Southern Dobruja, and selected western border regions after state-level research.

## GREATER_BULGARIA_OUTER

Additional historically relevant regions that can provide claims, diplomatic pressure, or optional integration without all being mandatory for first formation.

## IMPERIAL_BALKAN_CORE

The broader Balkan dominance set used by the Bulgarian Empire route. Exact requirements should be grouped by strategic region rather than forcing a single enormous all-or-nothing list.

## BLACK_SEA_GATEWAY

Ports, coast, and connecting territory needed to make northern Black Sea expansion logistically credible.

## CRIMEA_GROUP

Crimean territory. It can be strategically important to the final route without being described as an uncontested core of historical Old Great Bulgaria.

## AZOV_TAMAN_CORE

The Sea of Azov approaches and Taman Peninsula. This is part of the strongest historical-geographic core for the final route.

## KUBAN_CORE

The Kuban steppe and lower Kuban region. This is a principal final-formation group.

## LOWER_DON_CORE

The lower Don and nearby steppe approaches. This is a principal northern proof group.

## SOUTHERN_UKRAINE_OUTER

Bounded southern Ukrainian steppe territory used as an outer strategic group. Exact requirements need conservative map and historical binding.

## STEPPE_OUTER

Optional adjacent steppe regions that can support late-game claims or integration but should not be required merely to inflate the formable.

## Binding rules

- Use `hoi4.map_inspect` or the current supported map route before assigning IDs.
- Prefer whole state groups that form readable geographic shapes.
- Record every required, optional, subject-counting, and excluded state.
- Do not force modern state borders to masquerade as exact seventh-century borders.
- Reconcile with other formable state reservations before finalizing.
