# 120 Widespread Mutiny, Part 5: Ownership, connections and Chaos

## One physical history for each formation

The same soldiers can appear in several political stories. Their physical loss, release or transfer has one owner and one recorded outcome. Event 114 can record their first desertion, Event 120 can organize their refusal, Event 009 can end the relevant war, and Event 116 can offer a viable recipient. Those events must agree about who is still present, who holds the weapons, and which obligations remain.

The unit is tracked as an actual formation with its current personnel, equipment, experience and identity. Its template name is descriptive. Renaming a template does not create a different formation. Its legal owner, current controller and commanding host can be different countries. A lawful decision requires the authority relevant to that outcome.

Every irreversible disposition identifies the originating country and its current incarnation, the incident and cohort, the exact surviving formation or personnel set, the recipient when relevant, the agreed outcome and the actual committed result. The player's selected report is never the authority for a delayed operation.

| Disposition | Personnel | Equipment | Military authority |
| --- | --- | --- | --- |
| Continued refusal | Remain in the existing formation | Remain with their actual custodian | Disputed duties are restricted, legal ownership remains |
| Delivered return to service | Surviving present soldiers resume their accepted obligation | Uses actual surviving equipment | Command resumes under the delivered terms |
| Partial desertion | Only measured departing personnel leave deployed service | Follows the original owner's recorded departure rule | The surviving formation continues, the departed group has a separate outstanding status |
| Agreed demobilization | Move to protected release, with any native refund reserved correctly | Secured serviceable property returns once to the entitled owner | The formation's service ends or its verified released component leaves |
| Warlord defection | Exact surviving accepted contingent changes owner | Only measured property accompanying that contingent transfers | Recipient gains control after destination proof |
| Council separation | Exact consenting forces enter the prepared country | Only accepted formations and measured property transfer | Council gains its actual command and obligations |
| Combat destruction | Actual casualties and survivors follow combat evidence | Actual destruction, capture or recovery is recorded | A destroyed formation cannot later transfer or return |

No outcome creates a second reserve from the same people. Demobilization, desertion and transfer are not deaths. They do not call the civilian population-loss mechanism. Actual combat casualties remain the responsibility of the existing military and shared Chaos systems.

## A disposition commits only once

Selection reserves the intended set without deleting it. The government sees the real size and commitments. At commitment, the current authority, surviving membership, destination viability and earlier receipts are revalidated together. If a formation has changed materially, the proposal is revised or cancelled with its actual refund rule. A different convenient formation is never silently substituted.

Destination preparation must finish before the source is irreversibly consumed. A prepared country, template or visual marker alone does not prove that the destination owns the correct soldiers. The transfer needs evidence of the required live state on the destination and an exactly corresponding source outcome. Any staging mechanism must prevent temporary duplicates from fighting, supplying manpower, producing rewards or being selected by another system.

If preparation fails, the source retains its real soldiers and property. If an operation reaches an uncertain irreversible boundary, the exact disputed set is quarantined from further scripted transactions until reconciled. It cannot receive a second attempt that recreates missing troops by guesswork. A truthful failure report is preferable to a success message based on a requested amount.

These are required conservation outcomes. The inspected repository does not yet prove the native operations for arbitrary existing divisions, partial nonfatal personnel removal, or full live-state transfer. The implementation handoff keeps those gaps explicit. Event 019's approved reconstruction of its own generated units is a precedent for transaction discipline and carries narrower guarantees. It is not an approved substitute for Event 120's existing formations.

## 114 Demilitarization: a shared crisis, separate duties

The connection opens only when Event 114 owns a live compatible Desertion Crisis or an outstanding departure receipt for the exact soldiers involved. A generic demilitarized country flag is insufficient. The two systems distinguish an incident-pressure handoff from a physical-force handoff.

An active 114 crisis can increase Event 120 entry pressure and import the existing grievance, worse live Disaffection, relevant confidence history and already elapsed obligations. This receipt is consumed once. Merely viewing both crisis categories cannot add pressure again. Neither event resets the other event's deadline or gives a second favorable opening promise.

| State of the soldiers when the systems meet | Accepted Event 120 behavior |
| --- | --- |
| Still fielded, no physical departure committed | The first committed disposition becomes physical owner. The other system revalidates and skips any consumed target |
| Partial personnel loss already booked by 114 | Event 120 can organize only the measured outstanding departed people, while the surviving formation remains under its recorded owner |
| 114 dissolution scheduled but incomplete | One owner completes or cancels the agreed schedule. Event 120 can receive a future handoff, with no early transfer reward |
| 114 departure completed with delayed return liability | A lawful transfer consumes or transfers that exact outstanding liability once, preventing a later duplicate return |
| Equipment retained in the source by 114's partial-desertion rule | The recipient receives no copy of that equipment. Any later armed force needs an actual equipment source |
| Already returned, demobilized, destroyed or transferred elsewhere | The same people cannot be selected again under an old receipt |

Negotiation can combine the political settlement while keeping material origins distinct. A single commitment can promise discharge to the 114 group and leave to the surviving 120 formation. Each completed component is assessed separately. The country receives one confidence outcome for the actual major promise, with no double reward from two interfaces.

Suppression can drive an already armed departing group into organized resistance. A disarmed group cannot become a full division solely because suppression was selected. It needs actual recovered or donated equipment, a present force and a viable recipient. The armed recipient can be a council or the preferred compatible warlord.

The current 114 documents describe this ownership boundary, but no live cross-event receiving adapter was established in the repository inspection. Implementation must connect both owners and prove interruption, reload and callback order. Until then, the shared physical transaction remains a named dependency rather than a hidden approximation.

## 009 White Peace: settle the right war

White Peace owns its candidate pool, diplomatic settlement and ordinary peace reporting. Event 120 supplies contextual evidence about a particular eligible pair and receives the actual result. It cannot create an otherwise invalid peace candidate or treat a local compact as national peace.

For this connection, a major mutiny means either an organized cohort that has refused a delivered settlement, or actual affected deployed strength of at least 10% of the incident's opening army. The affected troops must belong to the war relationship being scored. Mutiny on a different front does not qualify merely because the country has the same flag.

The proposed score adapter applies once to the selected pair's existing positive weight:

| Current pair context | Mutiny multiplier |
| --- | --- |
| One side has a relevant major mutiny | 1.25 |
| Both sides have relevant major mutinies | 1.75 |
| Both sides have major mutinies and a sustained valid reciprocal front compact | 2.00 |

Use the strongest applicable row. It replaces the weaker row and does not multiply them together. The final pair still competes in Event 009's complete candidate pool. These numbers are authored balance anchors. Their effect on selection probability requires the full live pool and the owner's final score arithmetic.

When the actual settlement commits, its exact former belligerents, war relationship and settled scope are passed to the matching front incidents. The country can remain in another war. Only formations whose disputed obligation belongs to the settled relationship begin that stand-down or discharge review.

Peace removes the resolved offensive demand and can start the 10-day sustained-peace reduction in Disaffection. It does not deliver an overdue train, secure abandoned equipment, finish a discharge queue or restore trust in a broken leave promise. A government chooses or completes the appropriate local disposition. Soldiers can return to lawful noncombat duty, take agreed leave, repatriate or demobilize under the recorded terms.

Where a council is already independent, peace between the two former governments does not silently annex it or settle its own wars. The council's participants and territorial settlement require their own lawful agreement. If its original purpose has ended, the council can pursue reintegration or civilian government through Part 4.

Event 009's existing suppression of duplicate generic peace credit stays authoritative. Event 120 may later reduce only its own remaining instability after actual recovery. It grants no second immediate Chaos reduction for the same diplomatic transition.

## 116 Warlords: prefer a viable existing recipient

A compatible established local warlord can receive the exact mutinous contingent before a new country is created. Viability means more than having a tag. The recipient exists in its present incarnation, owns or controls a sustainable base, can feed and equip the accepted troops through a real route, has political authority to admit them, and has not already consumed the same transfer.

Locality is operational. Prefer a reachable recipient in the cohort's current state or an adjacent connected region, then one with a short verified secure land route. An ocean-separated warlord with no transport and access plan is not local because it belongs to the same continent or ideology. A warlord already being eliminated cannot receive troops into a nonexistent capital.

The offer identifies the actual contingent, personal and heavy equipment, promised command rights, service terms, repatriation rights and any unresolved obligations. The soldiers' acceptance and the recipient's acceptance are separate from the source government's consent. An armed defection can occur against the source government's wishes, but it still cannot seize equipment that is not with the defectors.

Rank viable recipients by secure supply, compatible terms, civilian risk, then continuity of the contingent. A ready existing recipient is preferred over another breakaway when those conditions are met. The AI refuses a recipient that is likely to destroy the force immediately or demands an impossible transfer. A human sees meaningful alternatives when more than one viable recipient exists.

After destination proof, the warlord gains only the transferred people and property. The sender consumes that same disposition and passes any accepted return or demobilization liability. Event 120 does not also release a council containing the same contingent. A later change of allegiance is a new political decision concerning the current real force, with no resurrection of its former state.

The bilateral evolution checks both origins. One warlord can receive both when it honors their shared terms and each contingent agrees. Otherwise their outcomes separate. A warlord's other wars, faction obligations and political ideology do not automatically bind the second origin through a joint council label.

The Event 116 runtime receiving contract was not found in the inspected repository. The acceptance and handoff described here are required future owner work. Event 014 or Event 019 warlord-like actors cannot be treated as Event 116 merely because their fiction sounds similar.

## Chaos follows concrete consequences

The event has a Low entry and can produce larger consequences through unresolved military refusal. Each source below records the actual milestone, its incident lineage and the amount posted after caps. Values are tuning proposals in Chaos points. Shared war, death, annexation and ordinary diplomatic consequences remain with their existing owners.

| Concrete milestone | Event-owned change | Guard and reason |
| --- | --- | --- |
| First actual refusal disrupts a country's fielded force | +5 | Once per country incident, with at most three credited countries and +15 total for one worldwide opening draw |
| A connected second or third cohort actually begins refusal | +5 each | Once per admitted cohort, at most +10 per country incident, normal spread and manpower caps still apply |
| Failed containment causes an actual new loss of government military authority | +5, or +10 when loyal committed troops also defect | One highest-severity credit per incident, later worsening can add only the uncredited difference |
| A reciprocal compact actually prevents the participating opposing forces from carrying out government orders | +5 | Once per exact disjoint front pact, at most two credited pacts per originating country incident |
| A new independent armed council acquires viable territory and actual command | +10 | Once per institution lineage, including all later carrier incarnations, with one receipt shared across both origins |
| The council or compatible mutineer movement establishes a third sustained front agreement in a new hostile relationship | +5 | Once after 30 days of actual compliance, all sectors distinct, renewal is insufficient |
| A council sustains a material increase in independent power | +5 per distinct power milestone below | Campaign lineage limits and measured growth prevent repeated reward loops |

First manifestation requires real military disruption. An empty incident record, an expired popup and a purely administrative registration receive zero. A split callback cannot create more credited countries than the original frozen draw. Repeated ordinary outbreaks in a country have a 180-day first-manifestation credit cooldown from its previous credited opening, independently of whether normal gameplay eligibility has resumed.

Baseline spread credits require the first refusal of the newly admitted real cohort. Moving existing members between reports or splitting the same formation does not qualify. Across the same worldwide occurrence, baseline spread credits are limited to +20 within any 90-day window. The consequences still happen if a credit cap is reached. The history explains a zero additional change without concealing the military outcome.

For a bilateral pact, the two constituents share one milestone receipt. The first side cannot post the source and leave the second side free to post it again. A failed crackdown posts only the additional abnormal breakdown. Starting a war or causing battle deaths through that crackdown does not duplicate the shared sources.

## Sustained council power and reversal

The country package has three distinct, once-per-lineage power milestones. Each needs 90 days of sustained effective control and an actual increase from its founding snapshot.

| Milestone | Required increase | Exclusions |
| --- | --- | --- |
| Industrial independence | At least five additional functioning factories, reaching at least 15 total, through paid construction, recovery of previously unavailable capacity or a lawful accepted territorial settlement | The same repaired factory counts once. Repeated damage and repair cannot produce another milestone |
| Broader civilian jurisdiction | An accepted territorial settlement expands the founding jurisdiction by at least one indispensable adjacent state and one million residents, with the required civilian mandate | Founding transfers, occupation without mandate and repeated ownership cycling do not count |
| Independent operational reach | The force can sustain two distinct connected operational sectors for 90 days using actual supply and paid or transferred conventional forces, while its original disputed settlement remains unresolved | A duplicated front record, allied forces without authority and a newly named template do not qualify |

These milestones measure the exceptional movement's durable ability to act outside its former command. They do not authorize extra territorial objectives, conquest ladders, subjects or free factories. The allowed territorial policy remains Part 4's founding footprint plus at most one indispensable adjacent supply state. An orderly council whose founding obligations are already settled gains no operational-reach credit merely for building a normal peacetime army. Total power-growth credit is capped at +15 for the institutional lineage.

Recovery can reverse the event's continuing instability. Each credited milestone records its reversible portion. A fully settled opening or spread cohort can reverse its actual +5 after 90 days of lawful disposition. A failed-containment source can reverse at most +5 after command or discharge has remained settled for 90 days. An enforced front pact can reverse its +5 when a lawful settlement, rotation or discharge ends the imposed military impasse and survives 90 days. An armed-country founding source can reverse at most +5 after durable reintegration or a civilian-backed settlement resolves the founding dispute.

Network and power-growth credits are historical structural consequences and have no automatic reversal. Actual deaths and generic war effects are also outside this ledger. Losing a council's capital does not erase those facts. Military defeat can begin a containment review only when surviving forces, prisoners, civilian authority and outstanding promises have a lawful disposition.

Reductions use only the amount actually posted for that receipt. A milestone suppressed by a cap cannot later earn a reduction. If Event 009 or another shared owner already credited the identical reversal, the overlapping portion is zero. Splitting countries, releasing a carrier, renewing a pact, changing player tag or loading a save cannot reset the consumed amount. The global Chaos floor still applies.

## Succession, shutdown and long aftermath

Annexation transfers or closes obligations according to the actual successor's authority. A newly released country using the same tag receives a new incarnation and cannot inherit expired popups, paid proposals, temporary restrictions or reward eligibility. Durable historical proof remains attached to the original lineage.

Capitulation does not necessarily destroy every soldier. Surviving formations, expeditionary service, protected discharged people, prisoners and lost equipment retain their separate recorded status. If no lawful recipient remains, the system closes impossible choices and presents the concrete remaining outcome. It does not invent a restoration country or an army to keep the event alive.

On final recovery, release only Event 120's own reservations, temporary restrictions, mission timers, spirits and AI commitments. Existing shared diplomacy, other-event incidents, normal command assignments and meaningful country content survive according to their owners. A stale cleanup call must prove the same incident and incarnation before removing anything.

The visible aftermath records the army that remains, fulfilled and broken promises, losses and releases, the status of each council or recipient, and any protected period still running. The history can influence a later outbreak for the bounded duration in Part 1. It is not an endless national penalty after the actual grievance has been resolved.
