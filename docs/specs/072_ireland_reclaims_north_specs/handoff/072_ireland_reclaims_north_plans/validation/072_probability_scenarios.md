# AI and probability scenarios

Begin with probability inspection and identify actual event, MTTH, AI decision and focus inputs.
The scenarios are design fixtures, not completed calculations.
Keep exact deterministic gates separate from weighted choices and time-varying MTTH eligibility.

Use evaluation and sweeps for exact named inputs.
Use simulation only for explicitly uncertain variables and report sampling assumptions.
Use sequence or timing views only when supported by the actual probability tool contract.
Retain rendered sensitivity or timing evidence when it improves review.
Do not claim a scripted AI strategy's target selection has been proven by probability evaluation alone.
Actual army staging, pathing, supply and naval conduct need separate game evidence.
