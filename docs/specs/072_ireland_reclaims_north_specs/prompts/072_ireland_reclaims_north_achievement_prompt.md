# Implement and illustrate the Event 072 achievements

Read the current achievement system, event assets skill, supplied icon-worker and completion-auditor profiles, and the complete campaign specifications.
Implement the ten contracts reproduced below using the existing eligibility and debug-disqualification rules.
The labels remain working directions until final localisation is written from the actual conditions.

Create each independent 64 by 64 completed icon and the approved locked-grey and not-eligible variants with the immutable project templates.
Keep actual runtime paths and sprite consumers in the final asset manifest.
Do not downscale a focus or news image and call it an achievement icon.

Implement reliable campaign provenance, player-country eligibility, permanent failure and success, interval tracking, distinct paid contributions, actual sovereign membership and event-specific one-time guards.
Test every negative condition as well as the positive case.

Never silently weaken the achievement or unlock it solely because the event fired.

## Tracking and anti-farming

Continuous intervals are recorded from verified game dates and reset on the actual failing condition.
A final-state check alone cannot prove an interval without breaches.
Keep eligible-country and campaign provenance through supported cosmetic and government changes.
A player changing country must follow the existing achievement system's policy and cannot simply inherit another country's earned conditions.

Where an exact gameplay fact cannot be reliably queried, the achievement remains blocked or is revised through an explicit design change.
Do not silently replace no foreign intervention with a different easy condition.
Do not make an achievement unlock because the event fired, the tree loaded, or a formation button was clicked without the additional requirements.
