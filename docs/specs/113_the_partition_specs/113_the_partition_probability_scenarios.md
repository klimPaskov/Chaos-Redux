## Common fixture envelope

The base date is 1 January 1940 and the first observation is before any Event 113 action that day.
The base form is baseline, Chaos is 100, all listed countries are normal civilian identities, and every omitted diplomatic relation is absent.
Every state is fully controlled by its listed owner.
Every country is independent, at peace, outside factions, without guarantees or active local crises unless a scenario changes that fact.
No country has prior Partition history, accepted commitments, unanswered requests, cooldowns, temporary strategies, or receipt records unless specified.
Every external selection and AI modifier must be explicitly neutral in the fixture adapter, or enumerated with its current value if neutrality cannot be established.

The evaluator records language, date, source revision, mod set, difficulty, player identity, country generation, relevant settings, native cost modifier, army technology, and enabled shared sources.
It must list a nonneutral external factor rather than silently assume it away.
Any result whose source or external inputs remain incomplete is classified unresolved.
