## The design

Every current subject receives an immediate native autonomy grant worth 25 percent of its current full tier interval.
The subject's normal requirements still govern any change of status.
The two optional next-firing evolutions add a finite growth opportunity and individual negotiations within each master's sphere.
Both can produce real domestic setbacks, with active recovery, optional assistance, and a free civilian withdrawal route.

The balance values are concrete proposed starting points, not measured playtest results.
The ordinary event is complete with both evolutions disabled.
The proposed classification is Minor Repeatable, Chaos level 1, Liberations membership of Low severity; these remain proposals pending parent confirmation.
Self-Government Momentum enters at proposed tier 2 and Common Demands at proposed tier 3.
