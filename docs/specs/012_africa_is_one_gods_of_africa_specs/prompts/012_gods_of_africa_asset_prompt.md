# Asset production prompt

Create the accepted Gods of Africa visual package for Event `012`.

## Cultural and visual rules

The Gods are a fictional state doctrine formed after African unification. Do not present a universal historical African pantheon. Do not combine unrelated sacred objects, masks, animals, monuments, scripts, and religious symbols into a generic continental collage.

Use one coherent fictional institutional design across all assets. Draw cultural specificity from a named scene, location, or Event 012 route when the brief provides one.

## Generated scene assets

Route to `chaosx_generated_event_art`:

- activation report or news image
- participant decision category picture
- optional credibility super-event image if implemented
- accepted fictional doctrine panels or emblems

Generated scenes must use 1936 to 1945 material culture and documentary realism. Avoid modern screens, digital equipment, contemporary tactical gear, readable generated text, map-only compositions, and generic fantasy throne rooms.

## Icon assets

Route to `chaosx_icon_artist`:

- Gods of Africa Strength icon
- Wrath of the Gods icon
- fulfill, substitute, extension, refuse, and defy decision icons
- Africa-side priority, leniency, offender, protection, pardon, and escalation icons
- accepted doctrine idea icons
- accepted focus icon families
- achievement triplets

Each icon type needs separate source art for its own consumer. Do not resize focus art into idea or decision icons.

Request native transparency for alpha-backed families and preserve alpha through DDS conversion.

## Reference requirements

Before production:

- inspect the canonical skill-local reference folder for each asset type
- inspect the live vanilla or Chaos Redux consumer
- lock target size, background rule, path, and sprite name
- register stable runtime names before final production

## Optional animation

Do not create animation unless the parent accepts a dedicated GUI or another clear state-driven consumer.

One acceptable later role is a high-Wrath warning seal. It requires genuine per-frame source art, native transparency, a static fallback, frame sheet, review GIF, contact sheet, and verified runtime wiring. Transform-only or filter-only motion is invalid.

## Handoff

For every asset provide:

- source file
- prompt or source notes
- processed PNG
- final DDS
- target size
- runtime path
- proposed sprite
- consumer
- alpha and alignment review
- contact sheet where relevant
- manifest
- permanent provenance plan
- blocked items and reasons

Do not edit gameplay, localisation, GUI, focus, decision, or spreadsheet files unless the parent grants exact narrow scope.
