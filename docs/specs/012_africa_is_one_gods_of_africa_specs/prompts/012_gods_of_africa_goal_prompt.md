# Goal: Implement Gods of Africa for Event 012

Implement the complete `Gods of Africa` subsystem under Event 012, `Africa Is One`, from the accepted specification package. This is not Event 070. Remove that catalog assignment and leave Event 070 available for another idea.

Activate it only after Africa Is One has fired, the unifier exists, Evolution I is active, and the consolidation delay has passed. Keep it Event 012 owned. Use a bounded participant registry and owner-managed delays. Do not add a separate random event or unrestricted whole-world scan.

Enroll every valid major and player country independently. Expose exactly two values. `Gods of Africa Strength` is global and derives from African power, continental control, war condition, stability, technology, Chaos, and Event 012 development. `Wrath of the Gods` is per participant. Keep relationship and settlement history hidden.

Create an indefinite tribute loop with one active demand per participant. Generate only demands the target can satisfy. Scale them from target capacity, Wrath, Strength, Chaos, Africa's needs, conduct, and recent repetition. Material tribute must reach the unifier through real transactions, never simulated transfers.

Participants may comply, negotiate, substitute valid tribute, refuse, or permanently defy. Respect the action budget. Defiance stops ordinary demands, sharply raises Wrath, abandons normal friendship, and leaves punishment, retaliation, protection withdrawal, and conflict active. Permit only the accepted restoration route.

Separate punishment intent from its capability ceiling. Wrath raises intent and Strength sets the highest tier. High Wrath alone cannot unlock catastrophe, and a first refusal cannot cause national ruin. Weak Africa produces pressure, unrest, limited disruption, failed manifestations, and bounded sabotage. Extreme harm requires extreme Wrath, extreme Strength, and every accepted gate. Reuse Event 013 where valid. Route civilian loss through the exact shared helper and Deaths once.

Give Africa real agency. The unifier receives tribute, reports, diplomatic memory, protection duties, and bounded choices over needs, leniency, priority targets, and proven offenses. Add the accepted Event 012 focus overlay branch, with doctrines that reshape demands, protection, retaliation, and settlement. Avoid a detached tree or modifier ladder.

When Africa secures the continent, stop demands and calculate one hidden-history settlement per participant: Favored, Respected, Distrusted, or Enemy. Loyal support earns substantial reciprocal rewards. Capitulation or disappearance of the unifier cancels demands, punishment, participant state, and current authority.

Keep the core loop functional without DLC. Optional mechanics may add valid demand families. Complete localisation, assets, Event 012 docs, SCN-011, milestone logging, and catalog alignment. Edit the XLSX only, then run the exporter.

Before engine-facing work, inspect the offline wiki, vanilla documentation and precedents, repository patterns, and HOI4 MCP surfaces. Audit weighted logic with the named scenarios before changes and compare afterward. Use the required specialist subagents. Use the UI worker only for a justified dedicated GUI.

Completion requires every accepted mechanic, AI route, cleanup path, asset, text surface, document, and catalog field to agree. Report every blocker, fallback, omission, and simplification. Do not invoke autonomous desktop playtesting unless explicitly requested.
