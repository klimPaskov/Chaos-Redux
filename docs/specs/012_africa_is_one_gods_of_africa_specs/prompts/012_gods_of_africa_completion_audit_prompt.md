# Completion audit prompt

Run a read-only completion audit of the Gods of Africa Event `012` subsystem.

## Sources

Compare:

- the complete accepted Gods of Africa specification package
- all Event 012 specs, plans, docs, handoffs, and implementation files
- all Event 070 references
- Event 012 and Event 070 workbook rows
- SCN-011
- decisions and missions
- focus tree
- scripted effects, triggers, constants, targets, and on-actions
- AI and probability evidence
- localisation and scripted localisation
- event logs and Event Details
- assets, GFX, super-event, audio, and manifests
- all subagent handoffs and unresolved addenda

## Blocking acceptance rules

Flag completion as blocked if any of these fail:

- Gods of Africa is fully owned by Event 012
- Event 070 is free of the old assignment
- only Strength and Wrath are public values
- every participant has isolated Wrath and one active demand
- demand family and amount follow real need and target capacity
- material tribute reaches Africa
- protected reserve and no-DLC rules work
- punishment cannot exceed Strength
- first refusal cannot reach Tier IV or Tier V
- Tier V uses the full gate and emergency sequence
- natural disasters use Event 013 gateway
- population loss uses exact shared accounting and Deaths once
- defiance, reconciliation, war, defeat, and final settlement work
- Africa pays real costs for protection
- Event 012 focus routes are complete and readable
- AI and every weighted surface have baseline and comparison evidence
- routine demands do not enter random pacing or flood the Event Log
- required assets are final and wired
- cultural review passes
- docs and authoritative workbook match final in-game wording
- every accepted plan is implemented, queued with reason, or rejected with reason

## Evidence

Require task-specific evidence. Do not treat source-only review as a substitute for mandatory MCP event, focus, probability, or GUI evidence.

## Output

Return:

- source-of-truth map
- implemented surface inventory
- missing or simplified requirement table
- Event 070 migration result
- demand-family coverage
- punishment-tier coverage
- focus route coverage
- AI probability evidence status
- asset and super-event status
- documentation and workbook status
- unresolved addenda
- blockers
- final completion verdict

Do not patch gameplay files.
