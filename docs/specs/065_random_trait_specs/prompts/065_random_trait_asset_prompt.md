# Event 065 Random Trait Asset Prompt

## Role

Use `chaos-redux-event-assets` and the relevant generated event-art worker.

Read `AGENTS.md`, the Event 65 specification package, and the event-asset skill before creating files.

Work only inside the Event 65 asset scope.

## Consumer

- Surface: normal report event
- Sprite: `GFX_report_event_leader_trait`
- Runtime file: `gfx/event_pictures/065_random_trait/report_event_leader_trait.dds`
- Final dimensions: `210x176`
- Canvas: opaque
- Animation state: static
- Source mode: generated fictional documentary scene

## Existing asset check

Inspect the current runtime DDS before replacing it.

Repository metadata in the planning snapshot reports a size of `130` bytes.

Verify:

- real DDS format
- native dimensions
- compression
- readability
- crop
- visible content
- alpha behavior
- in-game consumer
- source and provenance

Do not discard a valid approved asset without evidence.

Do not reuse an invalid placeholder.

## Image direction

Create a fictional mid-century press or international conference image.

Show several anonymous political leaders or senior public figures in one coherent documentary scene.

Their posture, clothing, papers, expressions, and surrounding details should suggest incompatible roles and temperaments.

The image can include signs of military authority, economic administration, nervous exhaustion, public confidence, rigid ceremony, or eccentric personal behavior.

Keep the scene readable at `210x176`.

Use a period news-photo treatment that matches the established Chaos Redux report-event reference family.

Use restrained grayscale or mild sepia when the inspected references support it.

The figures must not resemble specific real historical leaders.

Do not include readable text, flags that imply a specific country, modern objects, interface symbols, split panels, trait icons, fantasy glow, caricature, or a collage of disconnected portraits.

The event is absurd, but the image should look like a serious period report photograph.

## Reference inspection

Inspect the canonical vanilla-reference root named by the event-asset skill.

Open the event-art catalog, report-event references, contact sheet, and native dimensions.

If the required contact sheet or reference documentation is missing, create and document it before producing the final asset.

Record the exact references used for composition, crop density, contrast, and card treatment.

## Required files

Create the normal Event 65 asset workspace during production.

Retain:

- generated provider source
- generation metadata
- full-size source PNG
- approved crop preview
- processed `210x176` PNG
- final DDS
- contact sheet or comparison preview
- source and transformation manifest
- review notes
- runtime handoff

Promote durable provenance and review facts into permanent Event 65 documentation before the temporary workspace is removed.

## Processing

Preserve the approved composition through resize and conversion.

Check faces, hands, podiums, papers, and frame edges after the final crop.

Avoid crushed blacks and flat gray haze.

Sharpen only enough for the small report-event consumer.

Use the compression format required by inspected working report-event references.

## Wiring boundary

The asset worker prepares the sprite handoff and confirms the intended sprite name.

The main implementation agent owns the final `.gfx` edit and live event wiring.

Do not edit gameplay logic.

## Acceptance

The handoff must include:

- source mode and prompt record
- exact output paths
- image dimensions
- DDS format and compression
- file hashes
- reference files inspected
- crop comparison
- visual review result
- runtime consumer
- unresolved issues
- statement that the image contains no recognizable real person and no readable text

Do not create additional Event 65 icons or portraits unless the accepted specification is revised.
