# Event 065 Random Trait Localisation Audit Prompt

## Role

Run `chaosx_localisation_auditor` after Event 65 runtime data and report states exist.

Read `AGENTS.md`, the Event 65 specification package, the event skill, the current Event 65 localisation, generated trait-name selector, Event Log text, Event Details text, Evolution text, cluster text, and workbook-facing summaries.

This is a patch-capable Event 65 scope.

Inspect supported UI scales and languages already covered by the project when available.

## Writing requirements

The report should present an unexplained global change through concrete observed behavior.

Keep a dry and direct tone.

Show the local leader and accepted trait names.

Keep the global summary readable.

Avoid generic filler about the public watching, history changing, a new chapter, uncertainty gripping the world, or leaders approaching government and war differently.

Do not expose:

- registry indexes
- source IDs
- parser terms
- weight formulas
- debug counters
- implementation notes
- hidden technical exclusions

Use the source trait name when available.

Use a readable Event 65 fallback when the source name is missing.

Do not invent a false modifier description for a fallback.

Handle singular and plural grammar for every visible count.

Five trait names must fit without clipping.

Move the list to a tooltip when the normal description cannot fit cleanly.

Do not use em dashes or semicolons in player-facing sentences.

Preserve dynamic tokens and gameplay meaning.

## Cross-surface consistency

Align:

- Event 65 report
- Event Log

- Randomizations cluster text
- event documentation
- workbook summaries
- shared event-name mapping

The supplied user names `Random Trait`, `Double Traits`, `Exceptional Personalities`, and `Walking Contradictions` remain accepted.
