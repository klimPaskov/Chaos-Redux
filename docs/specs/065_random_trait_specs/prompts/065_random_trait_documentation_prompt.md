## Writing rules

Document implemented facts.

Do not copy temporary planning prose into permanent docs.

Do not preserve stale TODO text.

Use one clear sentence per line where the repository style expects merge-friendly Markdown.

Keep headings descriptive.

Avoid empty sections and repeated summaries.

Do not include player-facing localisation drafts.

Link to generated manifests and audit handoffs by repository path.

Record versions, checksums, and source roots where they matter.
