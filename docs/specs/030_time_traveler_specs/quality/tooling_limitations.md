# Tooling and Evidence Limitations

## Available evidence

This planning pass had access to every file supplied with the task, including all Markdown skills, the configuration file, three CSV exports, the event brief, and all twenty subagent TOML definitions unpacked from the ZIP.

It also had web access for institutional historical research and a connected read-only GitHub view of the public Chaos Redux repository. Repository search found no indexed `chaosx.nr30`, `time_traveler`, Event 30 implementation, or `SCN-015` registration. The existing specification package layout was inspected to shape this delivery.

## Unavailable evidence

The following required project resources were not exposed in this environment:

- a mounted writable Chaos Redux checkout
- the offline `paradox_wiki/` snapshot
- the installed Hearts of Iron IV directory and vanilla documentation
- approved Workshop reference files
- the production `hoi4-agent-tools` MCP server
- the Meshy and Blender production routes
- the project custom subagent spawn runtime
- the authoritative `chaos_redux_events_catalog.xlsx` workbook
- the user's live game and debug shortcut

## Consequences

This package cannot claim that:

- Clausewitz syntax was implemented or parsed
- event, focus, technology, probability, GUI, or map MCP evidence exists
- any custom subagent produced or audited a patch
- real-person portrait ownership was checked against the live repository and installed content
- scenario ID `SCN-015` is free in the current workbook
- any image, DDS, animation, model, sound, counter, or portrait was produced
- any spreadsheet was edited or CSV export regenerated
- the game was launched or tested

## Compensating work

The package provides context-complete prompts, explicit file and system ownership, named probability scenarios, source gates, asset inventories, acceptance criteria, and a final completion audit prompt. These reduce implementation ambiguity but do not replace the missing evidence.

The implementation agent must read the actual current repository and required local references before editing. Any conflict between this planning package and current live source must be resolved explicitly and documented.
