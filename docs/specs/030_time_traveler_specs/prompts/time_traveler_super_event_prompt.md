# Event 030 Super-Event Prompt

Create and wire the accepted Event 030 super-event packages. Read `AGENTS.md`, the complete Event 030 source package, `chaos-redux-events`, `chaos-redux-super-events`, `chaos-redux-event-assets`, and `chaos-redux-subagents`.

Required packages:

1. baseline verified arrival
2. War of the Possible Futures after the first genuine international temporal conflict
3. Machine Extinction War world-end activation
4. machine defeat aftermath only after a long multi-region global crisis

A historical restoration receives a super-event only when it changes a major regional order. Ordinary figure arrivals use report or news events.

Use `chaosx_super_event_text_researcher` for quote, button remark, exact wording, attribution, copyright-risk, and cultural reference research. Use `chaosx_super_event_audio_researcher` for licensed structured musical cues, legitimate downloads, WAV conversion, and documentation. Use the correct sourced or generated art worker for each image.

Do not invent quotes. Do not use unsourced lines, long copyrighted dialogue, generated music, test tones, drones, stingers, placeholder audio, or another super-event's track. Every package needs a unique final track unless the user explicitly approves an exact reuse.

For each package define and verify:

- campaign role and trigger
- intentional slot
- title, description, button text, and quote
- source and confidence for quote and cultural remark
- unique image and GFX wiring
- unique audio ID, base sound, settings-volume wrappers, and final WAV
- `global.current_super_event_audio_id`
- `play_current_super_event_sound = yes`
- scripted localisation including image selection
- event or effect trigger
- documentation and canonical music catalog row
- authoritative event catalog alignment

Text direction:

- baseline centers on verified impossible knowledge and government reaction
- possible-futures escalation centers on open conflict among temporal alignments
- machine world end centers on industrial conversion and causal monopoly
- defeat aftermath centers on survival, loss, reconstruction, and the choice over captured cores

Avoid generic end-of-world wording, film references, machine catchphrases, and effect lists. Write final player-facing localisation only after research is complete.

Write all research notes, files, identifiers, sources, licenses, durations, checksums, conversion notes, and remaining blockers into the permanent super-event documentation and the required subagent handoffs.
