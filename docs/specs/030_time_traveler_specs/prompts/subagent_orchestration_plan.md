# Event 030 Subagent Orchestration Plan

Every project subagent receives a fully explicit prompt with `fork_context=false` in Codex or the equivalent isolated context in Qoder and Cursor.

## Planning and exploration

| Stage | Agent | Purpose | Gate |
| --- | --- | --- | --- |
| pre-implementation file map | `chaosx_repo_explorer` | map existing patterns, files, vanilla precedents, and edit order | use only if parent still lacks file locations after direct inspection |
| post-tranche design review | `chaosx_improvement_loop_planner` | write one playable expansion or closure addendum | previous addendum must be disposed first |
| reusable script design | `chaosx_scripted_system_architect` | narrow effects, triggers, constants, event targets, registries, and provider APIs | broad design stays with parent |

| Stage | Agent | Evidence |
| --- | --- | --- |
