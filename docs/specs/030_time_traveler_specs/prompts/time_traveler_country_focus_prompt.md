# Event 030 Country and Focus Prompt

Implement or audit durable Event 030 country packages and focus content. Read `AGENTS.md`, the complete Event 030 package, `chaos-redux-events`, `chaos-redux-focus-trees`, `chaos-redux-decisions-missions`, `chaos-redux-event-assets`, and `chaos-redux-subagents`. Use context-complete isolated subagent prompts.

Default rule:

- the original traveler, historical figures, and future visitors remain inside existing countries through characters, decisions, events, movements, and crisis content
- do not replace existing major focus trees
- do not create a full tree for every claimant
- a full country package exists only for a durable territorial actor with capital, government, army, economy, supply, AI, assets, and cleanup

The Closed Future is the required durable country package. Implement:

- locked non-conflicting tag after full vanilla, Chaos Redux, Workshop, and local-mod audit
- special Chaos and actual nonhuman markers
- Consensus Engine leader and Causal Monopoly identity
- normal, medium, and small flags
- parties or fixed-purpose political structure
- starting and reinforcement military package
- equipment providers, CXT registration, sustainment, presentation, and cleanup
- industry conversion, logistics, air, and strategic target behavior
- country localisation, AI, ideas, decisions, victory, defeat, and annexation cleanup
- dedicated fixed-purpose focus tree with Causal Lock, Industrial Conversion, Predictive War, Archive Erasure, optional Controlled Preservation, and Final Convergence

The tree must have clear branch ownership, visible roots, meaningful choices, decision unlocks, varied rewards, route AI, search filters, Focus Navigation where needed, and no straight conquest ladder. Use `hoi4.focus_inspect`, full-tree `hoi4.focus_render`, lint, and bounded rewrite passes until first-glance branch clarity passes. Route focus weights through the probability auditor.

Historical restoration or alternate-state countries need separate accepted package briefs before full tree work. When a civil-war or cosmetic route can carry the content safely, prefer it over a new permanent tag.

Write required audit and patch handoffs under `docs/plans/030_time_traveler_plans/subagent_handoffs/`. Report every fallback, generic branch, missing asset, absent force package, or unresolved tag collision.
