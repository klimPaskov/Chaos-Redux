# Country and Focus Package Matrix

## Actor disposition

| Actor | Default representation | Full country package condition | Focus treatment |
| --- | --- | --- | --- |
| original traveler | character inside current custodian | none | host keeps existing tree, uses decisions and crisis events |
| historical figure | character, movement, claimant, or civil-war leader | controls durable territory and forms a researched restoration | existing tree plus event overlay, full tree only after separate accepted package |
| future visitor | character, movement, adviser, or claimant | controls durable territory through a serious polity route | existing tree plus event overlay, full tree only after separate accepted package |
| displaced ancient formation | unit or local revolt | claimant plus territory, government, economy, and force | no tree by default |
| alternate state delegation | event and regional claim | durable contiguous state with recognized government | researched country package required |
| Continuity Directorate | international network | no independent territory by default | member decisions, no separate tree |
| Horizon Compact | international network | no independent territory by default | member decisions, no separate tree |
| Restoration Concord | alliance network | member restored states only | member-specific content |
| The Closed Future | nonhuman machine country | world-end activation or durable pre-terminal machine state | dedicated fixed-purpose tree |

## Closed Future focus architecture

| Branch | Gameplay purpose | Main unlocks | Tradeoff or limit | Payoff |
| --- | --- | --- | --- | --- |
| Causal Lock | secure portals and erase rival futures | node closure behind front, archive attacks, anti-portal defense | less access to alternate reinforcements | stable machine supply network |
| Industrial Conversion | turn captured factories into machine production | foundry upgrades, equipment, repair, automated logistics | requires contiguous industry and creates sabotage targets | self-sustaining war economy |
| Predictive War | identify human responses and coordinate attacks | target priorities, drone support, siege groups, deception | vulnerable to captured-core misinformation | coordinated attacks on strategic systems |
| Archive Erasure | destroy visitors, claimants, research, and human memory | intelligence operations, collaborator purges, record deletion | raises resistance and human unity | removes rival future capabilities |
| Controlled Preservation | rare alternate machine method | preserve useful populations, puppet collaborators, selective exemptions | slows extinction and creates internal logic conflict | more stable occupation with lower immediate resistance |
| Final Convergence | capstone | master network, terminal victory checks | requires industry, nodes, and strategic control | Causal Monopoly end state |

The tree needs clear fixed-purpose choices inside the machine objective. It must not be one straight conquest ladder.
