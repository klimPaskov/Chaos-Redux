# Public Values and Thresholds

## Credibility

| Range | Stage | Main unlock | Main danger |
| ---: | --- | --- | --- |
| `0-19` | Discredited | final proof, investigation, expulsion | consultation system collapses |
| `20-39` | Provisional | basic consultations | government acts on uncertain advice |
| `40-59` | Established | normal consultation pool and staff copying | foreign interest expands |
| `60-79` | Trusted | country-specific advanced advice | traveler becomes politically influential |
| `80-100` | Indispensable | strongest advice and government routes | ambition and elite dependence |

## Exposure

| Range | Stage | Foreign pool | Host response |
| ---: | --- | --- | --- |
| `0-19` | Contained | intelligence-capable infiltrators only | maintain secrecy and narrow access |
| `20-39` | Rumored | nearby majors and allies | relocate or manage rumors |
| `40-59` | Suspected | several majors and rivals | counterintelligence and selective sharing |
| `60-79` | Confirmed | abduction, assassination, diplomatic pressure | guards, decoys, public strategy |
| `80-100` | Public | global political and news response | accept permanent exposure floor |

## Timeline Divergence

| Range | Stage | Advice quality | Temporal content |
| ---: | --- | --- | --- |
| `0-19` | Recognizable | exact short-term forecasts | no persistent portal incidents |
| `20-39` | Altered | date ranges and conditional advice | small traces and contradictions |
| `40-59` | Unstable | structural warnings | stable past portals possible |
| `60-79` | Fragmented | broad strategy only | future visitors and material incidents easier |
| `80-100` | Broken | no exact political prediction | strong anomalies and machine activity |

## Evolution V conversion

| Timeline Divergence | Temporal Stability | Display stage |
| ---: | ---: | --- |
| `0-20` | `80-100` | Coherent |
| `21-40` | `60-79` | Strained |
| `41-60` | `40-59` | Unstable |
| `61-80` | `20-39` | Fractured |
| `81-100` | `0-19` | Near collapse |

Only one of Timeline Divergence or Temporal Stability is shown as the numeric third value.

## Design guard

A new persistent Event 030 value is rejected unless it changes a distinct player decision and cannot be represented by these values, a qualitative stage, an incident state, or a temporary mission. The current design has no approved fourth meter.
