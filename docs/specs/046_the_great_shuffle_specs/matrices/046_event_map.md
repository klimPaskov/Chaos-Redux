# Event 046 event map

This map defines player-facing and hidden roles without fixing final subevent numbers beyond the required Event 46 namespace.

## Automatic or cluster entry

1. The shared event system selects Event 46 or a cluster selects it as one member.
2. The Event 46 entry checks its global transaction gate and current terminal conflict.
3. The entry fixes the firing source, repeatable context, current capability, and enabled evolution state.
4. The entry opens the hidden global transaction.

## Hidden transaction chain

1. Freeze registry version, legal anchors, and valid scope sources.
2. Select families through current coverage, quota, compatibility, and dependency rules.
3. Plan every selected family's complete result set.
4. Reject any family that cannot validate before commit.
5. Commit every valid family in fixed order.
6. Reconcile each committed family.
7. Calculate one direct Chaos result from actual committed disruption.
8. Build one global summary and one personalized report projection for every human country.
9. Record one Event 46 history entry and any cluster member result.
10. Clear transaction state after every report is queued safely.

## Human report

Every human receives one report after the shared transaction finishes.

The report contains the global summary and the controlled country's highest-priority changes.

The acknowledgement option closes the report and changes no result.

## AI path

AI countries receive the same global effects and owner reconciliation.

They receive no popup and no alternate randomization.

## Evolution path

Evolutions I through IV use independent Event 46 evolution milestones after their Chaos threshold becomes valid.

A milestone records the shared evolution entry and unlocks its capability for future firings.

The milestone can occur before the first Great Shuffle.

Evolution V activates immediately at its valid threshold and then follows the World Collapse reachability contract.

Evolution activation never starts a Shuffle by itself except for the bounded pre-freeze opportunity when the live freeze order requires that route.

## Abort path

When no family can commit and no family has begun commit, the transaction closes without consuming a firing, history row, direct Chaos entry, or success report.

## Recovery path

When a save or interruption occurs after commit begins, the same transaction resumes from its protected committed position.

Recovery cannot open the entry again, reroll a family, or create a second report.

## Manual and debug path

The existing Event 46 manual event route can call the same transaction contract when normal event gates permit it.

Force and validation routes use the project's explicit test proof and disqualify Event 46 achievement progress when detectable.

They do not receive a separate simplified implementation.
