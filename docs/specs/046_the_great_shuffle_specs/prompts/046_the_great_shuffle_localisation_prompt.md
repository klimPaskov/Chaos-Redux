# Event 046 localisation prompt

Use `chaosx_localisation_auditor` after the Event 46 gameplay and report surfaces exist.

Read `AGENTS.md`, `chaos-redux-events`, the Event 046 specifications, the report priority matrix, achievement prompt, final cluster registry, and current Event Log and Event Details localisation patterns.

Inspect existing English keys before creating or renaming anything.

Keep localisation UTF-8 with BOM and follow the project's key format.

## Required player-facing surfaces

Write and audit final English text for:

- Event 46 name mapping
- entry or report event title and description
- acknowledgement option
- personalized Shuffle Report section headings and row labels
- dynamic before and after value formatting
- committed and omitted change summaries
- safety rejection summary when a selected public domain could not apply
- Event Log history name and global actor treatment
- Event Details premise
- Event Details type, Chaos level, Randomizations membership, Medium severity, and status integration
- five evolution names, descriptions, enabled state, and stage display where applicable
- Randomizations cluster name, details, member row, and severity
- Domestic Unrest cluster name, details, and accepted members
- Event 21 multiple-cluster display
- final Event 43 and Alien Invasions text only after the parent resolves the source conflict
- six achievement titles, descriptions, requirement tooltips, and hidden-state text
- asset sprite or achievement display keys required by the final implementation
- event documentation and workbook-facing wording that must mirror in-game text

## Writing direction

Describe concrete facts that changed.

Use current country, state, unit, commander, production object, law, ideology, and owner-mechanic names when useful.

Keep the tone serious with restrained absurdity.

Avoid technical words such as random variable, family ID, registry, adapter, seed, array, commit, reconciliation, save file, or script.

Do not describe population change as death, migration, birth, or evacuation.

Do not claim that equipment or values were transferred from another country.

Do not promise restoration.

Do not reveal hidden family weights, evolution timing formulas, protected state, achievement percentiles, test disqualifiers, or future structural adapters.

Do not use generic crisis prose built around officials denying what witnesses report.

Write the changed world directly.

The acknowledgement option can use dry disbelief, restrained bureaucracy, or resigned irony.

Any exact cultural quotation, slogan, lyric, film line, book line, or game reference requires source verification.

Plain original wording is preferred for this minor repeatable report.

## Report clarity

Use concise grouped rows and the project's texticons where an established icon exists.

Format large numbers and percentages consistently.

Before and after values must be clear without creating a text table made from bars or divider characters.

Do not expose raw trigger blocks.

Use custom trigger tooltips for blocked or unavailable public rows.

Keep the report readable when high-tier transactions omit many lower-priority changes.

## Audit output

List every key added or changed.

Check missing keys, duplicate keys, dynamic scope resolution, integer and percentage formatting, actor fallback, evolution display, cluster membership, achievement wording, report overflow, and workbook wording alignment.

Patch only bounded localisation and scripted-localisation issues.

Broad gameplay or UI design gaps return to the parent.
