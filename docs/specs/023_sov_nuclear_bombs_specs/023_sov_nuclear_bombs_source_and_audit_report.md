## Supplied-source discrepancies found

### Event 23 status wording

The user calls the status `To Be Reworked, baseline implementation exists`.

The supplied CSV snapshot lists Event 23 as `Unavailable`.

The specification treats the event as unreworked and disabled by default until implementation. The live repository and authoritative workbook must determine the final status fields.

### Event 23 evolution IV

The supplied CSV has no Evolution IV text.

The user explicitly defines Evolution IV as increased AI willingness to start nuclear war. This package treats the user direction as authoritative and expands it into the 1000-Chaos AI first-use gate.

### Arms-race cluster

The user names the cluster `Arms-race`.

The supplied cluster CSV contains no such cluster and no free ID can be assumed.

This package preserves the intended future cluster identity and defers registration.

### `SCN-004 Final Silence`

The mechanics guide lists `SCN-004 Final Silence`.

The supplied scenario CSV omits it.

This package flags the discrepancy and does not assign the scenario to Event 23.
