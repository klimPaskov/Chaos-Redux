## Per-job evidence

Each model row needs:

- immutable selected artwork record
- source URL, creator, rights, and AI-use decision
- exact ImageGen preparation prompt
- source-to-prepared comparison
- approved one-image Meshy input
- provider request and response
- task IDs and credit ledger
- immediate downloads and checksums
- Blender source and checkpoints
- measured geometry
- measured scale crosswalk
- material and texture report
- rig map
- action start, middle, end, and loop evidence
- sound source and synchronization map
- counter artist handoff
- mesh and animation export
- reimport proof
- proposed runtime identifiers
- parent runtime handoff
- unresolved risks

## Creature-source rule

The selected model reference should come from eligible modern designed artwork with defensible rights or explicit reference-only authorization. A source-free generated reference is a separate fallback after documented search failure and needs explicit approval.

## No batch identity reuse

A shared support model serves only its declared support family. Apex geometry cannot be reused across named monsters. A common technical rig can be considered only when anatomy genuinely matches and every action remains substantive and creature-correct.
