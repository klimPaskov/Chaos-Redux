## Shared strategic-state ordering

1. Save an endangered apex.
2. Prevent loss of the last valid lair.
3. Resolve Frenzied Hunger.
4. Defend a coastal capital or port that anchors Sea Bond.
5. Complete the current short objective.
6. Expand along valid coast.
7. Build pact or rival route.
8. Extend inland range.
9. Pursue terminal readiness.

The order is modified by creature profile and route. Terminal Cthulhu AI uses its own ordering.

## Mandatory probability scenarios

- valid port versus invalid inland state
- weak nearby port versus rich deep capital
- own lair threatened during rival hunt
- Starving Hunger with a valid feeding state
- Starving Hunger with no valid feeding state
- pact proposal under human pressure
- pact proposal during dominance
- betrayal with and without clear strategic gain
- terminal readiness with one endangered apex
