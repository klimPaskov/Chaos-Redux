# Super-event orchestration prompt: Event 043 Monsters from the Deep

Create and wire the complete Event 043 super-event package from the accepted specification.

Use no inherited conversation context.

## Read

- `AGENTS.md`
- complete Event 043 package
- super-event skill
- event-assets skill
- frame-animation skill
- event skill
- current super-event slot, image, text, sound, settings-volume, and catalog systems

## Required roles

1. Event 043 global opening
2. Cthulhu's Dominion world end
3. eligible global defeat aftermath

The aftermath super-event fires only after the accepted campaign-scale threshold. A small contained incident receives ordinary reports.

## Research routing

Use:

- `chaosx_super_event_text_researcher` for quotes, button references, wording sources, and attribution
- `chaosx_super_event_audio_researcher` for licensed musical recordings, download, editing, WAV, rights, and handoff
- `chaosx_generated_event_art` for fictional super-event scenes
- `chaosx_asset_source_researcher` only when final art needs real historical material

Run every specialist with a self-contained prompt and no inherited context.

## Text rules

Final title, description, button, and quote must fit one role. Do not invent quotes. Keep direct copyrighted cultural fragments very short. Avoid generic end-of-world titles and implementation wording.

## Image rules

Opening shows a coordinated multi-region emergence without a map collage.

Cthulhu shows supernatural hierarchy over surviving apexes without implying a Cthulhu division.

Aftermath shows damaged and recovering shores with a reflective tone.

Avoid commercial Cthulhu and kaiju designs, modern vessels, fake text, and UI-like compositions.

## Audio rules

Each role needs one unique final musical recording. Verify composition and recording rights separately. Preserve source and license. Convert to a game-ready WAV. Add base sound, required volume wrappers, unique audio ID, settings-aware playback, and canonical music catalog entry.

No generated tone, drone-only substitute, sound-effect stinger, placeholder, default, or undocumented track is allowed.

## Wiring

For each role, align:

- trigger
- slot
- visibility
- image
- title
- description
- button
- quote
- audio ID
- settings-aware playback
- sound definitions
- docs
- workbook fields

## Output

Write permanent research documentation and asset handoffs. Mark unresolved quote, rights, slot, image, or audio issues as blockers. Do not claim a super-event complete when one component is missing.
