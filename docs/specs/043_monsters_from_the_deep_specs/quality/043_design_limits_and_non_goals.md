# Event 043 design limits and non-goals

## Purpose

These limits protect the event from feature drift, cultural flattening, performance problems, and weak substitutes.

## Fixed design decisions

- Event 043 is Major.
- Minimum Chaos level is 3.
- Event 043 belongs to no cluster.
- The natural baseline normally creates four full monster countries.
- Evolution I normally raises the roster to eight.
- Evolution II can create all sixteen.
- The roster contains the sixteen identities in the source specification.
- Cthulhu is the only public terminal union.
- Cthulhu is a leader and terminal state, not a division.
- Each named creature has one apex division.
- Dead apexes never return.
- Full monster countries use no ordinary recruitment.
- Monster players track Hunger and Sea Bond.
- The event uses decision categories and ordinary focus UI, not a dedicated scripted GUI.
- Human response uses real objectives and ordinary resources.
- The event replaces the old Massive Flood implementation.
- Event 013 remains the ordinary flood owner.

## No-go mechanics

Do not add:

- a third persistent monster currency
- a global monster score that ordinary players must track
- passive monthly free division spawns
- normal manpower recruitment
- ordinary rifle or tank production
- a conventional monster navy
- a full monster technology tree
- a full monster doctrine tree
- one shared generic focus tree
- one shared generic leader portrait
- one generic monster 3D model
- one generic monster sound
- one generic apex counter
- Cthulhu as a map unit
- apex resurrection
- apex cloning
- random deep inland war declarations
- one all-country daily or weekly scan
- one all-state recurring scan
- a full custom scripted GUI
- a fake inlay window
- copied cultural ornaments
- pseudo-language
- invented quotations
- placeholder super-event audio
- copied commercial monster designs
- transform-only final animation
- hidden fifth decision costs
- automatic universal human alliance
- a second world-end row for each readiness path
- direct Event 070 calls to the global invasion entry

## Balance limits

- Apex units remain killable.
- Coastal strength does not imply deep inland strength.
- One apex should not defeat every major power without support.
- Human counterplay requires preparation and concentration.
- Monster support caps depend on lairs, coast, and route.
- Hunger creates pressure without becoming a positive store currency.
- Sea Bond uses confirmation windows to prevent hourly oscillation.
- Range upgrades carry real costs.
- Pacts create cooperation and risk.
- Solitary routes create control and exposure.
- Cthulhu can conquer inland but remains vulnerable to all-apex destruction.

## Cultural limits

- Sisiutl is excluded from the roster.
- Ainu motifs are not generic Akkorokamui decoration.
- Māori carving and tā moko are not Te Wheke decoration.
- Codex imagery is not copied into Cipactli flags.
- Colonial Ipupiara sources are identified as colonial.
- Iku-Turso receives no false canonical anatomy.
- Biblical Leviathan receives no invented scripture.
- Japanese yōkai art is research material, not automatic final art.

## Asset limits

An asset is complete only when it has:

- approved source mode
- source evidence
- correct target type
- processed file
- final DDS or runtime format
- manifest
- sprite or entity handoff
- live consumer
- review evidence

An extra focus icon cannot replace a missing idea icon. A static creature model cannot replace a required animated unit.

## Scope additions that need a new accepted addendum

- a dedicated scripted GUI
- a monster navy
- technology or doctrine branches
- a seventeenth full monster
- playable human collaborators
- capture and domestication of an apex
- resurrection
- cross-event hybrid apexes
- a second Event 043 world end
- a large postwar global organization
- a shared event cluster
- a direct creature-specific real religion route
