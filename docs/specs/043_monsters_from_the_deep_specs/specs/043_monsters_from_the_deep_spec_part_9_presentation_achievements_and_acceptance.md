# Event 043: Monsters from the Deep

## Part 9: Presentation, assets, achievements, and acceptance

## Writing direction

Event 043 should read as a concrete invasion by visible creatures.

Player-facing text should describe:

- water moving where it should not
- ports collapsing or falling silent
- named coastlines
- civilians leaving coastal towns
- ships disappearing
- soldiers encountering one apex
- rival monsters contesting the same sea
- lairs and feeding damage
- changing Hunger and Sea Bond
- pact behavior
- terminal union

Text should avoid:

- generic staff-table scenes
- sealed-report framing as the default
- abstract map-change summaries
- raw mechanic labels
- implementation history
- update wording
- claims that a danger is a warning
- contrast templates built around officials denying what witnesses see
- long lists of modifiers
- final quotes invented during implementation
- cheap jokes during mass death

Humour can appear in a rare minor report or reaction button. It should use researched maritime, literary, religious, regional, or period references and fit the current stakes.

## Local emergence report direction

The local report should mention:

- selected state or coast
- creature name
- immediate visible destruction
- appearance of the new country
- first local military problem
- one practical reaction

The report should not explain every long-term mechanic.

## Global opening report direction

The global report should convey that several distant appearances form one event.

It should mention several named oceans or regions dynamically when the setup created them. It should not list all sixteen when only four emerged.

The player should understand that more creatures can appear as Chaos grows. The text should not reveal exact evolution thresholds.

## Monster-player awakening direction

A human monster player needs a concise gameplay handoff:

- apex is unique
- original lair matters
- Hunger rises
- Sea Bond comes from the coast
- support formations come from objectives
- deep inland advance is dangerous
- rival monsters begin hostile

The event option should open or point to the Monster Dominion category.

## Event Details

Event Details should contain:

- premise
- event type
- Chaos level 3
- current fired status
- two evolution rows
- one public Cthulhu world-end row
- no cluster field beyond empty or none
- current event enable checkbox
- separate world-end checkbox
- scenario reference only where the shared UI supports it

The details text should explain the premise. It should not print raw combat effects or terminal thresholds.

## Evolution detail direction

### The Rising Tide

Explain that more creatures emerge, existing invasions strengthen, and pacts become more likely.

Do not reveal exact roster counts or support formulas in the public premise.

### Every Sea Opens

Explain that every major maritime region can produce a monster country and terminal convergence becomes possible.

Do not state the five hidden readiness formulas.

## Public world-end detail direction

Cthulhu's Dominion details should explain:

- surviving creatures can be united
- old monster countries cease independent action
- surviving apexes transfer
- dead apexes remain dead
- the union can conquer the continental interior
- victory remains possible through capitulation or all-apex destruction

It should not list exact readiness thresholds.

## Super-event package 1: Global emergence

### Role

Major Event 043 opening.

### Trigger

After the opening transaction has successfully created the final opening roster.

### Image direction

Show several distinct coastal ruptures or creatures in one coherent global scene. The image should read as one worldwide event without becoming a map collage.

Possible composition:

- foreground harbor under one apex
- distant horizon silhouettes of other creatures
- broken ships and port lights
- period-authentic civilian and military scale
- no modern vessels
- no readable generated text
- no direct copy of a commercial kaiju design

### Title and description direction

Use a short maritime title that identifies emergence or opened seas. Final wording needs localisation review.

The description should name the scale, active regions, and new hostile countries.

### Quote direction

Research public-domain or clearly usable sources about the sea, monsters, the deep, leviathans, or human fear of unknown waters. Scripture, classical literature, medieval texts, and public-domain maritime writing are suitable. Do not invent a quote.

### Button direction

A restrained maritime or literary reaction can fit. It must be researched and short.

### Audio direction

Use a unique licensed or public-domain musical recording. Suitable directions include low choral, maritime requiem, dark orchestral, or historic sacred material with verified recording rights. A drone or sound effect alone is not sufficient.

## Super-event package 2: Cthulhu's Dominion

### Role

Public world-end activation.

### Trigger

After terminal transfer succeeds and the Cthulhu country is valid.

### Image direction

Show Cthulhu as the supernatural center above or behind several surviving apexes. The scene should communicate hierarchy and union. It must not imply a Cthulhu division on the map.

Use deep-water scale, coastal destruction, and living apex silhouettes. Avoid a direct copy of a known commercial Cthulhu illustration.

### Title and description direction

Use the final public world-end name or an approved close form. State that the separate monster countries have become one terminal power.

### Quote direction

Research public-domain cosmic-horror, maritime, religious, or classical material. Copyright status and exact wording need verification. No invented Lovecraft-like line is acceptable.

### Button direction

Use a brief cultural or literary remark only after source verification.

### Audio direction

Use one unique structured musical cue with finality and deep-sea scale. Rights for composition and recording require separate verification.

## Super-event package 3: Global defeat aftermath

### Working role

The Shores Remember.

### Trigger

Only after a long global campaign or terminal defeat satisfies aftermath eligibility.

### Image direction

Show repaired and ruined ports together, memorial lights, returning civilians, damaged breakwaters, and surviving ships. The scene should remain reflective.

### Title and description direction

Focus on cost, recovery, missing people, and the changed coastal order.

### Quote direction

Research public-domain material about survival, the sea, memory, rebuilding, or vigilance.

### Audio direction

Use a unique reflective musical recording. Avoid a victory march unless the final context supports it.

## Portrait direction

Every named monster and Cthulhu is fictional or impossible. Native ImageGen through the portrait worker is allowed.

Each portrait brief must include:

- nonhuman identity
- creature anatomy
- exact role
- `156x210` framing
- regional environment
- no human substitute
- no modern franchise copying
- no readable text
- no gore
- static fallback
- real frame plan for animation
- stable anchor
- separate portrait wiring and manifest

Animation should use restrained creature-specific movement. It cannot be made from shifting, scaling, or recolouring one still.
