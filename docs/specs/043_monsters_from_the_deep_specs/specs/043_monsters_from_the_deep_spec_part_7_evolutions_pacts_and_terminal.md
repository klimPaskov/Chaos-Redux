# Event 043: Monsters from the Deep

## Part 7: Evolutions, pacts, and Cthulhu's Dominion

## Evolution ownership

Event 043 has two actual evolutions.

1. **The Rising Tide**
2. **Every Sea Opens**

Normal focus progress, extra lairs, Hunger stages, pact stages, apex deaths, and territorial growth are baseline event progression. They must not be recorded as evolutions.

Evolution state adds zero Chaos. Concrete consequences created by evolved behavior may add or reduce Chaos through the Event 043 impact map.

## Evolution pacing contract

An evolution can apply in two ways.

### Pre-fire evolution

When an evolution is already active before Event 043 fires, the entry event uses the stronger opening package immediately. It does not create the weaker opening and upgrade it a day later.

### Post-fire evolution

When Event 043 is already active, the evolution becomes eligible after its Chaos threshold and any event-state requirements pass. It then waits for a paced event-owned milestone.

The intended base pacing is around `90` days. Dynamic factors may shorten or lengthen it based on:

- active monster count
- living apex count
- current coastal control
- human counterattack strength
- time since last emergence
- current world war scale
- current event pressure
- evolution enabled state
- manual scenario state
- another terminal threat

The exact timing formula requires probability evidence. It should not guarantee an immediate transition on the first eligible day.

### Evolution logging

When an evolution activates:

- set the shared Event 043 evolution context
- include the correct evolution type and stage
- use Event 43 as source
- include an actor only when the milestone belongs to one country
- record one evolution row
- unlock the changed package
- schedule evolved behavior
- add no Chaos for the state change

Disabling an evolution prevents its activation and its gated content. It must not set hidden recorded flags.

## Evolution I: The Rising Tide

### Requirement

- Chaos `800+`
- Event 043 enabled and active, or pre-fire opening state
- Evolution I enabled
- no incompatible world end
- at least one content-ready dormant monster identity when applying after opening

### Pre-fire opening

When Evolution I is active before Event 043 fires:

- eight monsters normally emerge
- selection spans as many distinct macroregions as possible
- every apex starts at its evolved baseline profile
- support packages are larger
- each tree begins past the shortest landing setup focus where safe
- each country receives one additional earned support receipt
- first pact actions become available earlier
- operational range remains bounded
- Cthulhu remains locked

The event should not auto-complete route commitments. A human monster player still chooses pact or solitary direction.

### Post-fire activation

When Evolution I activates after baseline opening:

1. record the evolution
2. rebuild dormant valid identity candidates
3. select four additional monsters across unused macroregions when possible
4. schedule their emergences over a paced window
5. strengthen existing full monsters through a one-time evolved package
6. reveal stronger pact and counterplay actions
7. update human Ocean Watch and response missions
8. refresh regional and terminal ledgers

The additional four are a design target. The final count can be lower when candidates fail. The system should not choose replacements from already crowded theatres only to reach eight.

### Evolved existing monsters

Each surviving full monster can receive:

- one support receipt
- one support-cap increase
- earlier access to a secondary family
- reduced delay on first pact proposal
- one evolved apex or lair focus unlock
- stronger human response visibility
- one Evolution I country report

A dead apex identity remains dead. A remnant does not regain full-monster status.

### Human response

Evolution I should increase the response category's strategic scale.

New or improved options can include:

- broader Ocean Watch
- allied specialist support
- regional lair-network missions
- joint port defense
- shared apex observation
- coordinated evacuations

Human countries still select one active threat at a time.

### Pact pressure

The Rising Tide makes pacts more likely because:

- more monsters can meet
- human coalitions become stronger
- weakened monsters seek survival
- compatible theatres overlap
- solitary predators gain more rivals

This is a change in AI and route access, not an automatic faction.

### Evolution I failure cases

The evolution should safely complete even when:

- all four baseline apexes are dead
- only one valid dormant identity remains
- a terminal world end started during pacing
- a selected landing state became invalid
- one new tag failed setup
- a human player switched tags
- a manual scenario already created more than eight monsters

If no full monster survives, the evolution records no activation and ends. It should not restart a defeated event from nothing unless a separate manual scenario is launched.

## Evolution II: Every Sea Opens

### Requirement

- Chaos `1000+`
- Evolution II enabled
- no incompatible active world end
- Event 043 active or pre-fire opening state
- at least one content-ready monster package

World Collapse is necessary for natural terminal readiness, but Evolution II does not itself set `world_end`.

### Pre-fire opening

When Evolution II is active before Event 043 fires:

- all sixteen valid monster identities emerge
- every macroregion is represented
- spacing remains a safety preference
- each package uses evolved apex and support profiles
- pact and solitary commitments become relevant immediately
- terminal readiness checks begin only after setup and World Collapse proof
- the opening super-event fires after all successful emergence transactions

A failure to create one identity must be reported. The launch cannot present a complete global opening when one package is absent.

### Post-fire activation

When Evolution II activates after earlier waves:

1. record the evolution
2. identify every remaining dormant content-ready identity
3. schedule emergence opportunities across unused and underrepresented regions
4. avoid creating all later countries on one day
5. strengthen existing full monsters once
6. open final range and terminal branches
7. enable Cthulhu readiness calculations
8. expand human counterplay
9. refresh world-threat and regional coverage

Later emergences should occur over a campaign window. A normal pacing target is one new regional emergence every `7-21` days, adjusted by remaining roster and world state. Exact distribution requires probability simulation.

### Evolution II existing-monster package

A surviving full monster can receive:

- one final support-cap step
- evolved apex profile
- final range branch access
- one terminal route reveal
- access to larger pact groups
- one last creature-specific power improvement
- stronger Hunger costs
- greater human observation

The design should not make Evolution II a free universal stat multiplier. It opens new goals and pressure.

### Final roster saturation

Evolution II tries to create every valid dormant identity once.

It does not:

- recreate dead apexes
- reactivate remnant identities
- duplicate active countries
- overwrite a special country
- ignore tag conflicts
- bypass asset readiness
- reset prior pact or rivalry history

## Pact system

## Pact purpose

Pacts let several predators stop fighting long enough to survive or dominate a shared sea. They create meaningful cooperation without removing country identity before the terminal route.

Pacts use four stages:

1. Proposal
2. Truce
3. Compact
4. Abyssal Faction

Each stage has entry, maintenance, failure, and cleanup rules.

## Proposal stage

A proposal is valid when:

- proposer and target are full monster countries
- each apex lives
- neither is under Cthulhu
- proposer has the pact route
- target has pact willingness or extinction pressure
- no permanent rivalry blocks the pair
- no recent betrayal cooldown exists
- they share an enemy, theatre, border problem, or terminal survival basis
- no active war structure makes a truce impossible to resolve safely

A human target receives a country event with route-aware choices. AI uses a weighted evaluation.

Proposal failure creates a cooldown. It should not immediately cause war unless the route or existing rivalry calls for it.

## Truce stage

The truce stops current direct hostility and opens one shared objective.

Possible objectives:

- hold two named ports
- defeat a human naval coalition
- preserve each apex for a defined period
- destroy one hostile lair
- control opposite shores of one sea
- survive a human offensive
- contribute support receipts
- keep Hunger below a crisis band

Truce duration should normally run `120-240` days.

Success opens the compact. Failure ends the truce or creates a weaker second chance.

## Compact stage

A compact provides:

- stable nonaggression
- shared target exclusions
- military access only where technically safe
- bounded reinforcement contribution
- Sea Bond support
- shared mission
- pact membership record
- betrayal action and consequence
- terminal pact contribution

A compact does not:

- merge focus trees
- transfer apexes
- remove national Hunger
- make every monster friendly
- allow free unit control
- permit deep inland bypass through partner territory without range proof

## Abyssal Faction stage

A compact group can form one Event 043 faction.

Minimum design requirements:

- three living apex members
- sufficient compact history
- one shared major enemy or coastal objective
- no member locked to solitary dominion
- no recent internal betrayal
- faction leader chosen through pact rules
- each member retains its tag and apex
- member target logic avoids duplicate wars and friendly border crises

The faction can grow through matching compact decisions.

## Pact leadership

Pact leadership should consider:

- living apex
- pact route progress
- controlled lairs
- weighted coastal control
- completed shared objectives
- betrayal record
- Hunger stability
- creature-specific broker weight

Cetus receives a broker advantage. Leviathan and Jormungandr receive dominance advantages. Hafgufa gains strength only in a northern pact. Scylla receives no automatic leadership advantage.

The leadership score remains hidden. The public interface names the current leader and next shared objective.

## Pact contributions

Each member can contribute one of a small set:

- one support receipt
- one lair-defense window
- one shared observation result
- one regional target
- one Hunger relief transfer through maritime feeding
- one terminal ritual receipt after Evolution II

Contributions need cooldowns and caps. A weak member should not empty itself through AI spam.

## Pact conflict rules

Members should not declare war on each other through normal frontier refresh.

Contested territory uses:

- ownership priority
- negotiated state transfer
- neutral buffer
- leadership ruling
- rivalry event
- betrayal route

The system needs deterministic tie resolution. It cannot leave two allied monster countries at war because one new border appeared.

## Pact failure

A pact can weaken or fail through:

- betrayal
- repeated Hunger crisis
- failure of shared objective
- leadership challenge
- loss of too many apex members
- territorial conflict
- terminal disagreement
- one member joining an incompatible system
- invalid war structure

Failure proceeds through a report and cleanup. It does not instantly clear all history. Betrayal memory remains permanent.

## Pact AI

AI acceptance should consider:

- compatibility pair
- shared enemy
- current wars
- apex health
- Hunger
- Sea Bond
- relative strength
- territorial overlap
- current pact size
- solitary route
- human coalition strength
- Evolution I or II
- World Collapse
- prior betrayal
- scenario type

Every pair does not need a hand-authored matrix entry, but the sixteen identity profiles need affinity, neutrality, and rivalry groups.

## Cthulhu's Dominion

## Public terminal identity

Event 043 has one public world-end scenario: **Cthulhu's Dominion**.

The five readiness paths are alternate campaign proofs for the same terminal outcome. Event Details should show one public row with one persistent toggle. It should not show five separate public terminal rows that all produce the same country.

Provisional registry identity:

- world-end scenario ID `15`
- owner event `43`
- visibility public
- default enabled
- dedicated super-event ID assigned at implementation
- one world-end details row

The numeric ID is an append-only planning proposal. Implementation must confirm that no newer source has claimed it.

## Shared terminal gates

Every natural readiness path requires:

- Chaos `1000+`
- World Collapse
- Event 043 active
- Evolution II active
- Cthulhu terminal branch enabled
- no existing `world_end`
- at least one living full-monster apex
- valid terminal country tag
- complete terminal country package
- complete transfer transaction
- no unresolved tag or war blocker

Manual Maximum Pact setup can prepare or invoke the terminal route under its scenario contract. It must raise Chaos into World Collapse before setting the terminal state.

## Readiness Path 1: Pact of the Deep

### Design threshold

Recommended starting threshold:

- at least five living apex members in one abyssal faction
- members present in at least four macroregions
- enough weighted coastal control
- one completed terminal pact objective
- no unresolved betrayal crisis

These values need map and probability evidence.

### Campaign meaning

The monsters have chosen cooperation before one creature defeated the rest. The faction leader completes a final call. Every member receives a choice or deterministic AI evaluation to submit to the union.

Refusal can:

- leave the member outside and hostile
- trigger a final pact war
- delay readiness
- strengthen the Apex Dominion path

The terminal transaction should normally absorb all willing surviving full monsters and then resolve holdouts through war or forced union rules defined by the final focus.

## Readiness Path 2: Apex Dominion

### Design threshold

Recommended starting threshold:

- one full monster has defeated, subjected, or absorbed four rival full-monster countries
- it controls a large weighted coastal realm
- it completed the solitary capstone
- it has at least one living rival or subject apex available for union
- its Sea Bond is stable enough to complete the call

### Campaign meaning

One monster has proven that separate predators cannot hold the world. It calls Cthulhu to bind conquered rivals and surviving subjects.

Defeated rival apexes can transfer only if they are alive and under a valid monster subject or conquered-survivor record. A dead apex never returns.

## Readiness Path 3: Global Emergence

### Design threshold

Recommended starting threshold:

- at least ten living apexes
- living full monsters in at least six macroregions
- active invasions across several oceans
- broad weighted coastal footprint
- Evolution II global-emergence receipt

### Campaign meaning

No single pact or victor controls the roster. The number and spread of living monsters create the convergence.

The path should use a paced event sequence. It should not merge sixteen countries on the exact day Evolution II activates.

## Readiness Path 4: Last Survivors

### Design threshold

Recommended starting threshold:

- at least sixty percent of the registered apex roster is dead
- three to five living full monster apexes remain
- human coalitions are stronger or actively threatening several lairs
- no stable large pact already satisfies another path
- extinction pressure has persisted through a confirmation window

### Campaign meaning

The remaining creatures abandon rivalry to avoid extinction.

This path should be rare. It prevents a nearly defeated global event from becoming irrelevant at World Collapse, while still requiring several living apexes and a real campaign history.

A single surviving monster does not call Cthulhu automatically. The route needs enough distinct living apexes to anchor the union.

## Readiness Path 5: Coastal Collapse

### Design threshold

Recommended starting threshold:

- monster countries control about twenty-five percent of the weighted global port score
- monster countries control at least twenty coastal capitals
- the footprint spans several macroregions
- enough living apexes remain
- control persists through a confirmation window

The exact score and capital count require map audit. A flat state count would overvalue empty coasts and undervalue major ports.

### Campaign meaning

The physical coastline has fallen far enough that the sea itself becomes the terminal basis. Several rival monster countries can trigger this path without a prior faction.

## Readiness confirmation

Readiness should use a receipt and confirmation window.

The event records:

- path ID
- first eligible date
- current proof
- living apex list
- proposed caller
- path still valid
- terminal toggle state

A path that loses eligibility before confirmation clears its pending state. It does not remain ready forever.

## Terminal call sequence

A successful path begins a short event sequence.

1. identify the calling monster or pact
2. freeze new pact betrayals
3. prevent new full-monster emergence
4. snapshot all living apexes
5. snapshot all full monster countries, remnants, lairs, subjects, wars, and support units
6. set the Event 043 terminal transaction in progress
7. set shared `world_end`
8. set Event 043 terminal flag
9. create or activate the Cthulhu tag
10. transfer valid states and subjects
11. transfer living apexes one time
12. transfer support formations
13. reconcile wars
14. reconcile lairs, support permissions, Hunger, and Sea Bond
15. retire old full-monster tags
16. activate Cthulhu leader and tree
17. set terminal world-threat source
18. display the world-end super-event
19. clear transaction state and temporary targets
20. verify every snapshot row has one disposition

The sequence must fail closed before setting `world_end` if the terminal tag, leader, focus tree, or transfer system is incomplete.

## State transfer

Cthulhu receives:

- every controlled state of a consenting or conquered full monster country
- valid monster subjects according to a documented subject policy
- registered lairs
- Event 043 occupation records
- valid nonhuman support formations
- no ordinary human stockpile unless a deliberate captured-resource rule uses it
- no duplicate capital or ownership conflict

Human allies or puppets of monster countries require explicit disposition. The event should prefer annexation into the terminal state or release into a hostile human successor over an incoherent human subject under a nonhuman union.

## Apex transfer

Each living apex snapshot row receives one result:

- transferred to Cthulhu
- left outside as hostile holdout
- destroyed during the final call through a visible event
- blocked with transaction failure

The normal intended result is transfer.

Transfer requirements:

- unit still exists
- creature identity matches
- no prior terminal transfer receipt
- original country matches
- dead-apex marker absent
- Cthulhu tag active
- unit retains unique battalion and model
- unit receives terminal ownership and roster marker

Apex transfer cannot recreate a missing unit from a flag.

## Old tag retirement

After successful transfer, old full monster tags:

- clear full-monster marker
- clear active leader and tree
- clear independent AI
- leave the active-monster array
- clear independent decisions
- clear pact membership
- retain historical origin and transferred-apex memory
- hold no state or unit
- cannot be selected again

A save repair should verify this state without recreating the old country.

## Terminal Hunger and Sea Bond

Cthulhu's Dominion should retain a simplified two-value surface.

### Terminal Hunger

Terminal Hunger reflects the combined pressure of generic broods and surviving apexes. It rises from failed continental offensives and overextended support forces. It falls from major conquest milestones.

It should not add one separate Hunger number per apex.

### Terminal Sea Bond

Terminal Sea Bond reflects the supernatural union and global lair network. It remains high under normal terminal play.

Low terminal Sea Bond can result from:

- loss of most coastal capitals
- destruction of many lairs
- isolation of the terminal capital
- death of several apexes
- human completion of major global response missions

It should reduce power but not restore ordinary shallow range.

## Terminal inland rule

Cthulhu's Dominion receives the **Terminal Unbound** operational tier.

The intended result:

- can target landlocked countries
- can plan through deep continental states
- can integrate deep territory
- retains minimal residual penalties at most
- can move surviving apexes far from the sea
- no longer stops at depth `3`

The final implementation can remove depth penalties or reduce them to a small residual effect. The result must prevent humans from winning solely by retreating inland.

## Terminal war behavior

Cthulhu should pursue:

- remaining major powers
- inland capitals
- industrial centers
- connected continental fronts
- surviving coastal coalitions
- human states holding former lairs

It should avoid meaningless wars against inaccessible exiles or tags with no valid territory.

## Defeating Cthulhu

There are two complete victory conditions.

### Normal capitulation

Human powers capitulate the Cthulhu country through ordinary war under the event's terminal settlement rules.

### All-apex destruction

Every transferred surviving apex division is destroyed.

When the last apex dies:

1. record last-apex receipt
2. collapse the supernatural union
3. clear terminal world threat
4. end or transform the Cthulhu tag
5. disperse remaining generic support forces into limited Abyssal Remnants or destroy them according to state context
6. begin eligible global defeat aftermath
7. apply the bounded Event 043 Chaos reduction
8. record achievements
9. preserve permanent death and destruction history

Generic support units alone cannot sustain Cthulhu's Dominion after the last apex.

## Terminal apex deaths

Each apex death after unification:

- marks the creature permanently dead
- removes that unit
- reduces terminal Sea Bond
- changes terminal AI
- can open collapse-risk focuses
- updates human objectives
- does not capitulate the whole country until the last living apex dies

The roster interface or decision category should show living names, not a raw count alone.

## Holdouts

A monster that refuses a Pact-path union can remain outside as a hostile full country only when:

- its tag and apex still exist
- war reconciliation can keep it separate
- the terminal country has a clear war goal against it
- it cannot trigger a second Cthulhu state
- its terminal path closes
- its survival is recorded

Holdouts should be rare. The normal global emergence and coastal collapse paths can absorb all valid full monsters through the event's supernatural premise.

## Public Event Details toggle

Cthulhu's Dominion needs one Event Details row.

The checkbox:

- defaults enabled
- writes only to the world-end scenario disabled registry
- persists through reopening and save
- does not disable Event 043
- does not disable the evolutions
- does not disable the manual Warring Titans scenario
- blocks automatic Cthulhu readiness and activation
- can block the manual terminal setup when the scenario contract chooses to respect public terminal settings

The scenario detail text must state whether manual Maximum Pact launch overrides or respects the terminal toggle. Preferred design respects the toggle unless Force Trigger Mode explicitly bypasses it.
