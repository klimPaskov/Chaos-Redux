## Material design findings

- Event 037 is cataloged as Minor Repeatable, Chaos level `1`, Various Anomalies, Low severity.
- The supplied Event 037 catalog premise still describes one major country receiving recruits. The accepted design replaces it with a global state-based civilian-population event.
- Various Anomalies has no stable numeric cluster ID in the supplied cluster export.
- Famine and Migration already have separate owner ledgers, public values, adapters, decisions, missions, map modes, and mortality contracts.
- The shared population-loss effects already support exact real civilian losses and Deaths integration.
- Shared civilian-country classifiers already distinguish ordinary civilian societies from actual nonhuman actors.
- Decision-system rules favor one primary value, selected-target workflows, phase-based visibility, active mission limits, dynamic costs, and no more than four spendable cost types.
- Asset rules require separate source art for separate icon families and final runtime packaging.
- The event-planning skill requires a ZIP, separate prompt files, a goal prompt below `4,000` characters, a final improvement pass, and source specs under `docs/specs/`.
