## Nearby catalog ideas that must remain distinct

### Event 029 Riches Found

Event 029 grants abstract political wealth and a state-linked bonus. Event 018 must not become another currency windfall. Its value comes from map resources, trade routes, industrial development, concessions, and the military consequences of a strategic deposit.

### Event 098 New Ore

Event 098 owns the concept of a unique fictional metal that improves armor and can be sold internationally. Event 018 uses ordinary HOI4 strategic resources. Its monster branch comes from excavation depth and an inhabited subterranean world, not from a special alloy or armor technology.

### Event 139 Mysterious Creature

Event 139 owns a single hunted creature that eats crops and people. Event 018 must not resolve through one monster hunt. Its later threat is a reproducing subterranean species with nests, armies, a country package, and a resource-driven reinforcement system.

### Event 013 Natural Disasters

Event 013 owns the disaster families. Event 018 can react to earthquakes, landslides, volcanic activity, or meteor shocks when Event 013 is active, but it must not duplicate disaster sequences. A disaster may expose a new vein, collapse a shaft, accelerate a breach, or damage a sealing project.

### Event 008 Tensions Rising

Event 008 owns broad diplomatic panic. Event 018 can add a resource-dispute context to relations, trade interest, and military readiness, but it should not replace the general relation-shock system.

### Event 050 The Great Embargo

Event 050 owns the global embargo incident. Event 018 may become more valuable under embargoes and may attract smuggling or emergency concessions, but it does not create a general embargo by itself.

### Event 078 Border Conflict

Event 078 owns the generic player border-conflict event. Event 018 has a narrower field-dispute ladder. Its border war can begin only after a contested resource field creates claims, failed talks, troop concentration, and a clear transfer stake.

### Event 002 Zombie Outbreak and Event 010 Death

These events already create existential nonhuman threats. Event 018 must use the shared special-chaos-country and actual-nonhuman-country classifications, world-threat framework, and exclusions, while preserving a distinct economy. Zombies use population. Death uses consumed lives and soul power. Cave monsters use captured strategic resources.
