# Event 018 Parent-Performed Improvement Loop Review

## Review status

This review applies the full `chaos-redux-improvement-loop` and `chaos-redux-event-planning` standards to the completed Event 018 planning package.

The supplied project rules require an independently spawned `chaosx_improvement_loop_planner` pass with `fork_context=false` before a planning goal is treated as near complete. This session did not expose a custom-subagent execution interface. The independent planner could not literally be spawned. This parent-performed review is therefore evidence of a depth and anti-bloat pass, but it does not replace the mandatory implementation-time planner run. The actual planner pass remains a disclosed blocker for formal project completion.

No prior Event 018 improvement addendum was present in the supplied corpus. There is no unresolved earlier addendum to disposition.

## Playable promise reviewed

Event 018 promises an ordinary positive resource discovery that can become a persistent economic project, diplomatic prize, labor disaster, monster emergency, nonhuman country, and terminal continental threat.

The package now supports that promise through:

- exact random resource discovery
- persistent multi-resource fields
- active development and safety decisions
- trade, concessions, nationalization, smuggling, commission, and border conflict
- separate baseline stages and evolution stages
- gradual Evolution II and III incident chains
- permanent full-seal prevention
- a complete cave-country package
- a unique captured-resource army economy
- three hierarchy routes
- three military doctrine routes
- visible continent progress
- world-end and defeat aftermath rules
- AI behavior for every important actor group
- static and animated asset plans
- super-event research gates
- difficult achievements
- implementation prompts and acceptance criteria

The design is no longer shallow or popup-only.

## Depth findings

### Baseline economy

Status: deep enough for implementation.

The discovery has a complete lifecycle even with evolutions disabled. The player can pursue national development, commercial development, foreign concession, commission, strategic reserve, or closure. Infrastructure, safety, contracts, and ownership transfer all matter. No broad new baseline system is needed.

### Diplomacy

Status: deep enough for implementation.

Foreign interest is based on material need and access. Covert action creates an intermediate layer. Nationalization has compensation rather than automatic war. Border war requires claims and staged escalation. The commission route provides a nonmilitary resolution. Additional global commodity-market simulation would add complexity without enough play value.

### Evolution pacing

Status: deep enough for implementation.

Every evolution has pre-fire and active entry paths. High-stage first firing remains gradual. Safety changes outcomes. Evolution III retains a guaranteed full-seal prevention route. No fifth evolution is needed because the project limit is five and the four mapped stages already cover compound wealth, hidden horror, public breach, and country emergence.

### Cave-country identity

Status: deep enough for implementation.

The country has an original identity, nonhuman leader, unique economy, clear military strengths and weaknesses, map role, focus architecture, decisions, AI, assets, and terminal route. It is more than a tag or unit spawn.

### Cave army economy

Status: mechanically distinctive and implementation-ready.

The fixed rule of one division per ten total state resources, capped at ten, is preserved. The origin exclusion prevents double counting. Continuous-control activation and paced spawning create counterplay. Capacity loss weakens excess divisions instead of deleting them. Additional currencies, brood population meters, or equipment fabrication systems would blur the concept.

### Focus tree

Status: deep enough for a major fixed-purpose country.

The tree has early, middle, and late play, route locks, map objectives, template changes, decisions, adaptation, and world-end preparation. The hierarchy and doctrine combinations create replay value. A conventional democratic, communist, fascist, and monarchist political set would weaken the nonhuman identity and should not be added.

### World end and aftermath

Status: complete at design level.

The terminal state has a clear chaos gate, continent rule, verification period, unique transformation, cross-continent expansion, system freeze, and defeat aftermath gate. Additional planetary, underground-world, or space branches would be bloat.

### Presentation

Status: complete at design level.

The asset prompt distinguishes report, news, super-event, focus, idea, decision, flag, portrait, achievement, and animation work. The scripted GUI remains compact. A large independent resource-management window would add implementation burden without improving the main choices.

## Anti-bloat decisions

The following additions are explicitly rejected for this package because they would dilute the event or duplicate other catalog entries.

### No unique fictional ore

Event 98 owns the unique armor-metal and special market concept. Event 018 uses standard strategic resources. Cave armor comes from the species and its resource consumption.

### No abstract riches currency

Event 29 owns broad wealth discovery. Event 018 stays grounded in state resources, infrastructure, contracts, and trade.

### No lone-monster hunting identity

Event 139 owns the mysterious lone creature. Event 018’s creatures are linked to an excavation system and later form an organized species and country.

### No manual triggerable scenario in the source pack

The supplied scenario catalog contains no Event 018 scenario. The ordinary random event and world-end route are sufficient. A scenario can be designed later through a separate accepted request.

### No normal cave navy or air force

The cave country is a land predator. Cross-continent expansion belongs to the terminal rupture system. Monster ships or aircraft would require new lore, assets, and counterplay with little benefit to the core design.

### No second cave country by default

One persistent cave tag keeps army capacity, AI, world threat, focus routes, and defeat cleanup coherent. Later breaches should join or strengthen the same country when valid.

### No unrestricted teleportation

Burrow War uses prepared adjacent or locally connected actions. It does not allow arbitrary state jumps.

### No extra hidden punishment after full closure

The user explicitly promised that pre-breach closure prevents Evolution IV. A secret revenge event would invalidate player agency.

### No separate global commodity exchange GUI

Normal HOI4 resources and trade remain the economic foundation. Contracts and concessions add behavior without creating a second trade game.

### No broad historical reenactment

Research provides concession, commission, strategic-material, labor-safety, and folklore inspiration. The event remains random and fictional.

None requires inventing a new route or mechanic. They must be decided and documented during implementation.

## Closure recommendation

Broad planning expansion should stop. The package is deep, connected, replayable, and bounded. Another large design addendum now would add noise, duplicate systems, or delay implementation.

The correct next stage is implementation, followed by the required independent improvement-loop planner pass after a meaningful implementation tranche. That planner should check actual code and assets for simplifications, missing AI, shallow route rewards, or disconnected presentation. If it returns only a closure handoff, the design loop can remain closed. If it finds a new implementation-created gap, that gap should be resolved before completion.
