## Cave Host AI

| Situation | Priority |
| --- | --- |
| Origin emergence | declare wars, stabilize origin, spawn initial broods |
| Adjacent resource state exists | attack it before low-resource states |
| Low capacity | capture resources, avoid spreading into empty states unless needed for path |
| Enemy has strong hard attack | move slowly, concentrate broods, use terrain |
| Continent threshold near | prioritize remaining states and VPs on same continent |
| World-end possible | push continental maw path and resource-state spawns |
| Losing resource states | counterattack rich states, retreat from empty fronts |
| Human nearby | avoid instant collapse but do not become passive |
| Enemy fort line with anti-tank | seek alternate resource state, use tunnel lane if unlocked |

## AI blockers

AI should not:

- deep drill ordinary sites with low benefit and high public danger unless high chaos or desperation applies
- trigger Cave Host casually in calm campaigns
- use border war if state transfer would be invalid
- accept concession loops that make it a puppet by accident
- keep public danger site open if it lacks military capacity and the resource is not critical
- train Cave Host divisions normally
- use human political decisions for Cave Host
- allow Cave Host to join normal factions or negotiate normal peace unless a specific defeat or containment event supports it
