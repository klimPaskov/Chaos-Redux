| Controlled state type | Capacity contribution |
| --- | --- |
| Origin state | Stored starting contribution only, not counted for future capacity |
| Non-origin state with 1 to 9 total resources | 0 divisions |
| Non-origin state with 10 to 19 total resources | 1 division |
| Non-origin state with 20 to 99 total resources | floor(total resources divided by 10) divisions |
