# Event 018 Cave Host Focus Tree Architecture

All focus group labels are working labels only.

## Architecture map

| Lane | Entry | Forks | Capstone direction |
| --- | --- | --- | --- |
| Opening trunk | emergence stabilization | none | establishes nonhuman rules and resource capacity |
| Hunger lane | after trunk | resource detection versus faster brood awakening | reliable resource-state spawning |
| Stone hide lane | after trunk | thicker armor versus fewer stronger bodies | high armor and anti-infantry resistance |
| Tunnel lane | after trunk | terrain movement versus underground redeploy | slow but less predictable expansion |
| Brood hierarchy lane | after first resource captures | many weak broods versus fewer elder broods | chosen spawn doctrine |
| Surface terror lane | after public victories | panic warfare versus city depopulation | enemy disruption and stronger coalition backlash |
| Continental maw lane | after large continent foothold | no ordinary fork | world-end threshold support |

## Reward rules

- Do not use political power, stability, war support, or ordinary industry as core Cave Host rewards.
- Rewards should change resource capacity, division quality, terrain behavior, enemy panic, target selection, or world-end progress.
- Branches should be non-linear enough that the Cave Host can emphasize armor, movement, spawn pattern, or terror.
- The tree may be narrower than a human country tree because the Host is fixed-purpose, but each branch must still change play.
