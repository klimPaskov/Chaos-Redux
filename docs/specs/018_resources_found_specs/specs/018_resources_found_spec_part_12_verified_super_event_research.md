## Candidate role A: Cave Host public emergence

Use for the moment when Evolution IV reveals the Cave Host as a public nonhuman country. The role is discovery becoming invasion. The tone should not sound like a generic apocalypse. It should feel like the earth has been treated as a mine for too long and something under it has learned the route upward.

| Field | Value |
| --- | --- |
| Source | Job 28, World English Bible British Edition. |
| Candidate excerpt | `Underneath it is turned up as it were by fire.` |
| Source URL | `https://bible.catholicgallery.org/english/webbe-job-28/` |
| Rights note | World English Bible is public domain according to the official World English Bible site. The phrase `World English Bible` is a trademark, so attribution should name the translation accurately and not imply an altered text is still WEB. |
| Fit | Directly connects mining, earth, extraction, and fire under the ground. Strong for the field becoming unnatural without naming monsters too early. |
| Risk | Religious scripture may feel too solemn for a strange economy event unless the super-event image and audio lean into the uncanny rather than moral judgement. |

Use for the continent-control world-end threshold. The role is not first discovery. It is the point where the Cave Host owns a continent and the world-end branch begins spawning stronger cave armies elsewhere.
