## Coalition review triggers

| Trigger | Required response |
| --- | --- |
| Scheduled review | Reconcile membership, fatigue, routes, and duration |
| Pressure threshold crossed | Update stage and material effects |
| Core enforcer leaves | Recalculate Pressure immediately |
| Smuggling exposed | Resolve host and enforcement response |
| Settlement offered | Convenor and core vote |
| Convenor invalid | Select replacement or begin collapse |
| Evolution activates | Add the new behavior without resetting the crisis |
| Planned end date | Renew with cost or resolve |

## Compact presentation rule

The target sees the convenor, the two or three most important enforcers, the selected outside target, and a grouped remainder. It does not manage every member as a separate row of permanent decisions.
