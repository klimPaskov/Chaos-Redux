# Original sources

The original brief and thirteen maps are preserved byte-for-byte. The map-source registry records the uploaded filename, visible sheet title, dimensions, and SHA-256. Original filenames have not been corrected.

The file named East Earth depicts a sheet titled West Earth. West-Earth depicts North Earth. Triton's Islands depicts Tornado Islands. Use the map keys in the registry when assigning arrival artwork, and keep the originals unchanged.

The brief is the primary source for society identities, characters, and political history. A handwritten place label does not prove that a proposed colony, species, dynasty, or army existed there. New histories, institutions, routes, numbers, and military packages in the specification are proposed game design. Uncertain lettering remains uncertain.

No original image in this folder is a finished runtime asset. Production must prepare region-aware news crops and preserve source provenance. These maps are provided for this project, which does not establish a public redistribution license outside the user's intended mod use.
