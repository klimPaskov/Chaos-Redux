# 14. Sources, conflict dispositions and specialist routing

## Scope

This part records how the planning package reconciled its inputs and which repository documents the design depends on. The original planning run read a supplied source archive that is not part of this repository. Its reading ledgers, tool observations and hashes are historical receipts, classified in the [package guide](00_package_guide.md#historical-receipts), and none of them is an instruction for later work. Current checkout facts belong to the [import evidence](../../plans/103_chaos_directorate_plans/103_import_evidence_2026-10-10.json), the [import review](../../plans/103_chaos_directorate_plans/subagent_handoffs/103_import_review_2026-10-10.md) and the [shared identifier registry](../shared_identifier_registry.md).

## Authority used

The event brief governs the event identity and gameplay promise. The proposed weight curve, force anchors, country setup, eight focus paths, contextual actions, Chaos bands and achievements are the original planning parent's selections within the authorized expansion task. They are not previously implemented behavior and not separate user approval of each tuning number. The 10 October 2026 changes (manual relaunch and the spec audit) are recorded in the package guide.

| Conflict or gap | Evidence | Disposition in this package |
| --- | --- | --- |
