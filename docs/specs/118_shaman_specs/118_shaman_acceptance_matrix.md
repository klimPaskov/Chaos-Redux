## Evidence classification

Planning calculations can prove arithmetic and bounds in the declared tables.
Source review can establish that a token or owner pattern exists at the pinned commit.
Static validation can check syntax and some flow invariants.
Rendered UI checks can establish the reviewed layout.
Only a capable engine execution can establish actual native modifier semantics and timing.

Record those categories separately.
Use available current HOI4 routes where they answer the concrete question.
When a route is unavailable or rejects the same underlying unsupported feature, obey the current retry limit and continue unaffected source work.
Do not launch a live game without the user's explicit request.
Deliver source work with the remaining native or live verification limits named precisely.
