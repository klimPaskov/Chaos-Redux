# Event 55 Specification Pack

## The Great Infrastructure Project

This folder is the source design package for Chaos Redux Event 55.

The event is a Minor Repeatable member of the Positive Economy cluster. Its first successful targeting gives one ordinary country maximum constructed infrastructure in every state it owns at that moment. The country then receives a persistent national works program that can survey, finance, build, operate, damage, repair, and expand major transport projects.

The specification keeps the large opening reward requested by the event concept. Balance comes from recipient history, project limits, real construction commitments, route validity, partner consent, maintenance, and the reduced value of later repeat firings. The opening grant is not weakened into a small modifier.

The prompts folder contains bounded handoffs for implementation, decisions, assets, achievements, weighted logic, catalog alignment, and the reusable scripted system.

The research folder records the historical and institutional sources that shaped the design. Research is used as design support. It does not make the event a historical simulation of any one real project.

The quality folder records source coverage, catalog conflicts, role-based review passes, probability scenarios, and the final planning audit.

## Design limits

Event 55 uses an ordinary decision category with a static category picture and a compact status header. It does not require a dedicated scripted GUI. The category must remain readable at ordinary resolutions and should show no more than six primary actions in one state.

The event uses one persistent public mechanic value. Project progress belongs to the normal mission progress display and does not become a second persistent custom currency.

Fixed links across straits may appear only where a predeclared crossing has engine and map evidence. An unavailable crossing must be excluded before the player sees it. A decorative modifier must never be presented as a functioning land connection.

The design stops at a complete national and multinational project system. Focus trees, new countries, portraits, 3D models, animated sprites, and super-events would add maintenance without improving this event's central play loop.
