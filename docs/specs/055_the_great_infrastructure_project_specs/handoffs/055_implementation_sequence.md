## Phase 1, repository evidence

- Read the full Event 55 spec pack and prompts.
- Inspect current event registration, Event Logs, decision, idea, dynamic modifier, scripted localisation, and catalog patterns.

## Phase 2, stable data model

- Define script constants and tuning bands.
- Define recipient, proposal, project, partner, route, and crossing identities.
- Implement target and route hard-validity triggers.
- Implement sparse recipient and project registries.
- Implement idempotent cleanup and save reload rebuild.

- Implement first-time target selection.

- Implement National Works Capacity.

## Phase 5, international runtime

- Implement invitations, receipts, counteroffers, deadlines, contributions, operating agreements, withdrawal, war suspension, renegotiation, and host transfer.

## Phase 6, evolutions and crossings

## Phase 7, adapters
