## Conflict rule

When an old catalog export conflicts with this package, do not edit the export. Verify final implementation and localisation, update the authoritative workbook, then regenerate the exports.

When a historical example conflicts with installed map behavior, installed map and engine evidence controls which dynamic project can be offered.
