## Source use policy

These sources support design principles and historical parallels. They are not copied into player-facing localisation.

The implementation agent should run any additional historical, map, engineering, or asset research required for a specific dynamic route. Claims that depend on exact map geography or engine behavior must be verified against the installed game and repository tools.
