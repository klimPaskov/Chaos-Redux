# National posture matrix

Behaviour is owned by [02](../02_national_postures_and_membership.md), and relief values by [03](../03_condemnation_normalization_and_cbrn_integration.md#source-multipliers).
The covert program is a flag on Public Rejection, shown here as its own column only where it differs.

| Dimension | Full Ratification | Chemical Accession Only | Retaliation Reservation | Public Rejection | Public Rejection with covert program |
| --- | --- | --- | --- | --- | --- |
| Membership | Member | Member, chemical and general only | Member | Opponent | Opponent |
| Standing weight | Full | Half | Full | Opponent weight | Opponent weight |
| Treaty families | All | Chemical and general families, chemical First-Use clause, chemical Arsenal sections | Baseline families, defensive sections of the Charter and Arsenal, no First-Use clause | None | None |
| Relief | Chemical, biological, nuclear | Chemical and nuclear | Retaliation only | None | None |
| Permission line at opening | Retaliation only until a First-Use clause is ratified | Same | Retaliation only | Not shown | Not shown |
| Program access | Any provider that permits it | Chemical and general providers | Providers whose participant trigger accepts retaliation-only members | None | None |
| Inspection exposure | When Protocol ratified | When Protocol ratified | When Protocol ratified | Existing condemnation inspections only | Same, plus covert exposure |
| AI first-use tendency | Rises with ratified clauses | Chemical only | Zero unless repealed | No Event 036 change | Hidden family only |
| Main benefit | Full network and strongest relief | Chemical relief without biological normalization | Protection, guarantees, and retaliation relief | Opposition leadership and clean standing | Public standing with a hidden capability |
| Main cost | Declarations, inspections, obligations | Smaller influence and no biological access | No offensive freedom without breach | No relief or program | Hidden cover-up evidence and exposure |
