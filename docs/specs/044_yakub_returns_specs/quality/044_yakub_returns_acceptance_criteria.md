# Event 044 Yakub Returns acceptance criteria

## Purpose

This document defines the evidence needed before Event 044 can be called implemented. A working opening popup or a formed country is not enough. Completion requires the domestic crisis, evolution tracks, state package, focus routes, foreign modules, International, terminal route, succession, manual scenario, AI, assets, documentation, and catalog surfaces to agree.

## Event identity and catalog

- Event ID remains `44` and the entry event remains `chaosx.nr44.1`.
- Repository event-owned files use the `044_yakub_returns` prefix or folder identity.
- The old Space Race concept is fully replaced across event registration, event names, Event Details, debug names, docs, catalog workbook, and generated CSV exports.
- Event 44 is registered as Minor Fire-Once.
- Event 44 requires Chaos level 2 for normal automatic or normal manual firing.
- Event 44 remains outside every event cluster.
- The event is enabled by default only after the implementation is ready for normal play.
- The normal event records one Event Log history entry and contributes one minor pacing transaction.
- Supporting incidents, formation reports, and evolution events do not create duplicate random-event pacing transactions.

## Host and eligibility

- The normal opening targets the United States when it exists and is a valid ordinary human country.
- A missing or invalid United States produces a clean unavailable state for normal firing unless an accepted fallback host is added to the source spec before implementation.
- Detroit and Michigan receive preferred opening logic where state control and ownership make that possible.
- The event never queues against a nonexistent country.
- Force Trigger Mode follows shared behavior.
- The manual scenario uses its own valid setup gates and does not depend on normal Chaos, date, event history, or evolution prerequisites.

## Yakub character lifecycle

- Yakub exists as a character with a stable character ID, portrait, ideology or role data, and event ownership.
- His public, monitored, detained, underground, missing, dead, and discredited states are mutually coherent.
- Every decision and event that requires Yakub checks the current founder state.
- Arrest, disappearance, death, and discredit change movement behavior and do not leave founder-dependent effects active.
- Missing and underground states do not expose information the government has not earned.
- A dead or missing founder does not make the event impossible to continue when institutions survive.
- Succession cannot produce simultaneous leaders or duplicate founder ownership.
- A discredited founder materially weakens personalist routes while leaving institutional routes possible.

## Doctrinal framing

- Yakub's racial creation narrative appears as movement doctrine, attributed teaching, propaganda, testimony, or contested belief.
- Objective narration does not state that any racial group has an inherent biological origin, moral nature, inferiority, or superiority.
- Nation of Islam doctrine remains distinct from mainstream Sunni and Shia Islam.
- Muslim countries and movements have independent response paths.
- The Original Supremacy route is labeled as Black supremacy and an extremist racial ideology.
- The supremacist route includes resistance, defections, repression, Condemnation, diplomatic backlash, and instability.
- No protected-class selector, race-percentage value, racial combat modifier, racial death mechanic, racial unit type, or racial population transfer system is introduced.
- Ordinary civilians never become generic kill targets based on race.

## Yakubite Influence

- The domestic crisis exposes exactly one persistent public custom value, `Yakubite Influence`.
- Influence uses a stable readable range and the five accepted qualitative stages.
- Every stage has a visible gameplay consequence.
- The category shows the current stage, direction or recent cause, and next material threshold.
- Hidden contributors remain hidden unless the player can act on them directly.
- Influence gains and losses use event-owned script constants or a documented tuning source.
- Influence cannot be farmed through repeated low-cost decisions, repeated arrests, repeated releases, or route-switching.
- Influence reflects institutions, repression outcomes, economic pressure, war losses, intelligence, public confidence, and rival movements without exposing a long component ledger.
- AI can reason from Influence and the same public stage thresholds used by the player.

## Local chapters and territorial proof

- Chapter state status is qualitative or map-based and does not become a second public numeric meter.
- Chapter selection uses valid owned or controlled American states and cleans invalid targets.
- State targeting is bounded and does not rely on an unapproved whole-world daily, weekly, or monthly scan.
- Institutions, local control, defectors, municipal authority, and negotiated cession contribute to territorial proof.
- Race or assumed racial population share never contributes to territorial proof.
- Formed territory is contiguous where practical.
- Enclaves require explicit negotiated, strategic, or campaign-state justification.
- State packages protect the United States from invalid capitals, zero-state outcomes, and broken supply where a valid alternative exists.

## Decision category

- The American crisis uses one normal decision category with an ordinary category picture or compact attached meter.
- No full scripted GUI is introduced without a separately accepted design change.
- Each phase exposes three to five primary actions, with six as the hard maximum.
- One to three missions are visible at a time.
- Obsolete actions hide or clean up when phase, target, war, founder state, or event outcome changes.
- Every decision represents a concrete action.
- Decisions use varied, fitting costs and no action consumes more than four spendable cost types.
- Player-facing costs use correct texticons.
- Government actions have clear blocked reasons and visible risks.
- Stabilization decisions can lower or stabilize Influence.
- Repression may reduce open organization while raising underground strength or martyr risk.
- Heavy suppression is neither an automatic win nor an automatic loss.
- The United States has a credible peaceful containment and a credible negotiated path.
- AI receives an equivalent action path for every AI-usable category action.

## Missions

- Missions have named objectives, meaningful durations, success effects, failure effects, and cleanup.
- The truth investigation can complete through evidence and does not resolve only by waiting.
- Federal corridor and security missions use named states or dynamic named regions.
- The martyr crisis mission responds to actual detention or violent suppression state.
- The constitutional commission has real political prerequisites and can succeed, fail, or stall.
- No mission duplicates another mission under a different name.
- Success does not accidentally increase the pressure it is meant to contain unless the public tradeoff explains why.

## Baseline outcomes

- Quiet discredit is achievable without war.
- Monitored remnant preserves limited movement memory and does not keep the full crisis active.
- Legal separatist movement creates a lawful or semi-lawful persistent outcome.
- Underground network preserves hidden risk and future interaction without permanent unmanageable event spam.
- Negotiated compact creates a valid autonomous or sovereign settlement with clear territory and relations.
- Breakaway and civil war create a valid state, armies, war participants, and postwar outcomes.
- Fragmented collapse removes the central movement while retaining relevant local or foreign memory.
- Each outcome records the founder state, institutional survival, United States policy memory, movement faction balance, territorial result, and foreign awareness needed by later stages.
- Baseline outcomes do not require an evolution to resolve.

## Evolution system

- Evolution I is registered at 400 or more Chaos.
- Evolution II is registered at 600 or more Chaos.
- Evolution III is registered at 800 or more Chaos.
- Each active evolution uses the shared evolution logger and correct actor context.
- Evolution activation itself changes no Chaos.
- Concrete consequences created by evolved behavior may change Chaos through the event-owned impact map.
- Disabled evolutions do not set recorded flags or unlock gated content.
- When an evolution is available before Event 44 fires, the opening is intensified without skipping the normal event identity.
- When an evolution becomes available during an active crisis, it enters through accepted pacing or an immediate transition only where the source spec explicitly allows it.
- Baseline phases are not misreported as evolutions.

## Evolution I and institutions

- Parallel schools, relief, businesses, courts, defense, press, and committees affect play through a bounded institutional system.
- Institutional details may use hidden scores, qualitative stages, state modifiers, or decisions without adding several public meters.
- Institution building creates tradeoffs in resources, exposure, legitimacy, and control.
- The five accepted movement factions have distinct route effects.
- Faction contest outcomes alter the founding convention and later focus routes.
- State formation recognizes negotiated sovereignty, unilateral secession, federal collapse, and autonomous compact paths.
- A high-influence opening does not guarantee automatic statehood.

## American Yakubite state package

- The state is classified as human.
- It remains outside `is_actual_nonhuman_country`.
- It continues using ordinary civilian, famine, migration, occupation, population, diplomacy, and Deaths systems.
- A special Chaos country marker is added only when shared routing requires it.
- Any shared classifier change is documented in the matching dynamic-trigger registry.
- The state has a valid tag or protected reusable carrier with collision audit evidence.
- Its normal, medium, and small flags exist.
- Route or ideology flag variants exist where the public identity changes.
- Country name, adjective, parties, leader, capital, color, politics, and history are complete.
- The state has a usable starting economy, technology package, manpower basis, production, supply, fuel, convoys, and trains appropriate to its territory.
- It has dynamic starting divisions and enough equipment to function without receiving a free major-power army.
- Reinforcement comes through decisions, focuses, captured depots, defectors, volunteers, industry, and mobilization.
- Starting ideas are limited to the accepted deep set and each has a lifecycle.
- The state is playable when created for a human player.
- AI receives a valid route plan and survival behavior.

## Focus tree

- The tree follows the accepted architecture map and has clear branch lanes.
- The opening addresses government, food, capital security, and provisional rule.
- The five political route families are implemented or any accepted merge is reported.
- Community economy, defense, diplomacy, intelligence, territorial integration, International, and terminal preparation branches have real gameplay depth.
- Route decisions alter focus access, leaders, flags, ideas, diplomacy, and state identity.
- Each major route has a tradeoff, failure state, and late-game payoff.
- No route exists only to satisfy an ideology quota.
- The Original Supremacy route is powerful, oppressive, unstable, and not the automatic best route.
- Every focus has an accurate search filter.
- Spatially separate major branches receive Focus Navigation entries.
- Hidden or terminal branches stay hidden until their reveal conditions are met.
- The full tree passes `hoi4.focus_inspect`, normal-zoom `hoi4.focus_render`, lint, and post-change comparison.
- The final route coverage table maps every required route to implemented focus IDs.
- Complex focus AI weights receive a separate probability audit.

## Foreign modules

- Evolution II target selection is dynamic and reads relevant population, colonial status, instability, ideology, discrimination, war, local movements, and existing event state where script support exists.
- Selection fails closed when proof is incomplete.
- Special Chaos countries and actual nonhuman countries are excluded or receive an explicit owner-approved route.
- Caribbean, Brazil, Britain, France, West Africa, South Africa, Ethiopia, and Liberia have distinct political modules.
- Local movements may adopt, adapt, cooperate, reject, or oppose.
- No local movement is forced to copy the American route.
- Foreign governments have tools for intelligence, reform, political inclusion, rival movement support, negotiation, and repression.
- Foreign breakaways receive valid territory, government, forces, and route-local identity.
- A shared regional tree uses country-specific localization, decisions, leaders, rewards, and AI.
- The system limits concurrent active foreign crises to a tuned capacity.
- Invalid, annexed, or resolved foreign targets clean up correctly.

## Yakubite International

- Formation requires more than Yakub's existence.
- The anchor is selected from viable states and movements using documented proof.
- `International Cohesion` is the main public bloc value and replaces domestic Influence as the anchor's primary international value.
- Cohesion has qualitative stages, clear causes, clear consequences, and player responses.
- Secretariat, relief, education and press, intelligence, volunteer, economic, and war offices have distinct functions.
- Membership supports full members, associates, observers, suspended members, and former members where the route needs them.
- Member admission, refusal, suspension, exit, and expulsion are valid and cleanup-safe.
- Doctrinal, federal, revolutionary, congress, and supremacist forms produce different policy and AI.
- Forced conformity can reduce Cohesion and produce a schism.
- A schism creates valid successor blocs and does not duplicate members.
- Member AI does not transfer all sovereignty or resources without route and risk checks.

## Original Supremacy route

- Entry requires a real faction victory or route choice.
- The route clearly adopts Black supremacy as state doctrine.
- It changes citizenship, education, political loyalty, security, diplomacy, and faction control through concrete systems.
- It does not add racial biology mechanics.
- It does not assign generic racial targets for violence.
- Opposition factions can resist, defect, reform, or revolt.
- Repressive acts use existing Condemnation, Deaths, population, occupation, camp, or repression systems only when their exact actions justify those hooks.
- The route has short-term strengths and severe long-term costs.
- Foreign Yakubite movements may reject the route and leave the International.
- Mainstream Muslim criticism and anti-colonial criticism appear without treating either as one unified actor.

## World-end branch

- `The Yakubite World` is registered as one public Event 44 world-end branch with its own Event Details row and persistent toggle.
- It cannot activate below 1000 Chaos.
- It cannot activate from Yakub's existence alone.
- It requires a viable state, a functioning International, a valid leader or successor, and a substantial geopolitical footprint.
- Readiness may be satisfied through the accepted federal, multi-state, revolutionary, conquest, or congress paths.
- Automatic selection respects the branch toggle.
- Terminal commitment sets the shared world-end state once.
- Supporting, opposing, neutral, and contested countries are assigned through valid route-aware logic.
- The terminal actor and route variant remain stable after activation.
- Military mobilization is strong but bounded by territory, members, equipment, supply, industry, and Cohesion.
- Uprisings require local proof and cannot create infinite units.
- The five accepted route variants change diplomacy, government, member treatment, and victory state.
- Victory and defeat have defined political and territorial aftermath.
- A defeat super-event fires only after a genuine global campaign.

## Succession

- Yakub can remain leader when alive and valid.
- Designated Messenger, Council of Temples, Federal Council, Revolutionary Committee, International Secretariat, Defense Council, Originalist Directorate, and contested succession outcomes are route-gated.
- Martyr, missing, dead, and discredited founder states change succession weights and legitimacy.
- Succession changes Cohesion and route access as specified.
- No successor silently restores a route that the movement rejected.
- Contested succession can resolve, split, or collapse and cannot remain an endless event loop.
- A missing founder can return only through a rare event with one-time proof and cleanup.

## Triggerable scenario

- Scenario ID is `SCN-015` unless the authoritative workbook or live registry proves a collision.
- The scenario name is Yakubite Uprising.
- Movement and World Order types are selectable.
- Low, Medium, High, and Maximum intensities produce distinct setups.
- The list row, detail panel, type control, slider, impact text, confirmation, and launch effect read the same stored values.
- Movement type does not force the shared world-end state.
- World Order type intentionally starts the terminal conflict and sets the required shared state.
- Scenario bypass flags are narrow and clear after setup.
- The scenario does not create duplicate event firing, duplicate states, duplicate leaders, duplicate members, or duplicate wars.
- Repeat-launch gates prevent invalid duplication.
- Scenario history and Event Log behavior follow the manual scenario contract.

## Cross-system integration

- Great Depression 2.0 changes recruitment pressure without creating a guaranteed route.
- Murder Mystery can target valid living figures and handles founder death or disappearance through the succession system.
- Lawrence of Arabia and Malta Crusaders connect only where colonial, regional, and religious politics overlap.
- Africa Is One and future liberation systems can read movement, state, and International outcomes.
- Famine and Migration use their public APIs and separate ledgers.
- Camp and Repression connections use existing site and evidence systems and do not create a race selector.
- Condemnation receives public wrongdoing through supported source families.
- Deaths records exact real population losses once and avoids duplicate logging.
- Generic war, annexation, deaths, contamination, and ideology Chaos sources are not duplicated.
- Event-owned Chaos changes use one-shot milestones and the accepted impact map.

## AI and probability evidence

- United States AI has stable containment, reformist, negotiated, security, and authoritarian approaches with campaign-state gates.
- Yakubite state AI selects routes from faction strength, territory, war, recognition, economy, founder state, and Chaos.
- Foreign AI reads local politics and can reject doctrine.
- International AI evaluates Cohesion, member risk, logistics, enemy strength, distance, and terminal viability.
- Every complex weighted surface has named scenarios from the probability matrix.
- The baseline pass starts with `hoi4.probability_inspect`.
- Any source patch receives a same-scenario `hoi4.probability_compare` pass.
- Exact, bounded, sampled, score-only, and unresolved evidence are labeled accurately.
- The event does not claim exact normalized probability when the candidate pool is incomplete.

## Assets and presentation

- Yakub has a complete fictional high-chaos portrait package through the portrait worker.
- No real historical figure receives a generated portrait or invented allegiance.
- All flags use ImageGen source evidence and exact flat-flag processing.
- Required route flags, regional flags, and International emblem exist and are distinct.
- Decision, idea, focus, category, achievement, faction, and any other icon family use separate asset-specific briefs and source art.
- The decision category has a final static picture with no fake controls.
- Required report and news images exist in period-fitting style.
- No custom 3D model or custom unit family is introduced.
- No animation is claimed unless a separately approved frame plan and final frame-sheet package exist.
- The terminal and defeat super-events each have aligned final image, title, description, button, verified quote, unique licensed or public-domain musical cue, sound definitions, settings-aware playback, docs, and catalog record.
- No placeholder, default, mismatched, or undocumented super-event asset remains.

- Event implementation docs exist under the accepted event documentation path.
- Decisions, focuses, countries, assets, super-events, scenario, probability, and completion evidence have permanent documentation.

## Completion audits

Before a completion claim, run or obtain:

- event-chain MCP inspect, render, lint, and compare evidence
- focus-tree MCP inspect, render, lint, and compare evidence
- probability audit and same-scenario comparisons for changed weights
- decision and mission audit
- focus-tree audit
- country-package audit
- localization audit
- final event completion audit
- asset coverage and runtime crosswalk review
- super-event research and wiring review
- spreadsheet alignment pass

The explicit autonomous debug playtest skill is outside the normal workflow and is not required unless the user invokes it.

## Forbidden simplifications

The following do not satisfy the specification:

- one popup followed by a generic civil war
- one flat national spirit replacing Influence
- a political-power shop with passive bonuses
- one generic foreign chapter event copied worldwide
- a formed state with no tree, army, AI, or economy
- a thin tree with one route per ideology
- a supremacist route with only stronger modifiers and no resistance or consequences
- a world end triggered only by Chaos and Yakub's existence
- Yakub's death making the whole event silently stop
- a scenario that merely fires the normal entry event at every intensity
- generated portraits for real leaders
- reused or recolored flags without ImageGen source work
- a default super-event track
- directly edited catalog CSV files
- hidden race simulation or race-targeting mechanics

## Completion statement

Event 044 is complete only when every accepted surface above is implemented or a deviation has been explicitly approved, recorded in the source spec, and reported in the final completion report. Any missing route, AI plan, asset, regional module, scenario type, terminal variant, succession outcome, or catalog surface keeps the event incomplete.
