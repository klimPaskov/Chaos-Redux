## Locked planning decisions

The crisis exposes one persistent public value, `Yakubite Influence`. Hidden state scores, chapter strength, institutional reach, faction strength, intelligence penetration, grievance pressure, and regional suitability may remain numerous. They feed the public value and qualitative state statuses.

The American crisis uses an ordinary decision category with a clear meter, state highlights, a static category picture, and phase-based decisions. A separate scripted GUI would add complexity without improving the main choices.

A formed Yakubite state is a human country. It may be registered as a special Chaos country for shared event-routing purposes. It must stay outside `is_actual_nonhuman_country` and must continue using normal civilian, famine, migration, occupation, population, and diplomatic systems.

The design creates no race-percentage simulation, racial unit bonus, biological racial modifier, protected-class target selector, or race-specific death mechanic. Yakub's claims remain movement doctrine. Objective narration never treats them as scientific truth.

The event uses normal land units, equipment, ships, and aircraft. No custom 3D model or custom unit family is required.

The design keeps the event outside the cluster system. Its domestic, separatist, international, and terminal stages already provide sufficient escalation.
