# Event 044 specification part 6: presentation, assets, and writing direction

## Presentation hierarchy

Event 044 should feel serious, strange, political, and increasingly international. Its presentation must keep the player oriented without turning the event into a separate game inside the game.

Use the least complex surface that communicates each stage clearly:

1. The first appearance uses a normal country event with a dedicated report image.
2. The domestic crisis uses one ordinary decision category with a static category picture, a visible Yakubite Influence meter, concise status text, chapter map highlights, and phase-based decisions.
3. Formation of a Yakubite state uses a major news event, country creation package, flag reveal, and focus tree reveal.
4. Evolution II uses regional report events, local decision categories, and map highlights rather than one global management window.
5. Evolution III uses the strongest surviving state's decision category as the International headquarters surface. International Cohesion replaces domestic Influence as the main public bloc value for the anchor state.
6. The terminal route uses a dedicated world-end super-event.
7. Defeat of the terminal order uses a separate global aftermath super-event when the campaign conditions justify it.

A full scripted GUI is not part of the accepted design. It would encourage extra counters, duplicate decisions, and a broad target list that normal decision tools can already handle. The implementation may use a compact attached meter or category header if the established Chaos Redux decision pattern supports it cleanly.

## Visual identity

The event's visual identity should develop through four stages.

### Stage one: the public claimant

The early palette should use muted industrial colors, church and meeting-hall interiors, street crowds, newspaper photography, microphones, printed pamphlets, factory districts, and government surveillance imagery. The central image is a disciplined movement forming around a man who claims impossible authority.

Avoid laboratory imagery, racial diagrams, skull charts, caricature, meme depictions of Yakub, fantasy lightning, and modern political rally visuals. The initial uncertainty should come from the claimant's presence and organization, not from supernatural spectacle.

### Stage two: parallel institutions

Evolution I should show schools, food distribution, printing presses, uniforms, neighborhood patrols, legal offices, cooperative stores, meeting halls, and contested municipal authority. Visual progression should make the movement look more organized and more capable of governing.

The imagery must distinguish public services from militarization. Relief, schools, and local administration should not all use armed figures. Community defense art should use disciplined period equipment and avoid paramilitary glamour.

### Stage three: state and diaspora

The formed state should gain a coherent national identity with government buildings, public congresses, industrial districts, military parades, foreign delegations, and competing route symbols. Evolution II should use regional art that preserves local identity. Caribbean, Brazilian, British, French, West African, South African, Ethiopian, and Liberian modules should not share one generic crowd image.

Regional art may show local newspapers, union halls, religious gatherings, port cities, schools, colonial police, anti-colonial meetings, or parliamentary chambers according to the module. It should not visually imply that every local movement accepts Yakub's doctrine.

### Stage four: international and terminal order

Evolution III should use congress halls, coordinated relief shipments, volunteer columns, radio offices, diplomatic delegations, and a shared emblem. The terminal route should expand to large-scale political mobilization, contested capitals, revolutionary armies, treaty accessions, and collapsing governments.

The supremacist variant needs authoritarian visual language, rigid formations, exclusionary civic symbols, loyalty ceremonies, and state surveillance. It must not use triumphal biological imagery or depict any race as monstrous. Its severity should come from government practice, repression, and political domination.

## Yakub portrait

Yakub is an impossible or fictional high-chaos subject. His complete portrait package belongs to the portrait worker and may use native ImageGen.

The portrait should show a serious Black male political-religious leader in a 1930s or early 1940s setting. The image should use full HOI4 leader framing and should support his role as an organizer, claimant, scientist-prophet, and ideological founder.

Required qualities:

- mature adult appearance
- composed expression
- period clothing with restrained ceremonial or scholarly detail
- distinctive but plausible silhouette
- no modern accessories
- no pseudo-scientific instruments as racial proof
- no grotesque anatomy
- no caricature
- no meme-associated depiction
- no readable generated text
- no symbols copied from a real modern extremist group without research and approval

The portrait should remain stable while Yakub is public, monitored, detained, or underground unless the implementation provides a justified alternate portrait. Dead, missing, and discredited states should normally change character availability and event imagery rather than create a corpse or humiliation portrait.

## Successor portraits and institutional leadership

The route package may use fictional one-person successors only when the spec requires a named political leader and the portrait brief classifies the subject as fictional high chaos. Institutional outcomes should use councils, committees, and directorates with institutional names when a single invented personality would add little.

Do not create real historical leaders and assign them fictional allegiance to Yakub. Do not use a real Nation of Islam leader, civil rights leader, Pan-African intellectual, religious leader, or anti-colonial activist as a route leader without direct source support and a separate grounded portrait workflow.

Possible portrait or identity packages include:

- a fictional Designated Messenger
- a fictional military chair for the Defense Council
- a fictional chief organizer for the International Secretariat
- an institutional portrait for the Council of Temples
- an institutional portrait for the Federal Council
- an institutional portrait for the Revolutionary Committee
- an institutional portrait for the Originalist Directorate

Every one-person leader needs route, role, gender, name-pool, and source-mode documentation. Every institutional leader needs an institutional name and a people-free or clearly staged institutional image.

## Flags and emblems

All new flags require an ImageGen source package under the event asset workflow. The design should produce separate flat flags for materially different political identities, not recolors of one emblem.

The base American Yakubite state flag should communicate statehood, industrial origin, Black separatist politics, and religious-political authority without copying a modern organization flag as a direct substitute. Research may inform geometry and symbols. The final design must remain a clean flat flag with no fabric scene, lighting, gradients, text, fake writing, or perspective.

Required route variants:

- founder-led religious state
- federal separatist republic
- secular Black republic
- Original Supremacy state
- Diaspora Congress state
- International headquarters identity when a cosmetic tag is justified
- terminal world-order identity for each route family only when the route changes the central state's public identity

Regional foreign breakaways should use locally grounded flags. A Caribbean state should not receive the same flag as a West African or Brazilian state. Shared symbolism can appear through an International emblem, small canton, seal, or faction symbol where the route supports it.

The Yakubite International needs one faction emblem and route-state variants only when the route has a different institutional identity. Avoid excessive emblem proliferation. A single emblem with distinct route flags is preferred over five nearly identical faction icons.

## Event and report images

The asset package should include a bounded set of strong report images rather than an image for every subevent.

Recommended report image families:

1. Yakub's first public appearance in Detroit.
2. Federal surveillance and chapter mapping.
3. A movement school or food-distribution network.
4. A failed arrest or martyr crisis.
5. A constitutional negotiation over autonomy or statehood.
6. A unilateral breakaway and improvised government.
7. A founding convention inside the new state.
8. A foreign chapter adapted to a local regional module.
9. An international congress.
10. An International schism.
11. A supremacist loyalty ceremony or crackdown.
12. A terminal mobilization scene.
13. A terminal defeat and dismantling scene.

Several regional events may share one carefully selected image inside a module. They should not share an image across unrelated regional modules when the location and political form are central to the event.

Generated report images should resemble period press photography or period documentary illustrations. They should avoid modern cinematic color grading, modern crowd-control gear, modern microphones, modern vehicles, contemporary city skylines, readable fake text, and theatrical fantasy effects.

## Decision category picture

The domestic crisis needs one static decision category picture on the established reference-family canvas after the active consumer is inspected.

The picture should show Yakub at a podium or meeting hall with followers, journalists, and discreet government observers in a Detroit industrial setting. It should establish the event's identity without painting a meter, button, or fake control into the image.

The picture may receive route replacements after state formation:

- founding convention
- state administration
- International congress
- Originalist authoritarian assembly

Only add replacements when the category remains active long enough for the changed identity to matter. Do not create a separate category picture for every Influence stage.

## Icon families

Each gameplay surface needs its own icon family. Do not resize one focus icon to fill decisions, ideas, and achievements.

### Decision icons

Decision icons should cover the main action families:

- surveillance and informants
- financial investigation
- negotiations and concessions
- public services and employment
- legal recognition
- arrest and targeted operations
- general suppression
- institution building
- defense organization
- foreign organizing
- aid corridors
- congress activity
- discipline and member sanctions
- federation and terminal commitment

The decision category icon should use a distinct movement emblem or podium motif. It should not use Yakub's full portrait reduced to a tiny icon.

### Idea icons

The three starting ideas need separate 64 by 64 symbolic art:

- Disputed Revelation
- Parallel Institutions
- Improvised National Defense

Each route's final institutional idea should receive its own icon only when the idea is a persistent route identity. Staged upgrades should normally reuse a coherent icon family with meaningful visual progression.

### Focus icons

Focus icons should be organized by route family:

- founder and religious authority
- federal institutions
- secular revolution
- Originalist authoritarianism
- Diaspora Congress and diplomacy
- community economy and relief
- national defense and arsenals
- intelligence and internal security
- territorial integration
- International offices
- terminal preparation

The route families should share visual language without using identical icons. The Original Supremacy route must not rely on racial caricature or pseudo-scientific imagery. Use state control, ideological schooling, loyalty administration, security organs, and rigid hierarchy.

### Achievement icons

Every achievement needs a full triplet with distinct composition:

- No Martyrs
- The Peaceful Partition
- A Nation Before a State
- The Congress Holds
- Doctrine Without Dominion
- The Founder Is Gone
- The Inversion
- Every Temple Empty

The Inversion may use ominous authoritarian imagery. It should not depict the domination or humiliation of a racial group as celebratory art. Every Temple Empty should communicate dismantling institutions and ending the movement, not destroying civilians or religious buildings indiscriminately.

## Animation decision

No animation is required for the accepted baseline asset package.

The event's presentation gains more from strong period report art, clear route flags, good focus icons, and unique super-event packages. Adding animated seals, leader overlays, or decision pictures would increase cost and wiring risk without clarifying a mechanic.

A later implementation pass may propose one animation only if it communicates a meaningful state that static art cannot show. Such a proposal must identify the state, consumer, frame plan, static fallback, and player benefit before asset work begins.

## Super-event presentation

### The Yakubite World

The terminal super-event marks the moment when a viable state and international system commit to replacing the existing world order. The image should show the route's political center, delegations or armed columns, and a visible sense of global commitment.

The selected route changes the image direction:

- supremacist route: rigid authoritarian congress, security formations, coerced accessions, and political domination
- federal route: a large convention of member governments and regional delegations
- revolutionary route: anti-colonial armies, liberated capitals, and coordinated uprisings
- congress route: diplomatic assembly, mass organization, and negotiated accession under intense pressure
- religious commonwealth route: ceremonial leadership, institutional devotion, and a transnational state order

The title, description, button text, quote, and unique musical cue require separate research. No quote, lyric, scripture excerpt, slogan, or cultural remark in this spec is final.

### Defeat of the terminal order

The defeat super-event should fire only after a true global campaign. It should show exhausted capitals, dismantled International offices, released member states, trials or negotiated settlements, and survivors rebuilding political life.

The tone should be reflective and specific. It should recognize the cost of the war and the unresolved future of Black self-determination, anti-colonial politics, and the successor states. It should not reduce the aftermath to victory over a racial group or a religion.

## Audio direction

Each super-event needs a unique licensed or public-domain musical recording, a unique audio ID, settings-aware playback, source and license documentation, and a final game-ready WAV.

The terminal cue should support political mass mobilization, religious authority, revolutionary momentum, or authoritarian ceremony according to the route. The defeat cue should be restrained and reflective. Pure drones, stingers, generated tones, test signals, or abstract noise beds cannot serve as final audio.

Normal event stages should rely on standard event sound treatment unless a specific existing sound helps communicate arrest, state formation, congress assembly, or war. Do not create a large bespoke sound package for ordinary decisions.

## Player-facing writing principles

All final text must describe an alternate-history movement, its institutions, its opponents, and its consequences. The narration must keep doctrinal claims inside attributed speech, movement teaching, propaganda, school material, testimony, or official analysis.

Objective narration may state that Yakub appears, makes claims, organizes institutions, gains followers, forms a government, or controls territory. Objective narration may not state that any racial creation story is scientifically true, that any race has an inherent moral nature, or that one race is biologically superior.

The movement's terms can appear where the speaker is clear. Tooltips and Event Details should use plain descriptive language when a faction term would confuse the player.

## Terminology rules

Use `Yakubite` for the event-specific movement, institutions, state, and International.

Use `Nation of Islam` only when discussing the historical movement, background, doctrinal relation, or a researched response. The event's new movement is not a direct recreation of the historical organization.

Use `Black separatist`, `anti-colonial`, `religious-political`, `federal`, `revolutionary`, `supremacist`, and `authoritarian` according to the actual route.

Use `Black supremacy` where the Original Supremacy route openly adopts it. Keep the speaker or state doctrine clear. Do not hide the route's meaning behind euphemism.

Do not describe mainstream Islam as Yakubite. Muslim governments and communities should be able to reject the doctrine explicitly.

Do not use zoological, contaminant, disease, infestation, purification, breeding, bloodline, or extermination language for racial groups. Such language should not appear as neutral interface text. A supremacist faction's propaganda may contain exclusionary claims only when needed to show its ideology, and final wording must avoid extended hate slogans or real-world recruitment language.

## First appearance writing direction

The opening event should present a public meeting in Detroit, the claimant's impossible identity, the first press attention, and the government's lack of reliable records. The player should understand that a movement can form around him even if the government doubts every claim.

The event should not open with a joke or internet reference. It should not summarize the whole doctrine in graphic detail. It should identify the racial creation claim as Yakub's teaching and explain that it inverts white-supremacist mythology.

American options should represent immediate policy posture:

- observe and verify
- tolerate monitored organization
- open a political channel
- prepare legal action
- order an aggressive response

Final option wording may use restrained official language, political cynicism, fear, or disbelief. It should not use racial slurs or joke about the protected groups involved.

## Crisis writing direction

Domestic report events should focus on visible developments:

- a school opens
- a food network wins support
- a chapter is infiltrated
- an arrest fails
- local officials negotiate
- security groups appear
- a prediction is discredited
- a municipal government loses authority
- a constitutional commission begins

Each report should explain the player's usable information and the immediate consequence. Hidden faction scores and internal formulas remain absent.

Government repression should be written in concrete terms. State raids, detention, censorship, financial seizures, and use of troops have different meanings and consequences. Avoid generic language such as `crack down harder` when the action has a specific form.

## State formation writing direction

The state-formation event should name the territory, formation path, provisional authority, and Yakub's role. A negotiated compact should sound different from a unilateral declaration or federal collapse.

The new state's text should acknowledge disputed legitimacy, mixed local loyalty, improvised administration, and the practical work of feeding cities and organizing defense. It should avoid presenting statehood as proof of the doctrine.

United States aftermath text should describe the constitutional, political, military, and economic consequences. It should not imply that all Black Americans joined the new state or that every person in ceded territory shares its ideology.

## Regional writing direction

Regional text must retain local political vocabulary and institutions. A Brazilian civic organization, Caribbean religious movement, British anti-colonial network, French intellectual movement, West African labor coalition, South African resistance organization, Ethiopian government, and Liberian political faction should not speak with one American voice.

Foreign event text should identify whether a local movement adopts Yakubite doctrine, adapts selected ideas, cooperates tactically, rejects the theology, or opposes the International. The player should be able to understand the relationship without reading hidden values.

References to real movements, organizations, people, slogans, religious terms, and period law require source verification before final localization.

## Original Supremacy writing direction

The route should state plainly that the state adopts Black supremacy and racial inversion as official doctrine. The writing should show authoritarian law, exclusion, loyalty control, repression, resistance, diplomatic isolation, and factional conflict.

The route may use self-important state propaganda, bureaucratic euphemism, grand racial destiny claims, and doctrinal certainty in attributed faction text. Objective descriptions and tooltips must maintain distance and explain consequences.

Avoid building the route around repeated hostile monologues. Most content should concern institutions, policy, resistance, diplomacy, military mobilization, and internal power. The route should feel like a government with a destructive ideology, not a collection of slogans.

## Event Details and catalog wording

Event Details should contain a concise premise that explains:

- Yakub's claimed identity
- the American origin
- the movement's political and institutional growth
- the possibility of state formation and international spread
- the fact that the doctrine is presented as faction belief

It should not list decision effects, hidden thresholds, secret routes, succession outcomes, terminal readiness formulas, achievement conditions, or future surprises.

Evolution detail entries should explain the new public stage:

- The New Nation: parallel institutions and territorial state-building
- The Diaspora Awakens: locally adapted chapters and anti-colonial connections
- Yakubite International: coordinated political, economic, intelligence, and military cooperation

The world-end row should describe a viable International committing to a global replacement order. It should have its own toggle and should not reveal the exact footprint proof.

The spreadsheet event detail, evolution detail, scenario detail, and world-end wording should match in-game text after implementation. Update the authoritative workbook and regenerate the CSV exports. Do not edit export CSV files directly.

## Event Log direction

The normal entry event records once as Event 44. Baseline subevents should not each create a normal global history row.

Each true evolution records one evolution entry with the correct actor when one exists. A pre-fire evolution intensifies the opening but still records the evolution through the accepted pacing and logger rules.

State formation, International formation, terminal activation, and terminal defeat may receive news events or super-event presentation without being misclassified as new random events.

The event log actor should be the United States during the opening crisis, the formed state when it becomes the event's central actor, and the International anchor during the final evolution and terminal branch.

## Localization quality controls

Final localization should:

- use complete readable sentences
- avoid em dashes and semicolons
- avoid staccato dramatic fragments
- avoid thesis and antithesis templates
- avoid generic crisis filler
- avoid raw variable names
- show integer values without unwanted decimals
- identify dynamic countries, states, actors, and routes where relevant
- give every blocked decision a concise reason
- keep value tooltips short and causal
- keep option text short enough for the UI
- preserve the distinction between doctrine, propaganda, official belief, rumor, and objective state

Broad text should receive a localization audit before completion.

## Documentation package

Implementation documentation should include:

- one event overview under `docs/events/044_yakub_returns/`
- system notes for Influence, chapter targeting, institutional state, International Cohesion, succession, and terminal readiness
- one country package document for the American state and foreign regional variants
- one focus tree route coverage table
- one decision and mission inventory
- one asset requirement and runtime crosswalk
- one super-event research note
- one scenario registration note
- one probability audit report
- one completion report

Durable asset provenance, route coverage, final audio sources, and runtime consumers must be promoted into permanent documentation before the temporary event asset workspace is deleted.

## Presentation acceptance state

The presentation is complete only when the player can identify the current crisis stage, the central public value, Yakub's status, the government's main policy choices, the formed state's route, the International's form, and the terminal conflict without reading implementation notes.

The visual package is complete only when every accepted visible surface has final art, the route flags are distinct, the portraits follow the correct source mode, the icon families are not resized copies, and both super-events have aligned image, text, quote, audio, trigger, documentation, and catalog records.
