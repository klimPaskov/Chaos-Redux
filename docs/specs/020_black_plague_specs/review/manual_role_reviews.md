# Manual Role Reviews

## Disclosure

All supplied custom subagent contracts were read in full. No custom subagent spawn tool was available. The reviews below apply each contract manually and do not claim that separate subagents ran.

## Repo explorer role

### Finding

Implementation spans events, disease decisions, selected-state UI, mapmode colour resolution, special projects, triggerable scenarios, focus trees, country packages, assets, super-events, AI, docs, and catalog data. A live explorer pass is required before final identifiers and paths are chosen.

### Limitation

The live repository, Windows game path, offline wiki, and vanilla files were not mounted. The coding prompt requires a real explorer pass before final scenario IDs, mapmode hooks, tags, helpers, GUI anchors, or precedents are selected.

## Decision and mission auditor role

### Result

The general disease category remains dynamic. It contains shared responses plus separate Black Plague actions such as cleaning city rats, sealing food stores, clearing sewers and burrows, flea control, transport-node purges, and block demolition. Costs use material, logistical, military, economic, political, and social burdens rather than becoming a political-power shop.

### High-risk implementation checks

- selected-state Black Plague actions appearing for the wrong disease
- obsolete actions remaining after phase changes
- rat-clearing actions stacking or farming Rat Infestation reduction
- quarantine without relief increasing mortality correctly
- selector cleanup after annexation, cure, tag change, or scenario launch
- scenario bootstrap flooding the category with every state action at once
- AI equivalents for all meaningful human-only controls

## Focus tree auditor role

### Result

Base Rat Nations have a 40 to 50 role architecture with interacting lanes. Rat King has a 70 to 100 role architecture with three governments, support branches, internal crises, continent play, and world-end convergence. Scenario-created actors receive the same full packages and valid route state as natural actors.

### High-risk implementation checks

- shared-tree archetypes feeling identical
- scenario actors missing opening focuses or route flags
- repeated icons or modifier-only rewards
- world-end line becoming a straight checklist
- Rat King government branches failing to change decisions and AI
- scenario King starting with terminal focuses bypassed

## Country package auditor role

### Result

The package covers finite tags, territory, capitals, nonhuman classification, leaders, portraits, flags, government, units, reinforcement, supply, focus loading, AI, decisions, defeat, cleanup, natural creation, and scenario creation.

### High-risk implementation checks

- tag conflicts or insufficient free tags at Maximum intensity
- invalid state transfer or overlapping Royal Basin selection
- units lost or duplicated during absorption and coronation
- ordinary manpower or equipment leakage
- portrait and name metadata mismatch
- destroyed tags retaining focus, pulse, or AI state
- scenario reuse of an existing Rat King creating a second sovereign

## Localisation auditor role

### Result

The spec gives direction rather than final copy. It distinguishes shared disease wording from Black Plague-specific sanitation wording, requires dynamic state names and Rat Infestation values, and marks scenario working labels as non-final.

### High-risk implementation checks

- working labels copied into final localisation
- dedicated-category wording appearing despite shared ownership
- raw dynamic triggers in tooltips
- black mapmode tooltip disagreeing with the actual colour
- inconsistent scenario names between registry, UI, docs, and catalog
- hidden evolution or achievement thresholds exposed
- Event Details listing effects

## Asset roles

### Source and generated art

No real historical rat leader or flag is required. Generated art is appropriate for fictional plague scenes, nonhuman leaders, flags, icons, and super-events. Audio and quote sources still require verification.

### Icon and UI review

The asset prompt separates disease selector, Black Plague decision, idea, focus, achievement, portrait, flag, report, news, super-event, UI, and animation outputs. It does not request a dedicated Black Plague category icon or separate scenario window art.

### Frame animation review

Animation is limited to surfaces where it carries state, including the crisis seal, black-fog prototype, Rat King portrait, and world-end readiness seal. Every final animation requires real source frames, a static fallback, a frame sheet, DDS, contact sheet, and review preview.

## Super-event text and audio roles

Coronation wording supports natural unification and scenario coexistence with independent broods. Coronation and world end require unique tracks and verified wording. Final selection, download, editing, conversion, attribution, and wiring remain implementation work.

## Documentation curator role

The revised spec folder is the source of truth. Part 9 and later user corrections supersede earlier anti-scenario statements. The obsolete Event 20 and scenario catalog rows require replacement after final localisation.

## Completion auditor role

The planning package covers the original request and later corrections. Final completion remains limited to design. Gameplay, assets, live-source validation, scenario registration, mapmode implementation, and in-game balance are not claimed complete.
