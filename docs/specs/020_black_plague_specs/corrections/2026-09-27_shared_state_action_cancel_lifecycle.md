# Shared state-action cancellation lifecycle

**Disposition: implemented in source; native decision-timer behavior remains unverified.** The user's accepted CBRN overhaul requires Event 020's response costs and actions to produce their stated outcomes without an internal state flag canceling a paid action. All 26 ordinary selected-state timed decisions previously used `NOT black_plague_shared_state_target_is_usable` as their `cancel_trigger`. The Royal Node counterstrike separately negated its own start-only gate. Both start gates require `NOT black_plague_shared_action_active`, while every timed action sets that flag. Thus 27 running actions could make their own cancel predicates true before reaching `remove_effect`.

The 26 ordinary decisions now call `black_plague_shared_active_state_action_is_invalid`, a state-scoped helper with the responding country as `ROOT`. It cancels when the actual active project is invalid: the state is no longer controlled or tracked, is cured or rat controlled, the world has ended, mobilization failed, the country cannot direct response, or the exact active/action/owner receipts are missing or belong to another country. It does not reuse the start-only cooldown or current-board-selection gate, so selecting a different state does not cancel a valid timed project. The Royal Node counterstrike uses a second continuation helper because its valid target remains rat controlled; it requires current rat-country control, the royal-node flag, access, military route, country authority, and the exact `strike_royal_node` action and owner receipts without negating its own active flag. Crown Strike, Seal, and the other fifteen special cancellation rules retain their separate contracts.

The shared cancellation effect clears a country-side pending action even when its start was rejected before an active state receipt was created. The finish effect clears its state action scale alongside the action and owner. These are cleanup changes, not new costs or rewards. An actual canceled paid action retains the existing material-spent-at-start behavior and receives its existing cooldown; no refund is added or promised. A valid completion continues to the existing once-only result, capacity release, and cooldown path.

Source acceptance cases: a selected valid state that sets `black_plague_shared_action_active` keeps `cancel_trigger` false through its timer; a later board selection change alone keeps it false. Control loss, cure, rat takeover, terminal world state, failed mobilization, a missing active receipt, or owner mismatch makes it true and routes to `cancel_effect` without `remove_effect`. A valid Rat-country-controlled Royal Node with access and an active strike receipt also keeps its cancel trigger false; loss of the node, current Rat controller, route, or owner cancels it. A rejected start with only the country pending token clears that token when canceled. These are source-path expectations; the game timer, payment timing, and cancellation outcome remain to be verified in the native consumer.
