The current inspected event is a fixed entrenchment reward. Its nine-month duration, acknowledgement-based application, multiple preset statistics, attrition penalty, and civil-war inheritance are not the requested random one-year system.

The rework preserves the existing entry identity while replacing that behavior. A zero-padded catalog or filename does not justify inventing a new `chaosx.nr087` namespace.

The uploaded event row must eventually become Military Madness with Military Preparation as its cluster. The uploaded cluster catalog identifies Military Preparation as cluster 18. Its member row does not yet contain Event 087.

Neither workbook nor CSV was edited for this planning task. The eventual workbook update must preserve other event rows and use the repository exporter.

## Feasibility findings and boundaries

Dynamic modifiers support variable-backed effects, but this does not establish arbitrary runtime enumeration of all engine modifier keys. The specification therefore chooses build-time discovery and admission, followed by runtime sampling from a compiled versioned pool.

The inspected snapshot distinguishes ordinary numeric modifiers from `equipment_bonus` and `research_bonus` idea attributes. Those attributes cannot simply be placed into the same dynamic-modifier block.

A soft-attack, armor, unit-specific, terrain-specific, or custom-system design row therefore needs a real country-scoped binding or reversible national adapter. It must not be claimed supported merely because a similarly named effect exists in another scope.

The daily evaluation order described by the snapshot makes a naive total-minus-self safety calculation suspect. The final applied-total protection must be proved against actual update ordering and supported external contributors.

No exact new HOI4 modifier token or numerical safety bound is certified by this package. The semantic magnitude table is a detailed design target, not a prevalidated runtime registry.

## Deliberate scope decisions

The package expands the lottery, timed overlap, readable results, tactical implications, provider coverage, and achievement opportunities. It does not add selectable military archetypes, paid rerolls, invented forces, a focus tree, a new country, a super-event, or a world-end scenario.

Those omissions preserve the requested passive random event. They are not hidden substitutes for requested systems.

The unresolved Boolean case is disclosed because “every temporary military effect” and “a randomized meaningful magnitude” can conflict for one-value capabilities. Such candidates must receive an explicit technical disposition rather than a fabricated numerical range.
