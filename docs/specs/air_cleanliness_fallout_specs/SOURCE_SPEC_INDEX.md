## Relationship to earlier packages

This package includes normalized accepted baseline specs, baseline matrices, and the corrected implementation architecture. The earlier zip packages remain historical inputs, but they are not required to understand this consolidated suite.

Where an earlier package gives Fallout an ordinary numbered event identity, zombie-owned asset path, fixed scenario id, normal super-event, 1000-percent-only trigger, or sparse post-rewrite event layer, this package and the corrected ownership files supersede that guidance.
