
# Fallout Living World Planning Pass

This package consolidates the accepted Air Cleanliness and Fallout baseline, corrected implementation architecture, and living-world expansion into one planning suite for a ten-year scenario.

The normalized baseline files establish the systems that destroy and rebuild the map. The new pass fills the former event-life gap with a large event architecture, regional and government-specific chains, recurring characters, diplomacy, war causes, social change, mutant-fiction boundaries, climate recovery, and a normal-map cold presentation requirement.

## Main additions

- A catalogue target of roughly 660 to 910 unique Fallout event blocks across the full implementation.
- A per-campaign target of roughly 90 to 180 meaningful visible events over ten years for a human country, with variation by region, government, cause memory, neighbors, and choices.
- Global events that affect food, water, shelter, medicine, salvage, power, legitimacy, crime, refugees, war, and recovery.
- Regional event pools for eight broad successor regions plus a separate polar and remote-station layer.
- Government-archetype event pools for all twelve accepted Fallout archetypes.
- Four linked country-memory arc obligations for every one of the 99 candidate successors, covering opening, domestic conflict, external relations, and late identity.
- Recurring character arcs whose outcomes change advisors, commanders, leaders, decisions, and route access.
- Diplomatic contact, recognition, compacts, trade, convoy, border, refugee, and war-settlement chains.
- Fictional mutant and altered-ecology events with explicit science boundaries.
- Recovery, thaw, ultraviolet, second-generation, constitutional, and interregional world-order arcs.
- Visible cold in normal map presentation in addition to the winter mapmode.

## How to use the package

Read `SOURCE_OF_TRUTH_AND_SCOPE.md` and `SOURCE_SPEC_INDEX.md` first. Then read the living-world event ecosystem and winter climate visual overhaul. The timeline spec determines when pools become eligible. The event bibles and matrices determine content. The content-budget and acceptance file defines the minimum depth and anti-spam standard.

The continuation prompt points the next implementation pass to the exact proof gates and first content tranche.
