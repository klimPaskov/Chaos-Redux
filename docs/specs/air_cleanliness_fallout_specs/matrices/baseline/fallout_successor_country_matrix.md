# Fallout Successor Country Matrix

Canonical status: accepted baseline matrix. Use with the living-world event matrices and corrected Fallout ownership rules.

Working labels in this file are not final localisation. They are implementation planning labels for cosmetic tags, existing tags, civil-war clones, releasables, or dynamic country names.

This matrix defines 99 candidate successor packages. The implementation does not need to spawn every candidate in one Fallout run. It should use the state-class map, regional cause memory, population survival, and tag availability to select a dense but playable spread.

Every selected successor must receive a Fallout origin flag, a government archetype, non-generic focus content, starting forces, survival-resource pressure, AI behavior, and visible assets. Mutant rows are fictional Chaos Redux content. They must not be presented as real radiation science.

## Selection rules

- Prefer existing tags, releasables, cosmetic tags, and civil-war clones before new base tags.
- Do not spawn two candidates that need the same capital state unless one becomes a subject, exile, convoy government, or cosmetic identity inside the other.
- A candidate with no matching state classes should stay dormant and appear only as a possible exile, focus route, or later releasable.
- A candidate with only one viable state should receive a small focus overlay and survival decisions, not a full regional empire path.
- A candidate with several high-value state classes should receive a stronger country memory branch and late-game ambition.

| --- | --- |
| Many bunker cities | Continuity governments, bunker authorities, machine protocols, and quarantine republics gain priority. |
| Many greenhouse refuges and ash farms | Food compacts, relief authorities, agrarian leagues, and refugee republics gain priority. |

| Many reactor keeps and hydro enclaves | Technates, reactor cults, and power-grid leagues gain priority. |
| Many forbidden zones and mutant biospheres | Mutant polities and hard quarantine states gain priority. |
| Cause memory from biological or chemical events | Quarantine republics, mutant biospheres, medical dictatorships, and altered ecology rows gain priority. |
| Cause memory from Final Silence or other terminal metaphysics | Machine protocol, religious refuge, and strange mutant rows gain priority. |
| Southern Hemisphere buffer | Food haven, lifeboat, mine continuity, and remote island rows gain priority because direct targeting and winter severity can be lower there. |

## Minimum package rule

A selected row is not complete until it has a leader or council direction, public country naming direction, flag plan, starting idea set, military package, focus overlay, decision category hooks, AI strategy, and at least one route-specific asset family. A shared archetype tree is allowed only when the row receives a regional overlay and a country memory overlay.
