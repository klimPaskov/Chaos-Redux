# Fallout Focus Overlay Matrix

Canonical status: accepted baseline matrix. Use with the living-world event matrices and corrected Fallout ownership rules.

Working labels in this file are not final localisation. The matrix defines how shared Fallout focus skeletons become non-generic through archetype overlays, regional overlays, and country memory overlays.

Every Fallout country should receive three layers: one archetype skeleton, one regional overlay from this matrix, and one candidate-specific memory overlay from the successor matrix. A shared skeleton without the other two layers is incomplete.

## Country memory overlay rules

| Memory input | What the overlay must add |
| --- | --- |
| Old capital survived | A legitimacy or command branch that uses the capital as a restoration proof. |
| Old capital became dead city | A memory branch around salvage, mourning, revenge, or deliberate rejection of the old capital. |
| Main assets are ports | A maritime branch with refugee policy, convoy law, piracy risk, and island diplomacy. |
| Main assets are farms | A food branch with seed banks, farm defense, ration legitimacy, and refugee pressure. |
| Main assets are reactors or hydro | A technate branch with power diplomacy, engineer rule, meltdown risk, and power-backed industry. |
| Main assets are bunkers | A bunker branch with citizenship rules, air rationing, surface expeditions, and authoritarian drift. |
| Main assets are forbidden zones | A risk branch with salvage rights, mutation events, quarantine conflict, and extreme late-game options. |
| Cause memory is chemical or biological | Medical, quarantine, filter, and public blame branches must appear even for non-medical archetypes. |
| Cause memory is Final Silence or other metaphysical terminal event | Religious, machine, mutant, or anti-memory branches gain rare focus options. |

## Branch depth rule

A country-specific overlay must contain at least one real branch family with decisions, missions, idea lifecycle changes, AI weights, and asset motifs. A two-focus label does not count. Small island states can use a compact overlay, but the compact overlay still needs a survival decision family and a late ambition.
