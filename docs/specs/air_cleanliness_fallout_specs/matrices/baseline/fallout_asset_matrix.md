# Fallout Asset Matrix

Canonical status: accepted baseline matrix. Use with the living-world event matrices and corrected Fallout ownership rules.

Working labels are not final localisation. This matrix tells asset agents what each visible identity state needs and which source mode applies.

The implementation should not request all assets at once. It should first select spawned successors, then request the matching asset rows in regional batches. Historical or real symbols and real leader portraits require sourced assets. Fictional flags, mutant identities, council portraits, icons, UI panels, and impossible scenes use generated assets through the Chaos Redux asset workflow.

## Shared asset rules

| Asset family | Required coverage | Source mode | Notes |
| --- | --- | --- | --- |
| Fallout mapmode | winter phase colors, fallout state grades, forbidden zones, greenhouse refuges, bunker cities, port remnants, rail spines | generated UI art and coded map colors | Must show state phase and class clearly. |
| Black screen transition | black overlay, centered text layer, fade controller, optional subtle film grain | generated or UI-native | Not a super-event image. It is a scripted GUI blackout. |
| State class icons | bunker city, dead city, greenhouse refuge, ash farm, scavenger badlands, forbidden zone, mutant biosphere, port remnant, hydro enclave, reactor keep, rail spine | generated icons | Use compact 32 or 64 pixel variants as UI requires. |
| Survival resource icons | food, water, shelter, filters, medicine, scrap, power, fuel, trains, convoys, old-world memory | generated icons | Must be readable in decision categories and scripted GUI. |
| Animated warning frames | black snow critical, fallout rewrite pending, shelter riot, food collapse, meltdown risk, mutant breach | generated frame animation package | Real source frames are required for final animation. |
| Archetype focus icon packs | one coordinated pack per archetype and per regional overlay | generated focus icons | Do not derive idea or decision icons from focus icons. |
| Achievement icons | route mastery, survival ten years, humane lifeboat, mutant victory, machine protocol, global reclamation | generated achievement icons | Completed, grey, and not-eligible variants required later. |
