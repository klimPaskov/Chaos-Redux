# Fallout Successor Event Overlay Matrix

Working labels are not final localisation. This matrix adds unique event-memory obligations to all 99 candidate successors from the accepted successor matrix.

Each selected successor receives all four listed arc groups. A candidate that does not spawn in one campaign remains dormant. A compact one-state successor may use shorter chains, but it still requires an opening, domestic identity, external relationship, and late memory arc.
