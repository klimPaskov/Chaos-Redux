Status: ready for reviewed generated production after symbol research.

The historical and cultural reference ledger is `docs/assets/fallout_world_end/nzl_lifeboat_state/source_references/nzl_lifeboat_symbol_manifest.json`. Every flag prompt must remain constrained by that ledger.

## Flags

Create three separate flat ImageGen source masters and three complete TGA size ladders.

| Cosmetic identity | Runtime filenames | Direction |

| `NZL_FALLOUT_PACIFIC_RELIEF_REPUBLIC` | normal, medium, and small tag names | red maritime field, white four-star cross, original green rescue roundel, white lifeboat or lifebuoy, blue wave |
| `NZL_FALLOUT_SOUTHERN_REFUGE` | normal, medium, and small tag names | near-black navy, compact white or silver four-star cross, hard-edged silver fern, restrained red accent |

No flag may use an exact official New Zealand ensign, Union Jack, protected humanitarian emblem, Coastguard branding, regulated Civil Defence mark, Australian fifth star, radiation trefoil, readable text, or anonymous Maori decoration.

## Package evidence

The final package requires source PNGs, processed PNGs, runtime DDS or TGA files, prompt records, a manifest, contact sheets, flag size comparisons, portrait comparisons, and a `.gfx` handoff. Final `.gfx` edits remain parent-owned.

No animation is required for this pilot. The four values change slowly and are presented as text bands. Static focus, decision, idea, achievement, portrait, report, and flag art gives clearer review evidence.
