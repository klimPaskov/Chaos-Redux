# Hungry Battalion Asset Brief

## Accepted row

This brief owns one fictional Fallout report image for the reviewed Food Compact chain reserved at `chaosx.fallout.677` through `chaosx.fallout.683`.

## Report image

| Surface | Requirement |
| --- | --- |
| Asset type | Report event image |
| Source mode | Generated through the approved image generation workflow |
| Target | `210x176` RGBA processed PNG and uncompressed BGRA DDS |
| Source subject | A period-documentary field kitchen beside a damaged granary gate under ash-dark cold |
| Human action | Tired soldiers hold mess tins at a measured ration point while civilian grain sacks and a food-council scale remain visible |
| Period treatment | 1936 to 1945 documentary camera technology, practical winter clothing, period mess gear, canvas shelter, wooden granary construction |
| Avoid | Modern uniforms, modern weapons, readable generated text, maps, war-room tables, cinematic color grading, gore, flags from real extremist organizations, and reuse of any zombie or Final Silence asset |
| Process | Apply the repository report-card processor after generation to create black-and-white sepia treatment, grain, paper border, tilt, transparent corners, and soft shadow |
| Final source path | `docs/assets/677_hungry_battalion/source_png/report_event_fallout_hungry_battalion_source.png` |
| Processed path | `docs/assets/677_hungry_battalion/processed_png/report_event_fallout_hungry_battalion.png` |
| Runtime path | `gfx/event_pictures/fallout/report_event_fallout_hungry_battalion.dds` |
| Sprite | `GFX_report_event_fallout_hungry_battalion` |
| Registry | `interface/fallout_consolidated.gfx` |

The asset worker must inspect the canonical report-event contact sheet before generation. The temporary workspace must retain the final prompt, source master, processed PNG, DDS decode, contact sheet, SHA-256 hashes, manifest, requirement-to-runtime crosswalk, and GFX handoff.

Static presentation is correct for this ordinary report chain. Animation would add motion to a single ration decision without clarifying a living mechanic or state change.
