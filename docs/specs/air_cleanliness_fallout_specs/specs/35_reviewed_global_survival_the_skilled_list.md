# The Skilled List

## Purpose

The Skilled List is a Fallout-owned character-memory chain for the first engineers, doctors, officers, and growers whose names survive the rewrite.

The chain is a country-level scheduler candidate that targets one deterministic native state with a produced Air Winter snapshot, surviving population, and repairable infrastructure.

It is intentionally distinct from the Vault of Voices archive chain and from the Ration Thief Election government chain because its central conflict is whether expertise belongs to a moving roster, a guild, a state service, or a self-governing quarter.

## Opening and choice

The human opening is `chaosx.fallout.429` and the hidden AI opening is `chaosx.fallout.430`.

The four policies are Disperse the Roster, Charter a Specialist Guild, Bind the List to State Service, and Recognize a Self-Governing Quarter.

Each policy has government-aware eligibility, distinct Food, Medicine, Recognition, and Cohesion costs, a visible player tooltip, and an AI preference test.

## Resolution and memory

The delayed result is `chaosx.fallout.431` for the human lane and `chaosx.fallout.432` for hidden AI.

The result freezes survival resources and four specialist ledgers, grades the branch deterministically, updates Food, Medicine, Recognition, Cohesion, Stability, War Support, Adaptation, Reclamation, Supply Access, and Exposure, and applies branch-specific state memory and dynamic modifiers.

Failure damages infrastructure or industrial capacity and routes population loss through the Deaths system contract.

The result records engineers, doctors, officers, and agronomists as durable country ledgers that later focus and event consumers can inspect.

The 240-day review is `chaosx.fallout.433` for human control and `chaosx.fallout.434` for hidden AI.

The review tests whether the named roles became a durable generation of work and applies a second set of resource, state, and memory consequences before the `chaosx.fallout.435` cleanup receipt closes the chain.

## Character surface boundary

The chain records specialist roles and durable memory only.

Native `create_character` or country-leader installation is not used because this engine surface has not been proven in the current repository evidence.

This is an explicit implementation boundary, not a hidden fallback. A later character audit may consume the role ledgers and add native characters after it proves scope, recruitment, death, and multiplayer behavior.
