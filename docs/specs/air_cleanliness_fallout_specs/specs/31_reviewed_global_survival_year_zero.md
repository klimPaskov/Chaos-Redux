# Year Zero

## Accepted identity

This is reviewed global-survival candidate 401. It belongs to the successor-memory cooldown family and the global survival, cause-memory, and world-order primary families. The row remains dormant until Fallout activation authority is proven.

## Opening

The selected native state must have a current Fallout state row, a produced Air Winter snapshot, surviving population, exposure between 18 and 80, and an accepted scarred, ash-zone, remote-refuge, or dead-city grade. The owning country must have a current registry row, food, recognition, and cohesion reserves, plus calendar memory, government legitimacy, anniversary cohesion, and ideology-pressure ledgers. The lowest qualifying native state id is selected so the anniversary returns to the same place on every deterministic rebuild.

## Branches

1. Keep the old calendar so families can compare surviving records with dates they still know.
2. Declare Year Zero so the rewritten country has a common beginning and a public founding memory. Democratic and communist governments may choose this route.
3. Let each region keep its count so ridge winters, river harvests, and damaged borders can be recorded without pretending recovery is even.
4. Set the year by sacred observance so a surviving ritual can carry memory into the new state. Neutral and fascist governments may choose this route.

## Delayed results and callback

The result arrives after 35 days and grades calendar memory, government legitimacy, anniversary cohesion, recognition, and food from frozen ledgers. Success, partial success, and failure alter food, recognition, cohesion, stability, war support, reclamation, supply access, exposure, calendar memory, legitimacy, ideology pressure, building integrity, and population through the Deaths system. Failure damages infrastructure before an industrial building and never writes population loss directly.

The callback arrives after 365 days. It tests whether the chosen date survives a first anniversary, updates the calendar ledgers, leaves branch and anniversary memories with dynamic modifiers, records a second Event Log entry, and releases both cleanup receipts only after the result and anniversary transactions are consumed.

## AI and cleanup

AI selects a branch from legitimacy, anniversary cohesion, calendar memory, recognition, and government identity. Human and AI receipts carry separate event tokens and visible-budget modes. Every registry variable is generation-bound and owner-bound. Cleanup clears frozen inputs, tickets, registry pointers, branch state, and temporary flags without erasing durable memories or Event Log history.
