# Reviewed archetype chain: False Positive

False Positive is a dormant Quarantine archetype chain for the first Air Winter after a completed First Red Line memory. It is ordinary survivor-country content that can run after the Fallout consequence, but it is not the Fallout consequence itself and it does not create a Fallout event-log or evolution row.

## Admission and target contract

The candidate producer selects the lowest owned native state that still has the current survival identity row, a durable country resource row, current Supply Access, Air Winter Shelter Capacity, Adaptation, Reclamation, Exposure, Disease Pressure, and surviving population. The state must already carry the completed First Red Line memory. The owning country must be a Quarantine State with public-health and grievance ledgers, enough Medicine, Cohesion, and Recognition, and at least one complete affordable branch.

The opening receipt stores the country, controller, target state, transition generation, branch, source ledgers, Air Winter values, and the target state reservation. Every delayed result, callback, and cleanup event revalidates those receipts. Ownership, control, generation, target identity, and reserved flags must match before any state effect is applied.

## Branches and delayed results

The human and hidden-AI lanes share four branch contracts.

1. Release and compensate spends Food, Medicine, and Recognition to release cleared households and reduce grievance.
2. Maintain the cordon spends Medicine, Fuel, and Recognition to hold the gate and improve disease control at the cost of fatigue and backlog.
3. Ward tribunal spends Food, Scrap, and Recognition to make the disputed register public and improve institutional memory.
4. Rotate inspection teams spends Medicine, Fuel, and Power to replace exhausted inspectors and reopen the registers.

The result arrives after fourteen days. Deterministic grading uses frozen state Supply Access, Shelter Capacity, Adaptation, Disease Pressure, Exposure, country Medicine, Recognition, reliability, and inspection fatigue. It applies branch-specific Air Winter, Supply Access, resource, Cohesion, public-health, grievance, reliability, compensation, fatigue, appeal backlog, and cause-memory deltas. A failure requests bounded state population loss through the Deaths system and removes one infrastructure level. No division, tag, or state is deleted.

The callback arrives after one hundred fifty days. It grades public health, Cohesion, Recognition, reliability, compensation, cause memory, supply, reclamation, disease, grievance, fatigue, and appeal backlog. It writes a second set of Air Winter and country-ledger effects, requests bounded Deaths on failure, and records a durable callback memory before cleanup.

## Memory, AI, and cleanup

Choice, result, and callback memories use survivor-country Event Log history `9176` with payload-specific scripted localisation. The history represents the country's experience of the screening error. It does not register the Fallout consequence as an ordinary event or evolution. Hidden AI uses the same affordability and result contracts and chooses a deterministic priority order. Cleanup releases both delayed tickets, clears the reservation, closes the state memory, and preserves the country ledger values. Repeated cleanup is idempotent.

## Asset and implementation boundary

The chain uses the dedicated `GFX_report_event_fallout_false_positive` report scene. Its source, processed PNG, DDS, manifest, and handoff live under `docs/assets/691_false_positive/`. The scheduler remains dormant, so static wiring is documented while live dispatch and player presentation remain unproven.
