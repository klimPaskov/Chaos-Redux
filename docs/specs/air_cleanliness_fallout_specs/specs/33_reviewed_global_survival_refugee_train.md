# Reviewed global survival pilot 33: The Refugee Train

The Refugee Train is a dormant Fallout scheduler candidate for a rail-connected border state. It represents migration as a receiving-state decision with a concrete local rail target, a public memory ledger, a bilateral-trust ledger, and an anniversary review. The candidate is not an ordinary super-event and is not eligible for the release-floor count until scheduler activation proves host delivery, save recovery, and multiplayer ownership.

## Opening gate

The producer selects the lowest owned state with a current Air Winter snapshot, surviving population, a native railway, and current-generation Fallout state and resource rows. The country gate requires recognition pressure, food, cohesion, campaign-day limits, and the selected state still being owned by the issuing country.

## Policies and delayed result

Admit the families spends food, recognition, and cohesion under democratic or neutral governments. Redirect the column spends the same ledgers under fascist or communist governments and records a route bargain. Quarantine the train spends the receiving ledger without a government lock. Recruit the specialists is available to several governments and turns the arrival into an engineer and clinician contract. Each branch has a separate outcome threshold, state modifier, survival-ledger effect, and Deaths-backed failure path. The result is delayed for 35 days.

## Memory and callback

The chain freezes food, recognition, cohesion, family memory, border legitimacy, integration cohesion, and bilateral trust before scheduling. The first anniversary returns after 365 days. Success, partial success, and failure change the four country ledgers, the target state's exposure, reclamation, supply access, and migration-arrival record, then release an idempotent cleanup ticket.

## AI and cleanup

AI resolves through border legitimacy, integration cohesion, family memory, and resource thresholds. Human and AI lanes share the same scheduler receipts. Result, callback, and cleanup flags are generation-bound and clear only after both delayed tickets are released.

Later tranches can connect the bilateral memory to a named partner, a refugee-train return crossing, a disease-screening mission, and successor-country citizenship law. Those expansions remain queued until this dormant candidate passes the activation audit.
