# The Bridge That Moved

The Bridge That Moved is a reviewed Fallout ordinary-event chain in `chaosx.fallout`. It is a thaw-year route incident that opens only when a produced Air Winter snapshot exposes a native railway state with damaged infrastructure and low state supply access. The chain remains dormant until the Fallout scheduler proves activation.

The scheduler owns candidate `464`, transaction `710040`, route `7140`, and Event Log history `9145`. Event ids `chaosx.fallout.464` through `.470` are defined in `events/fallout_world_end_events.txt` under the Fallout namespace.

The candidate selects the lowest valid owned state with a railway, infrastructure damage, current Fallout identity and resources, a produced Air Winter snapshot, thaw-eligible normal-map provenance, surviving population, and enough adaptation, reclamation, food, medicine, recognition, and cohesion to make a public crossing decision possible. State selection uses the native state id as a deterministic tie break.

The opening offers four government-aware policies.

- Close the crossing and reroute protects civilians and clinics with a marked detour, at the cost of route speed and local supplies.
- Lay a temporary trestle keeps a narrow civilian route open while the riverbank settles.
- Send military pontoons puts engineers on the crossing and accepts military control of the first repairs.
- Publish a shared bridge rule lets both banks set one public crossing order before private guards claim the route.

The chain freezes crossing damage, route reliability, engineer capacity, local consent, trade memory, food, medicine, recognition, and cohesion before a 45-day result. Result success and partial lanes repair infrastructure and update Air Winter adaptation, reclamation, exposure, supply access, water security, disease pressure, manpower, stability, war support, and the route ledgers. Failure damages rail or infrastructure through the native building effects and applies Deaths-system civilian loss through the exact state population contract.

The 365-day callback revisits the same crossing memory. It uses the same deterministic result for human and hidden AI lanes, records an Event Log payload, and releases the shared scheduler transaction through authenticated cleanup. Every branch has distinct outcome text, state modifiers, and delayed consequences. Durable branch and crossing-failure state flags preserve the route memory after the transaction is released.

The dedicated report asset is registered as `GFX_report_event_fallout_bridge_that_moved` in `interface/fallout_consolidated.gfx` and lives at `gfx/event_pictures/fallout/report_event_fallout_bridge_that_moved.dds`.

Native cross-map bridge topology, native bilateral scope creation, and runtime scheduler delivery remain engine-surface boundaries. The chain does not claim those surfaces.
