# Reviewed Quarantine archetype chain: Border Inspection Crisis

Border Inspection Crisis is a dormant Quarantine-state chain after a completed Clean Certificate memory. It owns candidate `726`, transaction `710075`, route `7182`, history `9181`, and event ids `726` through `732` under `chaosx.fallout`.

## Opening contract

The Fallout candidate producer chooses the lowest current native Air Winter state owned and controlled by a current Quarantine government. The state must have a completed `fallout_event_719_memory_closed` memory, surviving population, durable Air Winter and Supply Access rows, bounded Disease Pressure and Exposure, enough Shelter Capacity and Adaptation, and at least one foreign neighboring state with current state identity data. The owner must be within the reviewed campaign-day window, carry current public-health and grievance ledgers, and afford at least one branch.

The opening freezes the target state owner, controller, generation, Shelter Capacity, Supply Access, Adaptation, Exposure, Disease Pressure, public health, grievance, border guard capacity, border trust, trade dependency, crossing backlog, and cause memory. It also freezes the lowest valid foreign neighboring state and its owner, controller, Shelter Capacity, Supply Access, and Disease Pressure. Both states receive reservation flags. Any delayed lane fails closed if either state, owner, controller, generation, or neighbor relationship changes.

## Branches and delayed results

The player can close the crossing, admit a joint inspection team, issue named relief exemptions, or deploy a military screen. Closing uses Food, Medicine, and Recognition. A joint team uses Scrap, Power, and Recognition. Relief exemptions use Fuel, Recognition, and a Cohesion commitment. A military screen uses Food, Medicine, Fuel, and Recognition. No branch uses political power as a generic store.

Each branch resolves after thirty days through a deterministic grade built from Air Winter Supply Access, Shelter Capacity, Adaptation, disease and exposure relief, Medicine, Recognition, border guard capacity, trade dependency relief, and the Quarantine government match. Success, partial, and failure thresholds differ by branch. Results update Air Winter, Supply Access, Medicine, Recognition, Cohesion, public health, grievance, border guard capacity, border trust, trade dependency, crossing backlog, and cause memory. Failure routes bounded population loss through the Deaths contract and damages infrastructure in the target state.

The result also writes a branch memory on the initiating country, a result flag on the foreign neighboring state, and a Fallout-owned opinion modifier on the neighboring government. A joint-team success creates a health compact memory. Closure, exemptions, and military inspection create distinct bilateral memories. Failure records an inspection-register breakdown.

## Seasonal review and cleanup

The result schedules a hidden or human callback after one hundred eighty days. The callback grades current public health, Cohesion, Recognition, border guard capacity, border trust, cause memory, grievance, trade dependency, crossing backlog, target Supply Access, target Reclamation, and target Disease Pressure. It updates the same ledgers, writes a callback Event Log payload, routes callback failure through bounded Deaths, and prepares authenticated cleanup. Cleanup releases both state reservations, clears delayed flags and receipt variables, preserves branch memories and Event Log history, and marks the target state with the completed Clean Certificate memory for future authored chains.

## Content and asset ownership

The chain has authored event text for the Rime Ward clinic and East Gate crossing. It uses the dedicated `GFX_report_event_fallout_border_inspection_crisis` sprite and the dedicated report DDS under `gfx/event_pictures/fallout/`. Event Log history `9181` routes through the Fallout-owned detail localizer and has branch-specific choice and outcome text.

The candidate remains dormant until scheduler activation review. It is not a super-event and does not register Fallout itself as an ordinary event.
