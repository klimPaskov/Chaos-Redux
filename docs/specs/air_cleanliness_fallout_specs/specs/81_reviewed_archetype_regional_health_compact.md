# Reviewed Archetype Spec: Regional Health Compact

## Identity

Regional Health Compact is a dormant Fallout survivor chain for the Quarantine government archetype. It follows a closed Health Without Borders memory and asks one North Gate Health Corridor state to make a durable compact with a foreign neighboring state whose clinics serve the Ash Ward. Fallout itself remains a terminal consequence and is not registered as an ordinary event, evolution, or ordinary super-event.

The chain uses candidate `754`, transaction `710079`, route `7190`, event ids `chaosx.fallout.754` through `chaosx.fallout.760`, and survivor Event Log history `9185`. It is authored under `add_namespace = chaosx.fallout` and remains outside release-floor credit while scheduler activation is unset.

## Eligibility and target proof

The candidate producer runs through the existing reviewed registry rebuild. It selects the lowest owned state id with current state identity, durable survival rows, current Air Winter values, current Supply Access, surviving population, and at least one foreign neighboring state. The state must carry `fallout_event_747_memory_closed`, and its owner must be a current Quarantine country with durable health-authority ledgers, medicine, Cohesion, Recognition, and one affordable branch.

Every opening, result, callback, and cleanup lane revalidates the ordinary receipt, transition generation, owner, controller, target state, and frozen foreign neighbor. The registry freezes both sides before any cost, result, opinion, or Deaths write. A changed state, owner, controller, neighbor, or generation fails closed and releases through the authenticated cleanup path.

The human opening and hidden AI opening use the same branch affordability and deterministic grading inputs. Hidden AI uses authored branch priorities. It never receives a branch that the country cannot pay.

## Delayed results and callback

The result is scheduled forty-two days after the opening choice. Grading combines frozen Supply Access, Shelter Capacity, Adaptation, Disease Pressure, Exposure, Medicine, Recognition, Corridor Security, Refugee Pressure, and the Quarantine government bonus. Each branch has distinct success, partial, and failure thresholds and writes a branch-specific state memory.

Result success and partial outcomes update Air Winter, Supply Access, regional health ledgers, bilateral opinion, Stability, War Support, and corridor memories. Failure uses the Fallout aftermath Deaths contract with a bounded request and may damage the target state's infrastructure. No branch deletes a tag, creates a tag, transfers ownership, or registers Fallout as an event.

The callback is scheduled three hundred days after the result. Its score reads current Compact Legitimacy, Cohesion, Recognition, Corridor Security, Partner Trust, Cause Memory, Refugee Pressure, Border Fatigue, target-state Supply Access, Reclamation, and Disease Pressure. Success, partial, and failure update the same ledgers and Air Winter values with separate callbacks. Callback failure uses the same Deaths-backed contract and never writes to a stale target.

## Memory and Event Log

Choice, result, and callback memories are written to the survivor country's Event Log through history `9185`. The dedicated detail resolver uses `GetFalloutEvent754EventLogDetail` and concrete North Gate, Ash Ward, clinic, register, relief-road, and quarantine wording. Event Log entries describe survivor consequences only. The Fallout consequence remains outside this surface.

The chain owns these country ledgers and flags:

- `fallout_regional_health_compact_corridor_security`
- `fallout_regional_health_compact_partner_trust_fund`
- `fallout_regional_health_compact_refugee_pressure`
- `fallout_regional_health_compact_border_fatigue`
- `fallout_regional_health_compact_cause_memory`
- `fallout_regional_health_compact_*_memory` and `*_contested` branch flags

It reuses only the authenticated Health Without Borders ledgers `fallout_health_authority_compact_legitimacy_current` and `fallout_health_authority_client_pressure_current` as upstream state. The cleanup effect releases target and neighbor reservation flags, delayed tickets, branch costs, and temporary registry state idempotently.
