# Air Cleanliness and Fallout World-End Source Spec, Part 5 Regional Successors and Cosmetic Country Matrix

Canonical status: accepted baseline design, corrected for independent Fallout ownership and extended by the living-world specs in this package.

Working labels in this file are not final localisation. They describe identity directions for cosmetic tags, releasables, civil-war tags, or existing country transformations.

## Regional design rule

Fallout should not spawn one global set of generic warlords. Every region should feel like its own collapsed world. The implementation can use existing tags, releasables, civil-war mechanics, cosmetic tags, and dynamic country names, but each surviving polity must receive local identity, government archetype, focus overlay, assets, and AI behaviour.

## Cosmetic tag implementation principle

The spec asks for many new countries without requiring many new base tags. The implementation should prefer:

1. Existing releasable tags where plausible.
2. Civil-war clones where a large country fragments.
3. Cosmetic tags and dynamic names for regional identities.
4. Event origin flags so the same tag can behave differently when it is a Fallout successor.
5. Shared archetype focus skeletons with mandatory regional overlays.

A country package is incomplete if it only has a name. Every playable survivor needs a leader or council, government archetype, state class identity, starting problem, starting forces, survival resources, at least one special branch, AI behaviour, and asset needs.
