# Reviewed archetype chain: The Machine Suggests

## Contract

The Machine Suggests is a dormant ordinary Fallout chain for the Manchurian Reactor Keeps Technate. It follows a closed Laboratory Citizenship district and asks whether an automated recommendation can enter the institutions that control clinic hours, rail repairs, and food convoys. The consequence is not a super-event, does not request Fallout, and does not register Fallout as a normal Event Log evolution.

The candidate producer selects the lowest eligible current-generation East Asian industrial or arms state owned and controlled by the Technate. The state must carry the closed Laboratory Citizenship memory, produced Air Winter values, surviving population, native infrastructure, Supply Access, a foreign neighboring state, bounded Disease pressure, and enough technical buildings to make a machine recommendation meaningful. The country must retain the Manchurian Reactor Keeps memory, Technate government, durable survival resources, machine influence, machine risk, Medicine, Power, Scrap, Cohesion, Recognition, and one affordable branch.

The candidate uses id `845`, transaction `710092`, route `7216`, event ids `845` through `851`, and Event Log history `9198`. The result resolves after `63` days. The protocol review callback resolves after `390` days. Branch modifiers last `300` days and callback modifiers last `450` days.

## Branches

| Branch | Cost | Identity | Delayed result |
| --- | --- | --- | --- |
| Follow the recommendation on the main grid | Power 2, Scrap 1, Recognition 2 | Places the machine recommendation on the main clinic and rail schedule. | Can raise efficiency while retaining a human stop authority, or send medicine toward a dead route. |
| Test the recommendation in a sealed district | Fuel 2, Scrap 2, Recognition 1 | Compares the machine plan with a human roster behind a controlled gate. | Can establish a safer protocol, or lose the comparison ledger when the test reserve fails. |
| Reject it for a human review | Cohesion 2, Medicine 1, Recognition 2 | Suspends the machine plan and gives clinic crews authority to rebuild its assumptions. | Can preserve civic oversight, or dissolve into incompatible ledgers and miss the repair window. |
| Grant the machine an advisory seat | Food 2, Power 2, Recognition 2 | Gives the machine a public advisory seat with a named human sponsor. | Can create accountable protocol, or leave every exception without a responsible voice. |

## State and country ledgers

The chain initializes and clamps machine influence, machine risk, human review trust, efficiency margin, exception capacity, machine civic confidence, and machine protocol memory. It freezes those ledgers with the target state owner, controller, generation, shelter, Supply Access, Adaptation, Exposure, Disease, and the lowest authenticated foreign neighbor before payment. Result grading combines the frozen state values, Medicine, Recognition, machine influence, machine-risk relief, human review trust, exception-capacity relief, machine civic confidence, and Technate identity. Branch thresholds remain distinct and deterministic.

Successful and partial results change Air Winter, Supply Access, Medicine, Cohesion, Recognition, and the machine ledgers. Failure damages native infrastructure and requests bounded Deaths against the authenticated state. The callback changes the same state values, writes the durable machine protocol memory, and can apply a second bounded Deaths request. Bilateral opinion records the selected policy or protocol failure against the frozen neighbor.

## AI and cleanup

The hidden AI event scores all four authored branches with the same affordability and grade paths as the human event. Delayed result, callback, cleanup, generation, owner, controller, neighbor, target, and transaction checks are revalidated before each step. Cleanup is idempotent. It releases the state and neighbor reservations, refunds an opening cost only when the chain never committed, clears transient ledgers and receipts, and records cancellation only when the authenticated row is stale.
