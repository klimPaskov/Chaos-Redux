# Reviewed global survival generation pilot

Working labels in this file are not final localisation.

The First Safe Birth is a country-level global-survival incident for the first
post-Fallout year. It is a generation-change memory event, not a harmless
celebration. Its player-facing design, branch obligations, delayed result,
callback, AI parity, memory, asset, and blocker boundary are defined in
`docs/plans/air_cleanliness_fallout_plans/FALLOUT_FIRST_SAFE_BIRTH_EVENT_ADDENDUM.md`.

The implementation owns candidate `282`, event identities `282` through `288`,
transaction key `710014`, route `7114`, and history `9119`. It must remain a
Fallout-owned dormant row until the accepted scheduler activation conditions
are satisfied. It uses no Zombie identity, path, sprite, audio, or asset.

The numerical fields are centralized in
`common/script_constants/fallout_consolidated_constants.txt`. The candidate
producer must bind its Medicine pressure, frozen Cohesion value, frozen Shelter
receipt, and civilian-Deaths severity to current receipts. The opening reserves visible
budget three. The visible human result and callback reserve one each. Hidden AI
rows reserve zero visible budget while keeping the same mechanical envelope.

The result, callback, and cleanup must all authenticate the current scheduler
generation, owner, candidate identity, country target type, branch, and exact
transaction receipt. A failed result or callback uses the Deaths contract with
the event's lower callback rate. No direct population subtraction, building
damage, generic event, or free manpower loop is acceptable.

The source spec index lists this pilot after the Names for the Missing contract.
