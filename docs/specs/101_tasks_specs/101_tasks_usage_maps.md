## Handoff discipline

Every future specialist receives the exact accepted files, current source revision, permitted paths, named scenarios and required output path. Use the provided role's actual model and effort when specified. Read the current definition and owning skills before delegating.

Use `chaosx_improvement_loop_planner` with `fork_turns="none"` after a substantial implementation stage when a concrete depth or connection question remains. The imported review reports its seven corrections promoted. Do not reopen that unchanged pass or request another solely for a closure receipt. Give a justified new pass the complete accepted inputs and actual source, then record each proposal as implemented, promoted with acceptance basis, accepted and queued with reason, rejected, superseded, unresolved or blocked as applicable. Unaccepted proposals and separately queued work do not silently enlarge the current task.

The debug-playtest skill is invocation-only. Agents do not launch the game as an automatic final step or request or await user-owned live-game validation. Review supplied live evidence when available, keeping it distinct from source and local checks.
