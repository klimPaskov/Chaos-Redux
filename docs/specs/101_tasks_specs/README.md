## Principal decisions

Event 101 remains Minor Repeatable, Chaos level 1, with no cluster. The shared random-event system owns scheduling and recovery. One firing selects one eligible human country uniformly, then selects family, archetype and target with the specified contextual weights. Each country can have one active task, including one shared task for a co-op country.

The public experience is one ordinary category, one automatically completed mission, one progress or status measure and the native countdown. There are no Event 101 gameplay buttons, entry fees, extensions or rerolls.

The content inventory contains nineteen ordinary archetypes across five families, six named crisis integrations forming the sixth family, and an explicit admission contract for further real owners. Targets, work, time and outcomes are fixed when assigned. The generator must prove practical authority, capacity, access and measurement before a candidate receives weight.

The supplied evolutions remain I Higher Stakes at 200+, II Trials Under Pressure at 400+ and IV Chaos Tasks at 600+. No III is invented. Evolutions affect future assignments, while an active task keeps its original terms.

Ordinary industrial tasks reward new usable capacity and explicitly allow lawful post-assignment grants. The separate construction achievement requires recipient-funded commissioning evidence. Strict defense requires actual loss history. A convenient daily snapshot, stockpile change or global owner flag cannot silently substitute for the promised work.

Success has a strong related temporary benefit. Failure has a bounded temporary consequence and, where appropriate, a clamped confidence loss. Partial useful work reduces the penalty. Exact receipt and expiry rules prevent replay, duration accumulation and uncontrolled simultaneous capabilities. All direct Event 101 Chaos changes are zero.
