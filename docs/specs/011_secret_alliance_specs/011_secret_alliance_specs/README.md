# Secret Alliance planning package

Event 11, Secret Alliance, is specified here as a reworked Chaos Redux event package. The intended source location after extraction is `docs/specs/011_secret_alliance_specs/`.

This package contains a source design spec, decision and AI matrices, asset and super-event research prompts, achievement planning, and implementation prompts. It is design-only. It does not edit gameplay scripts, localisation, GFX, GUI, audio, or the event catalog workbook.

## Design stance

The event should feel like an intelligence and diplomacy crisis that slowly becomes military reality. The player must notice patterns, harden the country, build evidence, decide how much to expose, and prepare for the moment when the hidden pact becomes public. The reveal super-event belongs to the moment when private conspiracy becomes an open faction against the player.
