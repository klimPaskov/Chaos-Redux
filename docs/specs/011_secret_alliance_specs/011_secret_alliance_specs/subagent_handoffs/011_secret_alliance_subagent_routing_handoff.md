# Subagent routing handoff for 011 Secret Alliance

This package could not directly spawn project subagents in the current chat runtime. The implementation agent should use the following routing in the Chaos Redux repository environment.

## Early implementation

Use `chaosx_repo_explorer` only if file locations, existing patterns, or dependencies are unclear. The event is multi-surface, so a bounded exploration pass is reasonable if implementation begins without a current repo map.

Use `chaosx_scripted_system_architect` before duplicating logic for:

- member selection scoring
- hidden ring storage
- evidence and preparedness calculations
- reveal and cleanup helpers
- faction formation helper
- dynamic pact name handling
- event target lifecycle

## Decisions and missions

Use `chaosx_decision_mission_auditor` after the first full decision implementation. It should audit costs, active missions, target validity, player tooltip clarity, AI behavior, and cleanup.

## Localisation

Use `chaosx_localisation_auditor` after event text, decisions, tooltips, super-event localisation, and scripted localisation exist. The auditor should verify hidden mechanics are not spoiled too early and that final text follows project style.

## Assets

Use `chaosx_icon_artist` for decision icons, idea icons, national spirit icons, achievement icons, and small animated dossier or warning assets.

Use `chaosx_generated_event_art` for the fictional or symbolic super-event image if generated art is chosen.

Use `chaosx_asset_source_researcher` only if the implementation wants a real archival super-event image or a sourced historical analogue image.

## Super-event

Use `chaosx_super_event_text_researcher` for final quote, title direction confirmation, and cultural remark research.

Use `chaosx_super_event_audio_researcher` for final unique music research, license verification, download, conversion, and audio documentation.

## Completion

Use `chaosx_improvement_loop_planner` near completion. Resolve the planner result before completion.

Use `chaosx_event_completion_auditor` before final completion claim.

Use `chaosx_spreadsheet_doc_worker` only after final in-game wording exists and the event catalog workbook must be updated.
