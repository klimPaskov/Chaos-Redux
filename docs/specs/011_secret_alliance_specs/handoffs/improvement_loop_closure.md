# Improvement-loop closure handoff

## Review question

Does Event 011 still need a broader route, country, focus, formable, UI, asset, or super-event expansion before its source specification can close?

## Playable promise reviewed

The event promises a hidden coalition that begins through subtle interference, expands through recruitment, gains major sponsorship at higher evolution, becomes actively counterable, and converts into a public faction and war when secrecy breaks.

## Depth findings

The current package already includes:

- motive-based founder and recruit selection
- hidden doctrine and internal disagreement
- baseline stages distinct from evolutions
- active-event and pre-fire evolution entry paths
- six operation families
- Evidence, Preparedness, Cohesion, Readiness, Alertness, Resolve, and War Pressure roles
- investigation, protection, diplomacy, deception, border action, public exposure, emergency, and revealed-war decisions
- full, partial, and failure mission outcomes
- false-accusation consequences
- one or two major sponsor logic
- a hard hostile-war reveal contract
- value conversion into the war opening
- coalition Resolve, fracture, separate terms, and postwar outcomes
- route-aware AI and procedural geography
- one compact scripted GUI
- one justified animation family
- a reveal super-event package
- six difficult achievements
- a direct scenario with type and intensity controls
- complete asset and localisation handoffs

## Expansion ideas rejected as bloat

### Dedicated focus trees

The pact can include arbitrary existing countries. Event-owned focus trees would overwrite country identity, multiply compatibility work, and create shallow shared content. Existing countries should use event AI, decisions, modifiers, and faction behavior.

### New pact country or secret-society tag

A new tag would turn a diplomatic network into a map actor and weaken the core idea. The actual reveal should be a faction of existing states.

### Formable nation

The coalition is an alliance, not a state-building fantasy. A formable would distract from motive conflict and procedural membership.

### World-end branch

The event creates a dangerous war but not a terminal campaign state. A world-end layer would overlap other catalog events and inflate the scale.

### Multiple scripted GUI windows

The player needs Evidence, Preparedness, suspects, and mission status. One compact category-attached panel is sufficient. A full intelligence-board window would add maintenance without changing play.

### More animation

The Evolution III closure loop communicates the key state change. Animated meters, suspect cards, buttons, and faction emblems would reduce readability.

### More achievements

The six-achievement set already covers prevention, full investigation, turned source, wartime fracture, Maximum scenario survival, and two-major victory. Additional achievements would repeat existing routes.

## Closure recommendation

Broad design expansion should stop. The source specification is deep, connected, replayable, and bounded. Further planning before implementation would add repeated mechanics rather than improve the event.

## Final tasks before implementation completion

- confirm repo identifiers and existing helper precedents
- perform final audio research and licensing
- create all visual assets and animation frames
- implement and tune the system
- run specialist audits against actual files
- write final localisation
- align docs and workbook
- rerun the improvement loop only after a meaningful implementation tranche if a new gap appears

## Disposition

Closure handoff. No unresolved expansion addendum remains in this planning package.
