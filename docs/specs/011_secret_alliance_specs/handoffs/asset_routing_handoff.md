# Asset routing handoff

## Source-mode decision

Event 011 is procedural. Its participants can be any valid countries. A real archival coalition photograph would falsely lock the event to one historical alliance. Generated alternate-history documentary art is therefore the correct source mode for event scenes, news art, super-event art, and UI decoration.

No real leader portraits, historical flags, or historically attested faction symbols are required.

## Routing

### Generated event art role

Owns:

- seven report-event source scenes
- one public-coalition news scene
- one reveal super-event scene
- counter-network panel illustration and non-icon UI art

### Icon artist role

Owns:

- two decision category icons
- decision icons
- idea icons
- status icons
- faction emblem
- achievement icon triplets
- the eight-frame coalition-closure warning and static fallback

### Source researcher role

Not required for the accepted visual list. Use only if implementation later introduces a real person, real document, real flag, or specific photographed historical meeting.

## Animation decision

A major mechanic needs an animation planning pass. One state-driven loop is justified at Evolution III because it communicates a transition the player must notice. Additional animation would distract from suspect and evidence reading.

The selected animation shows a network closing around a broken seal. It requires eight genuine source frames. Transform-only motion is forbidden.

## Blocking conditions

- image generation workflow unavailable
- matching reference folders unavailable
- final GUI dimensions unresolved for UI assets
- animation cannot be produced from real source frames
- achievement IDs not final before filename generation
- super-event image not reviewed in the actual UI frame

A blocked asset remains blocked. Do not substitute a loose placeholder, resized unrelated icon, or default super-event image.
