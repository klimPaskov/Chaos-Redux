# Event 011 Secret Alliance Localisation Handoff

This is direction-only. Do not paste these notes as final localisation.

## Tone rules

Early text should feel like a pattern of small public facts rather than an intelligence report that knows too much. Avoid naming the pact before reveal. Avoid direct lines that call the incidents a warning or a danger signal.

Evolution II text can name suspicion, evidence, and suspects when the player has earned that view. It should still hide unconfirmed members.

Evolution III text can name the public Anti-[target country] Pact once reveal has happened or the pact has entered public crisis.

## Text surfaces

| Surface | Direction |
| --- | --- |
| event name | final title should be concise and fit the idea of hidden alignment |
| event detail before reveal | public unease, repeated diplomatic habits, odd meetings, trade problems, and foreign language shifts |
| event detail after reveal | private coordination has become a public anti-target alignment |
| Evolution I detail | more minor countries appear to move in common rhythm without a formal admission |
| Evolution II detail | active sabotage and countermeasures become visible, with possible major patron |
| Evolution III detail | public pact crisis, visible alignment, war option, and high war pressure |
| decision category name | dossier and counter-conspiracy direction, not generic security office wording |
| investigation decisions | active national work: couriers, payments, liaisons, registries, radio traffic |
| protection decisions | concrete defense: rail guards, factories, public figures, depots, allies |
| diplomacy decisions | backchannels, arbitration, exposed promises, weak links |
| border missions | named border states, rail corridors, customs routes, and supplied divisions |
| super-event title | research required, short and specific |
| super-event quote | research required |
| button remarks | route-aware irony or severity, researched if source-dependent |
| achievement titles | final in-world titles written during implementation, working labels are not final |

## Hidden information rules

- Do not reveal hidden member names before evidence supports them.
- Do not expose future evolution content in early tooltips.
- Do not describe exact hidden variables in event prose.
- Dynamic values can be visible in tooltips and GUI once the category opens.
- Use custom tooltips for complex requirements and avoid raw trigger exposure.
