# Event 011 Secret Alliance Subagent Routing Handoff

This handoff is for the implementation parent. It uses the uploaded subagent instruction files as routing guidance.

## Before implementation

Use `chaosx_repo_explorer` because the event touches event registration, event logs, decisions, scripted helpers, super-events, assets, localisation, AI, and possibly GUI. The explorer should map existing Chaos Redux event, decision, super-event, and GUI patterns before editing.

Use `chaosx_scripted_system_architect` before writing repeated member logic. The architect should design or patch helpers for member arrays, founder roles, member exits, reveal, faction formation, values, dynamic eligibility, cleanup, and event targets.

## During implementation

Use `chaosx_decision_mission_auditor` after the decision category and missions exist. It should inspect costs, objectives, target validity, AI, cooldowns, and exploit risk.

Use `chaosx_localisation_auditor` after player-facing text and scripted localisation exist. It should inspect hidden information leaks, missing keys, dynamic values, and event-detail wording.

Use `chaosx_generated_event_art` for the fictional reveal super-event image, report images, UI panel art, and faction emblem.

Use `chaosx_icon_artist` for decision icons, idea icons, achievement icons, decision category icons, and small animated UI icons if the parent routes animation through icon work.

Use `chaosx_super_event_text_researcher` for final title direction conversion, quote candidates, exact wording, button remark, and cultural reference research.

Use `chaosx_super_event_audio_researcher` for final licensed audio selection and conversion.

## Before completion

Use `chaosx_event_completion_auditor` before claiming the event is complete.

Use `chaosx_spreadsheet_doc_worker` only after implementation text exists. It should update the event catalog workbook from final in-game wording, not from this planning text.

Use `chaosx_documentation_curator` if implementation creates multiple addenda, handoffs, or stale docs.

## Notes

A live subagent runner was not available in the planning environment that created this package. This file is a routing handoff for the implementation environment.
