# Super-Event Prompt for Event 011 Secret Alliance

Use `chaos-redux-super-events`, `chaosx_super_event_text_researcher`, `chaosx_super_event_audio_researcher`, and the relevant asset worker.

Event ID: 011
Event slug: secret_alliance
Super-event role: reveal and faction formation
Trigger moment: the formal Anti-[target country] Pact becomes public through war reveal, or through a public self-reveal that reaches the same diplomatic threshold.

## Text research gates

Do not treat any working label in the spec as final localisation.

Research required:

- final title
- final button remark
- main quote
- cultural remark or allusion if used

Quote direction:

- secret diplomacy
- open covenants
- hidden protocols
- private promises becoming public obligations
- alliance duty turning into war

Candidate source direction:

- Woodrow Wilson's Fourteen Points with exact source verification
- public domain diplomatic speeches or memoirs
- treaty commentary
- older political writing about secret treaties

Button remark direction:

- bitter diplomatic irony
- short allusion about private promises coming due
- no cheap comedy if the reveal immediately starts a large war

## Description direction

The description should state that several states have converted private coordination into a public anti-target alignment. Use `[target]` dynamically. If reveal came from war, explain that the first war contact activated the hidden protocol. Keep the tone tense, formal, and specific. Avoid generic apocalypse language.

## Image direction

Use a generated super-event image unless the asset lead finds a better sourced archival analogue. The scene should show hidden diplomacy becoming visible: shadowed delegates, sealed protocol, guard-lit corridor, radio cables, and the sense that a prepared mechanism has been activated. No readable text, no real leader likenesses, and no map-only composition.

## Audio direction

Find final public domain or clearly licensed music. Mood should be restrained, formal, tense, and war-adjacent. Avoid drones, generated tones, sound effects, and placeholder tracks. Preserve source, convert to 44.1 kHz `.ogg`, and document license, source, duration, editing, final path, and sound id.
