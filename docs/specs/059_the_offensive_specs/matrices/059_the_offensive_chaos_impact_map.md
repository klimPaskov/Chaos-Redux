# Event 059 Chaos impact map

## Design rule

The event is an active source of Chaos at its first material manifestation. Later ordinary military consequences use the shared Chaos systems. Evolution state itself never changes Chaos.

## Initial gain calculation intent

The final implementation should use one simple bounded calculation.

- start near the bottom of the band when few ordinary AI countries remain
- rise with the number of affected AI countries
- give additional weight to affected AI major powers
- cap at 25
- apply once even when Event 059 enters through a cluster
- apply no extra amount for human countries, disabled evolutions, or pre-fire stage count

The exact constants belong in the event's tuning surface and must be verified against comparable minor global events.

## Why later event-owned premiums are omitted

Event 059 influences decisions, but later wars and losses remain ordinary game outcomes measured by shared systems. Attribution would be uncertain because the same AI country also follows focus routes, claims, factions, threat, strength, and owner-specific plans. Adding a premium to every war while the event is active would duplicate generic sources and create an uncontrolled permanent Chaos engine.

## Anti-farming and persistence

The direct gain is one-time and Fire-Once. It cannot be farmed by:

- player takeover and AI handback
- save and reload
- country release or restoration
- evolution activation
- cluster participation
- repeated AI strategy reevaluation
- later war declarations

Legacy save migration must set the one-time guard before any compatibility effect can run.
