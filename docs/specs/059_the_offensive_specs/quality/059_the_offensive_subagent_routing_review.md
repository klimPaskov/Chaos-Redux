## Manual scripted-system architecture review

### State ownership

- one global Event 059 active state
- one recorded state per evolution
- no player-facing aggression value
- country-local state only when the engine requires registration or migration
- event-owned constants for aggression and safety tuning

### Preferred call flow

1. Event activation sets the global state once.
2. Native AI strategy plans evaluate the global state and current AI control.
3. Evolution activation enables its independent plan layer.
4. New-country coverage is automatic through generic plans or bounded through existing creation hooks.
5. Player takeover makes the plan inactive without cleanup work.
6. AI handback reevaluates current conditions.

### Reuse decision

The offensive policy should remain Event 059 owned. A helper should move into a shared system only when repository inspection finds a neutral repeated need already used by several event families. Event-specific strategy, safety, and evolution logic should not be placed in generic dynamic-effect documentation merely because it is complex.

### Performance decision

A whole-world recurring scan is rejected. Native AI evaluation, one-time activation, and bounded country lifecycle hooks are the accepted routes.

## Manual AI probability review

The design avoids unsupported exact probabilities. It defines:

- complete named scenario inputs
- expected relative ranking
- hard veto cases
- dominance and starvation limits
- threshold sweeps
- baseline and evolution comparisons
- uncertainty labels

No event-specific cluster participation value is fixed by this package. The probability auditor must inspect the authoritative Diplomacy role and chance metadata, then test any weighted value against the complete cluster pool and the event's permanent global impact.

## Manual localisation review

The text direction passes the project tone rules because it:

- uses concrete military activity
- avoids invented quotations and cultural references
- avoids generic dramatic fragments
- explains human exemption without exposing implementation
- avoids claims of direct combat bonuses
- separates current-war pressure from opportunity-war behavior
- gives implementation a full key and surface inventory without final pasteable copy
