# Wrestling Tournament specification package

## Decisions carried through the package

The user's 10 October 2026 identity decision confirms Wrestling Tournament as Event 108. The immutable brief separately supplies original catalog ID 113, Minor Repeatable, desired status To Be Reworked, Chaos 1 and no assigned cluster. The current workbook state is separate: its Event 108 row is Fury / Unavailable with type, chaos and cluster blank, while original row 113 is also Unavailable. This package records the intended mapping, not a workbook edit or a current catalog match. The parent owns the canonical workbook and shared-registry reconciliation.

The six phases are ordinary tournament progression.
The four evolutions remain separate, independently eligible changes to the competition.
Cheating, banned tonics, risky medicine, injuries, sponsors and eligibility disputes already exist in the baseline.

Every entrant retains all six attributes.
Readiness and Strain are the two numerical management meters.
Profiles explain the six attributes in comparative language, while seeds, records, dates and result facts remain readable.
Neither money nor a high seed guarantees victory.

The initial portrait target is at least 80 distinct usable identities, with production capacity increased to cover the actual supported candidate demand.
The register distinguishes researched historical sources from unreviewed leads and future production.
The package contains no claim that 80 finished portraits have been produced.

## How to interpret the specification

The immutable brief is the user-intended design baseline. The current import instruction expressly preserves the six phases, four independent evolutions, country careers and returns, all six attributes and two management meters, preparation and scandal actions, seeded knockout design, achievement suite, and full portrait scope. Its basis is that current instruction together with the brief.

The archived review receipts report that an earlier planning-session parent accepted additional detailed rules. That historical claim is preserved in the [imported completion review](../../plans/108_wrestling_tournament_plans/imported_review/Review%20-%20Completion.md), but this import task does not newly accept every archive instruction. Detailed thresholds, formulas, owner adapters, edge cases, exact implementation contracts, visual specifications and expanded acceptance fixtures remain imported proposals unless they are stated by the brief or have a current parent disposition. See the current [import handoff](../../plans/108_wrestling_tournament_plans/subagent_handoffs/108_import_review_2026-10-10.md) for per-document dispositions.

Numbers identified as anchors are planning targets, not measured live-game balance.

Working labels identify mechanics and assets for the implementer.
They are not final event descriptions, option strings, decision titles, achievement titles or GUI localisation.
The writing assignment must create those after the mechanics and actual consumers are wired.

The package is a planning deliverable. Its historical mathematics and source review do not establish native GUI behavior, installed-engine syntax, portrait clearance, multiplayer synchronization or save persistence. The implementation maps describe useful evidence routes, subject to current source review and available tools. The archived review records document their authors' earlier planning dispositions only; they do not establish current implementation, current tool availability or blanket user acceptance.
