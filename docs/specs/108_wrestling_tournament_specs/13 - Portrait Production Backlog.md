## Scale beyond this initial backlog

The 80-item list is a production floor.
Before enabling the full worldwide feature, enumerate every actual supported delegation and its reserved candidate pool for each supported start-year range.
Add work items until every such country has the promised meaningful choice and every live field identity has its own portrait.
One selected wrestler per country does not reduce the portrait needs of the candidates that country was offered.
Extra extraordinary alternatives increase that country's asset demand without adding another delegation slot.
Retained archive versions and later career identities add storage and sourcing requirements as defined in Part 10.

For example, 32 countries each offered three distinct people need 96 active identities before any extra alternatives or retained historic versions.
This backlog is therefore not evidence that a 32-country release is fully covered.
The live feature's source and asset readiness gate must report the actual missing work and must not quietly exclude a country to make the arithmetic fit 80.
