## Source-of-truth rules

The seven files under `specs/` are the event design source. The CSV matrices are authoritative registries for broad coverage and should be read alongside the relevant spec part. The prompt files translate the source design into bounded implementation, asset, research, audit, and catalog tasks.

The research-complete package resolves all 206 candidates into 102 custom Event 6 countries, 91 registered vanilla-tag reuses, and 13 non-selectable vanilla route overlays. Every custom Event 6 tag is collision-free in the 2026-07-15 installed-registry audit and ends in `X`. The dated 2026-07-14 map audit originally recorded 149 bound and 57 unbound rows across all packages. Once the 13 overlay rows are excluded from country selection, the current selectable pool contains 138 bound and 55 unbound packages. The thirteen registered-tag compatibility adapters and thirteen additive overlay hooks remain implementation obligations. Identifier resolution does not prove that those adapters or overlays are implemented. The exact `6001` London Brass Players recording is blocked for United States redistribution until permission or a waiver is obtained. Final localisation outside the approved super-event text, asset production, audio conversion, focus coordinates, gameplay implementation, and gameplay validation remain.
