# Sensitive and broad identity package resolution

Research completed: 2026-07-10

This file converts every broad, dispersed, indigenous, communal, partition-sensitive, genocide-connected, or cross-border package from an open research gate into an explicit design disposition. A package can be resolved by restricting it. It does not have to become an automatic country.

The rules are binding:

- `specific_community_variant_only` means the broad label is not an automatic state. The event selects or creates a named community, district, nation, confederacy, or institutional package first.
- `formable_or_route_only` means the identity is a negotiated political project. It cannot take opening territory from several hosts.
- `automatic_pool_ready_if_unique_state_exists` means the package can enter the automatic pool only when the installed map has a distinct anchor and host survival passes.
- `high_chaos_only` means the package has a sufficient modern political bridge but remains outside early normal waves.

## Universal representation rules

Every named community package must record the public name chosen by the relevant source, the period institution that claims authority, internal representation, land and border limits, leader provenance, symbol provenance, and any member veto or autonomy rule. A broad cultural name does not authorize a maximal state.

A package that cannot obtain a unique current-map anchor is disabled from automatic waves. It remains valid as a formable, later secession, focus route, or triggerable scenario variant. The planner fills the wave slot from another ready package.
