## Honest boundary

The package does not claim that a public third-party state index is more authoritative than the installed game files. Numeric state IDs are a dated binding aid. When the installed build differs, the implementation agent binds the same named geographic anchor to the current state file and records the difference. The political, identity, tag-family, source, and reservation decisions remain in force.
