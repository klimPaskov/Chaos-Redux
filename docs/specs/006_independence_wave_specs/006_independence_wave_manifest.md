# 006 Independence Wave Planning Package Manifest

This is the complete source specification package for Chaos Redux Event 6, Independence Wave. It is organized under `docs/specs/006_independence_wave_specs/` and uses sequential spec parts because the event is too large for one readable Markdown file.

## Folder layout

| Folder | Contents |
| --- | --- |
| `specs/` | Five sequential specification parts covering the complete event design. |
| `prompts/` | Asset, super-event, achievement, decision and mission, implementation, coding, and goal prompts kept outside the spec files. |
| `research/` | Consolidated research notes and source-direction notes for historical, regional, symbolic, audio, visual, and super-event work. |
| `matrices/` | Country package matrix for package tiers, regions, tag handling, origin handling, forces, assets, AI, and formable hooks. |
| `acceptance/` | Package-level acceptance criteria summary. |

## Spec files

| File | Role |
| --- | --- |
| `specs/006_independence_wave_spec_part_1_core.md` | Core event model, release ladder, host safety, origin separation, release packages, evolutions, and scenario skeleton. |
| `specs/006_independence_wave_spec_part_2_mechanics.md` | Living mechanic model for released countries, former hosts, sponsors, leagues, aggressive blocs, value ranges, thresholds, AI, cleanup, and exploit prevention. |
| `specs/006_independence_wave_spec_part_3_decisions_missions_gui.md` | Decision categories, mission families, target selection, costs, outcomes, cooldowns, scripted GUI surfaces, AI behavior, cleanup, and scenario variants. |
| `specs/006_independence_wave_spec_part_4_focus_trees_country_packages.md` | Shared focus overlay, regional inserts, ambition inserts, idea lifecycles, country package tiers, politics, leaders, advisors, forces, economy, AI, and assets. |
| `specs/006_independence_wave_spec_part_5_formables_super_events_assets_achievements.md` | Formable web, hidden formables, league and compact endgames, super-events, assets, achievements, documentation, and acceptance architecture. |
