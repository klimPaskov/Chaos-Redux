# 006 Independence Wave Acceptance Criteria

This file summarizes the implementation acceptance criteria for the complete Event 6 planning package. Detailed acceptance criteria remain inside the relevant spec parts.

## Core release behavior

- Event 6 remains a Minor Repeatable event in the Liberations cluster.
- Automatic wave size follows the 3, 4, 5, 7, and 10 ladder.
- Countries release instantly.
- A former host is never fully deleted by Independence Wave. The host should keep the capital state when possible.
- Event 6 origin remains separate from Soviet Collapse and from other release systems, even when the same tag can appear through more than one event.
- New Event 6 custom tags, formable tags, cosmetic tags, and route split tags use the X-ending rule.

## Playable content depth

- Released countries receive Event 6 mechanics, decisions, missions, focus overlay access, starting politics, starting forces, reinforcement routes, AI behavior, and cleanup rules.
- Ordinary small releases use the shared overlay, regional inserts, and package-tier rules instead of empty generic content.
- Selected strong releases receive ambition inserts, stronger assets, formable access, and route-specific AI without requiring bespoke full trees for every possible country.
- Former hosts, sponsors, leagues, and aggressive blocs receive usable decision and mission surfaces with visible values, costs, outcomes, AI behavior, and cleanup.

## Mechanics and UI

- Legitimacy, recognition, foreign support, patron influence, coalition trust, border heat, post-release instability, local control, league cohesion, aggressive bloc pressure, former host anger, and sponsor rivalry are visible and interactive.
- Decision and mission costs use meaningful resources, risks, deadlines, map objectives, support values, or unit commitments instead of defaulting to political power or command power.
- Scripted GUI surfaces display the current state, explain thresholds, and do not bypass decision costs or AI equivalents.
- Categories hide obsolete actions and prevent clutter through phases, active caps, regional pools, route locks, cooldowns, and cleanup.

## Endgames, assets, and documentation

- Formables use Event 6 origin-aware requirements, state control, integration work, reveal gates, host safeguards, and post-proclamation play.
- League and coercive compact endgames have clear thresholds, faction behavior, super-event gates, AI logic, and failure risks.
- Super-events are reserved for globally important thresholds and use quote, cultural remark, image, and audio research gates.
- Historical flags, real symbols, and real leader portraits require sourced asset work. Fictional, symbolic, alternate-history, and high-chaos assets may be generated.
- Achievements have real unlock conditions, disqualifiers, route hooks, tracking notes, and icon directions.
- Final implementation must update event docs, event log/detail surfaces, spreadsheet-facing wording, asset manifests, prompt files, and validation reports.
