# 006 Independence Wave, Super Event Prompt

Research and prepare super-event packages for Event 6, Independence Wave. Use the canonical super-events and assets file as the source. Ordinary waves do not get super-events. Research only the thresholds selected for implementation, such as Independence League Charter, Congress of Small Nations, Coercive Compact Forms, Great Partition Week, Host Retaliation Coalition, and Hidden Formation Proclamation.

For each selected super-event, produce:

- Role and trigger summary.
- Quote candidates with exact wording, attribution, source, date or period, copyright status, and fit explanation.
- Button or cultural remark direction with copyright risk notes.
- Audio candidate with source URL, license terms, duration, editing notes, final `.ogg` path, and confidence.
- Image source mode and package note, generated for fictional composite scenes or sourced for real historical material.
- Suggested title direction, description direction, quote direction, and button direction, without final localisation text.
- Wiring notes for sound id, image sprite, settings-aware playback, docs, and event log alignment.

Reject unsourced quote-site text, unclear audio licenses, modern copyrighted excerpts that are too long, generic dramatic music, and map-first super-event art.
