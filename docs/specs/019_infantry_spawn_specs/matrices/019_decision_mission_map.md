## Selected-target and clutter control

- Only one formation lot is selected in the Muster Board at a time.
- Lot-specific decisions activate for the selected lot.
- AI evaluates all valid lots without using the human selection flow.
- Claimant decisions appear only for active claimants and current demands.
- Registry actions appear only for locally available families.
- Only one controlled formation trial may be active, and scenario setup rejects its attacker, its temporary opponent, and any quarantined cleanup country.
- Obsolete decisions close after generation closeout, revolt, annexation, or country transformation.
- A country normally has a bounded number of active audit, standardization, claimant, and containment missions.
