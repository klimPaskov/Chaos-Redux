# Infantry Spawn country package matrix

This file defines country packages that can emerge from Evolution III and Evolution IV. Public names below are working directions, not final localisation.

## Tag pool rule

Implementation should use an event-owned pool of temporary tags for human and chaos splinters. Final tag ids must be conflict-checked in the repository. A spawned country must set an origin flag so focus-tree loading and event behavior affect only countries created by Infantry Spawn.

## Public name rules

Names should be short map names. Do not use internal office names, bureaus, boards, or authority labels as country names. Military, host, horde, state, republic, legion, or regional names can be used when they read as a public actor rather than an internal department.
