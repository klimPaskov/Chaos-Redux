# Event 19 Evolution Entry and Cleanup Matrix

## Evolution entry paths

| Evolution | Active-event entry | Pre-fire evolved opening | Logged evolution | Main cleanup risk |
| --- | --- | --- | --- | --- |
| I Organized Muster | unresolved lots gain staff, district, and reorganization actions | next generation uses stronger coherent families | one global stage 1 record | old audit missions and equipment debt must migrate |
| II Arsenal Lottery | current lots can expand, preserve prototypes, and use requests | generation can create multiple serious or strange units per state | one global stage 2 record | request counters, advanced-equipment restrictions, and lot upgrades |
| III Command Fracture | automatic spawning pauses after active lots, claimants use existing districts | country receives Muster Board and first bounded draw or claimant offer | one global stage 3 record | baseline decision replacement and claimant target lifecycle |
| IV Anomalous Muster | registry and saturation attach to active crisis | first anomalous family incident follows local eligibility | one global stage 4 record | parent isolation, family targets, derivative release safety |

## Generation closeout

| Data | Closeout behavior |
| --- | --- |
| Generation active flag | clear when no unresolved lot, claimant obligation, or family obligation remains |
| Lot list | remove resolved entries and compact active list |
| Event-owned templates | retain only when integrated divisions still use them, otherwise clean safely |
| Equipment debt | settle, convert to persistent bounded debt, or clear after payment |
| Request count | archive into generation history and reset |
| Request cooldown | retain until expiry |
| Audit lock | remove from integrated ordinary formations |
| Selected lot target | clear when lot resolves or UI closes on invalid target |
| Temporary mission flags | clear on success, failure, annexation, or route transition |
| Stacked muster | remove only after overlapping generations are resolved |

## Claimant cleanup

| Outcome | Required cleanup |
| --- | --- |
| Peaceful retirement | remove active claimant role, detach or integrate loyal lots, preserve historical record |
| Arrest success | clear command target, remove or imprison character, reassign lots |
| Arrest failure | hand off to revolt setup without duplicating units |
| Takeover | migrate claimant to country leader, close civil-war-only actions, preserve Event 19 origin history |
| Revolt | transfer only loyal lots, set former parent and derivative targets, clear parent-side assignment |
| Claimant death | resolve succession or rival claimant, never leave portrait or target stale |
| Country annexed | clear claimant targets and missions unless claimant becomes a valid exile through explicit content |

## Anomalous family cleanup

| State change | Required behavior |
| --- | --- |
| Family unit count reaches zero | decay family pressure and hide empty actions after cooldown |
| Cantonment state lost | remove capacity and recalculate saturation |
| Parent country annexed | transfer, destroy, or contain units through verified rule |
| Derivative revolt | move family presence and loyal units once, no duplicate parent counts |
| Derivative defeated | stop family territorial effects, close decisions, clean origin targets |
| Registry entry removed or changed | run migration rule, do not leave invalid templates |
| Evolution disabled | prevent new family content, preserve or safely resolve existing units through defined alternate path |

## Scenario cleanup

| Data | Cleanup |
| --- | --- |
| Scenario launch flag | clear immediately after setup branches finish |
| Selected type and intensity | preserve only in scenario history, not as permanent bypass |
| Forced evolution state | scope to setup, do not mark natural parent event progression unless explicitly designed |
| Temporary target lists | clear after revolt countries and wars are created |
| Failed local setup | record and use safe takeover or skip, never leave half-created country |

## Country transformation safety

Before tag change, civil war, or release:

1. snapshot relevant Event 19 generation and loyalty state
2. determine which country owns each lot after transition
3. close invalid missions and UI targets
4. transfer only intended units
5. set origin and family flags
6. rebuild the active lot and claimant list for both sides
7. recalculate control, congestion, and saturation
8. verify parent-event isolation
9. clear temporary targets
