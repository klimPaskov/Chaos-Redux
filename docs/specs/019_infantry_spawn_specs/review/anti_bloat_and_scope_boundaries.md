# Anti-Bloat and Scope Boundaries

## Included because they change play

- diminishing territorial coverage
- weighted state identity
- formation lots and generation memory
- equipment, manpower, supply, and command burden
- four evolution stages
- on-demand random formation requests
- fully random safe composition
- claimant generals and revolt
- Chaos family registry
- derivative country packages
- selected-lot scripted GUI
- AI for ordinary and derivative countries
- triggerable immediate-mutiny scenario
- achievements and full asset planning

## Excluded because they dilute the event

### Ordinary-country bespoke focus trees

The event affects every country. A bespoke or additive focus branch for each one would overwhelm maintenance and create unequal coverage. Shared decisions and GUI are the correct ordinary-country surface.

### Direct parent-event mechanics

The Event 19 package does not copy zombie mutations, Death soul systems, parent golem endgames, or parent super-events. It uses bounded unit-family behavior and weaker derivative profiles.

### Direct world end

No branch sets the terminal world-end flag.

### Automatic global threat

Derivative countries become a shared world-threat source only through a future explicit threshold if they genuinely become global.

### Universal mixed anomalous divisions

Anomalous families default to separate family lots. Mixed anomalous templates require explicit registry compatibility.

### One decision per division

Management is by lot, district, claimant, or family.

### Twenty animated claimant portraits

Static portraits provide diversity. State animation belongs in the UI.

### Dedicated super-event package

The planned thresholds do not justify it.

### Event cluster creation

No current multi-member cluster is ready.

### Historical character copies

Claimants are fictional. Historical command crises inform the mechanics without turning real people into possessed generals.

## Future expansion gates

Reopen broad design only when:

- implementation proves the dynamic-country model needs a different package
- a new family cannot fit the registry profile classes
- a derivative state becomes a real global threat and deserves a separate super-event or shared world-threat source
- several reworked military events can support a coherent event cluster
- implementation reveals a recurring registry workflow that belongs in a project skill

Do not expand simply because another possible unit, portrait, focus, or incident can be imagined.
