# Infantry Spawn super-event research prompt

Use `chaos-redux-super-events`. This event does not need a terminal campaign state, but it can justify escalation super-events when the crisis becomes publicly larger than a normal popup. All title wording, button remarks, quotes, cultural references, and audio selections require research. Do not turn working labels into final localisation.

Event id: 019. Event slug: infantry_spawn.

## Candidate super-event 1, possessed command revolt

Role: escalation reveal.

Trigger direction: first time Evolution III creates a large possessed-general revolt, or first time multiple countries face simultaneous Barracks State revolts from the triggerable scenario.

Tone: military dread, strange command, soldiers obeying officers whose authority does not trace back to any known state. It should feel like the problem has moved from sudden manpower to a world army crisis.

Title direction: short title about the chain of command breaking under unnatural officers. Research required. Do not write a final title without source review if it draws from a real phrase.

Description direction: world governments notice that whole units are following commanders who appeared with complete staffs and no past. Avoid saying it is a warning. Describe public fear and observed military consequences.

Button remark direction: grim military or bureaucratic reaction, possibly a short researched military idiom. Research required.

Quote direction: real quote about command, obedience, armies, ambition, or dangerous generals. Prefer public domain military, political, or philosophical sources. Research required.

Audio direction: licensed or public domain music with martial unease, not a sound effect or oscillator cue. Unique final track required if implemented.

Image direction: generated super-event image showing a possessed officer and massed strange troops in period military composition, no real likeness, no text.

## Candidate super-event 2, first chaos splinter

Role: high-chaos escalation reveal.

Trigger direction: first time Infantry Spawn creates a Ragged horde, Grey host, Stone host, or registry-defined chaos splinter country.

Tone: containment failure, army registry becomes a gate for nonhuman or supernatural formations. The event should make clear that this is not the parent Zombie Outbreak or Death event.

Title direction: short title about an army leaving the human roster or a regiment becoming a country. Research required if using a real phrase.

Description direction: a local state loses command over strange units that no longer answer the parent country. It should explain visible consequences without parent-event spoilers.

Button remark direction: grim, fearful, or coldly official reaction. Research required for any cultural line.

Quote direction: real quote about monsters, armies, obedience, or human institutions creating what they cannot command. Research required.

Audio direction: licensed or public domain music with supernatural military tension, unique track if implemented.

Image direction: generated super-event image with a central nonhuman military formation, profile variant possible for zombie, ghost, or golem if implementation chooses multiple images.

## Candidate super-event 3, triggerable maximum crisis

Role: scenario launch spectacle.

Trigger direction: optional only for the triggerable scenario at Maximum intensity if many countries immediately revolt.

Tone: sudden global barracks crisis. It should feel like a sandbox challenge start rather than a canonical world-end.

Title direction: research required if final title uses a real phrase.

Description direction: multiple countries report immediate military splinters and impossible unit rolls. Avoid finality language.

Button remark direction: short reaction with grim irony or military understatement, research required.

Quote direction: real quote about armies, chaos, or command. Research required.

Audio direction: unique licensed or public domain track if implemented.

Image direction: generated super-event image showing multiple columns or banners forming under a dark military sky, no maps as main subject unless the asset lead decides it is strongest.

## Research and documentation rules

For each accepted super-event, create or update `docs/super_events/019_infantry_spawn_super_event_research.md`. Document quote candidates, selected quote, source, confidence, button remark candidates, audio candidates, final audio source, license, final file paths, image handoff, and implementation notes. Unverified source-dependent text or unclear audio license is a blocker.
