# Infantry Spawn planning package

This package contains the full planning handoff for Event 019 Infantry Spawn.

## Contents

- `specs/` contains the source event specification split into six parts.
- `matrices/` contains template, decision, country package, and AI matrices.
- `prompts/` contains asset, super-event, achievement, decision, coding, and goal prompts.
- `research/reading_manifest.md` records the uploaded files read and limitations.
- `handoff/` contains subagent work orders and a temporary continuation prompt.

## Important limitation

This is a planning package. It does not implement gameplay files or generate final assets. The uploaded project skill, catalog, Markdown, and subagent files were read. The actual repository tree, offline Paradox wiki snapshot, vanilla HOI4 docs, workbook, and custom subagent execution were not available in this chat.
