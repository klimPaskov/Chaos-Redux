# Advanced event system design

Read the relevant complete section before specifying a major focus tree, country package, starting or reinforcing forces, or an event that can materially change global Chaos.

The advanced standards are split into three files. Read the file that matches the work.

- [Focus tree, mechanic, and decision design standards](advanced-focus-tree-design.md): read when specifying a major focus tree, its routes, reward and idea design, special mechanics and faction systems, reward-dump and exploit checks, or decision categories. Sections: Focus tree path design standard through What the implementation agent owns.
- [Country package, starting forces, and model planning standards](advanced-country-and-forces-design.md): read when specifying a country package, dynamic identity, country naming, a formable nation, starting or reinforcing forces, a new unit type, or a 3D model or skeletal animation. Sections: Country package and dynamic identity standard, Starting forces and reinforcement pathway standard.
- [Chaos generation and feedback standards](advanced-chaos-generation-design.md): read when an event, decision, route, or evolution adds, scales, repeats, or reduces global Chaos. Section: Chaos generation and feedback standard.
